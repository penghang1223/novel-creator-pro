# 小说记忆

Inspect or maintain novel memory.

**输入**：`/novel-memory [小说名] [stats|pack|sync|review]`

**示例命令**：
```bash
python novel_creation_promax/novel-memory-pro/scripts/memory_manager.py stats --memory-dir "{小说目录}/记忆"
python novel_creation_promax/novel-memory-pro/scripts/memory_manager.py chapter-pack --chapter N --memory-dir "{小说目录}/记忆"
python novel_creation_promax/novel-memory-pro/scripts/memory_manager.py review-pack --chapter N --memory-dir "{小说目录}/记忆"
```
