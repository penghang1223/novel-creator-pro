# AI写作黑名单

> 可直接校对版（禁用词+替换词+禁用句式 规整版）

## 核心原则

**人会用"突然""微微""沉默"，但不会用下面的表达。** 区分标准：念出来觉得不像人话的，就是 AI 味。

---

## 一、精确量化时间（全禁用，直接替换）

人叙述时不会精确到秒、分钟，尤其涉及心理活动、对视、沉默、发呆场景。

| 禁用AI句式 | 推荐人话替换 |
| --- | --- |
| 沉默了两秒/三秒/几秒 | 沉默片刻、没说话、静了好一会儿 |
| 看了他整整两分钟 | 定定望着他、看了他许久 |
| 零点几秒后、0.5秒后、数秒之后 | 一瞬间、转眼之间、倏忽间 |
| 等了足足五分钟 | 等了好久、耐着性子等了片刻 |
| 恰好三秒后、整整一瞬 | 过了片刻 |
| 停顿了一下下、略微停顿片刻 | 顿了顿、稍稍一顿 |
| 过去了十分钟之久 | 一晃十来分钟过去 |
| 仅仅过了一秒钟 | 转瞬之间 |

## 三、AI生硬连接句式（禁用→替换）

| 禁用AI句式 | 人话替换 |
| --- | --- |
| 然而、尽管如此、即便如此 | 但是、不过、可 |
| 他之所以这样做，是因为… | 他这么做自有缘由、他心里早有盘算 |
| 总而言之、综上所述、由此可见 | 直接删，网文不用总结 |
| 不仅如此，他还…、除此之外还有… | 他不光…还… |
| 正是因为…才…、究其原因是因为… | 就是因为…才… |
| 在这一刻、此时此刻、就在这时 | 这一刻、这会儿 |
| 不得不说、不得不承认 | 说实话、坦白讲 |

## 五、AI心理描写（禁用→替换）

| 禁用AI写法 | 人话替换 |
|------------|----------|
| 他在心里暗暗想道、心中暗自思忖 | 他想、他暗自嘀咕 |
| 心中不禁涌起一阵XX | 只觉得心头发堵、心里一阵发慌 |
| 一股莫名的情绪在胸中蔓延 | 说不上来是什么滋味 |
| 内心翻江倒海、内心波澜四起 | 心里乱作一团 |
| 一种难以言喻的感觉萦绕心头 | 心里五味杂陈 |
| 脑海中闪过一个念头、脑中灵光一闪 | 忽然想到、念头猛地冒出来 |
| 不由得暗自庆幸、不由得心生后怕 | 暗自庆幸、心里一阵后怕 |
| 内心无比纠结、心中充满矛盾 | 左右为难，拿不定主意 |

## 七、安全白名单（可正常使用，别套AI模板即可）

突然、微微、沉默、感觉、觉得、嘴角、很、特别、看到、听见、抬头、低头、好像、似乎、仿佛、顿了顿、愣了下

---

### 使用规则（一键自查）

1. 全文检索上面**禁用词**，搜到直接删掉替换；
2. 看到「精确到秒/分钟」的时间描写，全部改成模糊时长；
3. 心理描写不要写「心里想、心中涌起」，改用动作、神态、直白情绪；
4. 少用书面连接词：然而、综上所述、正是因为 这类全部换掉。
