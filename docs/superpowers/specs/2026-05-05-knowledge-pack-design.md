# 知识包自动组装设计

> **问题**：知识库 864 个文件、SKILL.md 1072 行，但写作时"想不起来用"、"加载了但注意力分散"、"知道但做不到"。

> **目标**：写前自动从知识库提取本章相关的 5-10 个知识点，输出精简知识包（~200-400 字），注入写作 prompt。后续可扩展为"按阶段动态切换"（Part B）。

---

## 核心思路

从"一次性加载全文库"转变为"按需组装本章知识包"。AI 在写前阶段根据章节细纲，语义判断哪些知识对本章最相关，组装为精简指引。

## 实现方式

**AI 自动组装**（非 Python 脚本）。理由：
- "适用技法"需要语义判断，硬编码匹配规则不可行
- AI 已经在 Phase 0 读取细纲，顺带组装知识包不增加额外步骤
- 不需要维护新的 Python 组件

## 改动范围

| 文件 | 动作 | 说明 |
|------|------|------|
| `novel_creation_promax/SKILL.md` | 修改 | Phase 0 新增 Step 5：知识包组装 |

**不改**：Python 脚本、knowledge_base 目录结构、其他流程

## 在写作流程中的位置

```
阶段 0：写前准备
  1. 加载写作宪法 ✓
  2. 9问必答 ✓
  3. 写前5项检查 ✓
  4. 约束组装（已有）✓
  5. ★ 知识包组装（新增）
  6. 套路预判 ✓
```

## AI 执行步骤（写入 SKILL.md）

### Step 1：读取本章细纲

从 `细纲/卷X_标题.md` 中定位本章对应的段落，提取：
- 出场人物
- 场景类型（对话 / 动作 / 情绪 / 悬疑 / 环境）
- 核心冲突 / 情绪基调
- 章末截断点

### Step 2：按场景类型读取对应知识

| 场景类型 | 读取路径 | 典型内容 |
|---------|---------|---------|
| 对话场景 | `knowledge_base/40_Writing/03_人物与对话/` | 对话六要素、动作锚点、回避式回答 |
| 情绪/心理 | `knowledge_base/40_Writing/04_场景与描写/` | 行为>生理>心理>命名优先级 |
| 悬疑/紧张 | `knowledge_base/40_Writing/02_节奏与结构/` | 节奏模板、爽点密度 |
| 去AI | `knowledge_base/40_Writing/05_降AI痕迹/` | 七大反模式、三刀法则 |
| 毒舌/特殊语体 | `knowledge_base/70_Corpus/毒舌知识库.md` | 毒舌话术模板 |

**规则**：某类场景不涉及 → 跳过对应读取（不浪费 token）

### Step 3：读取出场人物档案

从 `设定/人物设定.md`（或 `设定/人物档案/`）提取本章出场角色的：
- 矛盾特质
- 行为指纹
- 负面约束（本章不能做什么）

### Step 4：组装输出

格式如下（~200-400 字）：

```markdown
# 第N章 知识包

## 出场人物
- 角色A：矛盾特质=xxx，行为指纹=xxx，本章注意=xxx
- 角色B：矛盾特质=xxx，行为指纹=xxx，本章注意=xxx

## 本章场景类型：[类型]
适用技法：
- [技法要点1]
- [技法要点2]

## 本章高危项
- 绝对禁止词已加载（13个）
- 高危限制词 ≤3 次
- 本章重点去AI：[具体项]

## 平台要求
- 字数：[范围]
- 截断点：[事件]
```

### Step 5：注入写作 prompt

知识包内容在 Pass 1 开始时直接包含在写作指令中，作为"本章写作指引"。

## 关键约束

1. 知识包是**建议不是命令**，不替代写作宪法的硬约束
2. 每次写前重新生成，不缓存（保证跟最新状态一致）
3. 知识包总字数控制在 400 字以内（避免信息过载）
4. 如果知识库中找不到对应文件，跳过该项，不报错

## 验证方法

1. 用现有小说（她眼里有我的未来）测试：选第 12 章，跑一遍知识包组装流程
2. 检查输出是否包含：出场人物 + 场景技法 + 高危项 + 平台要求
3. 人工判断：知识包中的知识点是否对本章真正相关
4. 对比：用知识包写的 Pass 1 vs 不用知识包写的 Pass 1（AI味/角色一致性/技法运用）

## 未来扩展（Part B）

Part A 验证通过后，可扩展为：
- 写中按场景切换知识子集（写对话时弹出对话技法，写情绪时弹出情绪规则）
- 知识包 + 阶段引导结合，实现"写到哪查到哪"
