# 小说创意生成与评分

## 任务目标
- 本 Skill 用于：为小说作者生成完整的创作方案，包括标题、简介、大纲和人物设定；对已有创意进行专业评估和优化建议
- 能力包含：平台热门方向分析、流派模板应用、五维创意评分、智能优化建议
- 触发条件：用户需要创作新小说、评估已有创意、或寻求创意灵感时

## 前置准备
- 无外部依赖，所有功能由智能体自然语言处理
- 使用前确认目标平台和题材偏好

## 操作步骤

### 流程一：创意生成

**标准流程**：

1. 收集用户需求
   - 确定目标平台（起点/晋江/番茄/七猫/纵横/知乎盐选/飞卢/海棠）
   - 确定题材流派（玄幻/仙侠/现言/古言/系统/穿越/都市/历史/快穿等）
   - 询问特殊偏好（如主角设定、核心冲突、篇幅等）

2. 分析平台特征（参考 [references/platform-hot-trends.md](references/platform-hot-trends.md)）
   - 读取平台热门方向
   - 理解标题风格和内容偏好
   - 避开平台雷区

3. 应用流派模板（参考 [references/genre-templates.md](references/genre-templates.md)）
   - 提取流派核心元素
   - 选择合适的人物原型
   - 确定冲突模式和大纲结构

4. 生成完整方案
   - **标题**：生成 3-5 个版本，符合平台调性
   - **简介**：100-200 字，包含强钩子和核心冲突
   - **大纲**：主线方向 + 3-5 个分卷关键节点
   - **人物设定**：主角（身份/性格/动机）+ 反派（对立关系）+ 重要配角

5. 输出平台适配说明
   - 说明方案如何契合平台特点
   - 标注潜在的优化点

### 流程二：创意评分与优化

**标准流程**：

1. 接收用户创意
   - 理解用户提供的标题、简介、大纲或人物设定
   - 识别目标平台和题材

2. 五维评分（参考 [references/scoring-criteria.md](references/scoring-criteria.md)）
   - **创新性**（10%）：设定是否新颖、是否有独特视角
   - **市场潜力**（25%）：是否符合平台热门趋势、受众需求
   - **可读性**（20%）：世界观是否自洽、逻辑是否清晰
   - **情绪价值**（25%）：爽点/情感张力/代入感强度
   - **商业价值**（20%）：IP衍生潜力、长期连载价值

3. 生成评分报告
   - 输出总分（0-100）
   - 各维度得分和评价
   - 优点和不足分析

4. 提供优化建议（参考 [references/optimization-tips.md](references/optimization-tips.md)）
   - 针对每个不足点给出具体改进建议
   - 参考成功案例进行调整

5. 生成优化版本（可选）
   - 根据建议生成完整优化方案
   - 对比优化前后的关键变化

## 使用示例

### 示例 1：番茄平台现言创意生成

**用户输入**：
"帮番茄平台生成一个现言甜宠的创意，要火爆、有反转"

**输出内容**：
- 标题（3个版本）：
  1. 《闪婚后，千亿总裁宠我入骨》
  2. 《退婚当天，我被首富儿子求婚了》
  3. 《假戏真做：陆先生的替嫁新娘》
- 简介：[100-150字，包含婚姻契约、身份反转、甜蜜宠溺等核心元素]
- 大纲：[主线 + 分卷节点：相遇契约、升温心动、误会波折、身份揭晓、圆满结局]
- 人物设定：[男女主身份、性格、核心动机]
- 平台适配说明：符合番茄短篇节奏、强冲突、强代入感特点

**关键要点**：
- 番茄平台偏好快节奏和强冲突，标题需包含婚姻/总裁/反转等关键词
- 简介开头即抛出悬念或冲突

### 示例 2：起点玄幻创意评分优化

**用户提供**：
```
标题：《修仙之路》
简介：一个少年意外获得神秘玉佩，开始修仙之旅，最终成为最强者。
```

**输出内容**：
```
评分：65/100
- 创新性：4/10（设定过于常规，缺乏新意）
- 市场潜力：6/10（有市场但缺乏突出亮点）
- 可读性：8/10（结构清晰，但内容单薄）
- 情绪价值：7/10（有爽点但不够强烈）
- 商业价值：5/10（竞争力弱，难以脱颖而出）

优点：结构完整，目标明确
不足：标题平淡，简介无钩子，金手指不明确，冲突单一

优化建议：
1. 标题加入金手指：《开局签到不死之身》或《修仙：我能看到万物属性》
2. 简介强化冲突："开局被退婚，意外签到神级功法，逆袭之路开启，终成仙帝"
3. 增加明确金手指和升级体系
4. 增加反派设定，强化对立关系和打脸爽点
5. 大纲明确分卷目标和关键打脸节点

优化版本：
标题：《修仙：开局签到神级体质》
简介：[优化后的简介]
大纲：[详细分卷]
人物设定：[增强的人物关系]
```

**关键要点**：
- 起点偏好明确金手指和升级体系
- 简介需要强钩子和爽点

### 示例 3：晋江古言创意生成

**用户输入**：
"晋江平台，古言权谋题材，要有男女主博弈"

**输出内容**：
- 标题（3个版本，文艺风格）：
  1. 《凤谋：权倾天下》
  2. 《山河为聘：摄政王的掌心娇》
  3. 《此间山河，共君谋》
- 简介：[权谋博弈、情感纠葛、朝堂风云]
- 大纲：[宫廷斗争、权力交替、情感升温、终极对决]
- 人物设定：[权谋型男主/聪慧型女主、复杂配角关系网]

**关键要点**：
- 晋江标题偏文艺唯美
- 注重情感细腻和人物关系
- 权谋与情感并重
