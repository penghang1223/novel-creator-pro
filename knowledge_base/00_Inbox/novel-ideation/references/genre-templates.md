# 流派模板

## 玄幻/仙侠

**核心元素**：
- 等级体系：练气→筑基→金丹→元婴→化神→飞升
- 修炼境界：明确划分，实力差距巨大
- 功法宝物：功法、法宝、丹药、阵法
- 宗门势力：宗门、家族、圣地、魔域

**人物原型**：
- 主角：穿越者/重生者/废柴逆袭/神秘传承
- 反派：宗门长老、世家少爷、魔道大能
- 配角：忠心伙伴、神秘老者、红颜知己

**冲突模式**：
- 夺宝：争夺珍贵资源或宝物
- 争霸：宗门争霸、正邪大战、飞升之战
- 复仇：家族灭门、恩怨情仇
- 守护：守护宗门、守护亲人、守护世界

**大纲结构**：
1. 新手村：主角觉醒金手指，初步修炼
2. 宗门篇：加入宗门，内部竞争，初露锋芒
3. 大赛篇：参加大赛，一举成名，获得机缘
4. 异界篇：前往更高境界，更广阔的天地
5. 飞升篇：最终对决，飞升成仙

**成功案例**：《凡人修仙传》、《遮天》、《完美世界》

## 现言甜宠

**核心元素**：
- 男女主设定：身份、性格、相遇方式
- 情感升温：暧昧、表白、甜蜜相处
- 情感波折：误会、前任、家庭反对
- 圆满结局：误会消除，携手一生

**人物原型**：
- 男主：霸道总裁/高冷学霸/温柔医生/电竞大神
- 女主：独立女性/小太阳/元气少女/坚强姑娘
- 反派：绿茶前女友/恶毒继母/势利亲戚

**冲突模式**：
- 身份差距：豪门与平民、上司与下属
- 误会波折：隐瞒身份、误会加深
- 外界阻碍：家庭反对、前任纠缠
- 内心挣扎：感情与事业、过去与现在

**大纲结构**：
1. 相遇：意外相遇，印象深刻
2. 暧昧：频繁接触，情感升温
3. 表白：感情爆发，确定关系
4. 甜蜜：甜蜜相处，情比金坚
5. 波折：误会冲突，感情受挫
6. 和好：误会消除，圆满结局

**成功案例》：《微微一笑很倾城》、《何以笙箫默》、《你是我的荣耀》

## 古言权谋

**核心元素**：
- 朝堂势力：皇帝、后妃、权臣、世家
- 宫廷斗争：夺嫡之争、后宫争斗
- 江湖势力：武林门派、江湖恩怨
- 情感纠葛：政治联姻、真情假意

**人物原型**：
- 男主：摄政王/权臣/皇子/江湖侠客
- 女主：皇后/公主/权谋之女/江湖女侠
- 反派：敌对皇子、奸佞权臣、后宫嫔妃

**冲突模式**：
- 权力斗争：夺嫡之争、权力交替
- 宫廷争斗：后宫倾轧、家族恩怨
- 江湖恩怨：门派争斗、江湖风云
- 情感纠葛：政治与感情、真心与利用

**大纲结构**：
1. 初入朝堂：女主入宫，初识男主
2. 权力博弈：朝堂斗争，权谋对决
3. 情感升温：相处加深，暗生情愫
4. 危机爆发：权力危机，感情受挫
5. 终极对决：最终对决，胜负已分
6. 圆满结局：携手一生，共享江山

**成功案例》：《琅琊榜》、《甄嬛传》、《芈月传》

## 系统文

**核心元素**：
- 系统设定：系统类型、功能机制、任务系统
- 奖励机制：奖励类型、奖励强度、奖励获取
- 升级体系：等级划分、实力提升
- 打脸爽点：逆袭打脸、装逼打脸

**人物原型**：
- 主角：绑定系统的普通人，通过系统逆袭
- 反派：各种看不起主角的人，被打脸对象
- 配角：被主角帮助或影响的人

**冲突模式**：
- 完成任务：系统发布任务，主角完成获得奖励
- 逆袭打脸：主角被轻视，通过系统逆袭
- 探索未知：探索系统功能，发现更多可能
- 最终目标：系统的最终目标或主角的终极追求

**大纲结构**：
1. 开局：主角绑定系统，获得新手奖励
2. 新手任务：完成新手任务，初步变强
3. 第一次打脸：被轻视，通过系统逆袭
4. 地图升级：前往更高层次，遇到更强敌人
5. 系统升级：系统功能增强，获得更强能力
6. 最终目标：完成最终任务，达成终极目标

**成功案例》：《超级神基因》、《全球高武》、《开局签到荒古圣体》

## 穿越重生

**核心元素**：
- 穿越方式：意外穿越、系统穿越、重生回到过去
- 身份转变：从现代人到古代人，从弱者到强者
- 预知未来：知道未来走向，提前布局
- 改变命运：改变原本的命运轨迹

**人物原型**：
- 主角：穿越者/重生者，拥有现代知识或未来记忆
- 反派：原本命运中欺压主角的人
- 配角：被主角改变命运的人

**冲突模式**：
- 改变命运：试图改变原本悲惨的命运
- 报复仇恨：报复前世或穿越前欺负自己的人
- 利用预知：利用对未来或现代知识的了解
- 命运对抗：与原本的命运轨迹对抗

**大纲结构**：
1. 穿越/重生：主角穿越或重生到新身份
2. 初步改变：利用优势，初步改变命运
3. 遭遇阻碍：遇到阻碍，必须应对
4. 力量积累：积累力量，为后续做准备
5. 重大转折：面临重大转折，必须做出选择
6. 改变结局：彻底改变原本的命运结局

**成功案例》：《庆余年》、《知否知否应是绿肥红瘦》、《重生之将门毒后》

## 都市异能

**核心元素**：
- 异能设定：异能类型、异能等级、异能觉醒
- 现代背景：都市生活、现代社会
- 隐藏世界：异能者组织、神秘势力
- 升级体系：异能修炼、等级提升

**人物原型**：
- 主角：觉醒异能的普通人，逐渐变强
- 反派：邪恶组织、强大异能者
- 配角：异能者组织成员、朋友、家人

**冲突模式**：
- 异能对决：异能者之间的战斗
- 组织对抗：正义组织与邪恶势力的对抗
- 身份保密：隐藏异能者身份
- 守护家人：利用异能守护家人和朋友

**大纲结构**：
1. 觉醒：主角觉醒异能，初步了解异能世界
2. 初战：第一次使用异能战斗，获得胜利
3. 加入组织：加入异能者组织，接受任务
4. 强敌出现：遇到强大敌人，必须应对
5. 力量提升：通过修炼和战斗，提升实力
6. 最终对决：与最终敌人对决，守护世界

**成功案例》：《龙族》、《都市修仙》、《第一序列》

## 历史爽文

**核心元素**：
- 历史背景：真实或架空的历史朝代
- 权谋夺嫡：皇子夺嫡、权臣争斗
- 建立霸业：开疆拓土、建立王朝
- 科技改良：利用现代知识改良科技

**人物原型**：
- 主角：穿越到古代的现代人，利用现代知识
- 反派：敌对皇子、奸佞权臣、外敌
- 配角：忠诚的部下、盟友、家人

**冲突模式**：
- 夺嫡之争：皇子之间的夺嫡之争
- 外敌入侵：外敌入侵，必须抵御
- 建立霸业：开疆拓土，建立霸业
- 科技改良：利用现代知识改良科技

**大纲结构**：
1. 穿越：主角穿越到古代，成为皇子或权臣
2. 初露锋芒：利用现代知识，初步展现才华
3. 夺嫡之争：参与夺嫡之争，击败对手
4. 外敌入侵：外敌入侵，率军抵御
5. 建立霸业：开疆拓土，建立霸业
6. 建立王朝：建立新王朝，登基称帝

**成功案例》：《大明王朝1566》、《庆余年》、《回到明朝当王爷》

## 快穿攻略

**核心元素**：
- 系统设定：快穿系统、任务系统、积分奖励
- 多个世界：穿越到不同的世界，完成不同任务
- 攻略目标：每个世界的攻略目标
- 情感成长：主角在任务中逐渐成长

**人物原型**：
- 主角：绑定快穿系统，穿越到不同世界完成任务
- 攻略目标：每个世界的攻略对象
- 配角：每个世界的重要配角

**冲突模式**：
- 完成任务：完成每个世界的任务
- 攻略目标：攻略每个世界的目标
- 积分奖励：完成任务获得积分，兑换能力
- 情感成长：在任务中逐渐成长

**大纲结构**：
1. 绑定系统：主角绑定快穿系统，开始任务
2. 第一个世界：穿越到第一个世界，完成任务
3. 第二个世界：穿越到第二个世界，完成任务
4. 多个世界：穿越到多个世界，完成各种任务
5. 最终世界：穿越到最后一个世界，完成终极任务
6. 任务完成：完成所有任务，达成最终目标

**成功案例》：《快穿之炮灰女配逆袭记》、《快穿之攻略男神》、《快穿之系统你坑我》

## 无限流

**核心元素**：
- 主神空间：穿越到主神空间，接受任务
- 副本世界：穿越到不同的副本世界，完成任务
- 任务系统：主神发布的任务，必须完成
- 生存挑战：在副本世界中生存，完成挑战

**人物原型**：
- 主角：进入主神空间的普通人，逐渐变强
- 队友：主神空间的其他人，组成团队
- 敌人：副本世界中的敌人，必须击败

**冲突模式**：
- 完成任务：完成每个副本世界的任务
- 生存挑战：在副本世界中生存
- 团队合作：与队友合作，完成任务
- 实力提升：通过任务提升实力

**大纲结构**：
1. 进入主神空间：主角进入主神空间，了解规则
2. 第一个副本：进入第一个副本世界，完成任务
3. 团队组建：组建团队，合作完成任务
4. 多个副本：进入多个副本世界，完成各种任务
5. 最终副本：进入最终副本，完成终极任务
6. 回归现实：完成所有任务，回归现实

**成功案例》：《无限恐怖》、《恐怖复苏》、《惊悚乐园》

## 同人衍生

**核心元素**：
- 原作背景：基于原作的世界观和设定
- 原作人物：原作中的主要人物
- 新角色：主角和原创配角
- 新剧情：基于原作设定的原创剧情

**人物原型**：
- 主角：穿越到原作世界的现代人
- 原作人物：原作中的主要人物
- 原创配角：原创的配角

**冲突模式**：
- 改变原作：试图改变原作的某些剧情
- 与原作人物互动：与原作人物产生互动
- 新剧情：基于原作设定的新剧情
- 最终目标：达成某个目标，改变原作结局

**大纲结构**：
1. 穿越原作：主角穿越到原作世界
2. 初步改变：利用对原作的了解，初步改变剧情
3. 深入剧情：深入原作剧情，产生更大影响
4. 新剧情：产生原作没有的新剧情
5. 最终目标：达成最终目标，改变原作结局
6. 改变结局：彻底改变原作的结局

**成功案例》：《海贼之最强暴君》、《火影之忍界传说》、《斗罗之开局吞噬唐三》
