# 创意评分标准

## 五维评分体系

### 1. 创新性（10%）

**评分标准**：
- 9-10分：设定极其新颖，有独特视角，开创全新模式
- 7-8分：设定有新意，在常见题材中有创新点
- 5-6分：设定常规，缺乏新意，但无明显问题
- 3-4分：设定陈旧，完全落入俗套
- 1-2分：设定毫无新意，严重套路化

**评价维度**：
- 核心设定是否新颖
- 是否有独特的切入角度
- 是否能给人耳目一新的感觉
- 是否避免了常见套路

**示例**：
- 高分：《三体》的黑暗森林理论、《诡秘之主》的魔药体系
- 中等：《修仙之路》的常见修仙设定
- 低分：完全照搬经典设定的作品

---

### 2. 市场潜力（25%）

**评分标准**：
- 9-10分：精准契合平台热门趋势，受众广泛，极易爆火
- 7-8分：符合平台热门方向，有明确受众
- 5-6分：有一定市场，但竞争激烈
- 3-4分：市场需求小，受众狭窄
- 1-2分：完全不符合市场趋势，无人问津

**评价维度**：
- 是否符合平台热门方向
- 是否有明确的目标受众
- 是否有爆火的潜质
- 是否与市场趋势一致

**示例**：
- 高分：番茄平台的闪婚总裁文、起点平台的开局签到文
- 中等：普通的修仙文、普通的言情文
- 低分：过于小众的题材、完全不符合平台调性的作品

---

### 3. 可读性（20%）

**评分标准**：
- 9-10分：世界观自洽，逻辑清晰，设定合理
- 7-8分：世界观基本自洽，逻辑基本清晰
- 5-6分：世界观有轻微漏洞，但可接受
- 3-4分：世界观混乱，逻辑不清，设定冲突
- 1-2分：世界观完全崩塌，逻辑混乱

**评价维度**：
- 世界观是否自洽
- 逻辑是否清晰
- 设定是否合理
- 是否有明显矛盾

**示例**：
- 高分：设定严谨、逻辑自洽的作品
- 中等：有轻微设定问题但不影响阅读的作品
- 低分：设定冲突、逻辑混乱的作品

---

### 4. 情绪价值（25%）

**评分标准**：
- 9-10分：爽点/情感张力极强，代入感极强，读者欲罢不能
- 7-8分：爽点/情感张力较强，代入感较强
- 5-6分：有爽点/情感张力，但不够强烈
- 3-4分：爽点/情感张力弱，代入感差
- 1-2分：无爽点/情感张力，毫无代入感

**评价维度**：
- 爽点是否密集（爽文）
- 情感张力是否强烈（言情）
- 代入感是否强
- 是否能引起读者情绪共鸣

**示例**：
- 高分：爽点密集的打脸文、情感细腻的言情文
- 中等：有一定爽点/情感，但不够强烈
- 低分：爽点稀疏、情感平淡的作品

---

### 5. 商业价值（20%）

**评分标准**：
- 9-10分：IP衍生潜力极大，长期连载价值极高
- 7-8分：IP衍生潜力较大，有长期连载价值
- 5-6分：有一定IP潜力，可长期连载
- 3-4分：IP潜力小，难以长期连载
- 1-2分：无IP潜力，无法长期连载

**评价维度**：
- 是否有IP衍生潜力（影视、游戏、动漫等）
- 是否有长期连载价值
- 是否有系列化潜力
- 是否有扩展空间

**示例**：
- 高分：世界观宏大、人物丰富的作品
- 中等：有一定扩展空间的作品
- 低分：格局小、无法扩展的作品

## 评分报告示例

### 示例 1：低分创意

**用户提供**：
```
标题：《修仙之路》
简介：一个少年意外获得神秘玉佩，开始修仙之旅，最终成为最强者。
```

**评分报告**：
```
总分：65/100

创新性：4/10（设定过于常规，缺乏新意，完全落入俗套）
- 问题：穿越+玉佩+修仙是极其常见的套路，没有任何新意
- 建议：加入独特的金手指或设定，如"能看到万物属性"、"签到系统"等

市场潜力：6/10（有一定市场，但竞争激烈，缺乏突出亮点）
- 问题：修仙文市场竞争激烈，这个设定没有任何突出点
- 建议：瞄准平台热门方向，如"开局签到"、"系统文"等

可读性：8/10（结构清晰，但内容单薄）
- 优点：结构完整，目标明确
- 问题：设定过于简单，缺乏细节

情绪价值：7/10（有爽点但不够强烈）
- 问题：没有明确的爽点和冲突，情感张力不足
- 建议：强化打脸爽点和升级快感

商业价值：5/10（竞争力弱，难以脱颖而出）
- 问题：设定普通，竞争力弱，难以长期连载
- 建议：增强世界观和人物设定，提升IP潜力

优点：结构完整，目标明确
不足：标题平淡，简介无钩子，金手指不明确，冲突单一，缺乏新意
```

### 示例 2：高分创意

**用户提供**：
```
标题：《开局签到不死之身》
简介：林风穿越到灵气复苏的世界，开局签到不死之身，从此横推一切。只要死不了，就能无限变强。当敌人绝望地看着他从废墟中爬起，他知道，他无敌了。
```

**评分报告**：
```
总分：88/100

创新性：8/10（设定有新意，不死之身是独特的金手指）
- 优点：不死之身是独特的金手指，有别于常见的系统或功法
- 建议：可以进一步丰富不死之身的机制和应用场景

市场潜力：9/10（符合起点热门方向，爆火潜质强）
- 优点：符合起点平台"签到+无敌流"热门趋势，极易爆火
- 建议：加强打脸爽点和升级节奏

可读性：9/10（设定清晰，逻辑自洽）
- 优点：设定清晰，逻辑自洽，世界观合理
- 建议：进一步丰富世界观细节

情绪价值：9/10（爽点密集，代入感强）
- 优点：不死之身带来的无敌感极强，爽点密集
- 建议：强化敌人绝望的描写，增强爽感

商业价值：9/10（IP潜力大，长期连载价值高）
- 优点：设定有趣，世界观宏大，有IP衍生潜力
- 建议：可以开发系列化作品

优点：设定新颖，符合平台热门，爽点密集，逻辑清晰
不足：可以进一步丰富世界观和人物设定
```

---

## 评分注意事项

1. **客观公正**：基于标准客观评分，避免主观偏见
2. **具体依据**：每个分数都要有具体的评价依据
3. **建设性**：评分不仅要指出问题，还要提供改进建议
4. **平台适配**：评分时要考虑目标平台的特点
5. **受众定位**：评分时要考虑目标受众的偏好
