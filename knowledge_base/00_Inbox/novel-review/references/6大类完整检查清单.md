# 6大类完整检查清单

## 概览
行业级小说审稿必须覆盖的完整检查清单，包含60+检查点，确保无盲区。

---

## 第一类：商业（标题 + 爽点 + 留存）

### 1.1 标题与封面
**核心问题：用户点不点？**

- [ ] **标题钩子**
  - 是否有冲突元素（如"废柴逆袭"、"总裁的替身妻"）
  - 是否有反差感（如"高冷校霸的软肋"）
  - 是否有悬念（如"消失的第13人"）
  - 钩子是否足够强（能否吸引点击）

- [ ] **题材传达**
  - 标题是否清晰传达题材（玄幻/言情/悬疑/科幻）
  - 是否有误导（标题与内容不符）
  - 读者能否从标题判断是否喜欢

- [ ] **点击欲**
  - 标题是否有吸引力
  - 是否有流行元素（符合当前趋势）
  - 是否有记忆点（容易被记住）

- [ ] **平台风格**
  - 是否符合目标平台风格
  - 起点：升级、打脸、爽点
  - 晋江：感情、甜虐、人物
  - 番茄：快节奏、短篇、爽文
  - 豆瓣：深度、思考、文学性

---

### 1.2 开头与前3章（留存关键）
**核心问题：用户走不走？**

- [ ] **快速进入冲突**
  - 前1000字是否进入核心冲突
  - 是否有明确的冲突事件
  - 冲突是否足够强（吸引人）

- [ ] **核心事件**
  - 前3章是否有核心事件
  - 事件是否推动剧情
  - 事件是否建立主角形象

- [ ] **想继续看的欲望**
  - 前3章结尾是否有悬念/钩子
  - 是否有爽点初步展现
  - 是否有让人好奇的地方

- [ ] **避免世界观堆砌**
  - 前3章是否避免大量设定说明
  - 设定是否随剧情自然展开
  - 开篇信息量是否适中

---

### 1.3 情绪与爽点
**核心问题：持续刺激读者**

- [ ] **情绪起伏**
  - 是否有情绪高点（爽点、甜点、高潮）
  - 是否有情绪低点（虐点、困境、挫折）
  - 情绪起伏是否明显（让读者有感受）

- [ ] **爽点有效性**
  - 爽点是否有效（不是自嗨）
  - 爽点是否有铺垫（积蓄情绪）
  - 爽点是否有爆发（释放情绪）

- [ ] **打脸/反转成立**
  - 打脸是否有铺垫
  - 反转是否合理（意料之外情理之中）
  - 打脸/反转是否爽

- [ ] **持续刺激**
  - 是否有持续的情绪刺激
  - 是否有长时间平淡期（超过15章无爽点）
  - 读者是否一直有期待

---

## 第二类：结构（剧情 + 节奏）

### 2.1 剧情结构
**核心问题：骨架是否稳固？**

- [ ] **主线清晰度**
  - 是否有清晰的主线目标
  - 主线是否贯穿全文
  - 主线是否容易理解

- [ ] **每章结构**
  - 每章是否有明确目标
  - 每章是否有冲突
  - 每章是否有结果（进展/挫折）

- [ ] **无效剧情识别**
  - 是否存在无效剧情（水文）
  - 是否有无关章节
  - 是否可以删减而不影响主线

- [ ] **高潮分布**
  - 高潮是否分布合理（间隔适当）
  - 高潮是否有铺垫
  - 高潮是否足够震撼

---

### 2.2 节奏控制
**核心问题：节奏是否合理？**

- [ ] **快慢合理**
  - 整体节奏是否拖沓
  - 整体节奏是否过快（跳跃）
  - 节奏变化是否自然

- [ ] **信息释放均衡**
  - 信息释放是否均衡（不过密/过疏）
  - 关键信息是否及时给出
  - 是否有信息堆砌

- [ ] **爽点间隔**
  - 爽点间隔是否合理（每8-12章一个）
  - 是否有爽点间隔过长（超过15章）
  - 爽点类型是否多样

- [ ] **连续低能量段落**
  - 是否有连续低能量段落（平淡期过长）
  - 低能量段落是否有必要
  - 是否可以压缩或删除

---

## 第三类：人物与设定（角色 + 世界观）

### 3.1 人物塑造
**核心问题：人物是否立得住？**

- [ ] **主角动机**
  - 主角是否有明确动机
  - 动机是否合理
  - 动机是否足够强（驱动主角行动）

- [ ] **性格稳定**
  - 主角性格是否稳定（不OOC）
  - 性格变化是否有过程
  - 行为是否符合性格

- [ ] **配角区分度**
  - 配角是否有区分度（不脸谱化）
  - 配角是否有记忆点
  - 配角是否有独特性

- [ ] **行为符合性格**
  - 人物行为是否符合性格
  - 是否有不合理的行为
  - 行为是否有动机

---

### 3.2 世界观与设定
**核心问题：设定是否自洽？**

- [ ] **规则清晰**
  - 世界观规则是否清晰
  - 规则是否容易理解
  - 规则是否有边界

- [ ] **规则自洽**
  - 规则是否前后一致（不打脸）
  - 规则是否有例外（合理吗）
  - 规则是否有冲突

- [ ] **规则被剧情使用**
  - 规则是否被剧情正确使用
  - 是否有设定浪费（设定了但没用）
  - 设定是否为剧情服务

- [ ] **设定不是摆设**
  - 设定是否服务于剧情
  - 设定是否产生冲突
  - 设定是否推动情节

---

## 第四类：连续性（时间线 + 记忆）
**核心问题：AI最容易崩的点，前后是否一致？**
⚠️ **优先级最高**

### 4.1 时间线一致性
- [ ] 时间线是否一致（无矛盾）
- [ ] 时间跨度是否合理
- [ ] 事件顺序是否正确
- [ ] 是否有时间线跳跃（未说明）

### 4.2 人物关系一致性
- [ ] 人物关系是否前后一致
- [ ] 关系发展是否自然
- [ ] 是否有关系突然变化（未说明）
- [ ] 是否有关系冲突

### 4.3 事件记忆
- [ ] 已发生事件是否被记住
- [ ] 前文事件是否被引用
- [ ] 是否有事件被遗忘
- [ ] 是否有事件被改变（不合理）

### 4.4 伏笔处理
- [ ] 伏笔是否被遗忘
- [ ] 伏笔是否被回应
- [ ] 伏笔是否有冲突（前后矛盾）
- [ ] 伏笔是否合理（不强行）

### 4.5 设定一致性
- [ ] 设定是否前后一致
- [ ] 能力是否前后一致
- [ ] 规则是否前后一致
- [ ] 是否有设定冲突

### 4.6 角色状态一致性
- [ ] 角色状态是否连续（如受伤后还生龙活虎）
- [ ] 角色位置是否连续
- [ ] 角色物品是否连续
- [ ] 角色能力是否连续

## 第五类：表现（叙事 + 对话 + 文风 + AI味）

### 5.1 叙事与表现
**核心问题：读感是否流畅？**

- [ ] **画面感**
  - 是否有画面感（不是概括）
  - 描写是否具体（有细节）
  - 场景是否有画面

- [ ] **情绪到位**
  - 情绪是否到位
  - 情感是否有层次
  - 情感是否真实

- [ ] **讲述 vs 展示**
  - 是否"讲述 > 展示"（AI常见问题）
  - 是否有直接描述情感（"他感到快乐"）
  - 是否有大量说明性文字

- [ ] **代入感**
  - 是否有代入感
  - 读者能否进入角色视角
  - 是否有情感共鸣

---

### 5.2 对话质量
**核心问题：对话是否自然？**

- [ ] **对话自然**
  - 对话是否自然（不像AI）
  - 对话是否口语化
  - 对话是否流畅

- [ ] **对话推动剧情**
  - 对话是否推动剧情
  - 对话是否有信息量
  - 对话是否揭示性格

- [ ] **符合人物性格**
  - 对话是否符合人物性格
  - 每个角色是否有自己的说话方式
  - 是否有OOC对话

- [ ] **避免信息硬塞**
  - 对话是否避免信息硬塞
  - 是否有"为了让读者知道而对话"
  - 对话是否自然（不是说明）

---

### 5.3 语言与文风
**核心问题：语言是否流畅？**

- [ ] **啰嗦/重复**
  - 语言是否啰嗦
  - 是否有重复表达
  - 是否有废话

- [ ] **句式单一**
  - 句式是否单一
  - 长短句比例是否合理
  - 是否有连续5句长度相近

- [ ] **AI痕迹**
  - 是否有明显AI痕迹
  - 连接词是否过度
  - 修饰词是否堆砌

- [ ] **符合目标风格**
  - 语言是否符合目标风格（网文/出版）
  - 是否符合平台风格
  - 是否符合题材风格

## 使用说明

### 执行顺序
1. **第一类**：商业（标题、开头、爽点）- 决定读者是否点进来、留下来
2. **第二类**：结构（剧情、节奏）- 决定读者是否持续阅读
3. **第三类**：人物与设定 - 决定读者是否喜欢
4. **第四类**：连续性 ⚠️ **优先级最高** - AI最容易崩，必须重点检查
5. **第五类**：表现 - 决定读感
6. **第六类**：逻辑与合规 - 决定是否可发布

### 检查标准
- [ ] 通过：符合要求，无需修改
- [ ] 警告：有问题，但不致命（P2）
- [ ] 严重：问题明显，会导致流失（P1）
- [ ] 致命：问题严重，会导致弃书（P0）

### 记录格式
每个检查项都要记录：
- 检查结果：通过/警告/严重/致命
- 问题描述：具体是什么问题
- 位置：章节/段落
- 影响：为什么这个问题会导致弃书
- 修改建议：如何修改

---

## 核心原则

### 原则1：找出弃书点
每个检查都要问：这个问题会让读者弃书吗？

### 原则2：检查清单化
60+检查点必须全部执行，不能跳过

### 原则3：连续性优先
连续性是AI最容易崩的点，必须优先检查

### 原则4：合理≠优秀
即使内容"合理"，如果影响阅读流畅度，仍需标记为问题
