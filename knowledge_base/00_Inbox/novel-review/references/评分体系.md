# 评分体系（工业版）

## 概览
可落地的评分权重体系，让系统能自动判断"这章能不能发 / 要不要重写"。

---

## 一、总评分结构（100分制）

```
总分 = 商业(25) + 结构(20) + 人物设定(15) + 连续性(15) + 表现(15) + 逻辑合规(10)
```

---

## 二、各维度详细评分拆解

### 1️⃣ 商业性（25分）👉 最重要

#### 1.1 标题吸引力（5分）
- [ ] 标题有钩子（冲突/反差/悬念）：2分
- [ ] 标题清晰传达题材：1分
- [ ] 标题具备点击欲：1分
- [ ] 标题符合平台风格：1分

**评分标准**：
- 5分：强钩子，非常吸引人
- 4分：有钩子，比较吸引人
- 3分：一般，无明显钩子
- 2分：较弱，缺乏吸引力
- 1分：很差，无吸引力

---

#### 1.2 开头钩子（5分）
- [ ] 前1000字快速进入冲突：2分
- [ ] 前3章有核心事件：1分
- [ ] 前3章让人想继续看：1分
- [ ] 前3章避免世界观堆砌：1分

**评分标准**：
- 5分：开篇强冲突，快速吸引
- 4分：开篇有冲突，吸引人
- 3分：开篇一般，吸引力不足
- 2分：开篇拖沓，吸引力弱
- 1分：开篇失败，无吸引力

---

#### 1.3 爽点密度（10分）
- [ ] 有情绪起伏：3分
- [ ] 爽点有效（不是自嗨）：3分
- [ ] 打脸/反转成立：2分
- [ ] 持续刺激读者：2分

**评分标准**：
- 9-10分：爽点密集且有效，强上头
- 7-8分：爽点较多且有效，有追读潜力
- 5-6分：爽点一般，可读但不爆
- 3-4分：爽点稀疏，吸引力弱
- 0-2分：无爽点，大概率扑街

**关键指标**：
- 每8-12章至少1个爽点
- 爽点间隔超过15章扣2分
- 爽点无效（自嗨）扣3分

---

#### 1.4 章节结尾钩子（5分）
- [ ] 每章结尾有悬念：3分
- [ ] 悬念吸引继续读：2分

**评分标准**：
- 5分：钩子强，必看下一章
- 4分：钩子明显，想看下一章
- 3分：有钩子，可看可不看
- 2分：钩子弱，吸引力不足
- 1分：无钩子，无吸引力

---

**商业性总评分标准**：
- **20-25分**：强上头，有追读潜力
- **15-19分**：可读但不爆
- **10-14分**：一般，可能扑街
- **<10分**：大概率扑街

---

### 2️⃣ 结构（20分）

- 3分：主线一般

---

- [ ] 每章有结果（进展/挫折）：1分

**评分标准**：
- 5分：每章结构完整
- 4分：大部分章节结构完整
- 3分：章节结构一般

- 1分：章节结构混乱

---

#### 2.3 节奏合理（5分）
- [ ] 快慢合理（不拖/不跳）：2分
- [ ] 信息释放均衡：2分
- [ ] 爽点间隔合理：1分

**评分标准**：
- 5分：节奏非常合理
- 4分：节奏合理
- 3分：节奏一般
- 2分：节奏有问题
- 1分：节奏混乱

---

#### 2.4 高潮分布（5分）

- [ ] 高潮有铺垫：2分
- [ ] 高潮足够震撼：1分

**评分标准**：

- 4分：高潮分布良好
- 3分：高潮分布一般
- 2分：高潮分布有问题
- 1分：高潮分布混乱

---

**结构总评分标准**：

- **12-15分**：结构良好，有少量问题
- **8-11分**：结构一般，有明显问题

## 三、评分结果 → 自动决策规则

### 🟢 可发布（直接用）
```
总分 ≥ 85
且无High严重问题
且合规风险不存在
```

### 🟡 优化后发布
```
总分 70-84
或存在 ≤2个High问题
且合规风险不存在
```
**操作**：做局部修改

### 🔴 必须重写
```
总分 < 70
或商业性 < 15
或结构 < 12
或连续性 < 10
```
**操作**：不要修，直接重写

### ⚫ 禁止发布（硬规则）
```
合规风险存在
或连续性严重错误（<8分）
```
**操作**：禁止发布

## 四、问题等级定义

### High（致命）- P0弃书级
- 影响阅读：开头拖沓、节奏混乱
- 逻辑崩：时间线矛盾、设定冲突
- 无钩子：开头无冲突、结尾无悬念

### Medium（重要）- P1流失级
- 影响体验但不致命：人物扁平、对话生硬
- 爽点稀疏、节奏问题

### Low（优化）- P2优化级
- 文风：语言单一、修饰词堆砌
- 细节：画面感不足、细节描写少

---

## 五、修改优先级（必须遵守）

### 顺序1：商业问题（不吸引人）
- 开头钩子：前1000字引入冲突
- 爽点密度：增加爽点
- 章节钩子：增加悬念

### 顺序2：结构问题（看不下去）
- 节奏：调整节奏，删除无效剧情
- 主线：明确主线目标

### 顺序3：连续性（崩）
- 时间线：修复时间线矛盾
- 设定：修复设定冲突

### 顺序4：逻辑
- 因果：强化因果关系
- 行为：让行为合理

### 顺序5：表现 & 文风
- 画面感：增加细节描写
- 对话：让对话自然

**顺序错了 = 白改**
