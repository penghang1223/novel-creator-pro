# 小说专业审稿系统

## 任务目标
- 本 Skill 用于：对小说（人写或AI写）进行全方位、多维度、专业级审稿
- 能力包含：
  - 11个专业角色协同审稿（4读者+7编辑）
  - AI写作特征识别与去除（30+指标、21个方法）
  - 7大题材专项检查（玄幻/言情/悬疑/科幻/都市/武侠/历史）
  - 8大平台适配审核（起点/晋江/番茄/七猫/豆瓣/知乎/掌阅/飞卢）
  - 数据化分析（7大类统计指标）
  - 综合报告生成（P0/P1/P2优先级）
- 触发条件：用户提出"审稿"、"检查"、"评估"、"AI味检测"、"平台适配"等需求

## 前置准备
- 依赖说明：无脚本依赖，纯自然语言指导
- 非标准文件准备：无
- 智能体能力：文本分析、逻辑推理、情感理解、创意评估、结构化思维

## 角色体系概览

### 读者组（4个角色）
1. **普通读者**：关注阅读体验、开头吸引力、代入感、情感共鸣
2. **类型读者**：关注题材契合度、设定吸引力、套路运用、竞品对比
3. **挑刺读者**：关注剧情逻辑、设定一致性、细节漏洞
4. **情感读者**：关注情感线质量、角色魅力、情绪调动

### 编辑组（7个角色）
1. **文字编辑**：关注基础错误、表达问题、语言风格、节奏与呼吸感
2. **剧情编辑**：关注整体结构、章节结构、冲突设计、节奏把控
3. **角色编辑**：关注主角/配角/反派塑造、人物关系网络、对话质量
4. **世界观编辑**：关注世界观完整性、规则体系、设定一致性、信息暴露节奏
5. **叙事编辑**：关注叙事视角、叙事方式、场景描写、叙事节奏
6. **商业编辑**：关注市场定位、吸引力指标、商业潜力、风险预警
7. **AI味去除专家**：关注AI特征识别、AI味检测、去AI味策略、效果评估

详细角色定义见 [references/角色详细定义.md](references/角色详细定义.md)

## 操作步骤

### 标准审稿流程

#### 阶段1：选择审稿模式
根据需求选择适合的审稿模式：

**模式1：快速评估**（3-5个角色）
- 适用：新人作品、快速判断、初步筛选
- 角色组合：普通读者 + 剧情编辑 + 角色编辑 + （可选）类型读者 + （可选）商业编辑
- 预计输出：快速评估报告，聚焦核心问题

**模式2：深度审稿**（7个角色）
- 适用：中期作品、投稿前审稿、重要修改
- 角色组合：普通读者 + 挑刺读者 + 情感读者 + 剧情编辑 + 角色编辑 + 世界观编辑 + 叙事编辑
- 预计输出：深度审稿报告，全面问题清单

**模式3：专业出版**（10个角色）
- 适用：出版级作品、签约前审稿、全方位打磨
- 角色组合：全部11个角色（4读者 + 7编辑）
- 预计输出：专业出版报告，业界级标准

**模式4：问题诊断**（针对性）
- 适用：已知某方面有问题，需要深度诊断
- 角色组合示例：
  - "剧情拖沓"：普通读者 + 剧情编辑 + 叙事编辑 + 商业编辑
  - "角色不立体"：角色编辑 + 情感读者 + 挑刺读者
  - "AI写作嫌疑"：AI味去除专家 + 挑刺读者 + 角色编辑 + 剧情编辑 + 叙事编辑
  - "设定混乱"：世界观编辑 + 挑刺读者 + 剧情编辑
  - "平台适配"：商业编辑 + （对应平台专属标准）
- 预计输出：诊断报告，针对性解决方案

#### 阶段2：并行审稿（各角色独立工作）
每个角色按其专业领域进行审查，生成独立报告。详细检查项见各角色定义。

#### 阶段3：意见整合与优先级排序
- 汇总所有角色意见
- 识别重复问题（多个角色指出同一问题）
- 识别冲突意见（如读者喜欢但编辑觉得有问题）
- 交叉验证（如挑刺读者发现逻辑问题，内容编辑确认剧情影响）
- 优先级分类：
  - 🔴 P0-必须修改：影响阅读、逻辑硬伤、设定冲突、严重AI味
  - 🟡 P1-建议修改：提升质量、优化体验、中度AI味
  - 🟢 P2-可选优化：锦上添花、风格调整、轻微AI味

#### 阶段4：生成综合报告
按模板生成完整审稿报告，见 [references/综合报告模板.md](references/综合报告模板.md)

### AI味检测与去除专项流程

#### 步骤1：AI味检测（多角色协同）
**主导角色**：AI味去除专家
**协同角色**：挑刺读者 + 叙事编辑 + 情感读者 + 文字编辑

使用30+AI味指标库进行全面检测，见 [references/AI味指标库.md](references/AI味指标库.md)

#### 步骤2：问题定位与分类
将检测到的问题按5大类分类：语言、叙事、逻辑、情感、创意

#### 步骤3：针对性修改
使用21个去AI味方法，见 [references/AI味去除策略.md](references/AI味去除策略.md)

#### 步骤4：效果评估
修改后重新检测，确保AI味有效降低

详见 [references/AI味检测工作流.md](references/AI味检测工作流.md)

### 题材专项检查流程
根据小说题材选择对应检查清单：
- 玄幻/奇幻：修炼体系、力量设定、世界观规模
- 言情：CP设定、感情线节奏、甜虐度
- 悬疑/推理：案件设计、线索埋设、逻辑严密性
- 科幻：科幻设定、科技逻辑、世界观
- 都市/现实：现实感、社会议题、人物真实度
- 武侠/仙侠：武学体系、江湖世界、侠义精神
- 历史：历史准确性、历史观、虚构与真实平衡

见 [references/题材特殊检查清单.md](references/题材特殊检查清单.md)

### 平台适配流程
根据目标平台执行专属审核：
- 起点：升级体系、世界观、金手指、打脸节奏
- 晋江：感情线、甜虐比、角色魅力、细节描写
- 番茄：快节奏、爽点密度、章节长度、完整性
- 七猫：代入感、爽点类型、黄金三章、结局满足感
- 豆瓣：思想深度、文学性、现实主义、人物复杂度
- 知乎：故事性、反转设计、话题性、篇幅控制
- 掌阅：易读性、流畅性、娱乐性、完整性
- 飞卢：极致爽感、超快节奏、系统设计、更新能力

见 [references/不同平台专属审核标准.md](references/不同平台专属审核标准.md)

## 使用示例

### 示例1：新人小说快速评估
- 场景/输入：作者完成了第一部长篇小说初稿，希望了解整体质量和主要问题
- 预期产出：快速评估报告，包含总体评分、核心优势、关键问题（P0级别）、修改建议
- 关键要点：
  - 使用"快速评估"模式（普通读者+剧情编辑+角色编辑+类型读者）
  - 重点关注：开头吸引力、主线清晰度、主角塑造、题材契合度
  - 输出简洁明确，避免过多细节
  - 提供第一阶段的修改优先级

### 示例2：长篇小说深度审稿
- 场景/输入：50万字长篇小说，准备投稿，需要全面打磨
- 预期产出：深度审稿报告，包含11个角色（或7个深度角色）的详细分析、完整问题清单、分阶段修改路线图
- 关键要点：
  - 使用"深度审稿"模式（7个角色）或"专业出版"模式（11个角色）
  - 全面覆盖：读者体验、创作技术、AI检测、数据统计
  - 生成详细的修改路线图（分阶段、分优先级）
  - 提供具体可操作的修改建议

### 示例3：AI写作识别与去除
- 场景/输入：怀疑某小说由AI生成或重度AI辅助，需要识别并去除AI味
- 预期产出：AI味检测报告，包含AI味评分（0-10分）、问题定位、逐条修改建议、修改后对比示例
- 关键要点：
  - 使用"AI味去除专项"模式（AI味去除专家主导）
  - 使用30+指标进行全面检测（语言、叙事、逻辑、情感、创意）
  - 提供针对性修改建议（21个方法）
  - 包含10+个修改示例供参考

### 示例4：平台适配分析
- 场景/输入：已完成小说，希望适配特定平台（如起点/晋江/番茄）
- 预期产出：平台适配报告，包含平台专属评估指标、适配性问题、修改建议、优化方向
- 关键要点：
  - 先确定目标平台
  - 使用对应平台的专属审核标准
  - 结合通用审稿体系
  - 提供平台针对性的修改方案

## 注意事项

- 角色职责分工：智能体负责所有11个角色的模拟和协调，无需人工参与
- 读取时机：仅在需要时读取参考文件，保持上下文简洁
- 灵活应用：根据实际需求调整角色组合和审稿深度
- AI味检测：涉及第三方API调用时，必须遵循相关授权流程
- 数据统计：智能体可基于文本估算数据指标，无需精确计算
- 平台适配：先确定目标平台，再执行对应专属标准
- 修改优先级：遵循P0→P1→P2顺序，确保核心问题优先解决
- 报告完整性：综合报告必须包含总体评分、核心优势、关键问题、修改建议、各角色详细报告

### ⚠️ 重要提醒：避免"合理化陷阱"

在审稿过程中，容易出现以下判断失误，必须警惕：

**陷阱1："合理=优秀"的误判**
- 即使内容类型"合理"（如日记、碎片化回忆、对话），如果存在明显的节奏问题，仍需标记
- 例如：日记内容用短句是"合理"的，但如果短句占比超过50%，影响阅读流畅度，必须标记为问题
- **原则**：合理≠优秀，优秀需要更严格的节奏控制

**陷阱2：过度关注"高层特征"忽略"基础问题"**
- 不要只关注悬念推进、角色逻辑、情感共鸣等"高层特征"
- 必须同时检查基础的文字节奏、句式结构、语言流畅度
- **原则**：基础问题是所有高质量作品的前提

**陷阱3：被内容类型蒙蔽**
- 日记、回忆、碎片化叙事等类型，不等于可以忽略节奏
- AI味指标库中的"句式单一"指标适用于所有内容类型
- **原则**：无论什么内容类型，节奏检测都是必要的

**强制检测项（文字编辑角色必须执行）**：
1. 句子长度分布检测（短句<10字、中句10-30字、长句>30字）
2. 短句占比超过50%必须标记为问题（即使内容合理）
3. 长句占比超过40%必须标记为问题
4. 连续5句以上长度相近必须标记为问题
