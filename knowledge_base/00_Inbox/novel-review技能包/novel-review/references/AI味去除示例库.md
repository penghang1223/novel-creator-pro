# AI味去除示例库

## 概览
本文件提供10+个AI味去除的典型案例，展示修改前后对比和具体操作。

---

## 示例1：去语言AI味 - 句式单一（AI中句堆叠）

### 原文（AI味重）
```
他十分高兴地走进房间，然后看到了桌子上的书，接着拿起来看了一会儿，最后觉得很不错。
```

### 修改过程
```
第1步：打破句式单一
他走进房间。桌上有一本书，他拿起来翻了几页。

第2步：减少连接词
他走进房间，桌上摊着一本书。他随手翻了几页。

第3步：增加细节
他推门而入，目光落在书桌那本摊开的书上。书页边角有些卷曲，他伸手翻了几页。

第4步：增强感官描写
他推门而入，陈旧的书桌在阳光下泛着光。桌上那本书的封皮已经磨损，他翻开时，纸张散发出淡淡的霉味。

最终版本：
他推门而入，陈旧的书桌在阳光下泛着光。桌上那本书的封皮已经磨损，他翻开时，纸张散发出淡淡的霉味。几页之后，他的嘴角勾了起来。
```

### 去除效果
- ✅ 句式多样化（短句/中句/长句交替）
- ✅ 减少连接词（然后、接着、最后都去掉了）
- ✅ 增加感官细节（视觉、嗅觉）
- ✅ 增强画面感（具体的场景描写）

## 示例1.5：去语言AI味 - 短句堆叠（碎片化内容）

### 原文（短句堆叠，即使内容合理也有问题）
```
10月15日。阴。天黑得很早。我不喜欢下雨。但今天下了。没带伞。冷。很冷。肚子饿了。想吃面。
```

### 问题分析
- 虽然是日记格式，碎片化是"合理"的
- 但短句占比约90%（>50%阈值），导致阅读卡顿
- 缺乏节奏变化，即使合理也不优秀

### 修改过程
```
第1步：识别短句堆叠
原文9句，其中8句是短句（<10字），占比89%

第2步：适度合并，保持日记感
10月15日，阴。天黑得很早，我不喜欢下雨，但今天偏偏下了。没带伞。很冷，刺骨的冷。肚子饿了，想吃面。

第3步：增加节奏变化
10月15日，阴。天黑得很早，我不喜欢下雨，但今天偏偏下了。没带伞，站在屋檐下等。很冷，刺骨的冷。肚子饿了，特别想吃面。

最终版本：
10月15日，阴。天黑得很早，我不喜欢下雨，但今天偏偏下了。没带伞，站在屋檐下等。很冷，刺骨的冷。肚子饿了，特别想吃面。
```

### 去除效果
- ✅ 短句占比从89%降至50%
- ✅ 保持日记的碎片化风格
- ✅ 增加中句，改善阅读流畅度
- ✅ 节奏有变化，不单调

### 重要提醒
即使内容类型"合理"（日记、回忆、碎片化），短句占比超过50%仍需优化，因为：
- "合理≠优秀"
- 影响阅读流畅度
- 读者容易疲劳
- 缺乏节奏美感

## 示例2：去叙事AI味 - 信息堆砌

### 原文（AI味重）
```
这是一个魔法世界，人们可以使用魔法。魔法分为五种元素：火、水、木、金、土。主角小明是一个火系法师，他非常强大。
```

### 修改过程
```
第1步：信息分散到剧情
小明抬起右手，掌心腾起一团火焰——这是他觉醒三个月的火元素之力。在这个世界，像他这样的元素法师并不多见。

第2步：通过角色互动展现设定
"又是火系？"教官皱了皱眉，"水系法师最近很抢手啊。"
"火系怎么了？"小明把火焰攥进掌心，"一样能杀人。"

第3步：加入细节和环境
训练场上，其他学员的水球、风刃飞来飞去，只有小明的火焰格外显眼。空气中飘着烧焦的味道。

最终版本：
训练场上，各种元素的光芒此起彼伏。小明抬起右手，掌心的火焰腾地窜起半尺高，周围顿时飘起一股焦糊味。"又是火系？"教官瞥了他一眼，转身走向下一个学员。小明没理会，把火焰攥进掌心——在这个元素为尊的世界，火系法师的威力，用不着解释。
```

### 去除效果
- ✅ 设定信息分散到剧情中
- ✅ 通过角色互动展现
- ✅ 加入环境细节（训练场、气味）
- ✅ 增强代入感

## 示例3：去情感AI味 - 情感浅表

### 原文（AI味重）
```
她很伤心，因为男朋友跟她分手了。
```

### 修改过程
```
第1步：Show, Don't Tell
她盯着手机屏幕，眼泪流了下来。

第2步：增加细节
她盯着手机屏幕上的那条短信，眼泪砸在屏幕上，模糊了字迹。

第3步：加入环境
手机屏幕的光在黑暗的房间里显得格外刺眼。她盯着那条短信，眼泪砸在屏幕上，模糊了"我们分手吧"这几个字。

第4步：增加情感层次
手机屏幕的光在黑暗的房间里显得格外刺眼。她盯着那条短信，想哭却哭不出来——昨晚他还在说"永远"，今天就变成"分手"。眼泪终于还是砸在屏幕上，晕开了那几个字。

最终版本：
手机屏幕的光在黑暗的房间里显得格外刺眼。她盯着那条短信，胸口闷得像塞了一团湿棉花。昨晚他还在说"永远"，今天就变成"分手"。眼泪终于还是砸在屏幕上，晕开了那几个字。
```

### 去除效果
- ✅ Show, Don't Tell（通过动作展现情感）
- ✅ 增加环境细节（黑暗、刺眼的光）
- ✅ 增加情感层次（想哭哭不出、回忆）
- ✅ 增强代入感

## 示例4：去逻辑AI味 - 因果简化

### 原文（AI味重）
```
他很努力，所以成功了。
```

### 修改过程
```
第1步：补充过程
他每天练习，所以成功了。

第2步：增加细节
他每天练习到凌晨，手指都磨出了茧，终于在比赛中获得了冠军。

第3步：增加波折
他尝试了很多次都失败了，但他没有放弃，最后终于成功了。

第4步：强化因果关系
他每天练习到凌晨，手指磨出了茧，失败了三次后，终于在第四次尝试时获得了冠军。

最终版本：
他每天练习到凌晨，手指磨出了茧，失败了三次后，终于在第四次尝试时获得了冠军。当主持人宣布他的名字时，他站了起来，眼泪夺眶而出——这三个月的努力，终于有了回报。
```

### 去除效果
- ✅ 因果关系更复杂
- ✅ 展示过程的困难
- ✅ 增加波折（失败三次）
- ✅ 结果更有说服力

## 示例5：去对话AI味 - 对话公式化

### 原文（AI味重）
```
"我很生气，因为你不尊重我，"他说。
"我很抱歉，我不是故意的，"她回答。
"那你以后注意，"他说。
"好的，我会注意的，"她说。
```

### 修改过程
```
第1步：口语化表达
"我很生气！你不尊重我！"他说。
"对不起，我不是故意的，"她回答。
"那以后注意点，"他说。
"好，我知道了，"她说。

第2步：加入动作和神态
"我很生气！你不尊重我！"他猛地站起来，胸口剧烈起伏。
"对不起，我不是故意的，"她低下头，声音很小。
"那以后注意点，"他瞪着她。
"好，我知道了，"她依然低着头。

第3步：加入省略和打断
"我很生气！你不尊重我！"他猛地站起来。
"我...我不是故意的..."她后退了一步。
"那以后注意——"
"我知道了！"

最终版本：
"我很生气！你不尊重我！"他猛地站起来，胸口剧烈起伏。
"我...我不是故意的..."她后退了一步，声音在发抖。
"注意点，这是最后一次！"他狠狠地瞪着她。
"我知道了..."她低下头，眼泪在眼眶里打转。
```

### 去除效果
- ✅ 对话口语化
- ✅ 加入动作和神态
- ✅ 加入省略和打断
- ✅ 对话更有张力

## 示例6：去场景AI味 - 细节不足

### 原文（AI味重）
```
他来到了森林里。
```

### 修改过程
```
第1步：增加视觉细节
他走进绿色的森林里，树很高。

第2步：增加更多感官
他走进森林，阳光透过树叶洒下来，脚下的落叶发出沙沙声。

第3步：增加氛围
他踏入森林，阳光被茂密的树冠筛成细碎的光斑，脚下的落叶发出沙沙声。四周很安静，只有偶尔的鸟鸣。

最终版本：
他踏入森林，阳光被茂密的树冠筛成细碎的光斑，在苔藓上跳跃。脚下的落叶发出沙沙声，空气中弥漫着泥土和松针的清香。四周很安静，只有偶尔的鸟鸣，像是怕惊扰了这片古老的森林。
```

### 去除效果
- ✅ 增加视觉细节（光斑、苔藓）
- ✅ 增加听觉细节（沙沙声、鸟鸣）
- ✅ 增加嗅觉细节（泥土、松针）
- ✅ 增强氛围感（古老、安静）

## 示例7：去角色AI味 - 角色行为公式化

### 原文（AI味重）
```
他是一个勇敢的英雄，所以他决定去冒险。
```

### 修改过程
```
第1步：增加动机
他是一个勇敢的英雄，为了拯救村庄，他决定去冒险。

第2步：增加内心冲突
他是一个勇敢的英雄，但他也害怕。为了拯救村庄，他决定去冒险。

第3步：增加细节和犹豫
他是一个勇敢的英雄，但面对未知的危险，他也害怕。看着村民绝望的眼神，他握紧了剑。他犹豫了很久，最后终于决定去冒险。

最终版本：
村民们绝望的眼神刺痛了他。他握紧了剑，手心全是汗。那座山充满了危险，很多人进去都没能出来。他转过身，看向村子——老人、孩子、妇女，所有人的希望都压在他身上。"我去，"他咬着牙说道，声音有些颤抖，但眼神坚定。
```

### 去除效果
- ✅ 增加动机（村民的眼神）
- ✅ 增加内心冲突（害怕vs责任）
- ✅ 增加细节（手心出汗、声音颤抖）
- ✅ 角色更真实

## 示例8：去悬念AI味 - 悬念缺失

### 原文（AI味重）
```
第二天，他来到了学校。
```

### 修改过程
```
第1步：增加细节
第二天，他来到了学校，学校很安静。

第2步：增加异常
第二天，他来到了学校，学校很安静，所有人都看着他。

第3步：制造悬念
第二天，他推开教室门，所有人都安静了下来。黑板上写着他的名字。

最终版本：
第二天，当他推开教室门时，原本喧闹的教室瞬间安静了下来。所有人的目光都集中在他身上，像是看到了什么不可思议的东西。他疑惑地看向讲台——黑板上，用鲜红的粉笔写着他的名字。
```

### 去除效果
- ✅ 制造悬念（为什么安静？）
- ✅ 制造异常（所有人都看向他）
- ✅ 制造钩子（黑板上的名字）
- ✅ 吸引读者继续阅读

## 示例9：去形容词AI味 - 修饰词堆砌

### 原文（AI味重）
```
那是一个美丽的、善良的、温柔的、聪明的女孩。
```

### 修改过程
```
第1步：减少形容词
那是一个美丽的女孩。

第2步：用细节替代
那个女孩很漂亮，眼睛很大，笑起来很甜。

第3步：用Show替代
那个女孩站在那里，阳光洒在她身上。她转过头，冲着小男孩笑了笑，小男孩的脸瞬间红了。

最终版本：
那个女孩站在树下，阳光穿过树叶，在她身上投下斑驳的光影。她转过头，冲着路边的老人笑了笑，弯腰帮老人捡起了掉在地上的菜篮。老人的眼睛亮了起来——这样的孩子，现在不多了。
```

### 去除效果
- ✅ 去除形容词堆砌
- ✅ 用细节展现特征
- ✅ Show, Don't Tell
- ✅ 人物更立体

## 示例10：综合案例 - 多种AI味混合

### 原文（AI味重）
```
他走进房间，看到了桌子上有一封信，然后拿起来看，发现是分手信，所以他很伤心。
```

### 修改过程
```
第1步：打破句式单一
他走进房间。桌上有一封信，他拿起来看。是一封分手信，他很伤心。

第2步：减少连接词
他走进房间。桌上摊着一封信。他伸手拿起来——分手信。他愣住了。

第3步：增加感官细节
他推开门，房间很暗，只有一盏台灯亮着。桌上有一封信，信封已经拆开。他拿起来，借着台灯的光。是一封分手信。

第4步：Show, Don't Tell
他推开门，房间很暗，只有一盏台灯亮着。桌上有一封信，信封已经拆开。他拿起来，借着台灯的光。字迹很熟悉，是她写的。"我们分手吧。"看到这几个字，他手中的信纸滑落，飘到了地上。他站在那里，久久没有动。

第5步：增加情感层次
他推开门，房间很暗，只有一盏台灯亮着。桌上有一封信，信封已经拆开。他拿起来，借着台灯的光。字迹很熟悉，是她写的。"我们分手吧。"看到这几个字，他手中的信纸滑落，飘到了地上。他站着，没有哭，只是觉得胸口空空的——像是什么东西被挖走了。

最终版本：
他推开门，房间里昏暗一片，只有台灯还亮着，在墙上映出摇曳的光影。桌上摆着一封信，信封已经拆开。他拿起信，借着昏黄的灯光。字迹很熟悉，是她写的。"我们分手吧。"四个字，简短而决绝。手中的信纸滑落，无声地飘到地上。他站着，没有哭，只是觉得胸口空空的——像是什么东西被挖走了，留下的只有风呼啸的声音。
```

### 去除效果
- ✅ 句式多样化
- ✅ 减少连接词
- ✅ 增加感官细节（视觉、光线）
- ✅ Show, Don't Tell
- ✅ 增加情感层次
- ✅ 增强画面感和代入感
