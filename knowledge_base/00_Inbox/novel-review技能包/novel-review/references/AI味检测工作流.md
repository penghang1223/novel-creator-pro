# AI味检测工作流

## 概览
本文件定义AI味检测与去除的完整工作流程，包含4个阶段和具体操作步骤。

---

## AI味检测与去除完整流程

### 阶段1：AI味检测（多角色协同）

#### 主导角色
- AI味去除专家（主导）

#### 协同角色
- 挑刺读者（检测逻辑问题）
- 叙事编辑（检测语言和叙事问题）
- 情感读者（检测情感问题）
- 文字编辑（检测文字问题）

#### 步骤1.1：使用30+指标库进行全面检测

**操作流程**：
1. 按语言、叙事、逻辑、情感、创意5大类逐项检测
2. 记录每个指标的检测结果（通过/不通过）
3. 标注问题位置（章节:段落）
4. 评估问题严重程度（高/中/低）

**检测表格示例**：
```
[语言特征]
- 句式单一：不通过（位置：全篇，严重度：高）
- 连接词过度：不通过（位置：第3章，严重度：中）
- 被动语态过多：通过
...

[叙事特征]
- Show vs Tell 失衡：不通过（位置：第5章，严重度：高）
- 信息堆砌：不通过（位置：第1章，严重度：高）
...
```

#### 步骤1.2：生成AI味检测报告

**报告内容**：
- AI味综合评分（0-10分）
- 各类别评分（语言/叙事/逻辑/情感/创意）
- 问题统计（总数、各类别数量）
- AI味等级（🟢/🟡/🟠/🔴）

**报告格式**：
```
[AI味去除专家报告]
AI味综合评分：7/10（等级：🟠 高度AI味）

分项评分：
- 语言特征：6/10（问题数量：12）
- 叙事特征：7/10（问题数量：10）
- 逻辑特征：8/10（问题数量：8）
- 情感特征：7/10（问题数量：6）
- 创意特征：6/10（问题数量：5）

问题统计：共发现41个AI特征问题
```

---

### 阶段2：问题定位与分类

#### 步骤2.1：标注问题位置
- 使用"章节:段落"格式标注
- 例如：第3章:第5段

#### 步骤2.2：分类整理
将检测到的问题按5大类分类：
1. 语言特征问题（句式、连接词、修饰词等）
2. 叙事特征问题（Show/Tell、信息堆砌、悬念等）
3. 逻辑特征问题（因果、角色行为、伏笔等）
4. 情感特征问题（情感深度、转换、共鸣等）
5. 创意特征问题（套路、角色扁平、表达模板等）

#### 步骤2.3：优先级排序
- 🔴 P0-必须修改：影响阅读、严重AI味、逻辑硬伤
- 🟡 P1-建议修改：中度AI味、影响质量
- 🟢 P2-可选优化：轻微AI味、锦上添花

**问题清单示例**：
```
[语言特征问题 - P0]
1. 第1章:第2段 - 句式单一：连续5句都是中等长度
2. 第1章:第3段 - 信息堆砌：500字内倾倒大量设定

[叙事特征问题 - P0]
3. 第5章:第7段 - Show vs Tell 失衡：直接描述情感
...

[逻辑特征问题 - P1]
10. 第8章:第3段 - 因果简化：成功来得太容易
```

---

### 阶段3：针对性修改

#### 步骤3.1：选择修改策略
根据问题类型选择对应的去AI味方法：
- 语言问题 → 使用语言层面方法（方法1-6）
- 叙事问题 → 使用叙事层面方法（方法7-11）
- 逻辑问题 → 使用逻辑层面方法（方法12-15）
- 情感问题 → 使用情感层面方法（方法16-18）
- 创意问题 → 使用创意层面方法（方法19-21）

#### 步骤3.2：逐项修改
**修改流程**：
1. 读取问题原文
2. 分析问题原因
3. 应用对应方法
4. 生成修改建议
5. 提供修改示例

**修改记录格式**：
```
问题：第1章:第2段 - 句式单一
原文：他走进了房间，然后看到了桌子，接着拿起了书。
问题原因：连续使用中等长度句子，缺乏节奏变化
修改方法：方法1 - 打破句式单一
修改建议：拆分为短句和中句，增加节奏感
修改示例：他走进房间。桌上摊着一本书，他顺手拿了过来。
```

#### 步骤3.3：生成修改路线图
按优先级和类别规划修改顺序：

**路线图示例**：
```
[阶段1：语言层面修复]（预计降低AI味2分）
- 修复12个语言特征问题
- 重点：句式单一、连接词过度、修饰词堆砌

[阶段2：叙事层面修复]（预计降低AI味1.5分）
- 修复10个叙事特征问题
- 重点：Show vs Tell失衡、信息堆砌、悬念缺失

[阶段3：逻辑层面修复]（预计降低AI味1分）
- 修复8个逻辑特征问题
- 重点：因果简化、角色行为公式化

[阶段4：情感层面修复]（预计降低AI味0.8分）
- 修复6个情感特征问题
- 重点：情感浅表、情感转换生硬

[阶段5：创意层面修复]（预计降低AI味0.7分）
- 修复5个创意特征问题
- 重点：情节套路化、角色扁平化

总计：预计降低AI味6分，从7分降至1分
```

---

### 阶段4：复检与迭代

#### 步骤4.1：修改后检测
- 完成所有修改后，重新执行AI味检测
- 使用相同的30+指标库
- 对比修改前后的评分

#### 步骤4.2：效果评估
**评估标准**：
- 综合评分是否有效降低
- P0级别问题是否全部解决
- 是否引入新的问题
- 整体质量是否提升

**复检报告格式**：
```
[复检报告]
修改前AI味评分：7/10（🟠 高度AI味）
修改后AI味评分：2/10（🟢 轻微AI味）

P0问题解决情况：10/10（100%）
P1问题解决情况：15/18（83%）
P2问题解决情况：8/13（62%）

新增问题：2个（轻微，不影响整体）

效果评估：✅ AI味显著降低，质量明显提升
```

#### 步骤4.3：迭代优化
如果复检发现问题未完全解决：
- 分析未解决问题的原因
- 调整修改策略
- 进行第二轮修改
- 再次复检

## 不同场景的应用

### 场景1：轻度AI味（3-4分）
**策略**：
- 重点修复P0级别问题
- 重点关注语言和叙事层面
- 预计修改1-2轮

### 场景2：中度AI味（5-6分）
**策略**：
- 全面修复P0和P1问题
- 语言、叙事、逻辑三管齐下
- 预计修改2-3轮

### 场景3：高度AI味（7-8分）
**策略**：
- 系统性修复所有问题
- 5大类别全面优化
- 预计修改3-4轮
- 可能需要局部重写

### 场景4：严重AI味（9-10分）
**策略**：
- 评估是否值得修改
- 如果修改，可能需要全面重写
- 建议保留核心创意，重新写作
- 预计修改4轮以上

---

## 注意事项

### 检测阶段
1. 不要过度检测，保持客观
2. 区分AI特征和个人风格
3. 保留合理的表达多样性
4. 标注要准确，便于修改

### 修改阶段
1. 修改不是机械替换，要考虑语境
2. 保持作者的核心创意和风格
3. 修改要自然，不能生硬
4. 逐项修改，避免遗漏

### 复检阶段
1. 复检要客观，不要盲目乐观
2. 对比修改前后，评估效果
3. 接受轻微AI味，追求平衡
4. 迭代优化，逐步完善

## 与其他角色的协同

### 与挑刺读者协同
- 挑刺读者负责逻辑漏洞检测
- AI味去除专家负责逻辑特征AI味检测
- 交叉验证，确保逻辑问题被全面识别

### 与叙事编辑协同
- 叙事编辑负责叙事质量评估
- AI味去除专家负责叙事AI味检测
- 共同优化叙事层面

### 与情感读者协同
- 情感读者负责情感共鸣评估
- AI味去除专家负责情感AI味检测
- 共同提升情感质量

---

## 使用说明
1. 按阶段执行工作流
2. 根据AI味严重程度调整策略
3. 与其他角色协同，全面优化
4. 迭代改进，逐步降低AI味
