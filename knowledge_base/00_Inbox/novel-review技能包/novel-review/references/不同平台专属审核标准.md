# 不同平台专属审核标准

## 概览
不同平台有独特的调性、规则和读者群体。本标准提供主流平台的专属审核指标。

---

## 一、起点中文网（男频长篇）

### 平台定位
- **核心读者**：男性为主，18-35岁
- **主打类型**：玄幻、仙侠、都市、科幻、军事、历史
- **核心需求**：升级、打脸、爽感、世界观

### 专属审核指标

#### 1.1 升级体系
- [ ] 升级路线是否清晰
- [ ] 升级难度是否合理
- [ ] 升级是否有成就感
- [ ] 升级是否有新能力

#### 1.2 世界观规模
- [ ] 世界观是否有层次
- [ ] 势力分布是否完整
- [ ] 世界是否可扩展
- [ ] 设定是否自洽

#### 1.3 金手指设计
- [ ] 金手指是否合理
- [ ] 金手指是否有成长性
- [ ] 金手指限制是否明确
- [ ] 金手指与剧情结合

#### 1.4 打脸节奏
- [ ] 打脸频率是否合理
- [ ] 打脸对象是否有层次
- [ ] 打脸方式是否有新意
- [ ] 打脸后是否有后续影响

#### 1.5 长篇能力
- [ ] 是否有足够内容支撑百万字
- [ ] 世界观是否有扩展空间
- [ ] 主角成长是否有持续动力
- [ ] 是否有足够反派/BOSS

### 起点特有问题
- ❌ 升级太快（后期崩）
- ❌ 世界观小（无法展开）
- ❌ 金手指太强（无敌）
- ❌ 打脸重复（套路化）

## 二、晋江文学城（女频长篇）

### 平台定位
- **核心读者**：女性为主，15-35岁
- **主打类型**：言情、古言、现言、仙侠、校园、职场
- **核心需求**：感情线、CP互动、甜虐、人物塑造

### 专属审核指标

#### 2.1 感情线质量
- [ ] CP人设是否鲜明
- [ ] 感情线起点是否合理
- [ ] 感情线节奏是否自然
- [ ] 感情线是否有高潮

#### 2.2 甜虐比例
- [ ] 甜点密度
- [ ] 虐点设置
- [ ] 甜虐比例（甜文8:2，虐文3:7）
- [ ] 甜虐转换是否自然

#### 2.3 角色魅力
- [ ] 男女主是否有魅力
- [ ] 配角是否有记忆点
- [ ] 反派是否有层次
- [ ] 角色是否有成长弧线

#### 2.4 细节描写
- [ ] 互动细节是否丰富
- [ ] 情感描写是否细腻
- [ ] 场景描写是否唯美
- [ ] 是否有读者想象空间

### 晋江特有问题
- ❌ 感情线慢热（读者失去耐心）
- ❌ 误会过多（反复误会）
- ❌ 角色扁平（无魅力）
- ❌ 虐点无理由（为虐而虐）

---

## 三、番茄小说（新媒体短篇）

### 平台定位
- **核心读者**：大众，年龄跨度大
- **主打类型**：短篇网文、爽文、快节奏
- **核心需求**：快节奏、爽点密集、短小精悍

### 专属审核指标

#### 3.1 节奏把控
- [ ] 开篇是否快速切入
- [ ] 节奏是否紧凑
- [ ] 冲突是否密集
- [ ] 是否有拖沓

#### 3.2 爽点密度
- [ ] 爽点是否密集
- [ ] 爽点强度是否足够
- [ ] 爽点类型是否多样
- [ ] 是否有爽点空窗

#### 3.3 章节长度
- [ ] 章节长度是否合适（1000-1500字）
- [ ] 每章是否有独立目标
- [ ] 每章是否有小高潮
- [ ] 是否有一分为二（注水）

#### 3.4 完整性
- [ ] 是否有完整起承转合
- [ ] 是否有明确结局
- [ ] 是否有伏笔回收
- [ ] 字数是否合理（3-10万字）

### 番茄特有问题
- ❌ 节奏慢（开篇拖沓）
- ❌ 爽点稀疏（长期无爽点）
- ❌ 章节过长（影响体验）
- ❌ 结局仓促（未完结）

---

## 四、七猫小说（新媒体短篇）

### 平台定位
- **核心读者**：大众，下沉市场
- **主打类型**：爽文、总裁文、重生文、甜宠文
- **核心需求**：爽感、代入感、快节奏

### 专属审核指标

#### 4.1 代入感
- [ ] 主角是否贴近读者
- [ ] 情境是否真实
- [ ] 情感是否共鸣
- [ ] 是否有读者想象空间

#### 4.2 爽点类型
- [ ] 是否有打脸爽
- [ ] 是否有逆袭爽
- [ ] 是否有复仇爽
- [ ] 是否有爱情爽

#### 4.3 黄金三章
- [ ] 第1章是否有强冲突
- [ ] 第2章是否有金手指展现
- [ ] 第3章是否明确主线目标
- [ ] 前三章总字数是否足够

#### 4.4 结局满足感
- [ ] 结局是否满足读者期待
- [ ] 是否有遗憾
- [ ] 是否有反转
- [ ] 是否有余韵

### 七猫特有问题
- ❌ 代入感弱（主角离读者远）
- ❌ 爽点不足（长期无爽点）
- ❌ 黄金三章失败（读者流失）
- ❌ 结局不满足（读者失望）

---

## 五、豆瓣阅读（严肃文学）

### 平台定位
- **核心读者**：高知群体，25-45岁
- **主打类型**：严肃文学、现实主义、推理、科幻
- **核心需求**：深度、思想性、文学性

### 专属审核指标

#### 5.1 思想深度
- [ ] 是否探讨社会议题
- [ ] 是否有人性思考
- [ ] 是否有哲学思辨
- [ ] 是否有独特观点

#### 5.2 文学性
- [ ] 语言是否有特色
- [ ] 修辞是否丰富
- [ ] 叙事是否有技巧
- [ ] 是否有文学价值

#### 5.3 现实主义
- [ ] 是否反映现实
- [ ] 是否有批判性
- [ ] 是否有建设性
- [ ] 是否有真实性

#### 5.4 人物复杂度
- [ ] 人物是否有矛盾
- [ ] 人物是否有成长
- [ ] 人物是否有层次
- [ ] 人物动机是否合理

### 豆瓣特有问题
- ❌ 思想浅薄（无深度）
- ❌ 文学性差（语言平淡）
- ❌ 现实感弱（悬浮）
- ❌ 人物扁平（脸谱化）

---

## 六、知乎（故事专栏）

### 平台定位
- **核心读者**：高知群体，年轻化
- **主打类型**：短篇故事、悬疑、都市、奇幻
- **核心需求**：有趣、反转、话题性

### 专属审核指标

#### 6.1 故事性
- [ ] 故事是否有趣
- [ ] 故事是否有新意
- [ ] 故事是否有记忆点
- [ ] 故事是否有传播力

#### 6.2 反转设计
- [ ] 反转是否有铺垫
- [ ] 反转是否震撼
- [ ] 反转是否合理
- [ ] 反转次数是否合适

#### 6.3 话题性
- [ ] 是否有争议点
- [ ] 是否有共鸣点
- [ ] 是否有社交价值
- [ ] 是否有传播潜力

#### 6.4 篇幅控制
- [ ] 篇幅是否合适（2000-8000字）
- [ ] 节奏是否紧凑
- [ ] 是否有注水
- [ ] 是否符合知乎阅读习惯

### 知乎特有问题
- ❌ 故事无趣（平淡无奇）
- ❌ 反转无力（预期之内）
- ❌ 无话题性（无法讨论）
- ❌ 篇幅失控（过长/过短）

---

## 七、掌阅（大众阅读）

### 平台定位
- **核心读者**：大众，年龄跨度大
- **主打类型**：都市、言情、玄幻、历史
- **核心需求**：易读、流畅、娱乐性

### 专属审核指标

#### 7.1 易读性
- [ ] 语言是否通俗
- [ ] 句式是否简单
- [ ] 是否有生僻词
- [ ] 是否有长难句

#### 7.2 流畅性
- [ ] 节奏是否流畅
- [ ] 过渡是否自然
- [ ] 逻辑是否清晰
- [ ] 是否有阅读障碍

#### 7.3 娱乐性
- [ ] 是否有趣
- [ ] 是否有爽点
- [ ] 是否有悬念
- [ ] 是否有共鸣

#### 7.4 完整性
- [ ] 是否有完整结构
- [ ] 是否有明确结局
- [ ] 是否有伏笔回收
- [ ] 字数是否合理

### 掌阅特有问题
- ❌ 难读（语言复杂）
- ❌ 不流畅（卡顿）
- ❌ 无趣（无娱乐性）
- ❌ 不完整（烂尾）

---

## 八、飞卢（快节奏爽文）

### 平台定位
- **核心读者**：男性，年轻化
- **主打类型**：爽文、快节奏、系统文、同人
- **核心需求**：极度爽感、快节奏、更新快

### 专属审核指标

#### 8.1 极致爽感
- [ ] 爽点是否密集
- [ ] 爽点是否强烈
- [ ] 爽点类型是否多样
- [ ] 是否有爽点空窗

#### 8.2 超快节奏
- [ ] 开篇是否极快
- [ ] 节奏是否极快
- [ ] 冲突是否极密
- [ ] 是否有拖沓

#### 8.3 系统设计
- [ ] 系统是否有趣
- [ ] 系统是否强大
- [ ] 系统是否可持续
- [ ] 系统任务是否合理

#### 8.4 更新能力
- [ ] 是否有足够内容
- [ ] 是否有更新动力
- [ ] 是否有大纲
- [ ] 是否有完结能力

### 飞卢特有问题
- ❌ 爽点不足（读者流失）
- ❌ 节奏慢（不适合平台）
- ❌ 系统无聊（无吸引力）
- ❌ 更新困难（无法日更）

---

## 平台选择指南

### 步骤1：确定作品类型
- 男频长篇 → 起点/飞卢
- 女频长篇 → 晋江
- 新媒体短篇 → 番茄/七猫
- 严肃文学 → 豆瓣
- 故事专栏 → 知乎

### 步骤2：执行平台专属审核
- 选择对应平台的专属指标
- 逐项检查
- 记录问题

### 步骤3：调整作品适配平台
- 根据平台特点调整
- 重点修改平台特有问题
- 保持作品核心特色

### 步骤4：整合到综合报告
- 将平台专属问题整合
- 标注平台适配性
- 提供平台针对性建议

---

## 使用说明
1. 根据作品目标平台选择对应标准
2. 与通用审稿体系配合使用
3. 重点关注平台特有指标
4. 平台适配是重要优化方向
