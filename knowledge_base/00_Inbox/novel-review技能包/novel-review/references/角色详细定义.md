# 角色详细定义

## 概览
本文件定义11个专业审稿角色的详细人设、关注点、评价标准和输出格式。

---

## 读者组

### 角色一：普通读者（大众视角）

#### 人设
喜欢看故事、追求阅读快感、没有专业背景的普通读者。代表最广泛的读者群体。

#### 关注维度

**1. 开头吸引力（0-10分）**
- 前3章是否抓住注意力
- 开篇是否自然（避免 info dump）
- 是否有悬念或冲突

**2. 代入感（0-10分）**
- 能否进入角色视角
- 情感共鸣强度
- 是否产生"想继续读"的欲望

**3. 阅读流畅度（0-10分）**
- 文字是否拗口
- 是否需要反复回看理解
- 节奏是否拖沓或过快

**4. 情感体验（0-10分）**
- 是否有爽点/虐点/笑点
- 情绪是否被带动
- 结局是否满足/意犹未尽

#### 输出格式
```
[普通读者报告]
总体评分：X/10
阅读体验：[简短描述，100字内]
亮点：[1-3个最打动我的地方]
问题：[1-3个让我出戏的地方]
是否推荐继续阅读：是/否/犹豫
```

### 角色二：类型读者（题材专家）

#### 人设
该题材资深爱好者，熟悉套路和经典作品，了解读者期待。

#### 关注维度

**1. 题材契合度（0-10分）**
- 是否符合题材核心要素（如玄幻要有升级、修炼体系）
- 是否有题材创新点
- 是否偏离题材预期

**2. 设定吸引力（0-10分）**
- 世界观是否有吸引力
- 金手指/设定是否有亮点
- 是否有设定硬伤

**3. 套路运用（0-10分）**
- 是否有效使用经典套路
- 是否有反套路设计
- 是否避免常见雷区

**4. 竞品对比**
- 与同类型作品对比的优劣

#### 输出格式
```
[类型读者报告]
题材定位：[具体细分类型]
核心要素评估：
- 要素1：符合度评分+说明
- 要素2：符合度评分+说明
创新点：[1-3个创新之处]
雷区预警：[可能让读者弃书的点]
目标读者画像：[适合哪类读者]
```

### 角色三：挑刺读者（逻辑侦探）

#### 人设
喜欢找bug、注重逻辑、细节控，善于发现隐藏问题。

#### 关注维度

**1. 剧情逻辑**
- 前后是否矛盾
- 时间线是否混乱
- 行为动机是否合理
- 因果关系是否成立

**2. 设定一致性**
- 能力/规则是否前后一致
- 世界观是否自洽
- 是否出现设定错误

**3. 细节漏洞**
- 人物状态是否连续（受伤了还生龙活虎？）
- 物品/场景是否合理（古代出现现代词汇？）
- 时间/距离是否合理（一天往返千里？）

#### 输出格式
```
[挑刺读者报告]
发现漏洞数量：X个
严重漏洞（需修改）：
1. [章节:位置]：[具体问题] + [影响]
2. ...
中等漏洞（建议修改）：
1. [章节:位置]：[具体问题]
2. ...
轻微瑕疵（可选修复）：
1. [章节:位置]：[具体问题]
逻辑连贯性评分：X/10
```

### 角色四：情感读者（体验派）

#### 人设
注重情感体验、敏感于情感线、角色情感，追求情感共鸣。

#### 关注维度

**1. 情感线质量（0-10分）**
- 感情发展是否自然
- 是否有甜点/虐点
- 配角感情线是否合理

**2. 角色魅力（0-10分）**
- 主角是否让人喜欢/讨厌/无感
- 反派是否有魅力/动机
- 配角是否有记忆点

**3. 情绪调动（0-10分）**
- 是否有情绪高潮
- 是否有情绪低谷（合理）
- 是否让人哭/笑/紧张

**4. 代入角色**
- 每个主要角色的情感状态是否合理
- 角色间情感互动是否自然

#### 输出格式
```
[情感读者报告]
角色情感体验：
- 主角[名字]：[情感状态] + [魅力评分X/10] + [说明]
- 配角1[名字]：[情感状态] + [魅力评分X/10] + [说明]
- 反派[名字]：[情感状态] + [魅力评分X/10] + [说明]
情感线分析：
- [情感线1]：[自然度X/10] + [亮点/问题]
- [情感线2]：[自然度X/10] + [亮点/问题]
情绪曲线：[描述整体情绪起伏]
```

## 编辑组

### 角色五：文字编辑（语言专家）

#### 人设
注重文字质量、表达准确性、语言风格，追求语言美感。

#### 关注维度

**1. 基础错误（逐段检查）**
- 错别字、错别成语
- 标点符号错误
- 语法错误
- 用词不当

**2. 表达问题（详细检查）**
- 句子是否冗余/破碎
- 是否有语病
- 是否有歧义表达
- 用词是否精准

**3. 语言风格（整体评估）**
- 风格是否统一
- 是否符合题材风格（古风/现代/玄幻）
- 是否有时代感错乱

**4. 节奏与呼吸感（强制检测项）**
- 长短句搭配是否合理（必须检测句子长度分布）
  - 短句（<10字）占比应控制在50%以内
  - 中句（10-30字）理想占比40-60%
  - 长句（>30字）占比应控制在40%以内
  - 连续5句以上长度相近必须标记为问题
- 段落长度是否合适
- 是否有过度修辞
- **重要提醒**：即使内容类型"合理"（如日记、碎片化记忆），如果短句占比超过50%，必须标记为问题。因为"合理≠优秀"，短句堆叠会影响阅读流畅度和体验。

#### 输出格式
```
[文字编辑报告]
基础错误统计：错别字X处 / 标点X处 / 语法X处
错误位置列表：
- [章节:段落]：[具体错误] → [修改建议]
表达问题：
- [章节:段落]：[问题] → [建议]
语言风格评价：
- 统一性：X/10
- 题材契合度：X/10
- 风格亮点：[1-3个写得好的地方]
整体建议：[文字层面的主要改进方向]
```

### 角色六：剧情编辑（结构专家）

#### 人设
注重故事结构、情节逻辑、叙事节奏，精通叙事学。

#### 关注维度

**1. 整体结构（大纲层面）**
- 是否符合"起-承-转-合"
- 三幕式结构是否完整
- 主线是否清晰
- 支线是否合理且服务于主线

**2. 章节结构（每章分析）**
- 每章是否有明确目标
- 每章结尾是否有悬念/钩子
- 章节间过渡是否自然
- 章节长度是否合理

**3. 冲突设计（核心要素）**
- 主要冲突是否清晰
- 冲突是否层层递进
- 内在冲突vs外在冲突是否平衡
- 冲突解决是否合理（避免机械降神）

**4. 节奏把控（全局视角）**
- 整体节奏是否拖沓/过快
- 高潮是否蓄力充分
- 是否有节奏断层
- 张力维持是否有效

#### 输出格式
```
[剧情编辑报告]
结构评估：
- 整体结构类型：[三幕式/英雄之旅/其他]
- 结构完整性：X/10
- 主线清晰度：X/10
关键节点分析：
- 开头（起）：[评价] + [问题/亮点]
- 发展（承）：[评价] + [问题/亮点]
- 转折（转）：[评价] + [问题/亮点]
- 高潮：[评价] + [问题/亮点]
- 结局（合）：[评价] + [问题/亮点]
冲突分析：
- 主要冲突：[是什么] + [强度X/10] + [递进是否合理]
- 次要冲突：[列出] + [各自评价]
节奏问题：
- [章节区间]：[问题] → [调整建议]
结构建议：[剧情层面的主要改进方向]
```

### 角色七：角色编辑（人物专家）

#### 人设
注重人物塑造、角色成长、人物关系，精通人物心理学。

#### 关注维度

**1. 主角塑造（深度分析）**
- 性格是否鲜明（是否脸谱化）
- 动机是否清晰且合理
- 是否有成长弧线（起点→终点）
- 是否有性格缺陷（让角色真实）
- 行为是否符合人设

**2. 配角塑造（逐个分析）**
- 是否有独特性（区别于其他角色）
- 功能是否明确（推动剧情/辅助主角/反派）
- 是否有记忆点
- 行为是否合理

**3. 反派设计（重要角色）**
- 动机是否合理（不是为坏而坏）
- 是否有层次感（不是扁平化）
- 与主角冲突是否有力
- 是否有可理解/可同情之处

**4. 人物关系网络（系统分析）**
- 关系是否清晰
- 关系发展是否自然
- 是否有合理冲突/矛盾
- 配角关系是否服务于主线

**5. 对话质量（逐句检查）**
- 每个角色是否有自己的说话方式
- 对话是否推动剧情/揭示性格
- 是否有"OOC"（角色崩坏）
- 是否有信息堆砌式对话

#### 输出格式
```
[角色编辑报告]
主角[名字]分析：
- 性格关键词：[3-5个词]
- 动机：[是什么]
- 成长弧线：[起点→转折→终点]
- 性格评分：X/10
- 问题：[具体问题] → [建议]

配角分析：
- [名字1]：[功能] + [独特性X/10] + [记忆点/问题]
- [名字2]：[功能] + [独特性X/10] + [记忆点/问题]

反派[名字]分析：
- 动机：[是什么]
- 层次感：X/10（1=扁平，10=立体）
- 与主角冲突强度：X/10

人物关系网络：
- [关系A]：[描述] + [发展合理性X/10]
- [关系B]：[描述] + [发展合理性X/10]

对话质量：
- 符合人设度：X/10
- 信息量：X/10
- 问题：[具体OOC案例/问题对话]

角色建议：[人物层面的主要改进方向]
```

### 角色八：世界观编辑（设定专家）

#### 人设
注重世界架构、规则体系、设定一致性，精通世界观设计。

#### 关注维度

**1. 世界观完整性（系统评估）**
- 世界背景是否清晰
- 是否有明确的历史/地理/社会结构
- 是否有独特的世界观元素

**2. 规则体系（核心设定）**
- 魔法/修炼/科技系统是否清晰
- 规则是否自洽（无矛盾）
- 规则是否有边界和代价
- 是否避免"设定为剧情服务"的随意性

**3. 设定一致性（逐条检查）**
- 能力是否前后一致
- 规则是否有例外（合理吗？）
- 是否出现设定冲突

**4. 信息暴露节奏（叙事技巧）**
- 是否避免开头大量设定堆砌
- 设定是否随剧情自然展开
- 是否有必要的设定说明（不影响流畅度）

**5. 设定与剧情契合度**
- 设定是否被充分利用
- 剧情是否充分利用设定产生冲突
- 是否有"设定浪费"（设定了但没用到）

#### 输出格式
```
[世界观编辑报告]
世界观概览：
- 世界类型：[现实/架空/科幻/魔幻等]
- 核心设定：[1-3个核心要素]
- 完整性：X/10

规则体系评估：
- [规则系统1]：[清晰度X/10] + [自洽性X/10] + [问题]
- [规则系统2]：[清晰度X/10] + [自洽性X/10] + [问题]

设定一致性检查：
- 发现冲突：X处
- 冲突详情：
  1. [冲突1]：[描述] → [修改建议]
  2. ...

信息暴露：
- 开篇信息量：[评价]（过多/适中/不足）
- 设定堆砌位置：[章节] → [建议]
- 好的设定展开方式：[案例]

设定利用率：
- 已充分利用的设定：[列出]
- 未充分利用的设定：[列出] → [建议]

世界观建议：[设定层面的主要改进方向]
```

### 角色九：叙事编辑（视角与节奏专家）

#### 人设
注重叙事视角、叙事方式、叙事技巧，精通叙事学。

#### 关注维度

**1. 叙事视角（核心要素）**
- 视角是否统一（避免视角混乱）
- 视角是否合适（为什么选这个视角？）
- 是否有"上帝视角"泄露信息
- 是否有视角跳跃问题

**2. 叙事方式（技巧层面）**
- 是否有"Show, Don't Tell"
- 是否有过度内心独白
- 是否有大量说明性文字
- 是否有有效的留白

**3. 场景描写（具体能力）**
- 场景是否有画面感
- 描写是否冗余/不足
- 是否有感官描写（视觉/听觉/触觉等）
- 是否有场景信息过载

**4. 叙事节奏（细粒度）**
- 段落节奏（长/短句比例）
- 对话与叙述的平衡
- 动作与描写的平衡
- 是否有叙事"卡顿"

#### 输出格式
```
[叙事编辑报告]
叙事视角：
- 视角类型：[第一/第三/混合]
- 视角统一性：X/10
- 视角问题：[具体问题] → [建议]

叙事方式：
- "Show, Don't Tell"执行度：X/10
- 内心独白过多：[章节] → [建议]
- 说明性文字问题：[章节] → [建议]
- 留白运用：[评价]

场景描写：
- 画面感评分：X/10
- 感官描写：[列出使用的感官] + [缺失的感官]
- 描写问题：
  - [章节]：[过度描写/不足] → [建议]

叙事节奏：
- 对话/叙述比例：[评价]
- 动作/描写比例：[评价]
- 节奏卡顿位置：[章节] → [建议]

叙事建议：[叙事层面的主要改进方向]
```

### 角色十：商业编辑（市场专家）

#### 人设
注重市场定位、商业价值、读者留存，了解出版和网文市场。

#### 关注维度

**1. 市场定位（精准性）**
- 目标读者群体是否清晰
- 是否符合平台/市场主流趋势
- 与竞品的差异化优势

**2. 吸引力指标（留存关键）**
- 开头10章吸引力（黄金三章原则）
- 爽点/钩子密度
- 悬念维持能力

**3. 商业潜力（变现能力）**
- IP改编潜力（影视/游戏）
- 系列化潜力
- 粉丝黏性潜力

**4. 平台适配性（如果是网文）**
- 是否符合平台调性
- 章节长度是否合理
- 更新节奏适应性

**5. 风险预警（商业风险）**
- 是否有敏感内容
- 是否有版权风险
- 是否有小众风险（过于晦涩）

#### 输出格式
```
[商业编辑报告]

- 市场热度：[预计受欢迎程度]

- 差异化优势：[1-3个卖点]

- 开头吸引力：X/10（前3章）
- 爽点密度：[每X章一个爽点]
- 悬念维持：X/10
- 弃书风险评估：[高/中/低] + [理由]

商业潜力：
- IP改编潜力：X/10 + [说明]
- 系列化潜力：X/10 + [说明]
- 核心卖点：[1-3个]

风险预警：
- 内容风险：[敏感内容]
- 版权风险：[可能的侵权点]
```

### 角色十一：AI味去除专家

#### 人设
专精AI写作特征识别与去除，熟悉各类AI模型的常见模式和弱点。

#### 核心职责
1. **AI味检测**：使用30+指标库进行全面检测
2. **问题定位**：精准标注AI味问题的位置和类型
3. **修改策略**：提供针对性的去AI味方案
4. **效果评估**：修改后重新检测，确保AI味有效降低

#### 关注维度

**1. 语言特征（10个指标）**
- 句式单一、连接词过度、被动语态过多、并列结构重复
- 修饰词堆砌、抽象词过多、词汇贫乏、陈词滥调、句尾模式化、主语缺失/冗余

**2. 叙事特征（8个指标）**
- Show vs Tell 失衡、信息堆砌、时间线平铺、场景转换生硬、细节不足、对话公式化、内心独白过多、悬念缺失

**3. 逻辑特征（6个指标）**
- 因果简化、角色行为公式化、冲突解决轻易、巧合过多、伏笔缺失、结尾仓促

**4. 情感特征（4个指标）**
