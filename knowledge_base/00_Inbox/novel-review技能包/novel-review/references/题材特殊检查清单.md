# 题材特殊检查清单

## 概览
不同题材有独特的创作规律和读者期待。本清单提供常见题材的特殊检查项。

---

## 玄幻/奇幻类

### 核心要素检查
- [ ] **修炼体系**
  - 体系是否清晰（等级、能力、晋升规则）
  - 晋升难度是否合理
  - 体系是否有创新点
  - 体系是否被充分利用

- [ ] **力量设定**
  - 力量来源是否合理
  - 力量代价是否明确
  - 力量边界是否清晰
  - 力量成长曲线是否合理

- [ ] **世界观规模**
  - 世界层级是否清晰
  - 势力分布是否完整
  - 地理设定是否完整
  - 历史背景是否有厚度

### 玄幻特有问题
- [ ] **主角外挂（金手指）**
  - 金手指是否合理
  - 金手指是否有成长性
  - 金手指限制是否明确
  - 金手指与剧情契合度

- [ ] **打脸节奏**
  - 打脸是否频繁
  - 打脸对象是否有层次
  - 打脸方式是否有新意
  - 打脸后是否有后续影响

- [ ] **设定一致性**
  - 修炼等级是否前后一致
  - 能力描述是否前后一致
  - 时间线是否合理
  - 地理距离是否合理

---

## 言情类

### 核心要素检查
- [ ] **CP设定**
  - 男女主人设是否鲜明
  - CP吸引力来源
  - 感情线起点是否合理
  - CP模式是否清晰

- [ ] **感情线节奏**
  - 初期互动是否有吸引点
  - 中期发展是否自然递进
  - 高潮爆发（表白、危机）
  - 结局（HE/BE/OE）

- [ ] **甜虐比例**
  - 甜点密度
  - 虐点设置
  - 甜虐比例（根据类型）
  - 甜虐转换是否自然

### 言情特有问题
- [ ] **配角感情线**
  - 配角CP是否有吸引力
  - 配角线是否喧宾夺主
  - 配角线是否服务于主线
  - 配角线是否有完整结局

- [ ] **误会处理**
  - 误会是否合理
  - 误会解除时机是否恰当
  - 误会是否有多次
  - 误会后感情是否有成长

- [ ] **第三者/情敌**
  - 情敌人设是否立体
  - 情敌动机是否合理
  - 情敌对主线的推动作用
  - 情敌最终结局

---

## 悬疑/推理类

### 核心要素检查
- [ ] **案件/谜题设计**
  - 谜题是否合理
  - 线索是否充足
  - 谜题是否有层次
  - 谜题解答是否震撼

- [ ] **线索埋设**
  - 线索是否隐蔽但可发现
  - 线索是否有误导
  - 线索是否有层次
  - 线索是否与结局呼应

- [ ] **逻辑严密性**
  - 时间线是否无矛盾
  - 人物动机是否合理
  - 犯罪手法是否可行
  - 推理过程是否严谨

### 悬疑特有问题
- [ ] **反转设计**
  - 反转是否有铺垫
  - 反转次数是否合理
  - 反转是否震撼
  - 反转后逻辑是否自洽

- [ ] **节奏把控**
  - 悬疑感维持
  - 高潮分布
  - 伏笔回收
  - 结局解释

- [ ] **角色可信度**
  - 侦探/主角能力是否合理
  - 反派智商是否在线
  - 证人/嫌疑人是否有动机
  - 角色行为是否符合常理

---

## 科幻类

### 核心要素检查
- [ ] **科幻设定**
  - 核心设定是否清晰
  - 设定是否科学合理或自洽
  - 设定是否为剧情服务
  - 设定是否有深度

- [ ] **科技逻辑**
  - 科技发展是否合理
  - 科技限制是否明确
  - 科技与人类关系
  - 科技伦理问题

- [ ] **世界观**
  - 未来社会结构
  - 科技对社会影响
  - 人类命运
  - 宇宙观

### 科幻特有问题
- [ ] **硬科幻vs软科幻**
  - 硬科幻：科学准确性、细节丰富度
  - 软科幻：设定自洽性、情感共鸣
  - 是否明确定位
  - 是否符合定位标准

- [ ] **时间旅行/平行时空**
  - 规则是否清晰
  - 悖论是否处理
  - 时间线是否复杂但可理解
  - 结局是否自洽

- [ ] **AI/机器人**
  - AI是否有人性/情感
  - AI与人类关系
  - AI觉醒过程是否合理
  - AI伦理问题

---

## 都市/现实类

### 核心要素检查
- [ ] **现实感**
  - 场景描写是否真实
  - 人物行为是否符合常理
  - 社会环境是否准确
  - 细节是否可信

- [ ] **社会议题**
  - 议题选择是否贴近现实
  - 议探讨是否有深度
  - 议题是否与人物成长结合
  - 议论是否自然

- [ ] **人物真实度**
  - 人物背景是否合理
  - 人物动机是否真实
  - 人物缺点是否真实
  - 人物成长是否可信

### 都市特有问题
- [ ] **职场描写**
  - 职场细节是否准确
  - 职业角色是否立体
  - 职场冲突是否真实
  - 职场成长是否合理

- [ ] **城市文化**
  - 城市氛围是否到位
  - 方言/俚语是否自然
  - 城市地标/文化是否融入
  - 时代感是否准确

- [ ] **现实主义**
  - 问题是否真实存在
  - 解决方案是否可行
  - 结局是否现实
  - 是否引发思考

---

## 武侠/仙侠类

### 核心要素检查
- [ ] **武学体系**
  - 招式、内功、轻功是否清晰
  - 武学等级是否合理
  - 武学传承是否合理
  - 武学与剧情结合

- [ ] **江湖世界**
  - 江湖势力分布
  - 江湖规则
  - 江湖文化
  - 江湖历史

- [ ] **侠义精神**
  - 主角的侠义观
  - 侠义与现实的冲突
  - 侠义是否贯穿全文
  - 侠义是否引发思考

### 武侠特有问题
- [ ] **战斗描写**
  - 战斗过程是否精彩
  - 招式描写是否生动
  - 战斗结果是否合理
  - 战斗是否有意义

- [ ] **江湖恩怨**
  - 恩怨是否有层次
  - 恩怨解决方式
  - 恩怨是否有代价
  - 恩怨是否与主线结合

- [ ] **爱情线**
  - 爱情与侠义的平衡
  - 爱情线节奏
  - 爱情线结局
  - 爱情对人物的影响

---

## 历史类

### 核心要素检查
- [ ] **历史准确性**
  - 时代背景是否准确
  - 历史事件是否真实或合理虚构
  - 历史人物是否真实或合理改编
  - 历史细节是否准确

- [ ] **历史观**
  - 作者的历史观是否清晰
  - 历史评价是否客观
  - 历史与现实的联系
  - 历史教训是否探讨

- [ ] **虚构与真实平衡**
  - 虚构部分是否合理
  - 虚构与历史冲突时的处理
  - 虚构角色与历史人物的互动
  - 虚构情节是否推动历史

### 历史特有问题
- [ ] **年代考据**
  - 服饰、饮食、器物是否符合时代
  - 语言风格是否符合时代
  - 社会制度是否符合时代
  - 地理是否准确

- [ ] **历史人物塑造**
  - 历史人物是否符合史实
  - 历史人物是否有新解读
  - 历史人物与虚构角色互动
  - 历史人物的成长/变化

- [ ] **历史事件改编**
  - 改编是否合理
  - 改编是否有意义
  - 改编是否震撼
  - 改编是否注明

---

## 使用说明
1. 根据小说题材选择对应清单
2. 与通用审稿体系配合使用
3. 重点关注题材特有检查项
4. 记录问题并整合到综合报告
