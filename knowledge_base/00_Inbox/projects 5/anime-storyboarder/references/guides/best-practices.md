## 分镜制作最佳实践

### 1. 场景构建的最佳实践

#### 三维空间布局
- **前景元素**：放置物体来增加深度感（门框、屏风、植物）
- **中景元素**：主要角色和动作发生的区域
- **背景元素**：环境和氛围的营造

#### 案例：
> 不要只写"一个房间"，要写：
> - 前景：半掩的雕花木门，门缝透出微光
> - 中景：八仙桌，两把椅子
> - 背景：满墙的书架，摇曳的烛台

### 2. 光影运用的最佳实践

#### 光源设计
- **主光**：主要光源，确定整体基调
- **辅光**：填充阴影，增加层次
- **轮廓光**：勾勒角色轮廓，分离主体与背景

#### 情绪用光
- **紧张/悬疑**：侧光、大光比、硬阴影
- **温馨/浪漫**：柔光、小光比、暖色调
- **恐怖/诡异**：底光、顶光、不规则阴影

### 3. 角色调度的最佳实践

#### 动效设计
- **入场**：角色如何进入画面（推开门、从阴影中走出、从天而降）
- **动线**：角色在画面中的移动路径
- **静止**：角色静止时的姿态和表情

#### 案例：
> 不要只写"他走进来"，要写：
> - 入场：靴声先至，然后他从黑暗的走廊踏入光影中
> - 动线：他没有直接走向她，而是先在门口停顿，打量房间
> - 静止：他站在光影交界处，一半脸在明，一半脸在暗

### 4. 景别运用的最佳实践

#### 景别节奏
- **开场**：远景/全景 → 建立环境
- **发展**：中景/近景 → 推进叙事
- **高潮**：特写 → 强化情绪
- **结尾**：全景/远景 → 收尾升华

#### 多样化原则
- 避免连续3个相同景别
- 混合使用：大景别交代环境，小景别聚焦细节
- 创造性使用：用特写拍环境，用全景拍细节

### 5. 运镜设计的最佳实践

#### 运镜与情绪匹配
- **推镜**：强调、发现、逼近
- **拉镜**：揭示、远离、收尾
- **摇镜**：扫视、跟随、展示
- **移镜**：跟随、平行、探索
- **跟镜**：紧张、追逐、代入
- **手持**：动荡、真实、主观

## 常见错误与避免方法

### 错误1：全片近景/特写

**问题**：
- 观众不知道角色在哪里
- 缺乏空间感和环境信息
- 容易产生视觉疲劳

**修正方法**：
- 每5-6个镜头至少有一个全景/远景
- 新场景开场必须用大景别建立空间
- 重要动作前先交代环境

### 错误2：滥用"推镜"

**问题**：
- 每个镜头都"缓慢推近"
- 没有变化，观众麻木
- 真正需要强调时反而没有效果

**修正方法**：
- 推镜只用于关键情绪点
- 用不同的运镜方式：拉镜、摇镜、移镜、跟镜
- 有时候"静止"比"动"更有力量

### 错误3：场景描述只有地点

**问题**：
- "房间"、"花园"、"街道"
- 美术师不知道怎么设计
- 缺乏氛围感

**修正方法**：
- 时间：什么季节？什么时辰？
- 天气：晴天？雨天？雪天？
- 光线：自然光？人造光？
- 氛围：温馨？诡异？紧张？
- 细节：有什么特别的物品？

### 错误4：分镜和剧本完全一样

**问题**：
- 剧本写"他很生气"，分镜也写"他很生气"
- 没有视觉化
- 失去分镜的意义

**修正方法**：
- 把情绪转化为视觉：
  - 生气 → 握紧的拳头、青筋暴起、咬牙切齿
  - 悲伤 → 颤抖的肩膀、滑落的泪水、空洞的眼神
  - 紧张 → 冒汗的额头、不安的眼神、急促的呼吸

### 错误5：角色提示词包含场景信息

**问题**：
- "沈晚瑜站在婚房里"
- 角色和场景混在一起
- 无法单独使用角色图

**修正方法**：
- 角色提示词只包含角色：
  - 人物：沈晚瑜
  - 外貌：描述她的长相、穿着、表情
  - 背景：simple background 或 solid color background
- 场景单独用场景提示词生成

### 错误6：场景提示词包含人物

**问题**：
- "一个房间，里面有个人"
- 每次生成的人物都不一样
- 无法控制角色 consistency

**修正方法**：
- 场景提示词必须包含：
  - empty / scenery only / no people
  - 只描述环境
- 人物后期合成或单独生成

## 优化建议

### 1. 角色提示词优化

#### 结构优化
```
原始：
沈晚瑜, 古风美女, 穿红色衣服

优化后：
(masterpiece, best quality:1.2), 1girl, solo, Shen Wanyu,
black hair, traditional Chinese updo, delicate hair accessories,
red wedding dress, intricate embroidery, phoenix pattern,
looking at viewer, gentle expression, slight blush,
soft lighting, shallow depth of field,
simple background, solid color background
--ar 2:3 --v 6.0 --s 250
```

#### 关键要素
- 质量标签：masterpiece, best quality
- 人物：1girl, solo, 名字
- 发型：细节描述
- 服装：面料、图案、颜色
- 表情：情绪、神态
- 光线：soft lighting, dramatic lighting
- 背景：simple background, solid color background
- 参数：--ar, --v, --s

### 2. 场景提示词优化

#### 白名单策略
- ✅ empty / scenery only / no people
- ✅ interior / exterior
- ✅ 建筑、家具、装饰
- ✅ 天气、光线、氛围
- ✅ 风格、艺术参考

#### 黑名单策略
- ❌ 任何人物：girl, boy, man, woman, people, person, character, figure
- ❌ 任何身体部位：face, hand, arm, leg, head, body
- ❌ 任何代词：she, he, her, his, they
- ❌ 任何动作：standing, sitting, walking, talking
- ❌ 任何暗示有人：occupied, inhabited, crowded

#### 优化示例
```
原始：
一个中式房间，里面有张桌子，还有两把椅子

优化后：
Interior of a luxurious ancient Chinese study, empty.
Dark wooden furniture, ornate carvings, antique decorations.
Scroll paintings on the walls, incense burner on the table.
Dramatic lighting from paper windows, dust motes in the air.
--ar 16:9 --v 6.0
```

### 3. Sora分镜优化

#### 时间段设计
- **0-3秒**：建立、入场、发现
- **3-7秒**：发展、互动、高潮
- **7-10秒**：收尾、反应、转场

#### 案例
```
原始：
0-3秒：他走进来
3-7秒：他们说话
7-10秒：他离开

优化后：
0-3秒：【环境建立】镜头从摇曳的烛火缓缓拉开，露出沈晚瑜端坐在床沿的剪影，红盖头已经取下放在一旁。
3-7秒：【动作展开】陆砚礼站在阴影中，沉默良久，终于开口："晚瑜，我有件事要告诉你。"他的声音在空旷的房间里回响。
7-10秒：【情绪转折】沈晚瑜抬起头，眼中先是疑惑，然后随着他的话语逐渐变为震惊。
```

## 质量检查清单

### 分镜前检查
- [ ] 我理解故事的核心情绪和主题
- [ ] 我知道每个场景的目的
- [ ] 我已经规划了景别的节奏变化
- [ ] 我已经设计了光影的整体基调
- [ ] 我知道哪里应该快，哪里应该慢

### 分镜中检查
- [ ] 新场景开场都有大景别
- [ ] 没有连续3个相同景别
- [ ] 运镜方式多样化（不是每个都推镜）
- [ ] 有角色入场、动线、静止的设计
- [ ] 有前景、中景、背景的三维布局
- [ ] 光影有明确的光源和情绪目的

### 分镜后检查
- [ ] 所有描述都是"视觉化"的
- [ ] 没有"他很生气"这种直接写情绪的
- [ ] 每个镜头都有明确的功能
- [ ] 整体节奏有张有弛
- [ ] 没有滥用特效和慢动作

### 角色提示词检查
- [ ] 有质量标签（masterpiece, best quality）
- [ ] 明确标注 1girl/solo 或 1boy/solo
- [ ] 外貌细节足够（发型、服装、表情）
- [ ] 背景是 simple background 或 solid color background
- [ ] 没有场景信息
- [ ] 有合理的参数（--ar, --v, --s）

### 场景提示词检查
- [ ] 明确标注 empty / scenery only / no people
- [ ] 没有任何人、身体部位、代词、动作
- [ ] 有足够的环境细节（建筑、家具、装饰）
- [ ] 有光线和氛围描述
- [ ] 有合理的参数（--ar, --v）
- [ ] 通过了白名单/黑名单检查

### Sora分镜检查
- [ ] 每个分镜都有完整的【0-3秒】【3-7秒】【7-10秒】
- [ ] 三个时间段有明确的功能区分
- [ ] 景别和运镜多样化
- [ ] 描述足够详细，可以直接用于生成
- [ ] 符合Sora的输入格式
