## 景别详细规则

### 远景（Long Shot）

**作用**：展示环境、交代场景、建立空间关系

**使用场景**：
- 开场镜头，交代故事发生的地点
- 转场时连接不同场景
- 展现大规模场景（战争、游行、自然灾害等）
- 表现人物的渺小与环境的对比

**典型示例**：
- 开场：侯府全景，展示深宅大院的压迫感
- 转场：从京城远景切到侯府
- 战争：战场全景，展现两军对垒

### 全景（Full Shot）

**作用**：展现人物全身姿态和周围环境的关系

**使用场景**：
- 人物出场，展示整体造型
- 场景交代，展示人物与环境的互动
- 动作场景，展现人物的完整动作
- 转场，连接不同空间

**典型示例**：
- 沈晚瑜站在回廊中，展现她的孤身一人
- 陆砚礼在房间中痛苦打滚，展现完整的动作
- 人物穿过花园，展现环境的移动

### 中景（Medium Shot）

**作用**：展现人物上半身，适合对话和普通叙事

**使用场景**：
- 对话场景，展现人物的互动
- 普通叙事，平衡人物和环境
- 人物表情变化，展现情绪波动
- 多人场景，展现人物关系

**典型示例**：
- 陆砚礼和沈晚瑜对话
- 侯老夫人训斥沈晚瑜
- 多人聚集的场景

### 近景（Medium Close-up）

**作用**：聚焦人物面部表情和上半身

**使用场景**：
- 情绪表达，展现人物的内心状态
- 重要对话，强调台词的分量
- 人物反应，捕捉细微的表情变化
- 心理活动，展现人物的情绪波动

**典型示例**：
- 沈晚瑜面露为难的神色
- 陆砚礼痛苦的表情
- 侯老夫人严厉的目光

### 特写（Close-up）

**作用**：突出某个细节或强烈情绪

**使用场景**：
- 情绪高潮，强化情感表达
- 关键细节，强调重要道具或动作
- 人物眼神，传递内心活动
- 系统提示，突出特殊效果

**典型示例**：
- 沈晚瑜瞪大的眼睛
- 陆砚礼痛苦扭曲的脸
- 系统文字的特写
- 手部动作（攥裙摆、绞手帕）

### 大特写（Extreme Close-up）

**作用**：极近距离展示微小细节

**使用场景**：
- 瞳孔变化，展现震惊
- 眼泪、汗水，强化情绪
- 道具细节，强调重要性
- 极致情绪，展现人物内心的剧烈波动

**典型示例**：
- 沈晚瑜眼角的泪珠
- 陆砚礼额头上的青筋
- 系统文字的细节

## 运镜详细规则

### 固定镜头（Static）

**特点**：摄像机静止不动

**使用场景**：
- 冷静观察，客观陈述
- 稳定对话，展现人物关系
- 环境交代，展现空间
- 悬念营造，等待突发事件

**效果**：冷静、客观

**典型示例**：
- 对话场景，双方中景固定
- 房间全景，交代环境
- 等待暴风雨前的宁静

### 推镜（Dolly In）

**特点**：摄像机向主体推进

**使用场景**：
- 强调细节，聚焦重要元素
- 情绪递进，展现情感变化
- 悬念营造，逐步揭示真相
- 人物聚焦，引导观众关注

**典型示例**：
- 从中景推进到沈晚瑜的脸部特写
- 推进到系统文字
- 推进到关键道具

### 拉镜（Dolly Out）

**特点**：摄像机远离主体

**使用场景**：
- 展示环境，释放紧张感
- 转场，连接不同场景
- 孤独感，展现人物的孤立
- 释放情绪，缓解紧张气氛

**典型示例**：
- 从沈晚瑜脸部拉到房间全景
- 从特写拉到远景
- 从人物拉到环境

### 摇镜（Pan）

**特点**：摄像机水平转动

**使用场景**：
- 跟随人物移动
- 扫描场景，展示环境
- 人物互动，展现关系
- 转场，平滑过渡

**效果**：流畅的视角转换

**典型示例**：
- 摇镜头跟随沈晚瑜走过回廊
- 扫描房间，展示陈设
- 在两人对话时摇镜

### 俯镜（Tilt）

**特点**：摄像机垂直转动

**使用场景**：
- 展示高低差
- 从上到下，俯视人物
- 从下到上，仰视人物
- 展现建筑的层次

**典型示例**：
- 从天花板俯视痛苦中的陆砚礼
- 从沈晚瑜脚下仰到脸部
- 展示侯府建筑的宏伟

### 晃动镜头（Handheld）

**特点**：模拟手持摄像机的晃动

**使用场景**：
- 混乱场景，体现失控
- 主观视角，增强代入感
- 惊悚氛围，营造紧张感
- 动作场景，增强动感

**典型示例**：
- 沈晚瑜受到惊吓的视角
- 陆砚礼痛苦挣扎的场景
- 混乱的打斗场面

### 跟拍（Tracking Shot）

**特点**：摄像机跟随移动的主体

**使用场景**：
- 人物移动，展现行进过程
- 跟随主角，增强代入感
- 转场，平滑过渡
- 动作场景，展现动态

**效果**：沉浸感、参与感

**典型示例**：
- 跟随沈晚瑜穿过回廊
- 跟随人物跑动
- 跟随人物进入房间

### 旋转镜头（Orbit）

**特点**：围绕主体旋转拍摄

**使用场景**：
- 戏剧化效果，增强冲击力
- 环视环境，展示360度空间
- 人物关系，展现互动
- 强化情绪，营造氛围

**效果**：戏剧性强、视觉冲击力

**典型示例**：
- 围绕沈晚瑜旋转，展现她的孤立
- 环视房间，展示环境
- 围绕关键道具旋转

### 推拉镜（Dolly Zoom）

**特点**：摄像机移动同时变焦，产生透视变化

**使用场景**：
- 戏剧化效果，视觉冲击
- 情绪突变，营造不安
- 悬念营造，突出异常
- 梦境/幻觉效果

**典型示例**：
- 沈晚瑜意识到系统存在的瞬间
- 陆砚礼谎言成真时的视觉冲击
- 回忆与现实交替

## 场景组合模板

### 开场场景

**镜头组合**：远景固定 → 中景推进 → 中景摇镜

**效果**：环境交代 → 聚焦主体 → 带入故事

**示例**：侯府远景 → 推进到沈晚瑜 → 摇镜跟随走向婚房

### 对话场景

**镜头组合**：中景固定 → 近景切镜 → 特写拉远

**效果**：展示对话 → 聚焦说话者 → 展现听者反应

**示例**：双方对话 → 陆砚礼说话 → 沈晚瑜反应

### 情绪爆发

**镜头组合**：近景突发 → 手持摇晃 → 特写固定

**效果**：事件开始 → 混乱感 → 聚焦情绪

**示例**：惨叫 → 在床上打滚 → 痛苦表情

### 转场场景

**镜头组合**：全景固定 → 中景推进 → 中景拉远

**效果**：环境交代 → 过渡引导 → 释放紧张

**示例**：老夫人房中 → 推进到门口 → 沈晚瑜离开

### 悬疑场景

**镜头组合**：特写推进 → 近景俯拍 → 中景摇镜

**效果**：制造悬念 → 展现压迫 → 释放紧张

**示例**：系统文字 → 侯老夫人俯视 → 扫描房间

### 回忆场景

**镜头组合**：中景固定 → 特写推进 → 特写拉远（带滤镜）

**效果**：建立回忆 → 聚焦关键 → 返回现实

**示例**：沈府花园 → 暖玉特写 → 拉远（暖色调滤镜）

## 多样化约束

### 景别多样化

**约束1：景别多样化**
- 至少包含远景、全景、中景、近景、特写5种景别
- 相邻镜头必须使用不同景别
- 特写后不要立即用特写，先用中景或近景过渡
- 远景和特写交替使用，创造节奏感

### 运镜多样化

**约束2：运镜多样化**
- 至少包含固定、推进、拉远、摇镜、切镜5种运镜
- 不能所有镜头都是固定镜头
- 同一种运镜方式不要连续使用超过3次
- 运镜速度要有快慢变化

### 时长多样化

**约束3：时长多样化**
- 时长1-3秒，不重复
- 重要内容时长稍长（2-3秒）
- 快节奏场景时长较短（1-1.5秒）
- 转场镜头适中（2秒）
- 不能所有镜头都是相同时长

### 最少包含

**约束4：最少包含**
- 景别：至少包含远景、全景、中景、近景、特写5种
- 运镜：至少包含固定、推进、拉远、摇镜、切镜5种

### 时间段递进

**约束5：时间段递进**
- 同一分镜的3个时间段要有逻辑递进
- 0-3秒：建立场景或事件开始
- 3-7秒：事件发展或情绪递进
- 7-10秒：事件结果或释放紧张
