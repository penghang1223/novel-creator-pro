## 提示词结构公式

### 基础公式

```
[主体] + [动作] + [场景] + [光线] + [氛围] + [风格] + [质量]
```

### 完整公式

```
[镜头类型], [主体描述], [动作/姿态],
[场景/环境], [时间], [天气],
[光线设置], [色彩基调],
[情绪氛围], [风格关键词],
[质量增强词]
```

### 权重分配（重要性排序）

1. **主体** (30%) - 最重要，决定画面核心
2. **动作/姿态** (20%) - 定义主体状态
3. **场景** (15%) - 提供上下文
4. **光线** (15%) - 影响整体氛围
5. **风格+质量** (20%) - 统一视觉效果

## 组合技巧

### 多元素组合

```
公式:
[景别] + [运镜] + [主体] + [动作] + [场景] + [光线] + [氛围] + [质量]

示例:
大远景 + 缓慢推近 + 城市天际线 + 日落时分 + 黄金时刻光线 + 温暖色调 + 史诗感 + 电影感高质量
```

### 情绪递进

```
场景开始:
中景 固定镜头 平静对话
↓
情绪升级:
特写 推镜头 紧张对视
↓
高潮爆发:
大特写 甩镜 激烈冲突
↓
情绪释放:
中景 拉镜头 无力瘫坐
```

### 一致性组合

```
角色一致性:
[角色ID] + [核心外貌特征] + "保持外貌一致, 同一个人, 维持身份"

场景一致性:
[场景ID] + [环境特征] + "保持环境一致, 维持地点"

光线一致性:
[光线ID] + [光源描述] + "整场保持光线一致"
```
