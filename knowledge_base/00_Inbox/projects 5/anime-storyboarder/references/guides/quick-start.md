## 1分钟上手

### 步骤1：准备剧本
直接把小说或剧本原文发给我，任何格式都可以。

### 步骤2：选择内容
我会问你需要什么，可多选：
- 角色形象
- 角色提示词
- 场景提示词
- Sora分镜
- 表格分镜
- 提示词优化

### 步骤3：获取分镜
几分钟后获得专业级分镜内容。

## 输入示例

### 小说片段
```
新婚夜，红烛摇曳。
沈晚瑜端坐在床沿，手指紧张地攥着裙摆。
陆砚礼站在桌前，面露难色。
"晚瑜，"他的声音低沉，"我在战场上伤了命根子。"
沈晚瑜猛地抬头，眼中满是震惊。
```

### 简单剧本
```
场景：公园长椅
时间：黄昏

（李明和王芳并肩坐着）

李明：（轻声）我们...真的要分手吗？
王芳：（点头，眼眶微红）嗯，不合适。

（王芳起身离开，李明独自坐着，夕阳拉长身影）
```

### 故事描述
```
时间旅行故事：
张晨每天穿越到前一天，试图改变过去但带来意外后果。
场景：现代都市、办公室、公寓
角色：张晨（上班族）、林小雨（女友）
```

## 常见模式

### 模式1：快速预览
**选择**：角色形象 + 场景提示词
**优点**：快速了解视觉风格
**适用**：不确定是否要做完整分镜

### 模式2：AI视频制作
**选择**：Sora分镜 + 场景提示词
**优点**：直接用于Sora等AI视频工具
**适用**：快速生成AI视频

### 模式3：专业制作
**选择**：全部（1-6）
**优点**：完整制作级分镜包
**适用**：专业动漫/动画制作

### 模式4：提示词优化
**选择**：角色提示词 + 提示词优化
**优点**：获得高质量AI绘画提示词
**适用**：优化现有提示词

## 进阶技巧

### 提升质量的技巧
1. **提供详细描述**：越详细的剧本，越好的分镜
2. **明确风格**：告诉我要什么风格（古风、现代、赛博朋克等）
3. **指定情绪**：说明场景的情绪氛围（紧张、温馨、悬疑等）
4. **参考示例**：给我参考图片或描述，我能更好地理解需求

### 修改和调整
- 告诉我哪里需要调整
- 可以只修改某一部分
- 要求重新生成某个镜头或场景

### 批量处理
- 长剧本可以分批处理
- 每批处理1-3个章节
- 保持整体一致性
