## 模块1：需求识别与路由层

### 功能定位
技能的"守门员"，确保输出符合用户预期，避免盲目生成。

### 实现逻辑
```
输入剧本 → 意图识别 → 强制询问 → 等待用户确认 → 路由到对应生成模块
```

### 核心规则

**规则1：强制询问**
- 无论用户需求是否明确，必须先询问需要生成什么内容
- 避免一次性生成所有内容（资源浪费、用户不需要）

**规则2：模块化解耦**
- 5种输出类型完全独立
- 支持用户任意组合选择

**规则3：依赖检测**
- 角色提示词需依赖角色形象
- 若用户未提供角色形象，需询问是否先生成

**规则4：模糊处理**
- 用户说"都生成"、"全部"时，需再次确认具体指哪些内容
- 确保精确产出

### 询问模板
```
我已收到您的剧本/小说原文。请告诉我您需要生成哪些内容（可多选）：

1. 角色形象（角色名称、外貌、性格、小传）
2. 角色提示词（需先有角色形象，用于AI绘画）
3. 场景提示词（场景描述和绘图指令，纯环境场景）
4. Sora分镜提示词（视频分镜，每个分镜含0-3秒、3-7秒、7-10秒三个时间段）
5. 分镜提示词（表格化分镜脚本）

您可以选择其中一项或多项，我将按照您的要求生成对应内容。

例如：请生成角色形象和场景提示词
```

### 用户响应处理

| 用户响应类型 | 处理方式 | 示例 |
|------------|---------|------|
| 明确指定 | 按用户指定生成 | "请生成角色形象和场景提示词" |
| 模糊表述 | 再次确认 | "都生成" → "请明确选择1-5中的具体项" |
| 依赖缺失 | 提示补全 | "生成角色提示词" → "需先有角色形象，是否先生成？" |
| 数字编号 | 解析编号 | "1、3、5" → 生成角色形象、场景提示词、分镜提示词 |

## 模块2：结构化信息提取层

### 功能定位
从非结构化剧本中提取结构化信息，为后续生成提供数据基础。

### 角色提取引擎

**提取流程**：
```
文本扫描 → 实体识别 → 对话归属 → 行为分析 → 性格推断 → 外貌补全 → 角色档案构建
```

**提取维度表**：

| 维度 | 提取方式 | 示例 |
|-----|---------|------|
| 角色名称 | 人名识别 + 对话归属 | "陆砚礼说" → 角色：陆砚礼 |
| 外貌描述 | 直接描述提取 + 合理推断 | "身穿大红婚服" → 外貌特征 |
| 性格特征 | 对话语气 + 行为动作 + 心理活动 | "眼神闪烁躲避" → 虚伪狡诈 |
| 身份定位 | 称谓 + 上下文关系 | "小侯爷" → 身份：侯府少爷 |
| 角色小传 | 剧情位置 + 动机分析 + 与主线关系 | 新婚丈夫 + 撒谎动机 → 小传构建 |

**角色档案结构**：
```
角色名称：[名称]
外貌：[基于文本描述或合理推断]
职业/身份：[在故事中的角色定位]
性格：[基于行为、语言、心理活动分析]
角色小传：
[背景、动机、关键事件、与主线的关系]
```

### 场景提取引擎

**提取流程**：
```
地点识别 → 空间描述 → 氛围提取 → 关键道具 → 场景边界判定 → 场景档案构建
```

**提取维度表**：

| 维度 | 提取方式 | 示例 |
|-----|---------|------|
| 场景名称 | 地点识别 | "侯府婚房" |
| 空间结构 | 室内/室外，房间类型 | 室内，婚房 |
| 家具陈设 | 物品识别 | 红烛、喜床、桌椅 |
| 装饰物品 | 装饰品识别 | "囍"字、绸缎、锦盒 |
| 光线氛围 | 光源 + 情绪描述 | 烛光摇曳、冷清月光 |
| 关键事件 | 场景内发生的事件 | 翻倒酒杯、凌乱床铺 |

### 动作序列提取

**提取流程**：
```
动词识别 → 时序分析 → 动作分解 → 镜头适配 → 动作序列生成
```

**示例**：
```
原文："陆砚礼突然惨叫，蜷缩身体，双手死死捂住裆部"

动词识别：[惨叫、蜷缩、捂住]
时序分析：
  0-3秒：突然惨叫
  3-7秒：蜷缩身体
  7-10秒：捂住裆部
动作分解：
  - 惨叫：张大嘴巴、面部扭曲、身体前倾
  - 蜷缩：弯腰抱膝、身体收缩
  - 捂住：双手交叉覆盖、表情痛苦
镜头适配：
  - 0-3秒：近景突发（捕捉惨叫瞬间）
  - 3-7秒：中景晃动（展现蜷缩动作）
  - 7-10秒：特写固定（聚焦痛苦表情）
```

## 模块3：多模态转换引擎层

### 功能定位
将文本信息转化为各类视觉指令（角色提示词、场景提示词、分镜方案）。

### 角色提示词生成器

**生成流程**：
```
角色形象信息 → 字段映射 → AI绘画指令格式化 → 提示词输出
```

**字段映射表**：

| 原始字段 | 目标字段 | 转换规则 |
|---------|---------|---------|
| 年龄/性别 | 基础属性 | 直接提取 |
| 五官特征 | 五官描述 | 扩展为详细描述（如"杏眼" → "低垂顺从的黑色杏眼"） |
| 发型/发色 | 发型 | 添加质感词（如"乌黑长发梳成温婉的随云髻"） |
| 服饰 | 服饰描述 | 添加材质、色彩、款式（如"淡青色立领对襟刺绣长袄"） |
| 配饰 | 配饰 | 添加细节（如"插着一支素雅的珍珠步摇"） |
| 表情神态 | 表情 | 基于当前情境推断 |
| 时代背景 | 风格词 | 添加"古代"、"宫廷"、"民间"等 |
| - | 技术参数 | 固定添加"8k、高分辨率、大师级画作、精致的面部细节" |

### 场景提示词生成器

**核心原则**：
- **绝对禁止**：绘图指令中包含任何人物
- **必须包含**：绘图指令必须是纯环境场景（empty/scenery only/no people）

**双通道生成逻辑**：
```
场景信息
    ├─ 通道1：画面描述（中文）
    │   ├─ 可以提及人物活动（如"由于陆砚礼的剧痛挣扎"）
    │   ├─ 可以提及故事背景（如"暗示原本装在那里的暖玉已被强行抢走"）
    │   └─ 重点描述空间、光线、氛围
    │
    └─ 通道2：绘图指令（英文）
        ├─ 删除所有人物相关词汇（人名、人称、身体部位、动作、衣物）
        ├─ 强制添加：empty / scenery only / no people
        ├─ 只描述：空间结构、家具陈设、装饰物品、建筑元素、自然元素、光线效果、质感细节、环境氛围
        └─ 添加技术参数：8k, --ar 16:9, --v 6.0
```

### Sora分镜生成器

**核心原则**：
- 每个分镜必须包含完整的时间分段（0-3秒、3-7秒、7-10秒）
- 景别和运镜必须多样化，避免重复
- 时间段之间要有逻辑递进，画面内容要连贯

**时间分段规则**：

| 时间段 | 作用 | 典型内容 |
|-------|------|---------|
| 0-3秒 | 建立场景/事件开始 | 环境交代、人物出场、事件触发 |
| 3-7秒 | 事件发展/情绪递进 | 动作展开、情绪升级、互动进行 |
| 7-10秒 | 事件结果/释放紧张 | 动作完成、情绪释放、转场准备 |

## 模块4：镜头语言规则库层

### 功能定位
提供专业分镜知识，确保产出的专业性和多样性。

### 景别规则库

**6种景别定义**：

| 景别 | 作用 | 使用场景 | 示例 |
|-----|------|---------|------|
| **远景**（Long Shot） | 展示环境、交代场景、建立空间关系 | 开场镜头、转场、展现大规模场景 | 侯府全景、战场全景 |
| **全景**（Full Shot） | 展现人物全身姿态和周围环境的关系 | 人物出场、场景交代、动作场景 | 沈晚瑜站在回廊中 |
| **中景**（Medium Shot） | 展现人物上半身，适合对话和普通叙事 | 对话场景、普通叙事、人物表情变化 | 陆砚礼和沈晚瑜对话 |
| **近景**（Medium Close-up） | 聚焦人物面部表情和上半身 | 情绪表达、重要对话、人物反应 | 沈晚瑜面露为难 |
| **特写**（Close-up） | 突出某个细节或强烈情绪 | 情绪高潮、关键细节、人物眼神、系统提示 | 沈晚瑜瞪大的眼睛 |
| **大特写**（Extreme Close-up） | 极近距离展示微小细节 | 瞳孔变化、眼泪、汗水、道具细节 | 眼角的泪珠 |

### 运镜规则库

**9种运镜定义**：

| 运镜 | 特点 | 使用场景 | 示例 |
|-----|------|---------|------|
| **固定镜头**（Static） | 摄像机静止不动 | 稳定对话、环境交代、客观观察 | 双方对话中景固定 |
| **推镜**（Dolly In） | 摄像机向主体推进 | 强调情绪、聚焦细节、营造紧张感 | 推进到沈晚瑜脸部特写 |
| **拉镜**（Dolly Out） | 摄像机远离主体 | 展示环境、释放紧张感、转场 | 从脸部拉到房间全景 |
| **摇镜**（Pan） | 摄像机水平转动 | 跟随人物移动、扫描场景 | 摇镜头跟随走过回廊 |
| **俯镜**（Tilt） | 摄像机垂直转动 | 展示高低差、俯视/仰视 | 从天花板俯视痛苦中的陆砚礼 |
| **晃动镜头**（Handheld） | 模拟手持晃动 | 混乱场景、主观视角、紧张氛围 | 沈晚瑜受惊吓时的视角 |
| **跟拍**（Tracking Shot） | 摄像机跟随移动主体 | 人物移动、转场、动作场景 | 跟随人物穿过回廊 |
| **旋转镜头**（Orbit） | 围绕主体旋转 | 戏剧化效果、环视环境 | 围绕沈晚瑜旋转 |
| **推拉镜**（Dolly Zoom） | 移动同时变焦，产生透视变化 | 戏剧化效果、情绪突变、梦境/幻觉 | 沈晚瑜意识到系统存在的瞬间 |

## 模块6：质量控制层

### 功能定位
确保输出质量和专业性，通过多维度约束和检查保证产物质量。

### 质量控制点
```
约束检查 → 多样性验证 → 逻辑一致性 → 格式规范 → 最终输出
```

### 约束清单

| 约束类型 | 检查项 | 违规处理 |
|---------|-------|---------|
| **景别多样性** | 至少包含5种景别 | 重新分配 |
| **运镜多样性** | 至少包含5种运镜 | 重新分配 |
| **时长多样性** | 时长1-3秒，不重复 | 重新调整 |
| **场景无人物** | 绘图指令含empty等关键词 | 重新生成 |
| **时间段完整** | Sora分镜包含3个时间段 | 补全缺失 |
| **依赖关系** | 角色提示词需角色形象 | 提示用户 |
| **格式规范** | 严格按照模板输出 | 重新格式化 |
