用户输入剧本

    ↓

## 用户交互流程

```
用户输入剧本
    ↓
智能体：询问需要生成什么内容（1-5）
    ↓
用户：选择（如"1、3、5"）
    ↓
智能体：按照用户选择生成对应内容
    ↓
质量检查：通过
    ↓
智能体：交付最终产物
```

### 询问模板
```
我已收到您的剧本/小说原文。请告诉我您需要生成哪些内容（可多选）：

1. 角色形象（角色名称、外貌、性格、小传）
2. 角色提示词（需先有角色形象，用于AI绘画）
3. 场景提示词（场景描述和绘图指令，纯环境场景）
4. Sora分镜提示词（视频分镜，每个分镜含0-3秒、3-7秒、7-10秒三个时间段）
5. 分镜提示词（表格化分镜脚本）

您可以选择其中一项或多项，我将按照您的要求生成对应内容。

例如：请生成角色形象和场景提示词
```

## 异常处理流程

### 模糊表述处理
```
用户响应：模糊表述（"都生成"）
    ↓
智能体：再次确认具体选择
    ↓
用户：重新明确选择
    ↓
继续执行
```

### 依赖缺失处理
```
用户响应：依赖缺失（"生成角色提示词"但未提供角色形象）
    ↓
智能体：提示是否先生成角色形象
    ↓
用户：选择
    ↓
继续执行
```

### 质量检查未通过处理
```
质量检查：未通过（如景别不够多样化）
    ↓
智能体：自动调整（重新分配景别）
    ↓
再次检查：通过
    ↓
继续执行
```

## 附录：快速参考卡片

### 景别速查

| 景别 | 何时使用 | 时长建议 |
|-----|---------|---------|
| 远景 | 开场、转场、大规模场景 | 2-3秒 |
| 全景 | 人物出场、场景交代 | 2-3秒 |
| 中景 | 对话、普通叙事 | 1.5-2秒 |
| 近景 | 情绪表达、重要对话 | 1-2秒 |
| 特写 | 情绪高潮、关键细节 | 1-2秒 |
| 大特写 | 瞳孔、眼泪、道具细节 | 1秒 |

### 运镜速查

| 运镜 | 何时使用 | 效果 |
|-----|---------|------|
| 固定 | 对话、环境交代 | 冷静、客观 |
| 推进 | 强调情绪、聚焦细节 | 紧张感 |
| 拉远 | 展示环境、释放紧张 | 孤独感 |
| 摇镜 | 跟随人物、扫描场景 | 流畅转换 |
| 俯镜 | 俯视/仰视、高低差 | 权威/弱小 |
| 晃动 | 混乱、主观视角 | 紧张感 |
| 跟拍 | 人物移动、转场 | 沉浸感 |
| 旋转 | 戏剧化、环视环境 | 冲击力 |
| 推拉 | 情绪突变、梦境 | 不安感 |
