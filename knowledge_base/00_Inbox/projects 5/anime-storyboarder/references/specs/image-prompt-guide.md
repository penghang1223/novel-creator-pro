## 概览
本文档专门针对 AI 文生图（Text-to-Image）的提示词优化，提供系统化的方法论和模板，帮助将用户的描述转换为高质量的图像生成提示词。

## 文生图提示词特点

### 与视频提示词的区别

**静态 vs 动态**
- 文生图：关注静态画面美感、构图、光影、细节
- 视频生成：还需要考虑运动、镜头变化、时间推移

**构图优先级**
- 文生图：构图是核心，直接影响视觉冲击力
- 视频生成：构图是基础，但镜头运动同样重要

**细节精度**
- 文生图：注重纹理、材质、细节的精细度
- 视频生成：关注动态过程中的细节连贯性

### 文生图核心要素

**主体（Subject）**
- 人物：年龄、性别、外貌、服装、表情、姿态
- 物体：材质、颜色、形状、纹理、细节
- 动作：冻结的瞬间动作状态

**环境（Environment）**
- 场景：室内、室外、自然、城市
- 背景：天空、建筑、风景、装饰
- 道具：与主体相关的物品

**构图（Composition）**
- 景别：近景、中景、远景、特写
- 角度：平视、俯视、仰视
- 布局：三分法、对称、引导线

**光影（Lighting）**
- 光源：自然光、人工光、方向
- 色温：暖光、冷光、黄金时刻
- 强度：明亮、柔和、阴影

**风格（Style）**
- 艺术风格：写实、插画、油画、动漫
- 渲染质量：8K、超细节、照片级
- 技术参数：分辨率、色调

## 优化方法论

### 三步优化法

**第一步：理解用户核心需求**
- 识别用户想表达的情感或故事
- 明确视觉重点（主体、动作、环境）
- 确定风格定位（写实、艺术、商业等）

**第二步：补充专业要素**
- 添加构图细节（景别、角度、布局）
- 补充光影描述（光源、色温、强度）
- 优化色彩方案（色调、饱和度、对比度）
- 增加技术参数（分辨率、风格、质量）

**第三步：结构化输出**
按照标准模板组织提示词，确保完整性和可读性

### 优化原则

**具体性原则**
- ❌ 模糊："美丽的风景"
- ✅ 具体："壮丽的雪山倒映在碧蓝湖水中，阳光穿透云层洒下金色光芒"

**专业性原则**
- ❌ 通俗："好看的光"
- ✅ 专业："侧逆光营造轮廓，暖橙色暖色调，黄金时刻光线"

**完整性原则**
- 主体 + 细节 + 环境 + 构图 + 光影 + 风格 + 技术参数

**平衡性原则**
- 具体但不过度约束，留出创作空间
- 专业但不晦涩，保持可理解性
- 丰富但不冗余，突出重点

## 提示词结构模板

### 基础结构模板
```
[主体描述] <人物/物体> + <外观特征> + <动作/姿态>
[场景细节] <表情/细节> + <材质/纹理> + <互动元素>
[环境设定] <场景类型> + <背景> + <道具/装饰>
[构图光影] <景别> + <角度> + <构图法则> + <光源> + <色调>
[风格参数] <艺术风格> + <渲染质量> + <技术参数>
```

### 详细要素说明

#### [主体描述]
**人物**
- 基础信息：年龄、性别、种族
- 外貌特征：发型、眼睛、身材
- 服装：类型、颜色、材质、细节
- 表情：微笑、严肃、忧郁、惊讶
- 姿态：站立、坐着、运动中

**物体**
- 基本属性：类型、形状、大小
- 材质：金属、木头、玻璃、布料
- 颜色：主色、辅色、渐变
- 纹理：光滑、粗糙、光泽

**动作状态**
- 静态：站立、坐着、躺着
- 冻结瞬间：跳跃、奔跑、投掷
- 微动作：手部动作、眼神方向

#### [场景细节]
**表情细节**
- 眼神：直视、斜视、目光游移
- 嘴巴：微笑、微张、紧闭
- 眉毛：上扬、皱眉、舒展

**材质纹理**
- 皮肤：光滑、皱纹、斑点
- 服装：丝绸、棉质、皮革
- 物体：金属反光、木纹、玻璃透明

**互动元素**
- 与其他物体的关系
- 与环境的互动
- 光影的影响

#### [环境设定]
**场景类型**
- 自然场景：山川、森林、海洋、沙漠
- 城市场景：街道、建筑、室内、广场
- 特殊场景：科幻、奇幻、抽象

**背景元素**
- 天空：云层、星星、极光
- 远景：山脉、城市天际线、大海
- 中景：建筑、树木、车辆

**道具装饰**
- 实用道具：家具、工具、日用品
- 装饰元素：花卉、画作、灯光
- 氛围道具：烟雾、雨滴、雪花

#### [构图光影]
**景别**
- 特写（Close-up）：面部或局部
- 近景（Medium Close-up）：胸部以上
- 中景（Medium Shot）：腰部以上
- 全景（Full Shot）：全身
- 远景（Long Shot）：广阔环境

**拍摄角度**
- 平视（Eye level）：自然视角
- 俯视（High angle）：俯瞰、压迫感
- 仰视（Low angle）：仰视、宏伟感

**构图法则**
- 三分法（Rule of Thirds）：主体在交叉点
- 对称（Symmetrical）：中心对称
- 引导线（Leading Lines）：线条引导视线
- 负空间（Negative Space）：留白突出主体

**光源类型**
- 顺光（Front Light）：正面光线
- 侧光（Side Light）：侧面光线，立体感
- 逆光（Back Light）：背面光线，剪影
- 顶光（Top Light）：顶部光线
- 黄金时刻（Golden Hour）：日出日落暖光

**色调方案**
- 暖色调（Warm）：红橙黄色系
- 冷色调（Cool）：蓝绿紫色系
- 对比色（Contrast）：互补色搭配
- 单色调（Monochromatic）：单一色系

#### [风格参数]
**艺术风格**
- 写实（Photorealistic）：照片级真实
- 电影感（Cinematic）：电影画面质感
- 油画（Oil Painting）：油画质感
- 水彩（Watercolor）：水彩风格
- 插画（Illustration）：插画风格
- 动漫（Anime）：动漫风格

**渲染质量**
- 8K：超高分辨率
- 4K：高分辨率
- 超细节（Ultra detailed）：精细细节
- 高质量（High quality）：高质量
- 照片级真实（Photorealistic）：照片质感

**技术参数**
- 宽高比：16:9、4:3、1:1、9:16
- 色彩饱和度：高、中、低
- 对比度：高对比、低对比

## 常见场景优化

### 场景 1：人物肖像
**用户描述**："一个女孩微笑"

**优化后**：
```
[主体描述] 20岁亚洲女孩，长发微卷，穿着白色T恤，面带温暖微笑，眼神明亮
[场景细节] 肤色自然，眼神柔和，嘴角微微上扬，头发有自然光泽
[环境设定] 室内，背景虚化，简洁
[构图光影] 特写，平视角度，居中构图，柔和正面光，暖色调
[风格参数] 照片级真实，8K分辨率，背景虚化，人像模式
```

### 场景 2：自然风光
**用户描述**："美丽的山和湖"

**优化后**：
```
[主体描述] 壮丽的雪山，山峰覆盖皑皑白雪，山体呈灰蓝色
[场景细节] 山石纹理清晰，雪层有层次感，山顶云雾缭绕
[环境设定] 雪山脚下是碧蓝的湖面，湖水清澈见底，岸边绿草如茵
[构图光影] 远景，低角度拍摄，三分法构图，阳光穿透云层，冷蓝色和金色对比
[风格参数] 电影感，8K分辨率，超高细节，光线追踪
```

### 场景 3：城市夜景
**用户描述**："晚上的城市"

**优化后**：
```
[主体描述] 繁华的都市街道，高楼大厦林立，霓虹灯闪烁
[场景细节] 玻璃幕墙反射灯光，街道上行人匆匆，车流如织，红绿灯交替
[环境设定] 夜晚的城市，远处有摩天大楼剪影，天空深蓝
[构图光影] 远景，俯视角度，引导线构图，霓虹灯光源，高对比度，冷蓝色和彩色对比
[风格参数] 电影感，4K分辨率，夜景模式，光线追踪
```

### 场景 4：科幻场景
**用户描述**："未来的机器人"

**优化后**：
```
[主体描述] 高科技风格的机器人，金属外壳泛着蓝光，体型修长，有人类面部特征
[场景细节] 金属纹理清晰，关节连接精密，眼睛发出蓝色光芒，有机械细节
[环境设定] 未来城市的天台，背景是霓虹闪烁的摩天大楼，天空中有飞行器
[构图光影] 中景，仰视角度，对称构图，蓝色霓虹灯光，冷色调，高对比度
[风格参数] 科幻风格，8K分辨率，光线追踪，超细节
```

### 场景 5：古风场景
**用户描述**："古代的宫殿"

**优化后**：
```
[主体描述] 宏伟的古代宫殿，红色宫墙，金色琉璃瓦，飞檐斗拱，雕梁画栋
[场景细节] 建筑细节精美，木质纹理清晰，雕刻细致，宫灯高高挂起
[环境设定] 宫殿广场，地面铺着青石板，远处有连绵的宫殿群
[构图光影] 远景，仰视角度，对称构图，午后阳光，暖色调，红色和金色对比
[风格参数] 电影感，8K分辨率，超高细节，历史感
```

### 场景 6：动漫风格
**用户描述**："动漫里的女孩"

**优化后**：
```
[主体描述] 18岁动漫少女，粉色长发，大眼睛，穿着校服，表情可爱
[场景细节] 眼睛明亮有光泽，头发柔顺飘逸，有动漫特有的光影效果
[环境设定] 动漫风格的教室背景，有窗户和黑板，阳光透过窗户
[构图光影] 近景，平视角度，居中构图，柔和光线，明亮色调
[风格参数] 动漫风格，2D手绘感，清新可爱，色彩鲜艳
```

### 场景 7：静物摄影
**用户描述**："咖啡和书"

**优化后**：
```
[主体描述] 一杯热咖啡放在木质桌上，旁边有一本打开的书，书页有折痕
[场景细节] 咖啡杯上有精美花纹，咖啡冒着热气，书本文字清晰，有书签
[环境设定] 温馨的室内，背景虚化，有暖黄色的灯光
[构图光影] 特写，45度俯视角度，三分法构图，侧逆光营造轮廓，暖色调
[风格参数] 照片级真实，4K分辨率，静物摄影风格，柔和光线
```

### 场景 8：抽象艺术
**用户描述**："流动的色彩"

**优化后**：
```
[主体描述] 抽象的流动色彩，多种颜色交织融合，形成有机形态
[场景细节] 色彩渐变自然，有流动感和深度，像液体一样蔓延
[环境设定] 纯色背景，突出色彩主体
[构图光影] 全景，俯视角度，自由构图，柔和光线，高饱和度
[风格参数] 抽象艺术风格，超现实主义，色彩丰富，艺术感
```

## 专业术语转换

### 描述 → 专业术语对照表

| 通俗描述 | 专业术语 | 示例 |
|---------|---------|------|
| 漂亮 | 美丽、精致、优雅 | Beautiful, elegant |
| 好看 | 精美、有魅力 | Attractive, charming |
| 真实 | 照片级真实、写实 | Photorealistic, realistic |
| 漂亮的光 | 柔和光线、侧光、逆光 | Soft lighting, side light, back light |
| 黄色的光 | 暖色调、黄金时刻 | Warm tones, golden hour |
| 蓝色的光 | 冷色调、冷光 | Cool tones, cold light |
| 清楚 | 清晰、细节丰富 | Sharp, detailed |
| 大 | 宏伟、壮观 | Majestic, magnificent |
| 小 | 精致、细致 | Delicate, detailed |
| 模糊 | 梦幻、柔和、虚化 | Dreamy, soft, blurred |
| 亮 | 明亮、通透 | Bright, luminous |
| 暗 | 昏暗、神秘 | Dim, mysterious |
| 彩色 | 多彩、鲜艳 | Colorful, vibrant |
| 黑白 | 黑白、单色 | Black and white, monochrome |

### 常用形容词优化

**形容美丽**
- 美丽 → 壮丽、精致、优雅、迷人
- 漂亮 → 美观、俊俏、秀丽

**形容光线**
- 明亮 → 璀璨、熠熠生辉、金光闪闪
- 柔和 → 温馨、朦胧、柔和

**形容色彩**
- 彩色 → 多彩斑斓、绚丽多彩、五彩缤纷
- 红色 → 绯红、猩红、绯色

**形容质感**
- 光滑 → 光泽、润泽、柔滑
- 粗糙 → 粗砺、斑驳、纹理清晰

### 质量提升技巧

**增加细节**
- 使用形容词增加描述丰富度
- 添加材质和纹理信息
- 说明光影的具体效果

**增强专业度**
- 使用专业摄影术语
- 引用构图法则
- 明确技术参数

**提升艺术性**
- 加入艺术风格描述
- 营造情感氛围
- 强调视觉冲击力
