## 角色形象格式

```
角色名称：[角色名称]
外貌：[基于文本描述或合理推断]
职业/身份：[在故事中的角色定位]
性格：[基于行为、语言、心理活动分析]
角色小传：
[背景、动机、关键事件、与主线的关系]
```

**示例**：
```
角色名称：沈晚瑜
外貌：青年女性，低垂顺从的黑色杏眼，乌黑长发梳成温婉的随云髻
职业/身份：侯府少夫人、神秘系统宿主
性格：表面胆小怯懦、唯唯诺诺，实则拥有致命的"因果律"能力；自称心善怕事，内心活动冷静且带有黑色幽默
角色小传：
她在娘家时如履薄冰，唯恐被人发现身上绑定了"假话成真系统"。这并非主动攻击的能力，而是当他人对她撒谎或她顺从谎言时，谎言便会成为现实。曾经，庶妹骗走暖玉导致自身终身不孕，庶弟毒狗撒谎导致自身智力退化。如今新婚嫁入侯府，面对夫君陆砚礼谎称"战场受伤不举"的借口，系统的力量再次发动，将其谎言变为惨痛的现实。
```

```

```


## Sora分镜提示词格式

```json
[
  {
    "分镜序号": 1,
    "sora提示词": "角色:角色信息\n【0-3秒】\n镜头:【景别+运镜】画面描述\n音效/音乐:音效描述\n情绪/氛围:情绪基调\n旁白/对话:台词或内心独白\n\n【3-7秒】\n...\n\n【7-10秒】\n..."
  }
]
```

**示例**：
```json
{
  "分镜序号": 1,
  "sora提示词": "角色:沈晚瑜(身穿正红色繁复嫁衣,头戴金钗,面容清秀,眼神显得怯懦畏缩),陆砚礼(身穿大红婚服,面容俊朗但透着一丝虚伪的无奈)\n【0-3秒】\n镜头:【中景固定】婚房内红烛高照,喜字贴在床头。陆砚礼坐在喜床上,眉头紧锁,装出一副愧疚难当的模样,双手虚握住沈晚瑜的手,眼神却在闪烁躲避。\n音效/音乐:窗外微风吹动树叶的沙沙声+屋内红烛爆灯芯的\"噼啪\"声+陆砚礼深情却虚假的叹息声。\n情绪/氛围:表面温情,实则虚伪压抑。\n旁白/对话:陆砚礼(故作悲痛):\"晚瑜,我在战场上伤了命根子,嫁给我当真是委屈你了……除了孩子,我会给你我能给的一切。\"\n\n【3-7秒】\n镜头:【特写推进】镜头快速推进到沈晚瑜的脸部特写,她本是低眉顺眼地听着,突然瞳孔猛地放大,眼神中充满了震惊和不可思议。此时,在她视角的虚空中(画面上方)浮现出一行发光的半透明系统文字:【嘀!小侯爷陆砚礼的命根子已毁。】\n音效/音乐:系统提示音\"嘀——\"的一声(清脆、电子音,与古风环境形成反差)+沈晚瑜倒吸一口凉气的呼吸声。\n情绪/氛围:荒诞、错愕、突如其来的转折。\n旁白/对话:系统音:【嘀!小侯爷陆砚礼的命根子已毁。】\n\n【7-10秒】\n镜头:【中景拉远】沈晚瑜下意识地后退半步,眼神惊恐地看向陆砚礼的下半身,双手紧紧绞着手中的喜帕。陆砚礼原本装模作样的表情凝固在脸上,似乎感觉到了一股莫名的寒意袭来。\n音效/音乐:背景音乐突然静止,只剩下尴尬的寂静。\n情绪/氛围:诡异的宁静,暴风雨前的宁静。\n旁白/对话:沈晚瑜(内心独白,声音颤抖):\"小侯爷……玩这么大?\""
}
```

## 场景提示词格式

```
场景 N：[场景名称] - [场景副标题]
画面描述：[画面描述]
绘图指令：[绘图指令]
```

**示例**：
```
场景 1：侯府婚房 - 谎言成真之地
画面描述： 展现大婚当夜极度喜庆却又诡异的氛围。满屋的大红绸缎与"囍"字，由于陆砚礼的剧痛挣扎，桌上的合卺酒杯翻倒，床铺凌乱，龙凤烛火在风中摇曳，投射出狰狞的长影。
绘图指令: Interior of a luxurious ancient Chinese wedding chamber, empty. Saturated red silk curtains and "Double Happiness" banners. Flickering dragon-and-phoenix candles casting long, dancing shadows. On the rosewood table, an overturned wine cup and scattered red dates. A large ornate canopy bed with messy red silk bedding. The atmosphere is festive yet suffocating and eerie. Cinematic lighting, 8k, hyper-realistic. --ar 16:9 --v 6.0
```
