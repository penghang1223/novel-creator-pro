## 多样性验证

### 景别多样性

**检查规则**：
- 至少包含远景、全景、中景、近景、特写5种景别
- 相邻镜头不能使用相同景别
- 特写后不要立即用特写，先用中景或近景过渡

**示例对比**：

| 错误示例 | 正确示例 |
|---------|---------|
| 中景 → 中景 → 中景 | 中景 → 近景 → 特写 → 中景 → 全景 |

### 运镜多样性

**检查规则**：
- 至少包含固定、推进、拉远、摇镜、切镜5种运镜
- 不能所有镜头都是固定镜头
- 同一种运镜方式不要连续使用超过3次

**示例对比**：

| 错误示例 | 正确示例 |
|---------|---------|
| 固定 → 固定 → 固定 | 固定 → 推进 → 摇镜 → 晃动 → 拉远 |

### 时长多样性

**检查规则**：
- 时长1-3秒，不重复
- 重要内容时长稍长（2-3秒）
- 快节奏场景时长较短（1-1.5秒）
- 转场镜头适中（2秒）

**示例对比**：

| 错误示例 | 正确示例 |
|---------|---------|
| 1s → 1s → 1s → 1s | 2s → 1.5s → 3s → 1s → 2s |

## 逻辑一致性检查

### 角色一致性

**检查项**：
- 角色外貌在不同分镜中保持一致
- 角色行为符合性格设定
- 角色位置变化合理

### 场景一致性

**检查项**：
- 场景描述与剧情发展匹配
- 场景切换有逻辑（如通过转场镜头）
- 同一场景的细节保持一致

### 时间段逻辑

**检查项**：
- 同一分镜的3个时间段有逻辑递进
- 时间段之间的画面内容连贯
- 景别和运镜配合时间递进

## 格式规范检查

**检查清单**（8项）：

- [ ] JSON格式正确（Sora分镜）
- [ ] 表格列名完整（分镜提示词）
- [ ] 每个场景包含"画面描述 + 绘图指令"（场景提示词）
- [ ] 每个角色包含"名称、外貌、职业、性格、小传"（角色形象）
- [ ] 时间段标记正确（【0-3秒】【3-7秒】【7-10秒】）
- [ ] 景别和运镜多样化（分镜提示词、Sora分镜）
- [ ] 绘图指令包含强制关键词（empty / no people）
- [ ] 角色形象之间用三个星号（***）分隔

### 标点符号规范

| 内容类型 | 标点符号 | 示例 |
|---------|---------|------|
| 中文内容 | 中文标点（，。：！？"） | 角色：沈晚瑜，性格：胆小怯懦 |
| 英文内容（绘图指令） | 英文标点（,.:!?\"） | Interior of a room, empty. The atmosphere is gloomy. |
| JSON代码块 | 英文标点 + JSON标准格式 | "分镜序号": 1 |
| 字段名称后 | 中文冒号（：） | 角色名称：沈晚瑜 |

## 质量检查报告

### 检查报告示例

```
质量检查报告：
✓ 景别多样性：包含远景、全景、中景、近景、特写、大特写（6种）
✓ 运镜多样性：包含固定、推进、拉远、摇镜、晃动、跟拍（6种）
✓ 时长多样性：1s、1.5s、2s、3s（4种）
✓ 场景无人物：5个场景均包含empty关键词
✓ 时间段完整：6个Sora分镜均包含0-3s、3-7s、7-10s
✓ 格式规范：JSON格式正确，表格列名完整

结果：通过检查，可交付。
```

### 约束清单

| 约束类型 | 检查项 | 违规处理 |
|---------|-------|---------|
| **景别多样性** | 至少包含5种景别 | 重新分配 |
| **运镜多样性** | 至少包含5种运镜 | 重新分配 |
| **时长多样性** | 时长1-3秒，不重复 | 重新调整 |
| **场景无人物** | 绘图指令含empty等关键词 | 重新生成 |
| **时间段完整** | Sora分镜包含3个时间段 | 补全缺失 |
| **依赖关系** | 角色提示词需角色形象 | 提示用户 |
| **格式规范** | 严格按照模板输出 | 重新格式化 |
