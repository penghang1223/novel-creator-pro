# Anime Storyboarder - 新手完全指南

## 📌 这个技能能做什么？

**一句话总结**：把你的故事剧本变成专业的动漫分镜和AI生成提示词

### 核心功能（6大能力）

#### 1. 角色形象生成 📚
**能做什么**：
- 提取剧本中的角色信息
- 生成完整的角色档案（姓名、外貌、性格、背景故事）
- 为角色创建"人物小传"

**示例输出**：
```
角色名称：沈晚瑜
外貌：青年女性，黑色杏眼，乌黑长发，随云髻
性格：表面胆小怯懦，实则拥有"假话成真系统"
小传：当他人撒谎或她顺从谎言时，谎言便会成为现实
```

**什么时候用**：
- 你想了解角色的完整设定
- 需要给动画师或画师提供角色参考
- 想创作角色的背景故事

---

#### 2. 角色提示词生成 🎨
**能做什么**：
- 基于角色形象生成AI绘画提示词
- 适用于 Midjourney、Stable Diffusion 等工具
- 保证角色在不同图片中的一致性

**示例输出**：
```
(masterpiece, best quality:1.2), 1girl, solo, Shen Wanyu,
black hair, traditional Chinese updo, delicate hair accessories,
red wedding dress, intricate embroidery, phoenix pattern,
looking at viewer, gentle expression, slight blush,
soft lighting, shallow depth of field,
simple background, solid color background
--ar 2:3 --v 6.0 --s 250
```

**什么时候用**：
- 你需要用AI生成角色图片
- 想保证多张图片中角色一致
- 需要高质量的绘画提示词

---

#### 3. 场景提示词生成 🏠
**能做什么**：
- 生成场景的中文描述
- 生成AI绘画用的英文提示词（纯环境，不含人物）
- 包含构图、光影、氛围等专业要素

**示例输出**：
```
场景：侯府婚房
画面描述：满屋大红绸缎，龙凤烛火摇曳，投射狰狞长影
绘图指令: Interior of a luxurious ancient Chinese wedding chamber, empty.
Saturated red silk curtains, flickering dragon-and-phoenix candles
casting long shadows. --ar 16:9 --v 6.0
```

**什么时候用**：
- 你需要用AI生成场景背景
- 想创建纯环境场景（不含人物）
- 需要专业的场景描述

**重要提示**：场景提示词必须是"纯环境"，不含人物，这样后期可以合成角色。

---

#### 4. Sora分镜生成 🎬
**能做什么**：
- 为Sora等AI视频生成工具准备分镜
- 每个分镜包含3个时间段（0-3秒、3-7秒、7-10秒）
- 包含景别、运镜、动作、音效等完整信息

**示例输出**：
```json
{
  "分镜1": {
    "0-3秒": "【环境建立】镜头从烛火缓缓拉开，露出沈晚瑜端坐在床沿的剪影",
    "3-7秒": "【动作展开】陆砚礼站在阴影中，沉默良久，终于开口",
    "7-10秒": "【情绪转折】沈晚瑜抬起头，眼中从疑惑变为震惊"
  }
}
```

**什么时候用**：
- 你想用Sora、Runway、Pika等AI视频工具
- 需要专业的视频分镜脚本
- 想让AI生成连贯的视频

---

#### 5. 表格分镜生成 📊
**能做什么**：
- 生成完整的表格化分镜脚本
- 可直接导入Excel、Google Sheets
- 包含镜头编号、景别、运镜、时长、音效等完整信息

**示例输出**：
| 镜头编号 | 景别 | 镜头内容 | 时长 | 运镜 | 音效/台词 |
|---------|------|---------|------|------|----------|
| 1 | 中景 | 沈晚瑜端坐床沿 | 2s | 缓慢推镜 | 烛火噼啪声 |
| 2 | 近景 | 陆砚礼面露难色 | 1.5s | 切镜 | 陆："我在战场上伤了命根子" |
| 3 | 特写 | 虚空浮现发光文字 | 2s | 缓慢推进 | 系统音："嘀——" |

**什么时候用**：
- 你需要给动画团队提供分镜脚本
- 想用表格管理分镜
- 需要可打印或导出的分镜文档

---

#### 6. 提示词优化 ✨
**能做什么**：
- 优化你已有的AI生成提示词
- 将描述性语言转换为专业术语
- 添加构图、光影、色彩、风格等要素

**优化示例**：
```
原始：沈晚瑜，古风美女，穿红色衣服

优化后：
(masterpiece, best quality:1.2), 1girl, solo, Shen Wanyu,
black hair, traditional Chinese updo, red wedding dress,
intricate embroidery, phoenix pattern, gentle expression,
soft lighting, shallow depth of field
--ar 2:3 --v 6.0 --s 250
```

**什么时候用**：
- 你已经有提示词但效果不好
- 想提升AI生成的质量
- 需要更专业的提示词

## 🚀 新手三步上手

### 第一步：准备你的剧本
任何格式都可以：
- 小说片段
- 剧本
- 简单的故事描述
- 对话记录

**示例**：
```
新婚夜，红烛摇曳。
沈晚瑜端坐在床沿，手指紧张地攥着裙摆。
陆砚礼站在桌前，面露难色。
"晚瑜，"他的声音低沉，"我在战场上伤了命根子。"
沈晚瑜猛地抬头，眼中满是震惊。
```

### 第二步：选择你需要的
告诉我你需要什么（可多选）：

| 选项 | 功能 | 推荐场景 |
|------|------|---------|
| 1. 角色形象 | 生成角色档案 | 想了解角色设定 |
| 2. 角色提示词 | 生成AI绘画提示词 | 需要生成角色图 |
| 3. 场景提示词 | 生成场景描述和提示词 | 需要生成场景图 |
| 4. Sora分镜 | 生成AI视频分镜 | 用Sora等工具 |
| 5. 表格分镜 | 生成表格分镜脚本 | 给团队用 |
| 6. 提示词优化 | 优化现有提示词 | 提升AI生成质量 |

**新手推荐组合**：
- 快速预览：1 + 3
- AI绘画：1 + 2 + 3
- AI视频：3 + 4
- 专业制作：全部（1-6）

### 第三步：获取分镜
几分钟后，你就能获得专业级的分镜内容！
