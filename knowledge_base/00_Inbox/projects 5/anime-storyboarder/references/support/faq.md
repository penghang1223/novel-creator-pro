# 常见问题FAQ

## 基础问题

### Q1: 这个Skill是做什么的？
**A**: 将剧本/小说转化为专业动漫分镜，支持：
- 角色形象档案
- AI绘画提示词
- 纯环境场景提示词
- Sora视频分镜
- 完整表格分镜脚本
- 提示词优化服务

### Q2: 需要分镜基础吗？
**A**: 完全不需要。提供剧本，选择内容，等待结果即可。

### Q3: 支持什么类型的故事？
**A**: 所有类型！古装、现代、科幻、悬疑、恐怖、浪漫、喜剧等。

### Q4: 一次可以处理多长的剧本？
**A**: 建议：
- 小说：1-3个章节
- 剧本：5-10个场景
- 短篇：完整故事

长剧本可以分批处理。

## 技术问题

### Q9: 什么是"纯环境场景"？
**A**: 没有人物的场景。为什么要纯环境？
- AI生成人物容易出错
- 保证角色一致性
- 人物可以后期合成

**如何保证？**
- 提示词包含 empty / scenery only / no people
- 严格检查不含任何人或身体部位

详见 [场景生成规范](../specs/scene-specs.md)

### Q10: 什么是"景别"和"运镜"？

**景别**：镜头距离
- 远景：看环境
- 全景：看全身
- 中景：看对话
- 近景：看表情
- 特写：看细节

**运镜**：镜头运动
- 推镜：向前推，强调
- 拉镜：向后拉，揭示
- 摇镜：左右摇，扫视
- 移镜：平行移，跟随
- 跟镜：跟主体，紧张
- 静止：不动，客观

详见 [镜头语言](../guides/camera-language.md)

### Q11: Sora分镜为什么有三个时间段？
**A**: 最佳实践：
- 0-3秒：建立场景
- 3-7秒：主要动作
- 7-10秒：收尾转场

让AI生成更连贯的视频。

### Q12: 生成的提示词可以直接用吗？
**A**: 是的！
- 角色提示词：Midjourney、Stable Diffusion
- 场景提示词：AI绘画工具
- Sora分镜：Sora等AI视频工具

## 进阶技巧

### Q13: 如何让分镜更有电影感？

**小技巧**：
1. **光影设计**：不要均匀照亮，要有明有暗
2. **角度变化**：用低角度（仰拍）或高角度（俯拍）
3. **动静对比**：紧张动作后接静止镜头
4. **前后景**：用前景物体增加深度
5. **色彩情绪**：暖=温馨，冷=孤独

详见 [最佳实践](../guides/best-practices.md)

### Q14: 如何保证角色一致性？

**方法1：先生成角色图**
1. 生成角色形象和提示词
2. 用提示词生成满意的角色图
3. 后续用图生图保持一致性

**方法2：使用LoRA**
1. 用提示词训练LoRA
2. 在所有提示词中加入触发词

### Q15: 分镜太长怎么办？

**策略**：
1. **精简**：去掉不必要细节
2. **合并**：把小动作合并到一个镜头
3. **分批**：分成几个部分
4. **重点突出**：重头戏多镜头，过渡戏快速

### Q16: 可以生成特定风格吗？
**A**: 可以！告诉我你想要的风格：

**美术风格**：新海诚、吉卜力、美式动画、赛博朋克
**时代/地域**：古代中国、现代都市、未来科幻、欧洲中世纪
**Mood**：温馨治愈、紧张悬疑、恐怖诡异、浪漫唯美
