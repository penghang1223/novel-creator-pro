## 快速诊断

### 第一步：确认问题类型

| 问题类型 | 特征 | 参考章节 |
|---------|------|---------|
| 输入问题 | 剧本格式乱、内容不清晰 | 输入问题修复 |
| 输出问题 | 生成内容不符合预期 | 输出问题修复 |
| 格式问题 | 格式不对、缺字段 | 格式问题修复 |
| 内容问题 | 角色不一致、场景有问题 | 内容问题修复 |

### 第二步：收集信息

提供以下信息：
1. **输入**：你给的剧本
2. **选择**：你选择了什么（1-6）
3. **问题**：具体哪里不对
4. **预期**：你希望得到什么
5. **实际**：实际得到了什么

## 常见问题修复

### 问题1：剧本格式混乱

**症状**：
- 没分段
- 格式乱
- 分不清对话和叙述
- 缺标点

**修复**：
1. **分段**：每个动作或对话单独一段
2. **标注**：标注说话人
3. **简化**：给精简版

**示例**：
```
❌ 不好的格式：
新婚夜红烛摇曳沈晚瑜端坐在床沿手指紧张地攥着裙摆陆砚礼站在桌前面露难色晚瑜他的声音低沉我在战场上伤了命根子

✅ 好的格式：
新婚夜，红烛摇曳。

沈晚瑜端坐在床沿，手指紧张地攥着裙摆。

陆砚礼站在桌前，面露难色。

"晚瑜，"他的声音低沉，"我在战场上伤了命根子。"
```

### 问题2：角色不一致

**症状**：
- 角色形象前后矛盾
- 一会儿黑发一会儿金发
- 性格描述混乱

**修复**：
1. **确认原文**：检查是否有矛盾
2. **明确优先级**：告诉我哪些更重要
3. **分步生成**：先生成角色形象，确认后再生成其他

**反馈示例**：
```
你：原文中一会儿说"黑发"，一会儿说"金发"，我希望是黑发

我：好的，我会以黑发为准，重新生成
```

### 问题3：场景提示词中有人物

**症状**：
- 场景提示词出现人物
- 生成的场景图里有人
- 没有empty/scenery only/no people

**修复**：
1. **要求重生成**：告诉"场景提示词里有人，请重新生成"
2. **强调约束**：提醒"必须是纯环境场景"
3. **检查输出**：收到后检查是否符合要求

**预防**：明确要求"场景提示词要纯环境"

详见 [场景生成规范](../specs/scene-specs.md)

### 问题4：景别/运镜重复

**症状**：
- 连续好几个都是"中景"
- 每个镜头都"缓慢推镜"
- 缺乏变化

**修复**：
1. **指出问题**：告诉"景别太单一"或"运镜重复"
2. **要求多样化**：提醒"注意景别和运镜的多样性"
3. **参考模板**：参考 [镜头语言](../guides/camera-language.md)

### 问题5：Sora分镜缺时间段

**症状**：
- 缺少【0-3秒】【3-7秒】【7-10秒】
- 时间段不完整
- 三个时间段混乱

**修复**：
1. **指出缺失**：告诉哪个时间段缺失
2. **要求补充**：让我补充完整
3. **确认格式**：要求严格按照JSON格式

**正确格式**：
```json
{
  "分镜1": {
    "0-3秒": "【环境建立】镜头从烛火缓缓拉开...",
    "3-7秒": "【动作展开】陆砚礼站在阴影中...",
    "7-10秒": "【情绪转折】沈晚瑜抬起头..."
  }
}
```

### 问题6：表格分镜缺列

**症状**：
- 表格缺列
- 列顺序不对
- 格式混乱

**修复**：
1. **指出缺失**：告诉缺哪些列
2. **要求完整**：让我补充完整9列
3. **参考格式**：参考 [输出格式](../specs/output-formats.md)

**正确列顺序**：
| 镜头编号 | 场景 | 景别 | 镜头内容 | 时长 | 运镜 | 音效/台词 | 备注 |

## 自助解决

### 检查清单

**在使用前**：
- [ ] 剧本有正确分段
- [ ] 对话和叙述清晰
- [ ] 关键信息明确

**在请求帮助前**：
- [ ] 我给了清晰的剧本
- [ ] 我明确选择了内容
- [ ] 我查看了相关文档
- [ ] 我尝试了基本修复

### 如何有效描述问题

**不好的描述**：
```
你：生成的不对，重新来
```

**好的描述**：
```
你：问题：场景提示词中出现了人物"沈晚瑜"
预期：场景提示词应该只描述环境，不含任何人
实际："Interior of a wedding chamber, Shen Wanyu sitting..."
请重新生成，确保包含 empty / scenery only / no people
```

### 分步修复策略

**1. 明确问题**
- 具体哪里不对
- 是全部还是部分
- 有没有错误信息

**2. 收集上下文**
- 输入是什么
- 选择了什么
- 生成了什么

**3. 尝试自助修复**
- 参考常见问题
- 查看相关文档
- 要求重新生成

**4. 寻求帮助**
- 提供完整信息
- 清晰描述问题
- 说明尝试了什么

## 何时寻求帮助

### 应该请求帮助

✅ **这些情况请告诉我**：
- 生成内容完全不对
- 出现格式错误
- 角色/场景明显不符合预期
- 不知道如何继续
- 想调整方向

### 提供有效反馈

**反馈模板**：
```
1. 问题概述：[一句话总结]
2. 具体问题：
   - [问题1]
   - [问题2]
3. 我的需求：
   - [如何调整]
   - [预期结果]
4. 附加信息：
   - [其他有用信息]
```

**反馈示例**：
```
1. 问题概述：角色形象和我想的不太一样
2. 具体问题：
   - 外貌说"银发"，但原文是"黑发"
   - 性格描述太简单
3. 我的需求：
   - 把发色改成黑发
   - 性格更详细，参考原文第2段
4. 附加信息：
   - 原文中她是"表面柔弱但内心坚强"
```

## 预防问题的最佳实践

### 1. 提供清晰输入

✅ **好的输入**：
- 有正确分段
- 对话和叙述清晰
- 关键信息明确

❌ **不好的输入**：
- 没分段
- 格式混乱
- 缺关键信息

### 2. 明确需求

✅ **好的方式**：
- "我要1、3、5"
- "我想先看看角色形象"
- "我需要专业的分镜"

❌ **不好的方式**：
- "你看着办"
- "随便"
- "都可以"

### 3. 及时反馈

✅ **好的方式**：
- "这里不对，因为..."
- "我希望是..."
- "能不能调整..."

❌ **不好的方式**：
- "算了，就这样吧"
- "也行"（但其实不满意）
- 沉默
