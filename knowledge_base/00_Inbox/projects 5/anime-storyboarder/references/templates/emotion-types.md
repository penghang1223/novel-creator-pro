## 概述

本文档提供10种情绪类型的详细模板，覆盖各类情绪的分镜需求。

### 情绪类型清单

| 情绪类型 | 典型景别 | 运镜特点 | 音效特点 |
|---------|---------|---------|---------|
| 喜悦 | 中景 → 近景 → 特写 | 缓慢推进、固定镜头 | 轻快、明亮 |
| 悲伤 | 中景 → 近景 → 大特写 | 缓慢推进、固定镜头 | 低沉、压抑 |
| 愤怒 | 中景 → 近景 → 特写 | 快速切镜、推进 | 急促、高亢 |
| 恐惧 | 近景 → 特写 → 中景 | 快速推镜、晃动 | 心跳声、倒吸凉气 |
| 压抑 | 全景 → 中景 → 近景 | 固定镜头、推进 | 佛珠声、压抑呼吸 |
| 温馨 | 中景 → 近景 → 特写 | 缓慢摇镜、推进 | 轻柔、温暖 |
| 荒诞 | 特写 → 近景 → 中景 | 推进、拉远 | 系统提示音、尴尬寂静 |
| 悬疑 | 特写 → 近景 → 中景 | 推进、切镜 | 心跳声、寂静 |
| 孤独 | 中景 → 近景 → 特写 | 固定镜头、推进 | 风声、压抑哭声 |
| 绝望 | 中景 → 近景 → 大特写 | 固定镜头、推进 | 压抑哭声、哀嚎声 |
