## 概览
本文档提供标准的影视剧本格式规范和常用模板，帮助编剧创建专业规范的剧本，确保故事结构完整、节奏合理。

## 标准剧本格式

### 基本格式规范

**场景标题 (Scene Heading)**
```
内景. 客厅 - 日
INT. LIVING ROOM - DAY
```
说明：内景/外景 + 场景地点 + 时间（日/夜/黄昏/黎明）

**动作描述 (Action)**
```
李明坐在沙发上，手中握着一杯咖啡，眼神凝重地看着窗外。
窗外的雨滴拍打着玻璃，映衬着他内心的不安。
```
说明：描述场景中发生的事情，用现在时态，简洁生动

**角色名 (Character)**
```
李明
```
说明：角色名称居中，首字母大写

**对白 (Dialogue)**
```
李明
（轻声）
你知道这意味着什么吗？
```
说明：
- 角色名居中
- 括号内标注语气、动作等舞台提示
- 对白内容在下方

**旁白/画外音 (V.O.)**
```
旁白（V.O.）
有些事情，永远无法忘记。
```
说明：画外音用 (V.O.) 标注

### 格式示例

```
内景. 咖啡馆 - 日

阳光透过落地窗洒进咖啡馆，空气中弥漫着咖啡香气。
李明（30岁，穿休闲西装）坐在角落的桌子旁，不时看向门口。
门铃响起，张芳（28岁，长发，职业装扮）推门进来。

李明
（站起身）
你来了。

张芳
（微笑）
抱歉，路上有点堵。

两人坐下，服务员走过来。

服务员
两位喝点什么？

李明
一杯拿铁，谢谢。

张芳
我也是。

服务员点点头离开。李明看着张芳，欲言又止。

李明
最近还好吗？

张芳
挺好的，你呢？

李明
（苦笑）
老样子。
```

## 场景类型模板

### 开场场景

**目的**：建立时间、地点、氛围，引入主要角色

**模板结构**：
1. 场景描述（环境+时间+氛围）
2. 主角出场（外貌+动作+状态）
3. 暗示故事主题或冲突

**示例**：
```
外景. 城市街道 - 夜

霓虹灯闪烁，繁华的都市夜晚。车流如织，行人匆匆。
一个穿着风衣的男人（35岁，陈宇）独自走在街上，手里提着一个黑色公文包。
他停下脚步，抬头看了一眼对面的高楼，神色凝重。
一阵冷风吹过，他裹紧了风衣，加快了脚步。
```

### 对话场景

**目的**：推动剧情发展，展现人物关系，传达信息

**模板结构**：
1. 场景设定（地点+环境）
2. 人物位置和状态
3. 对话交流（潜台词和冲突）
4. 结束方式（解决矛盾或埋下伏笔）

**示例**：
```
内景. 办公室 - 日

宽敞明亮的办公室，落地窗外是城市天际线。
王总（50岁，戴眼镜，严肃）坐在办公桌后翻看文件。
刘明（30岁，略显紧张）站在桌子对面。

王总
（合上文件）
这个项目你负责多久了？

刘明
三个月。

王总
三个月，没有任何进展。

刘明
（低头）
我们在努力...

王总
努力是不够的。我们需要结果。

刘明
（抬起头）
给我一周时间。

王总
（盯着他）
一周。如果还是这样...

刘明
我知道。

王总点点头，重新打开文件。刘明转身离开。
```

### 动作场景

**目的**：展现激烈冲突，推动剧情高潮

**模板结构**：
1. 场景设定（环境+条件）
2. 动作开始（触发事件）
3. 冲突升级（对抗过程）
4. 高潮与结局（胜败与后果）

**示例**：
```
外景. 废弃工厂 - 夜

黑暗的工厂车间，只有月光透过破碎的窗户照进来。
陈宇手持手电筒，小心翼翼地前进。
突然，一个黑影从阴影中跳出，挥刀砍向陈宇。

陈宇
（闪避）
你是谁！

黑影不回答，继续攻击。
陈宇闪身躲过，反手挥拳。
两人扭打在一起，拳脚相加。

黑影
（喘息）
交出来！

陈宇
什么？

黑影
你知道我说的什么！

两人搏斗，陈宇渐落下风。
陈宇看到旁边的铁管，冲过去抓起铁管。
黑影后退一步，警惕地盯着陈宇。

陈宇
（举着铁管）
告诉我你想要什么！

黑影冷笑一声，转身逃离。
陈宇追了几步，但黑影已经消失在黑暗中。
```

### 情感场景

**目的**：展现人物内心，深化角色形象

**模板结构**：
1. 场景氛围（环境烘托）
2. 人物状态（动作+表情）
3. 内心活动（通过动作或独白展现）
4. 情感转变（触发和结果）

**示例**：
```
内景. 卧室 - 夜

昏暗的卧室，只有床头灯亮着柔和的光。
林晓雨（25岁，长发，美丽但疲惫）坐在床边，看着床头柜上的相框。
相框里是她和母亲的合影。

林晓雨
（轻声）
妈妈，我想你。

她拿起相框，手指轻轻抚摸照片中母亲的脸。
泪水从眼角滑落，滴在相框上。
她放下相框，躺回床上，拉起被子盖住头。

（画外音）
有些离别，是无法接受的现实。

被子下传来啜泣声。
```

### 悬疑场景

**目的**：制造悬念，引发观众好奇心

**模板结构**：
1. 神秘氛围（环境+光线）
2. 异常现象（不寻常的事物）
3. 线索揭示（部分信息）
4. 留下疑问（不完全解答）

**示例**：
```
内景. 古老图书馆 - 夜

古老的图书馆，书架高耸入云。蜡烛的微光照亮了角落。
李文（28岁，戴眼镜，文质彬彬）在一本旧书中翻找。
突然，一张纸片从书中滑落。

李文
（捡起纸片）
这是什么？

纸片上是一张泛黄的照片，照片中是一个他从未见过的老人。
照片背面写着一行字："真相在地下室"。

李文皱眉，环顾四周。
空无一人的图书馆显得格外安静。
他合上书，看向通往地下室的门。
门半开着，里面漆黑一片。

李文
（犹豫）
真的要去吗？

他深吸一口气，走向地下室。
门在他身后慢慢关闭，黑暗吞噬了他的身影。
```

### 过渡场景

**目的**：连接不同场景，转换时空

**模板结构**：
1. 前场景收尾（简要结束）
2. 过渡元素（转场设计）
3. 新场景开始（引入新地点）

**示例**：
```
内景. 会议室 - 日

王总说完最后一句话，宣布会议结束。
众人起身离开会议室。

（切至）

外景. 公园 - 黄昏

夕阳西下，公园里散步的人渐渐多了起来。
李明坐在长椅上，看着不远处玩耍的孩子。
他的手机响了，是张芳的短信。
```

## 常见结构模板

### 三幕式结构

**第一幕：铺垫（Setup）**
- 建立世界观和角色
- 触发事件（Inciting Incident）
- 主角决定行动

**第二幕：冲突（Confrontation）**
- 障碍和挑战
- 角色成长和变化
- 中点转折（Midpoint）
- 全部失去（All is Lost）

**第三幕：结局（Resolution）**
- 高潮
- 解决问题
- 新平衡建立

### 英雄之旅模板

**1. 平凡世界**（Ordinary World）
主角的日常生活

**2. 冒险召唤**（Call to Adventure）
触发事件

**3. 拒绝召唤**（Refusal of Call）
主角犹豫

**4. 遇见导师**（Meeting the Mentor）
获得指导

**5. 跨越门槛**（Crossing the Threshold）
离开舒适区

**6. 试炼、盟友、敌人**（Tests, Allies, Enemies）
面对挑战

**7. 接近洞穴**（Approach to the Inmost Cave）
准备最终挑战

**8. 苦难煎熬**（The Ordeal）
最大挑战

**9. 奖赏**（Reward）
获得力量

**10. 返回之路**（The Road Back）
回去面对敌人

**11. 复活**（Resurrection）
最终考验

**12. 归来**（Return with the Elixir）
带着经验回归

### 悬疑片结构

**1. 建立神秘**
- 发现异常事件
- 提出疑问

**2. 调查过程**
- 收集线索
- 遇到阻碍

**3. 转折点**
- 线索指向错误方向
- 主角陷入困境

**4. 揭露真相**
- 关键线索出现
- 拼凑完整信息

**5. 高潮对决**
- 与反派对抗
- 危机解除

**6. 结尾**
- 真相大白
- 新的平静

### 爱情片结构

**1. 相遇**
- 男女主角相遇
- 产生初步印象

**2. 了解**
- 互相接触
- 发现对方优点

**3. 亲近**
- 感情升温
- 确立关系

**4. 冲突**
- 出现问题
- 关系破裂

**5. 改变**
- 自我反思
- 成长变化

**6. 重逢**
- 解决问题
- 重新在一起

## 创作技巧与要点

### 人物塑造

**核心要素**
- 目标（Goal）：想要什么
- 障碍（Obstacle）：什么阻碍了他
- 成长（Change）：经历了什么改变

**角色类型**
- 主角（Protagonist）：故事中心
- 反派（Antagonist）：对抗主角
- 配角（Supporting）：辅助主角
- 导师（Mentor）：引导主角

**人物小技巧**
- 给每个人物独特的说话方式
- 通过动作展现性格，而非直接描述
- 每个角色都要有动机
- 人物要有缺点和矛盾

### 对白写作

**基本原则**
- 对白要推动剧情
- 展现人物关系
- 传达潜台词（言外之意）
- 简洁有力，避免废话

**对白技巧**
- 使用省略和暗示
- 每个角色的说话风格不同
- 动作描述辅助对白
- 避免过于直白的表达

**示例对比**
```
❌ 直白表达：
李明：我很生气。

✅ 通过动作：
李明重重地放下杯子，拳头紧握。
李明：我没事。

✅ 潜台词：
张芳：你最近是不是很忙？

（潜台词：你为什么总是躲着我？）

李明：嗯，项目比较多。

（潜台词：我不想解释。）
```

### 场景节奏

**节奏控制**
- 快节奏：动作场面、紧张情节
- 中节奏：正常叙事、对话
- 慢节奏：情感戏、沉思时刻

**转场技巧**
- 切至（CUT TO）：直接切换
- 溶（DISSOLVE TO）：时间流逝
- 划（WIPE TO）：时间或地点转换
- 音效转场（SOUND BRIDGE）：声音连接

### 悬念设计

**常用技巧**
- 信息不完全（保留关键信息）
- 时间限制（倒计时）
- 反转（意想不到的转折）
- 铺垫（早期埋下线索）

**示例**
```
铺垫：电影开头主角收到了一个神秘包裹。
悬念：里面是什么？
发展：主角多次想打开，但被阻止。
高潮：最终打开，里面是关键证据。
```

### 情感表达

**展示而非讲述（Show, Don't Tell）**
- ❌ 告诉：他很伤心
- ✅ 展示：他低下头，眼眶红了，强忍着泪水

**环境烘托**
- 悲伤场景：雨、黄昏、阴天
- 欢快场景：阳光、花朵、音乐
- 紧张场景：黑暗、狭窄、寂静

**动作传达**
- 紧张：抖动、来回踱步、咬手指
- 快乐：跳跃、拥抱、微笑
- 愤怒：握拳、瞪眼、砸东西

### 常见错误与纠正

**错误 1：对白过多**
- 症状：大段文字，没有动作
- 纠正：拆分成对话和动作交替

**错误 2：描述过于详细**
- 症状：详细的服装、环境描写
- 纠正：只保留关键信息，给导演留空间

**错误 3：没有冲突**
- 症状：一切顺利，没有矛盾
- 纠正：每个场景都要有目标或障碍

**错误 4：节奏单调**
- 症状：全是快节奏或慢节奏
- 纠正：节奏交替，张弛有度

**错误 5：人物扁平**
- 症状：角色性格单一，没有变化
- 纠正：给人物矛盾和成长空间
