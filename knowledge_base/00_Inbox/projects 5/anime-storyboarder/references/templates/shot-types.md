## 概述

本文档提供12种分镜类型的详细模板，覆盖各类场景的分镜需求。

### 分镜类型清单

| 分镜类型 | 使用场景 | 典型景别组合 |
|---------|---------|-------------|
| 开场镜头 | 故事开始、场景交代 | 远景 → 中景 → 近景 |
| 对话镜头 | 人物对话、互动 | 中景 → 近景 → 特写 |
| 动作镜头 | 突发动作、追逐 | 近景突发 → 中景晃动 → 特写 |
| 情绪镜头 | 情绪表达、内心活动 | 中景 → 近景 → 特写 |
| 回忆镜头 | 回忆、闪回 | 中景（带滤镜）→ 特写 |
| 悬念镜头 | 悬念营造、神秘氛围 | 特写 → 近景 → 中景 |
| 冲突镜头 | 冲突、矛盾 | 快速切镜 → 中景 → 全景 |
| 转场镜头 | 场景转换、时间流逝 | 全景 → 中景 → 拉镜 |
| 独白镜头 | 内心独白、心理活动 | 近景 → 特写 → 中景 |
| 细节镜头 | 细节强调、重要道具 | 大特写 → 大特写 → 大特写 |
| 群戏镜头 | 多人场景、群体互动 | 全景 → 中景 → 近景 |
| 结尾镜头 | 故事结束、留余韵 | 中景 → 近景 → 远景拉升 |
