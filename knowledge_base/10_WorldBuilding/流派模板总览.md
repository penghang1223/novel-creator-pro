# 流派模板总览

> 立项时根据题材选择对应模板。大纲结构+人物原型+冲突模式+成功案例参考。

---

## 都市现实主义

**适用场景**：职场内卷、家庭矛盾、相亲催婚、社会不公、边缘人群

**核心元素**：
- 日常场景的真实还原（办公室/家庭/街头）
- 社会痛点直击（PUA/甩锅/道德绑架）
- 情绪过敏/感知异常等轻奇幻设定
- 人际关系修复/觉醒成长

**人物原型**：
- 主角：社恐+讨好型人格→觉醒者/发疯者
- 配角：老刘（老油条）、陈阿姨（扫地僧）、赵明远（引路人）
- 对手：李总（强势方）、妈妈（亲情绑架）

**冲突模式**：
- 职场线：PUA、甩锅、模糊否定
- 家庭线：催婚、亲情绑架、控制欲
- 社会线：路人不公、陌生人际关系
- 自我线：自我怀疑、认知重建

**大纲结构**：
1. 触发：主角确诊/觉醒，发现"感知不合理"的能力
2. 职场修复：李总→老刘→小周→王可可
3. 家庭修复：妈妈→相亲→亲情关系
4. 社会线：路人→物业→更广泛社会关系
5. 真相线：轻奇幻悬念揭晓（过敏症是什么）

**对标案例**：《我在修仙界开网约车》《破事精英》

## 玄幻/仙侠

**核心元素**：
- 等级体系：练气→筑基→金丹→元婴→化神→飞升
- 功法宝物：功法、法宝、丹药、阵法
- 宗门势力：宗门、家族、圣地、魔域

**人物原型**：
- 主角：穿越者/重生者/废柴逆袭/神秘传承
- 反派：宗门长老、世家少爷、魔道大能
- 配角：忠心伙伴、神秘老者、红颜知己

**大纲结构**：
1. 新手村：主角觉醒金手指，初步修炼
2. 宗门篇：加入宗门，内部竞争，初露锋芒
3. 大赛篇：参加大赛，一举成名，获得机缘
4. 异界篇：前往更高境界，更广阔的天地
5. 飞升篇：最终对决，飞升成仙

**成功案例**：《凡人修仙传》《遮天》《完美世界》

## 现言甜宠

**核心元素**：
- 男女主设定：身份、性格、相遇方式
- 情感升温：暧昧、表白、甜蜜相处
- 情感波折：误会、前任、家庭反对
- 圆满结局：误会消除，携手一生

**大纲结构**：
1. 相遇：意外相遇，印象深刻
2. 暧昧：频繁接触，情感升温
3. 表白：感情爆发，确定关系
4. 甜蜜：甜蜜相处，情比金坚
5. 波折：误会冲突，感情受挫
6. 和好：误会消除，圆满结局

**成功案例**：《微微一笑很倾城》《你是我的荣耀》

---

## 古言权谋

**核心元素**：
- 朝堂势力：皇帝、后妃、权臣、世家
- 宫廷斗争：夺嫡之争、后宫争斗
- 江湖势力：武林门派、江湖恩怨
- 情感纠葛：政治联姻，真情假意

**大纲结构**：
1. 初入朝堂：女主入宫，初识男主
2. 权力博弈：朝堂斗争，权谋对决
3. 情感升温：相处加深，暗生情愫
4. 危机爆发：权力危机，感情受挫
5. 终极对决：最终对决，胜负已分
6. 圆满结局：携手一生，共享江山

**成功案例**：《琅琊榜》《甄嬛传》

## 系统文

**核心元素**：
- 系统设定：系统类型、功能机制、任务系统
- 奖励机制：奖励类型、奖励强度、奖励获取
- 升级体系：等级划分、实力提升
- 打脸爽点：逆袭打脸、装逼打脸

**大纲结构**：
1. 开局：主角绑定系统，获得新手奖励
2. 新手任务：完成新手任务，初步变强
3. 第一次打脸：被轻视，通过系统逆袭
4. 地图升级：前往更高层次，遇到更强敌人
5. 系统升级：系统功能增强，获得更强能力
6. 最终目标：完成最终任务，达成终极目标

**成功案例**：《超级神基因》《开局签到荒古圣体》

## 穿越重生

**核心元素**：
- 穿越方式：意外穿越、系统穿越、重生回到过去
- 身份转变：从现代人到古代人，从弱者到强者
- 预知未来：知道未来走向，提前布局
- 改变命运：改变原本的命运轨迹

**大纲结构**：
1. 穿越/重生：主角穿越或重生到新身份
2. 初步改变：利用优势，初步改变命运
3. 遭遇阻碍：遇到阻碍，必须应对
4. 力量积累：积累力量，为后续做准备
5. 重大转折：面临重大转折，必须做出选择
6. 改变结局：彻底改变原本的命运结局

**成功案例**：《庆余年》《知否知否》《重生之将门毒后》

## 都市异能

**核心元素**：
- 异能设定：异能类型、异能等级、异能觉醒
- 现代背景：都市生活、现代社会
- 隐藏世界：异能者组织、神秘势力
- 升级体系：异能修炼、等级提升

**大纲结构**：
1. 觉醒：主角觉醒异能，初步了解异能世界
2. 初战：第一次使用异能战斗，获得胜利
3. 加入组织：加入异能者组织，接受任务
4. 强敌出现：遇到强大敌人，必须应对
5. 力量提升：通过修炼和战斗，提升实力
6. 最终对决：与最终敌人对决，守护世界

**成功案例**：《都市修仙》《第一序列》

## 无限流

**核心元素**：
- 主神空间：穿越到主神空间，接受任务
- 副本世界：穿越到不同的副本世界，完成任务
- 任务系统：主神发布的任务，必须完成
- 生存挑战：在副本世界中生存，完成挑战

**大纲结构**：
1. 进入主神空间：主角进入主神空间，了解规则
2. 第一个副本：进入第一个副本世界，完成任务
3. 团队组建：组建团队，合作完成任务
4. 多个副本：进入多个副本世界，完成各种任务
5. 最终副本：进入最终副本，完成终极任务
6. 回归现实：完成所有任务，回归现实

**成功案例**：《无限恐怖》《惊悚乐园》

---

## 快穿攻略

**核心元素**：
- 快穿系统：快穿系统、任务系统、积分奖励
- 多个世界：穿越到不同的世界，完成不同任务
- 攻略目标：每个世界的攻略目标
- 情感成长：主角在任务中逐渐成长

**大纲结构**：
1. 绑定系统：主角绑定快穿系统，开始任务
2. 第一个世界：穿越到第一个世界，完成任务
3. 第二个世界：穿越到第二个世界，完成任务
4. 多个世界：穿越到多个世界，完成各种任务
5. 最终世界：穿越到最后一个世界，完成终极任务
6. 任务完成：完成所有任务，达成最终目标

**成功案例**：《快穿之炮灰女配逆袭记》
