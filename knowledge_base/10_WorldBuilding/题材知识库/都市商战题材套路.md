# 都市商战题材套路

> 投资文/商战文/逆袭文的读者预期和核心套路。直接对标本项目。

---

## 读者预期（番茄平台）

打开一本"都市+投资+系统"小说的读者，预期看到：

1. **快速逆袭** — 不要磨叽，3章内必须有起色
2. **数字爽感** — 资产数字从3万→25万→150万，每次跃升要具体
3. **打脸前公司/前同事** — 都市文最经典的爽点
4. **投人比投公司更赚** — 发现被低估的人才，证明眼光独到
5. **父女线** — 温情线穿插在爽点之间，调节节奏
6. **系统升级** — 能力提升→看到更大世界→更多机会

**读者不会原谅的事**：
- 主角有系统还磨叽3章以上不行动
- 赚到钱不花（数字变大但生活没变化）
- 打脸不彻底（对手跑了/没道歉/没付出代价）
- 连续3章没有爽点

## 核心套路结构

### 套路1：投资发现 → 验证 → 回报

```
发现（系统看到价值）→ 接触（试探/搭话）→ 投入（押上筹码）
→ 等待（紧张期）→ 爆发（回报远超预期）→ 连锁（带来更多机会）
```

**节奏**：发现1章 + 接触1章 + 等待1-2章 + 爆发1章 = 一个完整投资周期（4-5章）

**本项目映射**：
- 发现：Ch11-12（看到许铭远投资价值8.9）
- 接触：Ch13（了解AI工具项目）
- 投入：Ch14（投资15万，占股30%）
- 等待：Ch15-17（认识人脉、找新机会）
- 爆发：Ch20（产品爆发，股份涨到150万）

### 套路2：实力不对等打脸

```
对手以为主角弱 → 主角展示实力 → 对手震惊 → 主角不稀罕/淡定离开
```

**关键**：主角的反应必须**淡定**。越淡定越爽。慌张/炫耀/报复心重→降低爽感。

**本项目映射**：同学会赵天宇炫耀（Ch18-19），林辰微笑不语（Ch19），手机亮了——许铭远产品突破5万用户（Ch19结尾）。

### 套路3：贵人引路 → 跨阶

```
底层主角 → 偶遇大佬/贵人 → 被认可 → 获得进阶资源/人脉 → 进入新圈层
```

**关键**：贵人不是施舍，是**看中主角的某个特质**（眼光/人品/坚持）。

**本项目映射**：老钱（钱万里）看到林辰的投资眼光。

### 套路4：系统升级 = 信息差扩大

```
Lv1能看到基本数据 → Lv2看到曲线 → Lv3看到90天预测 → Lv4看到多条分支
```

每次升级 = 主角比别人多知道一些 → 信息差 = 投资优势 = 赚更多钱。

**关键**：升级必须**立刻用**，不能升级了放着不用。

## 都市商战文常见毒点

| 毒点 | 为什么毒 | 怎么避免 |
|------|----------|----------|
| 主角圣母 | 有系统还不狠→读者恨铁不成钢 | 有底线但不手软 |
| 金融细节太假 | 读者中有真股民/金融人 | 不写具体K线术语，用系统代替分析 |
| 反派太弱 | 打脸没快感 | 反派要有实力，被碾压才爽 |
| 感情线喧宾夺主 | 商战读者是来看赚钱的 | 感情线穿插，不独占整章 |
| 数字膨胀太快 | 3万→1亿不现实 | 设合理的增长曲线（见世界观设定） |
| 只赚钱不花钱 | 数字好看但没有实感 | 每次赚钱后写花钱效果 |

按题材常见场景列出，写细纲/场景卡时参考：

| 场景类型 | 典型地点 | 典型事件 | 常用爽点 |
|----------|----------|----------|----------|
| 职场 | 办公室/会议室 | 被裁/被打压/反杀 | 打脸/逆袭 |
| 投资 | 咖啡馆/出租屋/证券APP | 发现机会/下单/暴赚 | 系统/暴富 |
| 家庭 | 前妻家/出租屋 | 交学费/看女儿 | 团宠/温情 |
| 同学 | 酒店/KTV | 同学会/被嘲讽 | 打脸 |
| 商战 | 会议室/律所 | 谈判/收购/对赌 | 虐渣/逆袭 |
| 生活 | 便利店/超市/街边 | 花钱/改善生活 | 暴富/种田 |
