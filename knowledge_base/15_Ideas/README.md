# 创意方案库

> 按**平台 → 题材**二级目录结构，方便投稿时快速定位。

## 目录结构

```
15_Ideas/
├── 番茄/           # 适合番茄小说的创意
│   ├── 都市/
│   ├── 悬疑/
│   ├── 言情/
│   ├── 历史穿越/
│   └── 其他/
├── 起点/           # 适合起点中文网的创意
├── 知乎盐选/       # 适合知乎盐选的创意
├── 七猫/           # 适合七猫小说的创意（已发布项目优先）
├── 晋江/            # 适合晋江文学城的创意
├── 豆瓣阅读/        # 适合豆瓣阅读的创意
├── 其他/
│   ├── 平台调研/   # 各平台市场调研文件
│   ├── 内部参考/   # 内部策划文件（方向A/B/C等）
│   └── 抖音短剧/   # 短剧创意
```

## 入库规则

1. 新创意 → 先判断**平台**，再判断**题材**，放入对应子目录
2. 不确定平台 → 先放 `其他/平台调研/`，48小时内确认后归位
3. 内部策划文件（方向A/B/C） → 放 `其他/内部参考/`，投稿后移入对应平台目录

## 命名规范

- 完整创意方案：`{一句话书名}_完整小说创意方案_YYYYMMDD.md`
- 策划文档：`{方向标签}_{题材描述}_完整策划_YYYYMMDD.md`
- 平台调研：`{平台名}_{调研类型}_YYYYMMDD.md`
