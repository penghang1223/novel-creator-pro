# 一、平台洞察速览

| 维度 | 结论 | 创意指向 |
|------|------|---------|
| **用户画像** | 30-50岁男性为主，下沉市场 | 接地气、代入感强、生活化设定 |
| **内容偏好** | 爽文、逆袭、打脸、金手指 | 爽点密集、节奏快、金手指明确 |
| **最高优先级** | AI漫剧剧本（S+级5-10万保底+20%分成） | 故事结构需适配分镜脚本 |
| **第二优先级** | 短剧向网文（月上新20-30部） | 强冲突、快节奏、3分钟一爽点 |
| **第三优先级** | 女频古言/现言（爆款增长250%） | 女频赛道增长快，值得布局 |
| **中优先** | 男频历史架空/玄幻（爆款+175%） | 男性基本盘，稳定流量 |
| **中优先级** | 短篇网文（1-3万字） | 漫剧改编效率最高 |

# 二、创意方向方案

## 方向一：《废婿觉醒：我能看见万物价值》

**类型**：男频都市异能爽文 / 短剧向

### 一句话简介
入赘三年被全家欺辱的废物女婿，意外觉醒"万物估值之眼"——能看到一切物品的真实价值，从此捡漏暴富、打脸逆袭。

### 核心看点/钩子
- **金手指可视化**："万物估值之眼"——每件物品头顶显示价格，古董/原石/地皮一目了然，读者爽感直接
- **开局冲突强**：第一章就在丈母娘生日宴上被当众羞辱，随即在街边地摊花50块买到价值500万的古董，当场翻盘
- **爽点密度高**：每3章一个打脸场景（鉴宝打脸专家、赌石打脸富二代、拍卖行打脸同行）
- **升级路径清晰**：初期看小物件 → 中期看房产地皮 → 后期看"人的价值"（识人、投资、布局）

### 目标受众
- 七猫核心用户：30-50岁男性
- 喜欢鉴宝/捡漏/赘婿逆袭题材
- 下沉市场偏好"暴富梦"+"打脸爽感"

### 变现路径
| 路径 | 规格 | 预估收益 |
|------|------|---------|
| **短剧改编** | 每集3-5分钟，80-100集 | S+级5-10万保底+20%分成 |
| **长篇连载** | 200-300万字 | 七猫广告分成+打赏 |
| **AI漫剧** | 1-3万字精简版改编 | 漫剧分成 |

### 为什么适合七猫
- 赘婿+鉴宝是七猫男频TOP3常驻品类
- "金手指可视化"天然适配短视频/漫剧——画面冲击力强
- 下沉市场男性对"捡漏暴富"有天然代入感（古玩城、旧货市场是全民记忆）
- 竞品多但同质化严重，"万物估值"概念比传统"透视眼"更新颖

## 方向二：《我在古代当首富》

**类型**：男频历史架空 / 经营爽文

### 一句话简介
现代破产老板穿越到架空古代，从一间破面摊起步，靠现代商业思维降维打击，一步步打造古代商业帝国。

### 核心看点/钩子
- **降维打击爽感**：现代商业模式吊打古代——加盟连锁、会员制、饥饿营销、饥饿营销、品牌溢价，古人看傻了
- **经营养成感**：面摊 → 酒楼 → 商号 → 钱庄 → 跨海贸易，每一步都是升级，读者有"看着孩子长大"的满足感
- **反差喜剧**：现代商战话术（"赋能""抓手""闭环"）放在古代语境里自带笑点
- **冲突不断**：同行恶性竞争、官府刁难、同行嫉妒、商会围剿，每次危机都用现代商业智慧化解
- **群像精彩**：收服古代"打工人"——落魄书生当账房、退役老兵当保安、青楼花魁当公关

### 目标受众
- 七猫男频历史架空爱好者
- 喜欢经营养成、种田流、穿越逆袭
- 30岁以上男性对商业/财富话题有天然兴趣

### 变现路径
| 路径 | 规格 | 预估收益 |
|------|------|---------|
| **长篇连载** | 300-500万字 | 七猫广告分成+读者打赏 |
| **短剧改编** | 商战打脸单元剧，60-80集 | 漫剧/短剧分成 |
| **IP授权** | 经营类小游戏联动 | 额外版权收入 |

### 为什么适合七猫
- 历史架空+经营是七猫男频稳定品类（爆款增长175%）
- "商业降维打击"题材在番茄验证成功，七猫尚在蓝海
- 经营养成天然长文（越写越长），适合七猫长篇连载生态
- 可拆分出独立"商战单元"改编短剧/漫剧，一鱼多吃

## 方向三：《替嫁冷妃：王爷的读心小娇妻》

**类型**：女频古言 / 替嫁+读心+甜宠

### 一句话简介
替妹妹嫁给传说中冷酷无情的王爷，却发现他能听见自己的心声——从此内心疯狂吐槽，表面端庄贤淑，两人在反差中越陷越深。

### 核心看点/钩子
- **读心设定=天然喜剧**：女主表面恭恭敬敬"妾身遵命"，内心疯狂吐槽"这冰块脸装什么高冷"，男主听得一清二楚但表面不动声色
- **甜而不腻**：不是无脑甜，有替嫁阴谋、宫斗暗线、身世之谜，甜虐交替
- **人设反差**：男主"冷酷王爷"实则护短，女主"柔弱庶女"实则内心戏精
- **钩子密集**：每章末尾留悬念——"他到底能不能读心？""她什么时候会发现？""替嫁真相何时揭穿？"
- **名场面预设**：洞房夜内心疯狂吐槽被发现、宴会上两人表面恩爱内心互怼、男主暗中保护女主却不承认

### 目标受众
- 女频古言读者（25-40岁女性）
- 喜欢替嫁、读心、甜宠、欢喜冤家
- 七猫女频增长快（爆款增长率250%），竞争尚不激烈

### 变现路径
| 路径 | 规格 | 预估收益 |
|------|------|---------|
| **长篇连载** | 150-200万字 | 七猫广告分成+打赏 |
| **短剧改编** | 甜宠短剧，60-80集 | S+级保底+分成 |
| **AI漫剧** | 甜宠漫剧，竖屏 | 漫剧分成 |

### 为什么适合七猫
- 女频古言是七猫2025年增长最快的品类（+250%）
- "读心+替嫁"是短视频平台已验证的爆款公式（抖音/快手短剧高频题材）
- 甜宠题材天然适合漫剧/短剧改编——画面美、冲突轻、情绪价值高
- 七猫女频内容供给不足，优质作品容易脱颖而出

## 方向四：《重生1998：从小厂长到商业帝国》

**类型**：男频重生年代 / 商战爽文

### 一句话简介
2026年破产跳楼的中年老板，重生回到1998年国营厂倒闭那天，带着30年商业记忆，从濒临破产的小厂长做起，一步步重建商业帝国。

### 核心看点/钩子
- **时代红利爽感**：知道未来30年所有商机——房地产、互联网、智能手机、新能源，每一步都踩在风口上
- **年代共鸣**：70后、80后对1998年有集体记忆——国企下岗、下海经商、第一批万元户，代入感极强
- **复仇线**：前世坑害自己的仇人，今生逐个收拾——抢订单的同行、背叛的合伙人、落井下石的亲戚
- **商战智慧**：不是无脑爽，每次商业决策都有逻辑——做空、杠杆、并购、品牌战，让读者觉得"学到了"
- **家国情怀**：从小厂到民族企业，对抗外资收购，最后"中国制造"走向世界——下沉市场男性最爱的情怀牌

### 目标受众
- 七猫核心用户：35-50岁男性（恰好是经历过那个年代的人）
- 喜欢重生、商战、年代文
- 下沉市场对"改革开放致富故事"有天然好感

### 变现路径
| 路径 | 规格 | 预估收益 |
|------|------|---------|
| **长篇连载** | 200-300万字 | 七猫广告分成（长文广告收益最高） |
| **短剧改编** | 年代商战短剧，80-100集 | 短剧分成 |
| **现实题材征文** | 可申报百万奖金征文 | 征文奖金+平台流量倾斜 |

### 为什么适合七猫
- 年代+重生+商战完美契合七男性用户画像（30-50岁）
- 现实题材可参与百万奖金征文，一举两得
- 年代文的"真实感"比纯玄幻更容易做漫剧/短剧改编（场景、服装、道具都好还原）
- 下沉市场中年男性对"那个年代"有深厚情感，完读率极高

## 方向五：《我的老婆是未来大佬》

**类型**：女频现言 / 反差萌+都市异能

### 一句话简介
普通社恐程序员意外娶了一个"什么都不会"的全职太太，直到某天发现——她随手画的涂鸦成了热搜爆款漫画、随便写的菜谱成了米其林餐厅秘方、连养的流浪猫都成了网红宠物博主。

### 核心看点/钩子
- **反向金手指**：不是主角有金手指，是主角的"废物老婆"其实是满级大佬——读者和男主一起"发现"她的隐藏技能
- **日常甜+惊奇感**：每章都是"老婆又干了一件不可思议的事"，像拆盲盒一样有期待感
- **轻松治愈**：不虐不狗血，纯爽纯甜，适合碎片化阅读
- **单元剧结构**：每个"掉马"（暴露技能）事件独立成章，适合拆分做漫剧/短剧
- **反差人设**：社恐程序员丈夫 × 隐藏全能天才妻子，日常互动的反差感是天然笑点

### 目标受众
- 女频现言读者（20-35岁女性）
- 喜欢轻松甜宠、日常向、反差萌
- 七猫现言赛道竞争小于古言，容易出圈

### 变现路径
| 路径 | 规格 | 预估收益 |
|------|------|---------|
| **AI漫剧** | 日常甜宠漫剧，竖屏，50-80集 | 漫剧分成（制作成本最低） |
| **短剧改编** | 轻松向短剧，40-60集 | 短剧分成 |
| **长篇连载** | 100-150万字 | 七猫广告分成 |

### 为什么适合七猫
- 轻松甜宠是漫剧/短剧最高效的品类（制作成本低、受众广、传播快）
- "日常掉马"单元剧结构天然适配短剧改编——每集一个新技能曝光
- 七猫女频内容供给不足，轻松向尤其稀缺
- 适合AI辅助生产（日常场景好生成、对话驱动、不需要复杂特效）

# 三、执行建议

## 3.1 优先级排序

| 优先级 | 方向 | 理由 |
|--------|------|------|
| **🥇 P0** | 方向一《废婿觉醒》 | 最契合七猫用户画像，短剧/漫剧变现路径最短 |
| **🥈 P1** | 方向四《重生1998》 | 完美匹配30-50岁男性用户，可申报百万征文 |
| **🥉 P2** | 方向三《替嫁冷妃》 | 女频增长最快，竞争小，甜宠短剧已验证 |
| **P3** | 方向二《我在古代当首富》 | 长线项目，适合长篇连载+IP衍生 |
| **P4** | 方向五《我的老婆是未来大佬》 | 低成本漫剧试验田，试水女频现言 |

## 3.2 生产策略

### AI漫剧剧本管线（对应望舒调研：月产100部目标）
1. **故事框架**：以上述5个方向为母版，每个方向可拆出3-5个独立故事
2. **剧本格式**：直接输出分镜脚本格式（画面描述+台词+时长），跳过小说中间环节
3. **批量生产**：建立角色库、场景库、对白模板，AI辅助批量生成
4. **S+级标准**：前3集必须出现3次以上强冲突/反转，第1集完播率决定定级

### 短剧向网文管线（对应望舒调研：月上新20-30部）
1. **大纲先行**：先出100章大纲，确定爽点分布
2. **节奏控制**：每章3000字，至少1个小爽点，每10章1个大高潮
3. **签约策略**：2万字即可签约，先快速签约再逐步优化

### 长篇连载管线
1. **存稿策略**：开书前存稿10万字，保证日更6000字不断更
2. **全勤奖**：满足日更4000字即可拿全勤，优先保量再保质
3. **读者运营**：章末互动、读者群运营，提升追读率

## 3.3 时间节点建议

| 时间 | 动作 |
|------|------|
| **第1周** | 选定方向一/四，完成大纲+前10章 |
| **第2周** | 投稿签约 + 同步启动漫剧剧本改编 |
| **第3-4周** | 稳定日更 + 漫剧前3集制作 |
| **第2个月** | 根据数据反馈调整方向，启动女频方向 |
| **第3个月** | 评估漫剧收益，决定是否加大投入 |
