# 一、故事大纲

## 1.1 世界观设定

### 时代背景
现代都市，2026年。表面是普通都市，暗地里存在一个"异能者"群体——拥有特殊能力的人，但隐藏在普通人中。

### 核心设定

**金手指：女主有"未来投影"能力**
苏小满能看到一个人"未来的样子"——不是预知未来，而是看到一个人"如果继续现在的状态，5年后会变成什么样"。

**规则：**
- 看到的是"投影"（半透明的未来影像）
- 只能看到"熟人"（接触过3次以上的人）
- 看到的"未来"不是固定的——如果那个人改变，未来也会改变
- 副作用：过度使用会流鼻血

**反差萌设定：**
女主苏小满表面上是一个"社恐+废柴"的便利店店员——但她看到的"未来"让她知道每个人真正的潜力。男主陆霆表面上是一个"高冷霸道总裁"——但苏小满看到的"未来投影"是：5年后他会变成一个"温柔奶爸"。

## 1.2 主线剧情

### 起（1-30章）：相遇
苏小满在便利店值夜班，遇到了来买泡面的陆霆。她看到他的"未来投影"——5年后，这个高冷总裁会抱着一个婴儿，笨拙地冲奶粉。她没忍住笑了出来。陆霆皱眉："你笑什么？"

### 承（31-150章）：相知
苏小满用"未来投影"能力帮助身边的人——帮同事找到适合的职业方向、帮邻居解决家庭矛盾、帮陆霆的公司避开危机。陆霆开始注意到这个"奇怪的便利店女孩"。

### 转（151-300章）：相爱
陆霆追求苏小满。苏小满发现陆霆的"高冷"是装的——他其实是一个"社恐+温柔"的男人。两人从"互相试探"到"互相依赖"。同时，苏小满的能力开始"升级"——她能看到更远的未来。

### 合（301-400章）：相守
苏小满的能力最终形态：她能看到"所有人的未来"——但她选择"不看"。因为"未来不是用来看到的，是用来创造的"。陆霆求婚。苏小满说："我看到我们的未来了。"陆霆紧张："是什么样的？"苏小满笑了："不告诉你。"

# 二、人物设定

## 2.1 男主

```markdown
## 陆霆（男，28岁）
- 身份：集团总裁
- 外貌：①高冷型帅哥 ②眼神锐利但看女主时会慌乱 ③穿着永远一丝不苟
- 性格：外表高冷霸道，内心社恐+温柔（只对女主敞开心扉）
- 核心优势：商业天才、果断、有责任感
- 性格缺陷：不擅长表达感情（社恐）；过度工作（用工作掩饰孤独）
- 成长弧线：从"封闭自己"到"学会表达"到"温柔奶爸"
- 核心恐惧：被拒绝（童年被霸凌的阴影）
- 核心渴望：被真心对待
```

## 2.2 女主

```markdown
## 苏小满（女，22岁）
- 身份：便利店店员 → 陆霆的妻子 → 慈善基金会主席
- 外貌：①可爱型 ②圆眼睛+酒窝 ③穿着随意但干净
- 性格：社恐但善良、有同理心、不圣母
- 金手指：未来投影（看到人5年后的样子）
- 核心优势：能看到别人的"潜力"
- 性格缺陷：过度使用能力会流鼻血；有时过度依赖能力
- 成长弧线：从"被动看未来"到"主动创造未来"
- 核心恐惧：被人当成"怪物"
- 核心渴望：被真心爱
```

## 3.2 前10章细纲

### 第1章：便利店的夜班
苏小满在便利店值夜班。凌晨2点，一个穿西装的男人走进来，拿了一碗泡面。苏小满抬头——看到他头顶的"未来投影"：5年后，这个男人抱着一个婴儿，笨拙地冲奶粉。
**爽点**：无（铺垫）
**钩子**：苏小满没忍住笑了出来。

### 第2章：你笑什么？
男人皱眉："你笑什么？"苏小满赶紧摇头："没什么！"男人付钱离开。苏小满看着他的背影——未来投影还在："温柔奶爸"。
**爽点**：🟢小爽点（反差萌）
**钩子**：男人走出便利店，回头看了一眼。他的眼神很奇怪。

### 第3章：能力觉醒
苏小满回忆——她的能力是18岁那年觉醒的。母亲去世前说："小满，你能看到别人的未来。但记住——未来不是用来看到的，是用来创造的。"
**爽点**：🟡中爽点（能力背景）
**钩子**：苏小满流了一点鼻血——过度使用能力的副作用。

### 第4章：帮助同事
同事小王抱怨工作不顺。苏小满用能力看到他的未来——如果他继续现在的工作，5年后会一事无成。但如果他转行做销售，5年后会是销售总监。
**爽点**：🟡中爽点（帮助他人）
**钩子**：苏小满建议小王转行。小王半信半疑。

### 第5章：陆霆再次出现
陆霆又来到便利店。这次他买了两碗泡面。苏小满看到他的未来投影——还是那个温柔奶爸。但这次，投影里多了一个女人——是她自己。
**爽点**：🔴大爽点（未来里有她！）
**钩子**：陆霆说："上次那个泡面……还挺好吃的。"

### 第6章：邻居的求助
邻居张阿姨来找苏小满——她和儿子吵架了。苏小满用能力看到——如果继续吵，5年后母子形同陌路。但如果和解，5年后儿子会带着孙子回来看她。
**爽点**：🟡中爽点（帮助邻居）
**钩子**：苏小满帮张阿姨和儿子和解。张阿姨送了一面锦旗。

### 第7章：陆霆的调查
陆霆开始"调查"苏小满——他发现她只是一个普通的便利店店员。但为什么他觉得她不普通？
**爽点**：🟢小爽点（总裁开始在意）
**钩子**：陆霆的心声："她到底是什么人？"

### 第8章：商业危机
陆霆的公司遇到危机——一个项目出了问题。苏小满用能力看到——如果按现在的方案，5年后公司会破产。但如果调整方向，5年后会成为行业第一。
**爽点**：🔴大爽点（帮男主避坑）
**钩子**：苏小满匿名给陆霆发了一封邮件。

### 第9章：陆霆的震惊
陆霆收到匿名邮件——里面的建议完美解决了危机。他震惊：谁发的？
**爽点**：🟡中爽点（女主暗中帮忙）
**钩子**：陆霆开始怀疑苏小满。

### 第10章：LV2升级
苏小满的能力升级到LV2——能看到更远的未来（10年）。
**爽点**：🔴大爽点（能力升级）
**钩子**：她看到陆霆的10年未来——他抱着两个孩子，笑着叫她"老婆"。

# 四、商业化设计

## 4.1 短剧前3集脚本

### 第1集：《未来投影》（3分钟）
- 场景1：便利店夜班，苏小满打瞌睡。
- 场景2：陆霆进来买泡面。
- 场景3：苏小满看到他的未来投影——温柔奶爸。
- 场景4：她笑了出来。陆霆皱眉。
- 钩子：陆霆走出便利店，回头看了一眼。

### 第2集：《匿名邮件》（3分钟）
- 场景1：陆霆公司遇到危机。
- 场景2：苏小满用能力看到"未来"。
- 场景3：她发了匿名邮件。
- 场景4：陆霆收到邮件，震惊。
- 钩子：陆霆："是谁发的？"

### 第3集：《能力升级》（3分钟）
- 场景1：苏小满能力升级到LV2。
- 场景2：她看到陆霆的10年未来——两个孩子+叫她老婆。
- 场景3：她脸红了。
- 场景4：陆霆再次来到便利店。
- 钩子：陆霆："我们是不是在哪里见过？"苏小满："在……你的未来里。"

- 重点表现"未来投影"特效（半透明影像）
- 反差萌（高冷总裁→温柔奶爸）
- 每集8-12个关键分镜

# 五、竞品差异化

| 竞品 | 特点 | 本书差异 |
|------|------|---------|
| 《我的老婆是大佬》 | 女强男弱 | 本书是"反差萌"——男主外表强内心软 |
| 《未来男友》 | 预知未来 | 本书是"看到别人的未来"而非"预知事件" |
| 《便利店女孩》 | 日常治愈 | 本书有异能元素，节奏更快 |

**风险**：异能题材同质化 → 用"未来投影+反差萌"差异化。不是传统异能战斗文，是"用异能帮助他人"的治愈系甜宠。
