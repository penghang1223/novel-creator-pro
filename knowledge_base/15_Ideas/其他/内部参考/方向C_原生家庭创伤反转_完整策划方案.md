# 方向C：《我妈说我是捡来的》

> 灵犀 💡 | 2026-04-22
> 类型：原生家庭创伤+反转 | 第一人称 | 15-20万字
> 对标：《我妈说我是捡来的》（10-25万）、《我爸的遗嘱里，没有我的名字》（8-20万）
> 预估：过稿率65%，收入5-30万，完读率70%

---

## 一、一句话故事

我一直以为我恨的是我妈——直到她去世那天，我发现她留给我的一封信，里面写着一个我从未想过的真相。

---

## 二、世界观设计（五维模型）

| 维度 | 设计 |
|------|------|
| **时空** | 2026年，三线城市（湖南某地级市），时间跨度15年（从主角12岁到27岁） |
| **规则** | 中国式家庭的"潜规则"：不说爱、不说抱歉、不表达情绪；用"为你好"掩盖伤害 |
| **权力** | 母亲（绝对权威）→ 女儿（服从者）；母亲掌控一切：钱、信息、话语权 |
| **禁忌** | 不能问"爸爸在哪"、不能提"过去的事"、不能在亲戚面前"闹" |
| **例外** | 主角是"被收养"的——但真相远比"被收养"复杂 |

**家庭世界侧重点：**
- 信息封锁：母亲刻意隐瞒过去
- 情感压抑：中国式家庭的"不说"文化
- 日常暴力：不是打骂，而是冷暴力、忽视、比较

---

## 三、核心异质物/触发器

**一封信。**

母亲去世后，主角在整理遗物时发现了一封写着"给晚晚"的信。信的第一句话是："如果你看到这封信，说明我终于可以不骗你了。"

## 四、人物设计

### 4.1 主角（MACH模型）

```markdown
## 主角：林晚（女，27岁）
- 年龄/性别/职业：27岁/女/长沙某广告公司文案策划
- 外貌特征：①笑起来有酒窝（像母亲） ②左手腕有一道小时候的疤痕 ③紧张时会摸左耳
- 表层动机：搞清楚母亲到底瞒了她什么
- 深层动机：确认自己"值得被爱"——27年来一直在证明自己
- 核心能力：
  - 硬能力：文字能力极强（职业文案）
  - 软能力：敏锐的观察力、共情能力、韧性
- 能力边界：不擅长面对冲突（习惯性逃避）、经济能力有限
- 性格缺陷：过度讨好（职场和感情中都是"讨好型人格"）
- 认知缺陷（错误信念）："我不值得被爱，除非我做得足够好"
- 致命弱点：对"母爱"的渴望——这让她容易被操控
- 口头禅/习惯动作：紧张时摸左耳；思考时咬笔帽
- 成长弧光：从"讨好型人格"→"学会拒绝"→"学会爱自己"
- 核心恐惧：被抛弃（"我又会被丢下"）
- 核心渴望：被无条件地爱
- 关系锚点：母亲（已故）——她一生都在渴望母亲的爱
- 读者代入点：每个在原生家庭中受过伤的人
```

### 4.2 核心配角（3F模型）

```markdown
## 配角1：母亲（陈秀英，享年55岁）— 推动型/复杂反派
- 角色类型：推动型（通过"遗物"推动剧情）
- 与主角关系：母女
- 私人欲望：保护女儿——用自己的方式
- 秘密：林晚不是"捡来的"，而是……（终极反转）
- 对主角的作用：一切冲突的源头
- 独立行为线：通过"遗物"（信/日记/照片/录音）在"死后"继续影响女儿
- 结局：她的真相被揭开——她不是"恶母"，而是一个"用错误方式爱女儿的母亲"
```

```markdown
## 配角2：小姨（陈秀兰，50岁）— 功能型
- 角色类型：功能型（提供信息）
- 与主角关系：母亲的妹妹，唯一知道真相的亲戚
- 私人欲望：不想再背负秘密
- 秘密：她知道林晚的真实身世，但答应姐姐不说
- 对主角的作用：关键信息的提供者
- 独立行为线：她也在逃避——27年来每次林晚问，她都回避
- 结局：在林晚的追问下，终于说出了真相
```

```markdown
## 配角3：赵宇（29岁）— 对比型
- 角色类型：对比型
- 与主角关系：林晚的男友，来自一个"完美家庭"
- 私人欲望：和林晚结婚
- 秘密：他的"完美家庭"也有裂痕——他父亲出轨，母亲假装不知道
- 对主角的作用：镜像对照（"你的家庭有问题，我的家庭也有——但我们可以选择不同"）
- 独立行为线：他试图用"爱"治愈林晚，但林晚需要的不是被爱，而是学会爱自己
- 结局：他和林晚分手了——不是因为不爱，而是因为林晚需要一个人面对
```

```markdown
## 配角4：老周（60岁）— 推动型
- 角色类型：推动型
- 与主角关系：母亲的老同事，知道27年前的真相
- 私人欲望：赎罪——27年前他做了一件对不起林晚生母的事
- 秘密：他参与了27年前的"那件事"
- 对主角的作用：揭开最终真相的钥匙
- 独立行为线：27年来一直在默默关注林晚的成长
- 结局：他向林晚道歉——这27年的沉默是他最大的罪
```

### 4.3 反派设计（3R模型）

**这部作品没有传统意义上的"反派"。最大的"反派"是——沉默。**

**Reason（合理性）：**
- 母亲：她隐瞒真相是因为"保护"——她知道真相会伤害女儿
- 小姨：她不说，因为答应了姐姐
- 老周：他不说，因为内疚

**Ruthless（压迫感）：**
- 不是暴力的压迫，而是"你问了27年，没人告诉你"的绝望
- 每一代人的沉默，叠加成一座山

**Redemption（反转空间）：**
- 母亲不是"恶母"——她是一个不知道如何表达爱的女人
- 她做的一切（打骂、冷漠、比较）都是因为她自己也是这样被对待的
- 终极反转：她不是"不爱"，而是"不会爱"

### 4.4 人物关系图

```
               [母亲/陈秀英]（已故）
              ↗（母女/秘密）↖
         [林晚]              [小姨/陈秀兰]
        （主角）     （信息源/沉默者）
           ↓                    ↓
      [赵宇/男友]          [老周/关键证人]
    （镜像对照）         （27年前的参与者）
    
关系本质：每个人都爱林晚，但每个人都在伤害她
——因为他们都不知道如何正确地爱。
```

## 六、三条暗线全览

### 暗线1："捡来的"真相
- **明面**：母亲骗她说她是捡来的
- **暗面**：不是捡来的，是被生母"托付"的——母亲用"捡来的"来掩盖真相
- **回收**：第22章，小姨说出真相

### 暗线2：母亲的打骂
- **明面**：母亲对林晚不好（打骂、冷漠）
- **暗面**：母亲在"刻意"对她不好——因为她觉得"买来的孩子"不能太宠，否则会被丈夫怀疑
- **回收**：第28章，日记完整版揭示真相

### 暗线3：赵宇的"完美家庭"
- **明面**：赵宇来自一个完美家庭
- **暗面**：赵宇的父母也有裂痕——他一直在假装幸福
- **回收**：第16章，赵宇承认"我的家也不完美"

## 八、开篇设计（3选1）

### 方案A（情感冲击型）⭐推荐

> 我妈死了。
>
> 我站在灵堂里，看着她的遗像。她笑得很平静——和我认识的那个她一点都不像。
>
> 我妈是个很凶的女人。
>
> 从小到大，她打我、骂我、拿我和别人家的孩子比。她从来没有夸过我，从来没有抱过我，从来没有说过"我爱你"。
>
> 我恨了她27年。
>
> 但此刻，我站在这里，眼泪止不住地往下掉。
>
> 不是因为悲伤。
>
> 是因为我终于可以不用再恨她了。
>
> 然后我看到了那封信。
>
> 枕头上，白色的信封，上面写着两个字："晚晚。"
>
> 我的手开始发抖。

### 方案B（悬念型）

> 我妈说我是捡来的。
>

>
> 我一直以为这是吓唬小孩的话。
>

>
> 我翻到第二页——没有了。
