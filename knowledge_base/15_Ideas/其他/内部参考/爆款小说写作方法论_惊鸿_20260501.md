## 一、各品类通用公式

### 1.1 开篇钩子公式

**3章定生死，3000字定留存。**

所有爆款作品的开篇都遵循以下原则：

| 原则 | 说明 | 案例 |
|------|------|------|
| **不铺垫** | 不要花3章介绍世界观，直接进入核心场景 | 《十日终焉》醒来就在圆桌旁 |
| **日常异化** | 把日常事物变成恐怖/异常来源 | 《全球高考》把考试变成生死游戏 |
| **身份反转** | 让读者以为的"弱者"其实是"强者" | 《我在无限游戏里封神》失业男其实是神明 |
| **预期违背** | 书名/简介暗示一件事，正文走向另一件 | 《攻略不下来的男人》不是攻略文 |
| **直接高潮** | 第一局游戏/第一次冲突就是高潮 | 《死亡万花筒》开门就是恐怖副本 |

**实操公式：**
```
前500字：建立场景+引入主角（1-2句话搞定）
500-1500字：第一次冲突/异常事件（直接扔进麻烦）
1500-3000字：主角的反应+第一个悬念钩子（让读者想知道"然后呢"）
```

### 1.2 节奏控制公式

**猫腻的原话："关键是节奏。"**

#### 通用节奏模型：情绪流（铺垫-高潮-过渡）

```
铺垫（压抑/期待）→ 高潮（释放/爽点）→ 过渡（喘息/新悬念）
```

#### 不同品类的节奏密度

| 品类 | 千字几高潮 | 爽点间隔 | 说明 |
|------|-----------|---------|------|
| 番茄男频 | 每2-3章一个小高潮 | 每1章有爽点 | 类似微短剧节奏 |
| 晋江女频 | 每5-10章一个情感高潮 | 每3-5章有甜点 | 情感驱动，节奏较慢 |
| 知乎盐选 | 每1000字一个爆炸点 | 每500字有冲突 | 短篇需要极致密度 |
| 起点男频 | 每10-20章一个大高潮 | 每3-5章有小爽点 | 长篇需要呼吸感 |

#### 节奏自检表

- [ ] 1-3章是否有明确冲突+卡钩子？
- [ ] 4-10章第一次爽点爆发铺垫是否足够？
- [ ] 30章后主角是否有"成长感"？
- [ ] 每个章节结尾是否留了悬念？
- [ ] 高潮之间是否有"喘息空间"？

### 1.3 人设设计公式

**"大红书"人物设定公式（猫腻）：**
> "范闲有很多特质，对女性有吸引力。他是出色的诗人、文人、特务头子、爱国志士，武艺高强，还长得特别好看。他结合了霸道总裁的特点。"

**通用公式：3个标签 + 1个反差 + 1个成长线**

```
3个标签：读者一眼能记住的特征（如"爱钱""疯批""冷静"）
1个反差：外表vs内心、能力vs性格的反差
1个成长线：从A到B的变化弧线
```

**CP感公式（女频专用）：**
```
互补型：智力×武力 / 直球×内敛 / 强势×温柔
对立型：考官×考生 / 敌人×盟友 / 强者×弱者
追光型：暗恋者×被暗恋者 / 追光者×光本身
```

### 1.4 冲突设计公式

**"安全感之上的不安全感"（猫腻《庆余年》核心技法）**

```
给主角强大背景（安全感）→ 让背景变得不可靠（不安全感）→ 但不安全感是可控的（安全感回归）
```

**冲突层级设计：**
```
表层冲突：眼前的敌人/困难（每章都有）
中层冲突：阶段性目标/对手（每10-20章）
深层冲突：世界观层面的矛盾（贯穿全书）
终极冲突：主角的终极选择/牺牲（结局）
```

### 1.5 世界观设计公式

**"一句话原则"：**
> 你的世界观能不能用一句话说清楚？

| 作品 | 一句话世界观 | 复杂度 |
|------|-------------|--------|
| 《全球高考》 | 参加一场诡异的高考，每个考场是一个副本 | 低入口，高扩展 |
| 《死亡万花筒》 | 打开一扇门进入恐怖世界，过12扇门回家 | 低入口，高扩展 |
| 《十日终焉》 | 被拉入终焉之地，玩死亡游戏活下去 | 低入口，高扩展 |
| 《庆余年》 | 私生子在古代权谋世界中成长 | 低入口，高扩展 |

**好的世界观 = 简单入口 + 丰富细节 + 持续悬念**

## 二、女频专用技巧

### 2.1 甜文/言情类

#### 顾漫模式（《你是我的荣耀》）

```
重逢 + 身份倒转 + 职业话题 + 理想主义内核
```

**要点：**
- 不需要狗血剧情，日常相处中的小细节就能推动感情
- 职业线不是背景板，而是与感情线交织的平行叙事
- 立意高于普通甜文——不只是谈恋爱，而是人生选择

#### 墨宝非宝模式（《我的时代你的时代》）

```
暗恋多年 + 事业线驱动 + 高语境对白 + 追光与并肩
```

**要点：**
- "他看了她很久，终于等到她也看到他"——暗恋结构
- 角色不直说"我爱你"，用行动和暗示表达
- 选择一个有专业度的行业，让爱情有现实根基

### 2.2 反套路/女性觉醒类

#### "反攻略"模式（《攻略不下来的男人》《女主对此感到厌烦》）

```
书名即反套路 + 快穿/轮回结构 + 终极反转 + 女性觉醒
```

**要点：**
- 用"反套路"吸引读者——读者以为是A，实际是B
- 每个副本/轮回验证同一个命题，但角度不同（螺旋深化）
- 终极反转颠覆一切——"快穿世界不存在"
- 用"厌烦"代替"愤怒"作为驱动情绪——更高级

#### 无CP大女主模式（2025-2026趋势）

```
拒绝恋爱脑 + 专注自我成长 + 女性友谊 + 搞事业
```

**要点：**
- 番茄2025-2026最热门品类：无CP大女主
- "无CP"不等于"无情感"——女性友谊是替代的情感核心
- 对标：《游戏入侵》《女主对此感到厌烦》

### 2.3 CP感营造技巧

| 技巧 | 说明 | 案例 |
|------|------|------|
| 口嫌体正直 | 嘴上不饶人，行动互相关心 | 《全球高考》游惑×秦究 |
| 战场CP | 不是"我保护你"，是"我们一起上" | 《全球高考》并肩炸考场 |
| 追光者 | "我的时代就是你的时代" | 《我的时代你的时代》 |
| 信仰式 | 神明对凡人的"欢迎回家" | 《我在无限游戏里封神》 |
| 养成式 | 强者引导弱者成长 | 《死亡万花筒》阮南烛×林秋石 |

## 三、男频专用技巧

### 3.1 "大红书"配方（猫腻总结）

```
70分以上的文笔 + 套路文 + 关键是节奏 + 安全感 + 可控不安全感
```

**安全感三件套：**
1. 大背景（皇帝父亲、豪门出身）
2. 金手指（特殊能力、先知优势）
3. 强大配角（保镖、导师）

**可控不安全感的制造：**
- 调走关键人物（五竹离开）
- 内部猜疑（皇帝/陈萍萍/户部尚书互相猜忌）
- 外部威胁（敌人太强）

### 3.2 番茄男频爆款公式

```
标题党 + 快节奏 + 脑洞大开 + 夸张性和趣味性
```

**番茄平台的节奏特征（许苗苗教授总结）：**
- **长故事、短情节、快反转**
- **"萌要素"：** 短小但情感激发能力强的元素
- 把这些"萌点"融合到情节里，串联到长篇故事

**番茄男频热门品类（2025-2026）：**
| 品类 | 热度 | 代表 | 核心 |
|------|------|------|------|
| 游戏入侵/无限流 | ★★★★★ | 《游戏入侵》《十日终焉》 | 在读近500万 |
| 悬疑脑洞 | ★★★★★ | 《斩神》《诡舍》 | 规则与人性博弈 |
| 修仙2.0 | ★★★★☆ | 《长生烬》 | 日常性修仙 |
| 人性博弈 | ★★★★☆ | 《诸神愚戏》 | "费脑子"释放压力 |
| 东方美学 | ★★★★☆ | 《我不是戏神》 | 戏曲/非遗融入 |

### 3.3 人物代入公式

**两种代入途径（猫腻）：**
1. **代入屌丝逆袭：** 跟着主角从弱变强（少年崛起）
2. **代入人生赢家：** 代入已经是贵公子的主角（人生赢家）

**男频主角常见配置：**
```
穿越/重生 + 金手指 + 升级系统 + 多女配 + 装逼打脸
```

**2026新趋势：反套路男主**
- 不无敌（《十日终焉》）
- 不后宫（《十日终焉》）
- 不无脑（《十日终焉》）
- 靠解密不靠武力（《十日终焉》《诸神愚戏》）

## 四、无限流专项技巧

### 4.1 副本设计公式

**好的副本 = 独立故事 + 主线线索 + 角色成长**

```
进入副本 → 规则介绍（简单易懂）→ 探索/解谜 → 高潮/逃生 → 回到主线（带出一条线索）
```

**副本类型选择：**
| 类型 | 恐怖来源 | 代表 |
|------|---------|------|
| 民俗恐怖 | 中国传统恐怖元素 | 《死亡万花筒》 |
| 考试异化 | 日常事物的恐怖化 | 《全球高考》 |
| SCP/克系 | 未知+不可名状 | 《我在无限游戏里封神》 |
| 规则怪谈 | 规则与人性博弈 | 《十日终焉》 |
| 密室逃脱 | 智力博弈 | 《十日终焉》 |

### 4.2 无限流开篇公式

```
第一句话：异常场景/醒来 → 前3章：第一场游戏/副本 → 3章内：展示主角能力/特质 → 5章内：建立核心悬念（这个世界是什么）
```

**不要做的事：**
- ❌ 花10章介绍世界观
- ❌ 让主角"慢慢发现"异常
- ❌ 第一场游戏不够精彩

### 4.3 副本间的"呼吸"

**晋江模式：**
- 副本之间回到"现实世界"休整
- 休整期推进感情线和主线
- 比例：副本70% + 休整30%

**番茄模式：**
- 几乎没有过渡，连续高潮
- 主线线索在游戏间隙"顺便"揭示
- 比例：游戏90% + 过渡10%

## 五、知乎盐选短篇技巧

### 5.1 盐选核心要求

> **强钩子、高爽点、稳节奏**

**具体指标：**
- 开头50字内植入主题，别铺垫
- 节奏要快，**最好1000个字一个爆炸点**
- 适当放钩子，引人阅读
- 别弄有理解门槛的东西——要简单

### 5.2 盐选爆款结构

```
导语（100-200字）：核心冲突+悬念
开头（500字）：直接进入高潮
正文（3000-8000字）：3-5个反转
结尾（300字）：终极反转+余韵
```

**钩子前置策略：**
- 在每章前30%处设置高潮
- 付费章节需包含核心反转
- 免费试读部分要有"钩到不看不行"的效果

### 5.3 盐选热门品类

| 品类 | 热度 | 特点 |
|------|------|------|
| 悬疑推理 | ★★★★★ | 第一人称叙事、层层反转 |
| 现实情感 | ★★★★★ | 婚恋/职场/家庭冲突 |
| 反转+虐心救赎 | ★★★★☆ | "千字一高潮"、强代入感 |
| 考据式穿越 | ★★★★☆ | 严谨考据、知识破局 |
| 发疯文学 | ★★★★☆ | "与其内耗自己，不如外耗别人" |

### 5.4 盐选写作铁律

1. **第一人称优先：** 知乎读者偏好第一人称叙事
2. **短句+多对白：** 让阅读体验更轻松
3. **冲突前置：** 不要铺垫，直接进入冲突
4. **反转密度：** 每1000字至少一个反转/冲突
5. **理解门槛低：** 不要让读者"费脑子"理解设定
6. **情绪拉满：** 盐选靠情绪驱动，不是靠文学性

## 六、新媒体引流技巧

### 6.1 推文/短视频引流公式

```
爆款内容 = 情绪共鸣 × 节奏密度 × 题材融合 × 短剧适配性
```

### 6.2 小说推文技巧

- **提炼"名场面"：** 每部小说找出3-5个最能引发情绪共鸣的场景
- **制造悬念：** 推文只放"前戏"，不放"高潮"——引导开通会员
- **情绪标签：** 给推文打情绪标签（虐心/爽/甜/反转）
- **平台适配：** 抖音重画面、小红书重文案、微博重话题

### 6.3 短剧适配性

**哪些小说适合改编短剧？**
- ✅ 强冲突、快节奏
- ✅ 人物关系简单（3-5个核心角色）
- ✅ 场景集中（减少拍摄成本）
- ✅ 情绪驱动（虐/爽/甜）
- ❌ 世界观复杂、角色众多、节奏慢

**短剧改编的"爆款公式"（抖音）：**
```
前3秒抓人 + 每15秒一个反转 + 结尾留悬念
```

### 6.4 AI漫剧趋势

> **望舒判断：** 2026年最大的机会是AI漫剧——成本极低、试错风险小。

**建议：**
- 先用AI漫剧测试IP市场价值
- 数据好再推进真人短剧/影视
- 成本：AI漫剧 << 真人短剧 << 影视

## 七、新人避坑指南

### 7.1 十大常见错误

| 错误 | 说明 | 修正 |
|------|------|------|
| **铺垫过长** | 花5-10章介绍世界观 | 3章内进入核心冲突 |
| **主角被动** | 主角一直在"被推着走" | 让主角主动做选择 |
| **冲突太弱** | 没有真正的威胁/代价 | 让冲突有"输了就完"的 stakes |
| **配角工具人** | 配角只是主角的陪衬 | 给配角自己的动机和故事 |
| **节奏平** | 没有明显的高潮低谷 | 用情绪流公式控制节奏 |
| **设定太多** | 一次性塞入所有设定 | 逐步揭示，用"一句话"说清核心 |
| **感情线硬塞** | 感情发展不自然 | 用共同经历/冲突推动感情 |
| **反派太弱** | 反派没有真正威胁 | 给反派合理的动机和能力 |
| **结局仓促** | 匆匆收尾，没回收伏笔 | 提前规划结局，回收所有线索 |
| **不研究市场** | 闭门造车，不看爆款 | 先拆解10部同品类爆款再动笔 |

### 7.2 新人起步路径

```
第一步：选择热门品类 → 降低起步难度
第二步：拆解5部同品类爆款 → 学习套路
第三步：写一个1万字短篇 → 验证写作能力
第四步：根据反馈调整 → 迭代
第五步：开始写长篇（目标50万字）→ 正式连载
```

### 7.3 平台选择建议

| 平台 | 适合谁 | 收入模式 | 建议 |
|------|--------|---------|------|
| 番茄小说 | 新人首选 | 免费+广告分成 | 热门品类+快节奏+系列化 |
| 晋江文学城 | 有文笔有故事 | VIP订阅 | 女频/纯爱，注重人设和情感 |
| 起点中文网 | 有野心有耐心 | VIP订阅 | 男频，注重世界观和长篇布局 |
| 知乎盐选 | 短篇能力强 | 盐选会员分成 | 强钩子+快节奏+1万字左右 |
| 七猫 | 下沉市场 | 免费+广告 | 类似番茄，但读者年龄偏大 |

## 八、各平台爆款作品清单与对标

### 8.1 调研报告汇总作品清单

基于望舒完成的13平台调研报告，提取的爆款作品：

#### 女频重点作品
| 作品 | 作者 | 平台 | 类型 | 对标价值 |
|------|------|------|------|---------|
| 《你是我的荣耀》 | 顾漫 | 晋江 | 现代言情 | 甜文+职业线+影视改编 |
| 《我的时代你的时代》 | 墨宝非宝 | 晋江 | 竞技言情 | 暗恋结构+事业线 |
