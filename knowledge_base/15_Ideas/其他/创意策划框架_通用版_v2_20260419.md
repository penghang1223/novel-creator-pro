# 第一部分：世界观搭建模板

## 1.1 五维世界观模型

任何故事的世界观，必须回答5个问题：

| 维度 | 核心问题 | 填充区 |
|------|---------|--------|
| **时空** | 何时何地？ | _______ |
| **规则** | 这个世界运行的底层逻辑？ | _______ |
| **权力** | 谁掌握资源？谁被压迫？ | _______ |
| **禁忌** | 不能做什么？触碰的后果？ | _______ |
| **例外** | 主角凭什么打破规则？ | _______ |

## 1.2 不同题材的世界观侧重点

**悬疑类** → 信息不对称（谁知道什么）
**言情类** → 情感阻碍（什么在阻止他们在一起）
**科幻类** → 技术变革（什么改变了人类社会）
**现实类** → 社会议题（什么现象在影响主角）
**神怪类** → 超自然规则（妖鬼如何隐藏在现代社会）

## 1.3 世界观元素检查清单

```
□ 时代背景（年份/历史事件）
□ 地理环境（核心场景+边缘场景）
□ 社会阶层（顶层/中层/底层+流动性）
□ 经济体系（钱从哪来？谁缺钱？）
□ 权力结构（明面规则 vs 潜规则）
□ 特殊设定（超能力/系统/穿越等，如有）
□ 禁忌清单（3件不能碰的事）
□ 日常细节（衣食住行，增强真实感）
□ 语言风格（方言/行话/口头禅）
□ 信息来源（主角如何获取信息？）
```

# 第三部分：分卷规划框架

## 3.1 四卷标准结构

| 卷 | 名称 | 功能 | 字数占比 | 情绪基调 |
|----|------|------|---------|---------|
| 卷一 | 起 | 建立世界观+主角+核心冲突 | 20-25% | 好奇→紧张→震惊 |
| 卷二 | 承 | 冲突升级+配角入场+假胜利 | 30-35% | 希望→挫折→绝望 |
| 卷三 | 转 | 最大反转+主角最低谷 | 25-30% | 绝望→觉醒→反击 |
| 卷四 | 合 | 最终对决+真相大白+余韵 | 15-20% | 紧张→释放→回味 |

## 3.2 每卷核心事件模板

### 卷一：起

```
情绪曲线：好奇 → 紧张 → 震惊 → 悬念

事件清单：
□ 事件1：日常被打破（前3章，触发事件）
□ 事件2：主角被迫行动（3-5章，第一次选择）
□ 事件3：发现冰山一角（5-7章，第一次震惊）
□ 事件4：卷末大钩子（推翻读者预期）

设计要点：
- 前3章：主角亮相+核心冲突+第一个悬念
- 第5章左右：给一个"小爽点"
- 卷末：必须有反转
```

### 卷二：承

```
情绪曲线：希望 → 挫折 → 希望 → 更大挫折 → 绝望

事件清单：
□ 事件1：主角找到方向
□ 事件2：第一次胜利（假胜利）
□ 事件3：反派反击
□ 事件4：配角背叛/牺牲（情绪低谷）
□ 事件5：卷末大反转（推翻卷一的某个认知）

设计要点：
- "假胜利"是关键
- 配角背叛/牺牲是最低谷
- 卷末反转必须有伏笔支撑
```

### 卷三：转

```
情绪曲线：绝望 → 挣扎 → 觉醒 → 反击 → 新危机

事件清单：
□ 事件1：主角最低谷
□ 事件2：转折契机（必须来自主角自己的觉醒）
□ 事件3：真相碎片（逐步揭示，不一次全给）
□ 事件4：主角蜕变
□ 事件5：反击开始

设计要点：
- 最低谷必须够低
- 转折不能靠天降救兵
- 真相碎片要像拼图
```

### 卷四：合

```
情绪曲线：紧张 → 高潮 → 释放 → 余韵

事件清单：
□ 事件1：最终对决准备
□ 事件2：最终对决（必须有意外）
□ 事件3：真相大白（所有伏笔回收）
□ 事件4：结局（主角去向）
□ 事件5：余韵/彩蛋

设计要点：
- 最终对决不能是简单的打败反派
- 所有伏笔必须回收
- 结局要有"余味"
```

## 3.3 卷末钩子6种类型

| 钩子类型 | 模板 | 填充区 |
|---------|------|--------|
| 身份反转 | "你以为的A，其实是B" | _______ |
| 动机反转 | "你以为他要害你，其实在救你" | _______ |
| 时间反转 | "你以为的顺序是错的" | _______ |
| 认知反转 | "你以为的真相是假的" | _______ |
| 关系反转 | "你以为的敌人其实是……" | _______ |
| 规模反转 | "你以为是小，其实是……" | _______ |

**钩子检查表：**
```
□ 是否推翻了读者建立的某个"确定性"？
□ 是否制造了至少2个新悬念？
□ 是否让读者产生"我必须看下一卷"的冲动？
□ 反转是否有伏笔支撑？
□ 反转后是否有情感冲击？
```

| F05 | | | | | |

**伏笔三分类：**
- **明示型**：读者能看到，但不知道重要性
- **暗示型**：读者能隐约感觉到不对劲
- **误导型**：读者以为是A，其实是B（red herring）

**伏笔铁律：**
1. 每个伏笔必须在3卷内回收
2. 回收时读者要有"原来如此"的感觉
3. 误导型伏笔回收后，回看必须觉得"合理"
4. 核心反转必须至少有3处暗示

# 第五部分：盐选长篇专用附加模块

## 5.1 开头2000字黄金法则

| 节点 | 必须完成 | 绝对不能 |
|------|---------|---------|
| 前200字 | 直接抛核心冲突/事件 | 背景介绍/人物简历/环境描写 |
| 前500字 | 展现主角是谁（通过行动） | 简历式描写 |
| 前1000字 | 明确主角动机 | 多视角切换 |
| 前2000字 | 埋第一个悬念 | 慢热铺垫 |

**开头禁忌清单：**
- ❌ 大段背景介绍
- ❌ 人物简历式描写
- ❌ 环境描写超过3句
- ❌ 回忆杀（除非与核心事件直接相关）
- ❌ 多视角切换
- ❌ 慢热铺垫

## 5.2 付费卡点设计

**公式：悬念建立（2章）→ 线索推进（2章）→ 小高潮/反转（1章）→ 卡在更高悬念处（付费）**

| 卡点原则 | 示例 |
|---------|------|
| 卡在悬念最高处 | "门开了，里面竟然是——" |
| 卡在反转前一刻 | "我终于找到了凶手，他是..." |
| 卡在情感高潮 | "她终于说出了当年的真相..." |
| ❌ 不要在平淡处卡 | "第二天早上他起床刷牙" |

## 5.3 爽点/钩子密度标准

- 每章至少1个小爽点/小悬念
- 每3-5章1个中等反转
- 每卷末1个大反转
- 付费卡点必须在情绪最高点

# 第七部分：创意质量检查清单

**灵犀交付的创意方案必须通过以下检查：**

| 维度 | 标准 | 检查方式 |
|------|------|---------|
