## 一、平台概况

| 指标 | 数据 |
|------|------|
| 成立时间 | 2017年 |
| 所属公司 | 七猫（百度系，与纵横中文网同属一个集团） |
| 平台定位 | 正版免费数字阅读 + 原创培育平台 |
| MAU | 超过5,000万（位列数字阅读行业前列） |
| 内容储备 | 8万多部独家长篇 + 近2万部优质短篇，超10万+IP储备 |
| 核心产品 | 七猫免费小说App、七猫中文网 |
| 最新动态 | 2025年成立七猫漫剧，全面拥抱AI漫剧赛道 |

**定位解读：** 七猫是免费阅读赛道的头部玩家，与番茄小说形成"免费双雄"格局。背靠百度生态（手机百度小说为集团分发渠道），拥有强大的流量优势。2025年进军AI漫剧，开放全部10万+IP储备供改编。

## 四、签约规则

### 签约门槛
- 相对宽松，新人友好
- 支持在线投稿，编辑审核

### 签约模式
| 模式 | 说明 |
|------|------|
| 保底签约 | 千字20元起，给钱痛快，适合求稳定收入的作者 |
| 分成签约 | 最高50%分成比例 |
| 保底+超保底分成 | 达到保底后按约定分成 |

### 独家要求
- 签约作品通常为独家授权
- 版权开发权（短剧、影视等）归平台或按比例分成

### 作者福利亮点
- 编辑回复速度快，改稿意见具体
- 给钱痛快——保底模式对新作者吸引力大
- 竞争相对番茄较小，作品质量过硬即可获推荐
- 纵横中文网作者福利与七猫联动：免除15%固定运营成本，参与作品可获得集团平台销售净收益的50%

## 五、收入模式

### 平台收入
- **广告变现**：免费+广告模式，读者阅读时看广告
- **会员订阅**：部分增值服务
- **IP授权**：版权出售、短剧/漫剧改编授权

### 作者收入构成
| 收入来源 | 说明 |
|----------|------|
| 保底稿费 | 千字20元起，稳定可预期 |
| 广告分成 | 按读者广告曝光量分成，最高50% |
| 版权分成 | 短剧/影视/IP授权分成 |
| 全勤奖 | 日更达标可获额外奖励 |

### 收入水平
- 保底作者：月入3,000-15,000元（取决于保底等级）
- 分成作者：月入2,000-50,000元（取决于作品数据）
- 头部作者：月入10万+

## 六、作者生态

| 层级 | 占比 | 特征 |
|------|------|------|
| 头部（月入10万+） | ~3% | 百万字长篇、粉丝基础稳固 |
| 中层（月入1-10万） | ~20% | 稳定日更、有一定读者群 |
| 新人/底层 | ~77% | 试水阶段、保底保障基础收入 |

**生态特点：**
- 保底模式降低了新人创作风险，是"最不怕扑街"的平台
- 编辑互动积极，对新人成长有帮助
- 与纵横中文网共享作者资源
- 相比番茄小说，竞争烈度略低，推荐机制更公平

## 七、IP 变现路径

```
七猫IP → 免费连载 → 人气积累 → 短剧改编 → 漫剧改编 → 影视/出版
```

| 路径 | 进展 |
|------|------|
| 短剧改编 | 2025年超6,700部网文进入短剧改编流程，七猫IP在其中占一定比例 |
| AI漫剧 | 2025年成立七猫漫剧，10万+IP全部开放改编权 |
| 影视授权 | 部分头部作品已售出影视版权 |
| 有声书 | 平台内有声化内容 |
| 出版 | 少数精品作品出版 |

**IP优势：** 超10万部IP储备是七猫最大的资产。2025年成立漫剧公司后，IP变现链路从"版权出售"升级为"自主开发"，价值大幅提升。

## 八、2026 年趋势与挑战

### 趋势
1. **AI漫剧是最大增量**：七猫漫剧+10万IP储备=天然的漫剧内容工厂
2. **保底模式升级**：更多灵活的收入保障方式
3. **百度生态协同**：手机百度小说为七猫导流，搜索+阅读一体化
4. **免费→付费混合**：部分精品内容尝试付费墙

### 挑战
1. **番茄压制**：番茄小说月活超2亿，七猫5,000万MAU差距明显
2. **广告单价下降**：宏观经济压力下广告主预算收紧
3. **人才争夺**：头部作者被阅文、番茄高价挖角
4. **内容同质化**：免费平台爽文模板化严重
5. **AI内容冲击**：AI生成小说对人工创作的冲击

## 九、新人作者建议

### 适合类型
- ✅ 想拿稳定收入的作者（保底模式）
- ✅ 擅长长篇爽文的写手
- ✅ 玄幻/都市/系统流创作者
- ✅ 不想面对激烈竞争的新人

### 冷启动策略
1. **先拿保底**——千字20元保底降低试错成本
2. **日更不断更**——免费平台推荐算法极度依赖更新频率
3. **前10万字是关键**——决定能否获得持续推荐
4. **研究平台榜单**——拆解Top作品的套路和节奏
5. **善用编辑反馈**——七猫编辑回复快、意见具体，这是优势
6. **关注漫剧机会**——作品数据好可能被选中改编漫剧
7. **保底转分成**——数据好的作品可申请转分成模式，收入上限更高

### 避坑指南
- ❌ 不要断更（免费平台断更=流量归零）
- ❌ 不要写太短（百万字以上是常态）
- ❌ 不要忽视读者评论（互动数据影响推荐）
- ❌ 不要同时多平台发布（独家签约收益更高）

## 十、平台竞争力评估

| 维度 | 评分 | 说明 |
|------|------|------|
| 收入确定性 | ★★★★☆ | 保底模式稳定可靠 |
| 新人友好度 | ★★★★★ | 门槛低、编辑积极、保底保障 |
| IP变现能力 | ★★★★☆ | 10万+IP储备+漫剧公司 |
| 创作自由度 | ★★★☆☆ | 爽文为主，题材受限 |
| 平台稳定性 | ★★★★☆ | 百度系背书，但MAU落后番茄 |
| 综合推荐指数 | ★★★★☆ | 新人保底首选，稳定可靠 |

> **望舒判断：** 七猫最大的优势是"给钱痛快"。对于追求稳定收入的新人，保底千字20元起步意味着第一月就能拿到钱，不像番茄要等首秀数据。2025年成立漫剧公司后，七猫的IP变现链路更完整了。但要注意：保底虽稳，分成才是大头——作品数据好一定要转分成。
