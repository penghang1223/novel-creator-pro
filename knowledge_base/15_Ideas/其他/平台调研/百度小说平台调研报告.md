## 一、平台概况

| 指标 | 数据 |
|------|------|
| 成立时间 | 依托百度搜索生态，具体上线时间不详 |
| 所属公司 | 百度（与七猫小说同属一个集团） |
| 平台定位 | 免费阅读 + 搜索分发 |
| 核心产品 | 手机百度小说（百度App内嵌）、百度小说频道 |
| 集团协同 | 与七猫小说共享内容库和作者福利 |
| 分发渠道 | 百度搜索入口（月活超6亿） |

**定位解读：** 百度小说不是一个独立的"创作平台"，而是**百度生态内的小说分发渠道**。它与七猫小说（纵横集团）深度协同——内容来自七猫，通过百度搜索和百度App分发。对作者来说，百度小说是"额外分发渠道"，作品在七猫签约后自动同步至百度小说。

## 四、签约规则

### 百度小说本身不直接签约
- 百度小说是**分发渠道**，不是创作平台
- 作者通过七猫中文网或纵横中文网签约
- 签约后作品自动同步至百度小说

### 通过七猫/纵横签约的福利
| 福利 | 说明 |
|------|------|
| 免除15%固定运营成本 | 纵横中文网作者福利特别条款 |
| 集团平台50%分成 | 七猫小说+百度小说产生的销售净收益50%给作者 |
| 保底千字20元起 | 通过七猫签约的保底模式 |

### 独家要求
- 签约作品在集团平台（七猫小说+百度小说）独家分发
- 版权开发权按合同约定

## 五、收入模式

### 平台收入
- **广告变现**：免费+广告模式
- **搜索导流**：百度搜索入口带来的流量变现

### 作者收入
| 收入来源 | 说明 |
|----------|------|
| 广告分成 | 百度小说产生的广告收入按比例分成 |
| 销售分成 | 签约作品在百度小说产生的销售净收益50%分成 |
| 保底稿费 | 通过七猫签约的保底收入 |

### 收入特点
- 百度小说作为分发渠道，为作者带来"额外收入"
- 分成通过七猫/纵横统一结算，作者无需单独处理
- 百度搜索的长尾流量效应显著——老作品持续获得曝光

## 六、作者生态

| 说明 | 详情 |
|------|------|
| 创作入口 | 七猫中文网 / 纵横中文网 |
| 分发出口 | 百度小说 + 七猫App + 其他渠道 |
| 结算方式 | 通过七猫/纵横统一结算 |
| 作者感知 | 大部分作者甚至不知道百度小说的存在（后台自动同步） |

**生态特点：**
- 百度小说的价值在于"搜索长尾流量"
- 百度搜索是网文发现的重要入口（尤其对非网文核心用户）
- 作者无需额外操作，签约即自动分发
- 百度AI搜索可能成为未来的新分发方式

## 七、IP 变现路径

```
七猫签约 → 百度小说同步 → 搜索长尾流量 → 读者积累 → 短剧/漫剧改编
```

| 路径 | 说明 |
|------|------|
| 百度搜索导流 | 用户搜索小说名→直达百度小说→阅读 |
| 七猫漫剧 | 七猫IP改编AI漫剧，百度系分发 |
| 短剧改编 | 通过集团内容生态进入短剧流程 |

**IP价值：** 百度小说的IP价值主要体现在搜索发现带来的长尾流量积累，为后续的短剧/漫剧改编提供数据支撑。

## 八、2026 年趋势与挑战

### 趋势
1. **AI搜索整合**：百度文心一言+搜索，智能推荐小说内容
2. **集团协同深化**：七猫+百度小说+纵横的内容一体化
3. **搜索+阅读闭环**：从搜索到阅读的一站式体验优化
4. **AI漫剧分发**：七猫漫剧内容在百度系全面分发

### 挑战
1. **入口依赖**：过度依赖百度搜索入口，独立App影响力不足
2. **内容同质化**：与七猫完全共享内容库，缺乏差异化
3. **品牌认知弱**：用户更多记住"七猫"而非"百度小说"
4. **短视频分流**：抖音/快手抢走大量碎片化阅读时间
5. **AI生成内容**：AI小说对搜索结果的冲击

## 九、新人作者建议

### 适合类型
- ⚠️ 百度小说不是首发创作平台
- ✅ 通过七猫/纵横签约后自动同步，无需额外操作
- ✅ 作品完成后，百度搜索会带来长尾流量

### 策略建议
1. **选择七猫或纵横签约**——签约即自动同步至百度小说
2. **关注搜索关键词**——优化小说标题和简介，提升搜索排名
3. **利用百度生态**——百度贴吧、百度知道等可辅助推广
4. **不必单独运营**——百度小说是"被动收入"渠道

### 避坑指南
- ❌ 不要单独为百度小说创作（它不是创作平台）
- ❌ 不要忽视百度搜索SEO——标题和简介影响搜索排名
- ❌ 不要以为"百度小说"是独立平台——它只是分发渠道
