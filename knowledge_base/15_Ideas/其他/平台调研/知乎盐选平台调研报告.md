> 调研时间：2026-05-01 | 执行者：望舒 (PM Luna) 🌙

## 一、平台概况

| 指标 | 数据 |
|------|------|
| 成立时间 | 2019年（盐选专栏正式上线） |
| 所属公司 | 知乎（NYSE: ZH / 港股：2390） |
| 平台定位 | 付费短篇故事平台，2-5万字中短篇主场 |
| 母公司MAU | 知乎全站MAU约1.2亿（2025Q3） |
| 盐选会员数 | ~1,500万月付费会员（2024年底） |
| 投稿作者 | 2024年超60万投稿作者 |
| 内容品牌 | 「盐言故事」 |

**定位解读：** 知乎盐选是网文行业短篇赛道的开创者和领跑者。与番茄小说（免费长篇）、起点中文网（付费长篇）形成差异化定位——**"千字一高潮"的短篇付费阅读**。盐选故事业务支撑了知乎付费会员收入的49%（2024年Q1达57.27%），是知乎营收支柱。

## 四、签约规则

### 投稿门槛
- 最低字数：1万字起（2023年起执行）
- 最佳字数：2-5万字
- 投稿方式：通过知乎创作服务平台投稿
- 审核周期：通常1-4周

### 签约模式
| 模式 | 说明 |
|------|------|
| 会员分成 | 新人默认50%分成，无隐藏扣费 |
| 制作人模式 | 资深作者可作为制作人签约，流程较长 |
| 保底+分成 | 部分优质作品可获保底预付+分成 |

### 独家要求
- 盐选签约通常为独家授权
- 版权方保留部分衍生权利（需协商）
- 数百部盐言故事IP已售出影视版权

## 五、收入模式

### 平台收入结构
- **会员订阅**：盐选会员月费19元，是知乎营收支柱
- **广告收入**：知乎社区广告
- **IP授权**：故事版权出售

### 作者收入构成
| 收入来源 | 说明 |
|----------|------|
| 会员分成 | 核心收入——盐选会员阅读作品，平台从会员费中50%分成 |
| 保底预付 | 优质作品可获得千字20-200元不等的保底 |
| 爆款奖励 | 数据优异作品额外激励 |
| IP版权 | 影视/出版授权分成 |

### 作者收入水平
- 新人短篇：单篇稿费5,000-20,000元
- 成熟作者：月入5,000-50,000元
- 爆款作者：单篇稿费可达7-8万元
- 头部作者：月入10万+

## 六、作者生态

| 层级 | 占比 | 特征 |
|------|------|------|
| 头部（月入10万+） | ~2% | 多部爆款IP、有粉丝基础 |
| 中层（月入1-10万） | ~15% | 稳定产出、有一定读者群 |
| 新人/底层 | ~83% | 投稿试水、单篇收入不稳定 |

**生态特点：**
- 2024年投稿作者超60万，竞争激烈
- 短篇创作周期短（1-4周/篇），适合快速试错
- 大量作者来自传统网文平台的"降维打击"
- 小红书是盐选作者引流和课程销售的重要阵地

**核心挑战：** 知乎问答社区土壤"失活"风险（36氪2025年7月报道），短篇作者规模需持续扩大，目前仍依赖原平台输血。

## 七、IP 变现路径

```
盐选故事 → 影视改编 → 出版 → 有声书 → 短剧 → AI漫剧
```

| 路径 | 进展 |
|------|------|
| 影视改编 | 数百部盐言故事IP售出影视版权 |
| 出版 | 《洗铅华》入选中国网络文学影响力榜 |
| 短剧 | 盐选IP进入短剧改编流程 |
| AI漫剧 | 2026年新赛道，盐选IP天然适配（短篇→短集漫剧） |
| 有声书 | 知乎站内音频化 |

**IP优势：** 短篇故事天然适合改编为短剧和AI漫剧，改编成本低、周期短、试错风险小。2026年AI漫剧350-500亿增量市场，盐选IP是优质内容源头。

## 八、2026 年趋势与挑战

### 趋势
1. **AI漫剧改编风口**：盐选短篇天然适配漫剧（1-3集），是2026年最确定的增量
2. **IP全链路开发**：从盐选→短剧→长剧→电影的IP孵化链路
3. **制作人模式升级**：资深作者角色从创作者→制作人
4. **AI辅助创作**：AI辅助大纲生成、情节优化等工具逐步渗透

### 挑战
1. **社区土壤失活**：知乎问答社区价值消解，内容生产土壤面临风险
2. **竞争加剧**：番茄、七猫等纷纷试水短篇模式
3. **制作人流程拖沓**：审核结果与个人偏好挂钩，效率待提升
4. **会员增长放缓**：知乎MAU增长趋缓，盐选会员增速承压
5. **同质化**：大量悬疑反转模板化，读者审美疲劳

## 九、新人作者建议

### 适合类型
- ✅ 擅长短篇（2-5万字）的创作者
- ✅ 悬疑推理、现实情感类写手
- ✅ 第一人称叙事能力强的作者
- ✅ 有公众号/知乎问答写作经验的人

### 冷启动策略
1. **第一人称 + 悬疑反转 = 过稿密码**
2. **前3章决定生死**——开头必须有钩子（冲突/悬念/反转）
3. **千字一高潮**——每1000字至少一个信息增量
4. **先在知乎问答区试水**——用高质量回答积累粉丝，再导入盐选
5. **研究榜单作品**——拆解Top 10盐选作品的结构、节奏、反转点
6. **利用小红书引流**——分享写作心得吸引读者关注
7. **快速试错**——短篇周期短，1个月写2-3篇测试市场反馈

### 避坑指南
- ❌ 不要写太长（超8万字完读率骤降）
- ❌ 不要慢热（知乎读者耐心极差）
- ❌ 不要抄袭（平台审核严格，一次封杀）
- ❌ 不要忽视数据（完读率是核心指标）
