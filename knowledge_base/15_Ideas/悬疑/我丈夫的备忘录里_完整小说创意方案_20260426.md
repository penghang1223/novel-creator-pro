# 一、故事大纲

## 1.1 核心设定

**一句话故事：**
我翻开了丈夫的手机备忘录——里面记录了"另一个我"的所有生活习惯。但我才是他的妻子。

**核心悬念：**
备忘录里的"她"是谁？丈夫出轨了？还是……有比出轨更可怕的真相？

**叙事风格：**
第一人称"我"叙述（知乎盐选标志性风格）。开头50字直接进冲突。几百字一个反转。

**社会议题：**
- 亲密关系中的信息不对称
- "你了解你的枕边人吗"
- 记忆与身份的可信度
- 中国式婚姻的"不说"文化

## 1.2 主线剧情（起承转合）

### 起（1-5章）：发现
沈念无意中翻开了丈夫顾言的手机备忘录。里面有一个加密文件夹，密码是她的生日。文件夹里有30条记录，标题从"Day 1"到"Day 30"。最后一条的日期——是他们婚礼的那天。标题是："如果她想起来了，我该怎么办？"

### 承（6-12章）：追查
沈念开始调查。她发现顾言一年前就认识她了——但他们"相识"只有8个月。她找到顾言的心理医生——医生说他一年前就开始治疗。她找到前同事——前同事说"你变了"。

### 转（13-18章）：真相
第一层反转：不是出轨——"她"是一个已经死去的女人。
第二层反转：那个女人是顾言的前妻——而"我"是整容成前妻的样子嫁给了他。
第三层反转（终极）：不是"我"整容——是顾言在"我"身上寻找前妻的影子，而"我"从一开始就知道。

### 合（19-22章）：选择
沈念面临选择：继续做"沈念"，还是做回"苏晚"？她选择了"两个都是我"。

# 二、人物设定

## 2.1 女主

```markdown
## 沈念/苏晚（女，27岁）
- 身份：自由插画师
- 外貌：①右耳有细小疤痕 ②咬下唇 ③笑起来有酒窝
- 性格：敏感、观察力强、讨好型人格
- 核心动机：搞清楚自己是谁
- 核心恐惧：遗忘——"如果我连自己都记不起来，那我还是我吗？"
- 核心渴望：被真实地爱
```

## 2.2 男主

```markdown
## 顾言（男，30岁）
- 身份：沈念的未婚夫
- 外貌：①温和型 ②眼神深邃 ③笑起来有泪沟
- 性格：温柔但有秘密，用"保护"的方式"欺骗"
- 核心动机：保护沈念（苏晚）不让她想起痛苦的真相
- 核心恐惧：再次失去爱的人
- 核心渴望：被原谅
```

# 三、分章规划

## 3.1 全文结构（3-5万字，22章）

| 阶段 | 章节 | 核心事件 | 反转 |
|------|------|---------|------|
| 起（发现） | 1-5 | 发现备忘录→开始怀疑 | 相识时间对不上 |
| 承（追查） | 6-12 | 找闺蜜/医生/警察→发现更多异常 | 失忆的是顾言 |
| 转（真相） | 13-18 | 安宁医院→两个女孩的故事 | 苏晚以沈念身份活下去 |
| 合（选择） | 19-22 | 重逢→选择→第二次初见 | 两个都是我 |

## 3.2 逐章细纲（前10章）

### 第1章：备忘录
顾言洗澡时，手机亮了。备忘录提醒："Day 14：她找到了那张照片。"今天是Day 14。我确实刚找到一张照片。我输入密码——我的生日。开了。30条记录。最后一条："如果她想起来了，我该怎么办？"
**钩子**：我的手开始发抖。

### 第2章：时间对不上
"Day 1"的日期是一年前。但我们"相识"只有8个月。我翻到"Day 1"的内容："她今天来医院了。她叫我'顾医生'。她不记得我了。"
**钩子**：顾言不是医生。他是做金融的。

### 第3章：监控？
每一条记录都对应我最近的行为。"Day 7：她问了车祸的事。我撒了谎。"——我确实问了。"Day 10：她翻了我的书房。"——我确实翻了。
**钩子**：他在监控我？

### 第4章：车祸
我回忆一年前的车祸——我的记忆只从"醒来"开始。顾言告诉我：是他救了我。我找到车祸报告——上面有一个被涂掉的名字。
**钩子**：谁涂掉了那个名字？

### 第5章：闺蜜
我找林夏问车祸的事。她回避了。"有些事，不知道更好。"——和顾言一样的话。
**钩子**：林夏听到"备忘录"后脸色大变。

### 第6章：书房
我趁顾言不在，打开书房上锁的抽屉。里面有一张我和顾言的合影——日期是一年前。照片背后写着："对不起。"
**钩子**：我们一年前就认识？

### 第7章：陈医生
我找陈医生问记忆恢复的事。他说"你的记忆可能永远无法恢复"。但他的眼神在说谎。
**钩子**：陈医生的桌上有一本病历——名字是"顾言"。

### 第8章：备忘录最后
我翻到备忘录最后一条："Day 30：婚礼。如果她想起来了，我该怎么办？"
**钩子**：婚礼是下个月。Day 30就是婚礼那天。

### 第9章：心理评估
在抽屉最深处，我找到一份心理评估报告。被评估的人不是我是顾言。诊断：解离性遗忘症。
**钩子**：失忆的不是我——是他？

### 第10章：反转
顾言回来了。我对峙。他哭了。"我一直在等你想起来。"
**钩子**："想起来"什么？

# 六、写作SOP

## 6.1 开头技巧（盐选铁律）
- **前50字必须有冲突**：不能背景介绍/人物描写/环境描写
- **直接进场景**：不要"我叫沈念，今年27岁……"
- **第一句就是钩子**："我丈夫的备忘录里，有另一个我。"

## 6.2 反转节奏
- 每章至少1个反转/悬念
- 每3章一个中等反转
- 每5章一个大反转
- 卷末（第12/18章）必须有终极反转

## 6.3 盐选过稿要点
- [ ] 第一人称"我"叙述
- [ ] 开头50字直接进冲突
- [ ] 几百字一个反转
- [ ] 短句为主（每段不超过5行）
- [ ] 不光爽文（需要情感深度）
- [ ] 不写耽美/同人/擦边
- [ ] 正文人工写（AI只辅助大纲）

## 6.4 完读率优化
- 每章前300字：冲突/悬念
- 每章中间：推进剧情+小反转
- 每章结尾：钩子（让读者忍不住点下一章）
- 付费卡点：第8章末尾（发现心理评估报告）
