## 一、一句话故事

> 母亲去世后，女儿在遗物中发现一本不属于母亲的日记——里面记录着一个被调换的人生，以及一桩跨越两代人、牵扯整座城市的秘密。

## 二、世界观设计（五维模型填充）

### 2.1 时空

| 维度 | 内容 |
|------|------|
| **时代** | 双线叙事：**现在线 2024年**（主线）+ **过去线 1998-2003年**（暗线回溯） |
| **核心空间** | 深圳某中产社区"云庭花园"——2005年建成的封闭式小区，表面光鲜，内里藏着两代人的秘密 |
| **辅助空间** | 旧城区（待拆迁的城中村）、市妇幼保健院（1998年婴儿调换发生地）、区档案馆（关键文件藏身处） |
| **空间隐喻** | "云庭花园" = 表面云端花园，底下是填平的坟地。小区建在旧殡仪馆原址上，开发商刻意抹去了这段历史 |

### 2.2 规则

| 类型 | 内容 |
|------|------|
| **明规则** | 户籍管理制度、医院新生儿登记流程、房产交易程序、遗产继承法——主角必须通过这些"合法渠道"追查，每一步都被制度卡住 |
| **潜规则** | "人情社会"的运作逻辑：邻居互相包庇、物业帮忙"处理"麻烦、老领导一句话能调档案、"家丑不可外扬"的家族默契 |
| **冲突点** | 主角想按明规则办事（报警、查档案、走法律程序），但每次都被潜规则挡回来——**制度是透明的墙，你看得见，穿不过去** |

### 2.3 权力

| 层级 | 掌握者 | 被压迫者 |
|------|--------|---------|
| **顶层** | 开发商周家（云庭花园的建造者）、当年的医院院长 | 被调换婴儿的亲生家庭、拆迁户 |
| **中层** | 物业主任、社区书记、主角的公公（区住建局退休干部） | 普通业主、外来租户 |
| **底层** | 保洁阿姨（知道最多但没人听）、当年被辞退的护士 | 所有"没有话语权"的人 |
| **信息差核心** | **谁掌握了1998年妇幼保健院的原始登记册，谁就掌握了所有人的命脉** |

### 2.4 禁忌

| 禁忌 | 触碰后果 | 剧情作用 |
|------|---------|---------|
| **不要追问孩子的来历** | 会被家族视为"不懂事"，被孤立 | 主角的追问成为推动力 |
| **不要翻旧账（尤其是拆迁和土地的事）** | 会触动开发商的利益链 | 暗线核心 |
| **家丑不可外扬** | 婆婆的终极武器——"你要是说出去，这个家就散了" | 情感施压 |

### 2.5 例外（主角凭什么打破规则）

- **专业优势**：主角是数据分析师/前调查记者，擅长从碎片信息中拼出真相
- **身份优势**：她既是"家里的人"（能接触到家庭内部信息），又是"外人"（被调换的，不属于这个家族的血缘）——这个双重身份让她能看到局内人看不到的东西
- **信息优势**：她意外获得的那本日记，是唯一一本没有被销毁的原始记录

## 三、异质设计（反常细节引发连锁反应）

> **异质 = 一个"不该存在"的东西出现在"不该出现"的地方**

### 核心异质物：一本不存在的日记

- **发现方式**：母亲去世后，主角整理遗物时在一个旧月饼铁盒里发现一本粉色封面的日记
- **反常之处**：
  1. 母亲从不写日记（性格不是这种人）
  2. 日记的笔迹是母亲的，但语气不像她
  3. 日记从1998年6月开始写，到1999年3月戛然而止——正好是主角的出生月份
  4. 最后一页只有一句话：**"对不起，我把你的孩子换了。但我会爱她的。"**

- **连锁反应**：
  1. 主角开始怀疑自己的身份 →
  2. 查出生证明发现编号对不上 →
  3. 找当年医院发现科室已撤销 →
  4. 查档案发现1998年该院有一批新生儿登记"遗失" →
  5. 发现同期还有3个家庭也在找"不对劲"的孩子 →
  6. 所有这些孩子的出生都指向同一个医生和同一个开发商的利益链

## 四、人物设计

### 4.1 主角（MACH 模型）

#### 沈知夏（35岁，女）

**基本信息**
- 年龄/性别/职业：35岁，女，数据分析师（前调查记者）
- 一句话人设：**"用数据追查真相的女人，却发现最大的数据漏洞是自己的人生"**

#### M - Motivation 动机

| 层级 | 内容 |
|------|------|
| **表层动机** | 查明自己的真实身世——"我到底是谁的孩子？" |
| **深层动机** | 确认自己是否"被爱过"——如果连身份都是假的，那母亲（养母）对她的爱是真的吗？ |
| **核心恐惧** | 发现自己从头到尾都是一个"错误"，没有人真正想要她 |
| **矛盾点** | 她越是追查真相，越可能摧毁现有的家庭关系——"知道真相"和"保住家庭"只能选一个 |

#### A - Ability 能力

| 类型 | 内容 |
|------|------|
| **硬技能** | 数据分析能力极强（能从海量信息中发现模式）；前调查记者，擅长暗访和交叉验证 |
| **软技能** | 直觉敏锐，善于观察人（记者生涯练出来的）；有韧性，不达目的不罢休 |
| **能力边界** | 不擅长处理亲密关系中的情感冲突（习惯用理性解决问题）；面对养母的"情感牌"容易心软 |
| **能力代价** | 过度理性 → 在需要感性共情的时候会显得冷漠，伤害身边人 |

#### C - Crack 缺陷

| 类型 | 内容 |
|------|------|
| **性格缺陷** | 控制欲强——习惯了用数据和逻辑掌控局面，面对无法量化的情感问题就失控 |
| **认知盲区** | 她认为"真相高于一切"，但没有意识到对某些人来说，"谎言"才是活下去的方式 |
| **情感创伤** | 12岁时曾无意中听到婆婆（养母）和邻居聊天，对方说"这孩子不像你们家的"，婆婆立刻岔开了话题——这句话在她心里埋了23年的刺 |

#### H - Hero's Arc 成长弧光

| 阶段 | 内容 |
|------|------|
| **起点状态** | "我要找到真相，真相能解决一切"——理性、冷硬、把所有人都当成"信息来源" |
| **转折点1** | 发现养母日记后第一次崩溃——"她写了'对不起'，但也写了'我会爱她的'。所以她知道。她一直都知道。" |
| **转折点2** | 找到亲生母亲后，发现对方早就放弃了她——"我不要你回来，我现在的生活很好。" |
| **终点状态** | "真相不是万能的。但选择不撒谎，是我唯一能做的事。"——从追求"真相"转向追求"真实"，接受不完美的答案 |
| **弧光类型** | ✅ 正向弧光（从"非黑即白"到"接受灰色"） |

#### 细节标注
- **外貌特征**：齐肩短发（干练），左耳三颗耳钉（大学时叛逆的遗迹），笑起来右脸有单边酒窝
- **口头禅**："让我想想"（思考时的缓冲词）
- **习惯动作**：紧张时会无意识地转左手无名指上的戒指（结婚戒指，但她很少戴）
- **标志性物品**：一台旧笔记本电脑（前记者时期用的，里面存着未发表的调查稿）
- **反差萌**：外表冷硬但极其怕黑，睡觉必须开小夜灯

| **对主角的作用** | 情感锚点 + 最大阻力。她知道真相但选择隐瞒，主角追查的每一条线索都要经过她这道"门" |
| **高光时刻** | 第18章，她终于开口说出1998年的完整经过——不是因为被揭穿，而是因为"我不想你带着恨活一辈子" |

### 4.3 反派设计（3R 模型）

#### 中层反派：周世雄（68岁，开发商/前医院院长侄子）

| 维度 | 内容 |
|------|------|
| **表层身份** | 云庭花园开发商、社区"慈善家"、捐建了社区图书馆 |
| **真实身份** | 1998年婴儿调换案的幕后策划者之一 |
| **核心动机** | 1998年，他的家族（周家）需要"延续香火"——他嫂子生不出男孩，于是他安排了调换。后来发现不止一家有这种需求，他把这变成了一门"生意"——帮有钱有势的家庭"定制"孩子 |
| **合理性** | 在他眼里这不是犯罪——"我帮了那些想要孩子的人。那些被换走的孩子也去了好人家。没有人受到伤害。" |
| **碾压主角的2项** | ① 财富和影响力（能摆平大部分调查）② 时间优势（他准备了25年，所有证据都销毁了）|
| **致命弱点1项** | 过度自信——他以为所有参与者的嘴都封住了，但他忽略了"最底层的人"（清洁工赵小满）|
| **反转空间** | 第32章揭示：他当年调换的不仅是婴儿，还有"身份"——他自己的亲生女儿也在被调换之列，他养了25年的"儿子"其实是别人的孩子 |
| **第一次正面交锋** | 第15章，在社区活动中"偶遇"主角，言语试探 |
| **真面目暴露** | 第28章，周明宇的5年调查材料被公开 |
| **结局** | 不是被法律制裁（证据不足），而是在家族内部被"抛弃"——他养了25年的"儿子"拒绝认他。他失去了一切"合法"的东西 |
| **读者情感** | 愤怒 → 震惊 → 讽刺式的满足 |

#### 终极反派：制度性沉默

> **这不是一个人，而是一种"系统"。**

| 维度 | 内容 |
|------|------|
| **本质** | 1998-2003年间，市妇幼保健院内部形成的一条"灰色产业链"——新生儿调换、户口伪造、档案篡改，涉及医生、护士、户籍警、社区干部等数十人 |
| **为什么是反派** | 因为它不是一个可以被打败的"坏人"，而是一张网——你剪断一根线，整张网还在 |
| **对主角的终极挑战** | 她最终会发现：即使找到了所有证据，法律也无法惩罚所有人（追诉期已过、关键人物已死、证据链不完整）|
| **最终结局** | 主角的选择：不能把所有人送进监狱，但她可以做一件事——**把真相公之于众**。小说结尾，她写了一篇长文（呼应她前记者的身份），发布后引发社会震动 |
| **主题升华** | "正义不一定意味着惩罚。有时候，正义意味着不再沉默。" |

## 五、分卷大纲（5卷结构）

### 总体情绪曲线


## 八、开篇设计建议

### 8.1 第1句话要求

> **必须有冲突/悬念/反常识**

#### 方案A（推荐）
> **"我妈死后的第三天，我在她装了35年的月饼盒里，找到了一本她从没写过的日记。"**

- ✅ 冲突：母亲去世 + 遗物中的异常
- ✅ 悬念：从没写过的日记为什么会出现？
- ✅ 反常识：一个人不会写日记，但遗物中出现了她的日记

#### 方案B
> **"日记的最后一页写着：'对不起，我把你的孩子换了。但我会爱她的。'——而我，叫了35年她'妈妈'。"**

- ✅ 冲突：直接把最大悬念抛出
- ✅ 情绪冲击极强
- ⚠️ 风险：过早暴露核心悬念，后续需要更多层次的悬念支撑

#### 方案C
> **"1998年6月14日，市妇幼保健院的37个新生儿中，有7个人的腕带在深夜被更换了。这件事没有任何人记录——除了一个不该存在的日记。"**

- ✅ 社会派悬疑感最强
- ✅ 格局感大
- ⚠️ 风险：不像"家庭伦理"的开篇，更像新闻调查

**臣推荐方案A**——它同时具备家庭情感（母亲去世）+ 悬疑（异常日记）+ 个人视角（第一人称），最契合"社会派悬疑 × 家庭伦理"的调性。

### 8.2 前500字必须完成"人物+处境+矛盾"

**人物**：35岁女性，刚失去母亲
**处境**：整理遗物时发现异常
**矛盾**：日记内容威胁到她对自己身份的全部认知

> 我妈死后的第三天，我在她装了35年的月饼盒里，找到了一本她从没写过的日记。
>
> 粉色的封面，塑料膜已经泛黄。打开第一页，是她的字——我认得，每年春节对联都是她写的。
>
> 但内容不是她的。或者说，语气不是她的。我妈说话直来直去，从来不绕弯子。但这本日记的字里行间，全是犹豫和躲闪。
>
> 1998年6月14日。第一页只写了这一行日期。
>
> 我翻到最后一页。
>
> **"对不起，我把你的孩子换了。但我会爱她的。"**
>
> 最后一页的日期是1999年3月8日。
>
> 我的生日是1999年3月15日。
>
> 我的手开始抖。

（~280字，已完成人物+处境+矛盾。后续220字补充：主角试图理性分析，但心跳加速；她翻回前面，看到日记中反复出现"医院""婴儿""深夜""周医生"等关键词——她开始怀疑自己的人生。）

### 8.3 前2000字必须明确"这个故事关于什么"

**核心命题**：当你发现你的人生是一个谎言——你还要不要追查真相？追查的代价是什么？

前2000字的叙事路径：
1. **0-500字**：发现日记，建立悬念
2. **500-1000字**：初步分析——日记的内容涉及医院、婴儿、调换，日期和自己的生日高度相关
3. **1000-1500字**：主角试图"理性处理"——查自己的出生证明、上户口记录，发现编号异常
4. **1500-2000字**：第一次正面接触"阻力"——问养母（此时还活着/或通过回忆），养母的反应异常——"有些东西，不知道比知道好。"

**2000字结束时读者必须知道的事：**
- 主角的身世可能不是她以为的那样
- 有人（养母）知道真相但不想说
- 主角决定查下去
- 这个故事关于"身份""真相"和"爱的代价"

## 九、投稿策略建议

### 9.1 样稿策略

| 项目 | 建议 |
|------|------|
| **样稿字数** | 3万字 = 卷一全8章 |
| **样稿范围** | Ch1-Ch8（从发现日记到卷末钩子"你妈妈不是自愿的"） |
| **为什么选卷一** | 卷一独立性强，有完整的悬念弧线；卷末钩子足够强，编辑看完一定会问"后来呢？" |

### 9.2 大纲提交材料

| 材料 | 内容 | 字数 |
|------|------|------|
| 一句话故事 | 见上文 | ~50字 |
| 故事简介 | 300-500字概述 | ~400字 |
| 人物小传 | 主角+5配角+2反派，每人100-200字 | ~1500字 |
| 分卷大纲 | 本文档第五部分精简版 | ~3000字 |
| 核心卖点 | 差异化分析（vs 竞品） | ~500字 |

### 9.3 核心卖点（差异化）

| 维度 | 竞品做法 | 本文做法 |
|------|---------|---------|
| **悬疑核心** | 谁是凶手？ | 我是谁？（从"外"转"内"） |
| **家庭伦理** | 婆媳矛盾/婚姻危机 | 身份认同+养育之恩vs血缘之恩 |
| **反派** | 单一大恶人 | 制度性沉默（无法被打败的"系统"） |
| **结局** | 善恶有报 | 不完美的正义（公开但不惩罚） |
| **情感内核** | "真相大白，一家团圆" | "真相不完美，但选择不沉默" |
