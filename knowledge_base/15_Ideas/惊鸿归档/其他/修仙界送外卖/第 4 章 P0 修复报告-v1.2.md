## 三、修复详情

### 修复项 1：魔教令牌来源

**问题描述**：
- 第 4 章开头未提及魔教令牌（圣女令）
- 第 3 章中苏清雪（血煞坛主）赠送了魔教令牌给林小凡
- 需要补充该道具，并明确来源

**修复前**：
```markdown
他盘腿坐在简陋的木床上，面前摆着两样东西：一块碧绿的传讯玉佩，十张金色的好评卡。

玉佩上"清雪"二字在晨光中泛着温润的光泽。
```

**修复后**：
```markdown
他盘腿坐在简陋的木床上，面前摆着三样东西：一块碧绿的传讯玉佩，一枚漆黑的魔教令牌，十张金色的好评卡。

玉佩上"清雪"二字在晨光中泛着温润的光泽。

令牌上刻着"血煞"二字，边角还沾着些许血迹——这是血煞坛主苏清雪所赠，她说关键时刻能保命。
```

**配套修改**：
```markdown
原句：
他站起身，将玉佩贴身收好，十张好评卡放进外卖箱的夹层里。

修改为：
他站起身，将玉佩贴身收好，魔教令牌放进内袋，十张好评卡放进外卖箱的夹层里。
```

**修改理由**：
- 与第 3 章情节保持一致（苏清雪赠送圣女令）
- 明确魔教令牌来源为"血煞坛主苏清雪"，不是王掌柜
- 为后续章节使用令牌埋下伏笔
- 增强道具系统的完整性

**影响范围**：
- 第一节开场道具描述
- 后续章节可调用魔教令牌道具

### 修复项 2：好评/抹杀机制描述

**问题描述**：
- 第 3 章结束后，系统已判定"抹杀倒计时已暂停"
- 第 4 章中林小凡说"两个差评，我就会被抹杀"与当前状态矛盾
- 需要修改为过去式或强调"危机已暂停"

**修复前**：
```markdown
"两个差评？"林小凡逼近一步，"你知道这两个差评对我意味着什么吗？按照系统规则，两个差评，我就会被抹杀！你这是在杀人！"
```

**修复后**：
```markdown
"两个差评？"林小凡逼近一步，"你知道这两个差评对我意味着什么吗？按照系统规则，两个差评就会触发抹杀机制！要不是系统判定危机暂停，老子现在已经死了！你这是在杀人！"
```

**修改理由**：
- 与第 3 章结尾系统状态保持一致（"抹杀倒计时已暂停"）
- 强调"危机已暂停"而非"正在面临抹杀"
- 保持人设一致性（林小凡嘴炮时会夸张，但逻辑要自洽）
- 避免读者困惑（为什么还没被抹杀）

**影响范围**：
- 第三节仲裁对峙场景
- 不影响其他章节
