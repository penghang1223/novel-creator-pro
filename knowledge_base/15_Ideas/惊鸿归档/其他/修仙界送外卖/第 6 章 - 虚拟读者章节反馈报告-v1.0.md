## 🟡 P1 问题（建议修改）

### 1. [P1-节奏] 黑水镇制作替身符过程略长

**问题位置**：第二节

**问题描述**：
- 林小凡制作替身符的过程描写较详细（拔头发、砸灵石、画符）
- 虽然增加了真实感，但在被追踪的紧张情境下，节奏略显拖沓
- 部分读者反馈"这时候还有时间慢慢画符？"

**读者反馈**：
> "制作替身符那段有点慢，前面还在被追踪，突然就停下来做手工了"
> "建议压缩制作过程，或者增加时间压力，比如'身后追兵越来越近'"
> "可以改成买现成的符箓，或者系统直接奖励，加快节奏"

**修改建议**：
压缩制作过程，增加时间压力：
```
原句（约 200 字）：
他笨手笨脚地画着符箓，额头上渗出细密的汗珠。这玩意儿看着简单，做起来难。符箓上的线条必须流畅，不能断，不能抖，否则灵力无法流通。
第一次，画歪了。
第二次，断了。
第三次，终于成了。

可改为（约 80 字）：
林小凡手忙脚乱地画着符箓，额头上渗出细密的汗珠。
身后，集市的入口方向传来骚动。追兵要来了。
第三次，符箓终于成了。
```

**影响**：节奏紧凑度，紧张感维持

### 2. [P1-设定] 替身附带电动车复制品略显突兀

**问题位置**：第三节

**问题描述**：
- 替身突然出现一辆电动车复制品
- 前文没有铺垫替身可以带道具
- 系统解释"替身附带基础道具"略显随意

**读者反馈**：
> "替身哪来的电动车？系统变的？那之前林小凡干嘛自己跑？"
> "建议提前铺垫一下，比如系统说'替身可携带基础道具'"
> "或者改成替身骑普通的马/剑，不要用电动车复制品"

**修改建议**：
方案 A（提前铺垫）：
在系统介绍替身符时增加说明：
```
"替身符……功效：制造一个与宿主气息相同的替身，持续一炷香时间。替身可携带宿主的基础装备。"
```

方案 B（简化处理）：
```
替身点点头，化作一道黄光向东边驶去。
林小凡愣了一下："系统，替身怎么跑的？"
"消耗宿主灵力模拟载具。"系统理直气壮，"别问，问就是功能。"
```

**影响**：设定一致性，系统可信度

### 3. [P1-情绪] 锁妖塔订单的情绪冲击可加强

**问题位置**：第五节

**问题描述**：
- 林小凡看到 5000 灵石订单时，反应比较平静
- 对比第 5 章 1000 灵石订单的激动（"手一抖，馒头掉在地上"）
- 这次 5000 灵石，反应反而弱了
- 建议增加情绪层次：震惊→犹豫→决定

**读者反馈**：
> "5000 灵石啊！比上次多 5 倍！林小凡就'脚下一滑'？"
> "建议增加他的心理活动：这钱能不能赚？会不会死？"
> "或者加个身体反应，比如呼吸变粗、手心出汗、心跳加速"

**修改建议**：
在接单前增加情绪描写：
```
5000 灵石。

这一单，够他买十辆电动车了。

林小凡的手心开始出汗。

他想起万魂谷的经历，想起苏清雪的求救信，想起老者那个诡异的笑容。

锁妖塔……那是什么地方？青云宗禁地，关押重犯之处。

进去了，还能出来吗？

系统提示音再次响起："检测到宿主犹豫。温馨提示：本订单超时惩罚为扣除 10 年寿元，请谨慎接单哦亲~"

又是威胁。

林小凡深吸一口气，脑海中浮现出苏清雪的脸。

"系统，你说……我是不是疯了？"

"检测到宿主自我怀疑。"系统沉默了片刻，"但宿主每次都能创造奇迹。这，或许就是凡人的力量。"

林小凡笑了。

他在系统界面上点了"接单"。
```

**影响**：情绪渲染，读者共情

### 2. [P2-对话] 系统吐槽可增加变化

**问题位置**：全文多处

**问题描述**：
- 系统的"温馨提示"和"哦亲~"出现频率较高
- 部分读者反馈"系统说话风格有点单一"
- 建议增加系统的语气变化，比如严肃、调侃、神秘等

**修改建议**：
在不同情境下，系统使用不同语气：
```
紧张情境："警告！追踪灵鸦进入攻击范围！"（严肃）
日常情境："检测到宿主疑心病发作。"（吐槽）
神秘情境："反追踪模块已锁定，需完成新手任务后解锁。"（神秘）
鼓励情境："但宿主每次都能创造奇迹。这，或许就是凡人的力量。"（温和）
```

### 3. [P2-环境] 黑水镇可增加特色描写

**问题位置**：第二节

**问题描述**：
- 黑水镇的描写比较通用（"修仙者集市"、"各种摊位"）
- 可以增加一些特色元素，让读者记住这个地方
- 比如镇名的由来、特色建筑、特殊人群等

**修改建议**：
增加黑水镇特色：
```
黑水镇比林小凡想象的要热闹。

镇子建在一条黑色河流旁边，河水终年不散着淡淡的雾气。据说这河水有灵力，喝了能提升修为，但没人敢试——喝过的人都疯了。

虽然是深夜，但镇上的修仙者集市依旧灯火通明。街道两旁摆满了各种摊位，卖什么的都有：法器、符箓、丹药、妖兽材料，甚至还有卖情报的。

林小凡注意到，集市里有很多戴着斗笠的人，看不清脸。他们走路无声，交易时只用眼神交流。

"那些人是什么人？"他问系统。

"赏金猎人。"系统回答，"黑水镇是中立地带，正邪两道都不管。所以……什么人都来。"

林小凡拉低帽檐，混进人群。
```
