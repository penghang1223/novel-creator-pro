# 主动记忆提取规则

> 基于 memU 理念 | 版本：1.0

---

## 🎯 提取目标

从与君上的对话中自动识别并提取：
- **偏好声明** - 君上的喜好、习惯、风格
- **意图目标** - 君上想要完成的任务/目标
- **知识点** - 新概念、新技能、新理解
- **关系信息** - 人、组织、服务配置
- **技能沉淀** - 可复用的方法、模式、经验

---

## 📋 提取规则

### 1️⃣ 偏好类 (preferences/)

**触发关键词**：
- "我喜欢..." / "我不喜欢..."
- "偏好..." / "习惯..."
- "用...比较好" / "...更方便"

**示例**：
```
君上："我喜欢结构化的回答"
→ 提取：偏好/沟通风格 → 结构化呈现
```

---

### 2️⃣ 意图类 (intents/)

**触发关键词**：
- "帮我..." / "我要..."
- "需要..." / "想要..."
- "计划..." / "准备..."

**示例**：
```
君上："帮我设计一个登录功能"
→ 提取：意图/任务 → 登录功能设计
```

---

### 3️⃣ 知识类 (knowledge/)

**触发关键词**：
- "原来是..." / "明白了..."
- "概念是..." / "原理是..."
- 学习/研究/理解 + 主题

---

### 4️⃣ 关系类 (relationships/)

**触发关键词**：
- 公司名、人名、组织名
- 配置、账号、API Key
- 服务、平台、工具名

---

### 5️⃣ 技能类 (skills/)

**触发关键词**：
- "学会了..." / "掌握了..."
- "可以..." / "能够..."
- 完成的任务、解决的问题

---

## 🎯 提取流程

```
对话输入 → 识别触发词 → 分类判断 → 提取内容 → 检查重复 → 创建/更新 → 建立引用 → 更新索引
```

---

## 💡 置信度评估

| 置信度 | 判断标准 | 处理方式 |
|--------|----------|----------|
| **高** | 君上明确表达、多次提及 | 直接创建记忆 |
| **中** | 隐含表达、上下文推断 | 创建但标注待确认 |
| **低** | 模糊表达、单次提及 | 暂存观察区 |
