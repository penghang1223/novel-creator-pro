## 🎓 技法体系（截至2026-03-28）

### 已掌握的核心技法
1. **Free Indirect Style (FIS)**：角色声音融入叙述，去掉"她想"标签
   - Ishiguro式：压抑容器（说了什么 vs 感受了什么之间的裂缝）
   - Morrison式：集体意识承载
   - Joyce式：语言表演意识本身
   - **实战验证**：特别适用于潘玥的双重身份叙事，实现"所说 vs 所感"的张力
2. **对白潜台词四法**：矛盾交代、沉默即潜台词、指东骂西+适度提醒、隐喻递进
   - **实战验证**：第95-105章中使用"指东骂西"和"沉默即潜台词"，对话张力显著提升
3. **成人写作技法12种**：退让式语言、环境不安全感、五感递进、权力女性主动掌控等
4. **爽点原子12种** + 冲突状态机 L1→L4
5. **反向约束体系**：套路黑名单、情感状态机、Show不Tell禁词、跨界嫁接

### 写作宪法
- 文件：`创作工业宪法.md`、`INSTINCTS.md`、`WORKFLOW.md`
- 核心："受约束的结构 > 自由发挥"
- 质量前置：写前设定must_include和must_avoid
