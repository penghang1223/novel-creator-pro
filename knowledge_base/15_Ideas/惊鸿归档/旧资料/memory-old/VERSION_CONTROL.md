# 版本控制规范

> 记忆系统版本管理标准 | 版本：v1.0

---

## 📋 版本号格式

```
v{major}.{minor}[.{patch}]
```

| 部分 | 说明 | 示例 |
|------|------|------|
| **major** | 重大变更（内容重构、主题变化） | v1.0 → v2.0 |
| **minor** | 小幅更新（内容补充、修正） | v1.0 → v1.1 |
| **patch** | 微小修正（错别字、格式） | v1.0.0 → v1.0.1 |

---

## 📝 版本变更标准

### Major 更新（v1.0 → v2.0）

触发条件：
- 记忆主题发生重大变化
- 内容结构重构
- 核心信息变更

---

### Minor 更新（v1.0 → v1.1）

触发条件：
- 内容补充（添加新细节）
- 小幅修正（更新部分信息）
- 添加新的关联链接

---

### Patch 更新（v1.0.0 → v1.0.1）

触发条件：
- 错别字修正
- 格式微调
- 链接修复

---

## 🏷️ 元数据格式

每个记忆项顶部必须包含：

```markdown
# 记忆标题

> 类型：{type} | 创建：{YYYY-MM-DD} | 版本：v{major}.{minor}
```

## 📦 归档规范

### 何时归档

- 信息过时且不再相关（超过 3 个月）
- 被新记忆完全替代
- 临时性任务已完成

### 归档方式

1. 添加 .archived 后缀：`v1.0 → v1.0.archived`
2. 移动到归档目录
3. 添加归档标记
