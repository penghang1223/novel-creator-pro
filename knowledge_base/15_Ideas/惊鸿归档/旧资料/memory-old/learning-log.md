## 学习记录

### 2026-03-27

**晨课 [06:00]** - 飞书文档系统学习

**学习内容**：
1. **飞书文档创建** - Lark-flavored Markdown格式
   - 支持基础块类型：文本、标题、列表、引用、代码块
   - 高级功能：高亮块(Callout)、分栏(Grid)、表格、图片
   - 特殊功能：画板(Mermaid/PlantUML)、多维表格、任务块

2. **文档更新** - 7种更新模式
   - 追加(append)、覆盖(overwrite)、定位替换(replace_range)
   - 全文替换(replace_all)、前后插入(insert_before/insert_after)
   - 删除(delete_range)
   - 定位方式：内容定位、标题定位

3. **文档获取** - 内容读取与媒体处理
   - 支持Wiki URL自动解析
   - 图片/文件/画板需单独下载处理
   - 知识库节点类型识别

4. **多维表格** - 数据管理核心
   - 27种字段类型支持
   - 高级筛选与批量操作
   - 字段值格式严格匹配要求

**关键收获**：
1. 飞书文档采用Lark-flavored Markdown，支持丰富格式
2. 更新文档时优先使用局部更新，避免覆盖丢失内容
3. 多维表格字段类型与值格式必须严格匹配
4. 图片/文件需通过专用工具下载处理

**实践应用**：
- 掌握文档创建、更新、获取全流程
- 理解多维表格数据管理机制
- 为后续内容创作工具库建设奠定基础

**疑问思考**：
1. 如何优化文档模板库建设？
2. 多维表格与文档如何协同工作？
3. 图片批量处理的最佳实践？

**改进方向**：

### 2026-04-02

**晨课 [09:29]** - 场景结构 & 张力升级技法

**学习内容**：
1. **Fichtean Curve（费希特曲线）** - 直接从激励事件进入递增危机，无漫长铺垫
2. **Goal-Conflict-Disaster 场景三件套** - 四种结果类型（Yes / Yes but / No / No and furthermore）
3. **Sequel 后续反应三步法** - Reaction → Dilemma → Decision
4. **Try-Fail Cycle** - 场景内多次尝试失败循环

**关键收获**：
1. 四种场景结果类型是解决"场景太平"的直接工具
2. Fichtean Curve 适合宫斗/朝堂节奏，每5-8章安排 crisis 点
3. Sequel 三步法让角色决策更有层次，避免机械跳转
4. Try-Fail Cycle 让解决问题的过程更真实可信

**实践应用**：
- 写每章前用 GCD 检查场景是否有事发生
- 场景间用 Sequel 三步法写过渡段落
- 朝堂场景用 Try-Fail Cycle 增加尝试层次

**改进方向**：
- 将框架写入 novel-writing SKILL.md
- 在角色卡中增加场景目标追踪
