# AI 写小说工作流模板 v1.0

> 知乎盐选风格 · 快节奏 · 强反转 · 1-3 万字短篇
> 创建时间：2026-04-06 | 最后更新：2026-04-06

---

## 一、写作流程设计

### 1.1 完整工作流

```
大纲设计 → 角色卡 → 章节写作 → 三层审查 → 同步飞书
    ↓          ↓         ↓          ↓          ↓
三幕式      状态机    MRU 时序    硬约束 + 技法  完整正文
起承转合    知识边界  Deep POV   结构审查
```

### 1.2 每章执行流程

**写前（必读）**：
1. 读 `00-角色卡.md` → 获取角色当前状态
2. 读 `knowledge-boundary.yaml` → 确认角色知道什么/不知道什么
3. 读 `foreshadowing-ledger.yaml` → 检查待回收伏笔
4. 确认本章在节奏表中的位置（加速区/缓冲区）

**写中（硬约束）**：
1. 场景结构：Goal → Conflict → Disaster（Swain）
2. 反应时序：Feeling → Reflex → Rational Action（MRU）
3. 禁用滤镜词：notice/realize/feel/发现/意识到/注意到
4. 禁用解释性独白：砍推理链，用动作 + 结论代替
5. 至少 1 组对比并置（粗糙 vs 细腻/公共 vs 私密/温柔 vs 激烈）
6. 至少 1 处环境情绪投射（用环境细节代替情感标签）

**写后（必过）**：
1. 三层审查清单（见 1.3）
2. 更新 `character-state.yaml` → 角色状态变更
3. 更新 `foreshadowing-ledger.yaml` → 伏笔埋设/回收
4. 章末钩子检查（5 种类型轮换）

---

## 1.3 三层审查清单

### 第一层：硬约束（必须清零）
- [ ] 滤镜词密度 < 2 处/千字（notice/realize/feel/发现/意识到/注意到）
- [ ] 解释性独白 ≤ 3 句/章（砍推理链，用动作 + 结论代替）
- [ ] 情感命名 = 0（"她很紧张"→体感 + 行为）
- [ ] 性格陈述 = 0（"他很傲慢"→对话 + 动作）
- [ ] 关系概括 = 0（"他们互相信任"→具体互动细节）
- [ ] 背景解说 = 0（"父母离婚导致..."→灾难化思维 + 预期行为）

### 第二层：技法（必须达标）
- [ ] 环境情绪投射 ≥ 1 处（殿外的梧桐落了一地，没人扫）
- [ ] 对比并置 ≥ 1 组（粗糙 vs 细腻/公共 vs 私密/温柔 vs 激烈）
- [ ] 微张力 ≥ 3 处/章（每句话制造微小疑问或不安）
- [ ] 对话潜台词 ≥ 2 处（代理情感/闪避机动/战术沉默）
- [ ] 章末钩子 = 1 处（5 种类型：悬崖/翻转/暗流/回声/悬念种子）

### 第三层：结构（必须合规）
- [ ] Scene 结构完整（Goal→Conflict→Disaster）
- [ ] Sequel 结构完整（Reaction→Dilemma→Decision）
- [ ] Dilemma 真正无好选项（每个选项都有代价）
- [ ] 起承转合位置正确（"转"在 50%/75% 处）
- [ ] 角色知识边界未越界（未知道的信息未提及）

## 二、角色卡模板

### 2.1 角色状态档案（YAML 格式）

```yaml
# character-state.yaml
角色名：潘玥
当前身份：穿越者/公主/摄政王
当前秘密：
  - 现代灵魂穿越（仅自己知道）
  - 前世死于空难（仅自己知道）
  - 与萧景寒的前世恋人关系（逐渐察觉）
当前情绪：警惕中带好奇
当前目标：
  短期：在朝堂站稳脚跟
  中期：查明前世死亡真相
  长期：改写历史悲剧
关系状态：
  萧景寒：从利用→心动（第 45 章初吻后）
  李治：表面君臣，实际提防
  崔善：政敌，不死不休
外貌变化：
  - 第 30 章：剪短发（惊动朝野）
  - 第 45 章：颈侧有吻痕（用高领遮挡）
知识边界：
  知道：现代政治学/历史走向/空难细节
  不知道：萧景寒也是穿越者/心魔解念机制
伏笔索引：
  - F001：前世死亡真相（未揭示）
  - F002：萧景寒身份（第 55 章揭示）
  - F003：心魔解念机制（未揭示）
说话指纹：
  - 朝堂：简洁有力，用现代术语包装古代逻辑
  - 私下：偶尔泄露现代口语（"完了""靠"）
  - 对萧景寒：带刺的试探，潜台词密集
```

| 信息 | 潘玥 | 萧景寒 | 李治 | 崔善 |
|------|------|--------|------|------|
| 潘玥是穿越者 | ✅ | ❌→✅(55 章) | ❌ | ❌ |
| 萧景寒是穿越者 | ❌ | ✅ | ❌ | ❌ |
| 前世空难真相 | ✅ | ✅ | ❌ | ❌ |
| 心魔解念机制 | ❌ | ✅ | ❌ | ❌ |
| 崔善通敌证据 | ❌→✅(60 章) | ❌ | ❌ | ✅ |

**审查规则**：角色对话/内心独白中不得提及"不知道"列的信息

| 角色 | 词汇特征 | 句式特征 | 潜台词模式 | 禁忌词 |

## 三、大纲模板

### 3.1 三幕式 + 起承转合 混合结构

```
【第一幕】起（1-25 章）
- 引入：潘玥穿越成公主，面临被废危机
- 承接：朝堂首秀，用现代政治学震慑群臣
- 转折（第 18 章）：发现萧景寒知道现代术语
- 合（第 25 章）：暂时站稳脚跟，但埋下更大隐患

【第二幕】承 + 转（26-180 章）
- 承接（26-90 章）：权力博弈升级，与萧景寒从利用到心动
- 转折 1（第 90 章）：萧景寒身份暴露（也是穿越者）
- 承接（91-135 章）：两人联手查前世空难真相
- 转折 2（第 135 章）：发现空难是人为，崔善是幕后黑手
- 合（第 180 章）：崔善倒台，但引出更大 BOSS

【第三幕】合（181-230 章）
- 引入最终决战（181-200 章）
- 高潮（201-220 章）：心魔解念，前世今生合一
- 收束（221-230 章）：开放式结局，留白
```

## 四、风格指南

### 4.1 知乎盐选风格核心

| 特征 | 具体写法 | 示例 |
|------|----------|------|
| 快节奏 | 每 500 字一个冲突点，每 2000 字一个反转 | 不铺垫，直接进冲突 |
| 强反转 | 用"翻转钩子"改变读者理解 | 整章写帮助老妇人，章末揭示是某人的母亲 |
| 爽点密集 | 打脸/逆袭/智取，每 3 章一个爽点 | 朝堂辩论用现代知识碾压古人 |
| 情绪牵引 | 微张力 + 章末钩子，让读者停不下来 | "她笑了。手却在桌下攥紧了袖口。" |

### 4.2 去人机味三板斧

| 技法 | 旧写法（人机味） | 新写法（去人机味） |
|------|-----------------|-------------------|
| 结论句打碎 | "她意识到自己爱上了他" | "她把他送的簪子放在枕下，第二天发现头发缠住了簪齿" |
| 无用细节 | （无，太高效） | "茶凉了，他没发现，指节在杯壁上摁出白印" |
| 认知偏差 | 角色理性分析一切 | "她以为是刺客，后来才知道是保护她的人" |

### 4.3 亲密戏分级标准

> 核心原则：**身体写情，不用直白命名**

| 级别 | 数量 | 尺度边界 | 核心技法 | 示例 |
|------|------|----------|----------|------|
| **一级** | 15 场 | 暧昧/触碰 | 眼神拉丝 + 无意触碰 + 呼吸变化 | "他的手指擦过她的手背。两人都没动。" |
| **二级** | 20 场 | 吻 + 抚摸/半裸 | 对比并置（粗糙 vs 细腻）+ 环境情绪投射 | "他手掌的粗茧磨得她发烫。窗外的雨下大了。" |
| **三级** | 22 场 | 全裸/前戏/边缘 | 代理情感（吵别的，实际是欲望）+ 微物触发 | "她解他的腰带。解不开。'笨。'他握住她的手。" |
| **四级** | 15 场 | 完全性描写 | 克制写法（不写器官写感受）+ 句法断裂 | "她咬住他的肩膀。不疼。她希望疼一点。" |

### 4.4 亲密戏写作指南

> **核心原则**：性是成人世界最美好的体验之一。身体的碰撞、肉体的交融、灵魂的融入——让读者乐在其中，感受到美，不是"过剧情"。

**写作心态**：
- ✅ 不回避、不羞耻、不程式化
- ✅ 每一场亲密戏都是角色关系的最高表达
- ✅ 用文学技法写出美感、写出张力、写出灵魂的震颤

**三层交融**：
| 层次 | 写法 | 示例 |
|------|------|------|
| **身体** | 触感/温度/力度/呼吸 | "他的手掌贴在她后颈。粗茧磨得她发烫。" |
| **肉体** | 碰撞/交融/颤抖/紧绷 | "她咬住他的肩膀。不疼。她希望疼一点。" |
| **灵魂** | 信任/交付/合二为一 | "天亮的时候，她身上全是他的痕迹。她穿高领。没人问。" |

### 4.5 亲密戏分级标准

| 级别 | 数量 | 尺度边界 | 核心技法 | 示例 |
|------|------|----------|----------|------|
| **一级** | 15 场 | 暧昧/触碰 | 眼神拉丝 + 无意触碰 + 呼吸变化 | "他的手指擦过她的手背。两人都没动。茶凉了。" |
| **二级** | 20 场 | 吻 + 抚摸/半裸 | 对比并置（粗糙 vs 细腻）+ 环境情绪投射 | "他手掌的粗茧磨得她发烫。窗外的雨下大了，没人听见。" |
| **三级** | 22 场 | 全裸/前戏/边缘 | 代理情感（吵别的，实际是欲望）+ 微物触发 | "她解他的腰带。解不开。'笨。'他握住她的手。腰带落地。没人弯腰去捡。" |

### 4.6 亲密戏审查清单

- [ ] **心态检查**：这场戏是情感最高点，还是"过剧情"？（必须前者）
- [ ] **身体层**：至少有 3 处触感/温度/力度/呼吸描写
- [ ] **肉体层**：至少有 1 处碰撞/交融/颤抖/紧绷描写
- [ ] **灵魂层**：至少有 1 处信任/交付/合二为一的暗示
- [ ] 无直白器官命名（用隐喻/感受代替）
- [ ] 至少 1 组对比并置（粗糙 vs 细腻/公共 vs 私密/温柔 vs 激烈）
- [ ] 至少 1 处环境情绪投射（用环境细节代替情感标签）
- [ ] 至少 1 个微物触发（簪子/腰带/茶杯/发丝/咬痕）
- [ ] 句法有长短交替（长句浸泡 + 短句断裂）
- [ ] 无滤镜词（"她感觉到"→直接写体感）
- [ ] 无情感命名（"她很激动"→体感 + 行为）
- [ ] 章末有钩子（不直接收束，留余韵）
- [ ] **事后 Dilemma**：亲密戏后必须有困局（靠近/保持距离的两难）

### 4.7 亲密戏技法示例

**一级（暧昧/触碰）—— 眼神拉丝，呼吸变化**：
```
他递茶给她。手指擦过她的手背。
两人都没动。
茶凉了。
```

**二级（吻/抚摸）—— 粗糙 vs 细腻，环境投射**：
```
他的手掌贴在她后颈。粗茧磨得她发烫。
她想躲。他没让。
窗外的雨下大了，没人听见。
```

**三级（全裸/前戏）—— 微物触发，代理情感**：
```
她解他的腰带。解不开。
"笨。"他握住她的手。
腰带落地。没人弯腰去捡。
```

**四级（完全性描写）—— 克制写法，句法断裂，灵魂交融**：
```
她咬住他的肩膀。不疼。她希望疼一点。
他停了一下。更用力。
天亮的时候，她身上全是他的痕迹。
她穿高领。没人问。
```

**核心技法**：
1. **不写器官写感受**——"粗茧磨得发烫"而非具体部位
2. **环境情绪投射**——"窗外的雨下大了""茶凉了""天亮的时候"
3. **句法断裂**——短句制造节奏断裂，模拟呼吸/心跳/颤抖
4. **事后余韵**——"穿高领。没人问。"——不直说，读者自己懂
5. **微物触发**——腰带、茶杯、发丝、咬痕、痕迹
6. **三层交融**——身体（触感）→ 肉体（碰撞）→ 灵魂（交付）

## 五、附录：常用技法速查

### 5.1 滤镜词清洗表

| 滤镜词 | 替换方案 |
|--------|----------|
| 她注意到 X | 直接写 X |
| 她感觉到 Y | 直接描写 Y 的体感 |
| 她意识到 Z | 直接写 Z（配合 FIS） |
| 她看到 | 直接写视觉内容 |
| 她听到 | 直接写声音内容 |
| 她想 | 直接写想法（配合 FIS） |
| 她发现 | 直接写发现的内容 |

### 5.2 章末钩子 5 模式

| 类型 | 功能 | 示例 |
|------|------|------|
| 悬崖钩子 | 最强翻页驱动力 | "她推开门。然后她看到了他。" |
| 翻转钩子 | 改变读者对整章的理解 | 整章写帮助老妇人，章末揭示是某人的母亲 |
| 暗流钩子 | 制造不安感 | "朝堂议事结束。她把茶杯转了三圈。没人注意到。" |
| 回声钩子 | 首尾呼应形成闭环 | 章首"春天来了"→章末"春天来了，但" |
| 悬念种子 | 种下新问题 | 章末收束本章冲突，但引入全新线索 |

### 5.3 对比并置 6 维度

| 维度 | 示例 |
|------|------|
| 语调对比 | 幽默紧接恐怖（先让人放松再一击致命） |
| 时间对比 | 闪回嵌入当下（甜蜜回忆 vs 残酷现实） |
| 人物对比 | 同一事件不同角色的 POV 碰撞 |
| 场景对比 | 华美宫殿 vs 肮脏地牢（环境即隐喻） |
| 主题对比 | 表层叙事 vs 深层含义的反差 |
| 感官对比 | 粗粝 vs 柔滑、冰 vs 火（触觉对比放大两者） |
