## 1️⃣ 爽点达成度（30分）

### 检查清单
- [ ] 本章有爽点吗？
- [ ] 爽点有铺垫→爆发的节奏吗？
- [ ] 爽点类型是什么？（face_slap/prophecy/reveal/power_up/enemy_defection）

### 自动检测
```python
# 检测爽点关键词
payoff_signals = ['赢了', '反转', '揭穿', '打脸', '没想到', '竟然', '原来']
tension_signals = ['怎么办', '紧张', '危险', '死', '暴露']
buildup_signals = ['暗中', '秘密', '计划', '布局']

# 评分逻辑
if has_payoff and has_tension_buildup: score = 9-10
elif has_payoff: score = 6-8
elif has_tension_only: score = 4-5  # 只压抑不释放
else: score = 1-3  # 无爽点
```

### 我们的爽点清单
| 类型 | 出现章节 | 得分 |
|------|------|------|
| face_slap（打脸） | 4, 19, 46, 48 | 9-10 |
| prophecy_fulfilled（预知应验） | 8, 26, 40 | 8-9 |
| reveal_identity（身份揭示） | 47 (萧景寒) | 8 |
| power_up（权力升级） | 20, 30, 50 | 7-8 |
| enemy_defection（敌人倒戈） | 37, 55 | 8-9 |
| mentor_loss（导师去世） | 45 | 9 |

- [ ] 本章改变了什么"世界状态"？

```python
# 检测推进信号
new_info_signals = ['第一次', '新的', '从未', '突然', '发现', '得知']
world_change_signals = ['从此', '改变了', '决定', '放弃', '选择']

# 评分逻辑
if introduces_new_info and changes_world_state: score = 13-15
elif changes_world_state: score = 10-12
elif only_repeats_info: score = 5-7
```

## 4️⃣ 逻辑自洽（10分）

### 检查清单
- [ ] 因果关系是否成立？
- [ ] 世界规则有没有被打破？
- [ ] 已死角色是否被复活？

### 自动检测
```python
# 硬约束
if dead_character_appears_alive: score = 0  # 致命错误
if violate_world_rules: score = 2-3

else: score = 8-10
```

## 5️⃣ 节奏控制（10分）

### 检查清单
- [ ] 是否拖沓？（太多无关描写）
- [ ] 是否过快？（一章塞了太多事件）
- [ ] 情绪曲线是否合理？

### 自动检测
```python
# 节奏指标
events_per_chapter = count_events(text)
conflict_gap = distance_between_conflicts(text)

if events_per_chapter > 3: score = 5-7  # 过快
elif events_per_chapter == 0: score = 1-3  # 水文
elif conflict_gap > 2000: score = 5-7  # 拖沓
else: score = 8-10
```

## 6️⃣ 伏笔管理（10分）

### 检查清单
- [ ] 本章是否推进了伏笔？
- [ ] 伏笔是否按时回收？
- [ ] 有没有遗忘的伏笔？

### 自动检测
```python
# 伏笔状态检查
for f in foreshadowing:
    if f.target_chapter < current_chapter and f.status != 'resolved':
        score -= 2  # 超期未回收
    elif f.status == 'progressing':
        score += 0.5  # 正在推进
```

## 7️⃣ 可读性（10分）

### 检查清单
- [ ] 平均句长是否合理？（15-25字最佳）
- [ ] 重复词比例
- [ ] AI味词检测
- [ ] 破折号密度（≤5%）

### 自动检测
```python
# 可读性指标
avg_sentence_len = total_chars / sentence_count
repeat_ratio = count_repeated_words / total_words
ai_taste_words = count(forbidden_words)
dash_density = dash_count / total_chars * 100

if avg_sentence_len > 30: score -= 2  # 句子太长
if repeat_ratio > 0.1: score -= 2  # 重复太多
if ai_taste_words > 3: score -= 2  # AI味
if dash_density > 5: score -= 2  # 破折号太多
```

## 8️⃣ 商业价值（5分）

### 检查清单
- [ ] 开头100字有没有钩子？
- [ ] 章末有没有悬念？
- [ ] 有没有"传播点"？

### 自动检测
```python
# 钩子检测
hook_in_first_100 = has_tension(text[:100])
cliffhanger_at_end = has_question(text[-200:]) or has_suspense(text[-200:])

if hook_in_first_100 and cliffhanger_at_end: score = 5
elif hook_in_first_100: score = 4
elif cliffhanger_at_end: score = 3
else: score = 1-2
```
