## 📅 学习路线（7天一轮）

### 第1周：对话——让角色"只看文字就知道是谁说的"
- [ ] 学：经典小说对话分析（猫腻、烽火戏诸侯、priest）
- [ ] 学：对话潜台词技法（说什么≠想什么）
- [ ] 学：对话节奏（短句交锋 vs 长段独白）
- [ ] 用：给《女皇》第1章写一段对话，做到不看标签能分辨谁说的
- [ ] 记：写入 lessons.md + 更新 AGENTS.md 对话规范

### 第2周：场景张力——让读者"翻页停不下来"
- [ ] 学：场景结构（目标→障碍→结果→新目标）
- [ ] 学：微冲突设计（每页至少一个小冲突）
- [ ] 学：悬疑技法（信息差+延后揭晓）
- [ ] 用：改造《女皇》第45章（锚铺垫①），加入场景张力
- [ ] 记：lessons.md

### 第3周：节奏——知道什么时候"该刹车"
- [ ] 学：网文断章技巧（章末钩子设计）
- [ ] 学：长短句交替节奏感
- [ ] 学：情感段落 vs 动作段落的速度差
- [ ] 用：分析《谢家短命鬼》3个章节的节奏，拆解学习
- [ ] 记：lessons.md

### 第4周：亲密戏高级技法——"色而不淫"
- [ ] 学：五感描写技法（触觉/嗅觉/温度/声音）
- [ ] 学：情绪驱动而非动作驱动的写法
- [ ] 学：亲密戏与剧情推进的咬合方式
- [ ] 用：重写《女皇》第44章亲密戏指南（四级尺度）
- [ ] 记：lessons.md

### 第5周：多线叙事——权谋+情感+悬疑如何交织
- [ ] 学：POV切换技法（权力的游戏式多视角）
- [ ] 学：信息差制造张力（读者知道角色不知道）
- [ ] 学：平行蒙太奇（两件事同时发生）
- [ ] 用：给《女皇》第60章设计POV交叉叙事
- [ ] 记：lessons.md

### 持续学习方向（按需深挖）
- 高级叙事理论：不可靠叙事者、元叙事
- 心理描写：创伤反应、PTSD写法（萧航锚衰变需要）
- 打戏写法：冷兵器战斗的节奏感
- 权谋经典：《琅琊榜》《庆余年》《长安十二时辰》技法拆解

## 📏 执行规则

1. **每次心跳至少1个学习闭环**（学→评→用→反馈）
2. **学完必须写 lessons.md**，口头说"记下了"=没记
3. **学完必须用**——要么改大纲，要么写示例段落，要么更新写作规范
4. **连续3次🟢没用→换方向**，连续3次🔴→深挖
5. **每月汇总一次**到 MEMORY.md
6. **不需要等君上问**——自己选方向，自己执行，自主汇报
