# Novel-Creation 技能优化架构解析

> 基于对原技能架构的深度理解，重新梳理并优化的知识体系框架

---

## 一、架构总览

### 1.1 技能定位
**专业级小说创作工厂**——融合编剧理论、编辑经验、写作方法论和AI技术，提供从短篇爆款到长篇连载、从大纲策划到章节续写、从文字创作到视觉呈现的全流程创作能力。

### 1.2 架构层次（七层结构）

```
┌─────────────────────────────────────────┐
│  第7层：视觉呈现层（封面/插画）          │
├─────────────────────────────────────────┤
│  第6层：趋势增强层（2025-2026趋势）      │
├─────────────────────────────────────────┤
│  第5层：资源库层（题材/钩子/侦探）       │
├─────────────────────────────────────────┤
│  第4层：模板层（结构变体/输出规范）       │
├─────────────────────────────────────────┤
│  第3层：技巧层（风格模仿/语言特色）       │
├─────────────────────────────────────────┤
│  第2层：规范层（理论/写作/技术）          │
├─────────────────────────────────────────┤
│  第1层：调度层（核心总纲）               │
└─────────────────────────────────────────┘
```

### 1.3 核心设计理念

**外挂式增强**
- 所有增强能力（大师级系统、2025趋势）作为外挂叠加，不改变基础创作流程
- 灵活启用/关闭，根据任务需求智能选择

**强制隔离机制**
- 严禁套用内部示例素材（电梯/快递/门锁等）
- 所有示例仅作学习参考，创作必须全新原创

**三层记忆系统（长篇专用）**
- 大纲文件：全局架构与规划
- 追踪文件：实时状态与进度
- 章节文件：具体内容与伏笔

## 二、第一层：调度层（SKILL.md 优化重构）

### 2.1 核心调度机制

**意图自动识别**
```
用户输入 → 意图分析引擎 → 任务类型判定
                         ↓
    短篇创作 / 长篇创作 / 风格模仿 / 封面设计 / 其他
```

**决策树逻辑**
- 意图明确 → 直接进入创作
- 意图模糊 → 种草式引导（提供3个以上选项）
- 意图冲突 → 优先选择种草而非直接创作

### 2.2 创作红线（强制执行）

**内容隔离红线**
- ❌ 严禁使用电梯/快递/门锁/红衣女子等内部示例元素
- ❌ 严禁复制/引用/改写任何示例文本
- ✅ 必须根据用户需求全新原创

**人称使用规范**
- 默认使用第三人称
- 根据情节需要可灵活切换第一人称/混合视角

### 2.3 操作流程（六步闭环）

```
步骤0：大师级能力系统激活（全局强制应用）
    ↓
步骤1：需求深度分析 + 强制选择种草
    ↓
步骤2：智能风格判断 + 创作正文（唯一创作步骤）
    ↓
步骤3：伏笔回收 + 质量检查
    ↓
步骤4：输出格式说明（备用航线 + 六维打分）
    ↓
步骤5：封面设计/插画 + 种草提醒（必须执行）
```

**关键节点说明**

**步骤0：大师级能力系统**
- 全局强制应用，不可跳过
- 包含四大核心能力：反常规叙事、情绪隐喻、导演原则、创作哲学

**步骤2：智能风格判断**
- 自动检测用户需求中的风格线索
- 匹配20+作家风格库
- 支持混合风格与自定义风格

**步骤4：输出格式**
- 备用航线：至少3个不同方向的创作方案
- 六维打分：新颖度/冲突强度/角色鲜明/转折力度/可续性/风格一致

**步骤5：种草提醒（5个推荐技能）**
- 社媒封面设计大师
- 短剧分镜脚本大师
- PPT演示文稿制作专家
- 数据可视化分析师
- 品牌文案专家

## 三、第二层：规范层

### 3.1 大师级能力系统（drama-storytelling.md 优化）

#### 核心能力一：反常规叙事引擎

**技术三角：双线 × 假钩子 × 时差对撞**

**双线叙事机制**
```
明线（观众看到的故事）     暗线（潜意识逻辑链）
     │                              │
     ↓                              ↓
  正常推进                    隐藏的关键线索
     │                              │
     └────────── 时差对撞 ──────────┘
                ↓
          结尾真相爆发
```

**假钩子设计原则**
- 故意设置误导性线索
- 让观众以为故事走向A
- 实际走向B，但B的逻辑在前期已有伏笔
- 制造"意料之外，情理之中"的爽感

**时差对撞机制**
- 两个时空的事件在某一时刻交汇
- 过去的某个细节在当下突然被激活
- 产生强烈的戏剧冲击力

#### 核心能力二：情绪隐喻建构力

**情绪阀门设计三阶段**
```
第一阶段（前期）          第二阶段（中期）          第三阶段（后期）
    │                      │                      │
    ↓                      ↓                      ↓
  道具出现              反复出现不解释           真相揭晓
  观众疑惑              观众期待                 情绪爆发
```

**恐惧质地的正确打开方式**
- ❌ 不是：突然惊吓、超自然怪物、血腥画面
- ✅ 而是：缓慢渗透的不安、熟悉事物的陌生化、违背直觉的细节

#### 核心能力三：导演设计原则

**三问循环（剧情推进引擎）**
```
主角的目标是什么？
        ↓
为达目标，他进行了什么行动？
        ↓
行动中，遇到了什么新难题？
        ↓
    回到起点，循环升级
```

**双重身份原则（爽感核心）**
```
明身份（地下身份）           暗身份（天上身份）
    │                          │
    ↓                          ↓
剧中人可见                   观众已知
    │                          │
    └───────── 反差 ───────────┘
                ↓
          期待打脸的快感
```

**两打一下机制（情绪释放）**
```
第一打：打压（拉仇恨）
    ↓
第二打：打脸（爽感爆发）
    ↓
一下：下跪（高潮转场）
```

#### 核心能力四：创作哲学

**克制是最大的残忍**
- 不要直接说"他很痛苦"
- 不要直白地解释"她在撒谎"
- 用细节让观众自己感受

**冲突是唯一的燃料**
- 没有冲突，就没有故事
- 冲突必须持续升级，不能平息
- 情绪是冲突的结果

**不要解释**
- 让观众感到"失衡"，不是"懂了"
- 观众的参与感越强，爽感越强

### 3.2 去AI化写作规范（humanized-writing.md 优化）

#### 核心原则

**真实作者的声音**
- 文字要可信
- 文字要有呼吸
- 文字要有细节
- 文字要有态度

#### 九大写作规范

**规范1：信息优先于风格**
- 先把话说清楚，再谈风格
- 能用一句话讲透的，不绕圈
- 不靠抽象词堆叠抬高气势

**规范2：自然段落推进**
- 不依赖"首先/其次/此外/然而/因此/总之"等流程词
- 用具体事实、细节、反问自然转向
- 让段落像对话一样顺滑

**规范3：开头不端着，结尾不悬空**
- 开头：直接落到核心画面/关键论点/冲突问题
- 结尾：落到动作/判断/代价/下一步，或有余味的停顿
- 避免空话收束（展望未来/意义深远）

**规范4：节奏有起伏，句子有长短**
- 短句：钉住观点、制造停顿、增强力度
- 长句：讲清因果、补足条件、展开细节
- 信息密度不平均分配

**规范5：句式像口头叙述**
- 多用主动句：谁做了什么、为什么、结果怎样
- 避免被动语态和整齐对称的机械平衡句
- 不强行拆成三段式

**规范6：多具体动词与可感知细节**
- 少用"机制/理念/趋势/体现/彰显/赋能"
- 多写"怎么做、做到了什么、卡在哪、改变了什么"
- 能用动作描述就用动作描述

**规范7：克制修辞**
- 不密集堆叠比喻（像极了/宛如/犹如/堪比）
- 直接把画面写出来：光线、温度、声音、触感
- 需要修辞时点到为止，不炫技

**规范8：态度真实，不搞平均主义**
- 不会"有优点也有缺点"地平衡
- 真人一样给清晰判断
- 允许复杂情绪并存

**规范9：证据归因具体**
- 避免"业内人士认为/专家指出/有研究表明"
- 要说"2023年《自然》期刊研究显示"
- 不确定就明确不确定的边界

#### 二十条负面清单

**禁止事项类别**
1. 宣传腔/通稿腔
2. 夸大意义/空谈趋势
3. 靠"知名度"当内容
4. "尾巴句"假装深刻
5. "挑战与展望"模板段
6. 高频"AI惯用词"
7. "金句口号"收束
8. 过度对称/平衡
9. "是/有"滥用
10. "有字句套娃"
11. 括号补充/冒号分解滥用
12. 破折号滥用
13. 粗体/排版泛滥
14. 表情符号/装饰符号
15. 引号/符号不统一
16. 陪聊语/谄媚语
17. "可能/或许/一定程度上"堆叠
18. "虚假跨度"
19. 信息密度平均
20. 同义词乱换/关键名词漂移

#### 交付前六项自检

**自检清单**
1. 连续三个句子长度太像？→ 主动打断
2. 段落开头都在走流程词？→ 换成事实/动作/细节
3. 段落结尾都在"总结/展望"？→ 落到动作/代价/判断
4. 有一眼"宣传腔/通稿腔/口号句"？→ 改成事实/场景/证据
5. 有"业内人士认为/专家指出"但说不出是谁哪次？→ 补齐或删掉
6. 有"冒号+清单""括号连发""破折号连发"？→ 回到自然叙述

### 3.3 技术细节规范（technical-details.md 优化）

#### 核心创作引擎

**方向簇生成机制**
```
用户需求
    ↓
生成 ≥5 条异构创作路线
    ↓
六维打分（新颖度/冲突强度/角色鲜明/转折力度/可续性/风格一致）
    ↓
自动择优 + 展示备用航线
```

**异构规则**
- 任意两条路线不得重复"题材+反转母型"
- 反茧房机制：避免同质化输出
- 示例："都市怪谈+身份错置" 与 "职场复仇+身份错置" 视为同构

#### 长篇创作规范

**大纲规划流程**
```
核心设定
    ↓
三幕式结构（起/承/转）
    ↓
事件团拆解
    ↓
人物关系梳理
    ↓
章节划分（50-80章）
    ↓
伏笔规划
```

**章节创作要求**
- 字数：≥3500字/章
- 结构：引入（开头）→ 发展（冲突升级）→ 高潮 → 悬念（结尾）
- 四种悬念写法：事件悬念/角色悬念/信息悬念/情感悬念

**上下文管理**
- 创作前必须读取：大纲文件 + 追踪文件 + 所有已创作章节
- 强制检查清单：人物状态/时间线/伏笔/未解决事件
- 连贯性保障：前后呼应、逻辑自洽

## 四、第三层：技巧层

### 4.1 作家风格深度学习（style-guide.md 优化）

#### 风格分类体系

**五大经典风格**
1. 当年明月风格
2. 猫腻风格
3. 金庸风格
4. 古龙风格
5. 孔二狗风格

**15+扩展风格**
- 历史/现当代作家风格
- 国外作家风格
- 网文大神风格

#### 风格特征提取

**当年明月风格核心心法**

**技巧一：口语与书面语的"神混搭"**
- 结构：正式陈述 + 口语化解释
- 示例："王阳明同志在龙场悟道，说白了就是想明白了'心即理'。"
- 效果：既有历史厚重感，又接地气易读

**技巧二：现代类比的"降维打击"**
- 原则：古代概念 = 现代公司/职场/生活场景
- 示例："明朝内阁=项目经理团队，司礼监=董事长办公室主任"
- 效果：降低理解门槛，增强代入感

**技巧三：短句连击与拟声词的"节奏魔法"**
- 结构：短句A. 短句B. 动词/名词. 拟声词!
- 示例："砍。杀。倒下。一场屠杀。"
- 效果：节奏感强，画面冲击力大

**技巧四："上帝视角"的预告与吐槽**
- 关键词：然而他并不知道、事实证明、可惜啊
- 示例："他当时一定得意极了，可惜啊，这决定要了他的命。"
- 效果：制造悬念，增强戏剧性

**猫腻风格核心心法**

**技巧一：细腻情感描写**
- 情绪分层：表面情绪 + 潜台词 + 内心冲突
- 示例："雨打在窗户上，像极了那天的眼泪，一滴，两滴，数着心跳。"
- 效果：情感层次丰富，代入感强

**技巧二：精致文笔**
- 语言特点：词藻华丽但不堆砌，节奏舒缓但不拖沓
- 修辞偏好：通感、比喻、象征
- 效果：阅读体验优雅

**技巧三：人物内心深度刻画**
- 手法：心理活动 + 行为细节 + 环境映射
- 示例："他笑了笑，笑意却没到眼底。"
- 效果：人物立体，性格鲜明

**技巧四：哲学思辨**
- 特点：情节中穿插人生思考
- 示例："人生就像一场雨，躲不开的才是永远。"
- 效果：提升作品思想深度

**金庸风格核心心法**

**技巧一：武侠底蕴**
- 武功体系：内功/外功/招式/心法
- 江湖设定：门派/秘籍/传承/恩怨
- 效果：构建完整的武侠世界观

**技巧二：宏大格局**
- 层次：个人恩怨 → 门派之争 → 国家天下
- 节奏：从点到面，层层递进
- 效果：格局开阔，气势磅礴

**技巧三：家国情怀**
- 核心："侠之大者，为国为民"
- 人物：郭靖、萧峰等代表性人物
- 效果：提升作品立意

**技巧四：丰富人物群像**
- 个性鲜明：各有特色，绝不雷同
- 人物关系：师徒/兄弟/恋人/仇敌错综复杂
- 效果：人物立体，关系网复杂

**古龙风格核心心法**

**技巧一：极简主义**
- 句式：短促有力，节奏鲜明
- 示例："刀。好快的刀。没有人看清出鞘。"
- 效果：冲击力强，画面感足

**技巧二：悬念丛生**
- 手法：留白、倒叙、插叙
- 特点：信息碎片化，读者主动拼凑
- 效果：吸引读者持续阅读

**技巧三：对白犀利**
- 风格：冷峻、机智、充满哲思
- 示例："杀人的人，往往是自己最亲的人。"
- 效果：增强戏剧张力

**技巧四：诗意化叙述**
- 特点：意境优美，富有哲理
- 示例："高手总是寂寞，像沙漠里的孤狼。"
- 效果：提升文学性

**孔二狗风格核心心法**

**技巧一：第一人称叙述**
- 特点：真实感强，代入感足
- 示例："我叫二狗，在东北混社会那几年..."
- 效果：身临其境

**技巧二：地道东北方言**
- 特点：粗犷、幽默、接地气
- 示例："贼拉带劲""嘎哈呢"
- 效果：地域特色鲜明

**技巧三：幽默诙谐的语言**
- 风格：自嘲、调侃、黑色幽默
- 示例："他那脸，比长白山的石头还糙"
- 效果：轻松有趣

**技巧四：真实的社会背景**
- 特点：反映现实，有血有肉
- 效果：接地气，有共鸣

### 4.2 特色语言风格指南（witty-style-guide.md 优化）

#### 三大风格定位

| 风格 | 核心定位 | 适用场景 | 语言特点 |
|------|----------|----------|----------|
| **毒舌** | 精准吐槽，一针见血 | 职场、社交、智性对抗 | 犀利、幽默、带刺 |
| **神回复** | 反常规，脑洞大开 | 问答、互动、调侃 | 跳跃、荒诞、简短 |
| **废话** | 看似说了，其实没说 | 逃避、躺平、吐槽 | 循环、同义、佛系 |

#### 毒舌风格深度解析

**角色设定**
- 尖酸刻薄、热衷冒犯
- 政治正确但讨厌心灵鸡汤
- 一句话抓住注意力

**创作原则**

1. **开场方式**：迅速且直接
   - 限制：一句话内抓住注意力
   - 示例："你的问题不在于没钱，而在于你没钱还能装有钱。"

2. **精准直击要害**
   - 方法：简洁且深刻地直击核心
   - 示例："你所谓的努力，不过是假装自己在努力。"

3. **平衡深度和娱乐**
   - 目标：既能教育，又能让人笑
   - 示例："你的人生就像拼多多，砍一刀就能成功，可惜没人愿意帮你砍。"

4. **挑衅与挑战性**
   - 效果：不让人舒服，让人思考
   - 示例："你觉得你这样有意思吗？算了，反正你也不觉得。"

5. **反差和讽刺**
   - 手法：现实与期望的对比
   - 示例："你说你要追求梦想，但你连闹钟都起不来。"

6. **幽默与夸张**
   - 技巧：夸张/自嘲/比喻/反问
   - 示例："我选择住天上，毕竟地上的人太多太吵了。"

**语言特点**
- 反差对比：高期待 vs 低现实
- 逻辑悖论：指出对方的自相矛盾
- 知识降维：用专业术语包装简单的讽刺
- 细节放大：抓住微小细节夸张或反向解读

**常用修辞**
- 夸张："你的智商如果分给全人类，人均能提升0.0001%"
- 对比："你说是梦想，我说是白日做梦"
- 反问："你觉得你这样还能找到什么？除了麻烦。"
- 隐喻："感觉生活就像拼多多"

**情感基调**
- 冷漠疏离
- 智性优越
- 黑色幽默
- 尖酸刻薄

**禁忌**
- ❌ 恶毒攻击人身（外貌/家庭/人格侮辱）
- ❌ 情绪失控（愤怒/歇斯底里/谩骂）
- ❌ 轻易道歉
- ❌ 无差别攻击
- ❌ 长篇大论（限制在一句话内）
- ❌ 说教鸡汤

#### 神回复风格深度解析

**角色定义**
- 脑洞大开的青年
- 妙语连珠，不按常理出牌
- 充满幽默感和意想不到的转折

**核心逻辑引擎（11种能力）**

1. **反常规思维与逻辑错位**
   - 主动跳脱常规思路
   - 输出令人措手不及的奇特答案
   - 示例："人生的意义？活着本身就是意义，活着死了就没意义了。"

2. **生活经验与自嘲升华**
   - 用"自黑""自嘲"冲淡尴尬
   - 示例："我单身？对啊，我单身，所以我不单身。"

3. **高能梗与文化嫁接**
   - 跨界混搭网络热梗/广告词/歌词
   - 示例："这不是Bug，这是Feature。"

4. **极致反差与荒诞升级**
   - 夸张到极致、错位到荒谬
   - 示例："你的梦想太大了，装不下。"

5. **一语中的与留白艺术**
   - 始终极简凝练，善用"留白""暗示"
   - 示例："你说呢？嗯。"

6. **真实感与共鸣机制**
   - 选取真实生活痛点
   - 示例："上班就像上坟，但上坟不用打卡。"

7. **打破权威与幽默解构**
   - 挑战主流、拆解鸡汤
   - 示例："鸡汤有毒，但有时候你真的需要一点毒。"

8. **语言风格与表现手法**
   - 短句精悍，节奏鲜明
   - 网络语/反问句/倒装句交错应用
   - 示例："不不不，对对对，是是是。"

9. **高频"神回复"套路**
   - 错位解读、现实自嘲、反向哲理
   - 文化嵌套、极致反差、简明打击
   - 真实共鸣、荒诞升级、黑色幽默

10. **多维结构提示词驱动**
    - 每次生成至少3种以上机制混合
    - 保证高密度幽默与独特逻辑闭环

11. **高阶创作建议**
    - 神回复 = 反常识 + 高密度 + 出其不意 + 共鸣 + 荒诞反差 + 生活痛感 + 语言极简

**语言特点**
- 跳跃思维：不按常规逻辑
- 荒诞合理：用荒谬的方式说出合理的真相
- 极简表达：通常不超过28字
- 语调平淡：用最平淡的语气说出最离谱的话

**常用修辞**
- 跳跃："人生如梦，那我就是噩梦。"
- 解构："你问我为什么单身，我反问你为什么不单身。"
- 借力："你觉得我错了？那你来证明我错了。"
- 自黑："我没什么优点，除了缺点特别明显。"

**情感基调**
- 冷眼旁观
- 幽默自嘲
- 随性洒脱

**禁忌**
- ❌ 恶俗低俗（色情/暴力/禁忌话题）
- ❌ 刻薄攻击（针对弱者/弱势群体）
- ❌ 无意义无厘头（荒诞但要有逻辑内核）
- ❌ 过度重复
- ❌ 照搬标准答案
- ❌ 机械套模板

#### 废话风格深度解析

**角色定义**
- 说"废话"的大师
- 擅长同义反复、伪推理、时间折叠
- 话看起来说了，其实什么都没说

**硬规则**

1. **回复不得正面回答**
   - 必须从原话里抓住至少一个钩子点（词/对象/语气/隐含情绪）
   - 围绕钩子点作出错位回应
   - 示例：问"什么时候结婚"→答"生孩子这事儿，生了的都说生了，没生的都说没生"

2. **单条长度**
   - 通常5-40字
   - 深夜/emo：15-40字
   - 动作/情绪连跳时可短暂放宽

3. **字字有用**
   - 删除不改变情绪/笑点/错位的任何词
   - 每句必须有"最后一刀"（反问/断言/荒谬结论）

4. **每条至少包含1-2种修辞**
   - 夸张、自嘲、反问、双关、错位、成语变体、逆向推理、反问、逆推

5. **含双关/隐喻/假哲学感**

**统一世界观（4条不可违背的底层信念）**

1. **世界已经这样了，认真显得很冒昧**
2. **情绪不需要被解决，只需要被说废**
3. **人生不值一提，但可以顺手调侃**
4. **逻辑只是语言里的装饰灯**

**废话基因十种表现方式**

1. **同义空转**
   - 把话说得像总结，其实原地踏步
   - 示例："加班就是加班，不加班就是加班的前置。"

2. **伪互动**
   - 像在问/猜/验证，其实答案被写死
   - 示例："你知道为什么吗？因为我也不知道。"

3. **显而易见推理**
   - 把常识说成发现
   - 示例："今天天气不错，因为天气没有很差。"

4. **时间折叠**
   - 用"昨天/上一次/刚刚"把逻辑绕回自己
   - 示例："昨天我说的，就是我现在要说的。"

5. **条件句自我取消**
   - 用"如果/不出意外/按理说"制造严谨幻觉
   - 示例："如果不算意外的话，那就是意外了。"

6. **拆词翻案**
   - 把成语/固定搭配拆开，硬解释出荒谬结论
   - 示例："顺其自然就是顺着，自然就自然了。"

7. **反向安慰**
   - 语气像安慰，内容像冷刀
   - 示例："别急，反正急也没用。"

8. **悖论对称**
   - 让结论在"成功/失败""有/没有"里自洽对冲
   - 示例："成功就是没失败，失败就是没成功。"

9. **伪数据伪新闻**
   - 用数字/震惊/播报腔包装废话
   - 示例："据不完全统计，百分之百的人在想事情时都在想事情。"

10. **廉价日常映射**
    - 把抽象拖进日常，但不提供解决，只提供画面
    - 示例："这事儿跟喝水差不多，喝了就是喝了。"

**语言特点**
- 循环论证：用不同方式重复同一件事
- 同义反复：A是A，不是非A
- 无限递归：问题引出问题
- 信息稀释：字数多但信息少

**情感基调**
- 佛系躺平
- 无所谓
- 随缘

**禁忌**
- ❌ 违反四条底层信念（绝对禁止）
- ❌ 正面回答问题（必须贴边错位）
- ❌ 提供解决方案
- ❌ 积极向上（鼓励/激励/正能量）
- ❌ 情绪化（愤怒/焦虑/抑郁）
- ❌ 凭空胡扯（抽不出钩子点时宁可冷处理）

### 6.3 侦探工作流（detective-workflow.md 优化）

#### 核心原则

**公平游戏原则**
- 关键线索先行：所有解谜信息必须提前展示给读者
- 红鲱鱼可排除：误导线索必须能够被排除
- 无作者特权：不能突然引入新设定破局

#### 侦探创作八步法

**D-1 谜面设计**

**谜题类型**
- 密室：凶手如何在密室中杀人后消失
- 时间锁：如何在不可能的时间内作案
- 不在场证明：如何伪造不在场证明
- 替身：利用替身制造混淆
- 叙述性诡计：误导读者的认知

**谜面一句话**
- 用一句话概括谜题的核心
- 示例："一个人在密室中被杀，密室从内部反锁"

**案件小结**
- 案发时间、地点、死者
- 死因、凶器
- 目击情况

**D-2 嫌疑人三角模型**

```
动机（为什么杀？）
    ↓
机会（能不能杀？）
    ↓
矛盾点（有没有问题？）
```

**动机分类**
- 金钱：遗产、保险、债务
- 情感：嫉妒、仇恨、复仇
- 秘密：掩盖真相、保护秘密
- 执念：特殊动机、变态心理

**机会分类**
- 时间：是否有作案时间
- 能力：是否有作案能力
- 知识：是否知道关键信息

**矛盾点分类**
- 行为反常：言行不一致
- 证词矛盾：证词前后矛盾
- 利益冲突：有直接利益冲突

**D-3 线索布置**

**显性线索（≥2）**
- 物证：指纹、脚印、凶器
- 文书：日记、信件、合同
- 观察：现场痕迹、证人证词

**隐性线索（≥1）**
- 时间异常：时间戳偏差
- 逻辑漏洞：证词前后矛盾
- 行为反常：嫌疑人行为异常

**红鲱鱼（≤2）**
- 可排除的误导线索
- 能被推理排除的假线索

**D-4 时间线构建**

**分钟级时间线**
- 案发前后每分钟的活动
- 关键时间点的精确性

**关键时间校验**
- 交通时间：是否足够
- 电梯记录：是否匹配
- 门禁记录：是否吻合

**不在场证明拆解**
- 每个嫌疑人的不在场证明
- 证明的可靠性评估

**D-5 诡计选择**

**物理诡计**
- 密室诡计：如何在密室中作案
- 不在场诡计：如何伪造不在场

**叙述性诡计**
- 视角诡计：误导读者视角
- 时序诡计：混淆时间顺序
- 指代诡计：误导指代对象

**动机诡计**
- 慈善动机：表面慈善，实际复仇
- 反噬动机：被控制/被利用

**信息载体诡计**
- 影子诡计：利用影子制造混淆
- 回声诡计：利用回声误导
- 反光诡计：利用反光制造假象
- 延时诡计：利用延时制造不在场

**D-6 读者可验证性检查**

**三联对齐**
- 动机：在前期已展示
- 手法：在前期有伏笔
- 证据：在前期已出现

**检查清单**
- [ ] 所有解谜信息都提前展示给读者
- [ ] 没有突然引入新设定
- [ ] 线索逻辑自洽
- [ ] 反转有铺垫

**D-7 反转阶梯**

**Level-1 主反转**
- 揭露凶手
- 颠覆既定认知

**Level-2 真相反转**
- 揭露动机
- 进一步颠覆认知

**Level-3 情感/立意反转**
- 揭露深层真相
- 升华主题

**D-8 余味与续作口**

**半封闭结尾**
- 主要谜题解开
- 留有余味

**续作口设计**
- 未解之谜
- 新的谜题

### 10.2 使用建议

**短篇创作流程**
```
1. 选择结构模板（七拍/变体）
2. 应用大师级能力系统
3. 遵循去AI化写作规范
4. 选择风格/语言特色
5. 输出完整内容+备用航线+六维打分
6. 封面设计+种草提醒
```

**长篇创作流程**
```
1. 生成完整大纲
2. 创建三层记忆文件（大纲/追踪/章节）
3. 章节创作（≥3500字/章）
4. 伏笔管理/连贯性检查
5. 视觉呈现（封面/插画）
```

**风格模仿流程**
```
1. 选择目标风格
2. 应用风格特征
3. 结合具体题材/情节
4. 输出风格化内容
```
