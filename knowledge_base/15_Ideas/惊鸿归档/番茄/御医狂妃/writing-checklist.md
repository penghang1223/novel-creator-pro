# 《御医狂妃》写后自检清单

> 每章写完必须逐条过，不通过不保存。

---

## 🔴 硬性检查（不过=重写）

### 1. 全量名称扫描
- [ ] `grep -rn "旧名" 全书目录` → 零残留
- 适用场景：任何改名、改设定后，必须跑全量扫描，不能只看局部

### 2. 字数达标
- [ ] 本章 ≥ 3000 字
- 关键场景（对峙/发现/结盟/救人）≥ 1500 字，不准用一句话收场

### 3. 禁词/禁句式计数
- [ ] "看了很久" ≤ 2 次
- [ ] "然后笑了" ≤ 2 次
- [ ] "声音很低" ≤ 2 次
- [ ] "微微一笑" ≤ 2 次
- 用 `grep -c` 数，超了就重写那几段

### 4. Show > Tell 检查
- [ ] 扫一遍全文——看到"因为""所以""说明""意味着"→ 删掉→ 改成动作/表情/环境反应
- [ ] 医疗场景：不准写教科书式解释→ 用角色视角+感官细节呈现

### 5. 章末钩子
- [ ] 结尾必须有钩子（悬念/冲突/反转/情感悬念）
- [ ] 不准以"然后她就睡了""天黑了"这种无钩子方式结尾

---

## 🟡 质量检查（提升用）

### 6. 感官细节 ≥ 3 种
- [ ] 视觉（颜色/光影/动作）
- [ ] 听觉（声音/沉默/呼吸）
- [ ] 嗅觉/味觉/触觉（气味/味道/温度/质感）
- 每章至少覆盖 3 种感官

### 7. 对话潜台词
- [ ] 至少有一段对话——角色没有直接说出想说的话
- 用沉默、转移话题、答非所问、动作代替台词

### 8. 节奏变化
- [ ] 本章有快有慢——紧张场景用短句（7-12字），缓和场景用长句（25-40字）
- [ ] 不准一章到底全是短句或全是长句

---

## 📋 执行方式

1. 写完一章
2. 跑 `grep` 检查名称和禁词
3. 过 Show > Tell 检查
4. 过感官细节和对话检查
5. 全部通过 → 保存
6. 同步飞书（不等全部写完）
