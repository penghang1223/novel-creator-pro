# 场景氛围速查表

> 写场景时不准只写"发生了什么"，要写"那个地方是什么样的"。
> 每章至少覆盖3种感官。

---

## 视觉（不准只写"很暗""很亮"）

| 场景类型 | 可用细节 |
|---------|---------|
| 夜晚室外 | 灯笼的光在青石板上洇开/月亮被云遮住/星光碎成一片/影子拉长又缩短 |
| 室内昏暗 | 烛火跳了一下/灯油快烧干了/墙角黑成一团/窗纸上映出模糊的人影 |
| 白天热闹 | 阳光刺得人眯眼/摊贩的幌子在风里晃/人群挤成一片/颜色混在一起分不清 |
| 冷清空荡 | 灰尘在光柱里漂浮/蛛网挂在梁上/地上有干了的泥脚印/风穿过空房间发出呜咽 |

## 听觉（不准只写"很安静""很吵"）

| 场景类型 | 可用细节 |
|---------|---------|
| 紧张安静 | 呼吸声很重/心跳撞在耳膜上/指甲刮过桌面的声音/远处传来一声狗吠 |
| 热闹环境 | 小贩的叫卖声混在一起/孩子的哭声/铜钱叮当/讨价还价的嗓门越来越高 |
| 室内对话 | 茶杯碰在桌上的脆响/衣服摩擦的窸窣声/窗外的风吹动帘子/钟摆滴答 |
| 夜晚 | 虫鸣/风穿过竹林/远处的梆子声/屋顶瓦片被风吹动的嘎嘎声 |

## 嗅觉（最容易被忽略的感官）

| 场景类型 | 可用细节 |
|---------|---------|
| 室内 | 墨汁味/熏香/药味/旧纸张的霉味/木头受潮的味道 |
| 室外 | 桂花香/烤肉油烟味/马粪味/泥土被雨打湿后的腥气/街边酒肆飘来的酒香 |
| 紧张场景 | 血腥味/汗味/石灰的呛味/火药味 |
| 回忆场景 | 熟悉的香粉味/某个人身上的气味/某个地方的专属气味 |

## 触觉

| 场景类型 | 可用细节 |
|---------|---------|
| 紧张 | 手心出汗/指甲掐进掌心/衣服贴在背上被汗浸湿/牙齿咬到嘴唇 |
| 冷 | 手指冻得发僵/呼出的气变成白雾/脚底踩着冰冷的石板/风从领口灌进来 |
| 热 | 汗顺着脊背往下淌/衣服粘在身上/嘴唇干裂/阳光烤得头皮发烫 |
| 触碰 | 手指碰到冰凉的门环/粗糙的树皮/温热的手/丝绸滑过皮肤 |

## 味觉

| 场景类型 | 可用细节 |
|---------|---------|
| 紧张/恐惧 | 嘴里发苦/咬到舌头尝到血腥味/喉咙发干咽不下去 |
| 吃东西 | 茶凉了变涩/粥太烫烫到舌尖/馒头干得噎人/药苦得皱眉头 |
| 情绪波动 | 嘴里没味道/想吐/嘴里发甜（肾上腺素） |

---

## 使用规则

写场景时问自己：**读者能闻到/听到/摸到这个场景吗？**

如果不能——加至少一个非视觉的感官细节。

写完一段后检查：
- [ ] 这段有没有视觉以外的感官细节？
- [ ] 细节是具体的还是抽象的？（"桂花香"✅ vs "很香"❌）
- [ ] 细节和角色情绪有关联吗？（紧张时注意到的东西≠放松时注意到的东西）
