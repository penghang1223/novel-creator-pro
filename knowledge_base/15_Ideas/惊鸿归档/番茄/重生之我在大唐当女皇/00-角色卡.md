## 【主角：潘玥 / 晏昭玥】

| 项目 | 内容 |
|------|------|
| 今世名 | 晏昭玥（大衍王朝四公主） |
| 前世名 | 潘玥 |
| 性别 | 女 |
| 前世身份 | 市级机关公务员（经济稳定，非出租屋） |
| 今世身份 | 大衍王朝不受宠四公主 → 女皇 |
| 女皇尊号 | 改元"昭玥" |
| 前世死因 | 空难（与萧航同机遇难，实为时空局所为） |
| 标志 | 锁骨下的痣（锚印，穿越后消失→反复浮现→最终消散） |

**性格锚点**：
1. 护短——自己人受欺负，她一定站出来
2. 嘴硬心软——明明在意，嘴上绝不承认
3. 底线不可碰——"你凭什么替我做决定？"

**性格矛盾（P0）**：
- 矛盾：理性至上 vs 渴望被理解
- 上下文：面对萧航时
- 解决路径：第60章"背叛"后意识到情感不可替代→第110章感性觉醒→第140章破锚时感性主导
- 行为表现：理性时用权谋博弈（第12章试探萧航），感性时打破规则（第140章"我宁愿一起死"）

**情感触发点（P0）**：
| 触发 | 情绪 | 反应 |
|------|------|------|
| 萧航替她做决定 | 愤怒 | 质问"你凭什么替我做决定？" |
| 自己人受欺负 | 愤怒 | 立即保护，不惜得罪世家 |
| 萧航沉默不说话 | 不安 | 反复追问，但又怕听到真相 |
| 有人提"前世" | 怀旧+痛苦 | 身体会不自觉摸锁骨（痣的位置） |

**决策风格**：
- 风格：果断，逻辑为主→后期感性权重增大
- 依据：前期=利益最大化（机关经验），后期=情感优先（萧航改变她）
- 典型案例：第12章权谋试探（理性）→第140章破锚（感性主导）

**能力体系**：
- 核心：政策思维、危机管理、权谋博弈、组织协调
- 来源：前世机关经验 + 现代思维（数据分析/公关/反侦察）
- 限制：现代理念需转化为古代语境，穿越者优势有限（第18章改革失败）

**核心成长弧线**：
穿越适应 → 被迫卷入权斗 → 学会运用权谋 → 与萧航确认关系 → 发现锚真相 → 愤怒（"你凭什么替我做决定"）→ 打破锚规则 → 两个人一起活

**经典台词**：
- "王兄，你变没变我不知道，但我知道你最近脸上的褶子变多了。"
- "你凭什么替我做决定？你凭什么一个人扛？"
- "我宁愿和你一起死，也不愿意一个人活。"
- "这一世我不会再放手。"

**当前状态**：
- 第1-40章：穿越适应，与萧航确认关系，发现前世车祸非意外
- 第41-60章：热恋期，发现锚机制，崔善临死揭穿"他在做锚"
- 第60章：萧航"背叛"（实为保护），崩溃后查古籍发现锚的真相
- 第61-100章：低谷→恢复→夺嫡→登基为女皇
- 第110章：萧航完整坦白，做出"两个人一起活"的决定

## 【男主：萧航】

| 项目 | 内容 |
|------|------|
| 姓名 | 萧航 |
| 性别 | 男 |
| 身份 | 异国将军 / 穿越者 / 锚 |
| 前世 | 潘玥的恋人，同机遇难 |
| 穿越时间 | 比潘玥早三年 |
| 标志 | 意识逐渐磨损（先忘细节→忘对话→忘脸→只剩"我答应过她，要等她"） |

**核心设定——锚**：
- 每次穿越需要一个锚：有情感羁绊的人用自己的意识锁住穿越者灵魂
- 锚的意识逐渐磨损直至消散
- 萧航自愿做锚，换潘玥穿越活命，没有告诉她
- 代价：先忘她的笑→忘她的声音→忘她的名字→忘她的脸

**性格锚点**：
1. 守护——她的安全高于一切
2. 克制——"等你准备好"（第10章）
3. 自作主张——替她做决定（核心矛盾）

**性格矛盾（P0）**：
- 矛盾：想要保护她 vs 不信任她的选择
- 上下文：面对时空局威胁时
- 解决路径：第60章假背叛（选择保护她不告诉她）→第110章坦白后学会尊重→第140章接受"两人一起活"
- 行为表现：保护时=沉默隐瞒（不告诉她锚的事），尊重时=开口坦白（第110章完整说清）

**应对压力（P0）**：
| 维度 | 内容 |
|------|------|
| 典型反应 | 默默承受，不让她知道真相 |
| 身体征兆 | 脸色苍白、手会抖、眼神空洞、写信时笔抖 |
| 应对机制 | 刻玉佩（强化记忆）、写信（哪怕写错三次也要写）、坐在屋顶（独处消化） |
| 底线崩溃 | 当她直接质问时——他第一次说不出话（第110章） |

**人际交往**：
- 信任等级：仅对晏昭玥极高 / 对其他人保持距离
- 沟通风格：含蓄，少言，用行动代替语言
- 关系模式：对晏昭玥极度保护 → 对其他人礼貌但疏离 → 被触发锚记忆时会突然失神

**锚的衰变时间线**：
- 第45章：首次记忆断片（3秒忘名字）
- 第52章：看到锚记载时脸色苍白
- 第58章：整夜失眠坐屋顶
- 第89章：白天长时间断片
- 第96章：战场断片差点被砍
- 第99章：写信给晏昭玥（手抖写错"我爱你"三次）
- 第140章：意识消散
- 第141章：被晏昭玥找到，部分恢复

**经典台词**：
- "比你早三年。我一直在这里，等你。"
- "我等了三年，就是想问一个问题——你，原谅我了吗？"
- "忘了她，总好过她死。"（对时空局说）
- "我答应过她，要等她。"（意识模糊时唯一记得的话）

**核心成长弧线**：
默默守护 → 身份确认 → 热恋 → 被迫"背叛"（保护） → 意识持续磨损 → 坦白 → 消散 → 被找到 → 完全恢复

## 【反派阵营】

### 魏王

| 项目 | 内容 |
|------|------|
| 身份 | 皇子，野心勃勃 |
| 定位 | 前期主要对手（1-95章） |
| 标志 | 习惯性试探，只相信利益 |

**性格锚点**：
1. 野心——想推翻皇帝自己登基
2. 现实——"不现实，怎么活？"
3. 利己——只相信利益

**说话风格**：
- 用词：直接、带嘲讽，偏好"胆子""赢""现实""利益"
- 句式：短句试探（"四妹，你最近……"），结尾常反问（"那你急什么？急死？"）
- 潜台词：从不直接说意图，永远在试探对方反应

**决策风格**：
- 风格：急躁但计算利益，利益最大化
- 典型案例：第20章政变准备不足但铤而走险（"至少我有敢赢的胆子"）；第95章接受时空局交易（利益驱使）

**核心弧线**：
试探晏昭玥 → 散布绯闻 → 设陷阱 → 政变失败下狱（第20章）→ 时空局救走越狱（第82章）→ 接受时空局交易 → 叛乱失败被捕（第95章）

**经典台词**：
- "至少，我有敢赢的胆子。"
- "那你急什么？急死？"
