# 《重生之我在大唐当女皇》设定总纲

---

## 一、世界观

**时代背景**：大唐贞观十六年（公元642年），唐太宗李世民在位晚期。贞观之治余晖尚在，但朝堂暗流涌动——太子李承乾与魏王李泰的夺嫡之争日趋白热化，边疆突厥、吐蕃虎视眈眈。

**核心规则**：
- 女主潘玥拥有前世记忆与历史预知，但仅限于大事件走向，细节不可控
- 无法直接使用现代科技，但可将现代治理理念转化为古代语境
- 历史可被微调，但重大节点存在"历史惯性"——强行逆转会产生不可预见的连锁反应
- 重生为同名公主，原主记忆碎片式保留，情感残留会偶尔干扰判断

## 二、主要人物档案

### 【主角：潘玥】

| 项目 | 内容 |
|------|------|
| 姓名 | 李昭玥（大唐公主名），潘玥（前世名，内心自称） |
| 女皇尊号 | **天玺帝** |
| 百姓尊称 | **玥皇** |
| 登基年号 | **明贞** |
| 性别 | 女 |
| 年龄 | 重生前32岁，重生后回到18岁（贞观十六年） |
| 身份 | 现代政府办公室文秘 → 大唐公主 → 未来女皇 |
| 身高 | 168cm |
| 标志 | 左手无名指有一道细微伤疤（原主无此疤，重生后消失，是她确认身份转变的锚点）；气质清冷，凤眼微挑，自带三分疏离感 |

**外貌特征**：
- 身高168cm，身姿清瘦挺拔，如一株临风而立的寒竹
- 凤眼，眼尾微挑，不怒自威；鼻梁高挺；唇色偏淡，平时不苟言笑
- 不是艳丽型美人，而是清冷疏离型——五官精致但气息偏冷，让人第一眼不敢靠近，第二眼又忍不住再看
- 标志性瞬间：认真/生气时气场骤变，凤眼微眯，周围温度仿佛降了三度

**性格锚点（不可违背）**：
1. 护短——自己人受欺负，她一定站出来
2. 嘴硬心软——明明在意，嘴上绝不承认
3. 底线不可碰——哪怕权力斗争再激烈，有些事她绝不做

**经典台词**：
- "我不需要别人替我操心。我自己的事，我自己解决。"
- "你以为我傻？我只是在等一个合适的时机。"
- "少跟我来这套。我在体制内见过的手段，比你吃过的米都多。"
- "别误会，我救你，是因为你还有用。"
- "规矩是死的，人是活的。可有些底线，死都不能碰。"

**标志性动作**：
- 思考时用左手食指敲击桌面，频率渐快
- 生气时嘴角微微上扬，露出冷笑
- 处理政务时习惯整理衣袖

**能力体系**：
- 核心：政策思维、危机管理、权谋博弈、组织协调
- 来源：前世政府办公室十年经验 + 重生历史预知
- 限制：无法改变所有历史节点，现代理念需转化为古代语境
- 特殊：洞察人心、借力打力、在规则中寻找破绽

**成长弧线**：
抵触权力 → 被迫卷入 → 学会运用 → 理解责任 → 成为规则制定者

### 【男主：萧景寒】

| 项目 | 内容 |
|------|------|
| 姓名 | 萧景寒 |
| 性别 | 男 |
| 年龄 | 22岁（贞观十六年） |
| 身份 | 萧家长子，少年将军，后封摄政王 |
| 身高 | 185cm |
| 标志 | 右眼角一道细长伤疤（幼年护公主时留下） |

**性格锚点**：
1. 守护——公主的安全高于一切
2. 克制——深爱但绝不越界
3. 担当——出了事他先扛

**背景**：
萧家开国功臣之后，其父萧伯庸在贞观初年的一场宫变中替皇室挡刀而死。萧景寒自幼被接入宫廷，成为公主的侍卫兼玩伴。因父亲之死对皇室有复杂情感——既有世代忠诚的使命感，也有丧父之痛的隐忍。

**经典台词**：
- "公主说去哪，我就去哪。哪怕是刀山火海。"
- "我不需要你解释什么。我只要你在我的视线里。"
- "我知道你会恨我，但我不会后悔今天的决定。"
- "军令如山，可如果军令要伤你，那军令就滚。"

**标志性动作**：
- 永远站在公主身后半步
- 紧张时无意识摸右眼角伤疤
- 思考时按剑柄

**成长弧线**：
盲目忠诚 → 产生怀疑 → 学会独立思考 → 并肩作战的伙伴 → 共同开创盛世

## 五、写作规范

**文风**：第三人称，以潘玥视角为主。语言厚重但不文绉绉，现代意识融入古代语境。
**节奏**：每章2000-2500字，每3-5章一个小爽点。
**情感描写**：克制为主，眼神交流 > 直白表白，肢体接触暗示 > 大段抒情。
**权谋描写**：具体可操作，不要"她很聪明地解决了"这种空话，要写出具体策略。
