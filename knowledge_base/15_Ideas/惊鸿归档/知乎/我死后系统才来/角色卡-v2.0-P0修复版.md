## 👑 主角：沈默

### 人设对照表

| 维度 | 生前 | 死后 |
|------|------|------|
| **性格** | 善良老好人，有求必应 | 冷静理性，不再被感情绑架 |
| **处事** | 容易心软，被利用 | 以鬼魂视角旁观，只看事实 |
| **情感** | 重感情，信任朋友/爱人 | 看到真相后心寒，但不失底线 |
| **智商** | 不笨但太善良 | 系统加持 + 上帝视角 = 降维打击 |
| **底线** | 不愿伤害任何人 | 不主动害人，但不再替害自己的人开脱 |

### 基础信息

| 维度 | 设定 |
|------|------|
| **年龄** | 28 岁 |
| **身份** | 创业公司联合创始人（持股 60%） |
| **死因** | 车祸（刹车被动手脚） |
| **名字寓意** | "沈"沉入深渊→"默"沉默复仇→归来 |
| **成长弧线** | 老好人→被害→觉醒→复仇→和解→重生 |
| **经典台词** | "我都死了你才来？" / "也许我早就有预感了，只是不愿相信。" / "对不起，我来晚了。" |
| **记忆点** | ⭐⭐⭐⭐⭐ |

### 🔑 标志性视觉特征（P0 新增：C1 修复）

- **左手腕有一道旧疤**——小时候被碎玻璃划的，父亲抱着他跑了三条街去医院缝的针。这道疤是父子情的物理锚点，在第 12 章尾声回收。
- **外貌**：瘦高，戴银框眼镜，看起来无害。但认真时会把眼镜摘下来——这个动作在死后的鬼魂状态中依然保留，是他"认真起来了"的标志。

### 🔑 行为习惯（P0 新增：C2 修复）

| 习惯 | 场景 | 叙事功能 |
|------|------|----------|
| 思考时摘眼镜擦镜片 | 面对关键线索时 | 标志性动作，鬼魂状态仍保留（手穿过眼镜），制造心酸感 |
| 说谎/隐藏情绪时右手握拳 | 生前与许知远交往中 | 读者回看伏笔时会发现他其实隐约感到不对 |
| 压力大时反复确认手机 | 创业期间 | 反映老好人性格——害怕遗漏别人的请求 |

## 🤖 系统人格：小寂

### 基础信息

| 维度 | 设定 |
|------|------|
| **真实身份** | 沈默父亲沈建国生前秘密开发的 AI（用沈默儿时照片训练） |
| **形象** | 穿白衣的小孩，面无表情→结局变成沈默儿时的样子 |
| **性格** | 绝对理性，不懂感情，偶尔冒出让人破防的话 |
| **口头禅** | "宿主，你生前的判断失误率高达 87.3%。" |
| **功能** | 任务派发 + 倒计时 + 能力解锁 + 冷酷吐槽 |
| **成长线** | 纯工具→理解感情→牺牲自己帮主角复活 |
| **名字寓意** | "寂"——死后寂静，也是系统的孤独 |
| **经典台词** | "你已死亡。是否启动死后模式？" / "你的识人能力评分：12 分。" / "爸爸爱你。——沈建国" |
| **记忆点** | ⭐⭐⭐⭐⭐ |

### 🔑 系统限制规则（P0 新增：C3 修复）

> **核心约束**：小寂为什么知道真相但不能直接说？

| 规则 | 内容 | 叙事功能 |
|------|------|----------|
| **因果协议** | 沈建国在代码中写入了"因果锁"：系统不可主动透露死因相关信息，只能提供工具让宿主自行发现。违反则系统自毁。 | 解释为什么小寂不直说 |
| **情感泄漏** | 尽管有因果锁，小寂偶尔会"不小心"流露出父亲的语言习惯——第 2 章的"你这孩子"、第 10 章声音变化 | 制造伏笔和温暖 |
| **设计初衷** | 沈建国设定因果锁的原因：他要的不是替儿子报仇，而是让儿子在调查过程中"看清身边的人"——真正成长 | 升华父爱主题 |

### 🔑 功能代价体系（P0 新增：L1 修复配套）

| 功能 | 能量消耗 | 解锁条件 |
|------|----------|----------|
| 情感扫描 | -3h | 系统激活后默认可用 |
| 死因重现 | -5h | 需宿主确认 |
| 嫌疑人锁定 | -2h | 死因确认后解锁 |
| 线索追踪 | -3h | 有嫌疑人后可用 |
| 记忆回放 | -8h | 关键线索触发 |
| 隐藏记忆解锁 | -6h | 核心关系人相关 |
| 鬼魂影响 | -10h | 仅限紧急情况 |
| 隐藏任务 | -5h | 关联事件检测 |
| 身份揭露 | -3h | 最终阶段 |
| 复活 | 全部剩余 | 代码注释触发 |

## 👿 凶手：许知远（挚友变凶手）

### 基础信息

| 维度 | 设定 |
|------|------|
| **年龄** | 28 岁 |
| **身份** | 沈默大学室友兼创业合伙人（持股 40%） |
| **表面** | 温文尔雅，所有人眼中的"好人" |
| **真相** | 极度嫉妒主角才华，策划了一场"意外" |
| **性格** | 笑面虎——永远微笑，永远在算计 |
| **名字寓意** | "许"谐音"虚"，"知远"看似深远实则虚伪 |
| **经典台词** | "这把椅子，我等了八年。" / 葬礼痛哭→转身笑着打电话 |
| **记忆点** | ⭐⭐⭐⭐ |

### 🔑 动机深层设计（P0 新增：C4 + C5 修复）

> **核心问题**：一个隐忍了 8 年的人，为什么突然选择杀人？

**三层动机递进**：

| 层次 | 动机 | 积累时间 |
|------|------|----------|
| **底层** | 嫉妒——沈默不费力就拿到他拼命才能争取的东西（才华、人脉、投资人青睐） | 大学时期起 |
| **中层** | 利益——沈默持股 60%，许知远只有 40%，但公司 80% 的业务是许知远在跑 | 创业 4 年起 |
| **表层（最后的稻草）** | 恐惧——沈默准备引入新投资人，新一轮融资后许知远股份将被稀释到不足 10%。八年的等待即将归零。 | 死前 1 周 |

**心理崩溃触发链**：

1. 死前 2 周：沈默兴奋地告诉许知远"找到了大投资人"
2. 死前 1 周：许知远拿到融资协议，发现自己将被稀释到 10%
3. 死前 5 天：许知远写了一封给沈默的信——"你答应过我的"，反复修改 7 次，最终删除
4. 死前 3 天：许广达（许知远父亲）打来电话，说了什么不知道，但通话后许知远去买了刹车油管切割工具
5. 死亡当天：许知远蹲在车底，手在发抖，犹豫了 3 秒

**关键细节**：
- 他用一次性手机卡打电话，只说了一个字"妥"，然后掰断 SIM 卡扔进下水道
- 他不是冷血杀手——他手在发抖，犹豫了。但他还是下手了
- 杀完人后在葬礼上的痛哭**不全是演的**——他确实有 3% 的真实愧疚

| 独处时面无表情 | 沈默鬼魂跟踪时看到 | 面具剥落的瞬间 |

## 💕 法医前女友：林晚晚

### 基础信息

| 维度 | 设定 |
|------|------|
| **年龄** | 27 岁 |
| **身份** | 法医，沈默的前女友（被许知远挑拨分手） |
| **分手原因** | 许知远伪造出轨证据，让沈默主动分手 |
| **真相** | 她一直爱沈默，分手后仍在暗中调查"意外"死因 |
| **能力** | 法医专业 + 敏锐直觉 + 执着性格 |
| **角色功能** | 阳间调查线推动者——主角鬼魂看到真相，但需要活人收集证据 |
| **名字寓意** | "晚"——来得太晚，也是最后的温暖 |
| **经典台词** | "你没来晚。你回来了就好。" |
| **记忆点** | ⭐⭐⭐⭐⭐ |

### 🔑 主动性增强（P0 新增：C6 修复）

> **核心修改**：林晚晚不再是被动等待真相的"催化剂"，而是主动追查的"阳间侦探"。

**独立行动线**：

| 章节 | 行动 | 叙事功能 |
|------|------|----------|
| 第 2 章 | 独自参加葬礼，在角落观察（伏笔） | 暗示她没放下 |
| 第 7 章 | 主动调取车祸报告 + 找许知远前女友套话 + 去修车店调查 | 展示法医的专业能力和执着 |
| 第 9 章 | 收到赵婷消息后，开车去接赵婷到自己公寓保护 | 展示担当——不是等别人来救，而是主动保护证人 |
| 第 12 章 | 用法医专业知识提供完整证据链，配合警方 | 阳间正义的执行者 |

**关键场景**：
- 深夜实验室翻阅尸检报告流泪
- 手机壁纸至今没换（碎屏手机换了保护膜但没换壁纸）
- 对赵婷说："你在我这里是安全的。"

### 🔑 行为习惯

| 习惯 | 场景 | 叙事功能 |
|------|------|----------|
| 工作时把头发扎成高马尾 | 法医工作 / 调查时 | 职业感 |
| 紧张时咬下嘴唇 | 翻阅尸检报告时 | 细腻情感 |
| 从不主动删除聊天记录 | 手机里还有所有和沈默的对话 | 深情伏笔 |
