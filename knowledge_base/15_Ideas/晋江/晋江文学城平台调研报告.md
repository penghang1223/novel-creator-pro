## 一、平台概况

| 维度 | 数据 |
|------|------|
| **创立时间** | 2003年8月（前身为网友众筹搭建的论坛） |
| **运营主体** | 北京晋江原创网络科技有限公司（2006年成立，注册资本1110万元） |
| **股权结构** | 阅文集团间接持股50%（通过上海宏文），创始团队（黄艳明、刘旭东等）控股运营 |
| **平台定位** | **中国最大的女性向网络文学原创基地**，女频网文头把交椅 |
| **日均 PV** | 超1亿 |
| **日登录固定用户** | 约220万 |
| **月活跃用户（MAU）** | 约535万（2023年11月数据） |
| **2025品牌排名** | 网络文学品牌 Top 10（中国品牌网、买购网） |
| **版权输出** | 覆盖20+国家，版权输出总量3000+部，改编作品5000+部 |

### 付费模式

- **VIP 章节订阅**：核心收入来源，读者付费阅读 VIP 章节（千字约3分钱）
- **打赏/投雷/手榴弹**：读者自愿打赏，作者与平台 **5:5 分成**
- **影视/出版版权**：影视版权作者与平台 **8:2 分成**（作者8）
- **广播剧/有声/漫画改编**：多样化 IP 衍生变现

## 二、读者画像

| 维度 | 特征 |
|------|------|
| **性别比例** | 女性用户占比 **>91%**，是全网女性用户最集中的网文平台 |
| **年龄分布** | 18-35 岁为主力，Z 世代（18-25岁）占比持续增长 |
| **消费能力** | 付费意愿强，VIP 订阅 + 打赏双驱动，核心读者 ARPU 值在网文平台中偏高 |
| **阅读偏好** | CP感 > 剧情，情感描写细腻优先；反玛丽苏、反套路；重视"人设好嗑" |
| **用户特征** | ① 口味杂（言情/纯爱/百合/无CP/衍生通吃） ② 讨厌主角滥情/太苏/太小白 ③ 对抄袭、敏感话题零容忍 ④ 社区参与度高（论坛活跃、催更文化强） |

> **我的判断**：晋江的读者不是一个同质群体，而是由"言情读者""纯爱读者""同人读者""百合读者"等多个亚文化圈层叠加而成的"万花园"。每个圈层的审美标准、付费逻辑、社区规则都不同——这是晋江的优势（生态丰富），也是劣势（审核难统一）。

## 四、新人作者生存指南

### 签约门槛

| 项目 | 要求 |
|------|------|
| **最低字数** | 已发表 **1万字以上** 文章 |
| **申签材料** | 300字简纲 + 50字人设 + 看点 + 创新点 |
| **考试** | 30道题（25道固定 + 5道随机，涉及举报规则、违规判定等） |
| **身份证明** | 身份证正反面扫描 + 银行卡 + 手机号 |
| **排他性** | **签身份证**，5年起步独家代理权，到期自动续期 |
| **年产量要求** | 每年至少1部 ≥20万字的作品 |

### 推荐机制

- **新书榜**：月榜/季榜/半年榜（新作品曝光）
- **新晋作者榜**：新作者专属曝光通道
- **金榜/VIP金榜**：全站作品按收藏+订阅排名（头部流量入口）
- **频道新晋榜**：各频道（言情/纯爱/幻想等）独立排名
- **榜单公平性**：拼收藏量和订阅量，编辑不干预排名（相对透明的推荐机制）

### 收入水平

| 收入类型 | 分成比例 | 说明 |
|----------|----------|------|
| **VIP订阅** | 电脑端 作者60%:平台40%，手机端另议 | 千字约3分 × 订阅数 |
| **打赏/投雷** | 50%:50% | 读者自愿打赏 |
| **全勤奖** | VIP收入的7%（日更3000字）或12%（日更6000字） | 入V后才有 |
| **影视版权** | 作者80%:平台20% | 优质作品核心变现路径 |
| **出版版权** | 视具体合同而定 | 出版转化率高 |

### 收入分布参考

| 层级 | 月收入 | 占比 |
|------|--------|------|
| 新人/透明作者 | <2000元 | 约44.6% |
| 中层作者 | 2000-5000元 | 约20.1% |
| 腰部作者 | 5000-10000元 | 约28% |
| 头部作者 | 10000-20000元 | 约7.1% |
| 大神级 | >20000元 | 约4.1%（全站月入破万约481人） |

> **⚠️ 关键提醒**：
> - 签约=有收入，不签约=0收入
> - **没有保底稿酬**，纯靠订阅和打赏
> - 入V门槛：言情频道需收藏≥300，耽美频道需收藏≥350
> - 开头5万字决定能不能签约，新人建议先发1万字申请
> - 被驳回后一周可重新申请
> - 解约极难：5年合同期 + 满字数要求 + 可能付违约金

## 五、2026 年趋势变化

### 🔴 重大事件：3月"锁文-发票"风波（信任危机）

2026年3月，晋江爆发平台历史上最大规模用户抗议：

**事件链：**
1. **3月24日**：热门女性觉醒向小说《女主对此感到厌烦》（豆瓣9.0分，已出版、改编音乐剧）被突然锁定，理由模糊
2. **3月25日**：平台回应称"疑似挑动对立"，恢复上架但抛出"严禁使用非经汉语权威机构承认的生造字词"标准，举例禁用"老天奶"——用户扒出晋江官方曾用该词宣传，质疑双标
3. **3月25-26日**：用户大规模申请历史充值发票抗议，单日排队从3万飙至19万，后续突破30万→42万+
4. **3月26日**：晋江发情况说明，将用户合法开票定性为"过激行为""报复"，副总裁刘旭东称开票是"魔法攻击"、"手累酸了"
5. **后续**：用户质疑税务合规（发票入口藏4层菜单），部分用户向税务部门投诉

**影响评估：**
- 用户信任严重受损，核心读者群出现流失
- 多部晋江作品转战番茄、微信读书等平台登上搜索榜首
- 作者群体人心不稳，部分转向其他平台

### 内容审核趋势收紧

- **"脖子以下"红线**：不得出现脖子以下的亲密描写，执行一刀切
- **AI 审核介入**：政府扫描平台 + 平台自查双重机制
- **分年龄推荐体系**：计划对不适合未成年人的作品标记18+
- **审核标准摇摆**：规则朝令夕改，执行层面缺乏一致性

### 网文出海加速

- 晋江已覆盖20+国家版权输出
- 2026年3月：晋江文学城与"中国(温州)网络文学交流中心"签订合作意向书
- AI翻译技术突破→出海作品数量有望井喷
- 亚洲海外市场占全球网文市场约55%

### 行业竞争格局变化

- 免费平台（番茄/七猫）持续蚕食付费用户
- 晋江 MAU 增长停滞（约535万），而番茄小说 MAU 已远超
- 阅文集团对晋江的资本控制与运营独立性之间的张力加剧

| **适合题材** | 言情/纯爱/百合/无CP | 玄幻/仙侠/都市/历史 | 都市/玄幻/脑洞 |

### 🌙 我的判断与建议

**对作者的选平台建议：**
- **女频新人练手** → 番茄小说（流量大、门槛低），积累成绩后再冲晋江
- **女频有写作功底** → 晋江（IP价值高、读者粘性强，但要做好"第一本零收入"的准备）
- **求稳拿保底** → 七猫（千字20起，适合套路文）
- **男频作者** → 起点（男频证道之地）

**晋江的未来判断：**
- 优势：女频IP价值无可替代，影视改编转化率高
- 风险：审核争议+技术落后+用户信任危机，如果不解决系统性问题，可能从"女频一姐"位置跌落
- 机会：出海（20+国家版权输出）+ AI翻译突破 = 新增长点
