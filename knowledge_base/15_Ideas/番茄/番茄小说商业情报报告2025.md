# 番茄小说商业情报调研报告

> 调研时间：2026-04-24 | 调研者：望舒 🌙
> 数据来源：番茄小说官方作家福利页、澎湃新闻、36氪、QuestMobile公开数据、行业分析

## 一、平台概况

| 维度 | 数据 |
|------|------|
| **所属公司** | 北京时光荏苒科技有限公司（字节跳动旗下） |
| **上线时间** | 2019年 |
| **商业模式** | 免费阅读 + 广告变现 + 会员免广告 + 网文IP衍生 |
| **MAU** | 1.92亿（2023年12月，QuestMobile），同比+35.8%，行业第一 |
| **行业排名** | 数字阅读行业MAU第一，远超第二名七猫小说（0.9亿） |
| **竞争对手** | 七猫小说（百度系）、掌阅、书旗小说（阿里）、起点读书（阅文/腾讯） |
| **内容生态** | 2023年12月MAU 1.92亿，2022年6月1.09亿，2020年12月6162万——**三年增长31倍** |
| **公司运营主体** | 京ICP备18018851号-8，京B2-20200085，有出版物经营许可证、广播电视节目制作经营许可证 |

### 平台定位

**核心定位**：免费网络文学阅读平台，背靠字节跳动流量生态（今日头条、抖音导流）

**商业模式本质**：流量生意——平台通过广告投放获客，用户在阅读中观看广告产生收入，与作者分成。与付费平台（起点、晋江）的"内容付费"模式截然不同。

**战略方向**：从"免费网文"向"IP生态"转型——番茄影视、番茄动漫两大厂牌 + 爱奇艺影视IP白金合作伙伴 + "和光计划"打通产业链

## 二、用户画像

| 维度 | 特征 |
|------|------|
| **核心用户群** | 下沉市场用户为主，价格敏感型 |
| **阅读偏好** | "爽文"、"杀时间"为导向，每3章1个高潮（付费平台10-20章1个高潮） |
| **用户行为** | 免费+网赚模式（"阅读赚金币"签到提现）驱动留存 |
| **男女频比例** | 男频与女频并重，女频偏言情/穿越/重生，男频偏玄幻/都市/系统 |
| **用户留存机制** | 签到赚金币、阅读时长奖励、书架收藏 |

### 用户画像推断

- **年龄**：18-40岁为主，学生+上班族+下沉市场
- **地域**：三四五线城市占比高
- **消费习惯**：不愿为单本内容付费，但接受"看广告换免费阅读"
- **阅读场景**：碎片化时间（通勤、睡前、休息间隙）
- **单用户价值**：远低于付费平台用户，但**用户基数是付费平台的10倍以上**

## 三、热门品类与趋势

### 男频热门品类（2025）

| 品类 | 特征 | 商业价值 |
|------|------|----------|
| **都市系统** | 主角获得金手指系统，逆袭打脸 | 读者基数最大，广告变现天花板高 |
| **玄幻修仙** | 升级流、斗法、世界观宏大 | 长篇潜力大（200万字+） |
| **历史穿越** | 现代知识+古代背景 | IP改编价值高（影视/短剧） |
| **末世/科幻** | 废土生存、系统种田 | 近年增长快，年轻读者偏好 |
| **都市神医/战神** | 扮猪吃虎、扮弱打脸 | 下沉市场最爱，爽点密集 |

### 女频热门品类（2025）

| 品类 | 特征 | 商业价值 |
|------|------|----------|
| **重生/穿越** | 重生复仇、穿越逆袭 | 女频第一大品类，阅读量大 |
| **古言/宫斗** | 古代言情、宅斗宫斗 | IP改编价值最高（短剧首选） |
| **现言/甜宠** | 总裁、校园、豪门 | 受众广但同质化严重 |
| **年代文** | 改革开放年代背景 | 近年热门，中老年女性读者偏爱 |
| **种田/快穿** | 慢节奏种田、快穿任务 | 粘性高、完读率高 |

### 2025-2026趋势判断

1. **题材融合加速**：单一品类同质化严重，"历史+系统"、"科幻+修仙"等跨界题材吃香
2. **短篇化趋势**：短故事/微小说在平台崛起（平台已区分"长篇网文"和"短故事"）
3. **IP向内容需求增长**：能被改编为短剧/动漫的作品获得额外分成和曝光
4. **AI辅助写作兴起**：部分作者开始用AI辅助生成大纲、初稿，但平台对纯AI内容有审核风险
5. **反套路/反同质化**：读者开始对重复套路疲劳，"反套路"作品容易脱颖而出

## 四、平台规则详解（2025版·官方数据）

### 4.1 签约规则

| 项目 | 规则 |
|------|------|
| **签约门槛** | 发布字数超过2万字 → 番茄作家助手点击签约 → 审核通过即可 |
| **审核标准** | "只要内容不违规，审核几乎没有门槛"（海克财经调研） |
| **签约类型** | 分成签约（55分成）/ 保底签约 / 超保底签约 |
| **版权归属** | 签约即授予平台版权，通常为20年 |
| **首发要求** | 必须"独家原创首发"才享受全部福利 |
| **非首发作** | 不参与全勤奖等各项平台福利 |

### 4.2 收入模式与分成

#### 基础收入（听读分成）

- **分成比例**：55分成签约（作者50%，平台50%）
- **收入来源**：用户在阅读作品时观看广告产生的广告收入分成
- **计算公式**：听读分成收益 = 广告展示量 × 广告单价 × 分成比例
- **重要**：广告单价、展示次数等核心数据**不向作者公开**，收入全靠平台算法计算

#### 2025年作家福利体系（官方：超一亿现金扶持）

| 福利项目 | 奖励对象 | 核心条件 | 奖励幅度 |
|----------|----------|----------|----------|
| **全勤奖** | 独家原创首发签约小说 | 日更≥4000字，月听读分成≥500元，字数满10万字次月起 | 分档（具体金额看后台图片） |
| **星火计划** | 55分成签约非同人小说 + 满足全勤奖条件 | 按"万字读完率"周均值和字数评估 | 分字数段奖励，同一字数段仅发一次 |
| **全年奖** | 全体签约作家 | 按签到天数+完结作品听读收益评估 | 全年核算，最高档位可达数十万 |
| **半年奖** | 全体签约作家 | 同上，分上下半年独立核算 | 取与全年奖/季度奖中最高的一项 |
| **季度奖** | 全体签约作家 | 同上，分4个季度独立核算 | 同上 |
| **优质加更奖** | 55分成/超保底签约连载小说 | 7日有效追更人数≥8000人，分档 | 按追更人数分档 |
| **新书追更奖** | 55分成非同人非保底签约 | 字数10-80万+全勤+月听读≥1000元 | 按追更人数分档 |
| **拉新激励奖** | 分成签约连载小说 | 月有效字数≥6万+月听读≥2万元 | TOP 50，单月单部**4000元~50万元** |

#### 福利叠加与互斥规则

- **全年奖、半年奖、季度奖**：同一自然月取最高一项，**不可叠加**
- **全勤奖、星火计划、优质加更奖、新书追更奖、拉新激励奖**：**可叠加**
- **单人全年总奖金最高可超百万元**（官方宣称）
- **符合条件自动发放，无需申请**

### 4.3 更新要求

| 项目 | 要求 |
|------|------|
| **全勤奖日更** | 每日有效更新≥4000字 |
| **签到机制（作者维度）** | 单日有效更新≥4000字或使用补签卡 |
| **补签卡** | 每月1日自动发1张；日更≥1万字额外得1张 |
| **补签上限** | 每季度最多使用6张 |
| **请假** | 每本书每月可请假1天（在打卡日历申请） |
| **补签限制** | 仅支持当月补签，不支持跨月 |
| **统计截止** | 次月1日凌晨，勿在次月1日修改内容 |

### 4.4 提现规则

- **提现门槛**：收益满100元方可提现
- **提现方式**：微信提现等
- **发放周期**：各项奖金随当月稿费发放

### 4.5 结算税务

- 稿费/奖金属于"稿酬所得"，平台代扣代缴个人所得税
- 具体税率按国家稿酬所得税标准执行（20%比例税率，有减征优惠）
- 大额收入建议咨询税务专业人士

## 五、内容审核与红线

### 5.1 内容发布规范（红线）

| 红线类别 | 具体内容 | 后果 |
|----------|----------|------|
| **违法违规** | 违反国家法律法规的内容 | 直接下架/封号 |
| **政治敏感** | 涉及政治敏感话题、诋毁国家领导人 | 立即处理 |
| **色情低俗** | 露骨色情描写、淫秽内容 | 下架/修改/封号 |
| **暴力血腥** | 过度暴力、血腥描写 | 下架/修改 |
| **侵犯版权** | 抄袭、洗稿、旧稿挪用、版权瑕疵 | 取消全部奖励 |
| **刷数据作弊** | 恶意刷取听读收益/刷数据 | 取消全部奖励 |
| **恶意水文** | 重复章节、恶意水文 | 取消全勤等奖励 |
| **章节重复** | 章节内容大量重复 | 系统自动拦截 |
| **旧稿挪用** | 在其他平台发布过的内容 | 不符合"首发"要求 |

### 5.2 审核机制特点

- **机审为主**：系统自动检测违规内容，包括重复段落检测
- **人工审核**：重要节点（签约、完结）有人工介入
- **违规后果**：轻则修改，重则**停止推荐分发**（作品在站内无法搜索到）
- **客服沟通**：违规原因通过站内信通知，但有时不具体说明
- **恢复机制**：修改后可申请恢复推荐，但流量通常大不如前

### 5.3 作者吐槽的典型问题

1. **违规通知不明确**：站内信文本里不具体说明违反什么规则
2. **系统检测过于机械**：两个结局略有相似即提示"重复段落"无法发表
3. **停止推荐 = 变相封杀**：搜索引擎和平台内都无法搜索到
4. **无保底签约风险大**：20年版权 + 无保底 = 写作数月可能收入为零

| **模式** | 免费+广告 | 免费+广告 | 付费阅读 | 付费阅读 |

### 番茄的优势
- **流量优势**：字节系导流（今日头条、抖音），获客成本极低
- **新人门槛低**：2万字即可签约，无需编辑看中
- **收入机制透明**：虽然单价不公开，但全勤奖等福利规则明确
- **IP转型机会**：短剧、动漫改编通道开放

### 番茄的劣势
- **内容质量天花板**：免费模式导致"爽文"为主，深度内容少
- **算法黑箱**：推荐算法不透明，作者无法预测流量走向
- **版权绑定**：签约即授20年版权，后续自主改编空间有限
- **同质化严重**：大量相似题材导致单部作品竞争激烈

## 七、短剧/漫剧改编机会

### 7.1 番茄IP改编现状

| 项目 | 数据 |
|------|------|
| **IP已售出** | 截至2023年11月：75部小说版权售出 |
| **动画开发中** | 截至2023年11月：18部作品动画开发中 |
| **2024年上线预期** | 超过10部作品上线 |
| **重点厂牌** | 番茄影视、番茄动漫 |
| **合作伙伴** | 爱奇艺（白金合作伙伴）、芒果TV（大芒计划）、优酷 |

### 7.2 成功案例

| 作品 | 改编形式 | 结果 |
|------|----------|------|
| 《少帅，你老婆又双叒叕被人撩了》→《锁爱三生》 | 短剧 | 优酷"2023年度扶摇最具IP价值" |
| 《穿成四个拖油瓶的恶毒后娘》→《当家小娘子》 | 短剧 | 优酷"2023年度扶摇最具IP价值" |
| 《重生：回到1983年当富翁》 | 短剧 | 优酷"2023年度扶摇最具IP价值" |
| 《我在精神病院学斩神》 | 动画+真人影视 | 累计阅读近1000万，番茄寄予厚望 |
| 《黑莲花上位手册》 | 短剧 | 曾爆红后被下架（内容违规），改编自有番茄原著 |

### 7.3 短剧改编条件与建议

- **女频古言/穿越/重生**最适合短剧改编
- **故事节奏快、冲突密集**的作品优先
- **20-50万字**的作品最适合改编（太长成本高，太短内容不够）
- **签约时注意版权条款**：如希望自行保留影视版权，需与平台协商
- **番茄影视向收稿**：2023年7月开放影视向网文收稿，高比例分成

### 7.4 AI漫剧机会

- 2026年AI漫剧市场约350-500亿增量
- 番茄小说 + AI漫剧 = **新蓝海**
- 小说→AI漫画→短剧 的三级IP开发链正在形成
- 建议：创作时考虑"画面感"，方便后续AI漫剧转化

## 九、收入波动因素与风险分析

### 9.1 影响收入的核心因素

| 因素 | 影响程度 | 说明 |
|------|----------|------|
| **推荐算法** | ⭐⭐⭐⭐⭐ | 算法推荐决定曝光量，是最大的不确定因素 |
| **完读率** | ⭐⭐⭐⭐⭐ | "万字读完率"是核心指标，直接影响星火奖和后续推荐 |
| **追更人数** | ⭐⭐⭐⭐ | 7日有效追更人数决定加更奖和新书追更奖 |
| **更新频率** | ⭐⭐⭐⭐ | 日更4000字是基础，断更直接影响全勤和推荐 |
| **题材热度** | ⭐⭐⭐⭐ | 热门题材自带流量，冷门题材起步难 |
| **字数节点** | ⭐⭐⭐ | 10万、20万字是流量推荐的关键节点 |
| **评分** | ⭐⭐⭐ | 平台评分（基于阅读量和完结量计算）影响推荐 |

### 9.2 典型收入场景

| 作者类型 | 月收入预估 | 说明 |
|----------|-----------|------|
| **纯新人（首月）** | 0-200元 | 大多数新人首月收入极低 |
| **普通作者（稳定期）** | 500-3000元/月 | 满足全勤+基本推荐 |
| **中等作者** | 3000-1万元/月 | 有一定追更人数，可能拿星火奖 |
| **头部作者** | 1万-10万元/月 | 高追更+全勤+多项奖金叠加 |
| **超头部** | 10万-50万元+/月 | 拉新奖TOP 50，单月最高可达50万 |

### 9.3 风险提示

1. **收入极不稳定**：算法调整可能导致收入断崖式下跌
2. **"前几章决定命运"**：开头不好→推荐少→无收入→恶性循环
3. **20万字陷阱**：20万字后流量推荐下降，但继续写性价比低
4. **版权风险**：签约即授20年版权，后续自主改编受限
5. **审核风险**：被判定违规后停止推荐，作品相当于"消失"

## 十、2026年最新趋势与政策变化

### 10.1 行业趋势

1. **免费+付费混合模式**：番茄也在推会员免广告服务，收入多元化
2. **AI辅助创作普及**：AI辅助大纲/初稿/润色成为趋势，但纯AI内容可能被限制
3. **短剧市场持续爆发**：番茄小说→短剧的IP转化链更加成熟
4. **出海**：番茄小说海外版（Fiction）在东南亚、北美市场扩张
5. **内容精品化**：平台开始引入知名作家（如马伯庸《太白金星有点烦》首发）

### 10.2 政策环境

1. **网络文学监管趋严**：国家网信办持续整治"低俗擦边"内容
2. **AI生成内容规范**：2024年起AI生成内容需标注，网文领域开始适用
3. **版权保护加强**：《著作权法》修订后，网文版权保护力度加大
4. **短剧监管**：广电总局对微短剧内容审核趋严，影响IP改编方向

### 10.3 对创作者的影响

- **合规成本增加**：内容红线扩大，审核更严格
- **AI标注要求**：使用AI辅助需标注，否则可能违规
- **精品化趋势**：低质"水文"越来越难获得推荐
- **IP价值提升**：能被改编的作品溢价更高

## 十一、新人入局建议

### 11.1 入局路径

```
注册 → 发文（每日更新） → 满2万字签约 → 满足全勤条件 → 获得基础收入
                                                    ↓
                                        优化内容→提高完读率→获得更多推荐
                                                    ↓
                                        冲刺星火奖/加更奖/追更奖→收入提升
                                                    ↓
                                        作品完结→冲刺全年/半年/季度奖
```

### 11.2 关键建议

| 建议 | 说明 |
|------|------|
| **开头极其重要** | 前3章决定生死，必须抓人，设置悬念/冲突 |
| **日更4000字是底线** | 全勤奖基础，也是推荐算法的最低要求 |
| **选热门品类** | 新人选冷门品类=地狱难度，先蹭热点再求突破 |
| **控制节奏** | 每3章一个高潮，高潮前设"钩子"吸引继续读 |
| **利用字数节点** | 10万字、20万字是推荐爆发点，在这些节点前要储备优质内容 |
| **不要水文** | 2025年规则调整后，水文直接影响全勤和星火资格 |
| **关注补签机制** | 每月1张补签卡+日更1万字得1张，合理利用避免断签 |
| **签约注意版权** | 默认20年版权，如希望保留影视版权需协商 |
| **不要纯AI生成** | 平台可能有AI检测，纯AI内容有违规风险 |
| **短剧思维创作** | 故事节奏快、画面感强的作品更容易被改编 |

### 11.3 避坑指南

1. ❌ 不要在次月1日修改内容（影响上月签到统计）
2. ❌ 不要抄袭/洗稿/旧稿挪用（直接取消全部奖励）
3. ❌ 不要刷数据/刷分成（封号风险）
4. ❌ 不要一稿多投（必须独家首发才能享受福利）
5. ❌ 不要忽视读者评论（差评影响评分和推荐）
6. ❌ 不要在20万字后摆烂（影响完结质量和年度奖）

## 十二、为"灵犀"创意策划的战略建议

### 12.1 平台机会点

1. **题材蓝海**：历史+系统、科幻+玄幻、考据穿越等融合题材竞争尚不激烈
2. **短剧适配**：创作时按短剧节奏写（每集3000-5000字一个完整冲突单元），后续改编价值翻倍
3. **AI漫剧先行者**：用AI将小说转化为漫画，形成"小说→漫画→短剧"三级IP链
4. **系列化运营**：同一世界观下的系列作品，读者互相导流

### 12.2 收入最大化策略

```
第一步：选择热门品类 + 强冲突开头 → 通过签约
第二步：日更4000字拿全勤 → 月听读≥500元
第三步：提高完读率冲星火奖 → 月度收入×2
第四步：7日追更≥8000冲加更奖 → 收入再×1.5
第五步：作品完结冲全年/半年奖 → 年终大额奖金
第六步：版权售出/短剧改编 → IP收入
```

### 12.3 长期IP战略

- **女频古言/重生** → 短剧改编价值最高
- **男频都市/玄幻** → 动漫改编潜力大
- **历史/科幻** → 影视化（长剧/电影）天花板最高
- **系列化** → 同一IP的多部作品互相引流
