# 方向B：《我把公司写进了我的辞职信》

> 灵犀 💡 | 2026-04-22
> 类型：职场复仇爽文 | 第一人称 | 15-20万字
> 对标：《被裁员那天，我带走了公司最值钱的东西》（20-50万）
> 预估：过稿率70%，收入10-50万，完读率65%

---

## 一、一句话故事

被上司抢了三年方案后，我被公司裁员——但我没有走，我用辞职信里埋的十个"彩蛋"，让全公司从上到下身败名裂。

---

## 二、世界观设计（五维模型）

| 维度 | 设计 |
|------|------|
| **时空** | 2026年，深圳，一家中型互联网公司（"星耀科技"，做AI营销工具） |
| **规则** | 职场潜规则：功劳归领导、背锅归下属；KPI至上，不择手段；"末位淘汰"是常态 |
| **权力** | CEO（资本方）→ VP（执行层）→ 总监（中间层）→ 普通员工（底层）；信息是最大权力 |
| **禁忌** | 不能越级汇报、不能留证据、不能在群里发牢骚、不能带走"公司资产" |
| **例外** | 主角是核心技术骨干，掌握公司最核心的算法代码和客户数据——这些都在他个人的云盘里 |

**职场世界侧重点：**
- 信息不对称：谁知道什么决定谁的地位
- 潜规则：表面公平，暗箱操作
- 利益链条：每个看似不合理的行为背后都有利益驱动

---

## 三、核心异质物/触发器

**辞职信。**

不是普通的辞职信。是一封长达2万字的辞职信，里面埋了10个"彩蛋"——每个彩蛋对应一个秘密，收件人从CEO到HR到前台，每个人都收到了一封"定制版"辞职信，内容不同。

当10封辞职信同时发出，整栋办公楼炸了。

## 四、人物设计

### 4.1 主角（MACH模型）

```markdown
## 主角：林默（女，28岁）
- 年龄/性别/职业：28岁/女/星耀科技AI算法工程师（P6级）
- 外貌特征：①永远穿灰色连帽衫 ②左手中指有长期敲代码留下的茧 ③黑眼圈但眼神极亮
- 表层动机：被裁员后，报复抢她方案的上司
- 深层动机：证明自己的价值，让那些看不起她的人付出代价
- 核心能力：
  - 硬能力：顶级AI算法工程师，掌握公司核心代码
  - 软能力：极强的信息搜集能力、数据分析能力、忍耐力（忍了三年）
- 能力边界：不懂商业运作、不会交际、没有资金 backing
- 性格缺陷：过度隐忍（什么都憋着不说）、报复心强（一旦决定报复就不留余地）
- 认知缺陷（错误信念）："只要我做出好作品，就一定会被认可"——这是她忍三年的根源
- 致命弱点：对"公平"的执念——一旦有人打破公平，她会不计代价报复
- 口头禅/习惯动作：紧张时会无意识敲桌面（像敲键盘）
- 成长弧光：从"渴望被认可的执行者"→"主动执棋的布局者"→"放下执念的解脱者"
- 核心恐惧：被遗忘/被替代（"我只是一个可替换的工具"）
- 核心渴望：被看见、被认可
- 关系锚点：母亲（唯一的家人，不知道她有多苦）
- 读者代入点：职场中被抢功、被忽视、被不公平对待的每个人
```

### 4.2 核心配角（3F模型）

```markdown
## 配角1：张总（张浩然，35岁）— 推动型/反派
- 角色类型：推动型 + 初级反派
- 与主角关系：直属上司，连续三年抢林默的方案
- 私人欲望：升VP，财务自由
- 秘密：他的"业绩"全是偷下属的；他在财务上有问题
- 对主角的作用：触发事件的核心推手
- 独立行为线：正在暗中挖公司墙角，准备带走团队自立门户
- 结局：身败名裂，但林默发现他也有苦衷（被上一任上司这么对待过）
```

```markdown
## 配角2：周小雨（25岁）— 功能型
- 角色类型：功能型
- 与主角关系：同期入职的同事，林默唯一的朋友
- 私人欲望：转正，留在大城市
- 秘密：她知道张总偷方案的事，但不敢说（怕被裁）
- 对主角的作用：提供内部信息，帮助林默收集证据
- 独立行为线：她也在被欺负，但不敢反抗——她是"另一个可能的林默"
- 结局：在林默的影响下，终于学会反抗
```

```markdown
## 配角3：陈思远（40岁）— 对比型
- 角色类型：对比型
- 与主角关系：前同事，三年前因为被抢功而离职
- 私人欲望：重新证明自己
- 秘密：他当年也想过报复，但放弃了——他现在过得很惨
- 对主角的作用：镜像对照（"如果林默不反抗，就是他的下场"）
- 独立行为线：他曾经是公司最亮的星，被毁掉后沦为外卖员
- 结局：成为林默复仇计划中的关键一环（提供张总的历史证据）
```

```markdown
## 配角4：沈总（沈明哲，45岁）— 推动型/终极反派
- 角色类型：推动型 + 终极反派
- 与主角关系：公司VP，张总的上司
- 私人欲望：把公司做上市，套现离场
- 秘密：公司核心技术涉嫌抄袭；他在做假账
- 对主角的作用：真正的大Boss，张总只是他的棋子
- 独立行为线：准备在公司上市前抛售股份
- 结局：被林默的辞职信揭露一切，但他在最后时刻反咬一口
```

### 4.3 反派设计（3R模型+终极反派）

**Reason（合理性）：**
- 张总：他也是从底层爬上来的，当年也是被抢功的受害者——"职场就是这样，你要么抢别人，要么被别人抢"
- 沈总：他要上市，需要漂亮的业绩——"我只是在做大事，牺牲几个人算什么"

**Ruthless（压迫感）：**
- 张总：连续三年抢方案，还在绩效考核时给林默打最低分
- 沈总：一句话就能裁掉整个部门；他知道林默在查，但不在乎——"她能怎样？"

**Redemption（反转空间）：**
- 张总：林默发现他抢方案是为了给女儿治病（医疗费缺口）
- 沈总：林默发现他也是从底层爬上来的，曾经也是一个有理想的年轻人

## 六、三条暗线全览

### 暗线1：辞职信的10个"彩蛋"
- **明面**：每章揭示一个彩蛋的内容
- **暗面**：第10个彩蛋是林默留给自己的——里面是她三年来的所有委屈
- **回收**：第37章，她删除了这个文件夹

### 暗线2：陈思远的身份
- **明面**：一个被毁掉的前同事
- **暗面**：他是林默大学时的学长，曾经帮过她——所以她一见到他就信任他
- **回收**：第24章，他认出了林默

### 暗线3：母亲的"病情"
- **明面**：母亲突然生病，需要大笔医疗费
- **暗面**：母亲的病是沈总安排的（通过医院的关系），目的是逼迫林默妥协
- **回收**：第31章，林默发现真相——但母亲是真的病了（巧合）

## 八、开篇设计（3选1）

### 方案A（冲突直给型）⭐推荐

## 九、投稿策略+核心卖点

### 核心卖点（差异化分析）

| 卖点 | 说明 | 竞品对比 |
|------|------|---------|
| **辞职信的"10个彩蛋"** | 每章揭示一个彩蛋，形成持续的悬念链条 | 竞品多为线性叙事，缺少结构创新 |
| **受害者变执棋者** | 从"被裁员工"到"布局者"的转变 | 反套路人设，命中2026趋势 |
| **每个角色都有苦衷** | 反派不是纯恶人，而是系统性问题 | 增加深度，不是简单爽文 |
| **技术细节真实** | AI行业、代码、算法——真实感强 | 作者/团队有行业背景 |
| **结尾有温度** | 不是简单的"爽完就走"，而是释然 | 盐选读者偏好有温度的结局 |

### 投稿策略
- **赛道**：现实赛道（社会话题绑定：职场霸凌/员工维权）
