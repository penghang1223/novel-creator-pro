# 二、故事大纲

## 2.1 核心设定

**一句话故事：**
社畜林凡被裁员后意外获得"修仙KPI系统"——把修仙等级、任务、宗门全部映射成现代职场规则。从此他开始用修仙思维打工，用职场套路修仙。

**世界观：现代都市 × 修仙体系 × 职场映射**

### 修仙体系（职场化改造）

| 传统修仙 | 本书映射 | 职场对应 |
|---------|---------|---------|
| 炼气期 | P1-P3 | 实习生/试用期 |
| 筑基期 | P4-P6 | 正式员工/骨干 |
| 金丹期 | P7-P8 | 部门经理/总监 |
| 元婴期 | P9-P10 | VP/合伙人 |
| 化神期 | P11+ | 董事长/行业领袖 |

### 金手指规则：修仙KPI系统

| 功能 | 说明 | 职场映射 |
|------|------|---------|
| KPI面板 | 显示修炼进度（替代经验条） | 绩效考核表 |
| 任务系统 | 每日/每周修炼任务 | OKR/KPI考核 |
| 宗门系统 | 加入修仙公司/势力 | 入职大厂/创业公司 |
| 排行榜 | 全服修仙者排名 | 公司绩效排名 |
| 奖励池 | 完成任务获得功法/丹药 | 年终奖/股权激励 |
| 处罚机制 | 未完成任务扣除修为 | 扣绩效/降薪 |

### 核心规则与限制

- **灵气浓度**：城市不同区域灵气浓度不同（写字楼灵气最稀薄，名山大川灵气浓郁）
- **修炼资源**：灵石=钱，丹药=保健品/咖啡，法宝=手机/电脑（可升级）
- **天劫**：突破瓶颈时触发（相当于职场危机/公司裁员/项目失败）
- **系统限制**：不能直接给修为，只能提供任务指引和奖励

## 4.2 前10章细纲

### 第1章：被裁
"林凡，公司决定优化掉你。"HR把辞退通知推过来。今天是他入职第3年。收拾完工位，他走在回家的路上。一辆车突然冲过来——他眼前一黑。醒来后，视野里出现了一个半透明面板：
```
【修仙KPI系统 已激活】
【当前等级：凡人（P0）】
【今日任务：完成第一次灵气感应（0/1）】
【奖励：筑基丹×1】
```
**钩子**：林凡以为自己在做梦——直到他真的"感应"到了灵气。

### 第2章：灵气感应
林凡按照系统提示，盘腿坐下。5分钟后，他感觉到一股热流从丹田升起。面板更新：
```
【任务完成：灵气感应（1/1）】
【奖励已发放：筑基丹×1】
【当前修为：炼气期P1（0/100）】
```
**钩子**：他吞下筑基丹——修为瞬间涨了10点。

### 第3章：修仙等级
系统面板显示修仙等级对照表：
- 炼气期 = P1-P3（实习生/试用期）
- 筑基期 = P4-P6（正式员工/骨干）
- 金丹期 = P7-P8（部门经理/总监）
- 元婴期 = P9-P10（VP/合伙人）
- 化神期 = P11+（董事长/行业领袖）
**钩子**：林凡发现自己现在是P1——相当于实习生。

### 第4章：职场修仙
林凡上网搜索"修仙"——发现一个隐藏论坛："修仙者交流区"。里面全是像他一样的"职场修仙者"。有人分享经验："我在大厂修仙，灵气浓度比小公司高30%。"
**钩子**：论坛里有一条招聘广告："青云修仙集团 招聘P1-P3修仙者，包五险一金+灵气补贴。"

### 第5章：面试
林凡去青云修仙集团面试。面试官是苏清雪（女主）。她问："你为什么会选择修仙？"林凡说："因为我不想再被裁了。"苏清雪笑了："那你来对地方了。"
**钩子**：面试通过。林凡正式入职青云修仙集团。

### 第6章：入职
林凡拿到工牌：姓名：林凡 | 部门：修炼部 | 等级：P1 | 灵气补贴：500灵石/月。他的导师是老张——一个筑基期P4的资深修仙者。
**钩子**：老张告诉他："在这里，修炼=工作。KPI完不成，扣绩效。"

### 第7章：第一个KPI
林凡的每日KPI：
- 灵气修炼：2小时/天
- 功法练习：1小时/天
- 宗门任务：1个/周
**钩子**：他发现自己的KPI和前世打工一模一样——只不过这次，完成的是"修仙KPI"。

### 第8章：同事
林凡认识了同事赵磊（筑基期P3）和小陈（炼气期P2）。赵磊告诉他："在这里，修为=职级。想要升职，就得突破。"
**钩子**：赵磊还说："但突破需要'天劫'——相当于职场危机。"

### 第9章：第一次修炼
林凡开始正式修炼。他发现写字楼的灵气浓度真的很低——但系统提示："完成修炼任务可获得'灵气丹'，提升修炼效率50%。"
**钩子**：他完成任务后，修为涨了20点。

### 第10章：新人考核
入职一周后，林凡迎来"新人考核"——相当于试用期转正考试。考核内容：在1小时内完成基础功法"引气诀"的完整循环。
**钩子**：林凡开始考核——但系统突然提示：【隐藏任务：在考核中排名前三】
