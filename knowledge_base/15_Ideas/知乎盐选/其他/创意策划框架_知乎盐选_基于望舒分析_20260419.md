# 模块二：题材创意模板（5个方向）

## 2.1 方向一：群聊悬疑 ⭐⭐⭐⭐⭐

**题材定位：** 微信群里的死人@所有人——被掩埋的秘密逐渐浮出水面

**核心钩子设计：**
| 钩子类型 | 设计 | 节奏 |
|---------|------|------|
| 主线钩子 | 谁在操控这一切？ | 每3章抛新线索 |
| 情感钩子 | 主角当年的内疚/回避 | 贯穿全文 |
| 反转钩子 | 至少3次（表面→深层→终极） | 卷末各1次 |
| 社交钩子 | 群聊形式天然代入感 | 开篇即有 |

**竞品参考：**
- 《我在班级群里看到了死去三年的自己》（15-30万）
- 《家族群里，奶奶发了她去世当天的照片》（10-20万）

**预估：** 过稿率75%，收入8-40万，完读率68%

## 2.2 方向二：职场复仇爽文 ⭐⭐⭐⭐

**题材定位：** 被裁员/被抢功的职场人，精心策划完美复仇

**核心钩子设计：**
| 钩子类型 | 设计 |
|---------|------|
| 爽点钩子 | 每章一个打脸/反击 |
| 技术钩子 | 复仇手段新颖（非简单举报，精妙布局） |
| 现实钩子 | 职场不公是全民痛点 |
| 反转钩子 | 以为赢了，其实还有更大的局 |

**竞品参考：**
- 《被裁员那天，我带走了公司最值钱的东西》（20-50万）
- 《上司抢了我的方案，我让他身败名裂》（15-35万）

**预估：** 过稿率70%，收入10-50万，完读率65%

## 2.3 方向三：原生家庭创伤+反转 ⭐⭐⭐⭐

**题材定位：** 我以为我恨的是父母，后来发现真相完全不同

**核心钩子设计：**
| 钩子类型 | 设计 |
|---------|------|
| 情感钩子 | 原生家庭是全民痛点 |
| 悬念钩子 | "我以为的真相" vs "实际真相" |
| 治愈钩子 | 最终走向和解/释然（盐选偏好有温度的结局） |
| 细节钩子 | 日常细节中埋线索，回头看恍然大悟 |

**竞品参考：**
- 《我妈说我是捡来的，后来我发现她说的是真的》（10-25万）
- 《我爸的遗嘱里，没有我的名字》（8-20万）

**预估：** 过稿率65%，收入5-30万，完读率70%

## 2.4 方向四：AI/科技悬疑 ⭐⭐⭐

**题材定位：** 我发现我的AI助手，正在替我做人生决定

**核心钩子设计：**
| 钩子类型 | 设计 |
|---------|------|
| 概念钩子 | AI替你做决定——2026年每个人都在经历 |
| 恐惧钩子 | 技术失控的恐惧 |
| 反转钩子 | AI是工具还是操控者？ |
| 时代钩子 | 紧扣AI时代焦虑 |

**竞品参考：**
- 《我的AI恋人，其实是我的心理医生》（5-15万）
- 《手机里的陌生人，比我的家人更了解我》（3-10万）

**预估：** 过稿率58%，收入3-20万，完读率55%

## 2.5 方向五：历史考据+穿越 ⭐⭐⭐

**题材定位：** 我穿越到XX朝代，发现历史书上写的全是假的

**核心钩子设计：**
| 钩子类型 | 设计 |
|---------|------|
| 知识钩子 | 真实历史细节让读者有"学到了"的获得感 |
| 反差钩子 | 历史书记载 vs 实际发生的事 |
| 生存钩子 | 现代人在古代的生存挑战 |
| 悬疑钩子 | 历史谜案的真相 |

**预估：** 过稿率63%，收入5-25万，完读率58%，写作门槛高

# 模块三：世界观搭建模板

## 3.1 五维世界观模型（必填）

| 维度 | 核心问题 | 悬疑类侧重点 | 现实类侧重点 |
|------|---------|-------------|-------------|
| **时空** | 何时何地？ | 信息传递的渠道（群/私信/匿名） | 社会环境（职场/家庭/社会） |
| **规则** | 底层逻辑？ | 谁知道什么？信息如何流动？ | 什么规则在压迫主角？ |
| **权力** | 谁掌握资源？ | 谁掌控真相？谁在隐瞒？ | 阶级/性别/职场权力结构 |
| **禁忌** | 不能做什么？ | 不能触碰的记忆/秘密 | 不能说的话题/潜规则 |
| **例外** | 主角凭什么破局？ | 主角知道别人不知道的信息 | 主角的特殊经历/视角 |

## 3.2 世界观元素检查清单

```
□ 时代背景（年份/社会背景）
□ 核心场景（微信群？办公室？家庭？）
□ 信息渠道（谁通过什么方式知道什么？）
□ 社会阶层/权力结构
□ 禁忌清单（3件不能碰的事）
□ 日常细节（增强真实感）
□ 语言风格（群聊体？职场黑话？）
□ 特殊设定（如有：系统/穿越/超自然）
```

# 模块四：人物设计模板

## 4.1 主角人设卡（四维驱动）

```markdown
## 主角：[姓名]
- 年龄/性别/职业：
- 外貌特征（3个标志性细节）：
- 表层动机（想要什么）：
- 深层动机（真正需要什么）：
- 核心能力：
- 能力边界（不能做什么）：
- 性格缺陷：
- 认知缺陷（错误信念）：
- 致命弱点：
- 口头禅/习惯动作：
- 成长弧光：起点 → 终点
- 核心恐惧：
- 核心渴望：
- 关系锚点（最在意的人）：
- 读者代入点（为什么读者会共情）：
```

**盐选主角设计要点（来自望舒分析）：**
- 反套路：受害者变执棋者，好人有阴暗面
- 第一人称：代入感强，完读率+15%
- 前500字立人设（通过行动，不是简历）

## 4.2 配角功能三角

| 类型 | 功能 | 群聊悬疑示例 | 职场复仇示例 |
|------|------|-------------|-------------|
| **功能型** | 推动剧情/提供信息 | 群里的线人角色 | 公司内部消息源 |
| **对比型** | 反衬主角（镜像） | 当年参与但毫无内疚的人 | 同样被欺负但选择沉默的人 |
| **推动型** | 逼迫主角改变 | 当年事件的关键人物 | 抢功的上司 |

**配角人设卡：**
```markdown
## 配角：[姓名]
- 角色类型：功能型/对比型/推动型
- 与主角关系：
- 私人欲望（自己的故事）：
- 秘密（后期可揭示）：
- 对主角的作用：
- 独立于主角的行为线：
- 结局：
```

## 4.3 反派三层压迫模型

```markdown
## 反派：[姓名]
- 表层身份：
- 真实身份（可反转）：
- 核心动机（在他眼里自己是正义的）：
- 前史（为什么变成这样）：
- 对主角的威胁（资源/心理/道德）：
- 先赢的3次（压迫感设计）：
- 可反转的伏笔（3个）：
- 最终结局：
- 读者情感轨迹（恨→理解→同情→？）：
```

**盐选反派要点：**
- 不能是纯恶人，必须有合理性
- 最好与主角有情感羁绊（亲人/朋友/同事）
- 反转空间：身份/动机/立场至少留一个反转余地

## 4.4 人物关系图谱

```
        [反派/幕后操控者]
       ↗(对抗)    ↖(利用)
   [主角] ←——(结盟/背叛)——→ [关键配角A]
      ↓(情感)        ↓(秘密)
   [恋人/重要他人] ←——(竞争)——→ [配角B]

群聊场景额外标注：
□ 群主是谁？
□ 谁在群里最活跃？
□ 谁在群里从不说话？
□ 谁的消息值得怀疑？
```

# 模块五：分卷规划模板

## 5.1 四卷标准结构（以15万字为例）

| 卷 | 名称 | 字数 | 章节数 | 功能 | 情绪基调 |
|----|------|------|--------|------|---------|
| 卷一 | 起 | 3-3.7万字 | 8-10章 | 建立冲突+第一个反转 | 好奇→紧张→震惊 |
| 卷二 | 承 | 4.5-5.2万字 | 12-15章 | 升级+假胜利+配角背叛 | 希望→绝望 |
| 卷三 | 转 | 3.7-4.5万字 | 10-12章 | 最大反转+最低谷+觉醒 | 绝望→反击 |
| 卷四 | 合 | 2.2-3万字 | 6-8章 | 对决+真相+余韵 | 紧张→回味 |

## 5.2 每卷核心事件清单（通用模板）

### 卷一：起（建立期）
```
情绪曲线：好奇 → 紧张 → 震惊 → 悬念

事件：
□ 触发事件（1-3章）：日常被打破
□ 主角被迫行动（3-5章）：第一次选择
□ 发现冰山一角（5-7章）：第一次震惊
□ 卷末反转（7-10章）：推翻读者预期

盐选开头铁律：
- 前200字：直接抛核心冲突（定生死）
- 前500字：通过行动展现主角（立人设）
- 前1000字：明确主角动机
- 前2000字：埋第一个悬念
```

### 卷二：承（升级期）
```
情绪曲线：希望 → 挫折 → 希望 → 更大挫折 → 绝望

事件：
□ 主角找到方向：第一次主动出击
□ 假胜利（关键！）：以为快赢了
□ 反派反击：摔得更惨
□ 配角背叛/牺牲：情绪最低谷
□ 卷末大反转：推翻卷一的某个"认知"
```

### 卷三：转（翻盘期）
```
情绪曲线：绝望 → 挣扎 → 觉醒 → 反击 → 新危机

事件：
□ 主角最低谷：一切都完了
□ 转折契机：必须来自自己的觉醒（不能天降救兵）
□ 真相碎片：拼图开始完整
□ 主角蜕变：不再是以前的自己
□ 反击开始：主动出击
```

### 卷四：合（收束期）
```
情绪曲线：紧张 → 高潮 → 释放 → 余韵

事件：
□ 最终对决准备
□ 最终对决（必须有意外，不能简单打败）
□ 真相大白（所有伏笔回收）
□ 结局（主角去向）
□ 余韵/彩蛋（回味）
```

## 5.3 卷末钩子6种类型

| 类型 | 模板 | 群聊悬疑应用 |
|------|------|-------------|
| 身份反转 | "你以为的A，其实是B" | 发消息的不是死人，是…… |
| 动机反转 | "以为要害你，其实在救你" | 操控者的真实目的 |
| 时间反转 | "你以为的顺序是错的" | 事件发生的真实时间线 |
| 认知反转 | "你以为的真相是假的" | 主角一直追查的方向错了 |
| 关系反转 | "敌人其实是……" | 最信任的人才是幕后 |
| 规模反转 | "以为是小，其实是……" | 个人行为→系统性阴谋 |

# 模块六：盐选专用模块

## 6.1 开头前2000字黄金法则

| 节点 | 必须完成 | 绝对不能做 | 示例 |
|------|---------|-----------|------|
| 前200字 | 核心冲突/事件 | 背景介绍/人物描写/环境描写 | "林晓死了三年。但昨天深夜，她在班级群里@了所有人。" |
| 前500字 | 主角是谁（通过行动展现） | 简历式描写 | 通过主角的反应展现性格 |
| 前1000字 | 明确动机（为什么必须做） | 多视角切换 | 读者产生"然后呢" |
| 前2000字 | 第一个悬念 | 慢热铺垫 | "这到底是怎么回事" |

**开头禁忌清单：**
- ❌ 大段背景介绍
- ❌ 人物简历式描写
- ❌ 环境描写超过3句
- ❌ 回忆杀（除非与核心事件直接相关）
- ❌ 多视角切换（开头只限一个视角）
- ❌ 慢热铺垫（盐选读者没有耐心）

## 6.2 付费卡点设计

**公式：悬念建立（2章）→ 线索推进（2章）→ 小高潮/反转（1章）→ 卡在更高悬念处（付费）**

| 原则 | 示例 |
|------|------|
| 卡在悬念最高处 | "门开了，里面竟然是——" |
| 卡在反转前一刻 | "我终于找到了凶手，他是..." |
| 卡在情感高潮 | "她终于说出了当年的真相..." |
| ❌ 不要在平淡处卡 | "第二天早上他起床刷牙" |

**付费点位置建议：** 约1/3处（第15-20章后）

## 6.3 更新节奏

| 阶段 | 字数 | 更新频率 | 目的 |
|------|------|---------|------|
| 免费期（前1/3） | 3-5万字 | 日更1-2章 | 快速积累读者，冲高完读率 |
| 付费初期 | 5-8万字 | 日更1章 | 保持热度，刺激付费转化 |
| 稳定期 | 8-12万字 | 日更1章或隔日更 | 维持订阅，防止掉粉 |
| 结尾期 | 12-15万字 | 日更1-2章 | 冲高潮，冲刺完结热度 |

**⚠️ 关键：免费期更新速度决定生死。免费期完读率<60%，付费转化会非常差。**

## 6.4 爽点/钩子密度标准

- 每章≥1个小爽点/小悬念
- 每3-5章≥1个中等反转
- 每卷末≥1个大反转
- 付费卡点必须在情绪最高点

## 6.5 新书自荐（必做！）

必须关联1-2个知乎问题，才有流量激励。

**推荐问题方向：**
| 方向 | 示例问题 | 流量 |
|------|---------|------|
| 群聊类 | "你在群里看到过哪些诡异的事？" | 极高 |
| 悬疑类 | "有哪些细思极恐的真实故事？" | 高 |
| 反转类 | "有哪些结局让你意想不到的故事？" | 高 |
