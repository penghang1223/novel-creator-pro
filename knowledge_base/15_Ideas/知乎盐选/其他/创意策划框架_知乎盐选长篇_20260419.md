## 一、世界观搭建模板

### 1.1 通用世界观框架（五维模型）

任何题材都必须回答以下5个维度的问题：

| 维度 | 核心问题 | 检查项 |
|------|---------|--------|
| **时空** | 故事发生在何时何地？ | 现代/古代/近未来/架空？一线城市/小镇/异世界？ |
| **规则** | 这个世界运行的底层逻辑是什么？ | 物理法则/社会制度/超自然规则？ |
| **权力** | 谁掌握资源？谁被压迫？ | 阶级结构/经济体系/信息差？ |
| **禁忌** | 这个世界不能做什么？ | 道德底线/法律红线/超自然禁忌？ |
| **例外** | 主角凭什么打破规则？ | 特殊身份/金手指/信息优势？ |

### 1.2 不同题材的世界观差异

**悬疑类：**
- 核心：信息不对称
- 世界观重点：谁掌握真相？谁知道什么？
- 关键设计：误导元素（red herring）的合理分布
- 案例：《妈妈不是妈妈》→ 世界观核心是"记忆的可靠性"

**言情类：**
- 核心：情感阻碍
- 世界观重点：什么在阻止两个人在一起？
- 关键设计：阶层差异/误会机制/时间错位
- 案例：霸总文→ "门第差异"是世界观核心

**科幻类：**
- 核心：技术/社会变革
- 世界观重点：什么技术改变了人类？
- 关键设计：设定自洽性 + 对日常生活的渗透
- 案例：《三体》→ "黑暗森林法则"重塑整个宇宙观

**现实类：**
- 核心：社会议题
- 世界观重点：什么社会现象在影响主角？
- 关键设计：真实感 + 代入感 + 痛点共鸣
- 案例：女性成长→ "职场性别天花板"是世界观核心

**中式神怪类：**
- 核心：传统与现代的碰撞
- 世界观重点：超自然力量如何隐藏在现代社会？
- 关键设计：民间传说现代化 + 规则边界
- 案例：《749局》→ 神秘机构 + 民间异闻

### 1.3 世界观设计关键元素清单

```
□ 时代背景：年号/年份/历史事件
□ 地理环境：核心场景 + 边缘场景（形成对比）
□ 社会阶层：顶层/中层/底层 + 流动性
□ 经济体系：钱怎么来？怎么花？谁缺钱？
□ 权力结构：明面规则 vs 潜规则
□ 特殊设定：超能力/系统/穿越/重生（如有）
□ 禁忌清单：不能碰的3件事（制造冲突）
□ 日常细节：衣食住行（增强真实感）
□ 语言风格：方言/行话/网络用语（增强代入感）
□ 信息来源：主角如何获取信息？（悬疑关键）
```

## 二、人物设计方法论

### 2.1 主角人设模板（四维驱动模型）

**公式：动机 × 能力 × 缺陷 × 成长弧光 = 立体主角**

#### 维度1：动机（驱动引擎）
- **表层动机**：主角想要什么？（钱/复仇/爱情/真相）
- **深层动机**：主角真正需要什么？（被爱/被认可/安全感）
- **矛盾点**：表层动机 vs 深层动机不一致 → 内心冲突
- **案例**：表层"我要复仇"，深层"我想要被爱"→ 复仇过程中发现爱是救赎

#### 维度2：能力（行动资本）
- **硬能力**：专业技能/超能力/资源
- **软能力**：情商/洞察力/韧性
- **能力边界**：主角不能做什么？（限制制造紧张感）
- **能力成长**：从A能力→B能力的转变路径

#### 维度3：缺陷（冲突引擎）
- **性格缺陷**：傲慢/懦弱/多疑/自私
- **认知缺陷**：错误信念（"我不值得被爱"）
- **行为缺陷**：习惯性逃避/攻击/讨好
- **致命弱点**：被反派利用的弱点

#### 维度4：成长弧光（情感内核）
- **起点状态**：故事开始时的主角（有缺陷）
- **触发事件**：什么打破了主角的舒适区？
- **中段挣扎**：旧模式失败 → 开始改变 → 反复
- **终点状态**：故事结束时的主角（克服/接受缺陷）
- **弧光类型**：
  - 正向弧光：从缺陷到成长（最常见）
  - 负向弧光：从好到坏（悲剧/反英雄）
  - 平弧光：主角不变，改变世界（福尔摩斯型）

#### 主角人设卡模板

```markdown
## 主角：[姓名]
- 年龄/性别/职业：
- 外貌特征（3个标志性细节）：
- 表层动机：
- 深层动机：
- 核心能力（硬+软）：
- 能力边界：
- 性格缺陷：
- 认知缺陷（错误信念）：
- 致命弱点（被反派利用的点）：
- 口头禅/习惯动作：
- 成长弧光：起点 → 终点
- 核心恐惧：
- 核心渴望：
- 关系锚点（最在意的人）：
```

### 2.2 配角设计原则（功能三角模型）

**每个配角必须至少满足以下一个功能：**

| 类型 | 功能 | 设计要点 | 案例 |
|------|------|---------|------|
| **功能型** | 推动剧情/提供信息/执行任务 | 不要写成工具人，给一个私人动机 | 侦探的助手、提供线索的线人 |
| **对比型** | 反衬主角特质（镜像/对立） | 和主角有相似起点，做出不同选择 | 主角的"另一个可能" |
| **推动型** | 逼迫主角做出改变 | 主角最不想面对的人 | 前男友、严厉的上司、曾经的背叛者 |

**配角设计铁律：**
1. 每个配角至少有一个"私人欲望"（不只是为剧情服务）
2. 每个配角至少有一个"秘密"（可以后期揭示）
3. 配角之间要有独立关系（不只是和主角的关系）
4. 配角的结局要有"余味"（不只是为了衬托主角）

#### 配角人设卡模板

```markdown
## 配角：[姓名]
- 角色类型：功能型/对比型/推动型
- 与主角关系：
- 私人欲望（自己的故事）：
- 秘密（后期可揭示）：
- 对主角的作用：
- 独立于主角的行为线：
- 结局：
```

### 2.3 反派设计要点（三层压迫模型）

**反派不是坏人，是"和主角目标冲突的人"。**

#### 第一层：合理性（反派为什么这么做？）
- 反派有自己的动机和逻辑（在他眼里自己是正义的）
- 最好的反派：读者能理解他，甚至同情他
- 设计方法：给反派一个"前史"（曾经也是好人）

#### 第二层：压迫感（反派为什么让读者害怕？）
- 资源碾压：比主角有钱/有权/有信息
- 心理碾压：知道主角的弱点并精准打击
- 道德碾压：做"正确的事"但手段残忍
- 设计方法：让反派先赢2-3次，主角屡败屡战

#### 第三层：反转空间（反派有没有可能不是坏人？）
- 身份反转：反派其实是主角的亲人/朋友/另一个自己
- 动机反转：反派的目的和主角其实是一致的
- 立场反转：反派曾经救过主角，只是方式不同
- 设计方法：埋3个"反派其实另有隐情"的伏笔

#### 反派人设卡模板

```markdown
## 反派：[姓名]
- 表层身份：
- 真实身份（可反转）：
- 核心动机（在他眼里自己是正义的）：
- 前史（为什么变成这样）：
- 对主角的威胁（资源/心理/道德）：
- 先赢的3次（压迫感设计）：
- 可反转的伏笔（3个）：
- 最终结局：
- 读者对他的复杂情感（恨→理解→同情→？）：
```

### 2.4 人物关系图谱设计方法

#### 关系类型矩阵

| 关系类型 | 作用 | 设计要点 |
|---------|------|---------|
| **情感纽带** | 制造软肋/软肋被攻击时的爆发 | 主角最在意的人最容易被伤害 |
| **利益冲突** | 制造对抗/逼迫选择 | 同一阵营内的暗战 |
| **信息不对称** | 悬疑核心（谁知道什么） | A知道但B不知道 → 张力 |
| **镜像对照** | 反衬主角特质 | "如果主角选了另一条路" |
| **历史羁绊** | 增加深度（前史） | 过去的恩怨影响现在的选择 |

#### 关系图谱绘制模板

```
                    [反派]
                   ↗    ↖
         [对抗]  ↗        ↖  [利用]
              ↗            ↖
    [主角] ←———[盟友]———→ [配角A]
       ↓          ↓          ↓
  [情感]      [背叛]     [秘密]
       ↓          ↓          ↓
    [恋人] ←———[竞争]———→ [配角B]
```

**绘制规则：**
1. 每条连线标注关系类型 + 情感色彩（红=爱/蓝=利用/黑=仇恨）
2. 标注信息不对称（谁掌握什么秘密）
3. 标注关系变化的关键节点（信任→背叛→和解）

## 三、分卷规划框架

### 3.1 盐选长篇标准卷结构（四卷模型）

| 卷 | 名称 | 功能 | 字数占比 | 情绪基调 |
|----|------|------|---------|---------|
| **卷一** | 起 | 建立世界观+主角+核心冲突 | 20-25% | 好奇→紧张→震惊 |
| **卷二** | 承 | 冲突升级+配角入场+假胜利 | 30-35% | 希望→挫折→绝望 |
| **卷三** | 转 | 最大反转+主角最低谷 | 25-30% | 绝望→觉醒→反击 |
| **卷四** | 合 | 最终对决+真相大白+余韵 | 15-20% | 紧张→释放→回味 |

### 3.2 每卷字数分配建议

以10万字为例：

| 卷 | 字数 | 章节数 | 单章字数 | 节奏 |
|----|------|--------|---------|------|
| 卷一（起） | 2-2.5万字 | 6-8章 | 3000-4000 | 快（快速进入） |
| 卷二（承） | 3-3.5万字 | 9-12章 | 3000-4000 | 中（铺陈+升级） |
| 卷三（转） | 2.5-3万字 | 8-10章 | 3000-4000 | 快（密集反转） |
| 卷四（合） | 1.5-2万字 | 5-7章 | 3000-4000 | 慢（余韵收尾） |

### 3.3 每卷核心事件 + 情绪曲线设计

#### 卷一：起（建立期）

```
情绪曲线：
好奇 → 紧张 → 震惊 → 悬念

核心事件清单：
□ 事件1：日常被打破（前3章，触发事件）
□ 事件2：主角被迫行动（3-5章，第一次选择）
□ 事件3：发现冰山一角（5-7章，第一次震惊）
□ 事件4：卷末大钩子（7-8章，"原来事情没这么简单"）

设计要点：
- 前3章必须完成：主角亮相+核心冲突+第一个悬念
- 第5章左右给一个"小爽点"（读者获得阶段性满足）
- 卷末必须有一个"推翻读者预期"的反转
```

#### 卷二：承（升级期）

```
情绪曲线：
希望 → 挫折 → 希望 → 更大挫折 → 绝望

核心事件清单：
□ 事件1：主角找到方向（9-10章，"我有办法了"）
□ 事件2：第一次胜利（11-13章，假胜利）
□ 事件3：反派反击（13-15章，"你以为你赢了？"）
□ 事件4：配角背叛/牺牲（15-17章，情绪低谷）
□ 事件5：卷末大反转（17-20章，"原来他一直骗我"）

设计要点：
- "假胜利"是关键：让读者以为快赢了，然后摔得更惨
- 配角背叛/牺牲是情绪最低谷
- 卷末反转必须推翻卷一建立的某个"认知"
```

#### 卷三：转（翻盘期）

```
情绪曲线：
绝望 → 挣扎 → 觉醒 → 反击 → 新危机

核心事件清单：
□ 事件1：主角最低谷（21-22章，"一切都完了"）
□ 事件2：转折契机（22-24章，"也许还有办法"）
□ 事件3：真相碎片（24-26章，拼图开始完整）
□ 事件4：主角蜕变（26-28章，"我不再是以前那个我"）
□ 事件5：反击开始（28-30章，主动出击）

设计要点：
- 最低谷必须够低（读者觉得真的完了）
- 转折契机必须来自主角自己的觉醒（不是天降救兵）
- 真相碎片要逐步揭示，不要一次性全给
```

#### 卷四：合（收束期）

```
情绪曲线：
紧张 → 高潮 → 释放 → 余韵

核心事件清单：
□ 事件1：最终对决准备（31-32章，磨刀）
□ 事件2：最终对决（32-34章，生死战）
□ 事件3：真相大白（34-35章，所有伏笔回收）
□ 事件4：结局（35-37章，主角去向）
□ 事件5：余韵/彩蛋（37-38章，回味）

设计要点：
- 最终对决必须有"意外"（不是简单的打败反派）
- 所有伏笔必须回收（读者会翻回去检查）
- 结局要有"余味"（不是所有问题都有答案）
- 彩蛋可以为续作留空间
```

### 3.4 卷末钩子设计模板

**钩子 = 推翻读者已知 + 制造新悬念**

| 钩子类型 | 模板 | 案例 |
|---------|------|------|
| **身份反转** | "你以为的A，其实是B" | 照顾三年的妈妈不是妈妈 |
| **动机反转** | "你以为他要害你，其实他在救你" | 老公的手机里不是杀人计划，是拯救计划 |
| **时间反转** | "你以为的顺序是错的" | 故事不是从过去到现在，而是从现在到过去 |
| **认知反转** | "你以为的真相是假的" | 主角一直追查的凶手，是自己遗忘的另一人格 |
| **关系反转** | "你以为的敌人其实是……" | 反派是主角失散多年的亲人 |
| **规模反转** | "你以为只是个小事，其实是……" | 失踪案→人口贩卖→国家级阴谋 |

**卷末钩子设计检查表：**
```
□ 是否推翻了读者在卷中建立的某个"确定性"？
□ 是否制造了至少2个新悬念？
□ 是否让读者产生"我必须看下一卷"的冲动？
□ 反转是否有伏笔支撑（不是凭空出现）？
□ 反转后是否有情感冲击（不只是智力冲击）？
```

### 4.3 伏笔追踪表模板

| 编号 | 伏笔内容 | 埋设位置 | 回收位置 | 类型 | 状态 |
|------|---------|---------|---------|------|------|
| F01 | [具体描述] | 第X章第X段 | 第Y章第Y段 | 明示/暗示/误导 | 未埋/已埋/已回收 |
| F02 | | | | | |
| F03 | | | | | |

**伏笔分类：**
- **明示型**：读者能看到，但不知道重要性（"她左肩有块月牙形胎记"）
- **暗示型**：读者能隐约感觉到不对劲（"他说话时总是避开那个名字"）
- **误导型**：读者以为是A，其实是B（red herring）

**伏笔设计铁律：**
1. 每个伏笔必须在3卷内回收（不要埋太深）
2. 回收时必须让读者有"原来如此"的感觉（不是"什么鬼"）
3. 误导型伏笔回收后，读者回看必须觉得"合理"（不是"被骗了"）
4. 最重要的伏笔（核心反转）必须至少有3处暗示

## 六、盐选长篇创意质量标准

**灵犀交付的创意方案必须满足：**

| 维度 | 标准 | 检查方式 |
