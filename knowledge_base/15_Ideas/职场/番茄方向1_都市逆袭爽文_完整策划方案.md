## 四、世界观设计

| 维度 | 设计 |
|------|------|
| **时空** | 2026年，深圳。现代都市背景，科技行业（互联网/AI/新能源） |
| **规则** | 资本为王的社会：有钱就有话语权；信息差是最大财富；年龄歧视是职场常态 |
| **金手指** | "神级投资系统"：①能看到任何人的"未来价值"（数字） ②能看到任何项目的"未来收益率"（百分比） ③完成任务获得"投资额度"和"技能卡" ④系统会发布"投资任务"，完成后解锁更高级功能 |
| **权力结构** | 底层社畜（主角起点）→ 中产（小老板/高管）→ 富豪（企业家/投资人）→ 资本寡头（掌控行业规则的人） |

### 金手指详细设定

**核心能力：**
- 未来价值视野：看到每个人头顶的数字（代表其未来10年的总价值，单位：万元）
- 未来收益率视野：看到任何项目/股票/资产的未来收益率
- 初始限制：只能看到"直接接触"的人和项目
- 升级路径：完成系统任务→提升等级→扩大视野范围→解锁新功能

**系统等级：**
| 等级 | 解锁条件 | 新能力 |
|------|---------|--------|
| LV1 | 初始 | 看到身边5米内的人和项目 |
| LV2 | 第一次投资成功（收益>10万） | 视野扩大到50米，解锁"项目详情" |
| LV3 | 累计收益>100万 | 视野扩大到500米，解锁"人物关系链" |
| LV4 | 累计收益>1000万 | 视野扩大到5公里，解锁"趋势预测"（3天） |
| LV5 | 累计收益>1亿 | 视野扩大到全城，解锁"趋势预测"（30天） |
| LV6 | 累计收益>10亿 | 全国范围，解锁"趋势预测"（1年） |
| LV7 | 累计收益>100亿 | 全球范围，解锁"趋势预测"（5年） |
| LV8 | 累计收益>1000亿 | 解锁"改变未来"（主动干预） |

**系统任务类型：**
- 日常任务：投资X个项目，收益>X万（奖励：投资额度+）
- 挑战任务：投资一个"被所有人看不起"的项目并成功（奖励：技能卡）
- 主线任务：帮助一个"未来价值极高但当前处于低谷"的人（奖励：系统升级）

**限制/平衡：**
- 系统只提供"信息"，不提供"钱"——主角需要自己筹集资金
- 看到的"未来"不是绝对的——如果主角不行动，未来可能改变
- 过度依赖系统会有"系统冷却"惩罚（暂时失去能力）

## 五、人物设计

### 5.1 主角

```markdown
## 主角：林浩（男，35岁）
- 年龄/性别/职业：35岁/男/前"锐思科技"运营主管→投资之神
- 外貌特征：①身材中等但结实（年轻时打过工） ②眼神从疲惫到锐利 ③穿着从廉价西装到定制西装
- 人设标签：底层社畜→逆袭大佬 / 隐忍→霸气 / 善良但有底线
- 金手指：神级投资系统（看到未来价值+收益率）
- 性格优势：隐忍、学习能力强、不贪（知道适可而止）、对身边人好
- 性格缺陷：前期过度自卑（被社会打压太久）；中期容易膨胀
- 成长线：
  卷1-2：从"被裁社畜"到"小有积蓄"（炒股+小投资）
  卷3-4：从"小有积蓄"到"区域富豪"（投资项目+建立团队）
  卷5-6：从"区域富豪"到"行业巨头"（收购+布局产业链）
  卷7-8：从"行业巨头"到"资本寡头"（改变行业规则）
- 核心恐惧：再次回到一无所有的日子
- 核心渴望：证明自己的价值——"我不是废物"
- 关系锚点：女儿朵朵（8岁）——他做的一切都是为了让女儿过上好日子
- 读者爽点代入：每个被社会毒打过的普通人，都幻想过"逆袭"
```

```markdown
## 配角1：苏晴（30岁）— 女主/事业合伙人

- 与主角关系：前公司同事，被裁后自己创业（开了一家小型科技公司）

- 未来价值：5000万（初期）→ 50亿（后期，因为林浩的投资）
- 对主角的作用：早期的"第一个投资项目"；后期的事业合伙人；最终的感情归宿
- 独立行为线：她的公司从濒临倒闭到行业独角兽
- 感情线：从"合作伙伴"→"知己"→"恋人"（慢热型，不舔不虐）
```

```markdown
## 配角2：老陈（50岁）— 导师型
- 角色类型：功能型
- 与主角关系：主角在天台上遇到的一个"流浪汉"——实际上是隐退的投资大佬
- 人设标签：看透世事 / 毒舌但心善 / 教主角"投资的本质"
- 未来价值：0（他已经不想赚钱了）
- 对主角的作用：系统之外的"人生导师"——教主角"钱不是万能的"
- 独立行为线：20年前他也是投资之神，但因为一次失败失去了一切
- 结局：他看着林浩走向了自己没走到的终点，释然了
```

```markdown
## 配角3：赵磊（28岁）— 功能型/兄弟
- 角色类型：功能型
- 与主角关系：主角在天台认识的外卖小哥——系统显示他"未来价值：千亿"
- 人设标签：勤奋 / 有想法但缺机会 / 讲义气
- 未来价值：100亿（因为林浩的"第一笔投资"就是他）
- 对主角的作用：主角"投资的第一个人"——后来成了主角商业帝国的CEO
- 独立行为线：从外卖小哥到千亿集团创始人（他的公司做什么？即时物流+AI调度）
- 兄弟线：他是主角最信任的人——"浩哥，你当初投我的时候，为什么选我？""因为系统说的。"（当然不能告诉他是系统）
```

```markdown
## 配角4：前妻王丽（33岁）— 对比型
- 角色类型：对比型
- 与主角关系：主角的前妻，因为主角被裁而离婚
- 人设标签：现实 / 不是坏人但很功利 / 后来后悔
- 对主角的作用：镜像对照——"当初你嫌我穷，现在我让你高攀不起"
- 独立行为线：她嫁给了一个"小老板"——但那个老板后来破产了
- 结局：她来找主角复合——主角拒绝了。不是报复，而是"我们已经是两个世界的人了"
```

### 5.3 反派设计

**初级反派：李总（45岁）——裁掉主角的CEO**
- 动机：为了公司"优化成本"——35岁以上的员工全部裁掉
- 压迫感：他裁掉主角时的那句"你35岁了，该认清现实了"
- 结局：公司破产（主角的"未来收益率"视野早就看到了），他来求主角投资——主角拒绝了

**中级反派：赵氏集团（家族企业）——主角在商业上的第一个大对手**
- 动机：垄断行业，打压新兴竞争者
- 压迫感：资金碾压、人脉碾压、规则碾压——主角在LV3之前完全不是对手
- 结局：主角用"趋势预测"能力提前布局，反杀

**终极反派：资本寡头联盟——掌控行业规则的一群人**
- 动机：维持既得利益，阻止"新势力"改变规则
- 压迫感：不是一个人，而是一个系统——这个系统曾经让主角一无所有
- 结局：主角用LV8的"改变未来"能力，打破了这个系统

## 六、分卷大纲（8卷结构，100万字+）

### 卷一：觉醒（约12万字，第1-40章）

**核心事件：** 被裁→觉醒系统→第一次投资→赚到第一桶金

**爽点设计：**
- 第3章：系统觉醒，看到路边股票"收益率+300%"——第一次验证
- 第5章：用仅有的5万块炒股，一天赚了15万——第一次爽感爆发
- 第10章：前妻来要赡养费，主角甩出一张20万的卡——第一个打脸
- 第15章：遇到赵磊（外卖小哥），系统显示"未来价值：千亿"——决定投资他
- 第20章：投资赵磊的公司（即时物流），赵磊感激涕零
- 第25章：前公司领导在同学聚会上嘲笑主角——主角亮出投资账户（500万），全场震惊
- 第30章：李总的公司开始出现问题（主角早就看到了）
- 第40章（卷末）：主角的系统升级到LV2——视野扩大到50米，解锁"项目详情"。**反转钩子：他看到了苏晴的公司——"未来收益率：+5000%，但90天后破产"。他必须在90天内投资她。**

### 卷二：布局（约15万字，第41-80章）

**核心事件：** 投资苏晴的公司→建立团队→赚到第一个1000万

**爽点设计：**
- 第45章：主角找到苏晴，提出投资——苏晴怀疑他是骗子
- 第50章：主角说出了苏晴公司的"核心问题"——苏晴震惊（他怎么知道？）
- 第55章：投资成功，苏晴的公司起死回生
- 第60章：赵磊的公司上线第一个版本——日活破10万
- 第65章：前妻的"小老板"老公开始出现问题（主角看到了他的"破产倒计时"）
- 第70章：主角用"项目详情"能力发现了一个被低估的AI项目——果断投资
- 第75章：AI项目爆发，主角赚到第一个1000万
- 第80章（卷末）：系统升级到LV3——视野500米，解锁"人物关系链"。**反转钩子：通过"人物关系链"，主角发现李总的公司背后有一个"大Boss"——赵氏集团。而赵氏集团正在策划一场"行业清洗"——主角的公司也在名单上。**

### 卷三：对抗（约15万字，第81-120章）

**核心事件：** 赵氏集团开始打压→主角反击→从"小鱼"变成"大鱼"

**爽点设计：**
- 第85章：赵氏集团开始打压苏晴的公司（断资金链、抢客户）
- 第90章：主角用"人物关系链"找到赵氏集团的"弱点"——他们的供应链有问题
- 第95章：主角投资了赵氏集团的"供应商"——间接掐住了赵氏的脖子
- 第100章：赵氏集团发现不对劲——开始针对主角
- 第105章：赵氏集团用"资本碾压"——试图收购主角的公司（恶意收购）
- 第110章：主角拒绝了——赵氏集团怒了
- 第115章：赵氏集团发动全面攻击（价格战、挖人、舆论抹黑）
- 第120章（卷末）：主角的公司差点被击垮——但在最后关头，赵磊的公司（即时物流）爆发了（日活破1000万）。**反转钩子：赵磊告诉主角一个秘密——赵氏集团的"大老板"，其实是20年前害老陈破产的那个人。**

### 卷四：反击（约15万字，第121-160章）

**核心事件：** 老陈的过去→主角全面反击→击败赵氏集团

**爽点设计：**
- 第125章：老陈讲述20年前的故事——他也是投资之神，但被赵氏集团的大老板坑了
- 第130章：主角决定帮老陈"报仇"
- 第135章：主角用LV3的"人物关系链"找到了赵氏集团的所有"致命弱点"
- 第140章：主角开始布局——表面上在和赵氏"合作"，暗地在"挖墙脚"
- 第145章：赵氏集团的一个核心项目被主角"截胡"
- 第150章：赵氏集团的股价开始暴跌
- 第155章：赵氏集团的大老板亲自找主角谈判——主角提出了一个"不可能"的条件
- 第160章（卷末）：赵氏集团破产。大老板跪着求主角投资——主角想起了当年李总裁他时的样子。**反转钩子：主角没有报复——他选择收购赵氏集团，而不是摧毁它。因为他意识到："摧毁一个旧世界很容易，但建立一个新世界很难。"**

### 卷五：帝国（约15万字，第161-200章）

**核心事件：** 收购赵氏集团→建立商业帝国→系统升级到LV5

**爽点设计：**
- 第165章：主角正式收购赵氏集团——从一个"被裁社畜"到"行业巨头"
- 第170章：苏晴的公司成为独角兽（估值100亿）
- 第175章：赵磊的公司上市（市值1000亿）
- 第180章：主角的女儿朵朵上贵族学校——前妻来"认亲"
- 第185章：主角拒绝了前妻——"我们已经是两个世界的人了"
- 第190章：系统升级到LV5——视野全城，解锁"趋势预测（30天）"
- 第195章：主角用"趋势预测"看到了一个"大危机"——30天后，整个行业会崩盘
- 第200章（卷末）：主角开始准备应对"大危机"——但他发现，这个危机不是自然发生的，而是有人"人为制造"的。**反转钩子：制造危机的人，是"资本寡头联盟"——一群掌控着整个行业规则的"老钱"。他们不允许"新势力"改变游戏规则。**

### 卷六：暗战（约15万字，第201-240章）

**核心事件：** 对抗资本寡头联盟→暗战→主角险些失败

**爽点设计：**
- 第205章：资本寡头联盟开始"做空"整个行业——主角的公司受到重创
- 第210章：主角用"趋势预测"提前布局——但还是低估了对手的实力
- 第215章：主角的公司股价暴跌——苏晴和赵磊都劝他"放弃"
- 第220章：主角拒绝放弃——他要用"趋势预测"做最后一次"豪赌"
- 第225章：豪赌成功——主角赚到了第一个100亿
- 第230章：资本寡头联盟震惊——他们没想到一个"底层出身"的人能对抗他们
- 第235章：联盟派出"终极武器"——一个比主角更厉害的投资天才
- 第240章（卷末）：主角和"投资天才"的对决——主角输了。**反转钩子：系统提示"检测到宿主能力不足，是否解锁LV6？条件：累计收益>10亿"。主角刚好差一点——他需要最后"一笔投资"来凑够10亿。而那笔投资，是他从未想过的方向。**

### 卷七：破局（约15万字，第241-280章）

**核心事件：** 解锁LV6→全国视野→打破资本寡头联盟

### 卷八：终局（约13万字，第281-320章）

**核心事件：** 解锁LV8→帮助100人逆袭→改变世界→结局

**爽点设计：**

- 第320章（结局）：五年后。主角站在公司楼顶，看着深圳的夜景。手机响了——是朵朵发来的消息："爸爸，我今天在班会上讲了你的故事。老师说你是最了不起的人。"主角笑了。全书最后一句：35岁那年，他失去了一份工作。但他找到了自己的命运。

## 八、开头3章详纲（必须留住读者）

### 第1章：35岁生日，我被裁了

**核心事件：** 林浩35岁生日当天被裁，人生跌入谷底

**冲突：** HR冷漠地递上辞退通知，林浩12年的付出被一句话否定

**爽点：** 无（第一章要压，压得越狠后面越爽）

**结尾钩子：** 林浩站在天台上，想跳下去——脑海里突然响起一个声音

**字数：** 3000字

**关键场景：**
- 开场直接进冲突："林浩，公司决定优化掉你。"
- 展示林浩的困境：房贷断供、妻子提离婚、女儿学费交不起
- 天台上的绝望——然后系统觉醒

### 第2章：神级投资系统

**核心事件：** 系统觉醒，林浩第一次使用能力

**冲突：** 林浩不相信系统——直到他验证了

**爽点：** 系统验证成功！路边一只股票头顶飘着"收益率：+300%"

**结尾钩子：** 林浩用仅有的5万块买了那只股票——第二天会发生什么？

**字数：** 3000字

**关键场景：**
- 系统介绍：能力、规则、限制
- 林浩半信半疑地验证——看到前老板头顶的"未来价值：破产倒计时365天"

### 第3章：5万变20万

**核心事件：** 股票暴涨，林浩赚到第一桶金

**冲突：** 林浩早上打开手机，看到股票涨了300%——但他不敢卖

**字数：** 3000字

**关键场景：**

## 九、更新策略

### 日更节奏

| 阶段 | 字数/天 | 时间 | 目的 |
|------|--------|------|------|
| 新书期（1-30天） | 6000字/天 | 中午12点+晚上8点各一章 | 快速冲验证期数据 |
| 首秀期（30-60天） | 6000字/天 | 同上 | 冲高完读率 |
| 稳定期（60天后） | 4000-6000字/天 | 晚上8点一章（或拆两章） | 维持追更率 |

### 卡章技巧

| 卡章类型 | 使用场景 | 示例 |
|---------|---------|------|
| **悬念卡章** | 每章结尾留一个未解问题 | "他打开手机，看到了一条消息。发件人是——"（断） |
| **情绪卡章** | 在高潮处断开 | "林浩按下了'卖出'键。然后他看到了账户余额——"（断） |
| **反转卡章** | 在反转前断开 | "对方笑了笑，说了一句话。这句话让林浩浑身冰凉——"（断） |
| **爽点卡章** | 在爽点爆发前断开 | "李总看着林浩的账户余额，脸色大变——"（断） |

### 完读率优化

- **每章前300字**：必须有冲突/悬念/爽点（不能平淡开头）
- **每章中间**：推进剧情+小爽点
- **每章结尾**：留钩子（让读者忍不住点下一章）
- **每10章**：一个中等高潮（防止读者疲劳）
- **每30章**：一个大高潮（卷末反转）
