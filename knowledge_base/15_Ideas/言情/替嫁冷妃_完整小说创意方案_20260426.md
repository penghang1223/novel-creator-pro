# 一、故事大纲

## 1.1 世界观设定

### 时代背景
架空历史"大周朝"，类似唐朝的开放风气+明清的后宫制度。皇帝昏庸，皇子夺嫡，朝堂动荡。

### 核心设定

**金手指：女主有"读心术"**
沈知意天生能听到别人的"心声"——但不是所有人的，只有当对方"情绪波动"时才能听到。

**规则：**
- 听到的是"真实想法"，不是谎言
- 距离限制：3米以内
- 副作用：读心过度会头痛
- 升级路径：LV1（听到情绪化心声）→LV2（主动触发）→LV3（屏蔽他人/只读特定人）

**替嫁设定：**
沈家大小姐沈知柔（嫡女）本该嫁给摄政王萧墨寒——一个传闻中"冷血无情、克死三任未婚妻"的王爷。但沈知柔有喜欢的人，不愿嫁。于是沈父让庶女沈知意替嫁。

## 1.2 主线剧情

### 起（1-30章）：替嫁入府
沈知意替嫁入摄政王府。新婚之夜，她听到萧墨寒的心声——不是"冷酷"，而是"紧张"。原来传闻中的"冷血王爷"其实是个"社恐+纯情"。

### 承（31-150章）：王府日常
沈知意用读心术化解一次次危机——侧妃陷害、管家刁难、太后试探。她和萧墨寒的关系从"相敬如宾"到"互相欣赏"到"暗生情愫"。

### 转（151-400章）：夺嫡风云
萧墨寒被卷入皇子夺嫡。沈知意用读心术帮他识破敌人、拉拢盟友。她发现替嫁背后有一个更大的阴谋——沈家与某位皇子勾结，意图谋害萧墨寒。

### 合（401-600章）：天下为聘
萧墨寒登基为帝。沈知意成为皇后。她终于可以告诉萧墨寒："我能听到你的心声。"萧墨寒笑了："我知道。我早就知道了。"

# 二、人物设定

## 2.1 男主

```markdown
## 萧墨寒（男，25岁）
- 身份：摄政王 → 皇帝
- 外貌：①冷峻型帅哥 ②眼神锐利但看女主时会温柔 ③穿着以玄色为主
- 性格：外表冷酷无情，内心纯情社恐（只对女主敞开心扉）
- 核心优势：武艺高强、智谋过人、手握兵权
- 性格缺陷：不擅长表达感情（社恐+纯情）；对感情极度不自信
- 成长弧线：从"封闭自己"到"学会信任"到"为爱放弃一切"
- 核心恐惧：再次失去爱的人（前三任未婚妻之死让他封闭自己）
- 核心渴望：被真心对待
```

## 2.2 女主

```markdown
## 沈知意（女，18岁）
- 身份：沈家庶女 → 摄政王妃 → 皇后
- 外貌：①清丽脱俗 ②笑起来有酒窝 ③眼睛特别亮（读心时会微微发光）
- 性格：聪慧、善良、有主见、不圣母
- 金手指：读心术（听到情绪波动者的心声）
- 核心优势：读心术+高情商
- 性格缺陷：过度使用读心术会头痛；有时过度依赖读心术而忽略"信任"
- 成长弧线：从"被动替嫁"到"主动掌控命运"
- 核心恐惧：被人当成"怪物"（读心术暴露后的恐惧）
- 核心渴望：被真心爱（不是因为"有用"，而是因为"她是谁"）
```

## 3.2 前10章细纲

### 第1章：替嫁
沈知意被父亲叫到书房。"你姐不愿嫁给摄政王。你替她去。"知意没有哭——她早就知道自己是庶女，命不由己。
**爽点**：无（压到最低）
**钩子**：知意听到父亲的心声："这个庶女，反正也不值钱。"

### 第2章：花轿
知意坐上花轿。轿外是沈知柔的哭声（假的）。知意听到轿夫的心声："这摄政王克死三个未婚妻，这姑娘怕是活不过洞房。"
**爽点**：🟢小爽点（知意淡定应对恐惧）
**钩子**：花轿到了王府。门开了——一个高大的身影站在门口。

### 第3章：新婚之夜
萧墨寒掀开盖头。知意抬头——冷峻的脸，锐利的眼。然后她听到了他的心声："她会不会讨厌我？我是不是该笑一下？"
**爽点**：🔴大爽点（冷血王爷竟是纯情社恐！）
**钩子**：知意差点笑出来——传闻中的"冷血王爷"，原来是个紧张到不会说话的男人。

### 第4章：侧妃挑衅
第二天，柳侧妃来"请安"。表面温柔，话里带刺。知意用读心术听到她的真实想法："一个庶女也配当王妃？"
**爽点**：🟡中爽点（知意完美反击）
**钩子**：柳侧妃离开时，知意听到她的心声："三皇子说了，这个女人必须死。"

### 第5章：第一次救人
知意听到管家的心声——他在王爷的茶里下了毒。知意"不小心"打翻了茶杯。王爷皱眉："王妃，你为何如此莽撞？"
**爽点**：🔴大爽点（暗中救人）
**钩子**：王爷听到知意的心声（他不知道知意能读心）——"王爷，我不能告诉你我能听到别人的心声。但我会保护你。"

### 第6章：王爷的疑惑
萧墨寒开始注意这个"替嫁"的庶女。她不似传闻中那般怯懦——她聪明、冷静，而且……有点可爱。
**爽点**：🟢小爽点（王爷开始在意女主）
**钩子**：萧墨寒的心声："她到底是个什么样的女人？"

### 第7章：太后召见
太后召知意入宫。表面是"关心"，实则是试探。知意用读心术听到太后的真实意图——她在测试知意是否值得信任。
**爽点**：🟡中爽点（完美应对太后）
**钩子**：太后的心声："这个女人……也许能帮到墨寒。"

### 第8章：王爷的醋意
知意在花园遇到一位年轻公子（其实是王爷的暗卫）。两人聊了几句。萧墨寒远远看到，心声："那个男人是谁？为什么对她笑？"
**爽点**：🟢小爽点（王爷吃醋，超可爱）
**钩子**：萧墨寒故意走到知意身边，冷冷地说："王妃，回房。"——但他的心声是："我不想她和别人说话。"

### 第9章：刺客
夜里，刺客潜入王府。知意用读心术提前听到刺客的心声，救了萧墨寒一命。萧墨寒震惊："你怎么知道？"
**爽点**：🔴大爽点（读心救夫）
**钩子**：萧墨寒看着知意，眼神变了。他的心声："她到底是什么人？"

### 第10章：LV2升级
知意的读心术升级到LV2——能主动触发。她第一次"主动"读了萧墨寒的心声。
**爽点**：🔴大爽点（能力升级）
**钩子**：萧墨寒的心声让知意眼眶湿润："如果……她能真心待我就好了。哪怕只是一天。"

# 四、商业化设计

## 4.1 短剧前3集脚本

- 场景3：管家在茶里下毒，知意"不小心"打翻。
- 场景4：王爷皱眉。

- 每集8-12个关键分镜
