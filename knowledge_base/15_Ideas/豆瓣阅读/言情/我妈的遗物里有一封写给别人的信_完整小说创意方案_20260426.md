# 一、故事大纲

## 1.1 世界观设定

### 时代背景
2026年，三线城市。母亲去世后，女儿在遗物中发现了一封写了30年但从未寄出的信——信的内容颠覆了她对"母亲"的所有认知。

### 核心设定：遗物叙事

**叙事结构：**
通过母亲的遗物（信/日记/照片/录音）逐步揭示真相。现在（女儿整理遗物）+ 过去（母亲的故事），两条时间线交替推进。

**社会议题：**
- 原生家庭：中国式家庭的"不说"文化
- 母女关系："不说爱"的中国式母亲
- 代际冲突：理解父母的不完美
- "母亲"这个角色的复杂性

## 1.2 主线剧情

### 起（1-20章）：遗物
母亲去世。女儿林晚整理遗物——发现了一封信，第一句话是："如果你看到这封信，说明我终于可以不骗你了。"

### 承（21-50章）：追查
林晚开始调查信中的内容——母亲的过去。每一样遗物都揭示一个秘密。

### 转（51-75章）：真相
母亲不是"不爱"——她是"不会爱"。她也是一个被伤害过的女儿。

### 合（76-90章）：和解
林晚理解了母亲——不是原谅，是理解。她带着母亲的爱，继续生活。

# 二、人物设定

## 2.1 女主

```markdown
## 林晚（女，27岁）
- 身份：广告公司文案策划
- 外貌：①笑起来有酒窝（像母亲） ②左手腕有一道小时候的疤痕 ③紧张时会摸左耳
- 性格：敏感、共情能力强、讨好型人格
- 核心动机：搞清楚母亲到底瞒了她什么
- 核心恐惧：被抛弃
- 核心渴望：被无条件地爱
```

## 3.2 前10章细纲

### 第1章：遗物
林晚站在灵堂里，看着母亲的遗像。她笑得很平静——和林晚认识的那个她一点都不像。整理遗物时，林晚在枕头下发现了一封信。信封上写着："晚晚。"
**反转**：无
**钩子**：信的第一句话："如果你看到这封信，说明我终于可以不骗你了。"

### 第2章：半页信
林晚翻到第二页——没有了。信只写了半页。剩下的一半，被谁撕掉了？
**反转**：🟡中
**钩子**：半页信上写着一个名字——不属于林晚认识的任何人。

### 第3章：回忆
林晚回忆母亲——她是个很凶的女人。打骂、冷漠、比较。林晚恨了她27年。但此刻，她站在灵堂里，眼泪止不住。
**反转**：🟡中
**钩子**：林晚在衣柜深处发现了一本日记——被撕掉了几页。

### 第4章：日记残页
残页上隐约能看到一个名字——和信上的名字对上了。
**反转**：🟡中
**钩子**：这个名字是谁？

### 第5章：小姨
林晚找小姨问真相。小姨回避了。"你妈让你别问了。"
**反转**：🟡中
**钩子**：小姨的眼神在说谎。

### 第6章：老照片
林晚在遗物中找到一张12岁前的照片——是她和母亲的合影。但母亲从来没有保留过她12岁后的照片。
**反转**：🟡中
**钩子**：照片背后写着一行字："对不起。"

### 第7章：赵宇
赵宇来看林晚。他说："你还好吗？"林晚说："不好。"然后她哭了。
**反转**：🟡中
**钩子**：赵宇说："也许你该去看看你妈的东西。"

### 第8章：录音笔
林晚在抽屉最深处找到了一支录音笔。按下播放——是母亲的声音。
**反转**：🔴大
**钩子**：母亲说："晚晚，妈妈对不起你。但妈妈最后想告诉你：你不是被买的，你是被选中的。"

### 第9章：选中？
"被选中"是什么意思？林晚完全不懂。
**反转**：🟡中
**钩子**：录音结束后，还有一个声音——一个男人的声音说"对不起"。

### 第10章：LV2
林晚的能力（调查能力）升级——她开始系统地整理母亲的遗物。
**反转**：🟡中
**钩子**：她找到了一份旧报纸——27年前的。日期正好是她的生日。

- 双线交替：现在（整理遗物）+ 过去（母亲的故事）
