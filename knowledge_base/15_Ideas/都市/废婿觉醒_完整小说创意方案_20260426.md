# 一、故事大纲

## 1.1 世界观设定

### 时代背景
现代都市，架空城市"江州市"。表面是普通都市，暗地里存在一个"鉴宝江湖"——古玩、玉石、文物、奇珍异宝的交易网络，水极深，利益极大。

### 金手指：万物估值之眼

**核心能力：**
男主林辰意外觉醒一双"估值之眼"——能看到任何物品的"真实价值"（显示为具体金额），以及"隐藏属性"（需要升级解锁）。

**显示规则：**
- 初级（LV1-LV3）：只能看到"金钱价值"——物品头顶显示价格标签
- 中级（LV4-LV6）：解锁"隐藏属性"——能看到物品的"隐藏价值"（如古董年代、玉石内部结构、药物成分）
- 高级（LV7-LV9）：解锁"未来价值"——能看到物品"未来的价值变化趋势"（如某块荒地未来会建地铁站）
- 终极（LV10）：解锁"万物本源"——能看到"一切事物的本质价值"（包括人的价值、信息的价值、关系的价值）

**升级条件：**
| 等级 | 升级条件 | 新能力 |
|------|---------|--------|
| LV1 | 觉醒 | 看到5米内物品的基础价值 |
| LV2 | 累计"捡漏"收益>10万 | 视野扩大到50米 |
| LV3 | 累计收益>100万 | 视野500米，解锁"稀有度标注" |
| LV4 | 累计收益>1000万 | 解锁"隐藏属性" |
| LV5 | 累计收益>1亿 | 视野5公里，解锁"历史溯源" |
| LV6 | 累计收益>10亿 | 解锁"未来价值趋势"（3天） |
| LV7 | 累计收益>100亿 | 视野全城，趋势预测（30天） |
| LV8 | 累计收益>1000亿 | 全国范围，趋势预测（1年） |
| LV9 | 累计收益>1万亿 | 全球范围，趋势预测（5年） |
| LV10 | 完成"终极任务" | 万物本源 |

**限制/平衡：**
- 能力有"冷却时间"——连续使用超过1小时会"眼睛剧痛"，强制冷却
- 过度依赖能力会导致"价值盲区"——有些东西的价值不能用钱衡量（如感情、信任）
- 能力只在"物品"上生效——不能直接看到"人"的价值（LV10解锁）

### 社会结构
- 底层：普通百姓（男主起点）
- 中层：小商人/白领/普通鉴宝师
- 高层：鉴宝大师/古玩商/玉石大亨
- 顶层："鉴宝四大家族"（掌控全国古玩玉石市场的四大家族）
- 隐藏层："暗网鉴宝圈"（跨国文物走私集团，终极BOSS）

## 1.2 主线剧情（起承转合）

### 起（1-30章，约30万字）：废婿觉醒
**核心冲突**：入赘三年受尽屈辱 → 觉醒估值之眼 → 第一次逆袭

**剧情线：**
- 林辰入赘苏家三年，被岳母羞辱、被大舅哥欺负、被全家族当成废物
- 妻子苏清雪对他冷淡但并非恶意——她只是被家族逼迫嫁给他
- 一次意外（被大舅哥推下楼梯撞到头），林辰觉醒"万物估值之眼"
- 用能力在地摊上"捡漏"到一个价值百万的古董，赚到第一桶金
- 用捡漏的钱投资一个项目，打脸大舅哥
- 初步引起鉴宝圈的注意

### 承（31-200章，约100万字）：鉴宝江湖
**核心冲突**：进入鉴宝圈 → 与各路高手过招 → 逐步积累财富和势力

**剧情线：**
- 林辰进入古玩市场，凭借估值之眼一路"捡漏"
- 结识鉴宝圈的重要人物（导师、盟友、竞争对手）
- 与苏家的关系开始变化——苏清雪开始重新认识他
- 鉴宝四大家族中的某一家开始注意到他
- 第一次与四大家族正面交锋——险胜
- 能力升级到LV4，解锁"隐藏属性"
- 发现妻子苏清雪的公司面临危机——暗中帮助

### 转（201-500章，约150万字）：商战风云
**核心冲突**：从"捡漏暴富"升级为"商业帝国" → 与四大家族全面对抗

**剧情线：**
- 林辰建立自己的商业帝国（古玩+玉石+房地产+投资）
- 四大家族联合打压——林辰陷入危机
- 发现四大家族背后有一个更大的势力："暗网鉴宝圈"
- 妻子苏清雪的公司被四大家族针对——林辰正面迎战
- 能力升级到LV6，解锁"未来价值趋势"
- 利用"未来趋势"提前布局，反杀四大家族
- 发现"暗网鉴宝圈"涉及跨国文物走私——上升到国家层面

### 合（501-800章，约120万字）：终极对决
**核心冲突**：对抗跨国文物走私集团 → 守护国宝 → 成就传奇

**剧情线：**
- 林辰发现"暗网鉴宝圈"的头目竟然是……（终极反转）
- 与国家力量合作，对抗跨国犯罪集团
- 能力升级到LV10，解锁"万物本源"
- 最终决战：不仅是财富的较量，更是"什么是真正的价值"的哲学思考
- 林辰明白：最珍贵的不是价值连城的古董，而是身边的人
- 结局：林辰建立"国宝守护基金会"，与苏清雪修成正果

# 二、人物设定

## 2.1 男主

```markdown
## 林辰（男，26岁）
- 身份：苏家赘婿 → 鉴宝圈新星 → 商业帝国掌控者 → 国宝守护者
- 外貌：①五官普通但耐看 ②觉醒后眼神变得锐利 ③穿着从廉价到定制
- 性格：前期隐忍（三年赘婿磨平了棱角）→ 中期霸气（能力带来的自信）→ 后期沉稳（财富和阅历的沉淀）
- 金手指：万物估值之眼（能看到任何物品的真实价值）
- 核心优势：隐忍力强、学习能力强、对"价值"有独特的理解
- 性格缺陷：前期过度自卑；中期容易膨胀（被财富冲昏头脑）
- 成长弧线：
  卷1-2：从"被欺辱的废婿"到"小有积蓄"
  卷3-4：从"小有积蓄"到"鉴宝圈名人"
  卷5-6：从"鉴宝圈名人"到"商业帝国掌控者"
  卷7-8：从"商业帝国"到"国宝守护者"
- 核心恐惧：再次回到一无所有的日子
- 核心渴望：证明自己的价值——"我不是废物"
- 关系锚点：妻子苏清雪（从冷漠到相爱）
```

## 2.2 女主

```markdown
## 苏清雪（女，25岁）
- 身份：苏家大小姐 → 苏氏集团CEO → 林辰的妻子
- 外貌：①冷艳型美女 ②职场精英范 ③笑起来有酒窝（只对林辰笑过两次）
- 性格：外冷内热、独立坚强、有商业头脑
- 背景：被家族逼迫嫁给林辰（家族与林家有旧约），起初对林辰冷淡但并非恶意
- 对男主的作用：早期的"情感动力"（林辰想证明自己配得上她）；后期的事业合伙人
- 感情线：冷淡→好奇→欣赏→依赖→深爱（慢热型，不舔不虐）
- 独立行为线：苏氏集团从濒临破产到行业独角兽
- 反转：第200章揭示她一直在暗中保护林辰（家族内部有人想害他）
```

- 下场：第400章被林辰用"未来价值趋势"反杀，赵家破产

- 动机：跨国文物走私，掌控全球黑市
- 压迫感：不是一个人，而是一个跨国犯罪网络
- 终极反转：第500章揭晓——他竟然是林辰父亲的"师弟"，也是当年害死林辰父母的凶手之一
- 下场：第800章被林辰和国家力量联手铲除

## 3.3 前10章细纲

### 第1章：赘婿的日常
**剧情**：林辰在苏家的日常——岳母的冷嘲热讽、大舅哥的欺辱、妻子的冷淡。3000字。
**爽点**：无（第一章压到最低）
**钩子**：大舅哥推了林辰一把，林辰后脑撞到了茶几。

### 第2章：觉醒
**剧情**：林辰昏迷中做了一场梦——梦里有一个声音说"万物皆有价，唯人心无价"。醒来后，他发现自己的眼睛不一样了——看到桌上的水杯，头顶飘着一个数字："¥15"。
**爽点**：🟢小爽点（能力觉醒的惊奇感）
**钩子**：林辰试着看向窗外——街对面一个地摊上，一个破碗头顶飘着："¥1,000,000"。

### 第3章：第一桶金
**剧情**：林辰跑到地摊前，用身上仅有的500块买下了那个破碗。摊主嘲笑他"花500块买个破碗"。林辰拿着碗去找鉴定专家——专家震惊：这是明清官窑，价值至少100万！
**爽点**：🔴大爽点（500块变100万）
**钩子**：专家问："你从哪得到的？"林辰说了一个地址——专家脸色大变："那个地摊……已经三年没有真货了。"

### 第4章：岳母的嘴脸
**剧情**：林辰回到苏家，岳母又开始羞辱他："你个废物，连个正经工作都没有，整天在外面捡垃圾。"林辰没有反驳——他打开手机银行，余额显示：1,000,000。
**爽点**：🟡中爽点（打脸前的铺垫）
**钩子**：大舅哥打来电话："明天家族聚会，你最好别来丢人。"

### 第5章：家族聚会
**剧情**：家族聚会上，所有人都在炫耀自己的成就。大舅哥炫耀自己新买的车。岳母炫耀大儿子的生意。轮到林辰——所有人都等着看他笑话。

### 第6章：鉴定

**爽点**：🔴大爽点（打脸全场）
**钩子**：岳母的态度开始变化——她从"废物"变成了"我们家辰辰"。

### 第7章：投资
**剧情**：林辰用100万投资了一个项目——大舅哥的公司正在竞标同一个项目。所有人都觉得林辰疯了。
**爽点**：🟢小爽点（林辰看到项目的"未来价值"）

### 第8章：反转

**爽点**：🔴大爽点（逆袭打脸）

### 第9章：老杨

**爽点**：🟡中爽点（导师登场）
