# 一、故事大纲

## 1.1 核心设定

**一句话故事：**
离婚后，我谈了个小我5岁的男朋友——直到见家长那天，我才发现他是前夫的亲侄子。

**叙事风格：**
第一人称"我"。开头50字直接进冲突。轻松幽默基调，但情感线真实。

**社会议题：**
姐弟恋 / 离婚女性 / 家庭关系 / "不婚"讨论

## 1.2 主线剧情

### 起（1-3章）：相遇
离婚后，林夏遇到了28岁的周默。他温柔、体贴、不像前夫那样"忙"。他们恋爱了。

### 承（4-8章）：甜蜜
姐弟恋的日常——甜蜜但也有外界的压力。父母的质疑、朋友的八卦、同事的好奇。

### 转（9-12章）：危机
见家长那天，门开了——开门的人是前夫。周默叫他"小叔"。

### 合（13-15章）：选择
面对这个戏剧性的局面，林夏和周默选择了彼此。前夫最终也释然了。

# 二、人物设定

```markdown
## 林夏（女，33岁）
- 身份：广告公司创意总监，刚离婚
- 外貌：短发/中性风格/笑起来灿烂
- 性格：独立、有主见、不妥协
- 核心恐惧：再次被抛弃
- 核心渴望：被爱"这个人"而不是"这个角色"
```

## 2.2 男主

```markdown
## 周默（男，28岁）

- 外貌：温和型/戴眼镜/笑起来有酒窝
- 性格：温柔、理性、有安全感
- 核心恐惧：被拒绝（因为年龄差和家族关系）
- 核心渴望：一个"不会散"的家
```

# 三、分章规划

## 3.1 全文结构（2-3万字，15章）

| 阶段 | 章节 | 核心事件 | 反转 |
|------|------|---------|------|
| 起（相遇） | 1-3 | 离婚→遇到周默→恋爱 | 周默的温柔 |
| 承（甜蜜） | 4-8 | 姐弟恋日常→外界压力 | 前夫来试探 |
| 转（危机） | 9-12 | 见家长→发现是前夫侄子 | 戏剧性反转 |
| 合（选择） | 13-15 | 面对→选择彼此→前夫释然 | 年龄和过去不重要 |

## 3.2 逐章细纲

### 第1章：离婚当天
我离婚了。走出民政局，天下着雨。一个年轻人把伞递给我。"需要伞吗？"他笑起来有酒窝。
**钩子**：他叫周默。28岁。

### 第2章：周默
周默很温柔。不像前夫——前夫永远在忙。周默会记得我不吃香菜，会在我加班时送饭。
**钩子**：但我知道，我们之间有一个问题——他比我小5岁。

### 第3章：决定
"你认真的？"小雨问。"认真。"我说。
**钩子**：周默说："我不在乎你离过婚。"

### 第4章：父母
我妈："他比你小5岁？你疯了？"我："妈，我很幸福。"
**钩子**：周默的紧张——他第一次见家长。

### 第5章：朋友
朋友八卦："姐弟恋不靠谱。""你怎么知道？""我表姐就是……"
**钩子**：我挂了电话。我不想听。

### 第6章：前夫
前夫发来消息："听说你谈恋爱了？"我回："嗯。"他："他什么样的人？"
**钩子**：前夫说："改天一起吃个饭。"

### 第7章：周默的话
"你真的想好了吗？"周默问。"想好了。"我说。
**钩子**：周默笑了。"那我们去见我家人吧。"

### 第8章：见家长
我紧张了一整晚。周默说："别紧张，我家人很好相处的。"
**钩子**：门开了。

### 第9章：反转
门开了。开门的人是——前夫。周默叫他："小叔。"
**钩子**：前夫看到我，脸色变了。"你怎么会……和我侄女在一起？"

### 第10章：混乱
周默看看我，又看看他小叔。"你们……认识？"前夫："她是我前妻。"
**钩子**：周默愣住了。

### 第11章：对话
前夫把周默叫到一边。我听到他们在说什么。"你疯了她比你大5岁！""小叔，我爱她。"
**钩子**：前夫沉默了很久。

### 第12章：前夫的态度
前夫回到我面前。"你真的爱他？""爱。"我说。
**钩子**：前夫叹了口气。"那就好好对他。"

### 第13章：家庭聚会
家庭聚会——戏剧性但温暖。前夫和周默居然聊得很开心。
**钩子**：前夫说："我以前对不起你。但他不会。"

### 第14章：父母被说服
我妈见了周默——被他的真诚打动了。"也许年龄真的不重要。"
**钩子**：周默笑了。

### 第15章：结局
一年后。我和周默办了一场小型婚礼。前夫来了，送了一份礼物——一本书，扉页写着："祝你们幸福。"全书最后一句：年龄和过去都不重要。重要的是现在和未来。
**钩子**：全书完。

# 六、写作SOP

## 6.1 开头技巧
- 前50字直接进冲突："门开了，开门的人是我前夫。"
- 不要背景介绍
- 第一句就是钩子

## 6.2 反转节奏
- 每章1个反转/悬念
- 第9章大反转（见家长）
- 卷末情感高潮

## 6.3 盐选过稿要点
- [ ] 第一人称"我"
- [ ] 开头50字冲突
- [ ] 几百字一反转
- [ ] 短句为主
- [ ] 不光爽文（情感深度）
- [ ] 正文人工写

- 每章中间：推进+小反转
- 每章结尾：钩子
- 付费卡点：第9章末尾（反转）
