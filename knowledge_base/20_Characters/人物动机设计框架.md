# 人物动机设计框架

> 让角色行为有"为什么"。不是"因为剧情需要所以这样做"，而是"因为这个人在这个处境下必然会这样做"。

---

## 四维动机模型

每个有台词的角色（不包括工具人），必须至少有**2个维度**的动机：

| 维度 | 定义 | 示例（林辰） |
|------|------|-------------|
| **欲望** | 他想要什么？ | 想要赚钱养女儿、想要证明自己 |
| **恐惧** | 他怕什么？ | 怕失去朵朵的抚养权、怕32岁再也没人要 |
| **创伤** | 什么经历塑造了他？ | 被裁员（十年忠诚被辜负）、离婚（关系失败） |
| **缺陷** | 他的性格弱点是什么？ | 面对女儿太心软、被逼急了才行动（不够主动） |

**关键**：四维之间必须有**内部冲突**。
- 欲望 vs 恐惧 = "想做但不敢"
- 欲望 vs 缺陷 = "想做但做不到"
- 创伤 → 恐惧 = 过去的伤导致现在的怕

---

## 动机→行为链条

角色的每一个行为，都应该能追溯到动机：

```
创伤 → 形成恐惧 → 恐惧塑造行为模式 → 行为模式产生缺陷 → 缺陷阻碍欲望 → 产生冲突
```

**示例（林辰）**：
```
被裁员（创伤）→ 怕再也找不到工作（恐惧）→ 不敢主动出击，只投简历（行为模式）
→ 错过机会（缺陷）→ 想赚钱但赚不到（欲望受阻）→ 内心冲突
```

**示例（苏晴）**：
```
林辰曾经不顾家（创伤）→ 怕朵朵再受伤害（恐惧）→ 对林辰冷淡但不绝情（行为模式）
→ 矛盾（嘴上硬，心里还是在意）→ 看到林辰变化时重新审视（欲望：希望家庭完整）
```

---

## 不同类型角色的动机侧重

| 角色类型 | 主导维度 | 说明 |
|----------|----------|------|
| 主角 | 欲望+恐惧+创伤+缺陷（四维全有） | 驱动整本书 |
| 主要配角 | 欲望+创伤（至少2维） | 有故事感 |
| 反派 | 欲望+缺陷（过度膨胀的欲望+性格缺陷） | 让人恨但不让人觉得蠢 |
| 打脸对象 | 欲望（虚荣/势利） | 一个维度就够，但要极致 |
| 引路人 | 欲望（惜才/传承） | 不需要恐惧和创伤 |

---

## 动机设计速查表

创建新角色时，填这个表：

```
姓名：
欲望：（他想要什么？）
恐惧：（他怕什么？）
创伤：（什么经历塑造了他？）
缺陷：（他的性格弱点是什么？）
内部冲突：（四维之间的矛盾是什么？）
行为外化：（这些内心动机表现为什么外在行为？）
```
