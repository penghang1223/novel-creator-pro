# 人物行为逻辑一致性

> 解决问题：角色为什么会这样做？行为不符合人设→读者出戏→OOC（Out Of Character）。

---

## 核心原则：角色行为 = 动机 × 处境 × 性格

```
行为 = 他想要什么（动机）× 他现在面对什么（处境）× 他是这样的人（性格）
```

三者缺一，行为就"不像这个人"。

---

## 行为逻辑检查清单

写完角色的一个关键行为后，检查：

### 第1层：动机检查
- [ ] 这个行为是否服务于他的**欲望**？
- [ ] 这个行为是否在回避他的**恐惧**？
- [ ] 如果两者冲突，选了哪个？为什么？

### 第2层：处境检查
- [ ] 他做这个决定时，知道多少信息？（读者知道的≠角色知道的）
- [ ] 他有没有时间/资源做更好的选择？
- [ ] 有没有外部压力逼他做这个选择？

### 第3层：性格检查
- [ ] 这个行为符合他一贯的行为模式吗？
- [ ] 如果是"反常"行为，有没有足够的触发条件？（重大创伤/极端处境）
- [ ] 读者能不能理解"他为什么会这样做"？

---

## 常见OOC模式及防御

### 1. 主角突然变圣母

**症状**：之前果断的主角突然原谅/帮助/放过敌人
**原因**：剧情需要一个和解，但没有给主角足够的心理铺垫
**防御**：如果要让主角做"不符合性格"的事，必须先给一个**触发事件**（看到女儿的照片、回忆过去的善良、敌人展示了脆弱面）

### 2. 反派突然变蠢

**症状**：之前精明的反派做出不合理决策
**原因**：需要主角赢，但想不出合理的赢法
**防御**：反派的失败应该来自**信息差**（主角有系统他知道的更多），不是反派智商下降

### 3. 配角突然消失

**症状**：之前活跃的配角几章不出现
**原因**：写到其他线忘了这条线
**防御**：novel_state.json 的 character_states 每章更新，检查活跃角色是否合理缺席

### 4. 角色能力忽高忽低

**症状**：这章很聪明，下章犯低级错误
**原因**：不同章节需要不同能力水平
**防御**：角色的核心能力（智商/情商/体力/专业技能）写入角色档案，每次使用时检查一致性

## 行为决策树

当角色面临选择时，用这个决策树判断他会选什么：

```
Q1: 这个选择涉及他的欲望吗？
  → 是：他会倾向选择（除非恐惧更强）
  → 否：看Q2

Q2: 这个选择涉及他的恐惧吗？
  → 是：他会倾向回避（除非欲望/创伤足够强）
  → 否：看Q3

Q3: 这个选择涉及他的创伤吗？
  → 是：会触发防御机制（回避/攻击/否认）
  → 否：按正常性格反应

Q4: 他现在的情绪状态？
  → 冷静：按理性决策
  → 激动：会做出比平时更极端的选择
  → 绝望：会选择"反正都这样了"的选项
```

---

## "反常行为"的正确写法

角色偶尔做不符合性格的事，是好故事需要的。但必须**三步走**：

1. **前置触发**：一个足够强的事件打破了他的行为模式
2. **行为本身**：做了一个"不是他会做的事"
3. **后果反应**：他自己/周围人意识到"这不是他"

```
例：一向冷静的林辰突然在会议室摔了杯子。
前置：赵天宇当着全部门的面说"你女儿上的那个国际学校，学费还是前妻出的吧？"
行为：林辰摔了杯子。
后果：全场安静。林辰自己也愣了一下——他从来没摔过东西。
```
