## 一、命名核心原则

### 1.1 三大原则

**原则一：名字服务于人物，而非服务于审美**
- 名字是人物身份的标签，不是作者文采的展示
- 配角名字忌太抢戏，主角名字忌太普通
- 名字应反映人物出身、家庭期望、时代背景

**原则二：同一作品中名字风格要有差异但和谐**
- 出身不同阶层的人物，命名逻辑不同
- 不同阵营的人物，名字气质应有区分
- 名字风格差异体现世界观的真实感

**原则三：名字要有"理由"**
- 父母为什么取这个名字？（期望、纪念、忌讳、随意）
- 名字在故事中是否有意义？（伏笔、象征、反讽）
- 没有理由的名字就是AI名字

### 1.2 命名层次

| 人物层级 | 命名投入 | 示例 |
|----------|----------|------|
| 主角 | 精心设计，有寓意有伏笔 | 梅长苏（梅岭藏苏） |
| 主要配角 | 有特色，避免混淆 | 蓝忘机（忘机鸟，道家意） |
| 次要配角 | 简洁好记，有辨识度 | 老赵、铁柱 |
| 工具人 | 功能性命名 | 掌柜、店小二 |

## 二、AI命名特征与规避

### 2.1 AI命名的六大特征

| 特征 | 典型表现 | 规避方法 |
|------|----------|----------|
| 过度诗意化 | 若雪、诗涵、语嫣 | 用朴素字入名（根、铁、福、顺） |
| 文艺姓氏扎堆 | 苏、顾、沈、叶、林 | 混用常见姓（王、刘、赵、陈） |
| 含义太直白 | 勇敢→勇、美丽→美 | 用典故或间接表达 |
| 风格统一化 | 所有角色名字都像诗人 | 按阶层/地域区分风格 |
| 忽视时代 | 古代人用现代名 | 研究对应时代命名习惯 |
| 配角敷衍 | 张三李四王五 | 给配角一个特点+姓（独眼赵、铁手张） |

### 2.2 高频AI命名模式黑名单

**男性AI名**：
- 子轩/子涵/子墨/子豪（"子"字头四件套）
- 墨寒/墨渊/墨白/墨尘（"墨"字头男主标配）
- 夜X/暗X/冥X/幽X（反派暗色系滥用）
- 冷X/寒X/冰X（冷酷系滥用）

**女性AI名**：
- 若雪/若曦/若烟/若兮（"若"字头滥用）
- 语嫣/诗涵/紫萱/梦瑶（AI古风女名四件套）
- 冰X/雪X/霜X（清冷系滥用）

### 2.3 破除AI味的技巧

**技巧1：用不"美"的字入名**
```
AI: 苏若雪、顾清寒
破味: 苏根生、顾守义
效果: 真实感骤升
```

**技巧2：用辈分/排行命名**
```
AI: 裴玄清、穆灵均
破味: 裴二、穆老三
效果: 乡土武侠感
```

**技巧3：名字与性格反差**
```
AI: 冷酷杀手叫"寒冰"
破味: 冷酷杀手叫"来福"——因为师父希望他有福气
效果: 人物立刻立体
```

**技巧4：用方言/俗语入名**
```
AI: 村妇叫"翠花"（AI的乡土也是套路）
破味: 村妇叫"改改"——家里想要男孩改改运气
效果: 真实接地气
```

## 四、各题材命名规范

### 4.1 古代/架空

- **士族**: 双字名为主，讲究典故（怀瑾、修远、含章）
- **平民**: 单字名常见，朴素（王二、赵大、刘三）
- **排行**: 伯仲叔季 + 名（伯庸、仲礼、叔达、季明）
- **字与号**: 名用于自谦，字用于他称，号表志趣
- **忌讳**: 避帝王讳、避长者讳，这是真实历史逻辑

### 4.2 武侠

- **名门正派**: 儒雅中带武气（岳不群、令狐冲）
- **江湖散人**: 朴素有辨识度（老顽童、铁手）
- **反派**: 名字忌太直白，表面正气更阴狠（岳不群）
- **绰号**: 比本名更重要（东邪西毒南帝北丐）

### 4.3 仙侠/修真

- **仙门弟子**: 取天地意象（长庚、望舒、瑶光）
- **散修**: 朴素务实（老张、铁牛道人）
- **妖族**: 取自然意象（青鸾、白泽、九尾）
- **忌**: 全员名字都"空灵"，缺乏人味。建议散修/底层弟子用俗名

### 4.4 现代都市

- **60-70后**: 时代特征名（卫东、建国、红梅）
- **80后**: 单字名流行（伟、静、磊、鹏）
- **90后**: 多元化（思远、嘉宁、若素）
- **00后**: 忌"子轩/紫萱"（AI味太重），可用复古名

### 4.4b 都市商战/金融题材

商战题材的命名逻辑与普通都市不同——名字要服务于**身份感**和**权力关系**：

| 角色类型 | 命名逻辑 | 示例 | 避坑 |
|----------|----------|------|------|
| 技术创业者 | 现代感强，有朝气但不浮夸 | 许铭远、乔宇航 | 忌太"老派"（国强、建业） |
| 投资人/资本方 | 稳重有分量，暗藏锋芒 | 曹德胜、魏志恒 | 忌太"轻"（浩宇、天宇） |
| 分析师/专业人员 | 聪慧敏锐，简洁利落 | 褚静好、韩知秋 | 忌太"花"（紫萱、若雪） |
| 暗面反派 | 表面正气，实则城府 | 张培渊、周知白 | 忌名字太"黑"（暗、冥、幽） |
| 商界大佬 | 大气有格局，世家感 | 沈明轩、陆铭远 | 忌太"平民"（铁柱、大壮） |
| 打脸对象 | 势利感，名字略带炫耀感 | 赵天宇、王德发 | 忌和主角名风格混淆 |

**关键原则**：
- 同一小说中，不同阵营的名字气质要有**可感知的差异**
- 反派名字忌太直白（叫"暗夜"的是反派谁都知道），表面正气更阴狠
- 投资圈角色名要有"分量感"，不宜太轻飘

### 4.5 科幻

- **近未来**: 现代命名延续，可加编号（张远-7号）
- **远未来**: 简化命名趋势（代号制、单音节）
- **AI角色**: 用数字/编号/功能命名（EVE、HAL、天枢）
- **外星种族**: 建立命名系统（音节规律、前后缀规则）

## 五、阶层与命名差异

同一世界观内，不同阶层的命名逻辑必须不同：

| 阶层 | 命名特点 | 示例 |
|------|----------|------|
| 皇族 | 辈分+美词，大气庄重 | 承乾、嘉宁 |
| 世家 | 字辈严格，典故出处 | 伯庸、仲礼 |
| 文人 | 诗词典故，清雅 | 怀瑾、修远 |
| 武将 | 刚健有力，简洁 | 铁山、破军 |
| 商人 | 吉祥祈福，朴实 | 福来、有财 |
| 平民 | 朴素好养，单字 | 大壮、铁柱 |
| 贱民 | 贱名好养 | 二狗、栓子 |

**关键原则**：如果主角出身底层却名字文雅，需要有解释（如：父亲崇拜某位文人、村中秀才代起、自己后改）。

## 六、命名自检清单

### 生成名字后必查

- [ ] 是否命中AI命名黑名单？
- [ ] 是否与知名小说角色撞名？（使用 `name_generator.py` 自动检查）
- [ ] 同一作品中是否有读音/字形相近的名字？（易混淆）
- [ ] 名字是否符合角色的阶层和出身？
- [ ] 名字是否符合时代背景？
- [ ] 配角名字是否抢了主角的风头？
- [ ] 是否所有角色名字风格统一？（应差异化）
- [ ] 名字是否有"起名理由"？

### 使用命名脚本（v2）

```bash
# 基础用法：生成5个古风雅致男性名
python scripts/name_generator.py --gender male --style ancient_elegant --count 5

# 角色类型模式：按人设自动选风格
python scripts/name_generator.py --role entrepreneur --gender male --count 5
python scripts/name_generator.py --role investor --gender male --count 5
python scripts/name_generator.py --role villain --gender male --count 5
python scripts/name_generator.py --role analyst --gender female --count 5

# 年代适配
python scripts/name_generator.py --role parent --era 70 --gender male --count 5
python scripts/name_generator.py --role child --era 00 --gender female --count 5

# 带命名理由输出
python scripts/name_generator.py --role capitalist --gender male --reason --count 3

# 排除已有角色名（反同音检测）
python scripts/name_generator.py --role tech --gender male --exclude-names 林辰 苏晴 赵天宇 --count 5

# 完整示例：为商战小说起投资人名
python scripts/name_generator.py --role investor --gender male --surname-tier literary --exclude-surnames 叶 林 苏 顾 沈 --reason --count 5
```
