### 角色弧线模板

> 角色弧线 = 角色从故事开始到结束的内在变化轨迹

#### 弧线类型
- **正向弧线（成长型）**
    - **模式**：缺陷 → 认知 → 改变 → 成长
    - **适用**：热血文、成长文、逆袭文
    - **示例**：怯懦 → 勇敢、自私 → 担当、天真 → 成熟
    - **正向弧线公式**：初始状态 + 触发事件 + 错误选择 + 痛苦代价 + 觉醒 + 最终选择 = 成长
- **负向弧线（堕落型）**
    - **模式**：善良 → 诱惑 → 妥协 → 黑化
    - **适用**：悬疑文、暗黑文、悲剧
    - **示例**：正义 → 复仇 → 疯狂、纯良 → 贪婪
- **平弧线（坚守型）**
    - **模式**：信念 → 动摇 → 坚定 → 影响他人
    - **适用**：爽文主角、系统文、无敌流
    - **关键**：主角不变，但改变周围的人和世界
- **复合弧线**
    - **模式**：外在成长 + 内在平弧线（或反向）
    - **适用**：长篇、群像
    - **示例**：能力越来越强，但内心越来越孤独

#### 弧线设计步骤
- **Step 1：定义初始状态**

| 维度 | 描述 | 示例 |
| :--- | :--- | :--- |
| **性格** | 角色的核心性格特征 | 表面乐观，实则自卑 |
| **信念** | 角色认为世界是如何运作的 | "只有强者才能生存" |
| **恐惧** | 角色最害怕失去什么 | 害怕被抛弃、被否定 |
| **渴望** | 角色表面想要什么 | 想要被认可、想要权力 |
| **致命缺陷** | 阻碍角色获得幸福的内在问题 | 无法信任他人、过度讨好 |

- **Step 2：设计关键节点**

| 阶段 | 章节范围 | 触发事件 | 角色反应 | 内在变化 |
| :--- | :--- | :--- | :--- | :--- |
| **常态** | 1-10 | 日常生活展示缺陷 | 维持现状 | 无意识 |
| **打破** | 11-20 | 激励事件发生 | 抗拒改变 | 开始动摇 |
| **挣扎** | 21-40 | 尝试旧方法失败 | 痛苦、犹豫 | 认知冲突 |
| **低谷** | 41-50 | 最大挫折/失去 | 绝望、崩溃 | 旧信念崩塌 |
| **觉醒** | 51-60 | 获得新认知 | 接受真相 | 新信念萌芽 |
| **蜕变** | 61-80 | 主动选择新道路 | 行动证明改变 | 新信念确立 |
| **终局** | 81+ | 最终考验 | 用新方式解决问题 | 完成蜕变 |

- **Step 3：设置镜像角色**
用一个与主角弧相反的角色做对照：
- **主角成长** → **镜像角色堕落**（如：主角选择宽恕，镜像选择复仇）
- **主角坚守** → **镜像角色背叛**（如：主角坚守正义，镜像选择妥协）
- **主角黑化** → **镜像角色救赎**（如：主角堕落，镜像选择牺牲）

#### 常见弧线陷阱

| 陷阱 | 表现 | 解法 |
| :--- | :--- | :--- |
| **弧线断裂** | 角色行为前后不一致 | 每次重大转变必须有触发事件+内心独白 |
| **弧度过快** | 3章就从懦弱变勇敢 | 用"反复摇摆"替代"直线成长"，设置回退点 |
| **弧线消失** | 中后期角色不再变化 | 每20章设一个新认知节点，保持成长节奏 |
| **全员成长** | 所有角色都在变 | 平弧线角色做锚点，提供稳定性 |
| **说教式改变** | 角色突然顿悟并长篇大论 | 用行动证明改变，而非用嘴说 |

#### 弧线检测清单
- **初始缺陷是否清晰**：读者能否在开篇就感受到角色的"不完整"？
- **改变是否渐进**：角色的转变是否有足够的铺垫和反复？
- **代价是否真实**：角色是否为了成长付出了真实的代价（失去、痛苦）？
- **最终选择是否艰难**：角色的最终选择是否比初始选择更难？
- **镜像对比是否鲜明**：镜像角色是否有效突出了主角的选择？
