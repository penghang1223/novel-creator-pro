## 概述

### 什么是主节点

主节点是故事中**不可偏离的核心事件**，是长篇连贯性的锚点。

| 概念 | 说明 |
|------|------|
| 主节点 | 必须发生的关键事件，不可跳过或大幅偏离 |
| 灵活区 | 主节点之间的过渡内容，可自由发挥 |

### 为什么需要主节点

| 问题 | 解决方案 |
|------|---------|
| 写着写着偏离大纲 | 主节点作为锚点，确保方向正确 |
| 不知道哪里可以改 | 主节点不可改，灵活区可改 |
| 连贯性难以保障 | 主节点串联故事脉络 |

## 主节点类型

| 主节点类型 | 说明 | 典型位置 | 示例 |
|-----------|-----|---------|------|
| **开篇锚点** | 故事开局核心设定 | 第1-3章 | 获得金手指、穿越重生、觉醒能力 |
| **境界突破** | 主角实力重要提升 | 不固定 | 突破境界、觉醒新能力、获得新功法 |
| **关键转折** | 故事走向重大变化 | 不固定 | 反派现身、阵营转变、身份暴露 |
| **高潮事件** | 阶段性大高潮 | 每卷1-2个 | 宗门大比、秘境争夺、生死决战 |
| **换地图** | 世界观扩展 | 卷末或卷中 | 从下界到上界、离开新手村 |
| **卷末收束** | 每卷收尾节点 | 每卷末尾 | 目标达成、伏笔回收、阶段结束 |

### 主节点特征

| 特征 | 主节点 | 灵活区 |
|------|--------|--------|
| 可否跳过 | ❌ 不可跳过 | ✅ 可调整 |
| 可否偏离 | ❌ 不可偏离 | ✅ 可自由发挥 |
| 规划时机 | 细纲阶段确定 | 写作时发挥 |
| 记录要求 | 必须记录执行情况 | 可选记录 |

## 章节类型标记

在细纲中，每章需标记章节类型：

| 标记 | 含义 | 说明 |
|------|------|------|
| 【主节点】M1, M2... | 主节点章节 | 必须按细纲执行 |
| 【灵活区】 | 普通章节 | 可适当发挥 |
| 【过渡】 | 过渡章节 | 连接两个主节点 |

### 细纲中的标记示例

```markdown
## 第一卷细纲

### 第1章：觉醒 【主节点】M1
- 核心事件：穿越 → 危机 → 系统激活

### 第2章：求生 【灵活区】
- 核心事件：消化金手指，规划求生

### 第3章：第一次任务 【主节点】M2
- 核心事件：完成系统任务，获得第一个奖励

### 第4-5章：宗门日常 【过渡】
- 核心事件：铺垫宗门环境，引出矛盾

### 第6章：冲突爆发 【主节点】M3
- 核心事件：与反派第一次正面冲突
```

## 主节点判断标准

### 判断流程

```
这个事件是否属于主节点？

1. 是否在细纲中标记为主节点？
   → 是：按主节点处理
   → 否：继续判断

2. 是否影响主线走向？
   → 是：按主节点处理
   → 否：按灵活区处理

3. 是否涉及以下类型？
   - 境界突破
   - 关键转折
   - 高潮事件
   - 换地图
   → 是：按主节点处理
   → 否：按灵活区处理
```

### 典型主节点示例

| 主节点类型 | 判断依据 | 典型特征 |
|-----------|---------|---------|
| 开篇锚点 | 是否涉及金手指/穿越/觉醒 | 故事起点的核心设定 |
| 境界突破 | 是否改变主角实力等级 | 从练气到筑基、从筑基到金丹 |
| 关键转折 | 是否改变故事走向 | 敌人变朋友、盟友变敌人 |
| 高潮事件 | 是否是阶段性高潮 | 大比、决战、秘境 |
| 换地图 | 是否切换世界观范围 | 离开新手村、进入新世界 |
| 卷末收束 | 是否完成卷级目标 | 阶段目标达成 |

## 主节点规划流程

### 细纲设计时

1. **识别主节点**：根据故事脉络，确定本卷的主节点
2. **标记主节点**：在细纲中用【主节点】M1, M2...标记
3. **描述主节点**：明确每个主节点的核心事件
4. **规划灵活区**：在主节点之间填充过渡内容

### 正文创作时

1. **识别章节类型**：确认当前章节是否为主节点
2. **主节点章节**：严格按细纲执行，记录执行情况
3. **灵活区章节**：可适当发挥，但不可影响后续主节点
