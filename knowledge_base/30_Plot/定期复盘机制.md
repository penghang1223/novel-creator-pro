## 概述

### 什么是复盘

复盘是在创作过程中定期回顾，检查连贯性、发现问题的机制。

| 复盘目的 | 说明 |
|---------|------|
| 检查连贯性 | 确保前后设定、情节一致 |
| 发现问题 | 及时发现伏笔遗漏、人物矛盾等 |
| 调整方向 | 根据实际情况调整后续规划 |
| 记录偏差 | 记录与细纲的偏差，便于追溯 |

### 复盘与评估的区别

| 维度 | 复盘 | 评估 |
|------|------|------|
| 执行者 | 编辑 | 编辑 |
| 触发时机 | 定期/条件触发 | 阶段完成时 |
| 关注点 | 连贯性、偏差 | 方案质量 |
| 作用 | 保障长篇连贯性 | 保障阶段性质量 |

## 复盘频率

### 按创作阶段设定

| 创作阶段 | 章节范围 | 复盘频率 | 原因 |
|---------|---------|---------|------|
| 开篇期 | 第1-30章 | 每5章 | 开篇关键，需密切关注 |
| 发展期 | 第31-100章 | 每10章 | 进入稳定期，频率降低 |
| 高潮期 | 卷末20章 | 每5章 | 高潮密集，需密切关注 |

### 复盘时机计算

```
当前章节 = X

开篇期（X ≤ 30）：X % 5 == 0 时复盘
发展期（30 < X ≤ 100）：X % 10 == 0 时复盘
高潮期（X > 卷末20章）：每5章复盘
```

### 示例

| 章节 | 阶段 | 是否复盘 | 说明 |
|------|------|---------|------|
| 第5章 | 开篇期 | ✓ | 5 % 5 == 0 |
| 第10章 | 开篇期 | ✓ | 10 % 5 == 0 |
| 第30章 | 开篇期 | ✓ | 30 % 5 == 0 |
| 第40章 | 发展期 | ✓ | 40 % 10 == 0 |
| 第50章 | 发展期 | ✓ | 50 % 10 == 0 |
| 第55章 | 发展期 | ✗ | 55 % 10 != 0 |

## 复盘触发条件

### 定期触发

根据复盘频率，在达到指定章节时自动触发。

### 条件触发

以下情况立即触发复盘，不受频率限制：

| 触发条件 | 说明 |
|---------|------|
| 主节点偏离 | 检测到主节点偏离时 |
| 伏笔异常 | 发现伏笔遗漏或矛盾时 |
| 人物矛盾 | 发现人物设定矛盾时 |
| 时间线错乱 | 发现时间线不合理时 |
| 用户要求 | 用户主动要求复盘时 |

## 复盘执行流程

### 流程图

```
触发复盘条件

↓

【编辑】执行复盘
├── 1. 读取状态记录
│     ├── 当前进度.md
│     ├── 人物状态表.md
│     ├── 时间线.md
│     ├── 伏笔清单.md
│     └── 细纲执行记录.md
│
├── 2. 检查连贯性
│     ├── 设定一致性：检查设定是否有矛盾
│     ├── 人物一致性：检查人物行为是否符合人设
│     ├── 时间线一致性：检查时间线是否合理
│     └── 伏笔追踪：检查伏笔埋设和回收
│
├── 3. 检查偏差
│     └── 对比细纲与正文，识别偏差类型
│
├── 4. 输出复盘报告
│     └── 见下方格式
│
└── 5. 提出建议
      └── 针对发现的问题提出修改建议
```

### 复盘报告结构

```markdown
【编辑】
━━━━━━━━━━━━━━━━━━━━━━━━━━━━
复盘报告 - 第X章

■ 复盘范围
  章节范围：第Y章 - 第X章
  复盘原因：定期复盘 / 条件触发：[具体条件]

■ 连贯性检查
  ✓ 设定一致性：无问题
  ⚠ 人物一致性：发现1处问题
  ✓ 时间线一致性：无问题
  ⚠ 伏笔追踪：发现2个伏笔待回收

■ 偏差检查
  灵活区调整：3处（已记录）
  主节点偏离：0处

■ 问题清单
  1. [问题描述]
     - 影响：[影响范围]
     - 建议：[修改建议]
  2. [问题描述]

■ 后续建议
  1. [建议内容]
  2. [建议内容]

请确认是否需要调整？
━━━━━━━━━━━━━━━━━━━━━━━━━━━━
```

## 复盘记录格式

### 存储位置

复盘记录存储在：`./小说创作/00-记忆/复盘记录.md`

### 记录格式

```markdown
# 复盘记录

## 复盘-01：第5章

**复盘时间**：[日期]
**复盘范围**：第1-5章
**复盘原因**：定期复盘

### 连贯性检查

| 检查项 | 状态 | 说明 |
|--------|------|------|
| 设定一致性 | ✓ | 无问题 |
| 人物一致性 | ⚠ | 配角A出场顺序有小矛盾 |
| 时间线一致性 | ✓ | 无问题 |
| 伏笔追踪 | ✓ | 1个伏笔待回收 |

### 偏差检查

| 章节 | 偏差类型 | 差异说明 | 处理方式 |
|------|---------|---------|---------|
| 第3章 | 灵活区调整 | 增加过渡情节 | 已记录 |

### 问题与建议

| 问题 | 影响 | 建议 | 状态 |
|------|------|------|------|
| 配角A出场矛盾 | 轻微 | 后续章节统一 | 待处理 |

---

```
