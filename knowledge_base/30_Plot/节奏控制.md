# 节奏控制系统

> 自动监控紧张度。节奏不再靠感觉，是可度量的数值。

---

## 紧张度模型

### 三幕式目标曲线

| 阶段 | 章节范围 | 紧张度走势 |
|------|---------|-----------|
| Act 1 | 第1-10章 | 从 0.3 起步，逐步攀升到 0.9，有起伏 |
| Act 2 | 第11-40章 | 渐进上升 + 多个峰值（15/25/35章为高峰） |
| Act 3 | 第41-50章 | 加速攀升至最终高潮 |

### 紧张度计算公式

```
紧张度 = 冲突强度 × 0.4 + 信息释放 × 0.3 + 对话密度 × 0.15 + 节奏速度 × 0.15
```

### 四维度分析

| 维度 | 低值表现 | 高值表现 |
|------|---------|---------|
| 冲突强度 | 平淡日常 | 生死对决 |
| 信息释放 | 无新信息 | 揭示真相 |
| 对话密度 | 大段描写 | 对话密集 |
| 节奏速度 | 长句铺陈 | 短句突刺 |

## 自动调节规则

### 紧张度偏低（gap < -0.2）

1. 增加冲突强度 — 让主角面临更紧迫的威胁
2. 加快信息释放 — 揭示关键线索
3. 减少铺垫段落 — 删减环境描写
4. 引入新的对抗力量

### 紧张度偏高（gap > 0.2）

1. 增加喘息空间
2. 加入情感描写
3. 插入回忆或反思
4. 降低冲突烈度

## 节拍结构库

| 类型 | 字数 | 节拍数 | 适用场景 |
|------|------|--------|---------|
| **基础七拍** | 1000-1200 | 7 | 短篇、快章节 |
| **八拍情绪隐喻** | 1000-1500 | 8 | 情感章 |
| **九拍双线** | 1200-1800 | 9 | 双线叙事 |
| **十拍多重反转** | 1500-2200 | 10 | 悬疑/高潮 |

### 基础七拍

1. 开场钩子（100字内抛出异常）
2. 设定递进
3. 初次错位
4. 加码证据
5. 主反转
6. 终点回击
7. 余味一击

### 十拍多重反转型

1. 开场钩子 → 2. 设定递进 → 3. 小反转① → 4. 加码证据 → 5. 小反转② → 6. 情节推进 → 7. 小反转③ → 8. 加码证据 → 9. 主反转 → 10. 余味一击

## 节奏历史追踪

每章记录：

| 章号 | 目标紧张度 | 实际紧张度 | 差距 | 处理 |
|------|-----------|-----------|------|------|
| 1 | 0.3 | 0.35 | +0.05 | 通过 |
| 2 | 0.4 | 0.38 | -0.02 | 通过 |
| 3 | 0.5 | 0.42 | -0.08 | 通过 |

## 章节内部节奏

| 章节位置 | 内容建议 |
| --- | --- |
| 开头 | 场景切入、悬念设置 |
| 前 1/3 | 推进剧情、铺垫冲突 |
| 中段 | 冲突升级、信息释放 |
| 后 1/3 | 小高潮或悬念收尾 |
| 结尾 | 留钩子、期待下章 |

### 篇幅控制

- 单章字数：2000-4000 字
- 小剧情单元：3-5 章
- 大剧情单元：10-20 章（一卷）

### 节奏调节技巧

```text
加速：短句、快节奏事件、多切换场景
减速：长描写、内心戏、对话展开
```

## 冲突升级

### 冲突层次

1. **个人层面**：主角的个人困境与成长
2. **人际层面**：与他人的矛盾与关系
3. **社会层面**：与社会规则/势力的对抗
4. **世界层面**：涉及世界存亡的重大危机

### 升级原则

- 后期敌人 > 前期敌人
- 新冲突在旧冲突解决前铺垫
- 避免冲突重复，每次升级要有新意

### 反派节奏

```text
小反派（3-5 章解决） → 中反派（一卷解决） → 大反派（全书主线）
```

### 冲突类型

| 类型 | 特点 | 示例 |
| --- | --- | --- |
| 生存冲突 | 生死存亡 | 被追杀、资源争夺 |
| 利益冲突 | 资源/地位 | 争夺宝物、职位竞争 |
| 情感冲突 | 爱/恨/恩/仇 | 情敌、复仇、报恩 |
| 理念冲突 | 价值观对立 | 正邪之争、道路之争 |

## 使用时机

- **创作前**：检查目标紧张度，确认本章需要的节奏
- **创作中**：参考节拍结构组织内容
- **创作后**：计算实际紧张度，对比差距，生成调节建议
