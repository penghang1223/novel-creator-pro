# 开场钩子与标题库（完整版·优化）

> 核心目标：
> **让AI和人都能稳定产出“有点击率的开头”**

---

# 一、开场钩子系统（生成版）

---

## 1.1 钩子底层公式（核心）

```id="hook_formula"
异常 + 日常场景 + 未解释信息
```

或

```id="hook_formula_2"
我以为X → 实际是Y
```

---

## 1.2 强钩子判断标准（必须满足2条以上）

* 有“异常”（不合理）
* 有“信息缺口”
* 有“反直觉”
* 有“即时画面”
* 有“隐含危险”

---

## 1.3 钩子强度分级（新增🔥）

| 等级 | 标准        |
| -- | --------- |
| S级 | 读完立刻想知道真相 |
| A级 | 有悬念但不致命   |
| B级 | 有信息但不刺激   |
| C级 | 普通句子      |

---

# 二、钩子模板库（可生成版）

👉 每个都可批量改写

---

## 2.1 都市异常（S级）

```id="urban_hook"
X发生了，但规则不允许
```

例：

* 门锁着，但钥匙在外面
* 电梯到了不存在的楼层
* 监控记录了不可能的行为

👉 扩展模板：

```id="urban_gen"
【日常物】 + 出现 + 【规则不允许的状态】
```

---

## 2.2 身份错位（强转化）

```id="identity_hook"
我 ≠ 我
```

例：

* 我看到自己的葬礼
* 有人说我已经死了
* 所有人认识我，我却不认识他们

---

## 2.3 时间异常（高留存）

```id="time_hook"
时间 ≠ 正常流动
```

例：

* 明天的信息提前出现
* 今天重复
* 时间停止/倒流

---

## 2.4 规则异常（强设定）

```id="rule_hook"
世界规则被修改
```

例：

* 新按钮出现
* 系统提示异常
* 规则被“提示”

---

## 2.5 记录异常（最稳）

```id="record_hook"
记录 ≠ 现实
```

例：

* 监控错位
* 聊天记录异常
* 订单异常

👉 特点：
**最容易出爆款（真实感强）**

---

## 2.6 陌生人提示（高效率）

```id="stranger_hook"
别人知道你不知道的事
```

例：

* “这栋楼没人住”
* “你不该在这”
* “你已经来过了”

---

## 2.7 AI/科技（黑镜）

```id="ai_hook"
系统比你更了解你
```

例：

* AI预测死亡
* 数据异常
* 身份被系统判定

---

## 2.8 恐怖直击（高刺激）

```id="horror_hook"
身体/空间被入侵
```

例：

* 床下有人
* 房间多了东西
* 有“另一个存在”

---

# 三、钩子生成器（核心🔥）

---

## 🧠 Prompt：开场钩子生成

```id="hook_prompt"
请生成10个开场钩子，要求：

1. 必须包含异常（违反常识）
2. 必须包含一个具体场景（电梯/房间/手机等）
3. 必须留下未解释信息
4. 每条不超过30字
5. 避免解释

风格：
- 都市怪谈 / 悬疑 / 黑镜任选

输出：
只输出钩子
```

---

## 🔥 强化版（爆款专用）

```id="hook_prompt_pro"
优化这些钩子，让它们：

- 冲突更强（×3）
- 信息更少（更神秘）
- 画面更清晰
- 更反直觉

目标：
让人必须继续看
```

---

# 四、标题系统（升级版）

---

## 4.1 标题核心公式

```id="title_formula"
日常物 + 异常 + 未完成信息
```

或

```id="title_formula_2"
我做了X，但发生了Y
```

---

## 4.2 高点击标题特征

* 有具体物（电梯/手机/门）
* 有异常（不存在/重复/错误）
* 有悬念（未解释）
* 不完整（留一口气）

---

## 4.3 标题模板库（优化版）

---

### ① 时间异常

```id="title_time"
《X发生在不该发生的时间》
```

例：

* 《明天发来的短信》
* 《重复的周三》

---

### ② 空间异常

```id="title_space"
《X出现在不存在的地方》
```

例：

* 《不存在的12层》
* 《多出来的房间》

---

### ③ 身份异常

```id="title_identity"
《另一个我》
```

例：

* 《我看到自己的葬礼》
* 《身份证不是我》

---

### ④ 记录异常（推荐🔥）

```id="title_record"
《X记录了不可能的事》
```

例：

* 《监控里的我》
* 《聊天记录的最后一句》

---

### ⑤ 规则异常

```id="title_rule"
《X规则被修改》
```

例：

* 《电梯多了一个按钮》
* 《门锁的提示》

---

### ⑥ 陌生人冲突

```id="title_stranger"
《他说了一句不该说的话》
```

---

# 五、标题生成器（直接用）

---

## 🧠 Prompt：标题生成

```id="title_prompt"
根据以下钩子，生成5个标题：

要求：
- 使用“日常物+异常+悬念”
- 不超过15字
- 不剧透
- 有点击欲望

输出：
5个标题
```

---

## 🔥 强化版

```id="title_opt"
优化标题：

- 提高点击率
- 增加冲突感
- 增加未知感
- 更口语化

目标：更像爆款短篇标题
```

---

# 六、钩子 + 标题匹配系统（关键🔥）

---

## 🎯 匹配原则

```id="match_rule"
标题 = 钩子的“信息外壳”
```

---

### 示例（优化）

#### 输入钩子：

> 电梯停在了12层——这栋楼只有11层

输出标题：

* 《不存在的12层》
* 《电梯停在了第12层》
* 《那天电梯多了一层》

---

# 七、爆款筛选机制（新增核心🔥）

---

## 7.1 钩子评分（10分制）

| 维度   | 分值  |
| ---- | --- |
| 异常强度 | 0-2 |
| 画面感  | 0-2 |
| 信息缺口 | 0-2 |
| 反直觉  | 0-2 |
| 情绪张力 | 0-2 |

---

### 判定

```id="hook_score"
≥8：爆款潜力  
6-7：可用  
≤5：废弃  
```

---

## 7.2 标题评分

* 是否有具体物
* 是否有异常
* 是否留悬念
* 是否短（≤15字）

---

# 八、组合生成流程（核心）

---

```id="full_pipeline"
生成钩子 → 评分 → 筛选 → 生成标题 → 优化 → 使用
```

---

# 九、快速使用方法（实战）

---

### 方法1：批量出爆款

```id="batch_method"
1. 生成20个钩子
2. 筛选Top5
3. 每个配3个标题
4. 选点击感最强的
```

---

### 方法2：只优化开头

```id="hook_only"
只重写第一句话，强化异常
```

---

### 方法3：钩子重写

```id="rewrite_hook"
把普通句改成“异常句”
```
