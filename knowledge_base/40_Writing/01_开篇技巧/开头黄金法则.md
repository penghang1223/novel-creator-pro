# 开头黄金法则——第1章必须做对的事

> 来源：网文写作实战技巧大全（2026版）by 望舒
> 适用：番茄/七猫等免费平台长篇网文

## 第1章5要素（字数分配表）

| 要素 | 字数范围 | 说明 | 示例 |
|------|---------|------|------|
| **一句话钩子** | 0-50字 | 开篇第一句抓人 | "我被未婚妻甩了那天，系统觉醒了" |
| **主角身份** | 50-300字 | 通过行动展现，非简历 | 不要"我叫XX，今年X岁" |
| **核心冲突** | 300-1000字 | 抛出核心矛盾 | 被甩/被欺/被背叛 |
| **金手指/转折** | 1000-2000字 | 出现转机 | 系统觉醒/身份reveal |
| **章末悬念** | 最后1句 | 让读者点下一章 | "就在这时，门被推开了..." |

## 开头10大禁忌

| 禁忌 | 后果 | 正确做法 |
|------|------|---------|
| 大段世界观介绍 | 读者秒退 | 通过剧情逐步展现 |
| 主角回忆童年 | 无聊弃文 | 只写当下冲突 |
| 环境描写超3句 | 拖沓 | 1-2句带过即可 |
| 多角色同时出场 | 混乱 | 先聚焦主角，再引入他人 |
| 慢热铺垫 | 3章内无爽点=流失 | 第1章必须有冲突 |
| 文青式叙事 | 番茄读者不买单 | 直白+爽感 |
| 设定堆砌 | 信息过载 | 边写边揭露设定 |
| 对话开场无冲突 | 平淡 | 对话必须带冲突 |
| 第三人称全知视角 | 代入感弱 | 用第一人称或限知第三人称 |
| 章末平淡断章 | 读者不点下一章 | 卡在悬念/冲突处 |

## 爆款开头模板（直接套用）

### 模板A：被甩/被欺+金手指觉醒（男频最常用）

```
第1段：我被XX甩了/打了/羞辱了（冲突）
第2段：周围人嘲笑/落井下石（加深冲突）
第3段：就在这时，XX觉醒了/出现了（转折）
第4段：我获得了XX能力/身份（金手指）
第5段：我冷笑/起身，准备打脸（期待感）
第6段：就在这时，门被推开了...（悬念断章）
```

### 模板B：重生/穿越+改变命运（女频最常用）

```
第1段：我死了/被背叛了（悲惨结局）
第2段：睁开眼，回到XX年前（重生）
第3段：这一次，我绝不再XX（决心）
第4段：我做的第一件事是XX（行动）
第5段：没想到，遇到了XX（意外）
第6段：他看着我，说了一句让我震惊的话...（悬念）
```

### 模板C：系统/空间+逆袭（通用）

```
第1段：我穷/被欺/走投无路（困境）
第2段：突然听到"叮"的一声（系统提示）
第3段：眼前出现XX面板（金手指展现）
第4段：我试探性做了XX，成功了（验证能力）
第5段：我笑了，知道人生要改变了（期待）
第6段：这时，XX找上门来...（新冲突/悬念）
```
