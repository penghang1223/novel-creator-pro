# 每章节奏公式

> 来源：网文写作实战技巧大全（2026版）by 望舒
> 适用：番茄/七猫等免费平台长篇网文

## 单章节奏模板（3000字/章）

| 段落 | 字数 | 占比 | 功能 |
|------|------|------|------|
| **开头承接** | 300字 | 10% | 承接上章悬念 / 引出新冲突 |
| **发展推进** | 1500字 | 50% | 推进剧情，埋下伏笔 |
| **章节高潮** | 1000字 | 33% | 本章节点 / 小爽点 / 反转 |
| **结尾断章** | 200字 | 7% | 新悬念 / 卡章，引导点下一章 |

## 核心原则

1. **开头300字必须有冲突** — 不能用环境描写或日常开场
2. **每章至少一个情绪高潮点** — 虐→爽循环
3. **章末必须卡在悬念/冲突处** — 平淡断章=读者弃文
4. **爽:压 = 7:3** — 不能一直爽，也不能一直压抑

## 无效断章（绝对不能犯）

- ❌ 日常描写后断章（"第二天他起床刷牙"）
- ❌ 大段设定后断章
- ❌ 平淡对话后断章
- ❌ 环境描写后断章
- ❌ 主角心理活动后断章（无新信息）

## 有效断章位置

| 位置 | 效果 |
|------|------|
| 悬念最高处 | "门开了，里面竟然是——" |
| 打脸前一刻 | "他冷笑一声，说出了那个名字..." |
| 新冲突出现 | "就在这时，手机响了..." |
| 情感高潮 | "她终于说出了那句..." |
| 身份reveal前 | "他摘下面具，露出一张熟悉的脸..." |

## 卡章公式

```
冲突升级（本章）→ 高潮前一刻（断章）→ 下一章释放
```

### 示例

```
第10章结尾：
"他举起了刀，对准了我的胸口。
我闭上眼，听到了刀锋破空的声音。
然后——"

第11章开头：
"刀停在了半空。
一只手抓住了他的手腕。
我睁开眼，看到了那个我以为已经死了的人。"
```

## 节奏禁忌

| 错误 | 后果 | 正确做法 |
|------|------|----------|
| 连续3章无爽点 | 读者流失 | 至少3章1爽点 |
| 连续5章纯对话 | 枯燥 | 加入动作/心理/环境 |
| 大段设定说明 | 弃文 | 边剧情边揭露 |
| 多线并行超3条 | 混乱 | 聚焦1-2条主线 |
| 高潮后无余韵 | 疲劳 | 高潮后给1章缓冲 |
