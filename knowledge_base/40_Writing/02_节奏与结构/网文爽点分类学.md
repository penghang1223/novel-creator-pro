# 网文爽点分类学

> 统一分类所有主要爽点类型，写作时按章节定位该用哪种爽点。

---

## 爽点的本质

爽点 = **读者代入主角后获得的心理满足**。不是"事情变好了"，而是"读者觉得主角该得到的终于得到了"。

核心公式：**压抑 → 释放 = 爽**。没有前面的压抑，后面的释放就不爽。

---

## 八大爽点类型

### 1. 打脸爽

**机制**：被看不起 → 证明自己 → 对方震惊
**压抑来源**：被轻视、被羞辱、被否定
**释放方式**：展示真实实力/身份/财富/能力，对方变脸

**典型场景**：
- 同学会被嘲笑穷 → 露出真实身份
- 被前同事看不起 → 业务碾压
- 被势利亲戚嘲讽 → 送礼打脸

**节奏要求**：压抑至少持续1-2章，打脸1章内完成。压抑越长越爽，但不能超过3章（读者耐心耗尽）。

**本项目示例**：赵天宇在同学会羞辱林辰（Ch18-19压抑），林辰投资回报打脸（Ch20释放）。

### 2. 逆袭爽

**机制**：从低谷 → 攀升 → 超越过去的自己/对手
**压抑来源**：被裁员、被分手、被骗、破产
**释放方式**：东山再起，比以前更强

**与打脸的区别**：打脸针对特定对手，逆袭针对自身处境。

**节奏要求**：长线爽点，每5-10章一个小逆袭，每卷一个大逆袭。

### 3. 种田爽

**机制**：从零建设 → 看到成果 → 扩大规模
**压抑来源**：资源匮乏、白手起家
**释放方式**：一步步积累，看到建设成果

**典型场景**：
- 开店从亏损到盈利
- 建厂从小作坊到大企业
- 收徒弟从一个到一群

**节奏要求**：慢性爽点，每次建设有具体数字（从1到10到100）。

### 4. 系统爽

**机制**：获得能力 → 使用能力 → 看到效果 → 升级
**压抑来源**：之前没有能力，被现实压制
**释放方式**：系统给能力→用能力解决问题→升级给更强能力

**核心循环**：获得→使用→验证→升级→获得更强
**节奏要求**：每3-5章必须有一次系统相关事件（获得/使用/升级）。

**本项目示例**：透视之眼Lv1→发现被低估股票→赚到钱→Lv2解锁→更多能力。

### 5. 成长爽

**机制**：弱者 → 变强 → 更强
**压抑来源**：实力不足、被人碾压
**释放方式**：实力提升后的碾压

**与逆袭的区别**：逆袭是回到正常水平，成长是超越正常水平。

### 6. 团宠/偏爱爽

**机制**：被某个有实力的人偏爱/保护/认可
**压抑来源**：孤独、不被理解、被排挤
**释放方式**：有大佬/家人/爱人无条件站你这边

**典型场景**：
- 被欺负时大佬出面
- 被全世界否定时有一个人相信你
- 女儿/家人的无条件信任

**本项目示例**：朵朵的"爸爸是全世界最厉害的人"。

### 7. 虐渣爽

**机制**：反派作恶 → 主角反击 → 反派惨败
**压抑来源**：反派的恶行（欺骗、背叛、陷害）
**释放方式**：让反派付出代价

**节奏要求**：反派必须先"活蹦乱跳"至少3-5章，读者恨够了再收拾。

### 8. 暴富爽

**机制**：穷 → 赚钱 → 花钱 → 看到效果
**压抑来源**：缺钱的痛苦（交不起学费、付不起房租）
**释放方式**：赚钱后改变生活的具体细节

**关键**：不能只写"赚了100万"，要写**钱花出去的效果**（交学费、还房贷、买东西、给家人改善生活）。

**本项目示例**：Ch10赚到25万→还信用卡、交房租、给朵朵转2万学费。

## 爽点密度参考

| 爽点类型 | 最小间隔 | 一章内可叠加 |
|----------|----------|-------------|
| 打脸 | 5-10章 | 不可叠加（一场打脸一章） |
| 逆袭 | 5-10章 | 可叠加系统爽 |
| 种田 | 每章可有 | 可叠加暴富 |
| 系统 | 3-5章 | 可叠加任何类型 |
| 成长 | 3-5章 | 可叠加打脸 |
| 团宠 | 5-10章 | 可叠加虐渣 |
| 虐渣 | 10-20章 | 可叠加打脸 |
| 暴富 | 5-10章 | 可叠加种田 |

**番茄节奏**：每3章至少1个小爽点，每10章1个中爽点，每卷1个大爽点。
