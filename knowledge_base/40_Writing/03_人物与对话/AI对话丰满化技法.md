# AI对话丰满化核心技法

> 来源：惊鸿 workspace-jinghong/skills | 整合时间：2026-04-28

---

## 核心认知

**AI 的默认设置是"礼貌、逻辑通顺、有问必答"——这恰恰是张力的天敌。**

**好对话要"不说人话"（不说完整、直白的话），学会"顾左右而言他"。**

---

## 一、万能公式

```
对话 + 细微动作/神态 + 环境感官 + 心理活动
```

**练习：**
- 练习前："我不想去。"
- 练习后："我不想去。"她缩回伸向门把手的手，指尖冰凉。她想起上次在那里的遭遇，胃里一阵翻江倒海。

---

## 二、五大技法

### 1. 动作锚点代替"他说/她问"

干涩写法：大量"他说""她问"
润色写法：用具体、带有情绪色彩的动作作为对话归属

```
干涩：张三说"你迟到了"。李四说"路上堵车"。
润色：张三抬起手腕看了看表，眉头锁成一个"川"字："你迟到了。"
李四一边喘着粗气，一边把被汗水浸湿的公文包扔在沙发上："路上堵车。"
```

### 2. 拒绝有问必答——潜台词

干涩写法：问什么答什么，直来直去
润色写法：回避/沉默/转移话题/言行不一

```
干涩："你爱我吗？""我爱你。"
润色："你爱我吗？"她盯着他的眼睛，手指无意识地绞着衣角。
他避开了她的视线，伸手去点了一支烟，手有些抖："……别问这种傻话。"
```

### 3. 环境烘托气氛

干涩写法：对话发生在真空里
润色写法：环境描写打断对话，调节节奏，暗示心理

```
干涩："我们要分开了。""为什么？""因为我们要去不同的城市。"
润色：窗外的雨噼里啪啦地打在玻璃上。
"我们要分开了。"她看着窗外模糊的霓虹灯，声音很轻。
"为什么？"他握着咖啡杯的手停在半空，杯子里的热气已经散尽了。
```

### 4. 制造冲突和打断

干涩写法：对话完整流畅
润色写法：抢话/打断/吞吞吐吐

```
干涩："我想告诉你一件事。""什么事？"
润色："我想告诉你——""如果是关于那个工作的事，就别说了。""你怎么知道？"
"因为我也收到了拒信。"他把手机屏幕转过来，重重地磕在桌子上。
```

### 5. 三种对话张力模式

#### 冰山理论（暧昧/冷战）
> 嘴上在讨论"今晚吃什么"，实际在讨论"我们要不要离婚"。通过环境压抑（风扇噪音/窗外雨声）和微小动作（手指敲桌面）体现未说出口的痛苦。

#### 权力博弈（审讯/谈判）
> 上位者漫不经心，做别的事（修剪花草），对下位者的话爱答不理。下位者急于辩解，语速快，句子破碎。用对话长短体现压迫感。

#### 暴力前夜（争吵爆发前夕）
> 充满讽刺和带刺的幽默。角色 A 不断逼近物理距离（把脸凑过去），角色 B 不断后退或僵硬。对话简短有力，像打乒乓球一样快速来回。

## 三、负面约束（告诉AI绝对不要做什么）

```
禁止：写"他感到很愤怒"或"她觉得很紧张"——必须通过动作表现
禁止：使用"你好""请问""谢谢"等礼貌用语——除非是虚伪的客套
禁止：让角色完整回答对方的问题——必须答非所问或直接无视
禁止：使用"他说""她问道"作为对话标签
```

---

## 四、对话占比定义

**"对话 + 说话时的动作/神态/归属"视为一个整体**，统称为"对话场景"。

- 纯对话（引号内）：骨架
- 归属与修饰（引号外）：血肉

**只要读者读起来感觉是两个人在互动，那就算对话；如果感觉是作者在解说，那就算叙述。**

---

## 五、对话辨识度要求

每个角色的说话方式必须独一无二，**去掉名字也能分辨谁在说**。

常见区分维度：
- 短句 vs 长句
- 有无语气词（"那个""呃"）
- 语速快慢
- 有无肢体动作伴随
- 是否完整回答问题
