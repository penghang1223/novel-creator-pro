# AI短句病治疗方案

> 来源：惊鸿分享 | 整合时间：2026-04-28
> 问题：AI生成大量短句和碎片化对话（"电报风"/"机器人味"）

---

## 核心认知

**AI在"传递信息"，而不是在"构建场景"。**

AI倾向于生成最安全、概率最高的"主谓宾"结构，忽略人类语言的韵律感、潜台词和环境氛围。

**解决核心：强迫AI慢下来。**

---

## 一、提示词优化（根本解决）

### 1. 设定具体文风标签

```
你现在是一位擅长描写细腻情感的资深小说家。
你的写作风格偏向沉浸式和文学性。
请避免使用短句和简单的问答，
多使用长短句结合的复句，
注重环境描写与人物心理活动的交织。
```

### 2. 强制"动作+语言+神态"混合模式

```
在对话中，请遵循"动作+语言+神态"的混合描写模式。
不要只写"他说""她问"。
请描写人物说话时的微表情、肢体动作，
以及周围环境的细微变化。
人物对话要有潜台词，不要直来直去。
```

### 3. 少样本提示（最有效）

给AI一段理想范文，让它模仿节奏：

```
请模仿以下段落的节奏进行续写：
[粘贴一段描写细腻、句式优美的文字]
注意观察其中的长句运用和感官描写。
```

---

## 二、后期润色技巧

### 1. "三明治"描写法

**在两句对话之间，强行插入环境或动作描写。**

❌ AI原版（短句多）：
> "你来了。"
> "是的，我来了。"
> "外面下雨了吗？"
> "下了很大。"

✅ 修改后：
> 他听到门轴转动的吱呀声，并没有回头，只是盯着杯中晃动的茶水低声说道："你来了。"
>
> 身后的脚步声停滞了片刻，带着一丝湿冷的寒气，那个声音才迟疑地响起："是的，我来了。"
>
> 他终于转过身，目光扫过对方肩头深色的水渍，眉头微蹙："外面下雨了吗？"
>
> "下了很大，"她一边收伞，一边用力跺了跺脚上的泥水，声音里透着疲惫，"整个城市都被淹没了。"

### 2. 合并句子 + 使用连接词

AI喜欢用句号。人类用逗号、分号和关联词（虽然/但是/鉴于/仿佛）来拉长句子。

**指令**：
```
请重写这段话，尽量减少句号的使用，
多用逗号连接从句，增加句子的流动性和复杂感。
```

### 3. 增加感官细节

短句是因为缺乏细节。要求AI加入视觉、听觉、嗅觉。

**指令**：
```
重写这段对话，在对话中融入对光线、气味和背景噪音的描写，
使场景更具真实感。
```

## 三、分步生成（进阶策略）

不要让AI一次性写完整个场景。分步引导控制节奏：

1. **第一步（大纲）**：写出对话的核心逻辑和冲突点
2. **第二步（扩写）**：选中一段对话，要求扩写成500字，重点描写心理博弈和眼神交流
3. **第三步（润色）**：使用专门的润色指令

### 润色专用提示词模板

```
请对以下文本进行深度润色：

1. 句式变换：将连续的短句合并为长短结合的复句，增加语言的韵律感。
2. 去机械化：删除"他说/她问"等简单的对话标签，改为通过动作和神态来引出对话。
3. 增加沉浸感：在对话间隙填充环境描写（光影、声音、温度），营造氛围。
4. 潜台词：修改对话内容，使其更含蓄，不要让人物把心里话全说出来。

待修改文本：
[粘贴你的文本]
```

---

## 四、核心心法

**强迫AI在两句对话之间填充内容，从而打破"你一句我一句"的乒乓节奏。**

对话间隙可以填充：
- 动作（微表情、肢体）
- 环境（光线、温度、声音、气味）
- 心理（闪念、回忆）
- 感官（触觉、嗅觉）

这些"填充物"越多，场景越真实，AI味越淡。
