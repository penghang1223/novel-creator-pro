# 乒乓球式短句病治疗方案

> 来源：惊鸿分享 | 整合时间：2026-04-28
> 问题：AI把写小说当成了写剧本，对话像乒乓球（你一句我一句），缺乏描写

---

## 核心认知

**AI把写小说当成了写剧本，或者是为了快速推进剧情而忽略了氛围感。**

解决核心：**强迫AI关注"对话之外的世界"**——动作、神态、环境、心理活动。

---

## 一、提示词优化

### 1. 强制加入"动作"与"神态"

❌ 弱指令：
> "写一段两人争吵的对话。"

✅ 强指令：
```
写一段两人争吵的对话。要求：
- 禁止连续使用短句对话。
- 每两句对话之间，必须插入人物的微表情、肢体动作或环境描写。
- 描写要体现出压抑和紧张的氛围，而不是直接说"他很生气"。
- 模仿传统文学的写法，增加画面的颗粒度。
```

### 2. "展示而非讲述"原则

告诉AI关注潜台词——不要让角色直接说出心里想什么，通过顾左右而言他、摆弄物品、眼神躲闪来表达情绪。

```
不要让他们直接说出心里想什么。
让他们通过顾左右而言他、摆弄手中的物品、眼神的躲闪来表达情绪。
把对话拉长，增加心理活动的描写。
```

### 3. 温度参数调整

- Temperature稍微调高（0.7 → 0.8）可增加用词丰富度和句式变化
- 或直接要求："请使用长短句结合的句式，增加描写的细腻度，避免流水账。"

## 二、实战对比

### ❌ 问题案例（乒乓球式对话）

```
"你来了。"
"我来了。"
"东西带了吗？"
"带了。"
"给我。"
"不行。"
"为什么？"
"因为我不信你。"
```

评价：干瘪，像电报，毫无画面感。

### ✅ 修正方案

**场景**：下雨的破旧仓库，A紧张攥包，B冷漠靠墙抽烟

```
雨水顺着仓库顶棚的破洞滴落，砸在满是灰尘的水泥地上，发出沉闷的声响。

"你来了。"B靠在斑驳的红砖墙上，指尖的烟头忽明忽暗，他甚至没有抬头看一眼。

我推门而入，冷风夹杂着湿气扑面而来。我下意识地缩了缩脖子，手心里全是汗，紧紧攥着那个黑色的帆布包，指节因为用力而发白。"我来了。"我回答道，声音比预想的要沙哑。

B终于抬起头，吐出一口烟圈，烟雾在昏黄的灯泡下缭绕。"东西带了吗？"他的眼神像鹰一样锐利，直刺向我。

我吞了口唾沫，没有立刻上前，而是警惕地扫视了一圈四周空荡荡的货架。"带了。"

"给我。"他伸出手，掌心向上，姿势随意却透着不容拒绝的强硬。

我后退了半步，脚后跟碰到了地上的碎石子，发出刺耳的摩擦声。"不行。"

B弹了弹烟灰，嘴角勾起一抹冷笑，慢慢站直了身体，压迫感瞬间笼罩了整个空间。"为什么？"

"因为我不信你。"我盯着他的眼睛，尽管双腿在打颤，但我知道此刻绝不能移开视线。
```

## 三、少样本提示（效果最稳定）

给AI一段理想范文让它模仿，比任何指令都有效：

```
请模仿以下段落的风格进行描写（注意其中的动作穿插和长短句节奏）：

"林黛玉听了，不觉带泪冷笑，道：'你倒来替人派我的不是。我怎么就是小性儿了？……'说着，便拿起帕子来擦泪。宝玉见她这般，心中也不由得软了，忙陪笑道：'好妹妹，原是我多嘴，你千万别往心里去。'一面说，一面便去拉她的手。"
```
