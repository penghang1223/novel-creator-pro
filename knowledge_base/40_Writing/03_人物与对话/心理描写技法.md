# 心理描写技法

> 解决问题：内心独白写得假、情绪描写只会"他感到……"、角色内心世界不立体。

---

## 核心原则：行为替代情绪

**不要写角色"感到"什么，要写角色"做了"什么。**

```
❌ 他感到很紧张。
✅ 他攥紧了手机，指关节发白。

❌ 她心里很难受。
✅ 她把头转过去，盯着窗外，没说话。
```

"感到/觉得/心里" 出现频率要控制。偶尔用可以，不能成为默认写法。

---

## 五种心理描写手法

### 1. 行为外化

内心状态通过**小动作**表现：

| 内心状态 | 行为外化 |
|----------|----------|
| 紧张 | 摸手机/攥拳/舔嘴唇/深呼吸 |
| 愤怒 | 沉默/语速变慢/摔东西/冷笑 |
| 心虚 | 不看对方眼睛/清嗓子/转移话题 |
| 悲伤 | 不说话/吃不下东西/反复看一个地方 |
| 开心 | 主动找人说话/做事有劲/哼歌 |
| 绝望 | 麻木/机械地做例行的事/不修边幅 |

### 2. 内心独白（简化版）

不用"他想："开头，直接写想法，用**不完整句**：

```
❌ 他想：我真是太没用了，连女儿的学费都交不起。
✅ 十年。十年就值八万块。
✅ 三万二。交了学费就剩六千。六千能撑多久？一个月？两个月？
```

**关键**：内心独白要像**碎碎念**，不是完整论述。断句、省略、重复、自问自答。

### 3. 感官聚焦

角色焦虑/紧张时，注意力会**聚焦在某个小细节**上：

```
他盯着合同上的签字栏。那根黑色签字笔不知道是谁放的，笔帽上有一道
牙印——有人紧张的时候会咬笔帽。
```

**技巧**：用一个感官细节暗示角色的心理投射。

### 4. 环境投射

内心状态影响角色对环境的感知：

```
开心时：阳光从窗帘缝里挤进来，暖洋洋的。
绝望时：阳光从窗帘缝里挤进来，刺眼。
```

**同样的环境，不同心情读出不同味道。**

### 5. 身体感觉

不写"情绪词"，写身体的**物理反应**：

```
❌ 他非常愤怒。
✅ 血往脑门上涌，耳朵嗡嗡的。

❌ 她很害怕。
✅ 后背的汗把衣服贴在了皮肤上，凉飕飕的。
```

## 不同情绪的写法模板

### 压抑/屈辱

```
行为：沉默、机械动作、不反抗
内心：反复想同一句话/一个画面
身体：呼吸变浅、肩膀下沉
环境：外部噪音反而显得更安静
```

### 焦虑/不安

```
行为：反复检查手机、坐不住、做事没耐心
内心：假设最坏情况、自我否定
身体：手心出汗、胃不舒服
环境：时间过得特别慢
```

### 温暖/感动

```
行为：动作变轻、声音变小、不自觉微笑
内心：想起过去的某个画面
身体：眼眶发热、鼻子酸
环境：注意到平时忽略的美好细节
```

### 决绝/坚定

```
行为：动作变利落、不再犹豫
内心：只有一个念头，反复确认
身体：呼吸变深、站直
环境：外部干扰变安静（心理过滤）
```

## 心理描写禁忌

| 禁忌 | 原因 | 替代 |
|------|------|------|
| "心中暗自思忖" | AI味极重 | "他想"或直接写想法 |
| "一股暖流涌上心头" | 陈词滥调 | 写身体反应（眼眶热） |
| "内心翻江倒海" | 空洞 | 写具体想到了什么 |
| "百感交集" | 四字成语偷懒 | 分别写哪几种感觉 |
| "他不知道该说什么" | 说明文式 | 让他真的沉默 |
