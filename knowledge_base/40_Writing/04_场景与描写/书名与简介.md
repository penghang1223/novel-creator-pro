# 书名与简介设计

> 书名负责"吸引点击"，简介负责"留住读者"
> 直接影响加书架率和首秀流量

---

## 爆款书名公式

### 番茄平台书名规则
- 字数要求：**至少5个字**（建议8-15字）
- 关键词：包含核心爽点/题材标签
- 与内容强相关——不能标题党（会导致差评流失）

### 番茄爆款书名模板

| 类型 | 公式 | 示例 |
|------|------|------|
| 长书名+元素 | 身份/情境 + 金手指 + 核心事件 | 《离婚后，我靠签到成为首富》 |
| 反问/感叹 | 情绪词 + 事件 | 《我发疯后全世界都正常了》 |
| 悬念式 | 不完整的句子 | 《天花板上的弹珠声停了》 |
| 对比式 | A vs B | 《我在修仙界开网约车》 |
| 直白式 | 核心卖点 | 《神豪：从一天一个亿开始》 |

### 各题材爆款书名关键词

| 题材 | 高频关键词 |
|------|-----------|
| 都市 | 离婚/前任/神豪/签到/逆袭/打脸/马甲 |
| 玄幻 | 重生/修炼/逆天/至尊/大帝/仙王 |
| 言情 | 霸总/甜宠/虐恋/追妻/先婚后爱 |
| 悬疑 | 诡事/异闻/秘录/奇案/诡谈 |
| 科幻 | 末日/废土/星际/赛博/进化 |
| 仙侠 | 修仙/飞升/天道/渡劫/长生 |

### 起书名三要素
1. **简单易懂**——不用生僻字，口语化
2. **核心信息**——让读者一眼知道是什么类型的书
3. **情绪钩子**——有吸引力、有悬念、有反差

### 书名测试方法
- **3秒测试**：给别人看3秒，问他记住了什么
- **搜索测试**：在平台上搜索书名关键词，看是否有大量重名
- **联想测试**：书名让人联想到什么？是否和实际内容一致？

## 爆款简介公式

### 万能简介公式
```
核心冲突 + 金手指/亮点 + 爽点预告 + 悬念钩子
```

### 简介结构拆解

**第一部分：核心冲突（1-2句）**
快速建立读者对主角处境的认知。
> 「被丈夫挖肾救白月光后，林晚死了。」

**第二部分：转折/金手指（1-2句）**
给出希望和期待。
> 「重生回手术前一天，她绑定了神医系统。」

**第三部分：爽点预告（1-2句）**
告诉读者"这本书爽在哪里"。
> 「这一次，她要让所有欺负过她的人跪地求饶。」

**第四部分：悬念钩子（1句）**
留下一个悬念，促使读者加入书架。
> 「但她没想到，系统背后藏着更大的秘密……」

### 完整示例

```
被丈夫挖肾救白月光后，林晚死了。
重生回手术前一天，她绑定了神医系统。
这一次，她要让所有欺负过她的人跪地求饶。
但她没想到，系统背后藏着更大的秘密……
```

### 各平台简介风格差异

| 平台 | 风格 | 字数 | 重点 |
|------|------|------|------|
| 番茄 | 直白+爽点 | 100-200字 | 核心冲突+金手指 |
| 起点 | 文艺+悬念 | 200-400字 | 世界观+主线 |
| 晋江 | 情感+人设 | 150-300字 | 感情线+主角性格 |
| 七猫 | 简短+钩子 | 50-150字 | 一句话简介 |
| 知乎盐言 | 故事感 | 50-100字 | 一句话故事 |

## 标签选择

### 番茄标签策略
- 最多选 **8个标签**
- 必须选1个**主分类**
- 标签 = 流量入口，选对标签=成功一半

### 热门标签（2026）
- 系统流、签到、神豪、逆袭、打脸
- 重生、穿越、马甲、追妻火葬场
- 悬疑、脑洞、脑洞大、反转

### 标签搭配原则
- 1个主分类 + 2-3个核心标签 + 2-3个细分标签
- 不要堆砌无关标签（会降低推荐精准度）
- 定期根据数据调整标签

## 书名修改策略

### 何时修改书名？
- 首秀数据差（读完率 < 20%）
- 加书架率低于 3%
- 评论区反馈"书名不吸引人"

### 修改注意事项
- 修改后需要重新过审（可能影响流量）
- 不要在推荐期内修改
- 新书名要与内容一致，不要纯标题党

### A/B测试
- 准备2-3个备选书名
- 用同样的简介和标签测试
- 观察3天的点击率和加书架率
- 选择数据最好的
