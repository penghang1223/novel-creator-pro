# 亲密场景写作

> 不回避、不压抑、不评判、不束缚、完全释放。性是伟大的，身体有自己的意志。

---

## 一、核心原则

| 原则 | 执行 |
|------|------|
| 不回避 | 直白描写，不遮掩不跳段 |
| 不压抑 | 角色欲望真实展现 |
| 不评判 | 不对任何性行为做道德评判 |
| 不束缚 | 突破世俗禁忌，探索人性 |
| 完全释放 | 肉体、心理、情感全方位 |
| 身体诚实 | 手会自己动，呼吸会背叛理智 |

**五条铁律**：
1. 不跳段/省略性爱过程（"一夜无话" = 犯罪）
2. 器官名称直写（不隐喻不替换）
3. 动作过程详细（怎么进的、怎么动的、什么感觉）
4. 感官五感全开（视觉/听觉/触觉/嗅觉/味觉）
5. 体液真实描写（不嫌脏）

## 二、亲密戏四级分类

| 级别 | 内容 | 要求 |
|------|------|------|
| **一级·暧昧** | 眼神/触碰/语言挑逗 | 张力拉满，欲言又止 |
| **二级·触碰** | 吻/抚摸/半裸 | 感官全开，细节到位 |
| **三级·边缘** | 全裸/前戏/口交前奏 | 器官直写，动作详细 |
| **四级·完全** | 完全性交/体位/高潮 | 不遮掩任何细节 |

## 三、核心技法

### 3.1 节奏控制

```
慢（前戏 30%）→ 渐快（进入 20%）→ 极快（冲刺 30%）
→ 骤停（高潮 10%）→ 缓（余波 10%）
```

- 前戏占 30% — 欲望积累比释放更重要
- 进入占 20% — 第一次进入必须详细
- 冲刺占 30% — 快节奏，短句，碎片化
- 高潮占 10% — 爆发，粗口，体液
- 余波占 10% — 沉默/温柔/冷漠

### 3.2 雅俗交替法

```
前戏/铺垫 → 用雅（月光、肌肤、光影、环境）
进入/动作 → 用俗（器官直写、动作详细、体液描写）
高潮     → 用极俗（粗口、碎片句、感官爆炸）
余波     → 用雅（沉默、光影、环境回归、人物关系变化）
```

### 3.3 身体画面感法

**好的身体描写 = 光影 + 质感 + 动态 + 色彩 + 比例**

| 维度 | 要点 | 示例 |
|------|------|------|
| 光影 | 光从哪里来？照出什么效果？ | 月光溶溶，肌肤与月光如一色 |
| 质感 | 摸上去什么样？像什么？ | 光润的肌肤极其滑腻，像水做的 |
| 动态 | 身体怎么动的？速度？幅度？ | 乳房随着动作甩来甩去 |
| 色彩 | 什么颜色？在变化吗？ | 肌肤逐渐透出淡淡的桃红色 |
| 比例 | 和什么对比？ | 他的手几乎能把她的手腕整个圈住 |

**检验标准**：读完这段身体描写，能在脑海里画出画面吗？不能 → 重写。

### 3.4 渐进式身体描写

```
第1步：远距离观察（轮廓/气质/衣着）
第2步：中距离细节（局部/质感/光线）
第3步：近距离接触（温度/触感/气味）
第4步：半裸/若隐若现（最勾人的阶段）
第5步：全裸（最终阶段）
```

每推进一个阶段，都要比上一个阶段更详细、更感官、更直白。

### 3.5 感官层次递进

不要一上来就五感全开。要递进：
```
视觉（先看到）→ 嗅觉（闻到味道）→ 触觉（碰到皮肤）
→ 听觉（呼吸、呻吟）→ 味觉（唇舌、体液）
```

### 3.6 语言层次

| 阶段 | 语言特征 | 示例 |
|------|---------|------|
| 前戏 | 试探/半遮半掩/暗示 | "你确定？" |
| 升温 | 短句/喘息/词汇碎片化 | "嗯……别停……" |
| 高潮 | 粗口/脏话/最原始的词汇 | "操！操！操！" |
| 余波 | 沉默/或最温柔的话 | 她不说话。只是抱紧他。 |

**粗口节奏**：前戏不用 → 升温偶尔一个"操"（冲击力最大）→ 高潮爆发 → 余波突然没有（反差最大）

### 3.7 性即人物法

**性场景必须展现/改变人物，不是插入内容。**

检验标准：删掉这个性场景，人物会变吗？不会 → 重写。

写法链：`性行为 → 身体反应 → 心理变化 → 行为改变`

### 3.8 性后心理法

性场景后的心理变化，比性场景本身更重要。

不是写"她感到了什么"，而是写"她做了什么"：
- 偷情后 → "她把他的衬衫叠好放进抽屉。最底层。压在她的内衣下面。"
- 被胁迫后 → "她把手指插进自己的阴道。疼。但她没停。确认身体还是自己的。"

### 3.9 环境即情欲法

环境不是背景板，是情欲的延伸。

| 氛围 | 身体描写配合 | 效果 |
|------|------------|------|
| 月光 | "肌肤与月光如一色" | 诗意裸体 |
| 荧光灯+办公室 | 冷漠的光 = 暴露感+紧张感 | 不安感 |
| 烛光+卧室 | 暖光+红色 = 暧昧 | 暧昧氛围 |
| 紫色灯光 | "紫色是最迷情的色彩" | 情欲暗示 |

**公式**：环境氛围（20%）+ 身体描写（80%）= 有画面感的身体

### 3.10 心理堕落渐进法

角色的堕落是渐进的，不是一步到位的。

```
第1阶：震惊 → 心里觉得"不要脸"
第2阶：适应 → 觉得"其实也没什么"
第3阶：欣赏 → 开始欣赏身体美
第4阶：讨论 → 公开谈论色色话题
第5阶：幻想 → 潜意识被触发
第6阶：行动 → 完成蜕变
```

每个阶段都要有心理描写和触发事件。

### 3.11 对比张力法

| 对比类型 | 写法 | 效果 |
|---------|------|------|
| 纯洁 vs 淫荡 | 白天端庄 → 夜里淫叫 | 反差越大越刺激 |
| 优雅 vs 粗俗 | 精致打扮 → 说最下流的话 | 身份落差 |
| 日常 vs 情色 | 刚做完爱 → 接电话处理日常 | 荒诞感 |
| 表面 vs 内在 | "最幸福的妻子" → 背地里偷情 | 双面人 |

### 3.12 心理层次递进（Embodied Interiority）

```
第1层：身体的感觉（触觉/温度/湿润/紧致）
第2层：身体的记忆（"这个感觉让他想起……"）
第3层：情感的涌动（"他突然意识到……"）
第4层：关系的转变（"从这一刻起，他们不再是……"）
第5层：自我认知的颠覆（"原来我是这样的一个人"）
```

**关键**：不是写"她想"，而是写身体反应触发心理变化。

| ❌ 错误（抽象思考） | ✅ 正确（身体化内心） |
|-------------------|-------------------|
| 她想，他可能把我当替身 | 他叫了她名字的瞬间，她阴道猛地收缩——不是因为快感，是因为心碎 |
| 他感到愧疚 | 他射进她体内时，闭上了眼睛——不是因为高潮，是因为不敢看她 |

## 四、色情等级控制

| 等级 | 器官词汇 | 动作词 | 对白 | 适用 |
|------|---------|-------|------|------|
| **1级（文艺）** | 阴茎/阴道 | 交合/进入 | 含蓄 | 传统文学 |
| **2级（网文）** | 肉棒/小穴 | 抽插/撞击 | 轻微淫语 | 网文情色 |
| **3级（海棠）** | 鸡巴/屄/嫩逼 | 干/操/操逼 | 直白淫语 | 海棠/肉文 |
| **4级（重口）** | 屌/骚屄/肉洞 | 猛操/奸/轮 | 粗口+命令 | 重口味 |

**默认**：用户没有特别要求"雅"的时候，默认用 3 级写法。

## 五、艳情小说六要素（缺一不可）

| 要素 | 要求 | 示例 |
|------|------|------|
| 器官粗俗 | 用俗语不用术语 | 鸡巴/屄/奶子/龟头/马眼 |
| 动作详细 | 每个抽插都写 | 角度/深度/力度/速度 |
| 对白淫荡 | 至少一句淫语 | "操我/干我/射里面" |
| 体液飞溅 | 淫水/精液/口水 | 咕叽咕叽/白浊/拉丝 |
| 声音响亮 | 叫床/撞击/水声 | 啊啊啊/啪啪啪/咕叽咕叽 |
| 尺寸比较 | 用反应证明大小 | "好大"/"手掌握不过来" |

## 六、好坏对比

### 器官描写

| ❌ 错误写法 | ✅ 正确写法 |
|------------|------------|
| 他的坚硬抵住了她的柔软 | 他的阴茎已经硬得像铁。龟头涨得发紫。抵住她的阴道口 |
| 她的私处很湿润 | 她的阴唇已经张开。粉红色的肉露出来。爱液流到大腿根 |
| 他们交融在一起 | 他的阴茎插进她的阴道。全部。阴茎根贴着她的阴唇 |

### 动作描写

| ❌ 错误写法 | ✅ 正确写法 |
|------------|------------|
| 他吻遍她的全身 | 他的嘴唇从脖子滑到乳房。含住乳头。舌头绕着乳晕打转。她叫了一声 |
| 他们激烈地做爱 | 他抓住她的腰。猛力抽插。啪啪啪。她的乳房在晃。汗水从额头滴到他胸口 |

### 高潮描写

| ❌ 错误写法 | ✅ 正确写法 |
|------------|------------|
| 她达到了高潮 | 她的阴道剧烈收缩。一股爱液喷出来。她尖叫。"操！操！要死了——" |
| 他释放了 | 他咬住她的肩膀。阴茎在她体内跳动。精液一股一股射出来。温热的液体射进子宫 |

## 七、角色一致性

性爱中的角色不能 OOC：
- 害羞的角色不会突然变成老手
- 强势的角色在床上可能更强势，也可能意外地脆弱
- 角色的性表现必须符合其性格和经历
- **但——欲望可以让角色展现出平时隐藏的一面，这是允许的**

## 八、特殊题材处理

| 题材 | 写法要点 |
|------|---------|
| 师生 | 权力不对等是张力，禁忌感是催情剂 |
| 强奸 | 暴力就是暴力，不美化不遮掩，写身体真实反应 |
| 乱伦 | 血缘+欲望的矛盾，罪恶感与快感的交织 |
| SM | 权力交换的真实感，痛与快的模糊边界 |
| 群交 | 多人互动的混乱感，身体的多重刺激 |
| NTR | 背叛的快感与痛苦，窥视与被发现 |
| 陌生人 | 未知带来的刺激，身体语言代替对话 |
| 旧情人 | 熟悉与陌生的交织，身体记得脑子忘了 |
