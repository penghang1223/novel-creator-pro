# 内容资产化系统

> 从"生成内容"到"生成资产"。小说只是起点，自动衍生流量资产。

---

## 核心哲学

每章写完不是终点，而是提取金句、爆款标题、短视频脚本、社媒帖子的起点。

## 一、5种内容资产

### 1. 金句提取
**标准**：
- 有哲理性或情感共鸣
- 适合社交媒体传播
- 独立可读（脱离上下文也能懂）
- 字数 ≤ 50 字

**来源**：
- 角色的标志性台词
- 叙述中的哲理句
- 对话中的犀利回应
- 内心独白的精华

### 2. 爆款标题生成
**模板库**：

| 类型 | 模板 | 示例 |
|------|------|------|
| 悬念型 | "他以为自己是废物，直到那一天..." | |
| 反转型 | "所有人都看不起她，直到她亮出身份" | |
| 冲突型 | "她嫁入侯府第一夜，夫君的命根子毁了" | |
| 数字型 | "3个秘密，让整个王朝为之颤抖" | |
| 提问型 | "如果你的每一句谎言都会成真，你会说什么？" | |
| 共情型 | "被所有人遗弃后，她终于不再忍了" | |

### 3. 60秒短视频脚本

**标准结构**：
```
0-5秒：钩子（强视觉/强冲突开场）
5-15秒：场景建立
15-30秒：冲突升级
30-45秒：高潮爆发
45-60秒：结局+引导关注
```

**输出格式**：
```json
{
  "hook": "0-5秒钩子描述",
  "scenes": [
    {"time": "5-15s", "visual": "画面", "audio": "音效/对话"},
    {"time": "15-30s", "visual": "画面", "audio": "音效/对话"},
    {"time": "30-45s", "visual": "画面", "audio": "音效/对话"},
    {"time": "45-60s", "visual": "画面", "audio": "音效/对话"}
  ],
  "call_to_action": "引导关注/追更"
}
```

### 4. 社媒帖子生成

**小红书风格**：
- 标题：悬念 + emoji
- 正文：轻松口语化
- 结尾：互动提问
- 标签：相关话题

**抖音风格**：
- 标题：冲突 + 悬念
- 正文：短平快
- 评论引导："你觉得主角下一步会怎么做？"

### 5. 人物金句/经典场景
- 角色标志性台词
- 适合做表情包的场景
- 适合二次创作的片段

## 二、提取时机

每章创作完成后自动执行：
1. 读取章节内容
2. 识别金句候选（3-5 句）
3. 生成爆款标题（3-5 个）
4. 提取适合短视频的场景（1-2 个）
5. 生成社媒帖子（2-3 条）

## 三、资产累积

所有资产存入 state.json 的 `content_assets` 字段：

```json
{
  "content_assets": {
    "golden_sentences": [
      {"content": "金句", "source_chapter": 5, "virality_score": 0.85}
    ],
    "viral_titles": [
      {"title": "标题", "source_chapter": 5, "clickbait_score": 0.8}
    ],
    "short_video_scripts": [
      {"chapter": 5, "scene": "场景描述", "duration": 60}
    ],
    "social_media_posts": [
      {"platform": "小红书", "content": "帖子内容", "chapter": 5}
    ]
  }
}
```

## 四、使用时机

- 长篇：每章完成后提取
- 短篇：全文完成后提取
- 项目汇报时展示资产清单

---

**核心口号**：小说是内容的起点，不是终点。
