# 场景加厚技法

> 解决问题：Claude首稿只有1500字，场景写不厚、细节不够。

---

## 核心思路：剧本的"五层场景"移植到小说

剧本里一个场景有5层，小说一样可以用：

| 层 | 剧本 | 小说对应 |
|----|------|----------|
| 1. 场景设定 | 场景标题（时间/地点） | 环境描写，1-2句定位 |
| 2. 表面动作 | 角色在做什么 | 行为描写 |
| 3. 潜台词 | 角色真正想说的 | 内心独白/微表情/潜台词 |
| 4. 障碍/冲突 | 什么阻止角色达成目标 | 障碍物描写（人/环境/自身） |
| 5. 情绪弧线 | 场景开始→结束的情绪变化 | 情绪描写（行为替代情绪） |

**首稿太薄的原因**：只写了第1-2层，漏了3-5层。

---

## 六种加厚手法

### 1. 障碍物堆叠

一个场景里至少放**2个障碍**，不是1个。

```
薄：林辰走进咖啡馆，看到了许铭远。
厚：林辰走进咖啡馆——门卡住了，推了三下才开。里面挤满了人，他绕过两
张桌子才看到角落里的许铭远，桌上堆满了外卖盒和揉成团的草稿纸。
```

**可执行规则**：每个场景写完后检查——角色想做什么？阻碍他的东西有几个？如果只有1个，加第2个。

### 2. 感官五感法

至少写到**3种感官**（视觉/听觉/触觉/嗅觉/味觉）。

```
薄：出租屋里很闷。
厚：出租屋里闷得像蒸笼，墙上霉斑散发出潮湿的气味，窗外空调外机嗡嗡响，
林辰脱了外套还是出汗。
```

**可执行规则**：场景描写卡壳时，依次问自己——这个场景里能"看到"什么？"听到"什么？"闻到/摸到"什么？

### 3. 动作分解

把一个大动作拆成**3-5个小动作**。

```
薄：他打开了电脑。
厚：他把背包扔在椅子上，摸出充电线插上，按了开机键，等了两秒屏幕才亮
起来——浏览器还开着昨天的招聘页面。
```

**可执行规则**：凡是"他V了O"这种3-5字的短句，问自己：这个动作能拆成几步？有没有细节可以加？

### 4. 时间锚点

不用精确计时（禁止"过了三秒"），用**事件锚点**标记时间流逝。

```
薄：等了一会儿。
厚：外卖到了他还没想出一个字。奶茶凉了。楼下的小孩放学回来了。
```

**可执行规则**：用"发生了什么"来标记时间，不要用"过了多久"。

### 5. 环境回应

环境不是背景布，要**回应角色的情绪**。

```
薄：林辰心情不好。外面下着雨。
厚：雨打在铁皮棚上噼里啪啦的，比他的心还乱。水顺着窗缝渗进来，在地
板上画了一条歪歪扭扭的线。
```

**可执行规则**：角色情绪变化时，环境有没有跟着变？如果没有，加一个环境细节。

### 6. 微冲突填充

大冲突之间插入**小摩擦**，不要让场景太平滑。

```
薄：林辰和苏晴谈好了朵朵的学费。
厚：林辰和苏晴谈好了学费——但苏晴多说了一句"你早该这样"，林辰没回
嘴。朵朵在旁边小声问："爸爸，你是不是又要走了？"林辰蹲下来抱她，
膝盖咯吱响了一声。
```

---

## 场景厚度自检清单

写完一个场景后，检查：

- [ ] 障碍物 ≥ 2个？
- [ ] 感官 ≥ 3种？
- [ ] 有没有"V了O"式的3-5字大动作没拆解？
- [ ] 时间流逝是用事件标记的？
- [ ] 环境有没有回应角色情绪？
- [ ] 大冲突之间有没有小摩擦？
- [ ] 这个场景的情绪弧线是：起始情绪 → 结束情绪（有变化）？

如果6项中 ≤ 2项达标，这个场景大概率偏薄，需要加厚。
