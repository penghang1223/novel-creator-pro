# 场景转换与转场技法

> 解决问题：场景切换生硬、时间跳跃突兀、读者"掉线"。

---

## 核心原则

转场不是"分隔符"，是**读者注意力的引导绳**。好的转场让读者无缝过渡，差的转场让读者需要重新加载上下文。

---

## 五种转场类型

### 1. 硬切（直接跳）

用法：场景之间有明显分隔（空行/分隔线），不解释就跳。

```
林辰走出公司大楼。
---
出租屋里，灯管闪了两下才亮。
```

**适用**：时间跨度短（几分钟到几小时）、读者已经知道要去哪。
**禁用**：跨越天/周/月时，必须给时间锚点。

### 2. 桥梁句

用法：上一个场景的最后一句，引导到下一个场景。

```
……林辰把手机塞回口袋，朝地铁站走去。

地铁上他打开招聘APP，刷了三条推送——35岁以下，本科以上，
三年以上管理经验。他32岁，全部达标，但投出去的简历全部显示"已读不回"。
```

**适用**：连续时间线，角色在移动。
**技巧**：桥梁句用**动作**（走向/打开/拿出），不用"与此同时"、"另一边"。

### 3. 时间锚点转场

用法：明确告诉读者"跳到了什么时候"。

```
三天后。
林辰的手机响了——是猎头。
```

**适用**：跳过几天/几周。
**规则**：时间锚点用**事件**，不用数字。
```
❌ 过了五天。
✅ 周五下午，外卖刚到。
❌ 两周后。
✅ 房东第三次敲门的时候。
```

### 4. 视角切换转场

用法：从A角色的场景跳到B角色的场景，用B的名字/身份锚定。

```
……林辰盯着手机上的余额数字，没说话。

同一时间，江城另一边。
苏晴刚把朵朵从学校接回来。朵朵一路上都在说今天美术课画了爸爸。
```

**适用**：双线叙事。
**规则**：切换时用**角色名+地点+在做什么**三件套锚定，读者3秒内知道自己在哪。

### 5. 悬念钩子转场

用法：上一个场景在高潮处断掉，跳到另一个场景，但悬念不散。

```
……林辰推开门，客厅里的灯亮着。沙发上坐着一个人。

（空行）

赵天宇今天心情很好。刚升了副总监，部门聚餐，有人敬酒。
"赵总，你那前师父呢？听说被裁了？"
赵天宇笑了笑，没接话。
```

**适用**：制造阅读驱动力，让读者急着看回上一条线。
**规则**：断点必须是**有信息差**的地方（读者想知道但还不知道的）。

---

## 禁止使用的转场词

| 禁用 | 原因 | 替代 |
|------|------|------|
| 与此同时 | AI味重 | 直接跳/用"同一时间" |
| 另一边 | 太随意 | 直接写角色名+地点 |
| 镜头一转/转场 | 电影术语，小说里用是AI味 | 直接跳 |
| 话说回来 | 口语化 | 直接跳 |
| 就在这时 | 老套 | 直接写发生了什么 |

---

## 转场自检清单

- [ ] 读者3秒内能知道"我在哪/什么时间/跟谁"？
- [ ] 没有使用禁用转场词？
- [ ] 跨天以上的时间跳跃有没有时间锚点？
- [ ] 悬念钩子转场的断点有信息差？
- [ ] 双线切换时，每条线至少推进了一个事件再切？
