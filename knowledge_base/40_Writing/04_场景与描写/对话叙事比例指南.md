# 对话叙事比例指南

> 解决问题：对话太多变流水账、叙事太多变说明文、不知道怎么分配。

---

## 核心概念：三种文本类型

小说正文只有三种东西：

| 类型 | 定义 | 功能 |
|------|------|------|
| **对话** | 角色说的台词 | 推进关系、暴露信息、制造冲突 |
| **叙事** | 动作+环境+心理描写 | 加厚场景、控制节奏、建立氛围 |
| **说明** | 背景交代、解释性文字 | 提供读者需要知道的信息（尽量少用） |

**黄金比例**（番茄都市文参考值）：

| 类型 | 占比 | 说明 |
|------|------|------|
| 对话 | 25-35% | 太少→节奏闷，太多→流水账 |
| 叙事 | 55-65% | 主力，场景厚度来源 |
| 说明 | 5-15% | 越少越好，能用对话/叙事替代就替代 |

---

## 对话密度控制

### 什么时候该多用对话

- 两个角色关系发生变化时（吵架、表白、谈判、摊牌）
- 需要快节奏推进时（对话是最紧凑的叙事方式）
- 需要展示角色性格时（说话方式比描写更直接）

### 什么时候该少用对话

- 角色独处时（没人可对话，用内心独白或环境描写）
- 需要加厚场景时（对话会压缩空间感）
- 信息量大时（用对话交代复杂信息会显得生硬）

### 对话节奏控制公式

```
对话-对话-对话 → 第4行必须插叙事
叙事-叙事-叙事 → 第4段可以来一句对话打破
```

**具体操作**：
- 每2-3行纯对话后，插1行叙事（动作/微表情/环境）
- 叙事段落超过5行没有对话时，考虑加一句角色说话或内心独白
- 禁止连续8行纯对话

## 说明文消解法

"说明"是最弱的文本类型，能消解就消解。

### 方法1：拆成对话

```
❌ 说明：林辰今年32岁，985毕业，在互联网公司工作了十年，职位是中层管理。
✅ 对话：HR说："林辰，你在公司十年了。"林辰想：十年。
```

### 方法2：拆成行为

```
❌ 说明：他的经济状况很糟糕，银行卡里只剩三万多。
✅ 行为：林辰打开手机银行。余额：32461.50。他盯着那个数字看了好一会儿，
   关掉了APP，又打开，再看一眼——没变。
```

### 方法3：拆成环境

```
❌ 说明：城中村的出租屋很小很破。
✅ 环境：房间放了张床就转不开身。墙皮起泡了，厕所的灯一闪一闪的。
```

## 特殊情况

### 纯对话场景（会议/争吵/表白）

可以突破"连续8行"限制，但必须每3-4行插**动作锚点**（不是心理/环境，是角色正在做的动作）：

```
"我不接受这个方案。"赵天宇把文件夹摔在桌上。
"不接受你拿出替代方案。"林辰没看他，翻着自己的笔记本。
"替代方案就是你走人。"
"我走不走，不是你说了算。"林辰合上笔记本，抬眼看他。
```

### 纯叙事场景（独处/回忆/旅途）

可以整段没有对话，但需要插入**内心独白**打破沉闷：

```
林辰沿着江边走了很久。路灯把他的影子拉得很长。
他想起十年前刚入职的时候，也是这条路，也是这个时间下班。那时候觉得
一切都来日方长。
十年。说没就没了。
```

### 高密度信息场景（系统觉醒/商战分析）

说明文不可避免时，用**节奏切割**：每2-3句说明后，插一句角色反应。

```
系统面板弹出来半透明的数字——许铭远，投资价值8.9。
林辰眨了眨眼，以为自己看错了。8.9？路人大部分是0.5到2.0之间。
这个数字意味着什么，他还不清楚。但他知道，这绝对不正常。
```

## 自检清单

写完一个场景后：

- [ ] 对话占比 25-35%？
- [ ] 没有连续8行纯对话？
- [ ] 没有连续5行纯叙事不插内心独白？
- [ ] 说明文占比 < 15%？
- [ ] 说明文能用对话/行为/环境替代吗？
