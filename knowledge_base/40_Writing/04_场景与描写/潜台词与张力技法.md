# 潜台词与张力技法

> **来源**：11111.md 对话写作深度技法
> **归类**：对话干涩/潜台词/张力创建
> **生效**：立即

---

## 一、核心理念：冰山理论

对话不能是"透明鱼缸"——角色把想法全说出来。**好对话是冰山：说出来的只占10%，藏在水下的90%才是真实意图。**

### 三种常见错误

| 错误 | 典型表现 | 问题 |
|------|----------|------|
| **透明鱼缸** | "我喜欢你" / "我很生气" / "我担心你" | 角色直白说出内心，没有悬念 |
| **单向传输** | A问→B答→C问→D答 | 信息完全透明，没有博弈 |
| **全知视角** | 角色知道所有信息，没有误会 | 没有信息差，没有张力 |

### 正确方向：信息博弈

对话中的信息流动应该是：**隐藏→试探→误解→反转**。

## 二、五种潜台词技法

### 技法1：指桑骂槐（借题发挥）

表面在说一件事，实际在表达另一件事。

**❌ 直白写法**：
```
"你根本不在乎我。"
```

**✅ 潜台词写法**：
```
"你连我生日都忘了。"她说。
"我最近太忙了。"
"你上周三凌晨两点还在朋友圈点赞。"
```

**要点**：
- 不直接说核心情绪，用一个具体事实暗示
- 对方听懂了但装不懂，或用其他理由搪塞
- 冲突升级靠"追加事实"而非"提高音量"

### 技法2：顾左右而言他（回避与转移）

被问到关键问题时，故意回答其他内容。

**❌ 直白写法**：
```
"你爱我吗？"
"我不爱你了。"
```

**✅ 潜台词写法**：
```
"你爱我吗？"
"今晚吃什么？"
"我在问你话。"
"冰箱里还有两个鸡蛋。"
```

**要点**：
- 回避本身就是一种回答（沉默=拒绝）
- 转移的话题越日常，回避的信号越强烈
- 追问→回避→再追问=张力递增

### 技法3：言行不一（行为泄露）

说的和做的完全相反。

**❌ 直白写法**：
```
"我才不关心你。"但她心里很担心。
```

**✅ 潜台词写法**：
```
"我才不关心你。"她把伞塞到他手里。
"淋湿了别来找我。"
```

**要点**：
- 永远不写"他心里想的是X"——让读者从行为中读出来
- 嘴上否定，身体诚实。行为永远比台词诚实。
- 这是"查理日记陷阱"的反面——不要替角色说出内心

### 技法4：信息差（读者比角色知道得多/少）

**❌ 无张力**：所有角色都知道同样信息，对话变成确认。

**✅ 有张力**：
- **模式A（读者多知）**：读者知道A在说谎，B不知道 → 紧张感
- **模式B（读者少知）**：角色知道某个信息但不说，读者好奇 → 悬念感
- **模式C（角色各知一半）**：A知道X不知道Y，B知道Y不知道X → 试探博弈

### 技法5：反话正说 / 正话反说

表面表达的意思和真实意思相反。

**❌ 直白写法**：
```
"你别走。"（挽留）
```

**✅ 潜台词写法**：
```
"你走了也好。"她背对着他说。
"终于没人跟我抢遥控器了。"
```

## 三、张力创建公式

```
张力 = 冲突 + 潜台词 + 动作锚点 + 负面约束
```

| 要素 | 含义 | 检查方法 |
|------|------|----------|
| **冲突** | 双方目标不一致 | 这场景里两人想要的东西是否矛盾？ |
| **潜台词** | 不说真实想法 | 遮住角色的台词，能否从行为猜出真实意图？ |
| **动作锚点** | 对话中的具体行为 | 这段对话有没有至少2个动作锚点？ |
| **负面约束** | 角色不能/不敢做的事 | 角色有什么不能说的？不能做的？ |

### 动作锚点示例

对话不能悬空。每一轮对话之间，角色必须在"做"什么。

**❌ 对话悬空**：
```
"你为什么要骗我？"
"我没有骗你。"
"你明明知道真相。"
"我不知道。"
```

**✅ 有动作锚点**：
```
"你为什么要骗我？"她把纸推到他面前。
他没有看。"我没有骗你。"
"你明明知道真相。"
他拿起杯子喝了口水。杯子是空的。"我不知道。"
```

**动作锚点的选择原则**：
- 动作应该反映角色情绪状态（紧张→反复做同一动作）
- 动作应该是角色的"行为指纹"（每个人的习惯性动作不同）
- 动作可以代替回答（沉默+某个动作=回答）

## 四、动作流大纲（写前步骤）

**在写对话之前，先写动作流大纲。**

对话是"冰山露出水面的一角"。写对话前必须先知道水面下是什么。

### 动作流大纲模板

```
【场景N：{场景名称}】
出场角色：A, B
表面话题：他们在聊什么（冰箱里的鸡蛋/天气/工作）
真实议题：他们实际在冲突什么（信任/分手/背叛）
A的目标：{想让B做什么/承认什么}
B的目标：{想避免什么/隐瞒什么}
A的负面约束：{A不能直接说什么}
B的负面约束：{B不能直接说什么}

动作流：
1. A {动作} → 试探
2. B {动作} → 回避
3. A {动作} → 加压
4. B {动作} → 反击/崩溃/继续回避
5. {张力升级点} → {触发事件}
6. {结局} → {未解决/部分解决/爆发}
```

**写完动作流大纲后，再写对话。** 对话只是动作流的"声音化"。

## 五、四步润色法（写后精修）

写完一章后，对对话场景执行四步润色。

### Step 1：删（删除废话和标签）

| 删除类型 | 示例 | 处理方式 |
|----------|------|----------|
| 对话标签 | "他解释道"、"她询问道" | 删除，或替换为"说" |
| 情绪命名 | "她愤怒地说" | 删除"愤怒地"，用行为替代 |
| 连接词 | "然后"、"接着"、"于是" | 删除，直接写下一段 |
| 解释性独白 | "他心想，这一定是……" | 删除，改为沉默/动作 |

### Step 2：加（加入潜台词动作）

- 在每轮关键对话之间，加入角色的行为反应
- 行为应该暗示真实情绪，而非直接表达
- 至少2个动作锚点/对话场景

### Step 3：变形（打破语法和逻辑）

真人说话不是完整句子。

| AI写法 | 人味写法 |
|--------|----------|
| "我已经知道了这件事，你不必再告诉我了。" | "知道了。" |
| "你怎么可以这样做呢？" | "你——" |
| "我认为我们应该考虑一下其他方案。" | "要不……换个办法？" |
| "虽然我很生气，但是我还是想听听你的解释。" | "说吧。" |

**变形技巧**：
- 打断句子（说到一半停下）
- 省略主语（"知道了"而非"我已经知道了"）
- 答非所问（问A答B）
- 重复一个词（"你你你——"表示激动）
- 用语气词结尾（"吧"、"呢"、"嘛"）

### Step 4：校准（检查人设冲突）

- 遮住说话人名字，能猜出是谁说的吗？
- 这段对话是否符合角色的矛盾特质？
- 角色的回应方式是否与其性格一致？（强势角色不一定大声说话，可能更冷）

## 六、对话干涩检测

### 干涩症状

| 症状 | 判断标准 |
|------|----------|
| **信息透明** | 所有角色完全坦诚，没有隐瞒/误会 |
| **直白命名** | 角色直接说出自己的情绪和想法 |
| **无动作锚点** | 对话悬空，角色只是"在说话" |
| **完整句式** | 所有对话都是完整的主谓宾结构 |
| **问答机械** | A问→B答→C问→D答，像采访 |

### 检测问题（每章3段对话抽查）

1. 这段对话里，角色有没有没说出口的真实意图？
2. 遮住角色名字，能猜出谁在说话吗？
3. 这段对话有没有至少一个动作锚点？
4. 角色有没有回避/转移/反答某个问题？
5. 如果删掉所有对话，只看行为，读者能猜出大致剧情吗？

**≥3个"否" → 对话干涩，需要润色。**

## 七、查理日记陷阱（反面教材）

**什么是查理日记陷阱**：把潜台词写得太明显，等于替角色说出了内心独白。

**❌ 陷阱写法**：
```
"你今天回来得很晚。"她尽量让语气听起来随意，但心里已经起了疑心。
```
→ "心里已经起了疑心" = 替角色说出了内心。读者不需要被告知。

**✅ 正确写法**：
```
"你今天回来得很晚。"她的目光落在他肩上——那里有一根不属于她的长发。
```
→ 不写"疑心"，写"目光落在长发上"。读者自己得出"她在怀疑"的结论。

**核心原则**：**永远不写角色的内心定义。** 用行为/感官/注意力的变化来暗示。
