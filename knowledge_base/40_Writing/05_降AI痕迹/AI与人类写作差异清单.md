# AI vs 人类写作差异清单

> 来源：用户分享
> 用途：降低AI味，提升文本人性温度

## 核心原则

- **人类写作的灵魂在于"毛边感"**——看似无用的环境描写、不合逻辑的情绪跳跃、语法瑕疵
- **没有闲笔、没有冗余、没有意外感的文本，大概率出自算法**
- 查"地/得"密度：副词过多必是AI
- 看抽象名词：频繁出现"勇气""命运""气息"等空洞概念

## 情绪描写

### AI滥用（禁止）
- "复杂/难以言喻的情绪" → 用生理反应：喉头一紧，眼眶发酸，手指掐进掌心
- "坚定/决绝的眼神" → 用动态细节：下颌绷紧，目光像钉子
- "贪婪/渴望地注视" → 用行为隐喻：指尖在玻璃柜上洇出水痕

### 人类有效
- 怔/愣/懵：瞬间呆滞感
- 涩/苦/烫：味觉通感替代抽象情绪
- 怵/怯/蔫：口语化词汇

## 动作描写

### AI滥用（禁止）
- "缓缓地……" → 省略副词，用动词本身传递节奏
- "紧紧抓住/盯着" → 精准动词：攥、攥着信纸指节泛白
- "勾起一抹冷笑/扬起嘴角" → 结合肢体细节

### 人类有效
- 蹭/挪/滑：微小动作传递情绪
- 睃/睨/瞟：差异化视线
- 哆嗦/颤/打摆子：生理本能反应

## 环境描写

### AI滥用（禁止）
- "神秘/诡异的气息" → 多感官细节：隔夜泔水的酸味，苔藓湿漉漉反青光
- "死寂般的安静" → 具体声音的缺失
- "璀璨/绚丽的灯火" → 色调与质感：霓虹晕在雨洼里，红得发脏

### 人类有效
- 阴冷/潮闷：体感形容词
- 噪/闹腾：听觉具象化
- 灰蒙蒙/昏黄：视觉色调词

## 叙事逻辑

### AI滥用（禁止）
- "与此同时" → 直接跳转或隐喻衔接
- "显然/毫无疑问" → 潜台词或反讽
- "仿佛/似乎" → 大胆使用隐喻
- "意味深长" → 用动作或潜台词
- "五花八门/形形色色" → 具体描写
- "不可思议" → 个性化反应

### 人类有效
- 省略连接词：分号、破折号、直接断句
- 口语化转折：偏巧/倒好/敢情
- 留白：刻意不解释关键细节

## 词汇优先级

### 优先使用
- 单音节词：绝/神/蔫
- 地域化表达：打摆子/硌应/齁咸
- 非常规搭配：打破语法的短句（"冷。真他妈冷。"）

### 禁止/限制使用
- 副词（XX地）密度控制
- 抽象名词：勇气、命运、气息、力量
- 成语堆砌
