# 风格硬约束系统

> 从"软标签"到"硬约束"。风格不是形容词，是可执行的规则。

---

## 通用硬约束（所有创作）

### 禁用词清单

`然而、此外、总而言之、值得注意的是、显而易见、众所周知、一定程度上、某种程度上、或多或少、某种程度`

### 必需元素清单

- 具体动词（不是"走"而是"踱步/踉跄/疾步"）
- 感官细节（视觉/听觉/触觉/嗅觉/味觉至少 2 种）
- 潜台词（对话不是信息交换，是博弈）
- 行动细节（不用形容词定义人物，用行动）

### 抽象词限制

每段抽象词 ≤ 3 个，超出则替换为具体描写。

## 叙事声音量化规则

| 风格 | 句长（min-max-avg） | 对话比例 | 特征 |
|------|-------------------|---------|------|
| 说书人 | 12-30-18 | 0.2-0.4 | 口语化、现代类比、幽默 |
| 猫腻 | 15-35-22 | 0.3-0.5 | 情感深度、哲学思辨、感官精准 |
| 古龙 | 5-15-8 | 0.4-0.6 | 段落1-3行、短促有力、诗意元素 |
| 金庸 | 15-40-22 | 0.3-0.5 | 古典引用、动作细节、风景散文 |

## 角色对话风格

| 类型 | 语气 | 偏好话题 | 禁区 | 回应模式 |
|------|------|---------|------|---------|
| 毒舌 | 犀利、讽刺、高冷 | 智商、效率、逻辑 | 感情、八卦 | 直接指出矛盾、逻辑碾压 |
| 神回复 | 机智、幽默、反击 | 反转、双关、自嘲 | — | 快速反应 |
| 话废 | 无厘头、躺平、逃避 | 转移话题、说废话 | 直接回答 | 装傻、回避 |

## 风格适配规则

```
题材 → 自动适配风格
├─ 都市言情/权谋 → 猫腻风格
├─ 都市底层/江湖 → 说书人风格
├─ 侦探/悬疑 → 简洁有力风格
├─ 武侠 → 金庸/古龙风格
├─ 历史 → 说书人风格
└─ 未明确 → 根据内容智能判断
```

## 人性化写作九条规范

1. 先把话说清楚，再谈风格
2. 段落推进像人类思考一样自然
3. 开头不端着，结尾不悬空
4. 节奏有起伏，句子有长短
5. 句式更像口头叙述不是模板拼装
6. 少抽象名词，多具体动词与可感知细节
7. 克制修辞，拒绝"假文采"
8. 态度真实，不搞平均主义
9. 证据与归因讲究"说得出是谁、哪一次、在哪里"

## 去 AI 化负面清单（20 条）

1. 不写宣传腔、通稿腔
2. 不夸大意义、不空谈趋势
3. 不靠"知名度"当内容
4. 不写"尾巴句"假装深刻
5. 不写"挑战与展望"模板段
6. 不用高频"AI惯用词"撑语气
7. 不用"金句口号"收束段落
8. 不过度对称、不过度平衡
9. 不滥用"是…的"
10. 少用"有字句套娃"
11. 少用括号补充、冒号分解
12. 破折号克制使用
13. 粗体与排版有节制
14. 正文不出现表情符号
15. 引号与符号统一干净
16. 不带陪聊语、谄媚语
17. 少"可能/或许/一定程度上"堆叠
18. 不做"虚假跨度"
19. 信息密度不平均
20. 同义词不乱换，关键名词不漂移

## 风格校验（每章写完后执行）

| 检查项 | 通过标准 |
|--------|---------|
| 句长在范围内 | avg 在目标 ±3 字内 |
| 对话比例达标 | 在目标 ±0.05 内 |
| 禁用词出现次数 | 0 |
| 抽象词密度 | 每段 ≤ 3 个 |
| 必需元素 | 具体动词、感官细节、潜台词都存在 |
