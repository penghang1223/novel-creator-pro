# 灵感获取与卡文急救

> 来源：网文写作实战技巧大全（2026版）by 望舒
> 适用：网文写作

## 灵感来源TOP5

| 来源 | 说明 | 示例 |
|------|------|------|
| **热搜话题** | 微博/抖音热搜 | 职场霸凌/原生家庭/AI |
| **读者评论** | 书评区/段评 | 读者想看什么就写什么 |
| **竞品分析** | 看爆款书 | 学习节奏/爽点/断章 |
| **生活经历** | 自己的故事 | 真实感最强 |
| **新闻事件** | 社会新闻改编 | 天然有话题度 |

## 卡文急救包（6招快速推进剧情）

| 方法 | 操作 | 效果 |
|------|------|------|
| **加新角色** | 引入新角色制造冲突 | 快速推进剧情 |
| **加新地图** | 主角去新地方 | 新鲜感 + 新冲突 |
| **加新能力** | 主角获得新技能 | 爽点 + 期待感 |
| **制造误会** | 角色间产生误会 | 冲突 + 后续解开 |
| **回忆杀** | 插入关键回忆 | 补充设定 + 情感 |
| **突发事件** | 天灾/敌人突袭 | 紧张感 + 推进剧情 |

## 使用建议

- 不知道写什么时，先看读者评论——他们想看的就是你的灵感
- 竞品分析重点看：节奏怎么排、爽点怎么埋、断章卡在哪
- 生活经历改编最强，因为细节天然真实，不需要编
