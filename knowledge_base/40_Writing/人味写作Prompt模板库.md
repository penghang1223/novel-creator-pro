# 人味写作 Prompt 模板库

> 核心理念：**不要让人物"正确地行动"，要让人物"像人一样行动，然后刚好赢了"**
> 使用方式：写作前将对应 Prompt 模板作为写作指令的一部分输入

---

## 一、全局人格注入（写作前必喂）

每章正文写作前，在写作指令中加入：

```
你现在不是在"写好看"，而是在"写像人"。

所有人物必须满足：
1. 有矛盾（同时是A也是B）
2. 会做偏差行为（不是最优解）
3. 情绪通过行为表达，而不是直接说出来
4. 会说不完整的话、说错话、回避问题

写作规则：
- 禁止用"他很X""她很X"直接描述情绪
- 禁止连续使用形容词堆叠人物
- 每一段至少有一个具体动作或细节
- 每个关键场景必须有一个"反人设行为"
- 对话不能全部逻辑正确，必须有人类的不顺、停顿或转移

优先级：行为 > 生理 > 心理 > 情绪命名

目标：让读者感觉"这个人真的存在"，而不是"作者在写一个人"
```

---

## 二、人物生成模板

用于首次引入新角色时：

```
生成一个角色，必须包含：

1. 表层标签（别人怎么看他）
2. 内在矛盾（他真实的一面，与表层冲突）
3. 触发条件（什么情况下会暴露矛盾）
4. 偏差行为（关键时刻做的"非最优选择"）
5. 一个日常细节（让人物落地）

要求：
- 不使用形容词堆砌
- 用行为说明性格
- 至少一个"嘴上说A，行为是B"的设计
```

---

## 三、场景生成模板

```
写一个场景，必须满足：

1. 有明确冲突（人物之间或人物与环境）
2. 情绪通过行为体现，而不是直接说出来
3. 插入至少一个"无关但真实"的细节（吃的、声音、光线、物品）
4. 至少一个人物出现"反人设行为"
5. 对话中至少包含：
   - 一句没说完的话
   - 一次答非所问
   - 一次情绪转移

禁止：
- 直接写"他很愤怒/紧张/难过"
- 写标准化、完整逻辑对话
- 写"完美表达"的台词
```

---

## 四、情绪真实化模板

输入情绪：_____ → 改写为行为表达

```
输出要求：
1. 不出现情绪词（愤怒、悲伤、紧张等）
2. 用动作、停顿、细节表达
3. 至少包含一个重复动作 + 一个环境/物体细节
4. 可以出现"行为与情绪不一致"的情况

示例：
输入：紧张
输出：他把杯子放下。又拿起来。没喝。
```

## 五、人味爽点模板（重要）

爽点不能写成"主角全程冷静掌控、按计划碾压"。

```
设计一个爽点场景，必须包含：

1. 明确目标（主角想要什么）
2. 强阻力（外部或内部）
3. 偏差行为（主角没有做最优选择，而是被情绪/局限影响）
4. 结果反转（不是按计划成功，而是"歪打正着"）
5. 爽点释放

额外要求：
- 爽点过程中必须有犹豫/停顿/误判
- 不允许主角全程冷静掌控
- 至少一个"本来不打算做 → 还是做了"的瞬间
```

## 六、对话去AI化模板

```
重写对话，使其更像真实人类交流：

要求：
1. 至少加入：一句没说完的话 + 一句答非所问 + 一句说错或后悔的话
2. 删除"过于完整、逻辑严密"的表达
3. 每段对话尽量短
4. 用停顿、动作替代部分语言

目标：让对话听起来像"现场说出来的"，而不是"写出来的"
```

---

## 七、反AI味审稿模板

写完一章后用于审稿：

```
检查并重写以下文本，去除"AI表演感"。

检查重点：
1. 是否存在直接情绪命名（如"他很愤怒"）
2. 是否存在过于完美的对话
3. 是否缺少具体动作或细节
4. 是否人物行为完全符合人设（没有偏差）

重写要求：
- 用行为替代情绪
- 加入矛盾或偏差行为
- 加入至少一个生活细节
- 打破过于工整的句式

只输出修改后的版本
```

---

## 八、整章生成模板

```
写一章小说，必须满足：

1. 目标出现（主角想做什么）
2. 阻力出现
3. 主角出现"偏差行为"（不是最优解）
4. 局势短暂恶化
5. 反转（歪打正着）
6. 小爽点 or 悬念结尾

强制规则：
- 至少一个反人设行为
- 至少一个无关但真实的细节
- 至少一段不完美对话
- 禁止直接情绪描写

风格：克制、具体、像人，而不是"写得好看"
```
