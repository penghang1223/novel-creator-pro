## 人物三维度

### 🎯 三维结构模型（升级）

```id="d9xq1n"
外在（表现） × 内在（驱动） × 变化（弧线）
```

---

### 📊 三维拆解（可执行版）

| 维度 | 内容            | 检查点      |
| -- | ------------- | -------- |
| 外在 | 外貌 / 身份 / 行为  | 是否可被“看见” |
| 内在 | 性格 / 动机 / 价值观 | 是否解释行为   |
| 发展 | 成长 / 转变 / 结果  | 是否发生变化   |

👉 核心原则：
**人物不是设定，而是“行为逻辑”**

## 人物记忆点

### 🎯 记忆点公式（升级）

```id="u8b6xq"
差异性 + 重复出现 + 情绪绑定
```

---

### 🧠 记忆点类型（强化）

| 类型   | 示例      | 用法   |
| ---- | ------- | ---- |
| 外貌特征 | 伤疤、异瞳   | 快速识别 |
| 行为习惯 | 总是冷笑、沉默 | 强化印象 |
| 语言特征 | 固定口头禅   | 增强辨识 |
| 性格标签 | 冷血、偏执   | 简化认知 |
| 能力标签 | 特殊技能    | 功能记忆 |

---

### ⚙️ 设计原则

* 不超过2-3个核心记忆点
* 高频重复强化
* 与剧情绑定（不能是装饰）

---

### ⚠️ 常见问题

* 记忆点过多 → 模糊
* 只有设定没有使用
* 无情绪关联 → 记不住

## 人物驱动系统（核心新增）

### 🎯 人物行为底层逻辑

```id="k1qz7c"
欲望 → 决策 → 行动 → 结果 → 强化/改变
```

---

### 🧩 驱动三要素

| 要素  | 作用   |
| --- | ---- |
| 欲望  | 推动行动 |
| 恐惧  | 制造犹豫 |
| 价值观 | 决定选择 |

---

### ⚙️ 人物决策公式

```id="c3h8vs"
目标 × 风险判断 × 性格 → 行动选择
```

---

### 🧠 核心原则

* 不同人物 → 同一事件 → 不同选择
* 决策必须体现性格
* 行动必须带来后果

---

## 人物弧线

### 🎯 标准成长路径（升级）

```id="k7f3lm"
初始状态 → 触发事件 → 认知冲突 → 行为改变 → 关键转折 → 新状态
```

---

### 📈 常见弧线类型

| 类型  | 描述   |
| --- | ---- |
| 成长型 | 从弱到强 |
| 堕落型 | 从好到坏 |
| 觉醒型 | 认知改变 |
| 反转型 | 立场变化 |

---

### ⚙️ 弧线设计原则

* 必须有“内在变化”
* 转折必须由事件触发
* 变化要有代价

---

### ⚠️ 常见问题

* 只有变强没有改变
* 转折突兀
* 成长无代价

---

## 人物关系设计

### 🎯 关系本质模型

```id="7twl2g"
关系 = 情感 + 利益 + 立场
```

---

### 🧩 关系类型（强化）

| 类型 | 功能    |
| -- | ----- |
| 对立 | 制造冲突  |
| 辅助 | 推动成长  |
| 情感 | 增强代入  |
| 映衬 | 突出主角  |
| 利用 | 增加复杂度 |

---

### 🌐 关系网络原则

* 每个核心角色至少2条关系线
* 关系必须动态变化
* 关系变化推动剧情

---

### ⚙️ 关系变化模型

```id="7w3z5n"
建立 → 强化 → 冲突 → 变化 → 重构
```

---

## 人物出场与使用（新增）

### 🎯 出场原则

* 出场即带功能（推动剧情/制造冲突）
* 出场即带记忆点
* 出场即带关系

---

### ⚙️ 出场公式

```id="n2hx0r"
场景 + 行动 + 冲突/异常 = 有效出场
```

---

### 🔁 使用原则

* 每次出场必须：

  * 推进剧情 或
  * 加深人物 或
  * 改变关系

---

### ⚠️ 常见问题

* 工具人角色
* 出场无作用
* 人物消失不再出现

---

## 人物一致性检查

### 🎯 一致性核心

```id="9m3r2p"
设定 → 决策 → 行为 → 结果（必须闭环）
```

---

### 📊 检查维度（强化）

| 维度 | 检查问题    |
| -- | ------- |
| 行为 | 是否符合性格  |
| 对话 | 是否有角色特色 |
| 决策 | 是否符合动机  |
| 情绪 | 是否合理变化  |
| 成长 | 是否连续    |

---

### ⚠️ 常见问题

* 为剧情服务而OOC
* 前后性格不一致
* 决策无逻辑

---

## 人物自检清单（核心）

### 设定检查

* [ ] 是否具备三维结构（外在/内在/发展）
* [ ] 是否有清晰动机
* [ ] 是否有记忆点

---

### 行为检查

* [ ] 行动是否由欲望驱动
* [ ] 决策是否体现性格
* [ ] 是否有行为后果

---

### 弧线检查

* [ ] 是否存在成长或变化
* [ ] 转折是否有触发事件
* [ ] 是否付出代价

---

### 关系检查

* [ ] 是否有关系网络
* [ ] 关系是否变化
* [ ] 是否推动剧情

---

### 使用检查

* [ ] 每次出场是否有效
* [ ] 是否避免工具人
* [ ] 是否持续参与剧情

---

## 使用建议

用于人物设定与细纲阶段，确保：

* 人物具备清晰驱动逻辑
* 角色具有记忆点与辨识度
* 人物关系形成网络结构
* 人物成长真实且可追踪
