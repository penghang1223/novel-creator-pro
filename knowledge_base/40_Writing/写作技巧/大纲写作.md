## 黄金开篇法则

### 三章任务模型

| 章节  | 必须完成             | 检查标准       |
| --- | ---------------- | ---------- |
| 第一章 | 人物 + 世界规则 + 冲突引爆 | 是否出现明确危机   |
| 第二章 | 核心能力/转机 + 行动动机   | 主角是否主动做出选择 |
| 第三章 | 第一个爽点释放 + 主线明确   | 是否形成追读动力   |

---

### 开篇禁忌（含替代）

| 禁忌    | 问题    | 替代方案       |
| ----- | ----- | ---------- |
| 大段背景  | 信息密度低 | 拆入冲突中逐步释放  |
| 多角色登场 | 认知负担高 | 保留核心功能角色   |
| 慢热铺垫  | 流失读者  | 提前设置假高潮    |
| 性格模糊  | 无代入感  | 第一章必须有决策行为 |

---

### 开篇结构公式

```
危机 → 选择 → 反转 → 能力/代价 → 新危机
```

---

### 开篇钩子模板

**压迫反转型**

```
极限处境 → 被轻视 → 突然反转 → 能力显现 → 更大危机
```

**觉醒展开型**

```
日常 → 异常 → 能力觉醒 → 初次使用 → 发现代价/阴谋
```

## 爽点设计

### 爽点核心公式

```
预期差 × 情绪积累 × 释放强度
```

---

### 爽点节奏模型

| 类型  | 作用     | 频率    |
| --- | ------ | ----- |
| 微爽点 | 维持阅读惯性 | 每章    |
| 小爽点 | 提供反馈   | 2-3章  |
| 中爽点 | 阶段高潮   | 6-10章 |
| 大爽点 | 卷爆点    | 每卷    |

---

### 爽点结构

```
压制 → 误判 → 反转 → 碾压 → 外部反馈 → 新压力
```

---

### 情绪曲线

```
压抑 → 希望 → 再压 → 爆发 → 余波 → 新钩子
```

---

### 爽点组合技巧

* 连环爽点：连续触发
* 反转爽点：结果反预期
* 延迟爽点：延长压抑
* 意外爽点：非预期收益
* 信息差爽点：读者知情角色不知

---

## 期待管理

### 核心公式

```
预期建立 → 延迟满足 → 超额兑现 → 新预期
```

---

### 钩子模板

**章末钩子**

```
突发变化 + 未解释信息
```

**段落钩子**

```
信息不完整 + 风险暗示
```

**开头钩子**

```
结果先行 + 过程未知
```

---

### 钩子类型表

| 类型   | 示例       | 位置 |
| ---- | -------- | -- |
| 章末钩子 | 突发事件出现   | 结尾 |
| 悬念钩子 | 危险未揭示    | 段落 |
| 预告钩子 | 即将发生重大事件 | 开头 |

---

### 期待管理原则

* 持续制造未完成感
* 避免预期落空
* 控制信息释放节奏
* 惊喜需基于已有铺垫

---

### 常见问题

* 只挖坑不填
* 反转无逻辑
* 爽点未兑现

---

## 伏笔技法

### 伏笔本质

```
未来情绪的提前布局
```

---

### 伏笔类型

| 类型   | 特点     |
| ---- | ------ |
| 显性伏笔 | 明确提示   |
| 隐性伏笔 | 不显眼    |
| 误导伏笔 | 引导错误理解 |
| 结构伏笔 | 影响主线   |

---

### 埋设技巧

* 借对话自然植入
* 融入场景细节
* 用次要事件掩盖
* 在高潮后埋设
* 重复元素强化记忆

---

### 回收原则

* 必须回收
* 回收需放大效果
* 回收改变认知

---

### 伏笔管理表

| 编号 | 埋设位置 | 内容   | 预计回收 | 状态  |
| -- | ---- | ---- | ---- | --- |
| F1 | 第3章  | 关键物品 | 第30章 | 未回收 |
| F2 | 第5章  | 关键台词 | 第20章 | 已回收 |
