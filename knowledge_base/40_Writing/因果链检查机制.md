# 因果链检查机制

**版本**：1.0.0
**创建日期**：2026-04-24
**解决问题**：#9 强行巧合、#10 转折无铺垫、#12 逻辑漏洞、#14 主线跑偏

---

## 一、核心原则

好的剧情推进靠**因果**，不是靠**巧合**。区别在于：

- **因果**：A 发生了，所以 B 发生了（因为 A）
- **巧合**：A 发生了，然后 B 也发生了（碰巧）

AI 天生喜欢用巧合推进剧情，因为巧合写起来简单。但巧合多了读者会觉得"太巧了吧"。

---

## 二、因果链检测

### 2.1 每章因果链

每章写完后，用以下模板提取因果链：

```
【第N章 因果链】
事件A：[什么发生了]
  → 因为：[为什么会发生]（前文的什么导致了这个）
  → 导致：[引发了什么]
  
事件B：[什么发生了]
  → 因为：[是事件A的直接结果？还是有其他原因？]
  → 导致：[引发了什么]

关键转折：[本章最大的变化是什么]
  → 铺垫于：[最早在哪一章有暗示/伏笔]
  → 合理性：[从角色动机出发，这个转折是否合理？]
```

### 2.2 巧合度评估

对每章的每个关键事件评估巧合度：

| 等级 | 定义 | 处理 |
|------|------|------|
| 低（好） | 事件有明确的因果链 | 通过 |
| 中（注意） | 事件有因果链但不够强 | 增加前因后果的连接 |
| 高（警告） | 事件主要靠巧合 | 必须改写：把巧合改成必然 |
| 极高（禁止） | 事件完全是天降巧合 | 必须删除重写 |

### 2.3 巧合改写法

把巧合改写成必然的三种方法：

| 巧合写法 | 改写方向 | 示例 |
|----------|----------|------|
| 恰好遇到 | 改成蓄意前往 | 不是"恰好路过看到"，而是"带着目的去找" |
| 恰好知道 | 改成分步获取 | 不是一下子全知道，是从之前的线索拼出来的 |
| 恰好有人帮 | 改成利益交换 | 不是有人无偿帮忙，而是帮忙背后有动机 |

## 三、主线偏离检测

### 3.1 主线锚点

每章写作前必须明确：

- **主线目标**：主角当前最核心的目标是什么（从记忆系统读取）
- **本章与主线的关系**：直接推进 / 间接铺垫 / 支线探索
- **如果是支线探索**：必须在章末回到主线或埋下回归主线的钩子

### 3.2 偏离预警

| 偏离程度 | 判断标准 | 处理 |
|----------|----------|------|
| 无偏离 | 本章直接推进主线 | 通过 |
| 轻微 | 本章间接铺垫主线 | 通过 |
| 中度 | 本章是支线但与主线有关联 | 章末必须埋回主线的钩子 |
| 严重 | 本章与主线无关 | 必须重写：要么建立关联，要么删除 |

### 3.3 支线收敛规则

- 同时活跃的支线不超过 3 条
- 每条支线超过 5 章没有进展 → 必须收束或关闭
- 支线关闭时必须有结果（解决/放弃/合并到主线）

---

## 四、转折铺垫规则

### 4.1 转折的最小铺垫量

每个重大转折（角色立场改变、真相揭露、关系破裂）在发生之前必须有至少 **2 处铺垫**：

| 铺垫类型 | 做法 | 隐蔽度 |
|----------|------|--------|
| 明示 | 直接说出来/写出来 | 读者第一次看就知道 |
| 暗示 | 一个不起眼的细节 | 读者第一次看可能忽略 |
| 伏笔 | 一个看似无关的东西 | 回头看才知道是伏笔 |

**最低要求**：1个暗示 + 1个伏笔。

### 4.2 "意料之外情理之中"检测

转折发生后，问自己：

1. **读者第一次看**：有没有觉得"太突然了"？
   - 是 → 铺垫不够，需要回补
   - 否 → 通过
2. **读者回头看**：有没有觉得"原来早有暗示"？
   - 是 → 通过
   - 否 → 转折太明显，需要更隐蔽的铺垫

---

## 五、写中因果校验

写作时遵守：

- **不写"恰好"**：所有"恰好"都要被质疑——这是巧合还是因果？
- **不写"突然"**：所有"突然"都要有前因（不是突然发生，而是读者/角色突然意识到）
- **不写"没想到"**：角色的每个"没想到"都应该是因为他缺少某个信息，而不是因为剧情太离谱

## 六、写后因果审计

每章审计时追加检查：

- [ ] 本章关键事件有没有明确的因果链？
- [ ] 巧合度评估：低/中/高？如果是中高，是否已改写？
- [ ] 本章与主线的关系是否明确？如果是支线，章末是否回归？
- [ ] 本章的重大转折是否有至少2处铺垫？
- [ ] 如果删掉本章，后面的剧情还能连起来吗？（可删除检测）
