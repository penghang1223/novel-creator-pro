# 套路预判+绕开机制

**版本**：1.0.0
**创建日期**：2026-04-24
**解决问题**：#42 高度套路化、#43 融梗/撞梗、#44 创意平庸

---

## 一、核心逻辑

AI写作的套路化不是因为AI"故意"套用模板，而是因为训练数据中的模板本身就是最常见的叙事模式。绕开的策略不是"完全不走常见路径"，而是**识别到常见路径后，至少在一个关键节点上做反向选择**。

---

## 二、套路识别库

### 2.1 通用套路模式（所有网文）

以下套路模式在网文中极其常见。当本章情节匹配到某个模式时，必须触发绕开。

| 套路编号 | 套路名称 | 典型表现 | 绕开策略 |
|----------|----------|----------|----------|
| TR-01 | 英雄救美 | 主角恰好出现救了弱势角色 | 救是救了，但方式不体面/被救者不领情 |
| TR-02 | 突然开挂 | 主角突然获得超能力/信息 | 能力是获得了，但有严重代价/限制 |
| TR-03 | 反派降智 | 反派为了衬托主角突然变蠢 | 反派不降智，用其他方式赢 |
| TR-04 | 天降贵人 | 某个大人物突然出现帮主角 | 贵人帮了，但有条件/是交易 |
| TR-05 | 绝地翻盘 | 主角在最绝望时刻突然反转 | 翻盘了但不完全，留一个更大的问题 |
| TR-06 | 打脸爽点 | 看不起主角的人被狠狠打脸 | 打脸但有代价，或者被看穿打脸的意图 |
| TR-07 | 误会解除 | 误会→解释→和好 | 误会解了，但信任已经碎了 |
| TR-08 | 感情升温 | 两人互动后关系明显更近 | 关系更近的同时出现新的距离感 |
| TR-09 | 深夜谈心 | 角色深夜坐下来掏心窝子 | 谈心但不真诚，有人隐瞒了东西 |
| TR-10 | 群情激愤 | 大家一致愤怒/感动/支持 | 人群中有三种以上不同态度 |
| TR-11 | 完美计划 | 计划完美执行成功 | 计划成功了但出现了计划外的副作用 |
| TR-12 | 意外转折 | 一切顺利突然出事 | 转折有伏笔（哪怕回头看才觉得是伏笔） |
| TR-13 | 嘴炮说服 | 主角一番话说服了对方 | 说服了但不是因为嘴炮，是因为利益/形势 |
| TR-14 | 沉默对峙 | 两人对视沉默然后爆发 | 不对视。或者沉默中有一方先笑了 |
| TR-15 | 苦情独白 | 角色一个人回想悲惨过去 | 过去是悲惨的，但回忆时带着奇怪的笑/恨 |

## 三、执行流程

### 3.1 写前预判

在"约束组装"阶段（硬门禁 2.5）中增加套路预判：

```
【第N章 套路预判】
本章情节概述：[一句话]
可能涉及的套路：[TR-XX, CS-XX...]
绕开策略：
- [TR-XX] → [具体绕开方案]
- [CS-XX] → [具体绕开方案]
```

### 3.2 写中校验

写作时，如果发现自己正在写以下任何一种情况，立即停下来：

1. 读者能猜到下一句台词 → 换一种说法
2. 读者能猜到下一个情节发展 → 加一个意外变量
3. 角色说的话太"正确"/太"完整" → 让他说得别扭一点
4. 场景的发展完全符合该套路的预期 → 至少在一个节点做反向选择

### 3.3 写后抽查

每章审计时加一条：

- 本章是否使用了套路库中的模式？如果使用了，是否有绕开？
- 如果使用了且没有绕开 → 标记为"套路化"，建议润色修改

## 四、原创性加分项

在绕开套路的基础上，每章至少尝试以下一项：

| 加分项 | 说明 |
|--------|------|
| **反预期细节** | 写一个读者不会想到的细节（如：愤怒的人反而笑了一下） |
| **视角偏移** | 在关键场景从配角/旁观者视角写一句 |
| **信息差利用** | 让读者比角色知道得多或少一点 |
| **留白** | 不说破某个情绪/事件，让读者自己感受 |
| **日常穿插** | 在紧张场景中插入一个完全日常的动作 |

## 五、融梗检测

**融梗**是指无意识地使用了其他作品的标志性情节/台词/设定。

**检测方法**：
1. 写完一章后，问自己：本章有没有某个情节/台词"似曾相识"？
2. 如果有，回忆来源——是经典网文、热播剧、流行电影？
3. 如果是 → 必须改写，至少在3个关键节点上做差异化

**高风险融梗点**：
- "你等着，我会让你付出代价"类台词
- "我早就看穿了一切"类反转
- 角色突然说出哲学名言
- 某个物品/能力恰好是克制对方的关键

**改写策略**：
- 换触发方式（不是靠物品，而是靠信息/人情）
- 换情感底色（不是愤怒而是无奈）
- 换结果走向（不是赢了而是惨胜）
