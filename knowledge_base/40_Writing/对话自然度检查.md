# 对话自然度检查

**版本**：1.0.0
**创建日期**：2026-04-24
**解决问题**：#29 对话尴尬、#32 靠对话解释设定、#41 感情来得莫名其妙、#40 情绪强行煽情

---

## 一、问题清单

### 1.1 对话解释设定（Exposition via Dialogue）

**典型表现**：
> "你知道吗，根据《民法典》第944条，物业服务收费必须遵循合理、公开的原则，而且物业企业必须定期公布费用明细。"

**为什么假**：真人不会对另一个已经知道这些事的人解释基础知识。

**正确写法**：
- 让解释变成冲突：一个人说错，另一个人纠正
- 让解释变成争论：双方对法律有不同理解
- 让解释变成求助：一个人不懂，另一个人解释

### 1.2 强行煽情

**典型表现**：
- 角色突然说出很感人但性格不符的话
- 连续使用情感词堆叠（感动、温暖、幸福、泪水）
- 没有行为铺垫直接"泪流满面"

**识别标志**：
- 这段对话/描写换到其他角色身上也一样 → 说明不是基于人物性格的
- 作者在读这段话时觉得"太刻意了" → 读者也会这么觉得

**替代方案**：
- 让角色想做感人的事但做砸了
- 让角色嘴上说不在乎但身体动作出卖了他
- 让情感通过一个小的细节泄露，而不是通过大段的独白

### 1.3 感情线无来由

**典型表现**：
- 两个角色互动了3次就"在一起了"
- 没有经历分歧→和解→更深的理解的过程
- 感情升温只靠甜腻对话，不靠共同经历

**正确写法**：
- 每次感情推进都要有一个具体事件作为支撑
- 感情升温的同时也要有距离感的出现（不是直线上升）
- 让读者感受到"他们为什么会在一起"，而不是"作者说他们在一起了"

## 二、对话"水"检测

### 2.1 信息密度检测

每段对话标注其功能（可多选）：

| 功能 | 说明 |
|------|------|
| 推进剧情 | 这段对话带来了新的信息/决定/行动 |
| 揭示人物 | 这段对话让读者更了解角色性格 |
| 调节氛围 | 这段对话缓解了紧张气氛或增加了幽默 |
| 建立关系 | 这段对话改变了角色之间的关系状态 |

**规则**：每段对话至少有一个功能。纯闲聊（无信息无性格无关系无氛围）超过2段 → 删除。

### 2.2 对话长度限制

- 连续3段对话超过50字且没有动作穿插 → 插入动作/环境描写
- 一段对话超过100字 → 考虑拆分成多段或加入反应
- 角色独白式对话（一个人说了超过5句）→ 必须有听众的反应打断

## 三、写后对话审计

每章审计时追加：

- [ ] 有没有对话在解释设定？如果有，是否已转化为冲突/争论/求助？
- [ ] 有没有强行煽情的段落？如果有，是否已替换为行为/细节？
- [ ] 感情线的每次推进是否有具体事件支撑？
- [ ] 有没有"纯水"对话（无剧情无人物无关系无氛围）？
- [ ] 连续对话是否有动作/环境穿插？
