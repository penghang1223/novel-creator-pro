# 章节创作工作流 v2（整合版）

> 整合来源：quality-gate + style-controller + novel-writing + virtual-reader + 红线系统 + 章节前检查
> 核心哲学：**质量不是评估出来的，是约束出来的**

---

## 总览：三阶段流程

```
┌──────────────┐    ┌──────────────┐    ┌──────────────┐
│   写前约束    │ →  │   写中执行    │ →  │   写后校验    │
│  (4+9+红线)  │    │ (硬约束+技法) │    │ (校验+评分)  │
└──────────────┘    └──────────────┘    └──────────────┘
```

---

## 阶段一：写前约束（动笔前必须完成）

### Step 1：原创性验证（一级红线）

- [ ] 故事核心元素 100% 源自用户输入/大纲
- [ ] 未引入任何内部示例元素
- [ ] 主角姓名非"陈默"
- [ ] 默认使用第三人称（除非用户明确要求第一人称）

### Step 2：quality-gate 4项前置约束

- [ ] 必须有≥1个**新事件**发生（非重复已知信息）
- [ ] 必须有**信息增量**（新真相/新线索/新秘密）
- [ ] 主角状态必须有**变化**（认知/目标/处境/关系至少一项）
- [ ] 必须**推进**主线或支线剧情

### Step 3：章节前检查（9问必答）

> 简化版——用 1 句话回答每个问题，不需要展开。第8/9题必须实质性回答。

| # | 问题 | 回答 |
|---|------|------|
| 1 | 当前是第几章？在整体结构中什么位置？ | |
| 2 | 属于哪个情节团？核心任务是什么？ | |
| 3 | 上一章结尾悬念是什么？如何承接？ | |
| 4 | 本章需要回收哪些旧伏笔？ | |
| 5 | 本章需要埋设哪些新伏笔？ | |
| 6 | 人物关系有什么变化？ | |
| 7 | 情绪爽点是什么？（爽/虐/燃/甜） | |
| 8 | **核心推进事件**（1句话，必须"首次发生"） | |
| 9 | **主角状态变化**（至少一项实质性变化） | |

**合格线**：第8题必须能用1句话说清楚"首次发生"的事件。第9题必须有实质性变化。说不出来→回到大纲。

### Step 4：矛盾矩阵（选1个核心矛盾轴）

| 矛盾轴 | 网文变体 |
|--------|---------|
| 个人 vs 集体 | 主角想自由 vs 宗门规矩 |
| 传统 vs 变革 | 老顽固 vs 新职业 |
| 信任 vs 背叛 | 兄弟/师父/恋人的双面身份 |
| 欲望 vs 道德 | 想救人但会暴露身份 |
| 真相 vs 谎言 | 读者知道但角色不知道 |
| 生存 vs 尊严 | 跪着活还是站着死 |

写前明确：本章核心矛盾轴 = ？冲突双方 = ？结果 = ？遗留钩子 = ？

### Step 5：节奏定位

根据**张弛模型**确定本章节奏：
- 1强（高潮）→ 2缓（呼吸）→ 1中（加速）→ 1强（下一高潮）
- 比上一章快还是慢？应有变化

## 阶段二：写中执行（写作过程中实时注意）

### 硬约束 1：禁用词清单（写中写后双重检查）

**绝对禁止**（出现即替换）：
```
然而、此外、总而言之、值得注意的是、显而易见、众所周知
一定程度上、某种程度上、或多或少、某种程度
说到底、顿时、不知不觉、不禁、暗自、恍然大悟、殊不知、说来也巧
```

**AI词浓度控制**：
| 词汇 | 单章上限 | 替代方案 |
|------|----------|----------|
| `像`（比喻） | ≤1 | 如同/如/直接描写 |
| `突然` | ≤1 | 一下子/忽地/冷不丁/猛然/骤然 |
| `微微` | ≤1 | 扬了扬/蹙了蹙/颤了颤/泛红/缩了一下 |
| `沉默` | ≤1 | 没说话/安静了X秒/顿了X秒 |
| `感觉` | ≤1 | 具体感官描写 |
| `嘴角` | ≤1 | 笑了/笑起来/唇边 |
| **全章AI词总数** | **<10** | 超标→必须润色 |

### 硬约束 2：必需元素清单

每章必须包含：
- **具体动词**（不是"走"而是"踱步/踉跄/疾步"）
- **感官细节**（视觉/听觉/触觉/嗅觉/味觉至少2种）
- **潜台词**（对话不是信息交换，是博弈）
- **行动细节**（不用形容词定义人物，用行动）

### 技法 1：去人机味三板斧

1. **结论句打碎**：不说"明白/意识到/觉得/可惜/原来"，用行为→细节→暗示让读者自己悟
2. **无用细节**：每500字加1个偏离主线但真实的小细节（跟剧情无关但真实）
3. **认知偏差**：角色可以理解错事情，不要上帝视角理性人

**量化标准**：
- 删20%解释句
- 30%直白情绪改成动作
- 10%加真实细节

### 技法 2：对话即战场（5铁律）

1. **潜台词**——说什么≠想什么
2. **节奏**——短句=高张力，长段=释放
3. **说话指纹**——只看文字知道谁说的。换个人说也成立？→重写
4. **不说破**——让角色自己悟
5. **对话即行动**——删掉这句对话剧情会变吗？不会→删

### 技法 3：场景张力（6种微冲突）

每章至少1个场景使用以下微冲突：

| 类型 | 说明 |
|------|------|
| 信息差 | 角色知道读者不知道的事 |
| 行动矛盾 | 做的事和想要的相反 |
| 两难 | 两个选项都不好 |
| 信任裂缝 | 合作的人出现猜疑 |
| 时间压力 | 限定时间必须完成 |
| 价值观冲突 | 信念受到挑战 |

### 技法 4：好坏对比示例（写前扫一眼）

**情绪描写**：
- ❌ "她感到无比悲伤，眼泪流了下来"
- ✅ "她把他的杯子洗了第三遍。水已经凉了，她还在搓"

**人物关系**：
- ❌ "他们感情很好，互相关心"
- ✅ "他记得她不吃香菜。每次点外卖都备注'不要香菜，多放醋'"

**对话**：
- ❌ "我很担心你。"他说
- ✅ "吃饭没？"他发了条消息。五分钟后："没吃的话，我给你带了。"

### 技法 5：速度句法

- 想加速→短句/碎片句/无主语句
- 想减速→长句/感官描写
- 想停顿→单句成段
- 想冲击→极短段+大段空白

### 节奏：500字爽点公式

- 500字一个小爽点（对话反转/信息揭露/意外事件）
- 1000字一个大爽点（冲突爆发/身份揭示/权力翻转）
- 2万字一个爆点（重大转折/格局洗牌/情感突破）

### 长篇字数要求

- **≥3500字**（硬性要求，写完后必须验证）

## 阶段三：写后校验（写完后必须执行）

### 校验 1：结构检查

```json
{
  "word_count": {"actual": ?, "min": 3500, "passed": true/false},
  "has_opening": true/false,
  "has_development": true/false,
  "has_climax": true/false,
  "has_cliffhanger": true/false
}
```

### 校验 2：红线系统全检

| 红线级别 | 检查项 | 处理 |
|----------|--------|------|
| **一级** | 原创性、人称、性别/姓名 | 触发→重写 |
| **二级** | 风格漂移、人物OOC、剧情矛盾、伏笔丢失 | 触发→修正 |
| **三级** | 章节推进、字数≥3500、结构完整、章末钩子 | 触发→改进 |
| **四级** | AI词浓度、标题匹配、对话差异化 | 触发→自动替换 |

### 校验 3：禁用词扫描

- [ ] 禁用词清单中词汇出现次数 = 0
- [ ] AI限制词未超单章上限
- [ ] 全章AI词总数 < 10

### 校验 4：章末钩子（7种选1）

1. **高压开场钩**
2. **剧情错位钩**
3. **对话断句钩**："其实……我那天不是想杀他，而是——"
4. **动作未完成钩**："门被她推开的那一刻——"
5. **新设定钩**："原来他不是她杀的第一个人。"
6. **情绪高潮钩**
7. **留白反转钩**

### 校验 5：virtual-reader 8维度评分

| 维度 | 权重 | 评分(1-10) | 备注 |
|------|------|-----------|------|
| 开篇吸引力 | 15% | | 前300字是否抓人 |
| 节奏把控 | 15% | | 张弛有度，不拖沓 |
| 人设讨喜度 | 15% | | 角色是否立体讨喜 |
| 逻辑自洽 | 10% | | 情节是否合理 |
| 情绪渲染 | 15% | | 是否能调动读者情绪 |
| 文字质量 | 10% | | 流畅度、画面感 |
| 创新性 | 10% | | 是否有新意 |
| 付费意愿 | 10% | | 是否愿意付费继续阅读 |

**综合评分** = Σ(维度评分 × 权重)

**评级**：
- 90-100：S级（头部作品）
- 80-89：A级（优质）
- 70-79：B级（合格）
- 60-69：C级（需大改）
- <60：D级（重写）

### 校验 6：去人机味三板斧复扫

- [ ] 有没有"明白/意识到/觉得/可惜/原来"等结论句？→打碎
- [ ] 有没有连续500字没有无用但真实的细节？→补充
- [ ] 有没有角色表现得像上帝视角的理性人？→加认知偏差

### 校验 7：伏笔台账更新

- 新埋了伏笔→记录（内容、章节、计划回收章节）
- 回收了伏笔→标注已回收
- 检查超过5章未回收的伏笔数量（应≤3个）

## 失败处理机制

| 级别 | 定义 | 示例 | 处理 |
|------|------|------|------|
| **Critical** | 致命问题 | 世界观矛盾、人物严重OOC、缺少必须伏笔推进、情节完全无推进 | 重新生成 |
| **Minor** | 轻微问题 | 句子长度略超标、对话比例偏差、抽象词略多 | 局部修复 |
| **Info** | 优化建议 | 文字润色、细节增强 | 可选优化 |
