# 常识与专业知识校验

**版本**：2.0.0
**创建日期**：2026-04-24
**更新**：2026-04-25 — 升级为双层系统（防错层 + 真实感增强层）

---

## 一、核心原则

> **不要写"专业知识"，要写"人在规则里的行动方式"。**
> **写"流程和限制"，不要写"术语和参数"。**

AI 在写不熟悉的专业领域时，会"编一个听起来合理的解释"。这个解释在文学上合理，但在专业上错误。

解决思路不是查资料堆术语，而是**写人怎么在规则里做事**——失败、限制、选择，这些谁都能写对，而且比术语更有真实感。

---

## 二、双层系统

| 层 | 目标 | 手段 |
|------|------|------|
| **防错层** | 不要写错 | 宁模糊勿错、不编法条/数值/参数 |
| **真实感增强层** | 写得像行内人 | 写流程+限制+失败+选择 |

### 对比示例

```
❌ 假专业："他快速调出系统后台，输入一段代码绕过防火墙。"
❌ 太具体："他用 iptables 规则修改了 TCP 端口转发……"（容易错，读者也不懂）
✅ 推荐：
    他试了两次，都被挡了回来。
    第三次，他没再碰那个入口。
    换了个地方进去。
```

推荐写法的特点：有过程、有失败、有选择、不靠术语。

---

## 三、高风险领域（防错层）

当章节涉及以下领域时，**必须**在写后进行专业校验：

| 领域 | 校验重点 | 常见错误 |
|------|----------|----------|
| **法律** | 法律位阶（法律>行政法规>部门规章>地方性法规）、诉讼程序 | 把部门规章当法律、搞错起诉/应诉流程 |
| **医疗** | 症状表现、药物作用、检查流程 | 把不同疾病的症状混用、药物作用夸张 |
| **财务** | 报表结构、成本核算、税务规则 | 搞错成本构成、税务计算错误 |
| **物理** | 物体运动、声音传播、光线效果、重力 | 不符合基本物理规律 |
| **技术** | 软件功能、网络操作、硬件能力 | AI 臆造不存在的功能 |
| **时代** | 2026年的现实：手机支付、扫码、APP、短视频 | 写出不属于这个时代的行为 |

### "宁模糊勿错"原则

| 错误写法（具体的错误） | 模糊但正确的写法 |
|------------------------|------------------|
| "根据《刑法》第243条……"（法条号错了） | "根据相关法律规定……" |
| "她的血清素水平升高了30%"（数值编造） | "她的情绪明显好转" |
| "他用了三行 Python 代码破解了防火墙"（技术不可能） | "他用自己的方法绕过了限制" |

### 写中遵守

- **不编造具体法条号**——不确定时写"相关法律"
- **不编造具体医学数值**——不确定时写定性描述
- **不编造不存在的功能**——不确定时写结果不写过程
- **角色的专业行为要符合职业常识**——律师不会像医生一样诊断，医生不会像工程师一样分析

## 四、真实感增强（核心）

### 4.1 动作真实化公式

```
动作 = 目标 + 身体限制 + 环境限制
```

```
❌ AI动作："他迅速冲过去，一把抓住对方。"
✅ 人味动作：
    他往前冲了一步。
    地上有水，鞋底滑了一下。
    他扶了一下墙，才伸手。
```

关键：有阻力、有调整、有不顺。

### 4.2 职业行为流模板

写任何职业场景时，必须体现以下至少两项：

| 要素 | 说明 | 示例（物业） |
|------|------|-------------|
| **日常动作** | 这个职业每天重复的事 | 先看业主群消息，已经99+了 |
| **工作限制** | 不能随便做什么 | 没有执法权，只能劝阻 |
| **决策方式** | 靠经验/流程/上级？ | 翻制度手册，看这条归谁管 |
| **压力来源** | 时间/责任/风险？ | 群里业主在骂，领导在催 |

```
❌ 假写法："物业经理冷静分析情况。"
✅ 真写法：
    他没先说话。
    先看了一眼群消息。
    已经99+了。
    他把手机扣在桌上。
```

### 4.3 2026行为增强模板

写现代场景时，必须包含至少一个"数字痕迹"：

| 类别 | 可用的细节 |
|------|-----------|
| **手机行为** | 看消息/撤回/已读不回/电量焦虑 |
| **群聊互动** | 截图/转发/潜水/@所有人 |
| **平台行为** | 短视频/外卖扫码/打车APP/社区团购 |
| **数字痕迹** | 订单记录/聊天截图/浏览历史/已读标记 |

```
❌ 普通写法："大家开始讨论。"
✅ 人味写法：
    群里先是没人说话。
    然后有人发了张截图。
    接着是三个"？"
    再然后，一下子刷起来了。
```

目标：让时代不是背景，而是"正在发生"。

## 五、物理逻辑校验

- 人在紧张时不会"优雅地"做动作
- 跑动后呼吸受影响，不能立刻说出长句子
- 物体的重量/体积限制了人的携带能力
- 声音在空旷空间和密闭空间中传播不同
- 门是开着还是关着？锁着还是没锁？
- 人物从一个地方到另一个地方需要时间

## 六、时代常识校验

### 6.1 2026年基准

| 类别 | 常识 |
|------|------|
| 支付 | 手机扫码支付是常态，现金使用频率低 |
| 通讯 | 微信是主要通讯工具，短信少用 |
| 社交 | 群聊、朋友圈、短视频是主要社交载体 |
| 物业 | 业主微信群是主要沟通渠道 |
| 购物 | 外卖、快递、社区团购是常态 |
| 娱乐 | 短视频、直播、游戏、网文 |

### 6.2 不属于2026年的事物

| 不该出现的 | 该用替代 |
|------------|----------|
| 拨号上网 | 5G/光纤 |
| MP3播放器 | 手机/蓝牙耳机 |
| "发微博"作为主要社交 | 发微信/朋友圈 |
| 用座机打电话 | 手机/视频通话 |

## 七、四步写作流程

### 1️⃣ 写前（标记领域）

- 本章是否涉及专业领域？（法律/医疗/技术等）
- 是否涉及复杂动作场景？
- 是否涉及特定职业的工作场景？

标记后在约束组装阶段加载对应校验规则。

### 2️⃣ 写中（控制真实感）

只记三件事：

- 有没有失败？
- 有没有限制？
- 有没有选择？

### 3️⃣ 写后（防错）

- [ ] 本章涉及的专业领域是否已标记？
- [ ] 引用的专业知识是否有不确定之处？
- [ ] 是否有"宁模糊勿错"需要处理的段落？
- [ ] 动作描写是否符合物理逻辑？
- [ ] 时代背景是否有常识错误？

### 4️⃣ 增强（关键一步）

- [ ] 有没有"像行内人"的行为？（日常动作/工作限制）
- [ ] 有没有"现实中的麻烦感"？（失败/限制/选择）
- [ ] 有没有至少一个数字痕迹？（手机/群聊/平台/订单）
