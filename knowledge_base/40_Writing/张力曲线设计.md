# 张力曲线设计

**版本**：1.0.0
**创建日期**：2026-04-24
**解决问题**：#34 高潮平淡缺张力、#35 铺垫过长不进入主线

---

## 一、张力的本质

张力不是"写得激烈"，而是**读者同时看到两个互相冲突的可能性**。张力来自：

1. **信息差**——读者知道角色不知道，或角色知道读者不知道
2. **时间压力**——必须在某个时间点前做出选择/行动
3. **两难选择**——不是"好vs坏"的选择，而是"好vs好"或"坏vs坏"

---

## 二、高潮场景设计模板

### 2.1 高潮场景的三层结构

每个高潮场景必须包含三层，缺一不可：

| 层级 | 做什么 | 怎么写 |
|------|--------|--------|
| **表层冲突** | 角色在做什么 | 外部事件：争吵、对峙、表决、揭露 |
| **中层矛盾** | 角色想要什么但不能得到 | 内心欲望与外部现实的冲突 |
| **底层暗流** | 读者知道但角色不知道的东西 | 信息差、伏笔回收的预感、即将到来的转折 |

**示例**：业主大会投票（表层）→ 许知意想团结所有人但她天生不擅长这个（中层）→ 读者感觉到有人准备临时变卦但许知意还没察觉（底层）

### 2.2 张力提升技法

| 技法 | 做法 | 适用场景 |
|------|------|----------|
| **倒计时** | 明确给出剩余时间 | 表决/对峙/等待结果 |
| **信息不对称** | 让读者知道角色不知道 | 即将背叛/即将揭露 |
| **小失误** | 角色在高压力下犯一个小错 | 发言时口误、东西掉了 |
| **打断节奏** | 在关键时刻被意外打断 | 正要说出真相时被打断 |
| **沉默拉长** | 角色该说话的时候不说话 | 对峙/等待回应 |
| **转移焦点** | 冲突中插入一个日常细节 | 紧张时注意到对方的鞋带散了 |
| **不可逆选择** | 角色做出了不可撤销的决定 | 按下发送键/说出不能收回的话 |

### 2.3 禁止的高潮写法

- 禁止用形容词堆叠制造"紧张感"（"紧张的气氛弥漫在空气中"）
- 禁止让所有角色同时做正确的事（张力来自有人做错事）
- 禁止高潮中没有人付出代价（必须有损失或风险）
- 禁止高潮后没有任何余波（高潮之后必须有"余震"段落）

## 三、铺垫长度控制

### 3.1 铺垫上限规则

- 铺垫章（类型为"铺垫"的章节）连续不超过 3 章
- 如果已经铺垫了 2 章，第 3 章必须包含至少一个推进事件
- 铺垫不能只靠"角色在做准备"——每章必须有一个实质性的推进

### 3.2 进入主线的检测

每章写完后自检：

1. 如果删掉这一章，后面的剧情还能连起来吗？
   - 能 → 这一章是"可删除章节"，必须重写
   - 不能 → 通过
2. 这一章有没有至少一个新事件/新信息/新变化？
   - 没有 → 原地踏步，必须重写
   - 有 → 通过

### 3.3 铺垫效率提升

铺垫不是"什么都不发生"。高效铺垫的特点是：

- 铺垫中埋着伏笔（读者回头看才知道是伏笔）
- 铺垫中有人物关系变化（即使主线没推进，关系要推进）
- 铺垫中有小冲突（不是高潮冲突，是日常冲突）

## 四、节奏与张力的映射

### 4.1 5章节奏模板

每5章的张力分布建议：

```
章1（推进）：张力 6 — 新事件发生
章2（铺垫）：张力 4 — 准备+人物关系
章3（铺垫）：张力 5 — 准备+小冲突
章4（高潮）：张力 8-9 — 冲突爆发
章5（过渡）：张力 2-3 — 余波+新方向
```

**变体**：如果连续需要高张力（大事件期间），可以：

```
章1（推进）：7
章2（高潮）：9
章3（过渡）：4（必须有缓冲）
章4（推进）：6
章5（铺垫）：5
```

### 4.2 张力标记

每章写完时在 novel_state.json 的 rhythm_dashboard 中标注：

```json
{
  "chapter": 44,
  "type": "高潮",
  "tension": 9,
  "climax_method": "倒计时+信息不对称",
  "cost": "有人临时变卦，信任关系受损"
}
```

## 五、张力检查清单

写每个高潮/冲突场景时自查：

- [ ] 读者是否同时看到了两种冲突的可能性？（不是确定会怎样，是"可能A也可能B"）
- [ ] 有没有时间压力或两难选择？
- [ ] 有没有信息差在起作用？（读者多知道/少知道什么）
- [ ] 高潮中有没有人付出代价或冒风险？
- [ ] 高潮之后有没有"余震"段落？（至少100字描写后果）
- [ ] 有没有用具体动作/细节制造张力，而不是用形容词？
