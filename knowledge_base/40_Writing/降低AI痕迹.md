## 一、AI痕迹识别（升级版）

---

### 1.1 表层特征（可快速识别）

**高频问题：**

* 连接词过多：首先 / 其次 / 因此 / 然后
* 情绪直说：紧张 / 愤怒 / 感动
* 对话完整：问→答→回应，全闭环
* 修辞工整：排比、对仗、句式整齐
* 描写过全：像在“说明”，不是在“展示”

---

### 1.2 结构层特征（关键）

👉 这是AI最致命的问题：

* 段落长度平均
* 句式重复（主谓宾）
* 节奏恒定（无快慢变化）
* 信息均匀分布

📌 判断标准：

```id="ai_detect_01"
越“顺滑”，越可能是AI
```

---

### 1.3 认知层特征（高级识别）

* 人物不犯错
* 推理无偏差
* 情节过于合理
* 没有“误解/犹豫/停顿”

📌 核心判断：

```id="ai_detect_02"
没有“人味”的地方，就是AI味
```

---

## 二、人类化改写八大核心技法（重构版）

---

### 1️⃣ 结构破坏（最重要）

**目标：打碎“整齐感”**

```id="break_structure"
长 → 短 → 极短 → 停
```

示例：

```
AI：
他走进房间，发现桌子上有一封信，于是他打开查看。

人类：
门开了。
他看见桌子。

有封信。

他没立刻动。
```

---

### 2️⃣ 断句控制（节奏制造器）

👉 强制加入停顿：

* 单句成段
* 半句断开
* 非完整表达

示例：

```
他说了很多。

其实没重点。
```

---

### 3️⃣ 行为替代情绪（核心）

```
❌ 他很愤怒  
✓ 他把杯子放重了一点
```

规则：

```id="emotion_replace"
情绪词 → 动作 / 生理反应 / 环境反馈
```

---

### 4️⃣ 对话降级（去“剧本感”）

**三原则：**

* 不完整
* 不礼貌
* 不解释

```
AI：
“你好，请问你是谁？”

人类：
“你谁？”
```

---

### 5️⃣ 信息删减（反解释机制）

👉 每段必须删掉：

* 解释句
* 总结句
* 因果句

规则：

```id="delete_rule"
能让读者自己懂的，全部删掉
```

---

### 6️⃣ 无效细节注入（关键人味）

👉 插入“没用但真实”的细节：

```
门卡了一下。
他用脚顶开。
```

作用：

* 增加真实感
* 打破AI效率逻辑

---

### 7️⃣ 认知偏差（人类特征）

👉 人物必须：

* 看错
* 误判
* 犹豫

```
他以为是血。

不是。
```

---

### 8️⃣ 风格扰动（防统一）

👉 同一段内允许风格变化：

* 口语 + 文学混用
* 冷静 + 情绪跳变

## 三、润色执行模型（核心升级🔥）

---

### 3.1 三阶段流水线

```id="pipeline_01"
AI初稿 → 结构破坏 → 人类注入 → 精修
```

---

### 3.2 段落改写标准（硬规则）

每一段必须完成：

```id="rule_3cuts"
① 删一句解释  
② 加一个动作  
③ 断一个句子  
```

---

### 3.3 节奏控制模型

| 场景 | 写法  |
| -- | --- |
| 动作 | 短句  |
| 紧张 | 极短句 |
| 情绪 | 稍长句 |
| 过渡 | 混合  |

---

## 四、工业级润色流程（可批量用）

---

### Step 1：扫描AI痕迹

标记：

* 连接词
* 情绪词
* 完整对话
* 长句段

---

### Step 2：结构破坏

执行：

* 打断句子
* 拆分段落
* 删除连接词

---

### Step 3：人类注入

逐段加入：

* 动作
* 感官
* 停顿
* 错误认知

---

### Step 4：语言压缩

执行：

* 删冗余
* 去解释
* 强节奏

---

## 五、反AI评分系统（升级）

---

### 五维评分

| 维度   | 标准        |
| ---- | --------- |
| 不均匀  | 长短变化明显    |
| 停顿感  | 有断裂       |
| 隐含信息 | 没说透       |
| 人类错误 | 有误判       |
| 细节纹理 | 有“没必要”的细节 |

---

### 判定标准

```id="score_rule"
≤2：强AI  
3：一般  
4：低AI  
5：接近人类  
```

## 六、自动润色Prompt（直接用🔥）

---

### 🧠 Prompt：低AI重写器

```id="rewrite_prompt"
请对以下文本进行“去AI化重写”，要求：

1. 打破句式结构（长短句混合）
2. 删除所有解释性表达
3. 将情绪改为动作/细节
4. 对话改为不完整表达
5. 插入少量“无效但真实”的细节
6. 加入停顿和断句
7. 允许人物出现误判或犹豫

目标：
让文本“不顺滑，但真实”

输出：优化后的文本
```

## 九、终极检测（专业级）

---

### 1️⃣ 朗读测试

```id="read_test"
太顺 = AI  
有卡顿 = 人类
```

---

### 2️⃣ 删减测试

```id="delete_test"
删一句还能读 → 多余  
删一句变差 → 保留
```

---

### 3️⃣ 注意力测试

👉 读的时候有没有：

* 停一下？
* 想一下？
* 误解一下？

没有 → AI味重

## 🔚 最终原则（升级版）

```id="core_rule"
人类写作的本质：
不稳定 + 不完整 + 不解释 + 有偏差
```
