## 一、AI痕迹识别（升级版）

---

### 1.1 表层特征（可快速识别）

**高频问题：**

* 连接词过多：首先 / 其次 / 因此 / 然后
* 情绪直说：紧张 / 愤怒 / 感动
* 对话完整：问→答→回应，全闭环
* 修辞工整：排比、对仗、句式整齐
* 描写过全：像在“说明”，不是在“展示”

---

### 1.2 结构层特征（关键）

👉 这是AI最致命的问题：

* 段落长度平均
* 句式重复（主谓宾）
* 节奏恒定（无快慢变化）
* 信息均匀分布

📌 判断标准：

```id="ai_detect_01"
越“顺滑”，越可能是AI
```

---

### 1.3 认知层特征（高级识别）

* 人物不犯错
* 推理无偏差
* 情节过于合理
* 没有“误解/犹豫/停顿”

📌 核心判断：

```id="ai_detect_02"
没有“人味”的地方，就是AI味
```

---

## 二、人类化改写八大核心技法（重构版）

---

### 1️⃣ 结构破坏（最重要）

**目标：打碎“整齐感”**

```id="break_structure"
长 → 短 → 极短 → 停
```

示例：

```
AI：
他走进房间，发现桌子上有一封信，于是他打开查看。

人类：
门开了。
他看见桌子。

有封信。

他没立刻动。
```

---

### 2️⃣ 断句控制（节奏制造器）

👉 强制加入停顿：

* 单句成段
* 半句断开
* 非完整表达

示例：

```
他说了很多。

其实没重点。
```

---

### 3️⃣ 行为替代情绪（核心）

```
❌ 他很愤怒  
✓ 他把杯子放重了一点
```

规则：

```id="emotion_replace"
情绪词 → 动作 / 生理反应 / 环境反馈
```

---

### 4️⃣ 对话降级（去“剧本感”）

**三原则：**

* 不完整
* 不礼貌
* 不解释

```
AI：
“你好，请问你是谁？”

人类：
“你谁？”
```

---

### 5️⃣ 信息删减（反解释机制）

👉 每段必须删掉：

* 解释句
* 总结句
* 因果句

规则：

```id="delete_rule"
能让读者自己懂的，全部删掉
```

---

### 6️⃣ 无效细节注入（关键人味）

👉 插入“没用但真实”的细节：

```
门卡了一下。
他用脚顶开。
```

作用：

* 增加真实感
* 打破AI效率逻辑

---

### 7️⃣ 认知偏差（人类特征）

👉 人物必须：

* 看错
* 误判
* 犹豫

```
他以为是血。

不是。
```

---

### 8️⃣ 风格扰动（防统一）

👉 同一段内允许风格变化：

* 口语 + 文学混用
* 冷静 + 情绪跳变

## 三、润色执行模型（核心升级🔥）

---

### 3.1 三阶段流水线

```id="pipeline_01"
AI初稿 → 结构破坏 → 人类注入 → 精修
```

---

### 3.2 段落改写标准（硬规则）

每一段必须完成：

```id="rule_3cuts"
① 删一句解释  
② 加一个动作  
③ 断一个句子  
```

---

### 3.3 节奏控制模型

| 场景 | 写法  |
| -- | --- |
| 动作 | 短句  |
| 紧张 | 极短句 |
| 情绪 | 稍长句 |
| 过渡 | 混合  |

## 九、32项AI味精准检测指标（工业级）

> 量化检测体系，30+指标可评分、可落地。来源：novel-review技能体系。

### 第一类：语言特征（10项）

| 指标 | AI特征 | 检测方法 | 异常阈值 |
|------|--------|----------|----------|
| 1.句式单一 | AI倾向中等长度句（15-25字），缺乏节奏变化 | 统计句子长度分布 | 中句占比>70%，或短句>50%，或长句>40% |
| 2.连接词过度 | 机械连接词："然后"/"接着"/"因此"/"但是" | 统计连接词密度 | >20个/千字 |
| 3.被动语态过多 | AI倾向被动语态（"被...所..."） | 统计被动句占比 | >15% |
| 4.并列结构重复 | "他...，他...，他..."连续堆叠 | 检测连续句子句式相似度 | 连续3句以上相同句式 |
| 5.修饰词堆砌 | "美丽的、善良的、温柔的"连续堆叠 | 统计形容词/副词密度 | >150个/千字 |
| 6.抽象词过多 | "快乐、悲伤"抽象词多，缺具体细节 | 统计抽象/具象词比例 | 抽象词占比>30% |
| 7.词汇贫乏 | "十分、非常、极其"程度副词重复 | 统计高频词重复率 | 同一程度副词连续出现3次以上 |
| 8.陈词滥调 | "不约而同地、难以置信、恍然大悟" | 检测成语和固定搭配密度 | >5个/千字 |
| 9.句尾模式化 | 多个句子以相同词结尾 | 统计连续句尾词 | 连续3句以上相同句尾 |
| 10.主语缺失/冗余 | 连续无主语，或每句重复主语 | 分析主语使用情况 | 连续5句无主语或每句重复相同主语 |

### 第二类：叙事特征（8项）

| 指标 | AI特征 | 检测方法 | 异常阈值 |
|------|--------|----------|----------|
| 11.Show vs Tell失衡 | 大量"他感到快乐"而非通过描写展现 | 统计直接描述情感的句子 | Show/Tell < 1:3 |
| 12.信息堆砌 | 大量背景设定在短时间内倾倒 | 检测开篇500字信息密度 | 信息密度超过设定值2倍 |
| 13.时间线平铺 | 事件按顺序发生，缺乏插叙/倒叙 | 分析时间标记词使用 | 90%以上线性推进 |
| 14.场景转换生硬 | "一天后、第二天"简单转场 | 分析场景转换过渡方式 | 80%以上简单时间标记 |
| 15.细节不足 | 缺少气味/触觉/声音等感官描写 | 统计感官词汇数量 | <10个/千字 |
| 16.对话公式化 | 多角色对话风格相似，缺乏个性 | 分析不同角色对话差异 | 对话相似度>80% |
| 17.内心独白过多 | 长篇内心独白解释角色动机 | 统计心理描写段落长度 | 平均长度>200字 |
| 18.悬念缺失 | 章节结尾平淡，缺乏悬念 | 分析章节结尾句式和内容 | 悬念设置率<30% |

### 第三类：逻辑特征（6项）

| 指标 | AI特征 | 检测方法 | 异常阈值 |
|------|--------|----------|----------|
| 19.因果简化 | 事件A→结果B过于直接，缺乏中间环节 | 分析因果关系链复杂度 | 平均长度<2环节 |
| 20.角色行为公式化 | 角色行为基于"应该做"而非"想做" | 分析动机类型多样性 | 单一动机>80% |
| 21.冲突解决轻易 | 关键问题轻松解决，缺乏波折 | 统计冲突解决步骤难度 | 主要冲突<3步 |
| 22.巧合过多 | 关键转折依靠巧合而非必然 | 分析事件概率合理性 | 巧合占比>30% |
| 23.伏笔缺失 | 重要事件无铺垫，突然发生 | 分析重要事件是否有暗示 | 无铺垫率>40% |
| 24.结尾仓促 | 关键线索未交代，匆忙收尾 | 分析结局章节完整度 | 未交代线索>3条 |

### 第四类：情感特征（4项）

| 指标 | AI特征 | 检测方法 | 异常阈值 |
|------|--------|----------|----------|
| 25.情感浅表 | 情绪停留表面，缺乏层次 | 分析情感描写层次感 | 层次单一（无复杂情感） |
| 26.情感转换生硬 | 情绪突然转换，无渐进过程 | 分析情绪转换过渡 | 无过渡率>50% |
| 27.共鸣点缺失 | 难以让读者产生代入感 | 分析共鸣场景密度 | <1个/10章 |
| 28.台词尴尬 | 角色说的话像"写出来的"而非"说出来" | 分析对话口语化程度 | 口语化程度<40% |

### 第五类：创意特征（4项）

| 指标 | AI特征 | 检测方法 | 异常阈值 |
|------|--------|----------|----------|
| 29.情节套路化 | 使用常见套路，缺乏创新 | 与套路库对比 | 套路化程度>60% |
| 30.角色扁平化 | 性格单一，缺乏矛盾和成长 | 分析性格维度数量 | 性格维度<3个 |
| 31.设定常规化 | 世界观与现有作品相似 | 与设定库对比 | 创新度<20% |
| 32.表达模板化 | 描写/比喻/对话都像"标准模板" | 检测表达方式多样性 | 重复率>50% |

### AI味综合评分

**评分规则**：加权平均
- 语言特征：30%
- 叙事特征：25%
- 逻辑特征：20%
- 情感特征：15%
- 创意特征：10%

**等级判定**：
| 分数 | 等级 | 评价 | 处理 |
|------|------|------|------|
| 0-2 | 🟢 无明显AI味 | 人工写作特征明显 | 可直接发布 |
| 3-4 | 🟢 轻微AI味 | 可能有AI辅助，有人工修改 | 轻度润色 |
| 5-6 | 🟡 中度AI味 | 明显AI特征，需深度修改 | P1级，需修改 |
| 7-8 | 🟠 高度AI味 | AI痕迹明显，需全面重写 | P0级，需重写 |
| 9-10 | 🔴 严重AI味 | 几乎纯AI生成 | 建议重写 |

**对表现力评分的影响**：
- AI味≥7分 → 表现力扣5分
- AI味5-6分 → 表现力扣2分
- AI味3-4分 → 表现力扣1分

## 十、21项AI味去除方法（带❌→✅案例）

> 针对32项检测指标的具体去除策略，5大类21方法，每项都有❌→✅改造示例。来源：novel-review技能体系。

### 语言层面（6方法）

**方法1：打破句式单一**
- ❌ AI式：他走进了房间，然后看到了桌子上的书，接着拿起来看了一会儿，最后觉得很不错。
- ✅ 改造：他走进房间。桌上摊着一本书，他顺手拿了起来。翻了几页后，嘴角勾了起来。
- 技巧：短句<40%（强调/快速推进），中句40-60%（叙事），长句<20%（描写/情感）

**方法2：减少机械连接词**
- ❌ AI式：因为他很生气，所以他大声吼道。
- ✅ 改造：他怒不可遏，吼声炸响。
- 技巧：用动作代替"然后"，用神态代替"因为...所以..."，用环境代替"但是"

**方法3：增强感官描写**
- ❌ AI式：他感到很害怕。
- ✅ 改造：冷汗顺着脊背滑下，心脏狂跳得像要撞破胸膛。

**方法4：减少抽象词，增加具象词**
- ❌ AI式：她很美丽。
- ✅ 改造：她的眼睛像湖水般清澈，长发垂在肩头，阳光下泛着金色的光泽。

**方法5：丰富词汇，避免重复**
- ❌ AI式：他十分高兴，非常开心，极其兴奋。
- ✅ 改造：他嘴角上扬，眼中闪烁着光芒，浑身充满活力。

**方法6：去除陈词滥调**
- ❌ AI式：他恍然大悟。
- ✅ 改造：他猛地拍了一下大腿："原来如此！"

### 叙事层面（5方法）

**方法7：Show, Don't Tell**
- ❌ AI式：他感到很悲伤。
- ✅ 改造：他盯着窗外，眼眶泛红，喉咙像堵了一团棉花。

**方法8：优化信息暴露节奏**
- ❌ AI式：这是一个魔法世界，有五大元素，分别是火、水、木、金、土。主角小明是一个火系法师...
- ✅ 改造：（随剧情展开）他看着手中的火焰——这是他觉醒三个月的火元素之力。

**方法9：增加场景细节**
- ❌ AI式：他来到了森林里。
- ✅ 改造：踏入森林，阳光被茂密的树冠筛成细碎的光斑，脚下的落叶发出沙沙声。

**方法10：优化对话真实性**
- ❌ AI式："我很生气，因为你不尊重我。"
- ✅ 改造："你当我是傻子吗？"他猛地站起来，胸口剧烈起伏。

**方法11：增加悬念和钩子**
- ❌ AI式：第二天，他来到了学校。
- ✅ 改造：第二天，当他推开教室门时，所有人都安静了下来——黑板上写着他的名字。

### 逻辑层面（4方法）

**方法12：强化因果关系**
- ❌ AI式：他很努力，所以成功了。
- ✅ 改造：他每天练习到凌晨，手指磨出了茧，终于在比赛中获得了冠军。

**方法13：增加波折和阻碍**
- ❌ AI式：他解决了问题。
- ✅ 改造：他尝试了三种方法都失败了，直到第四种方法才奏效，但又遇到了新问题...

**方法14：合理化角色行为**
- ❌ AI式：他决定去冒险。
- ✅ 改造：看着母亲日渐佝偻的背影，他攥紧了拳头——这是唯一的机会，但成功的概率微乎其微。他在房间里来回踱步，直到天亮。

**方法15：铺垫伏笔**
- ❌ AI式：他突然发现了真相。
- ✅ 改造：（前文伏笔）他总觉得那个锁有些奇怪...（真相揭晓）原来钥匙就藏在锁里！

### 情感层面（3方法）

**方法16：增加情感层次**
- ❌ AI式：她很爱他。
- ✅ 改造：她有时候讨厌他的固执，有时候又心疼他的逞强，但每次想到分开，心里就像被挖了一块。

**方法17：渐进式情感转换**
- ❌ AI式：他原谅了她。
- ✅ 改造：他冷冷地看着她，眼神逐渐软化，最后叹了口气："算了。"

**方法18：增强代入感**
- ❌ AI式：他感到很紧张。
- ✅ 改造：手心全是汗，他在裤子上擦了又擦，还是止不住地颤抖。

### 创意层面（3方法）

**方法19：突破套路**
- ❌ AI式：英雄打败了魔王，拯救了世界。
- ✅ 改造：他发现魔王其实是被迫的，真正的反派是...

**方法20：增加角色矛盾**
- ❌ AI式：他是一个勇敢的英雄。
- ✅ 改造：他表面上无所畏惧，但深夜里总会想起那次失败...

**方法21：独特化表达**
- ❌ AI式：他大声喊道。
- ✅ 改造：声音冲破喉咙，在空旷的房间里回荡。

## 🔚 最终原则（升级版）
