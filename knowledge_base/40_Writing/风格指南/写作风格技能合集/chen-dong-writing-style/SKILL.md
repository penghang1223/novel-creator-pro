# 辰东写作风格 Skill

> **作者定位**：起点中文网白金作家，玄幻悬疑流开创者
> **代表作**：《神墓》《遮天》《完美世界》《圣墟》
> **核心地位**：宏大世界观构建宗师、悬念流开山鼻祖、挖坑填坑大师

---

## 一、风格概述

### 1.1 核心基因

辰东的文风是**"史诗+悬疑+热血"**的三位一体，区别于其他玄幻作家的核心差异在于：

| 维度 | 传统玄幻 | 辰东风格 |
|------|---------|---------|
| 世界观 | 单一世界/位面 | 跨越古今未来、诸天万界 |
| 悬念 | 打怪升级为主 | 层层揭秘、谜底最后揭开 |
| 伏笔 | 短期埋设 | 长线铺垫、百万字回收 |
| 哲学 | 较少涉及 | 生死轮回、因果宿命贯穿 |
| 战斗 | 招式描写 | 宏大场面+气势渲染 |

### 1.2 标志性特色

```
【辰东标志清单】
✦ 开头即入谜——首章抛出惊天悬念
✦ 世界观倒叙——从宏大格局切入个人命运
✦ 死亡不是终点——死人也能复活、因果必偿
✦ 逆天改命——主角永远在对抗宿命
✦ 诸天万界——地图不断扩展、格局层层拔高
✦ 悬念套悬念——一个谜题解开引出更大的谜
```

## 二、核心技法总结

### 2.1 五大技法体系

| 技法 | 核心要点 | 适用场景 |
|------|---------|---------|
| **世界观构建** | 三层结构（诸天+纪元+因果） | 开篇定调、世界拓展 |
| **悬念流技法** | 问句驱动、信息释放节奏 | 情节推进、章节结尾 |
| **挖坑填坑** | 伏笔标记法、回收触发点 | 长线布局、高潮设计 |
| **东方哲学** | 轮回观+宿命论+因果律 | 主题深化、情感渲染 |
| **热血战斗** | 气势堆叠+对比反衬 | 战斗场景、情绪高潮 |

### 2.2 技法使用口诀

```
【开篇】先抛悬念，世界观徐徐展开
【中期】坑越挖越深，谜面越来越大
【高潮】填坑要狠，一口气回收所有伏笔
【战斗】气势先行，主角永远以弱胜强
【哲学】生死轮回，因果循环贯穿始终
```

## 三、使用方法

### 3.1 调用流程

```
1. 确定需求场景
   ├─ 开篇设计 → 参考 epic-world.md + suspense-flow.md
   ├─ 世界观拓展 → 参考 epic-world.md
   ├─ 悬念设计 → 参考 suspense-flow.md
   ├─ 伏笔埋设 → 参考 foreshadowing.md
   ├─ 哲学表达 → 参考 eastern-philosophy.md
   └─ 战斗场景 → 参考 text-generator.md 战斗模板

2. 按需调用 references 文件获取技法细节

3. 使用 text-generator.md 的模板生成具体内容
```

### 3.2 风格适配检查

使用本skill创作时，确保满足以下检查项：

- [ ] 开头前300字是否抛出悬念/谜题？
- [ ] 世界观是否具有"跨越性"（时间/空间/位面）？
- [ ] 是否有至少3层以上的悬念嵌套？
- [ ] 伏笔是否设置了明确的回收触发点？
- [ ] 是否融入生死/轮回/宿命元素？
- [ ] 战斗场景是否有气势堆叠和对比反衬？

## 五、版权与使用

- **适用类型**：玄幻、仙侠、东方幻想
- **适配题材**：史诗级世界观、长篇连载、多宇宙叙事
- **风格融合**：可与"热血战斗流"、"系统流"结合
- **禁忌提示**：不适合都市重生、系统无敌等快节奏类型
