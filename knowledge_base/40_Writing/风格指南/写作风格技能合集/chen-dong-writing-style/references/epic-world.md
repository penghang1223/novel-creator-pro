# 史诗级世界观构建技法

> 辰东的世界观不是"搭建"出来的，而是"揭开"出来的。从废墟中看到文明，从残骸中追溯辉煌。

---

## 一、三层世界结构

### 1.1 核心框架：诸天-纪元-因果

辰东式世界观的标志性结构：

```
┌─────────────────────────────────────────────────────┐
│                    【第一层：诸天万界】               │
│         无数星域、仙域、混沌海、堕落王族             │
│         主角视角从一域拓展到诸天                     │
├─────────────────────────────────────────────────────┤
│                    【第二层：纪元轮回】               │
│         上古纪元→当前纪元→未来纪元                   │
│         每个纪元都有文明兴衰、上苍沉浮               │
├─────────────────────────────────────────────────────┤
│                    【第三层：因果宿命】               │
│         一切皆因果，宿命纠缠、生死轮回               │
│         终极谜题的答案藏在第一层废墟中               │
└─────────────────────────────────────────────────────┘
```

### 1.2 《遮天》世界结构解析

| 层级 | 内容 | 体现方式 |
|------|------|---------|
| 诸天 | 北斗星域、荒古禁地、成仙路 | 地图拓展、强者分布 |
| 纪元 | 荒古、太古、上古、神话时代 | 历史碎片、遗迹线索 |
| 因果 | 九龙拉棺、红毛真相、天帝因果 | 终极谜题、轮回伏笔 |

## 二、开篇定调技法

### 2.1 废墟开场法

**技法核心**：不以"世界设定"介绍世界，而是通过**废墟/遗迹/传说**让读者自己感知世界之大。

```
【辰东式开头模板】

"天地间最古老的传说，发生在末世降临之前。
  那时的诸天万界，还没有名字。
  那时的仙域九十九重天，还未被埋葬。
  直到那一日，轮回尽头，有人回首……"

【技法解析】
├─ 不说"这是一个修仙世界"
├─ 而说"末世降临之前"的辉煌已被埋葬
├─ 用否定句式（还没有、未曾）暗示宏大
└─ 用"轮回尽头"点题哲学基调
```

### 2.2 传说倒叙法

**技法核心**：用"后人传言/古籍记载"的方式，将世界格局"说"出来。

```
【模板】

"据神话时代遗留的古籍记载——
  在那个璀璨到极致的年代，
  有九位天帝共掌诸天，
  有无上仙王独断万古。
  然而，一切辉煌都终结于一场无人知晓的灾变。
  那些名字，被从时间长河中抹去。
  那些真相，被埋葬在诸天最深处的……【某个地点】。"

【技法要点】
├─ 用"古籍/传说/后人记载"做世界介绍
├─ 重点信息用"无人知晓/被抹去"制造神秘感
└─ 结尾指向具体地点，引导探索
```

## 三、世界拓展节奏

### 3.1 地图拓展公式

```
【第一阶段】困于一域
  → 主线：成长、复仇、觉醒
  → 世界：只有主角所在之地

【第二阶段】触碰到壁
  → 触发：发现超出认知的遗迹/强者/真相
  → 世界：出现"界外有界"的暗示

【第三阶段】踏入诸天
  → 事件：跨越某道界限
  → 世界：诸天万界的大门打开

【第四阶段】追溯纪元
  → 发现：当前世界的文明只是上一个纪元的残骸
  → 世界：时间线拓展到上古/神话

【第五阶段】因果浮现
  → 核心：主角的命运与纪元覆灭有关
  → 世界：终极真相浮出水面
```

### 3.2 世界扩展信号词

| 阶段 | 信号词 | 示例 |
|------|--------|------|
| 触碰壁垒 | "传说之外..." | 传说之外的禁地开启 |
| 踏入诸天 | "横渡星海..." | 横渡星海，见识万域 |
| 追溯纪元 | "神话时代..." | 神话时代的遗迹出土 |
| 因果浮现 | "轮回之前..." | 轮回之前的因果纠缠 |

## 四、位面与势力设计

### 4.1 经典位面结构

```
【辰东式位面体系】
┌─ 仙域体系 ─────────┐
│  堕落仙域（被污染）  │
│  九天十地（当前）    │
│  彼岸（边界之地）    │
├─ 禁区体系 ─────────┤
│  生命禁地（不可入）  │
│  绝地（入者必死）    │
│  轮回之地（生死交界）│
├─ 势力体系 ─────────┤
│  荒古世家（底蕴深厚）│
│  太古王族（来历史上古）│
│  禁区至尊（沉睡的至强者）│
└─────────────────────┘
```

### 4.2 势力命名法则

```
【命名公式】：时间词 + 特征词 + 势力类型

时间词：荒古、太古、神话、上古、远古、开天
特征词：圣、仙、神、天、禁忌、堕落、永恒
势力类型：世家、王族、皇朝、帝族、禁区、不朽

【示例】
├─ 荒古世家（姜家、神朝姬家）
├─ 太古王族（黄金族、不死天皇）
├─ 神话禁区（仙王埋骨地）
└─ 永恒禁地（葬天葬地葬己身）
```

## 五、世界观融入情节

### 5.1 世界即悬念

**核心思路**：不要把世界观"讲"给读者，而是让读者在追寻答案的过程中"发现"世界。

```
【错误示范】
"这个世界分为九天十地，每一地都有守护者..."

【辰东式处理】
"直到他踏入那道门户，
  才发现所谓'九天十地'，
  不过是囚笼的名字。"

→ 用疑问引导：为什么是囚笼？
→ 用否定制造神秘：不止九天？
```

### 5.2 遗迹叙事法

**核心思路**：让遗迹/废墟自己讲述历史，而不是旁白叙述。

```
【模板场景】

他踏入古殿，脚下是碎裂的玉砖。
空气中残留的灵气告诉他——
这里曾经是一位仙王的道场。

殿中央，一具枯骨端坐。
枯骨的手中，握着一卷残破的古经。
古经上只有一句话清晰可辨：

"……万古之后，因果偿时，【某角色名】必归……"

【技法要点】
├─ 用感官描写代替直接介绍
├─ 用遗迹细节暗示辉煌过去
├─ 用文字/遗言设置悬念钩子
└─ 角色名是关键——暗示与主角有关
```

## 六、世界观检查清单

```
【世界观自检】
├─ [ ] 是否有"诸天万界"的宏大感？
├─ [ ] 是否有时间跨度的暗示（纪元/轮回）？
├─ [ ] 是否通过废墟/遗迹而非旁白展现世界？
├─ [ ] 是否有因果宿命的哲学内核？
├─ [ ] 位面/势力命名是否体现东方美学？
└─ [ ] 世界观是否与主角命运绑定？
```
