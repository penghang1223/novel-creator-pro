## 五、模板使用指南

### 5.1 选择原则

| 需求 | 推荐模板 |
|------|---------|
| 开篇定调 | 废墟悬念型 / 宿命轮回型 |
| 战斗高潮 | 以弱胜强型 / 群战型 |
| 世界拓展 | 古殿探索型 |
| 哲学升华 | 轮回之地型 |
| 情感爆发 | 因果对话型 / 宿命对话型 |
| 章节收尾 | 悬念式 / 反转式 |

### 5.2 模板改编技巧

```
【技巧一：替换核心词】
原文："叶凡" → 改为你的主角名
原文："荒古禁区" → 改为你的专属地点

【技巧二：调整情绪基调】
紧张压抑 → 增加环境描写（阴暗、血腥）
热血激昂 → 增加气势描写（天变、地裂）
悲伤沉重 → 增加情感描写（回忆、泪水）

【技巧三：融入个人设定】
世界观不同 → 替换"天帝"等概念
力量体系不同 → 替换"准帝"等境界
```

当这句话从他口中说出时，
他自己都不知道，
这究竟是承诺，还是诅咒。

他叫辰轩。
一个不该存在于这个时代的人。

三百年前，他是诸天公认的天才。
二十年前，他死于一场惊天阴谋。
三年前，他从一座无名古墓中醒来。

但最让他困惑的，不是死亡与重生。

而是——

每当他闭上眼，
就会看见一个女子的脸。

那张脸，他从未见过。
但心，却在剧烈地跳动。

仿佛有什么东西，在血脉中呼唤。

“辰轩……归来……”

那个声音，越来越清晰。

直到那一日，他终于找到了声音的来源。

——那座古墓的深处，
　有一具封印万年的棺椁。

棺椁之上，刻着四个大字：

“辰家祖墓。”

而辰家，早在万年前就已灭族。
