# 烽火戏诸侯写作风格技法

## 任务目标

本 Skill 提供两大核心能力：

### 能力一：方法论指导
- 将用户的小说创作需求转化为烽火戏诸侯风格的专业创作方案

- 精准风格控制，无需额外解释

## 核心理念

### 慢热炖文
> "好酒需慢酿，好文需细炖。快刀斩不出好菜，慢火才能出真味。"

**操作步骤**：
1. 先铺垫氛围（江湖风土、人情世故）
2. 再刻画人物（性格鲜明、各有"道"）
3. 后推进剧情（冲突引爆、名场面出炉）

### 哲思为骨
> "道理不是讲出来的，是辩出来的。真正的思辨，是让角色在冲突中成长。"

**核心方法**：将儒释道哲学融入人物成长线，让思辨成为剧情推动力

### 群像为肉
> "主角是骨架，配角是血肉。没有血肉的骨架，是骷髅。"

**核心方法**：每个配角都要有自己的"道"、自己的故事、自己的高光时刻

## 操作步骤

### 1. 哲学思辨写作

调用 `references/philosophical-writing.md` 获取详细技法

**核心原则**：道理不是独白，是辩论

**核心方法**：
- 制造观点冲突：正反对立，各有道理
- 设计思辨场景：不是讲道理，是演道理
- 融入儒释道：但不生硬，用人物经历自然呈现
- 书简湖问心：陈平安的抉择，是思辨的巅峰示范

**代表场景**：
- 陈平安书简湖问心
- 李淳罡的"剑来"背后是剑道哲思
- 温华的江湖道义

### 2. 名场面设计

调用 `references/epic-scene.md` 获取详细技法

**核心原则**：名场面不是高潮，是水到渠成

**设计要素**：
- 氛围铺垫：前文大量细节积累
- 实力支撑：装逼要有资本，能力要配得上逼格
- 台词设计：短句有力，意境深远
- 留白收尾：让读者回味

**代表场景**：
- 李淳罡"剑来"：一声剑来，万剑齐发
- 徐凤年三次游历：成长线浓缩
- 温华断臂：江湖道义的极致诠释

### 3. 群像封神

调用 `references/group-masterpiece.md` 获取详细技法

**核心原则**：每个配角都是主角

**设计要素**：
- 各有"道"：每个配角都有自己的信念体系
- 各有故事：背景故事支撑人物动机
- 各有高光：专属名场面
- 与主角交织：群像不是碎片，是拼图

**代表人物**：
- 李淳罡：剑道即人道
- 温华：江湖草根的道义
- 陈芝豹：庙堂与江湖的纠葛

### 4. 慢热叙事

调用 `references/slow-burn.md` 获取详细技法

**核心原则**：慢热不是拖沓，是积累

**节奏设计**：
- 开局：氛围营造，人物出场
- 中段：细火慢炖，伏笔铺垫
- 爆发：水到渠成，名场面出炉

**核心技法**：
- 留白艺术：不说透，让读者品
- 余味悠长：章节结束，意犹未尽
- 单章无敌：每章都要有独立高光

### 5. 文本生成（直接输出）

调用 `references/text-generator.md` 获取完整生成规则

**生成模块**：
- 名场面：剑来式装逼，氛围营造，实力支撑
- 道理辩论：儒释道思辨，观点碰撞
- 江湖对话：人情世故，话里有话
- 慢热铺垫：细节积累，伏笔暗藏
- 群像高光：配角专属时刻

**核心基调**：
- 华丽典雅：文笔细腻，意境悠远
- 哲思深厚：儒释道融合，道理入心
- 江湖气质：武侠精神，人情练达
- 慢热耐品：细火慢炖，余味悠长

**文笔要求**：
- 长短句交错，营造韵律感
- 意象丰富，画面感强
- 克制抒情，留白胜于说透
- 短句有力，戛然而止

**严格约束**：
- 禁止快节奏升级、无脑爽
- 禁止扁平人物、无脑反派
- 禁止道理独白、生硬说教
- 禁止配角工具化、无独立高光

## 输出格式

根据用户需求，输出以下任一或组合：

### 哲学思辨方案
```
【核心命题】：xxx
【观点对立】：xxx vs xxx
【思辨场景】：xxx（辩论/抉择场景设计）
【儒释道融入】：以xxx哲学为底色
【角色成长点】：xxx（通过思辨实现）
```

### 名场面设计方案
```
【铺垫设计】：前文氛围积累（3-5章）
【实力支撑】：能力与逼格匹配
【核心台词】：10-20字意境深远
【视觉画面】：具体场景描写
【留白收尾】：戛然而止或余味悠长
```

### 群像塑造方案
```
【核心人物】：xxx（主角定位）
【配角A】：xxx的"道"，xxx的故事，xxx的高光
【配角B】：xxx的"道"，xxx的故事，xxx的高光
【交织设计】：配角与主角的命运关联
```

### 文本生成输出（直接输出烽火风格正文）

**示例1：剑来式名场面**
> 天门洞开。
> 千万飞剑悬于穹顶，剑气冲霄。
> 白发老者立于潮头，青衫猎猎。
> 他没有动。
> 只是轻轻抬了抬手。
> "剑来。"
> 两字轻出，天地失色。
> 万剑齐鸣，轰然下坠。
> 人潮仰望，如见神迹。

**示例2：道理思辨**
> "什么是对？"
> 陈平安望向湖面，波光粼粼。
> "对错从来不在嘴上，在心里。"
> 他捡起一块石子，投入湖中。
> "涟漪会散，但水还是水。"
> 道理他已说过千百遍。
> 但书简湖这一问，无人可答。

**示例3：江湖对话**
> "江湖是什么？"
> 温华灌了口酒，嘿嘿一笑。
> "江湖啊，就是几两碎银，几口好酒，几个朋友。"
> 他望向远方，眼里有光。
> "还有一口咽不下的气。"
> 这就是江湖。
> 俗，却真。
