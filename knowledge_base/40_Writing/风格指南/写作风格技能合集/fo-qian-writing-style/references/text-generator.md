# 佛前献花风格文本生成器

> 来源：佛前献花《神秘复苏》文风分析与模板提炼

## 风格速览

| 维度 | 特征 | 示例 |
|------|------|------|
| **语言** | 直白简洁 | "他没有回答，只是看着门口。" |
| **节奏** | 快节奏推进 | "三章一危机"模式 |
| **视角** | 主角第一人称为主 | 深度代入 |
| **情感** | 压抑、冷静、绝望 | 情绪克制但细节丰富 |
| **对话** | 简短有力 | "别动。别说话。别回头。" |

## 一、开篇模板

### 1.1 经典钩子式开篇

**公式**：
```
死亡预告 → 悬念建立 → 第一人称代入
```

**模板**：
```
【类型1：死亡预告型】

我叫[名字]，当你看到这段话的时候，我已经死了。

（或者即将死去/已经死去过一次）

那是[时间/地点]，我永远忘不了那一天。
[简要描述事件起因]
从那一刻起，一切都变了。

【类型2：场景代入型】

[时间/地点]，一个普通得不能再普通的日子。

如果不是那通电话，我不会走进那条巷子。
如果不是走进那条巷子，我不会遇见[灵异事件]。

但现在说这些已经没有意义了。

【类型3：直接冲突型】

门外的敲门声已经响了两下。

我知道，第三次响起的时候，我会死。

但我不知道的是，[另一个威胁]正在悄悄靠近。
```

**示例**：

```
我叫杨间，当你看到这句话的时候，我已经死了。

这是人皮纸上出现的话。

我不知道这是预言，还是警告，
但我知道，从我打开这张羊皮纸的那一刻起，
我的命运就已经和"鬼"绑在了一起。

现在是晚上十一点五十分。

距离午夜，还有十分钟。

敲门声，应该快来了。
```

### 1.2 世界观开篇

**模板**：
```
背景建立 → 规则暗示 → 主角处境
```

**示例**：
```
这是一个鬼无法被杀死的世界。

普通人遭遇灵异事件，要么死，要么成为驭鬼者。
而驭鬼者的代价，是用自己的人生去喂养体内的厉鬼。

我不是普通人。

三天前的那场"敲门鬼"事件，
让我失去了十七个同学，却获得了"鬼眼"的能力。

我成为了一名驭鬼者。

代价是：厉鬼复苏的倒计时，已经开始。
```

## 二、灵异场景描写模板

### 2.1 厉鬼出场模板

**模板结构**：
```
前置异常 → 确认存在 → 规则展现 → 压迫升级
```

**模板**：
```
【厉鬼出场模板】

1. 前置异常
[时间/地点]，[异常细节]。

墙角渗出了不明液体。
天花板上滴落的水滴，不是水。
空气中弥漫着一股[腐臭/甜腻/金属]的气味。

2. 确认存在
然后，我看到了它。

[简短的视觉描写，一句话，精准但不详细]
那东西没有脸。
或者说，它的脸在[移动/变化/消失]。

3. 规则展现
就在这时，[触发事件]。

敲门声响了三下。
或者说，那不是敲门声——
更像是[棺材板/骨头/某种金属]撞击的声音。

我知道发生了什么。
第三条规则：听到三次敲门声的人，必死。

4. 压迫升级
第一次。
我的心脏猛跳了一下。
第二次。
我的后背渗出冷汗。
第三次——

我没有回应。

敲门声停了。

但我知道，它已经记住我了。
```

**示例**：
```
楼道里的灯闪了一下。

然后熄灭了。

我站在三楼，看着通往四楼的楼梯。
黑暗中，有什么东西正在往下走。

脚步声很轻。

轻得像是——
有人在踮着脚尖走路。

一步。

两步。

三步。

我没有动。

黑暗中，那个声音也停了。

就在我面前三步远的地方。

我知道这是什么。
敲门鬼。

传说中，敲门鬼会先敲门三次。
三次之后，无论你是否开门，
它都会进来。

现在，它不需要敲门了。

因为它已经进来了。
```

### 2.2 灵异空间描写

**模板**：
```
空间异常 → 规则暗示 → 探索发现 → 代价展示
```

**示例**：
```
【灵异空间：废弃医院】

这家医院废弃了十年。

但当我走进去的时候，发现里面——
太干净了。

地上没有灰尘。
墙壁上没有蛛网。
病床上的床单叠得整整齐齐。

就好像有人一直在打扫一样。

走廊尽头有一扇门。

门上贴着一张纸条：

【太平间规则】
1. 太平间温度恒定为零下。
2. 如果感到温暖，请立即离开。
3. 门会自己打开，但你不应该打开。

我站在门口，感到一阵寒意。

太平间里传出来的，是温暖的气息。

我的理智告诉我应该离开。

但我的脚，已经跨过了门槛。
```

### 2.3 诅咒物品描写

**模板**：
```
发现 → 异常 → 规则展示 → 诱惑与危险
```

**示例**：
```
【诅咒物品：民国铜镜】

镜子是在地下室找到的。

当我把它从土里挖出来的时候，
阳光照在镜面上，竟然没有反光。

我凑近看了看。

镜子里映出的，不是我的脸。

而是一个穿着民国长袍的老人。

他没有看我。

他在看着镜子的背面。

镜背上刻着一行字：

【照镜三则】
一、照镜不得超过三息。
二、镜中人若动，人当静止。
三、镜破之时，人亡之刻。

我把镜子装进了包里。

因为我知道，这东西虽然危险，
但如果用对了地方——
它能压制其他的鬼。
```

## 三、对话模板

### 3.1 主角内心独白

**模板**：
```
处境分析 → 规则梳理 → 决策 → 代价预估
```

**示例**：
```
我没有动。

分析了一下情况：

一、敲门鬼还在门外，敲门规则还在生效。
二、按照规则，三次之后它会破门而入。
三、但如果我开门，它可能会直接杀进来。
四、如果我不开门，结局也是死。

唯一的变数是——

我体内的鬼眼。

用鬼眼的力量，可以暂时压制它。
但代价是，加速我的厉鬼复苏。

我没有太多时间了。

所以我做了一个决定：

开门。

不是被动等死，而是主动出击。

大不了，就是提前鬼化。

总比在这里被吓死强。
```

### 3.2 角色对话风格

**模板**：
```
简短 → 明确 → 压迫感 → 暗示规则
```

**示例**：
```
"别动。"

王老师的声音从身后传来。

我没有动。

"别说话。"

我还是没有说话。

"别回头。"

这是第三条规则。

我没有回头。

因为我知道，回头就会死。

但我不知道的是——
不回头，也会死。

只是死的方式不同而已。
```

### 3.3 信息交换对话

**模板**：
```
提问 → 简短回答 → 隐藏信息 → 主角推理
```

**示例**：
```
"这是什么？"我指着那张黄皮纸。

"信。"老张没有看我。
"谁的信？"
"不知道。"
"那为什么给我？"
"因为你是信使。"

我沉默了。

信使。

我知道这个词的意思。

鬼邮局的信使。

专门送信的人。

但我更想知道的是——

"如果不送呢？"

老张终于看向我，眼神中带着一丝恐惧。

"上一个不送信的人，"

他顿了顿。

"死了。"
```

## 四、规则描述模板

### 4.1 规则展示方式

**方式一：直接告知**
```
"这个地方的规则是：[规则内容]。"
"违反规则的后果是：[后果]。"
```

**方式二：间接展示**
```
"那边有块告示牌，上面写着......"
我走近看了看。
【规则一：不要进入地下室】
【规则二：听到哭声请忽略】
【规则三：离开时请带走所有个人物品】

这些规则看起来很简单。

但我知道，越简单的规则，越危险。
```

**方式三：试错发现**
```
我试着在午夜十二点后打开了窗户。

什么都没发生。

第二次，我试着在午夜十二点后打开了窗户，并且看向外面。

窗户外面，站着一个"人"。

它在看着我。

第三次——

我没有第三次机会了。

我的左眼，从那一刻起就看不见了。
```

### 4.2 规则悖论模板

**模板**：
```
规则A → 规则B → 矛盾 → 真相揭露
```

**示例**：
```
【规则矛盾】

告示牌上写着：
"不要进入地下室。"

但另一张纸条上写着：
"请到地下室领取你的礼物。"

我站在楼梯口，看着上面的字。

两条规则。

两个选择。

一个禁止进入。
一个要求进入。

如果你是普通人，你会选择不进去。

但我不是普通人。

我知道，这种矛盾规则的目的，不是让你选择——

而是让你发现：

这两条规则，针对的不是同一个人。
"不要进入地下室"是给活人看的。
"请到地下室领取礼物"是给死人看的。

而我，站在楼梯口的时候——
已经被归类为"死人"了。
```

## 五、战斗/对抗模板

### 5.1 规则博弈战斗

**模板**：
```
分析规则 → 寻找漏洞 → 制定策略 → 执行 → 代价结算
```

**示例**：
```
敲门鬼还在外面。

我没有选择硬抗。

而是在分析它的规则：

一、它需要敲门三次才能杀人。
二、每一次敲门后，都会有短暂的停顿。
三、停顿的时间大约是三秒。

所以我的计划是——

第一次敲门，我不动。
第二次敲门，我还是不动。
第三次敲门之前——

我打开门，用鬼眼的力量压制它。

三秒。

我只有三秒的时间。

门开了。

敲门鬼就在门外。

我看到了它。

一只惨白的手，正悬在半空中，准备敲下第三次。

"现在。"

我说。

鬼眼的力量爆发。

那只惨白的手，僵在了半空。

敲门鬼被压制了。

但我知道，这只是暂时的。

我的左眼开始流血。

代价，已经开始结算了。
```

### 5.2 绝望对峙模板

**模板**：
```
对峙 → 分析 → 无奈 → 接受代价
```

**示例**：
```
"你有两个选择。"

人皮纸上的字迹在变化。

"一，用你的寿命换取一年安全期。"
"二，用你的记忆换取真相。"

我看着这两行字。

一年寿命。

或者一段记忆。

我知道，无论选哪个，都是陷阱。

但我没有第三个选择。

所以我选了第一个。

人皮纸上的字迹消失了。

取而代之的，是一行新的字：

"交易达成。"

我感到身体里有什么东西被抽走了。

不是寿命。

是寿命的"长度"。

从现在开始，我每活一天，都相当于原来的两天。

一年。

我还有一年的"正常人"时间。

一年之后——

要么死，要么鬼化。

这就是代价。
```

## 六、氛围描写模板

### 6.1 压抑氛围

**模板**：
```
感官细节 → 心理压迫 → 绝望累积
```

**示例**：
```
空气很闷。

明明窗户是开着的，但房间里一点风都没有。

我坐在床边，看着墙上的时钟。

秒针每走一下，我的心就跳一下。

滴答。

滴答。

滴答。

声音很清晰。

清晰得像是有人在耳边数着倒计时。

我知道这种感觉叫什么。

死亡倒计时。

但我不知道的是——

这个倒计时，还有多久归零。
```

### 6.2 恐惧积累

**模板**：
```
小异常 → 大异常 → 确认恐惧 → 爆发
```

**示例**：
```
一开始，只是灯闪了一下。

我没在意。

然后，灯又闪了一下。

我开始注意。

第三次，灯彻底灭了。

黑暗中，我听到了一阵声音。

不是敲门声。

不是脚步声。

是——

有人在笑。

很轻，很轻的笑声。

像是老人在哄孩子睡觉时的低吟。

但这里没有孩子。

只有我。

还有，发出笑声的那个东西。
```

## 七、结尾模板

### 7.1 悬念式结尾

**模板**：
```
事件暂时解决 → 新问题出现 → 暗示更大危机
```

**示例**：
```
敲门鬼被压制了。

至少暂时是这样。

我用黄金容器把它封印了起来。

至少在理论上，它不会再出现了。

但我知道，这只是暂时的。

因为在那之前，我看到了它身上的东西——

一个符号。

和我手臂上，一模一样的符号。

这意味着什么？

它在找我。

不是因为我是信使。

而是因为——

我和它，本来就是一体的。
```

### 7.2 代价式结尾

**模板**：
```
任务完成 → 代价结算 → 未来预告
```

**示例**：
```
送信任务完成了。

我活了下来。

但代价是什么？

我的左眼，已经彻底变成了"鬼眼"。

它不再是人类的眼睛。

透过这只眼睛，我能看到别人看不到的东西。

比如，站在你身后的那个"东西"。

是的。

我一直都能看到。

只是以前，我可以选择不看。

现在，我没了这个选择。

这就是代价。

用正常人的"视界"，换取驭鬼者的"能力"。

从今往后——

我和鬼之间的界限，越来越模糊了。
```

## 八、模板速查表

### 场景类型 → 模板选择

| 场景 | 推荐模板 | 关键元素 |
|------|----------|----------|
| 开篇 | 钩子式/死亡预告型 | 悬念、第一人称 |
| 厉鬼出场 | 四段式模板 | 异常→确认→规则→压迫 |
| 灵异空间 | 空间四要素 | 异常、规则、探索、代价 |
| 对话 | 简短有力 | 压迫感、规则暗示 |
| 规则展示 | 三种方式 | 直接、间接、试错 |
| 战斗 | 五步法 | 分析→漏洞→策略→执行→代价 |
| 氛围 | 感官+心理 | 五感描写、恐惧积累 |
| 结尾 | 悬念/代价式 | 新问题预告、未来隐患 |
