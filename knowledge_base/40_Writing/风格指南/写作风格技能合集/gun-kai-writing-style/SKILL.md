# 滚开写作风格Skill

## 概述

滚开，起点中文网白金作家，网文界"极道流"与"巫师流"的开山鼻祖。自2011年出道至今，创作了《巫师世界》《神秘之旅》《极道天魔》《永恒剑主》《十方武圣》《万千之心》《隐秘死角》《绝境黑夜》《腐朽世界》等十余部作品，累计字数超过2500万字。

**核心代表作**：
- 《极道天魔》—— 极道流巅峰之作，"深蓝加点"成为全网热梗
- 《神秘之旅》—— 诸天流先驱，数据化属性异能先河
- 《巫师世界》—— 巫师流开山之作，生物芯片设定影响深远
- 《十方武圣》—— 末世横练硬功，"石灰武圣"深入人心

## 风格核心定位

### 五大风格支柱

| 风格支柱 | 核心内涵 | 读者爽点 |
|---------|---------|---------|
| **极道暴力美学** | 肌肉碾压、拳拳到肉、肉身横推 | 纯粹的暴力爽感，"宇宙癌细胞"式碾压 |
| **黑暗压抑世界观** | 克苏鲁元素、诡异恐怖、弱肉强食 | 生存压迫感，绝境逆袭的快感 |
| **系统流创新** | 数据化升级、加点升级、代价平衡 | "深蓝，加点！"的即时反馈 |
| **主角狠辣人设** | 不圣母、不装逼、杀伐果断、利己主义 | 零憋屈，"人不犯我我不犯人" |
| **力量体系严密** | 层层递进、功法融合、代价机制 | 逻辑自洽，越看越上头 |

### 滚开风格公式

```
滚开风格 = 黑暗残酷世界观 + 冷漠利己主角 + 数据化金手指 + 暴力美学战斗 + 层层递进地图
```

## 核心技法体系

### 1. 暴力美学技法（详见 `references/violence-aesthetic.md`）

- **肌肉碾压法**：主角以绝对力量碾压敌人，不讲道理的战斗
- **非人异化法**：身体变异、多肢、巨硕等怪物特征
- **灾厄美学法**：主角如行走天灾，"此界当灭，助我修行"
- **拳拳到肉法**：具体化的身体对抗描写

### 2. 黑暗风格技法（详见 `references/dark-style.md`）

- **克苏鲁恐怖法**：多眼、触手、扭曲等诡异元素
- **丛林法则法**：弱肉强食，道德让位于生存
- **压抑氛围法**：灰雾、黑灾、血潮等意象
- **利益交换法**：情感淡薄，力量博弈优先

### 3. 系统流设计（详见 `references/system-design.md`）

- **深蓝加点法**：消耗代价+即时升级+可推演
- **属性面板法**：杀伤/防御/闪避/体质等数值化
- **代价平衡法**：气血亏空、透支潜力等副作用
- **融合推演法**：多功法合一，创造专属技能

### 4. 主角人设设计（详见 `references/protagonist-design.md`）

- **冷酷利己法**：绝对理性，生存第一
- **杀伐果断法**：不拖泥带水，斩草除根
- **反差萌法**：冷漠中带一丝直男搞笑
- **非人进化法**：从人类到怪物的转变

## 使用方法

### 快速入门

1. **确定三要素**：
   - 世界观：黑暗残酷 + 克苏鲁诡异
   - 金手指：数据化系统 + 加点升级
   - 主角：利己主义 + 杀伐果断

2. **遵循滚开节奏**：
   - 密集冲突，不水字数
   - 每章必须有行动目标或冲突事件
   - 升级-换地图-碾压的循环爽点

3. **使用文风模板**：
   - 参考 `references/text-generator.md` 中的开篇、场景、对话模板

### 进阶指南

1. **力量体系构建**：
   - 参考"层层递进法"，从低武到高维宇宙
   - 设定清晰的境界划分和功法特效
   - 保持代价机制平衡

2. **世界诡异氛围**：
   - 融入克苏鲁元素
   - 使用灰雾、血潮、黑灾等意象
   - 营造生存压迫感

3. **主角性格塑造**：
   - 冷漠自私，但有反差萌
   - 行事直接，不纠结
   - 对敌人斩草除根，对目标坚定不移

## 风格禁区

❌ **禁止行为**：
- 主角圣母心泛滥
- 过度纠结情感线
- 无意义的拖沓剧情
- 主角被反复打脸
- 系统过于无敌无代价

✅ **正确姿势**：
- 黑暗世界观，力量至上
- 密集冲突，快速推进
- 系统有代价，升级有代价
- 主角冷酷但有趣
- 换地图→新冲突→继续碾压
