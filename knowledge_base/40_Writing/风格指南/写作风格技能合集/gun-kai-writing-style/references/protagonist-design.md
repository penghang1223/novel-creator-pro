# 主角人设构建方法

滚开笔下的主角是网文界最具辨识度的存在之一。他们冷漠、自私、杀伐果断，为了力量不择手段。但同时，他们又有一种独特的"反差萌"，让读者在感受到压迫感的同时，又会觉得有趣。

---

## 一、滚开式主角的核心特质

### 主角特质一览表

| 特质 | 表现 | 读者感受 |
|-----|------|---------|
| **绝对利己** | 一切以自身利益为核心 | 代入感强，够真实 |
| **杀伐果断** | 不拖泥带水，斩草除根 | 爽、无憋屈 |
| **冷酷理性** | 情绪波动小，冷静决策 | 强大、有压迫感 |
| **目标明确** | 眼里只有变强，其他都是浮云 | 专注、有方向感 |
| **不装逼** | 有实力就碾压，不废话不解释 | 直接、爽快感 |
| **不圣母** | 不会因为可怜谁就放过谁 | 真实、黑化合理 |
| **反差萌** | 冷酷中偶尔流露出直男幽默 | 有趣、可爱 |

### 主角性格公式

```
滚开主角 = 绝对利己 + 杀伐果断 + 冷酷理性 + 目标单一 + 反差萌
```

---

## 二、冷酷利己法

### 技法定义

主角是绝对的利己主义者。在他的世界里，情感是最不重要的东西，利益才是永恒的主题。

### 利己表现清单

| 场景 | 传统主角 | 滚开主角 |
|-----|---------|---------|
| 救人 | 英雄救美、心软帮忙 | 看有没有好处 |
| 交易 | 吃亏是福、吃亏让人 | 绝对不能亏，亏了就要抢回来 |
| 背叛 | 纠结痛苦、被迫黑化 | 随时准备背叛，反叛只是时机问题 |
| 资源 | 靠努力获得 | 靠抢夺获得，能抢就不废话 |
| 关系 | 重视羁绊 | 只看利用价值 |

### 利己内心独白模板

```markdown
"妹妹？"

路胜看着面前那个泪眼婆娑的女子。

那是他这具身体的亲妹妹。

按照常理，他应该保护她。

但他不是常人。

在这个世界，他唯一信任的，只有自己的拳头。

"如果你有用，我会留你。"

他的声音冰冷。

"如果你没用……"

他没有说完。

但那女子已经明白了。

在这个残酷的世界，亲情是最奢侈的东西。

而他，只想活下去。

活下去，然后变强。

强到不需要任何人。

这，就是他的生存之道。
```

### 利己对话模板

```markdown
"你为什么要帮我？"

"因为我们是一伙的。"

"一伙？"

路胜嗤笑一声。

"在这个世界上，没有'一伙'这种说法。"

"只有'暂时利益一致'。"

"现在我们利益一致，所以是'一伙'。"

"但如果有一天，利益不一致了……"

他的眼神冷了下来。

"我会毫不犹豫地把你卖掉。"

"这就是这个世界的规则。"

"而我，只是遵守规则而已。"
```

## 三、杀伐果断法

### 技法定义

主角从不废话，从不犹豫。敌人出现就杀，挡路者就灭。斩草除根，不留后患。

### 杀伐果断表现

| 行为类型 | 描写要点 | 关键要素 |
|---------|---------|---------|
| 动手 | 不警告、不废话、直接打 | 速度和力量 |
| 追击 | 不给对方逃跑的机会 | 斩草除根 |
| 复仇 | 有仇必报，不隔夜 | 快、狠 |
| 碾压 | 不给对方尊严 | 直接、彻底 |

### 杀伐场景模板

```markdown
【场景：敌人出言不逊】

"你敢——！"

那纨绔子弟话还没说完。

路胜已经动了。

没有预警，没有警告，没有任何废话。

他的手掌，直接捏住了对方的脖子。

"咔嚓。"

颈椎断裂的声音，清脆悦耳。

那纨绔子弟的眼中，还残留着嚣张的神色。

但那神色，已经永远定格在那里。

"拖出去。"

路胜松开手，任由尸体滑落。

"顺便把整个王家都灭了。"

"他们家的人，一个不留。"

"是。"

手下们浑身一颤，恭敬地应声。

没有人敢质疑路胜的决定。

因为质疑他的人，都已经死了。

【关键要素：快、狠、不废话、不留活口】
```

### 斩草除根模板

```markdown
"大人，只剩下一个孩子了……"

"哪个孩子？"

"王家家主的幼子，只有五岁……"

手下有些犹豫。

"杀。"

路胜的声音没有丝毫波动。

"斩草不除根，春风吹又生。"

"这种道理，小孩子都懂。"

他转身离去。

身后传来一声惨叫。

然后，是死一般的寂静。

在这个世界，善良是最快死掉的那批人。

而他，不想死。

所以，他不会留下任何隐患。

哪怕是一个五岁的孩子。
```

## 四、冷酷理性法

### 技法定义

主角几乎没有任何情绪波动。无论发生什么，他都能保持冷静，做出最理性的判断。

### 情绪控制表

| 情绪类型 | 传统主角 | 滚开主角 |
|---------|---------|---------|
| 愤怒 | 暴怒、失控、黑化 | 不存在愤怒，只有冷漠 |
| 悲伤 | 痛苦、流泪、缅怀 | 不存在悲伤，只看利益 |
| 恐惧 | 害怕、颤抖、绝望 | 不存在恐惧，只有评估 |
| 感动 | 心软、帮助、牺牲 | 不存在感动，只有利用 |
| 后悔 | 纠结、反思、自责 | 不存在后悔，只有利益 |

### 冷酷决策模板

```markdown
"如果你杀了他，我就死给你看！"

女子手持匕首，对准自己的咽喉。

她以为这样能威胁到路胜。

"随便。"

路胜淡淡开口。

女子愣住了。

"你不怕我死？"

"怕？"

路胜看了她一眼，眼中没有任何情绪波动。

"你的命，对我来说只有三个月的利用价值。"

"三个月后，你的价值归零。"

"所以，你死不死，对我没有任何影响。"

"如果你觉得死能威胁我，那你就去死。"

"反正我没有任何损失。"

女子的手在颤抖。

她终于意识到，面前这个人，根本不是她能威胁的。

她手中的匕首，"当啷"一声落地。

"我……我不动了……"

"嗯。"

路胜点点头，转身离去。

"这才对。"
```

### 危机冷静评估模板

```markdown
【危机出现】

"不好！是宗师级强者！"

"怎么办？我们要死了吗？"

众人面露绝望。

路胜却面不改色。

"别慌。"

"让我分析一下。"

他眯起眼睛，快速评估局势。

"宗师级强者，速度比我快两成，力量比我高三成。"

"正面硬拼，我必死无疑。"

"但是——"

他的眼中闪过一丝精光。

"他刚战斗过，气血有亏损。"

"而且，他的右臂似乎有旧伤，出招时会有零点三息的迟滞。"

"如果是零点三息的话……"

他的嘴角微微上扬。

"我有机会。"

【关键要素：冷静分析、发现弱点、制定策略、执行计划】
```

## 五、目标单一法

### 技法定义

主角的人生目标非常简单、非常纯粹：**变强**。除此之外，一切都是浮云。

### 目标优先级表

| 事项 | 优先级 | 说明 |
|-----|-------|------|
| 变强 | ★★★★★ | 唯一核心目标 |
| 自保 | ★★★★☆ | 变强是为了自保 |
| 资源 | ★★★☆☆ | 获取变强的资源 |
| 势力 | ★★☆☆☆ | 势力是获取资源的工具 |
| 感情 | ★☆☆☆☆ | 没什么用，还碍事 |

### 目标单一独白模板

```markdown
"你难道就不想拯救这个世界吗？"

"世界？"

路胜脚步一顿。

"为什么要拯救？"

他回头，看着那个"正义使者"。

"这个世界没有救过我。"

"那些所谓的'正道'门派，每个月都在收刮民脂民膏。"

"那些所谓的'弱者'，他们的死活与我何干？"

"我唯一想做的，就是变强。"

"强到没有任何东西能威胁我。"

"至于这个世界……"

他继续向前走去。

"爱怎样就怎样。"

"我没有兴趣当救世主。"

"我只对一件事有兴趣。"

"那就是——"

他的眼中闪过一道精光。

"变强。"

"不断的变强。"

"直到这个世界，再也没有人能威胁我。"
```

### 感情线淡化模板

```markdown
"你就不能多看我一眼吗？"

绝色美女眼中含泪。

"我知道你有妻子，没关系，我可以当小的……"

"不需要。"

路胜头也不回。

"女人很麻烦。"

"会分心，会影响修炼，会拖慢我变强的脚步。"

"而且……"

他停顿了一下。

"你也会老，也会死。"

"等你老了，我的投资就亏了。"

"所以，不要再来烦我。"

"我只想变强。"

"女人？"

他嗤笑一声。

"不过是消耗品而已。"

【关键：直接、现实、不留情面、完全没有浪漫细胞】
```

## 六、反差萌法

### 技法定义

主角虽然冷酷无情，但偶尔会流露出一些"直男式幽默"或"反差萌"的特质，让读者觉得这个冷酷的"肌肉猛男"其实也挺有意思的。

### 反差萌表现清单

| 类型 | 表现 | 效果 |
|-----|------|------|
| 直男审美 | 给功法取名只求霸气 | 搞笑 |
| 自我调侃 | 走火入魔变成煤球也能淡定自嘲 | 可爱 |
| 实用主义 | 用石灰、毒药等接地气手段 | 真实 |
| 专注过头 | 变强变到忘记吃饭睡觉 | 痴迷 |
| 无感情线 | 感情线直接无视或跳过 | 纯粹 |

### 反差萌对话模板

```markdown
"这个功法的名字……"

路胜低头看着自己刚创造的功法。

他皱起眉头，认真思考。

"要霸气。"

"要威风。"

"要让人一听就腿软。"

他沉吟片刻。

"就叫——"

"'一拳无敌天下最帅终极灭世霸气拳'。"

"……"

旁边的下属沉默了。

"大人，这个名字是不是有点……"

"有点什么？"

"有点……长？"

"长？"

路胜不悦地皱起眉头。

"不长。"

"这才够霸气。"

"不改了。"

"……是。"

【关键：取名只求霸气，不管多中二都无所谓】
```

### 反差萌场景模板

```markdown
【场景：走火入魔后】

"大人！您没事吧！"

众人惊恐地看着路胜。

此刻的路胜，浑身冒着黑烟，皮肤呈现出诡异的焦黑色。

看起来就像是……一块人形煤炭。

"……"

路胜低头看了看自己。

沉默了三秒。

"哦。"

然后他就这样顶着"人形煤炭"的造型，拍了拍身上的黑灰。

"走火入魔而已。"

"小问题。"

"继续修炼。"

"……"

众人无语。

这位大人，真的是……

"对了。"

路胜突然想起什么。

"今天晚饭吃什么？"

"修炼消耗太大，有点饿了。"

"……是。"

【关键：出了这么大的事，主角第一反应是"小问题"，第二反应是"饿了"】
```

### 实用主义反差模板

```markdown
"魏师弟！这是生死之战，你怎么——"

"等等。"

魏合从怀里掏出一包石灰粉。

"什么？"

"石灰。"

他认真地说。

"撒眼睛用的。"

"……"

"还有这个。"

他又掏出一瓶毒药。

"抹在兵器上的。"

"以及这个。"

一把弩箭。

"远程偷袭用的。"

"你……你这是正派武者的作风吗！"

"正派？"

魏合看了对方一眼，眼中满是疑惑。

"打得赢就是正派。"

"打不过就是反派。"

"管他用什么手段？"

"能赢就行。"

他端起弩箭，瞄准远处的敌人。

"所以，不要废话。"

"让我先射他一脸石灰再说。"

【关键：使用石灰、毒药、偷袭等"不正派"手段，但主角觉得理所当然】
```

## 七、主角速写模板

### 模板一：冷酷开局

```markdown
【人设标签】冷漠、自私、杀伐果断、变强至上
【开场场景】主角穿越/觉醒，面对生死危机
【处理方式】冷静分析，果断行动
【反差点】可以用名字/审美/日常吐槽增加反差
【核心动机】变强，不择手段地变强

示例开场：

我叫路胜。

一个只想变强的普通人。

那些所谓的"正义"、"善良"、"道义"……

对我来说，都是狗屁。

我只相信一件事。

谁的拳头大，谁就是道理。

三天前，我穿越到了这个世界。

三天后，我杀光了所有欺负过"我"的人。

不是因为我心狠。

而是因为——

我饿了。

需要吃东西。

而他们手里，正好有食物。

所以，他们死了。

就这么简单。

"深蓝，加点。"

"变强。"

"然后，吃饱。"

这就是我的人生目标。

仅此而已。
```

### 模板二：敌人对峙

```markdown
【对峙场景】敌人嚣张挑衅
【主角反应】淡然、不在乎
【关键对话】主角直接说出自己的行事逻辑
【行动结果】直接碾压，不废话

示例对话：

"你知道我是谁吗！"

"不知道。"

路胜淡淡回答。

"也不想知道。"

"你——！"

"你挡路了。"

"什么？"

"我说，你挡路了。"

路胜向前一步。

"让开，我赶时间。"

"否则，死。"

"你敢！"

对方话没说完。

路胜已经动了。

一掌拍出。

那人的身体，直接化为血雾。

"说了不让开。"

路胜收回手掌。

"浪费时间。"

他继续向前走去。

身后，只剩下一滩血水。

【关键：废话少，直接动手】
```

## 八、主角人设练习任务

### 任务一：冷酷利己内心戏（400字）

场景设定：主角的"亲人"被敌人绑架，敌人要求主角用某项重要资源来换。

要求：
- 体现主角的利己主义
- 主角不会纠结太久
- 可以展现冷酷的计算过程
- 结尾要出人意料

### 任务二：杀伐果断战斗（500字）

场景设定：主角得罪了一个小势力的少主，对方纠集了一百人来围杀主角。

要求：
- 敌人要嚣张
- 主角要淡定
- 杀伐要果断
- 反转要快

### 任务三：反差萌日常（300字）

场景设定：主角在给新创的功法取名字，或者主角在吃饭/休息/做一些日常琐事。

要求：
- 体现主角的直男审美或实用主义
- 与平时的冷酷形成反差
- 让人看了觉得"这个杀神还挺有意思"
- 可以是功法的名字、取名理由、或者日常吐槽

### 任务四：完整主角人设卡（无字数限制）

任务要求：设计一个完整的滚开式主角，包括：

1. **基本信息**：名字、身份、背景
2. **核心特质**：至少5个核心特质
3. **行为准则**：主角的三条底线/准则
4. **金手指**：主角的系统/能力
5. **变强动机**：为什么主角要变强
6. **性格弱点**：虽然冷酷但可以有一点小缺点
7. **反差萌点**：冷酷之外的可爱之处
8. **经典语录**：至少3句符合人设的台词
