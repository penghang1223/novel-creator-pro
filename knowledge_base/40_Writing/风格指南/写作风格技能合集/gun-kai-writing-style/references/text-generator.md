# 文风文本生成器

本文件提供滚开写作风格的开篇、场景、对话、战斗等模板，帮助创作者快速上手滚开式文风。

---

## 一、开篇模板库

### 模板1：穿越+系统觉醒

```markdown
## 模板框架

【第一段】穿越落地+环境描写（压抑/黑暗/诡异）
【第二段】原身记忆涌入+处境艰难
【第三段】系统觉醒+金手指介绍
【第四段】主角心态转变+确立目标
【第五段】第一个行动（往往是杀/抢/吃）

## 完整示例

天是灰的。

灰得像一具腐烂的尸体。

路胜睁开眼睛，看到的就是这样一片天空。

"我……这是哪里？"

他的意识还有些恍惚。

原身的记忆涌入脑海。

他穿越了。

穿越到一个妖魔横行的世界。

这里没有法律，没有秩序，只有弱肉强食。

而他这具身体的原主人，是一个被人欺凌至死的废物少爷。

"有意思。"

路胜缓缓站起身，嘴角勾起一抹弧度。

"穿越、系统、妖魔、弱肉强食……"

"这种世界，我最喜欢。"

轰！

就在此时，他的脑海中响起一道冰冷的机械音。

"检测到符合条件的宿主。"

"深蓝修改器……绑定成功。"

"欢迎使用，深蓝。"

路胜的眼前，出现了一个只有他能看到的半透明界面。

【宿主：路胜】
【境界：凡人】
【可用潜能：0】
【状态：饥饿】

"潜能为零？"

路胜皱起眉头。

他看向远处，那里有一群正在进食的野狗。

准确地说，是正在进食"同类"的野狗。

它们刚刚吃掉了原主的身体。

"……刚好。"

路胜舔了舔嘴唇。

"我饿了。"

他迈步走向那群野狗。

不是逃跑。

是——狩猎。
```

### 模板2：绝境开局+系统救场

```markdown
## 模板框架

【第一段】绝境场景（被追杀/被困/濒死）
【第二段】希望破灭的绝望感
【第三段】系统觉醒的瞬间转折
【第四段】反杀/破局的快意
【第五段】确立新的目标

## 完整示例

"哈哈哈！跑啊！继续跑啊！"

嘲讽声从身后传来。

路胜咬紧牙关，拼命向前奔跑。

但他知道，跑不掉了。

身后是三十多个全副武装的杀手。

身前是一道百丈悬崖。

他被包围了。

"少主，您还是乖乖跟我们回去吧。"

为首的黑衣人缓步上前，声音带着猫戏老鼠般的戏谑。

"只要您交出路家的传承功法，我们可以给您一个痛快。"

"否则……"

他舔了舔嘴唇。

"我们会一点一点地切下您的肉，喂狗。"

路胜的眼中闪过一丝绝望。

完了。

彻底完了。

就在此时——

轰！！

一道金光从他胸口爆发而出。

"检测到宿主濒死状态。"

"紧急启动……一级权限。"

"血脉传承……觉醒。"

金光笼罩了他的全身。

他的气息，在这一刻疯狂攀升。

"这、这是什么——"

黑衣人瞳孔骤缩。

但他永远也得不到答案了。

因为路胜已经动了。

金色的拳头，带着毁灭一切的力量，轰向他的面门。

轰！！

黑衣人的整个头颅，瞬间化为血雾。

"现在——"

路胜收回拳头，声音冰冷。

"谁是猎物，谁是猎人？"

"该重新定义了。"

【剩余二十九人】 
【逃跑中】
【路胜】
【追杀中】
```

### 模板3：世界观展示+金手指展示

```markdown
## 模板框架

【第一段】世界观黑暗基调（300字左右）
【第二段】这个世界的生存法则
【第三段】主角的身份和处境
【第四段】金手指的特性和运作方式
【第五段】主角的第一个目标

## 完整示例

这个世界叫做"玄黄界"。

一个没有天理、没有王法、只有拳头的地方。

在这里，实力就是一切。

弱者，是强者的资源。

你可以是食物，可以是劳力，可以是炼器材料，可以是修炼炉鼎。

总之，弱者没有人权。

路胜站在九连城的街道上，看着来来往往的人群。

这些人看起来活着，但路胜知道，他们的生命，早已被明码标价。

"卖身救父，三两银子。"

"收购童工，包吃包住，童男童女优先。"

"高价收购修炼用的器官，活人死人皆可。"

路胜收回目光。

他的前身是九连城路家的大少爷，听起来风光。

但实际上，不过是一个被架空的傀儡。

他的父亲失踪，母亲病亡，偌大的家业被几个叔伯瓜分。

而他这个"大少爷"，连吃饭都要看人脸色。

"这就是这个世界啊。"

路胜叹息一声。

"弱肉强食，适者生存。"

"既然如此——"

他的眼中闪过一丝精光。

"那就让我来成为那个最强者吧。"

轰！

他的脑海中，一道冰冷的系统界面浮现。

【深蓝修改器】
【状态：已激活】
【核心功能：加点、融合、推演】
【当前可用潜能：10】

"十点潜能。"

"够我突破一次了。"

路胜抬起头，看向远处那座金碧辉煌的城主府。

"该去拿回属于我的东西了。"
```

## 二、场景描写模板

### 模板1：黑暗城镇

```markdown
【色调】灰暗、死寂、血腥
【意象】灰雾、废墟、血迹、残尸
【声音】寂静、偶尔的惨叫
【气味】腐朽、血腥、硫磺

示例：

这是一座死城。

至少，路胜是这么认为的。

街道上空无一人。

两侧的房屋大多已经坍塌，残存的那些，也布满了血迹和爪痕。

空气里弥漫着某种腐烂的甜腻味。

像是某种花朵的香气，又像是尸体的味道。

路胜停下脚步。

他看向路边的一具尸体。

那尸体已经看不出人形了。

只剩下一个扭曲的轮廓，和一滩深褐色的血迹。

"诡异入侵。"

路胜喃喃自语。

"这个世界，还真是危险啊。"

他没有停留，继续向前走去。

在他的身后，那具"尸体"的手指，微微动了一下。

但路胜没有回头。

因为那个东西，对他来说，已经没有任何威胁了。

他只是不想浪费时间。

"先找个地方落脚。"

"然后……"

他的眼神冷了下来。

"找点吃的。"
```

### 模板2：帮派老巢

```markdown
【色调】昏暗、压抑、混乱
【意象】酒缸、刀剑、血迹、赌场
【声音】喧哗、叫骂、刀剑碰撞
【气味】酒气、血腥、铜臭味

示例：

赤鲸帮的地盘，是一个占地数十亩的庞大院落。

还没走进大门，路胜就能听到里面传来的喧嚣声。

"买定离手！"

"哈哈哈！老子又赢了！"

"你他娘的是不是出老千——"

轰！

一声闷响，伴随着惨叫。

似乎有人被扔出了赌桌。

路胜面无表情地穿过人群。

周围的人纷纷让开。

不是因为畏惧，而是因为他身上那股淡淡的血腥味。

在这片地盘上，血腥味意味着"不好惹"。

"站住！"

一个疤脸大汉拦住了他的去路。

"新来的？知不知道这里的规矩？"

路胜停下脚步。

"规矩？"

他看着疤脸大汉，嘴角微微上扬。

"我只听说了一条规矩。"

"什么？"

"谁的拳头大，谁就是规矩。"

轰！

下一秒，疤脸大汉的身体，已经砸穿了墙壁。

路胜收回拳头，继续向前走去。

"太弱了。"

"连热身都不够。"
```

### 模板3：宗门大殿

```markdown
【色调】肃穆、压抑、等级森严
【意象】高台、匾额、守卫、蒲团
【声音】低沉、恭敬、死寂
【气味】檀香、压迫感

示例：

元魔宗，大殿。

路胜站在大殿中央，承受着来自四面八方的审视目光。

那些目光中，有好奇，有轻蔑，有敌意，也有……杀意。

但他毫不在意。

"你就是路胜？"

主位上，一个白发老者缓缓开口。

"是。"

"一个外来者，想要加入元魔宗？"

"是。"

"凭什么是？"

路胜沉默了一瞬。

然后，他抬起手。

轰！！

一股恐怖的魔气从他体内爆发而出，席卷整个大殿。

大殿内所有人的面色同时一变。

那些原本轻蔑的目光，瞬间变成了惊恐。

"这、这股气息——"

"这是……魔体觉醒！"

"怎么可能！他才多大！"

路胜收回手，魔气消散。

"够了吗？"

他看着主位上的白发老者。

老者沉默了很久。

最终，他开口了。

"够。"

"从今日起，路胜为我元魔宗弟子。"

"直接晋升为核心弟子序列。"

大殿内，一片哗然。

但路胜只是点点头。

"嗯。"

"宿舍在哪里？"

"我要去修炼了。"
```

## 三、对话模板库

### 模板1：主角+反派对峙

```markdown
【反派特点】嚣张、愚蠢、自以为是
【主角特点】淡然、冷漠、不废话
【结局走向】反派死亡或被碾压

示例对话：

"你就是那个新来的路胜？"

一个锦衣青年拦住了路胜的去路。

他身后跟着七八个打手，个个面露凶光。

"听说你一来就晋升为核心弟子？"

锦衣青年冷笑。

"你知道核心弟子的位子，值多少条人命吗？"

"不知道。"

路胜淡淡回答。

"也不想知道。"

"哦？"

锦衣青年挑了挑眉。

"胆子不小啊。"

"我倒要看看，你这个新来的，有什么本事——"

"说完了吗？"

路胜打断了他。

"什么？"

"我说，说完了吗？"

路胜看着锦衣青年。

"你挡路了。"

"让开，我赶时间。"

锦衣青年愣了一秒。

然后，他笑了。

笑得前仰后合。

"你说什么？让我让开？"

"你知道我是谁吗！"

"不知道。"

路胜的声音依然平淡。

"也不想知道。"

"那就——"

他的身影突然消失。

下一瞬。

锦衣青年的身体，直接被一股巨力轰飞出去。

轰！！

他撞穿了数道墙壁，最终嵌在了大殿的柱子上。

"太吵了。"

路胜收回拳头。

"我说了，赶时间。"

他继续向前走去。

身后，只剩下锦衣青年一滩烂泥般的身体。

以及周围那些噤若寒蝉的打手。
```

### 模板2：主角+利益合作者

```markdown
【对话特点】互相试探、各怀鬼胎
【核心】利益交换、博弈
【结局】达成交易，但双方都不信任对方

示例对话：

"你想要什么？"

杨家家主眯着眼睛，看着对面的年轻人。

"合作。"

路胜端起茶杯，浅浅抿了一口。

"合作？"

杨家家主冷笑。

"你和杨家的仇恨，整个九连城都知道。"

"你杀了杨家三位长老，灭了杨家一个分舵。"

"现在你来找我合作？"

"你觉得我会答应？"

"会。"

路胜放下茶杯。

"因为你有三个不得不答应的理由。"

"第一，杨家现在内忧外患。没有我，你撑不过这个月。"

"第二，我杀的那三个长老，都是主张对你动手的人。换句话说，我是在帮你。"

"第三——"

他的声音冷了下来。

"拒绝我，你全家都得死。"

"……"

杨家家主沉默了。

很久。

"你想要什么？"

"你的情报网络。"

路胜站起身。

"我要知道九连城所有人的弱点。"

"三天后，我会派人来取。"

"合作愉快。"

他转身离去。

杨家家主看着他的背影，额头上冷汗直冒。

这个年轻人……

太可怕了。

"来人。"

他低声开口。

"去查查这个路胜的底细。"

"我总觉得……"

"他不是普通人。"

"是。"

下人匆匆离去。

杨家家主看着桌上的茶杯，陷入了沉思。

他知道，从今天开始，杨家的命运，已经不完全掌握在他自己手中了。

但他更知道——

如果拒绝，他全家都会死。

所以，他没得选。
```

### 模板3：主角收小弟

```markdown
【小弟特点】敬畏、试探、小心思
【主角特点】直接、看穿、不在乎
【核心】展示实力，收服人心

示例对话：

"大人，我……我愿意追随您！"

一个年轻人跪在路胜面前，满脸恳切。

路胜看了他一眼。

"追随我？"

"是！"

"为什么？"

"因为……因为大人实力强大！"

年轻人的眼中闪过一丝精光。

"只要跟着大人，我一定能飞黄腾达！"

"……"

路胜沉默了一瞬。

然后，他笑了。

"你撒谎。"

年轻人面色一变。

"你其实是想利用我。"

路胜淡淡说道。

"你听说我得罪了某个大势力，所以想提前站队。"

"如果我赢了，你就是从龙之臣。"

"如果我输了，你会第一时间把我卖掉，换取活命的机会。"

"我说得对吗？"

年轻人的脸一阵红一阵白。

"大人英明……"

"够了。"

路胜抬起手，打断了他。

"我不关心你的心思。"

"我只关心一点——"

他的眼神冷了下来。

"你，有没有用？"

"有！"

年轻人连忙说道。

"我熟悉九连城的每一条街巷，知道每一个势力的弱点，还能打探各种情报——"

"够了。"

路胜再次打断他。

"既然有用，那就跟在我身边。"

"但是——"

他的声音骤然冰冷。

"如果我发现你有任何异心。"

"我会亲手剥了你的皮。"

"明白吗？"

年轻人浑身一颤。

"明……明白！"

"嗯。"

路胜转身离去。

"跟上。"

"别掉队。"

年轻人连忙爬起来，跟了上去。

他的眼中，既有恐惧，也有庆幸。

至少，他活下来了。

而且，跟了一个真正的大人物。

"这条路……"

他偷偷看着路胜的背影。

"或许，真的能让我飞黄腾达。"
```

## 四、战斗模板库

### 模板1：一拳碾压

```markdown
【结构】敌人嚣张 → 主角出手 → 碾压 → 旁人震惊

示例：

"哈哈哈！就凭你？"

王家家主放声大笑。

他身后站着三十多个全副武装的死士，每一个都是炼体巅峰的强者。

这就是王家的底蕴。

这就是他嚣张的资本。

"小子，你知道自己今天会怎么死吗？"

王家家主舔了舔嘴唇。

"我会让人把你身上的肉，一刀一刀地割下来——"

"说够了吗？"

路胜的声音打断了他。

"什么？"

王家家主愣了一下。

"我说——"

路胜抬起拳头。

"说够了吗？"

轰！！

一道拳劲爆发而出。

王家家主的整个身体，在这一拳之下，直接化为了血雾。

不是重伤。

不是倒飞。

是彻底的——化为血雾。

"——！"

周围所有人都愣住了。

三十多个死士，死士的王家家主。

就这么……一拳？

一拳就没了？

"太吵了。"

路胜收回拳头。

"我赶时间。"

他看向那群死士。

"还有谁想拦我？"

没有人回答。

没有人敢回答。

因为他们终于意识到——

面前这个年轻人，根本不是什么弱者。

而是一尊真正的杀神。
```

### 模板2：团战清场

```markdown
【结构】敌人包围 → 主角开启形态 → 连续击杀 → 终结 → 霸气收尾

示例：

包围圈合拢的那一刻，路胜笑了。

"多少人？"

他问。

"三百七十二人。"

手下恭敬地回答。

"三百七十二个锻体境以上的修士，还有十七个化意境的长老。"

"王家还真是下了血本。"

路胜点点头。

"既然如此——"

他撕开衣衫，露出布满鳞甲的胸膛。

"我也认真一点吧。"

轰！！

八大魔体同时运转。

黑色的魔气从他身上爆发而出，遮天蔽日。

他的身体开始膨胀。

三米……五米……十米……

背后，八条手臂撕裂衣衫生长而出。

他的双眼化为猩红的竖瞳。

此刻的他，哪里还有半分人样。

分明是一头从地狱爬出的魔神！

"杀。"

只有一个字。

然后，他动了。

不是闪避。

不是后退。

而是——正面冲锋！

一拳轰出，最近的一个敌人身体炸裂。

一掌拍下，最近的一个敌人化为血雾。

八臂齐动，每一条手臂都是一台死亡机器。

惨叫声此起彼伏。

血流成河。

尸横遍野。

十息。

只用了十息。

三百七十二人，全部死亡。

无一活口。

路胜收回手臂，身上的异象缓缓消散。

他看了看自己沾满鲜血的双手，皱起眉头。

"有点脏。"
```

### 模板3：终极对决

```markdown

【是否确认？】
```

## 六、综合练习任务

### 任务一：完整开篇（1500字）

场景设定：主角穿越到一个妖魔横行的古代世界，原身是一个被人欺凌的废物少爷。金手指是"深蓝修改器"。九连城的各大家族正在瓜分主角家族的产业。

要求：
- 营造黑暗压抑的氛围
- 展现主角的冷酷利己
- 展示系统的基本功能
- 结尾要有"冲突即将开始"的悬念

### 任务二：帮派争斗场景（1200字）

场景设定：主角加入了赤鲸帮（一个小帮派），现在要对付另一个帮派"黑风寨"的挑衅。敌人有三十多人，主角决定一个人去解决。

要求：
- 体现主角的杀伐果断
- 战斗场面要爽
- 结尾要有霸气收尾
- 可以加入一些"反派死于话多"的笑点

### 任务三：碾压宗门天才（1000字）

场景设定：主角在元魔宗得罪了一个"天才弟子"，对方纠集了一百多个同门来围杀主角。但主角完全不在乎，决定一个人迎战。

要求：
- 敌人要嚣张
- 主角要淡定
- 碾压要彻底
- 要有"你们一起上吧"的霸气
- 结尾可以加一些旁人的震惊反应

### 任务四：经典滚开式对话（800字）

场景设定：主角和一个"正义使者"辩论。"正义使者"指责主角"杀人如麻"、"不配称为人"。主角用滚开式的逻辑反驳他。

要求：
- "正义使者"要义正言辞
- 主角的反驳要简洁有力
- 主角的三观要完全贴合"丛林法则"
- 可以有适当的反差萌
- 结尾要让"正义使者"无话可说
