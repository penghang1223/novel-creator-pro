> 本文件提供可直接使用的模板，涵盖开篇、场景、对话、结尾等多种场景，帮助快速生成符合狐尾风格的内容。

## 一、开篇生成模板

### 1.1 标准开篇结构

```
[平静场景建立] → [异常出现] → [主角怀疑] → [制造悬念]
```

## 二、场景生成模板

### 2.1 诡异空间场景

```markdown
# 【场景生成模板】

## 入口描写

你来到这里的方式是模糊的。
不是走来的。
不是坐车来的。
是——"出现"的。
你站在这里的时候，之前在做什么？
你不记得。
或者——之前没有"之前"？

## 空间物理规则

这里的空间是扭曲的。
不是"看起来"扭曲。
是**真的**扭曲。
你的左手在身体的左边。
你确定。
但如果往前走三步——
左边会变成右边。
不是物理上的改变。
是"方向"本身在变。
你不能相信你的前、后、左、右。

## 时间规则

这里的时间——

时间在这里是什么？
是存在的吗？
还是——

这里没有时间。
这里只有"这一刻"。
"这一刻"有多长？
你不知道。
也许一秒。
也许一年。
也许——

"这一刻"就是永恒。

## 存在着的"什么东西"

你感觉到了。
有什么东西在看你。
不是目光。
目光是"看"的媒介。
但这里没有眼睛。
那是什么在"看"？

是——空间本身？
是"这里"在看你？
是——

你知道那东西存在。
你知道它就在你身边。
但你不知道它是什么。
它有形状吗？
有大小吗？
有——

有恶意吗？

## 离开的可能

你能离开吗？
怎么离开？
你不知道。
你来的时候没有"门"。
走的时候——会有吗？

也许你会一直在这里。
也许你会变成"这里"的一部分。
也许——

你会变成那个在"看"的东西。

## 污染效果

[离开后主角的变化]

你回到了"外面"。
外面是正常的。
有阳光。
有声音。
有——颜色。

但你看"颜色"的方式变了。
红色看起来太深了。
绿色看起来太——

太"活着"了。

你开始怀疑。
"外面"是"真的"吗？
还是——

还是"这里"才是"真的"？
```

## 三、对话生成模板

### 3.1 质疑型对话

```markdown
# 【医生/质疑者 vs 主角】

质疑者：[描述动作，语气平静]
火旺，你最近睡眠怎么样？

主角：[描述动作，语气……]
还好。
做了个梦。
梦到一扇红色的门。

质疑者：红色的门？
什么样的门？
为什么记得这么清楚？

主角：[犹豫]
……是木头的。
有狮头门把手。
门把手是铜的。
上面有……眼睛。
不对。
门把手没有眼睛。
是把眼睛的位置——挖掉了。

质疑者：[停顿]
火旺，你知道门把手不可能有眼睛。
门把手是金属。
眼睛是有机物。
这两者不能——

主角：[打断]
我知道。
我知道门把手不可能有眼睛。
但我看到了。
不是"觉得"。
是**看到**。

质疑者：[平静]
你确定你"看到"了？
还是"记得"自己"看到"了？
这两者有区别。

主角：[沉默]
[很长的沉默]
……有区别吗？

质疑者：[温和地]
这就是我们今天要讨论的问题。
你觉得呢？

主角：[再次沉默]
[内心独白开始]

我觉得——
我什么都不能确定了。
门把手有没有眼睛。
我有没有看到。
"看到"和"记得"有什么区别。

但有一件事——
我知道——
有什么东西在那里。
在我梦里。
在那扇门后面。
也许在我——

在我脑子里的某个地方。

它在那里。
我知道。
但我——

我**怎么知道**的？
```

火旺……

别。

那个"我"——

也在看着你吗？

关怀者：[不理会后退，继续靠近]

不管那个门是"真的"还是"假的"——

我在这里。

主角：[内心动摇]
[但仍有怀疑]

……但如果"我"是假的呢？

只是那扇门投射出来的——

关怀者：[轻声]
那你就是那扇门投射出来的"我"。
也是我的"我"。

主角：[震动]

……你说什么？

就算一切都是幻觉。

## 七、使用指南

### 7.1 模板选择原则

| 情境 | 推荐模板 |
|------|----------|
| **新章节开篇** | 标准开篇模板一或二 |
| **进入诡异空间** | 诡异空间场景 |
| **遇到诡异存在** | 诡异遭遇场景 |
| **医患对话** | 质疑型对话 |
| **情感互动** | 关怀型对话 |
| **制造悬疑** | 章节结尾模板 |
| **精神状态变化** | 癫狂状态文本生成 |
| **世界切换** | 转换桥段模板 |

### 7.2 模板修改建议

1. **颜色意象**：不要只写"红色"，可以写"红得像干涸的血"或"不正常的、刺眼的红"
2. **具体细节**：门把手、眼眶、数字——越具体越真实
3. **节奏控制**：癫狂模板不是全部使用，需要根据情节渐进使用
4. **情感锚点**：在癫狂描写中不忘插入情感/记忆锚点

### 7.3 创作后的自检

- [ ] 重复是否有递进效果？
- [ ] 碎片化是否保持悬念而非混乱？
- [ ] 癫狂描写是否让读者感到压力而非厌烦？
- [ ] 章节结尾是否留下足够的钩子？
- [ ] 转换是否平滑？
