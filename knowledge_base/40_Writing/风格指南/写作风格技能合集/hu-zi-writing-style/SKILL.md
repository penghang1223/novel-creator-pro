# 会说话的肘子写作风格技法

## 任务目标

本 Skill 提供两大核心能力：

### 能力一：方法论指导
- 系统创新设计：有趣、有代价、有成长
- 废土世界构建：残酷中有希望
- 脑洞设计：新奇设定服务于剧情
- 群像成长：配角各有故事线

### 能力二：文风文本生成
- 轻松热血结合的文本风格
- 脑洞清奇的设定描述
- 凡人逆袭的燃点描写
- 废土中的人性温暖

---

## 核心理念

### 系统即剧情
系统不是外挂，而是故事的核心驱动力。好的系统设计要有：
- 趣味性：让读者期待系统激活
- 代价性：使用要付出代价
- 成长性：随主角成长而进化

### 废土中的希望
废土世界不是绝望的深渊，而是人性光辉的试炼场：
- 残酷是背景，温暖是核心
- 在绝望中守护希望
- 小人物的成长最为动人

### 轻松与热血结合
搞笑不是削弱，而是为热血铺垫：
- 笑点之后是燃点
- 轻松中见深度
- 热血要有前期的铺垫

## 操作步骤

### 1. 系统创新设计

调用 `references/creative-system.md` 获取详细技法

**核心原则**：系统要有灵魂，不是数字工具

**创新方向**：
- 怨恨系统：《大王饶命》收集负面情绪
- 任务系统：《第一序列》完成奇葩任务
- 能力要有代价，使用要有风险

**设计模板**：
```
【系统名称】：xxx
【触发条件】：xxx
【核心功能】：xxx
【代价/限制】：xxx
【趣味点】：xxx
【成长路径】：xxx
```

### 2. 废土世界构建

调用 `references/wasteland-world.md` 获取详细技法

**世界观要素**：
- 灾难原因：核战、病毒、异变...
- 生存法则：资源稀缺、弱肉强食
- 势力分布：庇护所、组织、流浪者
- 希望所在：主角守护的东西

**废土温度**：
- 不是冰冷的绝望
- 而是有温度的残酷
- 人性光辉在黑暗中更显耀眼

### 3. 脑洞设计技法

调用 `references/brain-hole.md` 获取详细技法

**脑洞原则**：
- 新奇但不离谱
- 服务于剧情而非哗众取宠
- 要有逻辑支撑

**常见脑洞类型**：
| 类型 | 示例 |
|-----|------|
| 能力脑洞 | 抽取别人的负面情绪变强 |
| 设定脑洞 | 废土上的超凡觉醒 |
| 身份脑洞 | 主角的真实身份 |
| 剧情脑洞 | 意想不到的反转 |

### 4. 群像成长设计

调用 `references/group-growth.md` 获取详细技法

**群像原则**：
- 配角不是工具人
- 各自有故事线
- 与主角共同成长

**《第一序列》群像**：
- 任小粟：主角，从幸存者到守护者
- 颜六元：兄弟情，各自的成长
- 周迎雪：从敌人到伙伴
- 杨小槿：废土中的温暖

### 5. 热血情节设计

**热血公式**：
```
轻松铺垫 → 危机出现 → 笑点转折 → 热血爆发
```

**操作要点**：
- 前期轻松搞笑，降低读者防备
- 危机出现，紧张感上升
- 意想不到的笑点转折
- 热血燃点在此刻爆发

### 6. 文本生成（直接输出）

调用 `references/text-generator.md` 获取完整生成规则

**生成模块**：
- 系统激活场景
- 废土生存场景
- 脑洞设定描述
- 热血爆发场景
- 群像互动场景

**核心基调**：
- 轻松中有深度
- 搞笑中有热血
- 废土中有希望
- 凡人能逆袭
