# 废土世界构建技法

## 核心理念

> 废土世界不是绝望的深渊，而是人性光辉的试炼场

废土世界特点：
- 残酷是背景
- 温暖是核心
- 在绝望中守护希望
- 小人物的成长最动人

---

## 世界观基础构建

### 一、灾难背景

**灾难类型**：

| 类型 | 特点 | 剧情潜力 |
|-----|------|---------|
| 核战 | 经典废土，辐射变异 | 人类反思、资源争夺 |
| 病毒 | 感染者、幸存者 | 人性考验、避难所 |
| 异变 | 超凡觉醒、新秩序 | 力量体系、势力重组 |
| 外星入侵 | 抵抗与共存 | 科技vs超凡、文明存续 |

**设计要点**：
- 灾难原因要合理
- 灾难后要有改变
- 灾难真相可以是伏笔

### 二、生存法则

**资源稀缺**：
- 食物、水、能源
- 药品、武器、信息
- 安全区、庇护所的通行证

**弱肉强食**：
- 势力等级森严
- 个人实力决定地位
- 规则由强者制定

**人性考验**：
- 信任是奢侈品
- 背叛是常态
- 守护是选择

### 三、势力分布

**势力类型**：

| 类型 | 特点 | 代表 |
|-----|------|------|
| 官方庇护所 | 秩序、资源、等级 | 101庇护所 |
| 民间组织 | 自由、生存、兄弟 | 各种战队 |
| 流浪者 | 无根、自由、危险 | 独行者 |
| 异类势力 | 特殊目标、神秘 | 实验体、变异者 |

**势力关系**：
- 合作与对抗并存
- 利益驱动关系变化
- 主角在势力间周旋

## 废土温度设计

### 核心原则

**不是冰冷的绝望，而是有温度的残酷**

**温度来源**：
- 兄弟情义
- 守护弱者
- 废土中的爱情
- 共同的理想

### 《第一序列》的温度设计

**任小粟与颜六元**：
- 非亲兄弟，胜似亲兄弟
- 共同成长，各自抉择
- 废土中的温暖底色

**庇护所中的人情**：
- 不是所有人都是冷血
- 小人物的善良
- 选择守护的人

### 温度设计模板

```
【核心羁绊】：xxx（主角守护的人/事）
【温暖场景】：xxx（废土中的温情时刻）
【牺牲选择】：xxx（为守护而付出）
【希望所在】：xxx（为什么还要活下去）
```

## 废土生存细节

### 日常生存

**资源获取**：
- 搜寻废墟
- 狩猎变异生物
- 与其他幸存者交易/冲突

**危险来源**：
- 变异生物
- 其他幸存者
- 环境（辐射、污染）
- 组织势力的压榨

### 社会结构

**庇护所内部**：
- 统治阶层
- 武装力量
- 普通居民
- 底层幸存者

**庇护所外部**：
- 流浪者营地
- 各种势力据点
- 危险区域

---

## 废土中的超凡体系

### 超凡来源

**《第一序列》设定**：
- 灾难后人类觉醒
- 超凡能力多样
- 能力有等级
- 能力有代价

### 能力设计

**能力类型**：
| 类型 | 特点 | 代表 |
|-----|------|------|
| 战斗型 | 直接杀伤 | 元素操控 |
| 辅助型 | 增强生存 | 感知、治愈 |
| 特殊型 | 独特效果 | 空间、时间 |

**能力代价**：
- 使用消耗精神力
- 过度使用会失控
- 能力越大，代价越大

---

## 废土中的剧情设计

### 生存危机

**危机类型**：
- 资源危机：食物/水/药品短缺
- 安全危机：庇护所被攻破
- 身份危机：被追杀/暴露
- 选择危机：道德困境

### 势力博弈

**博弈要点**：
- 主角在不同势力间周旋
- 利益驱动的合作与背叛
- 最终选择立场

### 成长与选择

**成长弧线**：
```
幸存者 → 觉醒者 → 势力核心 → 守护者
```

**关键选择**：
- 为生存还是为信念
- 独善其身还是兼济天下
- 牺牲自我还是守护他人

---

## 检查清单

构建废土世界时检查：

- [ ] 灾难背景是否合理？
- [ ] 生存法则是否残酷但有逻辑？
- [ ] 势力分布是否清晰？
- [ ] 是否有温度设计？
- [ ] 超凡体系是否自洽？
- [ ] 危机是否有层次？
- [ ] 主角成长路径是否清晰？
