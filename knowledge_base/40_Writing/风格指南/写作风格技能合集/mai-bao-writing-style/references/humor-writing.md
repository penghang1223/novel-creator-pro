# 幽默写作技法库

> 卖报小郎君轻松诙谐风格核心技法

---

## 一、幽默理论基础

### 幽默的本质

```markdown
## 幽默公式
幽默 = 期待违背 + 安全释放

### 解读
1. 建立预期（让读者预判）
2. 打破预期（意外反转）
3. 安全距离（无害/轻松）

### 卖报小郎君的幽默特点
- 轻松为主，不以幽默为目的
- 服务于人物塑造和剧情推进
- 适时适度，不过分搞笑
- 有记忆点，有梗有料
```

## 二、幽默类型大全

### 类型一：吐槽式幽默

**核心**：角色对自身/他人/系统的吐槽

```markdown
## 基础句式

### 自我吐槽
"我叫许七安，一个普通的穿越者。
没有显赫身世，没有逆天资质，没有大佬做靠山。
唯一的金手指，是一个只会吐槽我的系统。"
（来源：《大奉打更人》风格）

### 系统吐槽
"叮～检测到宿主做出智障行为，已自动开启保护模式。
预计存活概率：0.01%。"
"系统，我怀疑你在针对我。"
"叮～系统表示：你确实值得被针对。"

### 命运吐槽
"作为一个主角，我本该一路开挂，走上人生巅峰。
但现实告诉我，我可能拿的是炮灰剧本。"

### 能力吐槽
"经过多年苦修，我终于掌握了——
做饭。
我的厨艺已经达到了可以开店的水平。
嗯，虽然还没人敢来吃。"
```

**使用场景**
- 开场自我介绍
- 系统登场介绍金手指
- 能力不足时的自嘲
- 遇到困境时的调侃

**技巧要点**
- 找准吐槽点（自嘲点）
- 保持轻松语气
- 不要过度自贬
- 埋下反转伏笔
```

### 类型二：反差式幽默

**核心**：身份/行为/场景的反差制造笑点

```markdown
## 反差类型库

### 身份反差
"堂堂大奉第一高手，此刻正蹲在墙角吃烧鸡。
他看到我的瞬间，烧鸡掉在了地上。
'你什么都没看到。'他说。
'我看到了。'我捡起烧鸡，咬了一口，'真香。'"

### 形象反差
"这位就是传说中的冷面神捕？
我只看到一个拿着糖葫芦的小老头。
'这是我的伪装。'他严肃地说。
然后他又舔了一口糖葫芦。"

### 严肃场景喜剧化
"大堂之上，气氛凝重。
县太爷一拍惊堂木——
'堂下何人，为何见本官不跪？'
'回大人，我腿麻了。跪不下去。'
全场沉默。"

### 前后反差
"三年前，他是京城第一才子，出口成章。
三年后，他是我的债主，正在追着我打。
'站住！还钱！'
'大哥你听我解释！'"
```

**使用场景**
- 高手/大人物登场
- 严肃场合打破气氛
- 人物回忆对比
- 场景转换过渡

**技巧要点**
- 先建立"严肃"形象
- 反差要合理自然
- 保持人物性格一致
- 不要为了反差而反差
```

### 类型三：梗式幽默

**核心**：网络梗、历史梗、行业梗的灵活运用

```markdown
## 梗类型库

### 网络梗
"这波啊，这波是肉包子打狗。"
"我不要你觉得，我要我觉得。"
"真香警告。"
"我裂开了。"
"格局小了。"
"打扰了，告辞。"
"就挺突然的。"

### 历史梗
"纸上得来终觉浅，绝知此事要躬行。
古人诚不欺我——亲自动手确实比看书快。
虽然书上也没教我如何越狱。"

### 行业梗
"作为一个专业的打更人，我的口号是——
白天睡觉，夜里巡逻，没事查案，有事跑路。"
"本医者的专长是——头疼开颅，脚疼截肢，肚子疼灌药。
至于治不治得好，那就要看天意了。"

### 文豪梗
"李白斗酒诗百篇，我斗酒只能吐三天。"
"杜甫草堂天下知，我在草堂吃泡面。"
"陶渊明采菊东篱下，我在东篱抓鸡鸭。"
```

**使用场景**
- 日常对话
- 内心吐槽
- 紧张氛围调节
- 人物互动

**技巧要点**
- 梗要符合时代背景（穿越者身份）
- 不要过度堆砌
- 自然融入对话
- 避免生僻梗/过时梗
```

### 类型四：自嘲式幽默

**核心**：主角承认自己的"low"或失败

```markdown
## 自嘲句式库

### 能力自嘲
"作为一个穿越者，我曾经以为我能靠抄诗走上人生巅峰。
后来发现，这个世界的人都会背唐诗。
'春眠不觉晓？'
'处处闻啼鸟！'
行吧，当我没说。"

### 地位自嘲
"别人穿越不是皇子就是世子，最差也是个有金手指的废柴。
我穿越成了——牢犯。
开局一个碗，装备全靠捡。"
不对，我没有碗。"

### 金手指自嘲
"别人的系统是逆天改命，我的系统是逆天吐槽。
'叮～检测到宿主智商余额不足，请及时充值。'
充值？我连饭都吃不起，还充值？"

### 运气自嘲
"别人穿越是气运之子，走到哪都有宝贝砸头上。
我穿越是气运之孙，走到哪都有锅砸头上。
'你被捕了。'
'？？？我做了什么？'
'因为你运气太好，涉嫌影响他人运气平衡。'
这罪名闻所未闻。"

### 努力自嘲
"天道酬勤，这是骗人的。
我每天努力修炼，实力却纹丝不动。
后来我发现，问题出在我修炼的功法上——
《如何成为一个合格的炮灰》。
这功法确实不适合主角修炼。"
```

**使用场景**
- 主角低谷期
- 与他人对比时
- 开局/重生设定
- 调节气氛

**技巧要点**
- 自嘲但不自卑
- 埋下逆袭伏笔
- 保持读者好感
- 不要过度卖惨
```

### 类型五：对话式幽默

**核心**：两人/多人对话中的语言博弈

```markdown
## 对话幽默模板

### 模式一：捧哏逗哏
"我觉得我行。"
"我觉得你不行。"
"我觉得你不行不行。"
"我觉得你行也行。"
"……我们这是在说什么？"
"不知道，反正挺热闹的。"

### 模式二：逻辑反转
"你知道我为什么打你吗？"
"不知道。"
"因为你欠打。"
"等等，我为什么欠打？"
"因为我今天想打人。"
"……这是什么逻辑？"
"我的逻辑。"

### 模式三：认真搞笑
"你这样做是不对的。"
"哪里不对？"
"哪里都不对。"
"能不能具体一点？"
"具体就是——你活着这件事本身就不对。"
"……"
"开玩笑的。你死了才对。"

### 模式四：连环套
"你叫什么名字？"
"许七安。"
"你从哪里来？"
"从牢里来。"
"你去哪里？"
"去另一个牢里。"
"……你是犯人？"
"目前是自由的。"
"那你去牢里干嘛？"
"工作。打更人。"
"……"

### 模式五：双关梗
"你说的'关'是什么意思？"
"就是关门大吉的'关'。"
"那是倒闭的意思。"
"对，倒闭。"
"为什么要倒闭？"
"因为你不关门，我就要关门了。"
"……这和门有什么关系？"
"没关系，就是想关门。"
```

**使用场景**
- 日常互动
- 角色出场介绍
- 紧张场景调剂
- 建立角色关系

**技巧要点**
- 对话要有来有往
- 保持人物性格
- 控制节奏
- 避免过度水字数
```

### 类型六：情景式幽默

**核心**：特定场景下的幽默营造

```markdown
## 情景幽默库

### 危机时刻
"敌人：'受死吧！'
我：'等等，让我先写个遗书。'
敌人：'你有遗言？'
我：'没有，就是想拖延时间等人来救。'
敌人：'……'
我：'你不动手吗？'
敌人：'我等你说完了再动手。'
我：'其实也没什么好说的。'
敌人：'那就受死吧！'
我：'等等——'"

### 打脸时刻
"那个人嘲笑我是废物。
第二天，他把嘲笑我的那段话刻在了牌匾上。
因为那是他人生中最后一个辉煌时刻。
第三天，他来找我求饶。"
"你不是很嚣张吗？"
"那是昨天的事。今天我学会了低调。"
"学会了吗？"
"没有。刚才那句话又暴露了。"

### 装逼时刻
"装逼失败的经典案例：
我本想像电视剧里那样潇洒地转身离开。
结果——
踩到了香蕉皮。
扑街。
全场沉默。
'这就是传说中的轻功吗？'有人问。
'是的，最新研发的功法。叫脸着地。'"

### 尴尬时刻
"我去相亲了。
对方问：'你有什么爱好？'
我想了想：'坐牢。'
对方：'？？？'
'不是那个意思！我是说——'
'没关系，我不介意。'
'但我介意！我介意你介意！'"
```

## 三、幽默节奏控制

### 密度控制

```markdown
## 幽默分布原则

### 章节内
- 每1000字1-2个笑点
- 开头结尾可适当增加
- 中间重点段落减少
- 保持"正常叙述+幽默点缀"的节奏

### 场景内
- 日常场景：可以连续幽默
- 紧张场景：最多1-2个笑点
- 情感场景：减少幽默，保持氛围
- 高潮场景：几乎不用幽默

### 情绪线
- 低谷期：增加幽默调节
- 平稳期：保持适度幽默
- 高潮期：减少幽默，严肃推进
- 结尾期：根据结局类型调整
```

### 度把控

```markdown
## 幽默过头表现
❌ 全程堆砌笑点，没有实质内容
❌ 每个角色都在搞笑，失去特色
❌ 搞笑与剧情脱节
❌ 为了幽默牺牲人物
❌ 梗过于生僻/低俗

## 幽默不足表现
❌ 全文过于严肃压抑
❌ 人物对话干巴巴
❌ 缺少记忆点
❌ 节奏过于平缓

## 黄金平衡点
✅ 轻松为主，适度幽默
✅ 幽默服务人物和剧情
✅ 每个角色有独特的幽默方式
✅ 关键情节保持严肃
✅ 笑点有记忆点，不俗套
```

"我说你不行。"

然后它就发生在我身上了。"

## 五、实战模板

### 模板一：人物出场

```markdown
## 出场幽默模板

"她来了。
踏着七彩祥云——不，是踩着泥泞小路。
穿着华丽锦袍——不，是披着我家旧床单。
她是京城第一美人。
——据她自己说的。
'难道不是吗？'她问。
'是是是，'我连忙点头，'在我见过的所有人里，你确实是最美的。'
'只是所有人里？'
'……在我见过和听说过的所有人里。'
'还好。'
她满意地点点头。
我松了口气。
活着真好。"

### 要素
1. 先正经介绍身份
2. 立刻打破形象
3. 加入主角吐槽
4. 有反转/意外
5. 保持人物魅力
```

### 模板二：紧张场景调剂

```markdown
## 紧张场景幽默模板

"剑光闪过。
我以为我死了。
但我没有。
因为——
剑偏了。
偏得很有技术含量。
'不好意思，'持剑人说，'第一次当刺客，业务不熟练。'
'……你行不行啊？'
'我不行，但我收费便宜。'
'便宜没好货？'
'对。'
我沉默了。
他沉默了。
我们都在思考一个问题：
我是不是该换一个刺客？"

### 要素
1. 先建立紧张感
2. 突然转折打破
3. 保持角色特色
4. 意外但合理
5. 调节读者情绪
```

### 模板三：装逼打脸

```markdown
## 装逼打脸模板

"'就凭你？也想打败我？'
对方很嚣张。
我也很紧张。
但我更会装。
'不试试怎么知道呢？'我微微一笑。
然后——
我动了。
只一招。
对方倒地。
'……'全场寂静。
'发生了什么？'有人问。
'不知道，'我收起手中的拖鞋，'可能是我太帅了，闪瞎了他的眼。'
'……'
'开玩笑的。我就是扔了个拖鞋。'
'拖鞋？'
'对，刚才在地上捡的。没想到这么好用。'
'……'

### 要素
1. 先让对方嚣张
2. 主角表面淡定
3. 实际用了很low的方法
4. 但效果拔群
5. 自嘲+反转
```

## 六、检查清单

```markdown
## 幽默自检

### 检查点
- [ ] 笑点是否与人物性格一致？
- [ ] 笑点是否服务剧情？
- [ ] 是否避免了过度堆砌？
- [ ] 笑点是否过时/低俗？
- [ ] 关键场景是否保持了严肃？
- [ ] 每个角色的幽默方式是否不同？
- [ ] 笑点是否有记忆点？
- [ ] 读者会记住哪个笑点？

### 常见问题
❌ 所有角色都在用同一种幽默方式
❌ 幽默太多导致内容空洞
❌ 梗过时/太冷门
❌ 搞笑破坏了人物形象
❌ 紧张场景被幽默破坏
```
