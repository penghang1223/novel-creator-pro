# 案件推理设计技法

## 核心理念

> 案件是驱动力，推理是爽点，逻辑是底线

卖报风格案件特点：
- 案件驱动剧情
- 推理过程有悬念
- 逻辑严密无漏洞
- 穿插搞笑元素
- 主角用独特视角破案

---

## 案件设计原则

### 一、案件即剧情

**原则**：案件不是独立副本，而是推动主线

**操作方法**：
- 案件背后有大阴谋
- 每个案件揭露一部分真相
- 案件之间有关联

**《大奉打更人》案件设计**：
- 太平县案 → 引出更大的势力
- 每个案件都是大棋局的一部分
- 案件推动主角成长和关系

### 二、推理要严密

**原则**：推理不能有逻辑漏洞

**操作要点**：
- 线索要在前期铺垫
- 推理过程要可复现
- 不能靠主角"直觉"

**推理设计模板**：
```
【案件】：xxx
【死者/受害者】：xxx
【嫌疑人】：xxx（列出多个）
【线索】：xxx（分显性和隐性）
【推理过程】：xxx
【关键转折】：xxx
【真相】：xxx
【后续影响】：xxx
```

### 三、爽点在破案

**原则**：破案过程要让读者爽

**爽点来源**：
- 主角的独特视角
- 意想不到的推理
- 打脸傲慢者
- 真相揭露的震撼

## 案件类型

### 1. 密室案件

**特点**：看似不可能犯罪

**设计要点**：
- 密室形成要有合理解释
- 不能靠超自然力量（除非设定允许）
- 主角的破局方式要巧妙

### 2. 连环案件

**特点**：多起案件有关联

**设计要点**：
- 案件之间有规律
- 主角发现规律的过程
- 最终找到幕后黑手

### 3. 政治案件

**特点**：涉及权力斗争

**设计要点**：
- 案件是权力博弈的体现
- 破案要考虑各方势力
- 主角在夹缝中行事

### 4. 灵异案件

**特点**：看似超自然力量

**设计要点**：
- 要有合理的非灵异解释
- 或者有符合世界观的灵异设定
- 主角用独特方式破案

## 推理过程设计

### 第一步：案件呈现

- 发现案件
- 受害者/死者情况
- 初步调查
- 嫌疑人名单

### 第二步：线索收集

**显性线索**：
- 物证
- 人证
- 现场

**隐性线索**：
- 时间线矛盾
- 人物关系
- 动机分析

### 第三步：推理展开

- 主角提出假设
- 验证假设
- 排除错误方向
- 逼近真相

### 第四步：真相揭露

- 锁定真凶
- 解释作案手法
- 揭露动机
- 后续影响

## 搞笑元素穿插

### 原则

**严肃中见轻松，紧张中有笑点**

### 穿插方式

| 场景 | 搞笑元素 |
|-----|---------|
| 审讯 | 主角的骚操作提问 |
| 调查 | 与配角的互怼 |
| 分析 | 吐槽案件的离谱 |
| 破案 | 打脸傲慢者 |

### 示例

**严肃场景的搞笑穿插**：
> "凶手的手法很专业。"许七安看着尸体说。
> "你怎么知道？"
> "因为如果是我，我会做得更干净。"
> "...你这是在炫耀吗？"

## 检查清单

设计案件时检查：

- [ ] 案件推动主线了吗？
- [ ] 推理过程有漏洞吗？
- [ ] 线索前期铺垫了吗？
- [ ] 破案过程有爽点吗？
- [ ] 有搞笑元素穿插吗？
- [ ] 案件逻辑自洽吗？
