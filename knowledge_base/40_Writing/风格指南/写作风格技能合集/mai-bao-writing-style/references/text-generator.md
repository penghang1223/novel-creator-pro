# 文风文本生成器

> 卖报小郎君风格模仿与创作工具

---

## 一、文风特征提取

### 语言风格特征

```markdown
## 卖报小郎君文风标签

### 句式特征
- 短句为主，长短交错
- 段落简洁，节奏明快
- 逗号停顿，句号收尾
- 感叹号强化情绪
- 问号制造悬念

### 语气特征
- 轻松调侃
- 自嘲幽默
- 偶尔正经
- 有梗有料
- 代入感强

### 修辞特征
- 比喻接地气
- 对比反差萌
- 排比增强气势
- 反问制造互动
```

## 二、开篇模板生成器

### 模板一：穿越开场

```markdown
## 生成模板
"我叫[名字]，[穿越前身份]。
本来以为穿越后能[期待的事情]。
结果——
[意外反转]。
[金手指/系统介绍]。

现在我面临的问题是：[困境]。

但没关系。
因为我是主角。"
```

### 示例输出
"我叫许七安，一个普通的社畜。
本来以为穿越后能左拥右抱，走上人生巅峰。
结果——
穿越到了牢里。
好消息：确实左拥右抱了——两个狱友。
坏消息：左边那个在磨刀，右边那个在哭。
'系统，我是不是拿错剧本了？'
系统没有回应。
大概也觉得没救了。

现在我面临的问题是：怎么活着出去。

但没关系。
因为我是主角。
——虽然这个开局确实有点惨。"
```

## 三、场景描写模板

### 场景一：紧张对峙

```markdown
## 生成模板
"气氛凝固。
[描述紧张感]。

对方[做了什么]，然后[说了什么]。

我[反应]。

'你不怕吗？'他问。
'怕。'
'怕还不跑？'
'跑不掉。'
'那你打算怎么办？'
'等死。'
'……'

'我打算——[反击]。'"
```

### 示例输出
"气氛凝固。

对方拔出刀，刀光如雪。

我后退一步，又后退一步。
退无可退。

'你不怕吗？'他问。
'怕。'
'怕还不跪下求饶？'
'怕也跪了，能活着吗？'
'不能。'
'那跪了干嘛？'

他一愣。

'我打算——赌一把。'

是的，拖鞋。
唯一的武器。
'你有刀，我有拖鞋。
公平对决。'
'……'
'开玩笑的。'
我转身就跑。
'救命啊——！'"
```

## 四、对话生成模板

```markdown
## 生成模板

```

'叮～宿主理解能力提升中。'
'这有什么好提升的？！'
'叮～因为确实需要。'
'……'
'行，我躺平了。你开心就好。'"
```

## 八、风格速查表

| 场景 | 风格 | 关键词 | 示例句式 |
|------|------|--------|----------|
| 开场 | 幽默+悬念 | 穿越/系统/困境 | "我叫XXX，本来以为……结果……" |
| 紧张 | 紧张+反转 | 危险/对峙/悬念 | "他不说话。空气凝固。" |
| 打脸 | 铺垫+爆发 | 嘲讽/震惊/碾压 | "所有人看着我。" |
| 日常 | 轻松+暧昧 | 互动/吐槽/暧昧 | "系统，我觉得你在针对我。" |
| 推理 | 冷静+分析 | 线索/逻辑/揭露 | "让我来告诉你们真相。" |
| 感情 | 温情+暧昧 | 关心/心动/表白 | "我保护你。不需要理由。" |
