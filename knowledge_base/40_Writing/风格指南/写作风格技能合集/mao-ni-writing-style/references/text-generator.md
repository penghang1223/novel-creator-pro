# 文风文本生成器：模板、范例与练习

## 概述

猫腻的文风可以用四个字概括：**"文"而"不装"**。有文学质感但不矫情，有思想深度但不说教。本文档提供系统性的文风训练方法，帮助作者掌握猫腻式的文字魅力。

---

## 一、猫腻文风的五大特征

### 特征一：精准而克制

**核心要点**：
- 每个词都有存在理由
- 不用多余的形容词
- 用动词代替形容词

**对比示范**：
```markdown
// 冗余（差）
范闲的心情非常复杂，他感到无比沉重和悲伤，
眼中闪烁着晶莹的泪光，心中涌起无限的感慨。

// 精准（好）
范闲沉默了很久。
窗外有风吹过，他忽然觉得很累。
然后他笑了一下。
是那种很淡的笑，淡到像是没有笑过。
```

### 特征二：留白与余韵

**核心要点**：
- 不把话说满
- 情感点到即止
- 让读者自己体会

**对比示范**：
```markdown
// 直白（差）
范闲对林婉儿一见钟情，他的心跳加速，脸颊发红，
他知道自己爱上了这个女子。

// 留白（好）
林婉儿回过头。
烛火在她脸上投下一片柔和的光。
范闲忽然觉得，今晚的月亮，好像格外亮了一些。
```

### 特征三：对话即人物

**核心要点**：
- 不同角色说不同风格的话
- 身份、性格决定语气
- 潜台词藏在表面之下

**对比示范**：
```markdown
// 扁平（差）
"你好，我是范闲。"
"你好，我是林婉儿。"
"很高兴认识你。"
"我也是。"

// 立体（好）
"你就是范闲？"
林婉儿上下打量着他，目光里带着几分审视，几分好奇。
"怎么，不像？"
"不像。"她老实说，"以为会更凶一点。"
范闲笑了："那是将军，不是书生。"
```

### 特征四：动作即心理

**核心要点**：
- 心理活动不直接写
- 用动作、细节暗示内心
- "身体语言"比"内心独白"更有力

**对比示范**：
```markdown
// 直写心理（差）
范闲心中忐忑不安，不知道这个决定是否正确，
他感到压力很大，有些想退缩。

// 动作暗示（好）
范闲的手指在茶杯上轻轻敲了两下。
那是他紧张时的习惯。
"……行。"
他抬起头，眼神已经恢复了平静。
但茶杯里的水，还是洒出来了一点。
```

### 特征五：长短句交错

**核心要点**：
- 节奏如呼吸，有起有伏
- 短句有力，长句有味
- 根据情绪调整句式

**对比示范**：
```markdown
// 单一节奏（差）
范闲慢慢走着，他看着周围的一切，
心中感慨万千，回忆着过去，展望着未来，
不知道前方还有什么在等待着他。

// 交错节奏（好）
他走在街上。
很长的一条街，从东到西，从白到黑。
他忽然想起小时候，在澹州，也是这样的黄昏。
五竹叔背着他，走得很慢。
"饿了吗？"
"嗯。"
"那就快点走。"
那时候的路，好像永远走不完。
```

## 二、场景描写模板

### 模板一：室内场景

```markdown
// 结构
1. 光线/环境（2-3句）
2. 陈设/氛围（2-3句）
3. 人物状态（2-3句）
4. 细节（1-2个关键物品）
5. 氛围暗示（1句收尾）

// 范例
屋内很暗，只有桌上的一盏油灯。
火光摇曳，在墙上投下晃动的影子。
范闲坐在椅子上，背靠着椅背，脚搭在桌上。
——这是他思考时的习惯。
桌上放着一封信，信封已经被拆开。
信纸上的字迹很熟悉。
落款是一个"爹"字。
他没有看第三遍。
有些事，看一遍就够了。
```

### 模板二：打斗场景

```markdown
// 结构
1. 氛围铺垫（2-3句）
2. 第一招/瞬间（短句）
3. 过程（3-5句，中短句为主）
4. 转折（1-2句）
5. 结束/余韵（1句）

// 范例
刀光一闪。
很快。
快到看不见刀，只看见血。
范闲侧身，血从肩头渗出。
不深。但很疼。
"还行。"他说。
然后他的匕首出手。
没有刀光。
只有风。
然后对方倒了。
风停的时候，范闲已经站在原地。
像是什么都没发生过。
只有地上的血，证明刚才的一切。
```

### 模板三：情感场景

```markdown
// 结构
1. 环境（1-2句，轻描淡写）
2. 人物外在（2-3句，动作为主）
3. 关键细节（1-2个）
4. 沉默/留白（1句）
5. 余韵（1-2句）

// 范例
雨很大。
林婉儿站在屋檐下，没有带伞。
她的裙摆已经湿透了，但她没有动。
远处有脚步声。
她抬起头。
然后又低下去。
"你来晚了。"
"嗯。"
范闲站在雨中，雨水顺着他的脸往下淌。
他什么都没解释。
有些事，解释了也没用。
林婉儿看了他很久。
"……进来吧。"
"嗯。"
雨还在下。
但屋檐下，好像没那么冷了。
```

## 三、人物描写模板

### 模板一：初登场描写

```markdown
// 结构
1. 第一印象（1-2句，整体感知）
2. 核心特征（2-3句，最抓人的特点）
3. 细节（1-2个，有意味的细节）
4. 氛围/悬念（1句收尾）

// 范例
那人坐在窗边，背对着光。
看不清脸，只能看到一个轮廓。
很瘦，很安静。
像是一株长在阴影里的竹子。
他的手指很长，正在翻一本书。
翻得很慢。
像是在数书页，又像是在等什么人。
范闲看了很久，那人始终没有回头。
但他知道有人在看。
因为翻书的动作，停了一瞬。
```

### 模板二：情绪转变描写

```markdown
// 结构
1. 情绪前状态（1-2句）
2. 触发事件（1句）
3. 微小变化（2-3个细节）
4. 情绪后状态（1-2句）

// 范例
陈萍萍在笑。
他很少笑，但今天笑了。
因为范闲带来了一个消息。
"好。"他说，声音很平静。
但他转动轮椅的手，停了一下。
就一下。
很短。
然后他继续转动轮椅，面向窗外。
"去吧。"
他的声音，依然很平静。
平静得像是什么都没有发生过。
但范闲知道，从这一刻起，很多事都不一样了。
```

## 四、对话描写模板

### 模板一：试探性对话

```markdown
// 结构
1. 说话者+动作（1-2句）
2. 对话内容A（1-2句）
3. 听者反应（1-2句）
4. 对话内容B（1-2句）
5. 潜台词暗示（1句）

// 范例
"听说你最近很忙。"
说话的人端着茶杯，目光却没有看向范闲。
"还好。"范闲说，"比闲着强。"
"年轻人，有冲劲是好事。"
"前辈有什么指教？"
茶杯轻轻放下。
"指教不敢当。"那人终于抬起头，"只是想提醒你一句。"
"什么话？"
"有些路，走出去容易，走回来就难了。"
他没有再说什么。
范闲也没有问。
有些话，问了反而没意思。
```

### 模板二：交锋式对话

```markdown
// 结构
1. 冲突背景（1句）
2. 第一轮交锋（你来我往，3-4句）
3. 僵持（沉默或动作，1-2句）
4. 第二轮交锋（升级，2-3句）
5. 转折/收尾（1-2句）

// 范例
"你太让我失望了。"
林若甫的声音很冷。
"是吗？"范闲不慌不忙，"不知道父亲指的是哪件事？"
"哪件事？"林若甫冷笑，"你心里清楚。"
"我心里……"
范闲顿了顿。
然后他笑了。
"我心里很清楚。"他说，"但父亲好像不太清楚。"
"你什么意思？"
范闲站起身，走到窗边。
"我的意思是——"
他回过头，眼神平静。
"有些事，我不说，是因为不想。"
"但您非要问。"
"那就别怪我说了。"
```

## 五、猫腻式句式训练

### 句式一：对比反转

```markdown
// 公式
[看似A]，[实际上B]。[转折：C]。

// 练习
原：范闲很强
改：范闲看起来很弱，弱到谁都可以欺负。
     但只有欺负过他的人才知道——
     这种弱，是装出来的。

原：陈萍萍很可怕
改：陈萍萍看起来很和蔼，对谁都是笑眯眯的。
     但所有人都怕他。
     不是因为他会杀人。
     而是因为他杀的人，都是该死的人。
```

### 句式二：留白省略

```markdown
// 公式
[事件/情感]……[一个沉默/动作]……[余韵]

// 练习
原：范闲很伤心
改：范闲站在那里，一动不动。
     很久。
     久到林婉儿以为他睡着了。
     "……走吧。"
     他的声音有些哑。
     林婉儿没有问为什么。
     有些事，不问比问好。

原：敌人很狡猾
改：那人的陷阱布置得天衣无缝。
     范闲发现的时候，已经晚了。
     "佩服。"
     他说。
     然后他笑了笑。
     那人也笑了。
     两个人都知道，这不是结束。
     只是开始。
```

### 句式三：蒙太奇式跳跃

```markdown
// 公式
[场景A]→[时间跳跃]→[场景B]→[时间跳跃]→[场景C]

// 练习
描写一个人从少年到成年的变化：
三月的桃花开了。
七月的蝉鸣停了。
十一月的雪落下。
三月。
七岁。
十一。
很多年后的某个黄昏，有人问他：
"你还记得吗？"
他记得。
他当然记得。
那是他一生中，最重要的三个数字。
```

### 句式四：细节暗示情感

```markdown
// 公式
[不去直接写情感]→[用一个细节/动作暗示]→[让读者自己体会]

// 练习
原：他很高兴
改：范闲笑了。
     笑得很轻，轻到像是风吹过水面。
     林婉儿看了他一眼，没有说话。
     但她的嘴角，也弯了一下。

原：她很紧张
改：林婉儿的手指在袖子下攥紧。
     很紧。
     但她的脸上什么都没有。
     只有她自己知道，手心已经出汗了。
```

## 六、综合练习

### 练习一：场景改写

将下面的"流水账"改写成具有猫腻风格的场景：

```markdown
// 原文
范闲和林婉儿在花园里见面了。
他们互相问候，聊天很开心。
突然下起了雨，他们赶紧躲到亭子里。
在亭子里他们聊了很久，互相表达了好感。
雨停了，他们依依不舍地分别了。
```

### 练习二：对话改写

将下面的对话改写成有潜台词的权谋对话：

```markdown
// 原文
"这件事你能帮我吗？"
"可以。"
"太好了。"
```

### 练习三：人物描写改写

用猫腻风格描写一个"亦正亦邪"的角色初登场：

```markdown
// 要求
1. 250字左右
2. 要有第一印象的冲击感
3. 要有细节暗示角色的复杂性
4. 最后一句要留有悬念
```

### 练习四：完整段落创作

以"告别"为主题，创作一个300-500字的段落。

```markdown
// 要求
1. 使用长短句交错
2. 有至少2处细节暗示
3. 结尾要"余韵悠长"
4. 不直接写"悲伤""不舍"等情感词
```

## 七、文风自检清单

```
□ 每个词是否都有存在理由？（删掉试试？）
□ 是否避免了冗余的形容词？
□ 情感是否点到即止？（留白而非说满）
□ 对话是否能体现人物性格？
□ 心理活动是否通过动作/细节暗示？
□ 长短句是否有交错？
□ 结尾是否有"余韵"？
□ 是否有猫腻式的"冷幽默"？
□ 是否避免了直白的情感描写？
□ 整体是否有"文学质感"但不矫情？
```

## 八、每日文风练习计划

### 第一周：精准与克制
- 每天改写一段200字的文字
- 目标：删减30%的冗余词句

### 第二周：留白与余韵
- 每天写一段情感场景
- 目标：不使用情感词（悲伤/高兴/愤怒等）

### 第三周：对话与潜台词
- 每天写一段300字的对话
- 目标：每句话都有潜台词

### 第四周：综合创作
- 每周写一个完整场景（1000字）
- 综合运用所有技法
- 请他人阅读，检查是否"说太满"

## 九、经典文风范例

### 范例一：庆余年开篇风格

```markdown
那是一个很长很长的故事。
长到我自己也不知道该从哪里说起。
但如果非要说一个起点的话——
应该是那个雨夜。
那夜的雨很大。
大到像是要把整个世界都淹没。
我站在鉴查院的门口，看着那扇沉重的铁门。
门的那一边，是我从未见过的人。
门的那一边，是我早已注定的命运。
很多年后，有人问我：
"你后悔吗？"
我没有回答。
因为有些事，不是后悔不后悔的问题。
而是——重来一次，你还会这样选吗？
我的答案是：
会。
哪怕知道结局，我依然会推开那扇门。
因为有些门，推开了就再也关不上。
但有些门——
如果你不推开，你永远不知道门后面是什么。
```

### 范例二：将夜书院风格

```markdown
书院很安静。
这种安静不是没有人说话的那种安静。
而是——
每个人都在说话，但每一句话都像是被什么东西包裹着。
你听得到声音，却听不到意思。
你要自己去猜。
猜对了，你是聪明人。
猜错了，你是死人。
所以在书院，最重要的不是修为，不是背景，不是财力。
而是——
能不能听懂别人没说的话。
宁缺花了三年学会这件事。
然后他成了书院最受欢迎的人。
不是因为他会说话。
而是因为他知道，什么时候该不说话。
```

### 范例三：间客硬汉风格

```markdown
许乐的原则很简单。
不做亏心事，不怕鬼敲门。
他这辈子没做过亏心事。
所以他不怕。
有人问他："你不怕死吗？"
"怕。"
"那你还敢？"
"怕和敢，是两回事。"
许乐看着面前的敌人，眼神平静。
"就像你。"
"你怕我吗？"
敌人没有说话。
但他的手，已经在发抖了。
"看，这就是答案。"
许乐笑了。
然后他动手。
很快。
快到没有声音。
快到只有结果。
这就是许乐。
从不废话，只给答案。
```
