# 文风文本生成器

> 彭湃风格开篇/场景/对话模板

---

## 一、开篇模板

### 模板1：都市日常型

```
【适用场景】：故事开始，建立"表世界"

【结构】：
开场环境 → 主角状态 → 日常互动 → 微妙的违和感

【模板】：

七月的离城，阳光刺眼。

高阳站在公交站台，手里攥着一杯冰美式。
耳机里放着歌，但他其实没在听。
他只是不想跟旁边的人说话。

"高阳！"

熟悉的声音从身后传来。
他不用回头也知道是谁——王子凯，他们班的活宝。
"你怎么不等我就自己走了？"王子凯喘着气跑过来，"说好的一起去网吧呢？"

"......忘了。"

"忘了？！"

王子凯作势要打他，高阳笑着躲开。
这是他们每天的日常，无聊、平淡，但不知道为什么，
高阳觉得，这样的日子能一直持续下去就好了。

【注】：最后一句要埋下"伏笔钩子"，暗示后续会有变化
```

### 模板2：身份悬疑型

```
【适用场景】：快速建立"里世界"悬念

【结构】：
异常事件 → 主角反应 → 真相一角 → 悬念

【模板】：

那天的月亮是红色的。

高阳躺在床上，翻来覆去睡不着。
他不知道为什么，总觉得今晚有什么不对劲。
像是空气中有什么东西，在盯着他。

"高阳？"门外传来母亲的声音，"怎么还不睡？"

"......马上。"

他闭上眼睛。
但就在意识模糊的瞬间，他听到了一个声音。
不是母亲的声音。
是从母亲房间里传来的，另一个声音。

"......找到他了。"

高阳屏住呼吸。
他告诉自己，那一定是电视的声音。
一定是的。

但他的心跳，已经快得不正常。
```

### 模板3：倒计时型

```
【适用场景】：建立紧迫感

【结构】：
命运转折 → 倒计时开始 → 第一选择 → 新世界

【模板】：

距离高考还有365天。

高阳看着日历，忽然觉得时间还很长。
十八岁，看起来很遥远。

但他不知道的是，
他的十八岁生日，
是一切的终点。

——

【三个月后】

距离十八岁生日还有三天。

高阳站在天台上，看着这座城市的灯火。
他终于知道了真相。
这个世界，不是他以为的那样。
他的父母不是父母，他的家不是家。

而三天后，他将面临一个选择：
接受虚假的幸福，
还是面对残酷的真实？

他看着手里那张全家福。
照片里的人在笑。
但高阳知道，
那笑容下面，藏着什么。
```

## 二、日常场景模板

### 场景1：校园日常

```
【要素】：考试/恋爱/兄弟情/烟火气

【模板】：

"你这次考得怎么样？"

王子凯凑过来，眼睛里闪着期待的光。
高阳默默把卷子翻了过去。

"......不及格？"
"及格了。"
"那为什么要藏？"
"因为我比你高。"

王子凯的脸瞬间垮了。
"不可能！让我看看！"

高阳躲闪不及，被王子凯一把抢走卷子。
"......八十七？"王子凯的声音都在颤抖，"你作弊了？"

"什么作弊，这是实力。"
高阳拿回卷子，嘴角忍不住上扬。
这种成绩超过兄弟的快乐，他可以回味一整年。

"......你请我喝奶茶。"
"为什么？"
"因为你让我伤心了。"

高阳翻了个白眼，但还是掏出手机。
"一杯还是两杯？"
"三杯！"
"滚。"
```

### 场景2：家庭日常

```
【要素】：中国式父母/唠叨/温暖/烟火气

【模板】：

"高阳！洗手吃饭！"

母亲的声音从厨房传来。
高阳应了一声，从房间出来。
餐桌上已经摆好了菜——红烧排骨、可乐鸡翅、清炒时蔬。
都是他爱吃的。

"今天怎么这么丰盛？"
"你考试考好了呗。"母亲给他盛饭，"你爸说了，吃饱了才有力气学习。"

"爸什么时候说的？"
"刚才，在车里打电话的时候。"
"......"

父亲在客厅看电视，假装什么都没说。
高阳坐下来，拿起筷子。
排骨很香，母亲的厨艺一如既往。
他吃着吃着，忽然有些恍惚。

这样的日子，还能持续多久？

"发什么呆？"母亲敲了敲他的碗，"快吃，凉了不好吃。"

"......哦。"

他低头扒饭，把那些不该有的念头藏了起来。
```

### 场景3：兄弟互动

```
【要素】：默契/损友/真实/温暖

【模板】：

"卧槽，你竟然带吃的了？"

王子凯看着高阳从书包里掏出一个袋子，眼睛都亮了。
"我妈让我带的。"高阳把袋子推过去，"多了一份。"

"多了一份？"
"嗯。"

王子凯打开袋子，里面是两个肉夹馍。
还是热的。
他看了看高阳，又看了看肉夹馍，忽然笑了。

"你妈怎么知道我今天没吃早饭？"

"她不知道。"
"那......"

"我跟我妈说你最近瘦了，让她多做一份。"
高阳的语气很平淡，像是在说今天天气不错。

王子凯愣了几秒。
然后他咬了一口肉夹馍，含糊地说：
"......还行吧，不难吃。"

高阳没说话。
但他记得王子凯最喜欢的早餐店，
记得他每次只吃一个肉夹馍，
记得他总是笑着说"不饿"。

有些话不用说。
兄弟都懂。
```

## 三、关键场景模板

### 场景1：身份揭露

```
【要素】：反转/冲击/情绪爆发

【模板】：

"高阳，生日快乐。"

母亲笑着，手里端着一个蛋糕。
十八根蜡烛，摇曳着暖黄的光。
高阳看着那张熟悉的脸，心里涌起一股暖流。

"谢谢妈。"

他闭上眼睛，准备许愿。
但就在这一瞬间——

"啪。"

灯灭了。

黑暗中，高阳睁开眼。
他看到母亲的眼睛。
那双眼睛，正在发光。

不是烛光。
是另一种光。

"终于等到了。"

母亲的声音变了。
变得陌生，变得冰冷。
"觉醒者，高阳。"

她笑了。
那笑容，高阳看过十八年。
但此刻，他只觉得毛骨悚然。

"你的第十八次心跳，是开启仪式的钥匙。"

她伸出手，掌心有光在凝聚。
"欢迎来到真实的世界，我的孩子。"

蜡烛熄灭了。
高阳的十八岁生日，
是一切的终结。
```

### 场景2：信任崩塌

```
【要素】：背叛/冲击/反转

【模板】：

"相信我。"

黄琦若握着他的手，眼神真挚。
高阳看着她的眼睛，那双他曾经无比信任的眼睛。

"我相信你。"

他点了点头。
这是他这辈子说过最后悔的话。

下一秒，枪口抵住了他的后脑。

"抱歉。"

黄琦若的声音从身后传来。
"这是我的任务。"

高阳没有动。
他甚至没有挣扎。
他只是问了一句：

"......从一开始就是假的吗？"

沉默。

"你有没有哪怕一个瞬间，是真心对我好的？"

还是没有回答。

高阳笑了。
笑着笑着，眼眶红了。

"......我知道了。"

他偏过头。
子弹擦过他的脸颊。
他转身就跑。

身后，黄琦若没有追来。
但高阳知道，
下一次见面，他们之间，
只有一个人能活。
```

### 场景3：牺牲告别

```
【要素】：温情/悲壮/日常化遗言

【模板】：

"走吧。"

青莽把高阳推进通道，转身面对潮水般的兽群。
"我断后。"

"你疯了？！"高阳挣扎着想回来，"我们一起——"

"一起什么？一起死？"

青莽回头，笑了。
那个笑容，和平时一样吊儿郎当。
"放心吧，兄弟。"
"我不是英雄，我只是......"

他顿了顿。
"想让你替我活下去。"

"青莽——"

"帮我跟阿姨说一声，今晚不回去吃饭了。"

他挥了挥手。
"还有那家鸡腿，记得帮我吃完。"

通道的门关上了。
高阳什么都没来得及说。

他只记得青莽最后的样子。
笑着，像往常一样。
好像这不是永别。
只是一顿普通的晚餐。
```

## 四、对话场景模板

### 模板1：暧昧对话

```
【要点】：心动但不明说，拉扯感

【模板】：

"你今天怎么走这条路？"

高阳看着身边的女生，有些意外。
这条路不是她家的方向。

"......绕路。"

"为什么？"

"......"

沉默。

"因为想走。"她终于开口，"不行吗？"

高阳愣了一下。
"......行。"

于是他们就这样走着。
谁都没再说话。
但不知道为什么，
高阳希望这条路，
能再长一点。

"高阳。"
"嗯？"

"没什么。"
她忽然加快了脚步。
"......到家了记得发消息。"

高阳看着她跑远的背影。
夕阳把她的影子拉得很长。
他站在原地，忽然笑了。

......什么啊。
这种感觉。
```

### 模板2：兄弟对话

```
【要点】：损但真实，不用心

【模板】：

"你这次真的考砸了。"

高阳看着王子凯的卷子，眉头皱起。
"......三十七分？"

"别念出来！"王子凯一把捂住卷子，"丢人！"

"全年级都知道了。"
"那是他们的问题！"

高阳叹了口气。
"要不要我帮你补课？"

"......你？"
王子凯一脸怀疑，"你不是也才八十七吗？"

"八十七和三十七，差距够我教你十遍了。"

"......"

王子凯沉默了几秒。
然后他一把搂住高阳的肩膀：
"好兄弟！"

"......放手。"
"不放！今晚你请我喝奶茶！"

"为什么？"
"因为你是我兄弟！"

高阳翻了个白眼。
但最后还是掏了钱。

没办法。
谁让他是自己兄弟呢。
```

### 模板3：情感爆发对话

```
【要点】：不说出来的痛，沉默的重量

【模板】：

"为什么？"

高阳看着眼前的青莽。
他刚刚才知道，青莽是"迷失者"——
一种失去人性的觉醒者。

"没有为什么。"

青莽的声音很平静。
平静得让人害怕。

"你曾经不是这样的。"
"那是曾经。"

"我们可以帮你——"

"帮我？"青莽笑了，"你知道我杀了多少人吗？"

高阳沉默了。

"别天真了，兄弟。"

青莽走向他，每一步都很慢。
"有些路，一旦走上去，就没有回头的余地。"

"那就别回头。"高阳的声音在发抖，"我们可以一起——"

"一起什么？一起背负那些人的命？"

青莽停在他面前。
很近。
近得能看清他眼底的空洞。

"别找我了。"
他转身。

"下次见面，我们之间，"
他的背影渐渐远去。
"只有一个人能活。"

高阳站在原地。
他张了张嘴，想说什么。
但最后，什么都没说出来。
```

## 五、金句场景模板

### 模板1：融入叙述

```
【要点】：不在对话里，在叙述里

【示例】：

高阳站在天台上，风很大。

他看着手里的照片。
照片里的人在笑。
那笑容他看了十八年。

但现在他知道了。
那笑容是假的。
那双手是假的。
那些拥抱是假的。

只有他的眼泪是真的。

"......妈。"

他叫了一声。
没有人回答。

但他还是选择继续叫她妈。

不是因为傻。
是因为——
就算世界是假的，
他愿意相信，
那些年的爱，是真的。
```

### 模板2：融入行动

```
【要点】：不说出来，做出来

【示例】：

战斗结束了。

高阳坐在废墟上，满身是血。
他的面前，是王子凯的尸体。

"说好的......一起旅游......"

他掏出那张照片。
是他们曾经说好要去的海边。

"......算了。"

他站起来，把照片收进口袋。

"替你去吧。"

他捡起刀。
眼泪落下的瞬间，刀锋划破了一只扑来的兽。

他没擦眼泪。
他只是继续战斗。

带着眼泪。
带着照片。
带着那些再也无法兑现的约定。

继续活下去。
```
