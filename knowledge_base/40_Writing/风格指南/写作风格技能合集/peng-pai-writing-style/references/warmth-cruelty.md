## 二、温柔发刀五步法

### 步骤1：充分铺垫（第1~3章）

**目标**：让读者"以为安全"

**操作**：
```
日常描写清单：
□ 角色A和角色B的默契互动
□ 一个让人会心一笑的小细节
□ 未来的约定或承诺
□ 温暖的小群体氛围
```

**示例**：
> 第五章写王子凯教高阳打游戏的场景：
> "你操作太菜了，我要是敌人，你早死八百遍了。"
> "那你别走前面，保护我。"
> "......行吧，谁让我是你兄弟。"

**读者反应预设**：
> "好甜！这两个人的互动太可爱了！"

### 步骤2：享受温馨（第4~5章）

**目标**：让读者放松警惕

**操作**：
```
温馨场景要素：
□ 轻松的对话
□ 不设防的姿态
□ 未来计划的讨论
□ 共同面对困难的约定
```

**示例**：
> "等这一切结束，我们一起去旅游吧。"
> "去哪儿？"
> "你说去哪儿就去哪儿，反正跟着你不会迷路......大概。"

### 步骤3：微妙违和（第6章）

**目标**：埋下伏笔，但不明显

**操作**：
```
违和信号（可选择用或不用）：
□ 角色说了某句话后，对方表情微妙
□ 某个习惯性动作突然变了
□ 环境描写中有一丝不协调
□ 其他角色的观察视角
```

**示例**：
> 王子凯今天格外话多，高阳没多想，只当是兄弟难得放松。

### 步骤4：爆发（第7章）

**目标**：刀子落下

**操作**：
```
爆发方式选择：
A. 直接揭露：直接揭示身份
B. 间接暗示：通过行为暴露
C. 背刺：被最信任的人亲手......
D. 牺牲：为保护某人而死
E. 黑化：曾经的战友成为敌人
```

**示例（背刺型）**：
> "兄弟，相信我。"王子凯笑着递过来一瓶水。
> 高阳喝下去的瞬间，世界开始模糊。
> "抱歉了，兄弟。"

### 步骤5：余韵（第8~10章）

**目标**：痛过之后的短暂温暖

**操作**：
```
余韵处理：
□ 让其他角色安慰/陪伴主角
□ 给一个"告别的机会"
□ 留下一个"未完成"的约定
□ 用回忆杀收尾
```

**示例**：
> 高阳独自坐在天台上，手里攥着那张旅游目的地的照片。
> "说好一起去旅游的......"

## 三、刀子类型分类

### 类型1：身份刀

**定义**：揭露亲近之人的真实身份（兽/卧底/叛徒）

**彭湃式写法**：
```
铺垫（充分）：3-5章的温馨日常
违和（微妙）：1-2个不明显的伏笔
揭露（震撼）：1章内的冲击
余波（持续）：3章以上的后续影响
```

**示例场景**：
> 生日会上，所有人都在笑。母亲说："高阳，许个愿吧。"
> 他闭眼许愿，睁眼时发现——
> 母亲的瞳孔里，倒映着不属于人类的东西。

### 类型2：牺牲刀

**定义**：角色为保护/拯救他人而牺牲

**彭湃式写法**：
```
铺垫（羁绊）：5章以上的感情铺垫
选择（两难）："我选择你，而不是世界"
牺牲（震撼）：不要拖沓，干脆利落
遗言（点睛）：一句话，但足够戳心
```

**示例场景**：
> "快走！"青莽把高阳推进通道，转身面对潮水般的兽群。
> "别回头，兄弟。"
> "活下去。"

### 类型3：信任刀

**定义**：被最信任的人背叛

**彭湃式写法**：
```
铺垫（信任）：至少3章的双向信任描写
动摇（怀疑）：1章的内心挣扎
崩塌（证实）：瞬间完成，不拖沓
后果（持续）：影响后续5章以上
```

**示例场景**：
> "我相信你。"高阳说。
> 黄琦若点头，眼神温柔。
> 下一秒，枪口抵住了他的后脑。

### 类型4：成长刀

**定义**：被迫放弃天真，被迫长大

**彭湃式写法**：
```
失去（必须）：失去某个天真的人/事
接受（痛苦）：主角的内心崩溃
转化（成长）：痛定思痛后的改变
体现（行为）：用行为证明成长
```

## 四、日常温情写法

### 烟火气三要素

**彭湃式日常**：
```
要素1：具体的生活细节
  ✗ "他们关系很好"
  ✓ "王子凯总是把自己的鸡腿夹给高阳"

要素2：只有两人知道的暗号/习惯
  ✗ "他们是兄弟"
  ✓ "每次考试考砸，他们就用'今天天气不错'来掩饰尴尬"

要素3：不经意的小温暖
  ✗ "高阳感到很温暖"
  ✓ "高阳的书包里，总会多出一盒牛奶，他没问是谁放的。"
```

### 校园日常模板

**场景1：课间互动**
```
甲：（趴在桌上）帮我看着老师，我睡会儿。
乙：（翻白眼）又睡？昨晚几点睡的？
甲：（含糊）没事......反正有你......
乙：（无奈叹气）行吧，五分钟。
甲：（已经睡着了，嘴角带笑）
乙：（小声）......真是欠你的。
```

**场景2：食堂场景**
```
"今天红烧肉不错。"
"你上次也说不错，结果全是肥肉。"
"那是意外！这次不一样。"
（高阳夹了一块，果然是瘦的）
"......行吧，算你运气好。"
"什么叫运气好？这叫经验！"
```

**场景3：回家路上**
```
"你今天怎么走这边？"
"......想走走。"
"少来，你肯定有事。"
"没事，就是......"
（沉默）
"行，不想说就不说。反正我在。"
（拍拍肩膀）
```

## 六、高阶技法：刀中带糖

**原理**：刀子落下的瞬间，反而是最温情的时刻

**彭湃式写法**：

### 牺牲场景的最高境界

**错误写法**：
> "为了你，我愿意牺牲！"（喊口号）

**彭湃式写法**：
> 他把高阳推进安全区，转身面对兽潮。
> "帮我跟阿姨说一声，今晚不回去吃饭了。"
> 语气轻松，像每天的日常告别。
> 只是这一次，是永别。

**要点**：
- 用日常掩盖悲壮
- 用轻松掩盖痛苦
- 用平静掩盖诀别

### 遗言的最高境界

**错误写法**：
> "我很骄傲，能为你而死。"（太直白）

**彭湃式写法**：
> "对了，冰箱里还有我昨天买的蛋糕，你帮我吃掉。"
> "别浪费了。"
> 这是他最后一句话。
> 说的是蛋糕，不是遗言。

**要点**：
- 遗言越日常，越真实
- 越不说"最重要的话"，越让人心痛
- 留白比说满更有力量

## 七、刀后修复技巧

### 目的

不是为了让读者哭，而是为了让读者**更爱这个角色**

### 方法

```
刀后修复清单：

□ 给其他角色一个"念叨"死者的机会
□ 留一个"未完成"的约定（后续会完成）
□ 主角做出"符合死者期望"的选择
□ 在关键时刻，让死者"活在回忆里"
□ 最后，用一个温暖的场景收尾
```

### 示例：王子凯牺牲后的修复

```
章1（刀）：王子凯牺牲
章2（刀后）：高阳沉默，独坐天台
章3（修复）：初雪路过，放了一瓶牛奶在
            他桌上，什么都没说
章4（修复）：王子凯的手机响了，是外卖
            提醒，他给自己订的鸡腿到了
章5（修复）：高阳去拿了那盒鸡腿，一个人
            吃完
章6（成长）：高阳擦干眼泪，继续战斗
```
