# 三天两觉写作风格技能

> 专为生成具备"三天两觉文风"的创意文本而设计

## 风格概述

三天两觉是起点中文网大神作家，代表作《惊悚乐园》《纣临》《贩罪》《盖世双谐》。其写作风格以"反套路智斗"为核心，融合高密度玩梗、游戏化叙事、黑色幽默与精密悬念设计，构建出独特的"智性爽文"范式。

**核心定位**：不是升级打怪的爽文，而是一盘下给读者的解谜游戏。

---

## 核心技法矩阵

| 技法 | 核心目标 | 标志性特征 |
|------|---------|-----------|
| 反套路设计 | 打破读者预期 | 主角是"看穿剧本的人" |
| 玩梗文化 | 制造共时性共鸣 | 梗是叙事元素而非装饰 |
| 游戏化叙事 | 建立可控的失控感 | 副本/系统是第二层叙事 |
| 黑色幽默 | 解构不回避 | 冷幽默+自嘲+反讽 |
| 悬念递进 | 维持认知张力 | 悬念嵌套悬念 |

## 使用方法

### 基础调用
```
使用三天两觉写作风格创作一段[场景类型]
```

### 场景类型映射
- **开篇生成**：使用 `anti-pattern.md` 的"开局反套路模板"
- **智斗场景**：组合使用 `anti-pattern.md` + `black-humor.md`
- **副本/游戏场景**：使用 `game-narrative.md` 的框架
- **玩梗场景**：使用 `meme-culture.md` 的"梗融合术"
- **对话场景**：使用 `text-generator.md` 的对话模板

### 创作参数
```
{
  "主角类型": "怪人/观察者/棋手",
  "智斗强度": 1-5,
  "玩梗密度": 低/中/高,
  "幽默类型": "冷幽默/自嘲/反讽",
  "悬念层级": "单点悬念/递进悬念/嵌套悬念"
}
```

## 技法协同指南

### 场景1：开局三章设计
```
1. 反套路开局 → 用 anti-pattern.md 的"异类主角开场法"
2. 悬念铺设 → 用 black-humor.md 的"悬念冷开场"
3. 玩梗植入 → 用 meme-culture.md 的"钩子型梗"
```

### 场景2：智斗高潮设计
```
1. 棋局构建 → 用 anti-pattern.md 的"多层级博弈"
2. 信息差渲染 → 用 game-narrative.md 的"系统界面"
3. 反转植入 → 用 black-humor.md 的"幽默式反转"
```

### 场景3：副本叙事设计
```
1. 副本设定 → 用 game-narrative.md 的"副本结构模板"
2. 梗融合 → 用 meme-culture.md 的"游戏梗+现实梗缝合"
3. 规则解构 → 用 anti-pattern.md 的"规则破解法"
```

## 质量检验清单

生成内容后，检查是否符合以下标准：

- [ ] 主角行为逻辑是否"反直觉但合理"
- [ ] 梗是否服务于叙事而非单纯堆砌
- [ ] 游戏元素是否有内在逻辑自洽
- [ ] 幽默是否带有"冷"感而非纯搞笑
- [ ] 悬念是否在下一章给出"部分答案+新谜题"
