# 黑色幽默技法

## 核心原理

三天两觉的幽默是"冷的"——不讨好读者，不缓和气氛，反而**主动打破温馨**。这种幽默的本质是解构：解构英雄主义、理想主义、以及网文套路本身。

**核心心法**：幽默是叙事的"刹车片"，用来调节节奏、制造反差、暗示人物心理，而非单纯逗笑。

---

## 一、冷幽默的本质

### 1.1 冷幽默 vs 热幽默

| 维度 | 热幽默（常规） | 冷幽默（三天两觉） |
|------|---------------|-------------------|
| 目的 | 让读者笑 | 让读者"愣住后笑" |
| 时机 | 配合气氛 | 主动打破气氛 |
| 来源 | 事件本身 | 对事件的"错误解读" |
| 效果 | 放松 | 强化荒诞感 |
| 典型 | 段子集合 | 性格外化 |

### 1.2 冷幽默生成公式

```
【公式】正常情境 + 非正常反应 + 不解释 = 冷幽默

【示例】
情境：反派威胁主角
热幽默："你敢动我试试？"
冷幽默：
"你敢动我试试？"
封不觉想了想："试试就试试。"
他原地转了一圈。
"动了。满意吗？"
反派："......"
反派现在不确定这场对峙该怎么收场了。
```

## 二、自嘲技法

### 2.1 自嘲的叙事功能

```
【功能1】拉近距离
让主角显得"真实"而非"装逼"

【功能2】转移注意力
在需要隐瞒信息时，用自嘲吸引读者注意

【功能3】讽刺解构
通过自嘲某个类型角色，讽刺整个类型
```

### 2.2 自嘲模板

**模板A：能力自嘲**
```
"我不擅长近战。"他说，"准确地说——
我的近战能力大概相当于'会走路的靶子'。
系统给过我一个评价：'建议转职'。
我拒绝了。
因为我想看看一个近战废物是怎么通关的。"
```

**模板B：人设自嘲**
```
"我是那种会在英雄救美时刻迟到的人。
不是能力问题，是性格问题。
比如现在，我本来可以冲上去的。
但我选择先观察一下。
——主要是因为腿短，跑不快。"
```

**模板C：命运自嘲**
```
"按照剧本，我现在应该有一个悲惨的过去。
父母双亡，朋友背叛，身负血仇。
但很遗憾，我的人生履历干净得像一张白纸。
没有血债，没有仇人，甚至没有房贷。
唯一的问题是——
为什么我这么普通，还能活到现在？"
```

### 2.3 自嘲使用节奏

```
【高光时刻】→ 避免自嘲，让角色"帅"一会儿
【转折节点】→ 用自嘲消解紧张感
【失败时刻】→ 自嘲缓解读者情绪
【对话间隙】→ 用自嘲填补沉默
【章节开头】→ 建立人设基调
```

## 三、反讽技法

### 3.1 反讽类型

| 类型 | 结构 | 效果 |
|------|------|------|
| 言语反讽 | 说A指B | 讽刺/暗示 |
| 情境反讽 | 预期vs现实 | 荒诞感 |
| 命运反讽 | 角色vs叙事者 | 宿命感 |
| 读者反讽 | 读者知道vs角色不知 | 紧张感 |

### 3.2 反讽模板

**模板A：台词反讽**
```
【场景】反派自我感觉良好

反派："我计划了一切，没有漏洞。"
封不觉："确实。"
反派："你认输了？"
封不觉："不，我在夸你。
你计划的漏洞确实没有——因为不是漏洞，是明洞。
大得能开进去一辆卡车的那种。"

【效果】反派颜面扫地 + 主角智商展示
```

**模板B：情境反讽**
```
【预期】
英雄应该挺身而出。

【现实】
封不觉挺身而出——
然后被绊倒了。

"我就说地上有东西。"他爬起来，拍拍裤子，
"为什么没人清场？"
围观群众表示：他们以为是道具。
```

**模板C：命运反讽**
```
【角色视角】
"我要拯救世界。"

【叙事者视角】
他确实拯救了世界。
但世界不知道的是——
他本来是去毁灭世界的。
只是走到半路，发现拯救比毁灭简单。
——主要是因为拯救有奖励，毁灭没有。
```

### 3.3 反讽组合拳

```
第一步：建立预期
"这是最后的决战。"

第二步：打破预期
"封不觉走上前，深吸一口气——
'那个，我有个问题。'"

第三步：深度反转
"'打完我能下班吗？今天加班超时了。'"

第四步：揭示本质
"反派愣住了。
他准备了十年的最终决战，
对方居然在算加班费。"
```

## 四、幽默式反转

### 4.1 反转类型

| 类型 | 结构 | 笑点来源 |
|------|------|---------|
| 预期反转 | A→非A | 意外感 |
| 逻辑反转 | 因为A→所以B | 荒诞感 |
| 身份反转 | A是B | 落差感 |
| 目的反转 | 做A为了B | 讽刺感 |

### 4.2 幽默反转模板

**模板A："认真"式反转**
```
【铺垫】
反派花三页PPT解释他的伟大计划。

【反转】
"所以你的计划是——"
"毁灭旧世界，建立新秩序。"
"等一下。"封不觉打断，"你的PPT第17页，数据来源是什么？"

反派："......"

"我查了一下，这个数据是三年前的。
而且统计口径有问题。"
"......"

【效果】
史诗级反派计划被一个"查数据"的举动动摇
```

**模板B："无意义"式反转**
```
【铺垫】
紧张的追逐戏。

【反转】
"站住！"
封不觉站住了。
"为什么？"
"因为我在追你！"
"哦。"

【持续反转】
"那我现在该跑吗？"
"应该。"
"但你在追我，我跑你就追。"
"对。"
"所以我为什么要跑？"

反派沉默了五秒钟。
反派开始怀疑人生。
```

**模板C："认真回应无厘头"式**
```
【无厘头】
"我是来杀你的。"

【认真回应】
"杀我？"封不觉看了看来人，"有预约吗？"
"什么？"
"我说，有预约吗？"
"杀人需要什么预约？"
"当然需要。
你看，医生手术要预约，外卖送餐要预约。
杀人不预约，显得很不专业。"
```

## 五、黑色幽默场景模板

### 5.1 死亡场景的冷处理

```
【常规处理】
"他死了，死得很安详。"

【冷幽默处理】
"他死了。
死因：话太多。
反派给了系统一个好评：'终于安静了'。"
```

### 5.2 紧张场景的吐槽插入

```
【紧张场景】
枪口对准了主角。
时间仿佛静止。

【插入点】
"你知道吗，"封不觉说，"按照统计学——
这个距离，这个口径，中弹率是98%。"

"所以？"

"所以我有2%的概率活下来。"

"这改变不了什么。"

"改变不了。"封不觉点头，"但我可以说一句帅话。"

"什么？"

"'就算是2%，也比0%强。'"

【效果】
紧张感没有消失，但被"2%"这个数字冲淡了
读者会想：这个人死到临头还在算概率？
——主角人设强化
```

### 5.3 幽默与严肃的边界控制

```
【禁忌】
✗ 严肃场景插入纯搞笑
  "炸弹要爆炸了——哈哈哈哈笑死我了"

✓ 严肃场景插入"冷"的幽默
  "炸弹要爆炸了。"封不觉说，"看来我今天要迟到了。"

【边界】
幽默不能消解紧张，但可以消解"装逼感"
幽默不能打断节奏，但可以"延长"某一刻的效果
```

## 六、幽默风格校准

### 6.1 幽默密度矩阵

| 场景类型 | 幽默密度 | 幽默类型 |
|---------|---------|---------|
| 高潮/战斗 | 极低 | 不用 |
| 智斗/博弈 | 中低 | 冷吐槽 |
| 日常/过渡 | 中高 | 密集自嘲 |
| 对话/互动 | 中 | 角色特色 |
| 副本结算 | 高 | 系统吐槽 |

### 6.2 风格自检

- [ ] 幽默是否"冷"而非"热"？
- [ ] 幽默是否服务于人物/情节？
- [ ] 幽默是否保持了"黑色"调性？
- [ ] 是否避免了"段子手式"堆砌？
- [ ] 幽默是否让角色更真实而非更"油"？
