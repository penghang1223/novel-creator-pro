# 文本生成器

## 概述

本文件提供三天两觉风格的核心文本生成模板，包括开篇、场景、对话三类。模板遵循"可组装"原则——根据需求自由组合元素。

---

## 一、开篇生成模板

### 1.1 标准开篇模板

```
【模板结构】
[异常状态] → [角色反应] → [世界观揭示] → [悬念钩子]

【变量填充】
主角名：__________
主角特质：__________
场景设定：__________
异常状态：__________
悬念钩子：__________
```

**示例输出**：
```
变量：
主角名=林远
主角特质=算账狂魔、前银行职员
场景设定=赛博朋克都市
异常状态=醒来发现自己在一个陌生房间，床头有一张欠条
悬念钩子=欠条上的签名是他自己的

---

【生成结果】

林远睁开眼睛的第一反应是数天花板。
不是格子数——是天花板的价格。
按照当前房价，这间卧室大概值三百万。
问题是：他为什么在这里？

床头放着一张纸。
他拿起来看了一眼。
那是一张欠条。
欠款金额：五百万。
借款人签名：林远。

他盯着那个签名看了五秒钟。
字迹确实是他的。
但他完全不记得自己借过这笔钱。

更重要的是——
他三年前就破产了，哪来的五百万可借？
```

## 二、场景生成模板

### 2.1 智斗场景模板

```
【模板结构】
[棋盘呈现] → [双方底牌] → [博弈过程] → [关键变量] → [结果]

【关键变量】
信息A（主角知道）：__________
信息B（对手知道）：__________
信息C（只有读者知道）：__________
```

**示例输出**：
```
变量：
信息A=对方是内鬼
信息B=主角不知道他是内鬼
信息C=主角其实是引蛇出洞

---

【生成结果】

"所以，内鬼就在我们中间？"
林远环顾四周，目光在每个人脸上停留两秒。
被看到的人都紧张起来。
只有一个人——代号"观察者"——表情如常。

"有意思。"林远心想，"正常人会紧张，会辩解。
但他什么都不做。"

"那么，"观察者开口，"你有怀疑对象吗？"

"暂时没有。"林远说，"但我有个想法。"

"什么想法？"

"与其找内鬼，不如让内鬼自己跳出来。"

他宣布：从现在起，所有人单独行动。

观察者的眼神变了——只有一瞬间。
但林远看到了。
"果然是你。"

"什么时候开始的？"
"从你问'你有怀疑对象吗'的时候。"
"那个问题有什么问题？"
"正常人应该问'谁是内鬼'。你问的是'怀疑对象'——"
林远笑了笑，"你在确认你的掩护身份有没有暴露。"
```

### 2.3 战斗场景模板（智斗型）

```
【模板结构】
[战力对比] → [规则限制] → [策略博弈] → [意外变量] → [主角解法]

【变量填充】
常规战力：主角弱于对手
规则限制：__________
意外变量：__________
主角利用点：__________
```

**示例输出**：
```
变量：
规则限制=战斗中禁止使用技能
意外变量=场地有隐藏开关
主角利用点=观察力

---

【生成结果】

战力对比：封不觉 vs BOSS = 3:10
规则限制：战斗区域禁止使用任何技能

"这不公平。"封不觉评价。

"公平是游戏里最不重要的东西。"BOSS说。

"确实。"封不觉点头，"所以我从不指望公平。"

他观察着战场。
空旷的房间，普通的地面，看不出任何异常。

——但地板有点太干净了。

"这里以前是什么？"他问。

"什么？"

"这个房间。"他蹲下来，敲了敲地板，"建材、布局、用途。"

BOSS皱眉："你怎么突然问这个？"

"因为这地板太干净了。"封不觉说，"一座战斗用的房间，
地板一尘不染，说明有人经常打扫。
或者——"

他按下了某一块地板。

"——或者这里有机关。"

【隐藏效果触发】
房间开始震动。

"等等——"BOSS意识到不对。

"你禁止我使用技能。"封不觉说，"但没禁止触发场地机关。"

"那些机关是BOSS专属机制！"

"你的BOSS。"封不觉纠正，"不是我的。"
```

## 三、对话生成模板

### 3.1 主角对话模板

**类型A：冷吐槽型**
```
模板：观察到异常 + 吐槽点 + 不解决问题的回应

示例：
"你的计划有个漏洞。"
"什么漏洞？"
"执行人是笨蛋。"
```

**类型B：装傻型**
```
模板：假装不懂 + 逼对方解释 + 反向利用

示例：
"你什么意思？"
"字面意思。"封不觉说，"你的计划很完美。
完美到像是——第一次做计划。"
"我做过很多次！"
"哦？那为什么还失败？"
```

**类型C：自嘲型**
```
模板：承认弱点 + 话锋一转 + 暗示优势

示例：
"我不擅长正面战斗。"
"那你来干嘛？"
"观察。"他推了推眼镜，"或者说——记录你的弱点。"
```

**类型D：反问型**
```
模板：抛出问题 + 逼迫选择 + 获取信息

示例：
"你有两个选择：相信我，或者死。"
"这算选择？"
"不算。所以你只能相信我。"
"......"
"你看，你已经想通了。"
```

### 3.2 反派对话模板

**类型A：仪式感型**
```
模板：铺垫威压感 → 被主角打断 → 仪式崩塌

示例：
反派："我是暗影之主，毁灭的代言——"
封不觉："等一下，你刚才说什么？"
"毁灭的代言——"
"不是，上一句。"
"我是暗影之主。"
"哦。"封不觉打断，"我还以为你要说'我是来谈恋爱的'。
这个名字太中二了。"

反派感觉自己今天的反派生涯不太顺利。
```

**类型B：认真型（配合冷幽默）**
```
模板：反派说正经话 → 主角用正经话回应 → 反转

示例：
反派："我给你一个机会。加入我，或者死。"
封不觉："我选第三个选项。"
"什么？"
"让你加入我。"
"......你在开玩笑？"
"从不说笑。"封不觉说，"我认真的。
你看，我这边有五险一金，你那边有吗？"
```

### 3.3 配角对话模板

**功能：解释规则/衬托主角**
```
模板：提出疑问 → 主角回答 → 展示配角反应

示例：
"所以，我们现在该怎么办？"
封不觉："等。"
"等什么？"
"等对方犯错。"
"万一他们不犯呢？"
"那我就想办法让他们犯。"
"......这算什么策略？"
"这叫'被动技能：对手降智'。"
```

## 四、高阶组装技法

### 4.1 技法组合矩阵

| 场景 | 反套路 | 玩梗 | 游戏化 | 黑色幽默 |
|------|--------|------|--------|----------|
| 开篇 | ✓ | ✓ | ✓ | ○ |
| 智斗 | ✓ | ○ | ✓ | ✓ |
| 副本 | ○ | ✓ | ✓ | ○ |
| 战斗 | ✓ | ○ | ✓ | ✓ |
| 日常 | ○ | ✓ | ✓ | ✓ |
| 结尾 | ○ | ○ | ○ | ✓ |

### 4.2 节奏调控模板

```
【高密度区】(智斗/战斗)
反套路（高）+ 游戏化（中）+ 黑色幽默（低）
目的：保持紧张感 + 展示智识

【中密度区】(副本/探索)
游戏化（高）+ 玩梗（中）+ 反套路（中）
目的：节奏适中 + 信息传递

【低密度区】(日常/对话)
玩梗（高）+ 黑色幽默（高）+ 反套路（低）
目的：调节情绪 + 人物塑造
```

### 4.3 生成检查清单

生成完成后，用以下问题自检：

```
1. 主角的行为是否"反直觉但合理"？
2. 梗的出现是否有叙事功能？
3. 游戏元素是否有内在逻辑？
4. 幽默是否保持了"冷"调性？
5. 悬念是否在合适位置抛出？
6. 节奏是否符合段落类型？
7. 读者能否获得"智识碾压"的快感？
```

## 五、模板速查表

### 快速生成提示词

```
# 开篇生成
"用三天两觉风格写一个[类型]开篇：
主角[特质]，场景[设定]，包含[异常状态]和[悬念钩子]"

# 智斗场景
"写一段智斗场景：
主角知道[信息A]，对手知道[信息B]，结果是[结果]"

# 对话生成
"生成[角色]的对话：
类型[冷吐槽/装傻/自嘲/反问]，场景[紧张/日常/对峙]"

# 副本场景
"设计一个[类型]副本：
核心谜题[谜题]，关键线索[线索]，结局[结局]"
```

### 参数速配

```
主角"怪"的程度：
- 轻度：偶尔吐槽 + 正常决策
- 中度：频繁吐槽 + 非主流解法
- 重度：全程吐槽 + 打破第四墙

玩梗密度：
- 低：每千字1-2个梗
- 中：每千字3-5个梗
- 高：每千字5个以上（需控制节奏）

幽默温度：
- 热：配合气氛的搞笑
- 冷：打破气氛的吐槽（推荐）
```
