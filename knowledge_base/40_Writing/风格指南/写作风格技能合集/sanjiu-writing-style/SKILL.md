# 三九音域写作风格技法

## 任务目标

本 Skill 提供两大核心能力：

### 能力一：方法论指导
- 将用户的小说创作需求转化为三九音域风格的专业创作方案
- 提供世界观构建、金手指设计、人物塑造等核心技法指导
- 帮助创作者建立"球体结构"的核心精神体系
- 优化情节节奏，平衡爽感与逻辑

### 能力二：文风文本生成
- 1:1复刻三九音域燃虐悲壮、中式家国、克苏鲁质感的写作风格
- 直接输出符合三九笔法的文本内容
- 支持战斗名场面、牺牲封神、家国热血台词、疯批主角内心戏、群像羁绊、开篇钩子等场景
- 精准风格控制，无需额外解释

## 触发条件

**方法论指导**：
- 用户提到"三九音域风格"、"热血小说"、"世界观构建"
- 需要设计金手指、人物塑造方案
- 创作都市异能、神话融合类小说

**文本生成**：
- 三九音域文风、斩神式写作、戏神文风
- 燃虐封神描写、家国热血桥段、牺牲名场面
- 三九式群像、疯批主角描写

## 核心理念

### 球体结构
> "一部作品不该是一成不变的、很扁平的状态，而是要像一个球一样为核心服务。"

**操作步骤**：
1. 先确定核心精神（如：牺牲与勇气、成长与守护）
2. 所有设定围绕核心服务
3. 世界观、人物、情节都要为核心精神烘托

### 世界观是钥匙
> "世界观是打开小说幻想屋的钥匙"

**核心方法**：不追求从无到有，在传统世界观基础上+新奇元素+反套路

## 操作步骤

### 1. 世界观构建

调用 `references/world-building.md` 获取详细技法

**极度反差设计**：
- 确定对抗双方：寻找两种差异极大的存在
- 示例：人类 vs 神明、凡人 vs 不可战胜者
- 原则：越是强烈的反差与绝望感，越能引起读者关注

**借力打力**：
- 利用读者已有认知（神话常识、文化符号）
- 省去大量世界观铺垫
- 让读者立刻体会到对立和落差感

**未知制造**：
- 每个未知的解开，立刻伴随着新未知的出现
- 构建迷雾、孤岛等隔绝设定
- 未知的源头和终点，是恐惧与绝望的来源

### 2. 金手指设计

调用 `references/golden-finger.md` 获取详细技法

**核心原则**：金手指不是工具，而是故事的核心驱动力

**创新方向**：
- 与世界观深度绑定（精神病院中的神明）
- 既是金手指，也是线索
- 有代价、有限制、有成长空间

**使用时机**：
> "当主角逐渐走向平淡，就需要有'生死危机'，这时候金手指就可以出来了。主角的人生必须时刻精彩。"

### 3. 人物塑造

调用 `references/character-design.md` 获取详细技法

**灵魂角色法**：
- 以"灵魂角色"为根基架构整本小说
- 而非传统副本升级流

**黄金配角设计**：
- 开场即死的赵空城：成为读者"入坑"的契机
- 戍边守夜人：原型来自抗洪军人、边防战士
- 悲剧中，角色的高光时刻是"死亡"

**侧面描写技法**：
> "要写守夜人的无私与奉献，就不能只写无私与奉献——要写他们在天崩地裂时，握刀站在惊慌逃离的民众身后面不改色；要写死里逃生后，深夜借着微弱火光看孩子爱人的照片压抑痛哭……"

### 4. 热血情节设计

调用 `references/passion-writing.md` 获取详细技法

**热血公式**：
```
热血 = 极度绝望 + 牺牲精神
```

**操作步骤**：
1. 先制造绝望（迷雾末世、孤岛设定、不可战胜的敌人）
2. 再塑造牺牲（明知必死仍前赴后继）
3. "凡人斩神"的壮烈感

**注意**：热血一定是建立在牺牲的基础上的

### 5. 画面感描写

调用 `references/scene-description.md` 获取详细技法

**核心技法**：
1. 描述动态，而非静态
2. 色彩的极致碰撞：红装少年+鬓角白霜
3. 直白的比喻："月光照在路上，像是撒满了盐"
4. 慢放镜头：打斗细节逐帧描写

### 7. 文本生成（直接输出）

调用 `references/text-generator.md` 获取完整生成规则

**生成模块**：
- 战斗名场面：凡人对抗超凡存在，黑红金色调，短句爆破
- 牺牲封神：配角赴死，白描不煽情，留白封神
- 家国热血台词：短句铿锵，守土护民内核
- 疯批主角内心戏：创伤+癫狂+正义底线
- 群像羁绊：生死与共，一人一句立人设
- 开篇钩子：开局即绝境，抛出核心冲突

**核心基调**：
- 现代都市基底 + 多元神话 + 克苏鲁诡谲感
- 中式家国情怀 + 凡人逆神 + 牺牲美学
- 燃虐交织，悲壮肃杀

**文笔要求**：
- 短句、动词前置、停顿切割
- 电影镜头式描写：全景→中景→特写
- 主色调：黑、红、金

**严格约束**：
- 禁止轻松搞笑、无脑龙傲天、长句堆砌
- 禁止偏离家国、守护、牺牲、逆神内核
- 禁止弱化角色悲壮感

### 8. 爽感与逻辑平衡

**观点**：爽感本身无错，关键是如何合理融入

**反面案例**：简单粗暴的爽文桥段堆砌，忽视逻辑
**正面案例**：《西游记》大闹天宫，爽但有逻辑支撑

> "爽感本身不会让作品失去格调，是一种符合人们情绪需求的正常表达。"

【借力元素】：利用读者已有的xxx认知
【未知设计】：xxx迷雾/孤岛设定
【伏笔预设】：xxx
```

### 金手指设计方案

【金手指形态】：xxx

【核心功能】：xxx
【代价/限制】：xxx
【成长空间】：xxx

【灵魂角色】：xxx（核心驱动力）

```

### 文本生成输出（直接输出三九风格正文）

**示例1：牺牲封神**
> 黑雾吞尽最后一缕天光。
> 神的威压碾碎街巷，骨裂声闷响在寂静里炸开。
> 男人攥紧染血的长刀，徽章上的金色纹路依旧灼眼。
> 他抬眸，眼底无半分惧色。
> "大夏守夜人，不退。"
> 刀身划破黑暗，血色溅上神袍。
> 没有哀嚎，只有一句轻喝。
> "此身归乡，护我河山。"
> 人倒，刀立。
> 神明止步，长夜留光。

**示例2：家国热血台词**
> "若黯夜终临，吾必立于万万人前，横刀向渊，血染天穹。"

**示例3：战斗名场面**
> 黑暗中，有什么在蠕动。
> 粘稠的触手从裂缝中探出，每一根都长满了眼睛。
> 他没有退。
> 手中的刀已经卷刃，血顺着指缝滴落。
> 还能站。还能挥刀。还能——斩。
> 金色的火焰在刀锋上燃起，照亮了他布满血丝的眼睛。
> "凡人亦可斩神。"
