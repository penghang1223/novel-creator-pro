# 世界观构建技法

## 核心理念

> "世界观是打开小说幻想屋的钥匙"

世界观指的是故事设定中世间万物运转的方式，是故事发生的场景、规则。这些规则和我们所在的现实世界不一样，但正是因为这些规则，才会发生一些超乎想象的故事。

## 三大核心技法

### 一、极度反差设计

**原理**：寻找两种差异极大的存在作为对抗双方

**操作步骤**：
1. 确定一方：通常是人类/凡人
2. 寻找另一方：必须是难以战胜、有神秘气息、能拉满期待感的对立面
3. 放大反差：越是强烈的反差与绝望感，越能引起读者关注

**示例**（《斩神》）：
- 对抗双方：人类 vs 神明
- 反差来源：通过从小阅读的神话典籍，我们知道人类在神的面前有多渺小
- 期待感：人类为什么要斩神？究竟要怎么样才能斩神？

**应用模板**：
```
【一方】：xxx
【另一方】：xxx
【反差来源】：xxx（读者已有的认知）
【期待问题】：为什么xxx？怎么样才能xxx？
```

### 二、借力打力

**原理**：利用读者已有的文化认知，省去世界观铺垫

**操作要点**：
- 选择读者耳熟能详的文化符号（神话、传说、历史人物）
- 利用读者已有认知建立威慑力
- 避免大篇幅解释设定

**示例**：
- 恶神一出现，读者立刻就能体会到对立和落差感
- 不需要解释"这个神有多强"，读者已经知道

**可借力的文化符号**：
| 类型 | 示例 |
|-----|------|
| 神话体系 | 希腊神话、北欧神话、中国神话、日本神话、埃及神话 |
| 历史人物 | 三国武将、历代帝王、名人轶事 |
| 文化符号 | 武侠江湖、修仙体系、科幻设定 |
| 现实原型 | 抗洪军人、边防战士、缉毒警察 |

### 三、未知制造

**原理**：每个未知的解开，立刻伴随着新未知的出现

**操作方法**：

**1. 构建隔绝设定**
- 迷雾笼罩的世界
- 孤岛般的幸存国度
- 信息封锁的组织

**示例**：
> "迷雾足以抹杀一切生命，世界上其余国家都被迷雾笼罩，成为废墟，只有大夏神牺牲自我，构建奇迹长城，让大夏成为世界上最后幸存的国家……这就构建了一座'孤岛'。"

**2. 层层递进**
- 像密室逃生：解开一个谜题，推开下一个房门
- 门后有什么？读者好奇又害怕

**3. 持续悬念**
- 迷雾外有什么？
- 其他神话的神明？
- 无尽的尸骨与死亡？

> "人类不知道，而未知的源头和终点，正是恐惧与绝望的来源，是拉开故事的序幕。"

## 世界观代入感

**原则**：通过与现实世界吻合的细节与设定，让读者代入

**技法**：从现实中汲取灵感

**示例**（《斩神》守夜人）：
- 灵感来源：抗洪一线的武警官兵、戍守边疆的边防战士
- 精神内核：勇敢、责任、担当、牺牲精神
- 让读者在幻想世界中看到现实的影子

## 检查清单

创建世界观时，检查以下要素：

- [ ] 是否有极度反差的对抗双方？
- [ ] 是否借力了读者已有的文化认知？
- [ ] 是否有未知元素持续制造悬念？
- [ ] 是否与现实有某种映射或联系？
- [ ] 核心精神是否清晰？
- [ ] 所有设定是否围绕核心精神服务？
