# 杀虫队队员写作风格技法

## 任务目标

本 Skill 提供两大核心能力：

### 能力一：方法论指导
- 将用户的小说创作需求转化为杀虫队队员风格的专业创作方案
- 提供规则怪谈设计、博弈智斗、人性救赎、时间循环等核心技法指导
- 帮助创作者建立"死亡游戏+人性探讨"的叙事体系
- 优化悬疑节奏，平衡智斗与情感

### 能力二：文风文本生成
- 1:1复刻杀虫队队员规则怪谈、博弈智斗、人性救赎的写作风格
- 直接输出符合其笔法的文本内容
- 支持死亡游戏开场、规则解读、博弈对峙、人性抉择、伏笔回收等场景
- 精准风格控制，无需额外解释

## 核心理念

### 死亡游戏外壳
> "规则是枷锁，也是破局的钥匙"

**核心方法**：在严苛规则中寻找漏洞，在绝望困境中挖掘人性

**操作步骤**：
1. 设计看似无解的规则困局
2. 赋予角色在规则内博弈的空间
3. 让智慧与信任成为破局关键

### 人性救赎内核
> "最可怕的不是怪物，是人心；最珍贵的也是人心"

**核心方法**：在极端环境下呈现人性的多面性

**操作步骤**：
1. 先展现人性的黑暗与自私
2. 再通过关键抉择展现人性的光辉
3. 让救赎成为绝望中的希望

## 操作步骤

### 1. 规则怪谈设计

调用 `references/rule-design.md` 获取详细技法

**极度复杂规则设计**：
- 传统文化元素融入（生肖、节气、折扇、象棋）
- 多层级规则嵌套
- 规则之间形成逻辑闭环

**示例**（《十日终焉》）：
- 十二生肖游戏：不同生肖对应不同能力与弱点
- 节气系统：时间流转影响游戏规则
- 折扇/象棋：作为关键道具与隐喻载体

**核心原则**：
- 规则越复杂，破局越精彩
- 规则解释权即权力
- 规则的漏洞就是主角的生存空间

### 2. 博弈智斗设计

调用 `references/game-theory.md` 获取详细技法

**心理博弈框架**：
- 信息不对称创造博弈空间
- 信任与背叛的反复拉扯
- 多方势力角逐的复杂格局

**操作步骤**：
1. 建立清晰的规则体系
2. 创造信息差与认知差
3. 设计角色之间的博弈关系
4. 安排反转与反反转

**杀虫队特色**：
- 智斗不是为了赢，是为了活下去
- 博弈的终极对手往往是人性本身
- 真正的胜利是保住人性的底线

### 3. 人性救赎叙事

调用 `references/character-redemption.md` 获取详细技法

**人性多面呈现**：
- 极端环境下展示人性真实
- 自私与无私的对比冲突
- 救赎的代价与意义

**核心技法**：
- 先抑后扬：先展现黑暗，再呈现光明
- 关键抉择：生死关头的真实选择
- 群体弧光：每个人都有自己的救赎线

**代表主题**：
- 信任是可以建立的吗？
- 为了活下去可以牺牲他人吗？
- 救赎是否需要代价？

### 4. 时间循环技法

调用 `references/time-loop.md` 获取详细技法

**十日轮回设计**：
- 循环结构创造"预知"优势
- 记忆传承形成信息积累
- 多周目视角拓展叙事可能

**操作要点**：
- 循环次数要控制（10日为一个经典单位）
- 记忆代价要合理
- 每轮都要有进展

### 5. 文风文本生成

调用 `references/text-generator.md` 获取完整生成规则

**生成模块**：
- 死亡游戏开场：规则宣告、氛围营造
- 博弈对峙场景：心理交锋、言语交锋
- 人性抉择时刻：生死关头、信任考验
- 伏笔回收场景：悬念揭晓、逻辑闭合
- 规则解读场景：信息获取、规则漏洞挖掘

**核心基调**：
- 悬疑压抑 + 智斗紧张 + 人性温暖
- 规则冰冷 + 博弈热烈 + 情感深沉
- 反转密集 + 细节丰富 + 伏笔精妙

## 严格约束规则

| 禁止项 | 原因 |
|-------|------|
| 规则过于简单或漏洞过于明显 | 削弱博弈张力 |
| 主角全程无敌/开挂 | 破坏智斗逻辑 |
| 人性描写非黑即白 | 偏离人性复杂性 |
| 循环设定过于随意 | 破坏世界观可信度 |
| 反转缺乏铺垫 | 让读者感到被愚弄 |
