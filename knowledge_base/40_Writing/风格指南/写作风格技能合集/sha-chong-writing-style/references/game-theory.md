# 博弈智斗设计技法

## 核心理念

> "博弈不是为了赢，是为了活下去"

杀虫队队员的博弈不是爽文式的碾压，而是建立在信息不对称、信任危机和人性考验基础上的真实智斗。每一个博弈场景都是对人性的深刻拷问。

## 博弈的四大基础

### 一、信息不对称

**定义**：不同角色掌握不同信息，形成博弈优势差

**信息类型**：

| 信息类型 | 描述 | 博弈价值 |
|---------|------|---------|
| 完全信息 | 所有参与者都知道 | 减少博弈空间 |
| 私有信息 | 只有特定角色知道 | 创造信息优势 |
| 公共信息 | 所有人都知道存在，但不知内容 | 制造悬念 |
| 元信息 | "你知道我知道"的程度 | 高阶博弈 |

**杀虫队特色运用**：
```
【典型场景】：
- 有人知道规则的漏洞，但不能说
- 有人知道某人撒谎，但不能揭穿
- 有人知道结局，但必须装作不知道
```

### 二、信任博弈

**定义**：在博弈中，是否信任对方是一个策略选择

**信任类型**：

| 信任类型 | 描述 | 风险 |
|---------|------|------|
| 初始信任 | 基于某种原因的初步相信 | 可能被利用 |
| 条件信任 | 满足某些条件才信任 | 条件可以被操控 |
| 试探信任 | 先小规模试探 | 可能暴露底牌 |
| 零信任 | 谁都不信 | 博弈成本最高 |

**杀虫队特色**：
- 信任是奢侈品，也是武器
- 建立信任需要代价，破坏信任只需要一次背叛
- 最高明的博弈是让对方"心甘情愿"被你利用

### 三、筹码与代价

**定义**：博弈中可交换、可威胁、可让步的筹码

**筹码类型**：

| 筹码类型 | 示例 | 博弈作用 |
|---------|------|---------|
| 核心筹码 | 关键信息、生命 | 不可轻易使用 |
| 有效筹码 | 能力、资源、人脉 | 可用于交换 |
| 虚假筹码 | 假装拥有的筹码 | 用于欺骗 |
| 沉默筹码 | 不说话也是一种表态 | 影响对方判断 |

**代价设计**：
```
【信任代价】：建立信任需要暴露弱点
【欺骗代价】：谎言被揭穿后的信任崩塌
【背叛代价】：背叛带来的道德压力和潜在报复
【沉默代价】：不说话会被认为有所隐瞒
```

### 四、博弈目标

**定义**：每个博弈者想要达成的目标

**目标层次**：

| 层次 | 描述 | 优先级 |
|-----|------|-------|
| 生存目标 | 活下去 | 最高 |
| 利益目标 | 获得某种好处 | 次高 |
| 关系目标 | 建立/破坏某种关系 | 灵活 |
| 尊严目标 | 维护/获取某种地位 | 灵活 |

**杀虫队博弈特点**：
- 生存是底线，但博弈往往发生在"生存无忧"之后
- 为了"活得更好"而进行的博弈更加复杂
- 最终博弈往往是多目标复合

## 博弈中的心理描写技法

### 心理博弈三层次

**第一层：行为观察**
```
描写要点：
- 细微动作（眼神、嘴角、手指）
- 微表情变化
- 语气停顿

示例：
他的手指在桌下微微颤抖。
只有一瞬。
但我看到了。
```

**第二层：意图推测**
```
描写要点：
- 基于观察的合理推测
- 不确定性的表达
- 推测与现实的差距

示例：
他在撒谎。
但我无法确定——
他是在隐瞒什么，还是在试探我？
```

**第三层：策略调整**
```
描写要点：
- 基于判断的应对策略
- 主动释放的信息
- 主动隐藏的信息

示例：
我点了点头，装作相信了他的话。
但他不知道——
我已经把"他的谎言"列入了我的筹码清单。
```

### 言语交锋技法

**冷读术运用**：
- 说出对方的"秘密"来建立信任
- 用模糊陈述让对方自己填补
- 观察对方反应来验证判断

**反冷读术**：
- 不直接回应对方的试探
- 用反问把问题抛回去
- 用沉默制造压力

**经典话术模式**：

| 场景 | 攻击方 | 防守方 |
|-----|-------|-------|
| 信息试探 | "你觉得...?" | "你为什么这么问？" |
| 施压 | "你应该知道..." | "我只知道我该知道的" |
| 联盟提议 | "我们可以..." | "代价是什么？" |
| 威胁 | "如果你不..." | "你觉得我会怕？" |

## 反转设计技法

### 反转的四种类型

**类型1：信息反转**
```
铺垫：xxx知道xxx
反转：实际上xxx不知道/xxx知道更多
力量：信息优势瞬间反转
```

**类型2：立场反转**
```
铺垫：xxx是敌人
反转：xxx一直在帮你/被迫成为敌人
力量：信任崩塌或重建
```

**类型3：目标反转**
```
铺垫：xxx的目标是xxx
反转：真正目标藏在更深层
力量：全局视角重塑
```

**类型4：代价反转**
```
铺垫：xxx付出了xxx代价
反转：代价其实是伪装/代价带来了意外收获
力量：重新评估博弈结果
```

### 反转铺垫技法

**前期埋设**：
- 细节暗示（人物不经意的一句话）
- 矛盾呈现（前后行为的差异）
- 第三方视角（其他角色的观察）

**中期强化**：
- 误导性解读（让读者/角色往错误方向推理）
- 关键证据（看似指向A的证据）

**后期反转**：
- 证据重解读（同样的证据指向B）
- 信息补完（揭示隐藏信息）
- 逻辑闭环（完美解释之前的矛盾）

## 高阶博弈设计

### 零和博弈 vs 非零和博弈

**零和博弈**：
- 一方所得即另一方所失
- 博弈激烈，结果确定
- 适合生死场景

**非零和博弈**：
- 可以存在双赢/双输
- 结果更复杂
- 适合复杂势力场景

**杀虫队偏好**：
- 初期可能是零和博弈
- 但最终目标往往转化为非零和
- 真正的胜利是"大家都能活下去"

### 重复博弈

**定义**：同样的博弈结构可能重复发生

**设计要点**：
- 记录本次博弈结果影响下次起点
- 建立"博弈记忆"
- 长期关系vs短期利益的选择

### 元博弈

**定义**：关于"博弈规则本身"的博弈

**最高级形式**：
- 质疑规则是否合理
- 提出新的博弈方式
- 改变游戏规则

**《十日终焉》特色**：
- 主角经常跳出"游戏内博弈"
- 进入"规则制定层面"的博弈
- 最终boss往往是在规则层面做文章

## 检查清单

设计博弈场景时检查：

- [ ] 是否创造了足够的信息不对称？
- [ ] 信任关系是否清晰且有变化空间？
- [ ] 各方筹码是否对等又各有权衡？
- [ ] 博弈目标是否明确且有层次？
- [ ] 是否设计了可预见但有惊喜的反转？
- [ ] 心理描写是否足够细腻？
- [ ] 言语交锋是否有张力？
- [ ] 博弈结果是否影响后续剧情？
