# 唐家三少写作风格技能

## 风格概述

唐家三少，起点中文网白金作家，代表作《斗罗大陆》系列、《神印王座》等。其写作风格是商业化网文的标杆范式，以**体系完善、情感真挚、节奏明快、改编友好**著称。

## 核心风格特征

| 特征 | 具体表现 |
|------|----------|
| **商业化标杆** | 故事流畅不拖沓，适合影视/游戏改编，IP价值最大化 |
| **体系完善** | 武魂体系、魂环魂技、等级分明，粉丝二创友好 |
| **情感真挚** | 爱情线完整动人，配角也有完整情感弧线 |
| **团队作战** | 史莱克七怪模式，多角色协作成长 |
| **连续更新** | 18年不断更，日更稳定，读者粘性极强 |

## 核心技法总结

### 1. 武魂体系设计（三层架构）

```
┌─────────────────────────────────────┐
│          第一层：武魂设定            │
│   兽武魂/器武魂/本体武魂/神武魂      │
├─────────────────────────────────────┤
│          第二层：魂环配置            │
│   百年→千年→万年→十万年→神级        │
├─────────────────────────────────────┤
│          第三层：魂技体系            │
│   单体技/群体技/领域技/神技          │
└─────────────────────────────────────┘
```

### 2. 情感线设计（四季递进法）

| 阶段 | 情感状态 | 经典场景 |
|------|----------|----------|
| **春** | 相遇相知 | 命中注定的初遇 |
| **夏** | 暧昧升温 | 共患难的羁绊 |
| **秋** | 确认心意 | 深情告白/危机守护 |
| **冬** | 圆满收束 | 婚礼/重生/永恒守护 |

### 3. 团队配置公式

**完美团队 = 1核心 + 2支柱 + 2辅助 + 2奇兵**

- 1核心：主角/最强输出
- 2支柱：力量型+控制型
- 2辅助：治疗+增益
- 2奇兵：刺客+特殊能力

### 4. 战斗场景模板

```
【开战】双方对峙 → 试探性攻击
【升级】底牌暴露 → 危机时刻
【转折】团队配合 → 反转制胜
【收尾】胜者收获 → 伏笔埋设
```

## 使用方法

### 快速生成

使用 `references/text-generator.md` 中的模板快速生成：

```bash
# 生成开篇
使用"开篇模板"章节的【命运相遇】模板

# 生成战斗
使用"战斗场景模板"章节的【标准团战】模板

# 生成情感
使用"情感场景模板"章节的【生死相依】模板
```

### 深度创作

按以下顺序使用references文件：

1. **power-system.md** → 设计能力体系
2. **commercial-writing.md** → 构建故事结构
3. **team-battle.md** → 设计团队与战斗
4. **emotional-line.md** → 铺设情感线
5. **text-generator.md** → 生成具体文本

### 风格校准

生成文本后可对照以下唐三风格要点进行检查：

- [ ] 主角是否具有明确的目标和动力？
- [ ] 能力体系是否层次分明、易于理解？
- [ ] 情感线是否有完整的起承转合？
- [ ] 团队角色是否有差异化定位？
- [ ] 战斗场景是否体现团队配合？
- [ ] 章节结尾是否有钩子吸引继续阅读？
