# 文风文本生成器

> 本文件提供可直接使用的文本生成模板，包括开篇、场景、对话、战斗等多种场景的模板代码。创作者可直接套用并填充内容。

---

## 一、开篇模板

### 1.1 命运相遇型

```markdown
【模板：命运相遇】

【开篇第一句】（必须抓眼球）
他们说，命运从不会开玩笑。
直到那一天，他遇见了她。

【或】
在这个以武魂定命运的世界里，
他从未想过，自己的命运会因为一个女孩而改变。

【场景设定】
地点：xxxxx（魂兽森林/学院/遗迹/城镇）
时间：xxxx年xx月xx日
背景：xxxx（简要交代世界观）

【核心冲突】
他/她 xxxx（遭遇事件）
导致两人 xxxx（产生关联）

【钩子设置】
就在他以为自己会xxxx的时候，
xxxx（突发转折/伏笔）

【示例填充】
在这个以武魂定命运的世界里，
他从未想过，自己的命运会因为一个女孩而改变。

六岁那年，他在武魂觉醒仪式上觉醒了废武魂——蓝银草。
所有人都说他没有修炼天赋，注定只能成为最普通的魂师。
但他不信命。

直到那一天，他在星斗大森林中遇到了一个被魂兽追击的女孩。
她有着一头蝎子辫，大眼睛里满是倔强。
"你……愿意帮我吗？"
他看着她的眼睛，鬼使神差地点了点头。

那是他第一次见到十万年魂兽化形的人类。
也是他命运的真正起点。

（章节结尾钩子）
他不知道的是，她的出现，
将彻底改变他的人生轨迹……
```

### 1.2 废柴逆袭型

```markdown
【模板：废柴逆袭】

【开篇核心】
在这个世界，武魂决定一切。
而他，觉醒的却是最废物的武魂。

【背景设定】
- 家族/势力：xxxxx
- 武魂类型：xxxxx（废物武魂）
- 初始实力：xxxxx
- 核心矛盾：xxxxx（被轻视/欺辱/退婚等）

【逆境描写】
所有人都xxxxx（嘲笑/欺压/放弃）
只有xxxxx（某人的支持/自己的坚持）
让他在绝望中xxxxx（找到希望）

【转折契机】
直到有一天，他xxxxx（获得机缘/发现秘密/遇到贵人）

【爽点前置】
当所有人还在xxxxx的时候，
他已经xxxxx（做出惊人举动）

【示例】
在这个世界，武魂决定一切。
而他，觉醒的却是最废物的武魂——一根杂草。

他是唐家最末等的子弟，
父亲早亡，母亲病重，
六岁觉醒时被判定为"先天魂力半级，废物武魂"。

整个唐家都放弃了他。
同龄人欺辱他，下人轻视他，
就连族中的长老都说："让他去厨房帮忙吧，修炼这条路，不适合他。"

只有母亲还在病床上拉着他的手：
"三儿，别放弃。妈妈相信你。"

他没有放弃。
在所有人都嘲笑他的时候，
他躲在角落，默默地修炼着最基础的功法。

直到十二岁那年，
他意外触发了一个尘封的机关，
从家族的禁地中，得到了一本古籍。

《玄天宝录》
当第一页的内容映入眼帘时，
他的眼睛亮了。

那是失传已久的唐门绝学。
那是足以改变命运的契机。

"蓝银草……"
他握紧拳头，
"未必就不能成为最强的武魂！"
```

### 1.3 穿越重生型

```markdown
【模板：穿越重生】

【穿越设定】
他原本是xxxxx（前世身份），
却在xxxxx（死因）中，
重生到了xxxxx（异世界/少年时期）。

【异世界设定】
- 世界观：魂师世界/修仙世界/现代都市
- 规则：武魂体系/灵气体系/异能体系
- 身份：xxxxx（原身背景）

【金手指】
但他发现，自己脑海中xxxxx（携带的能力/记忆/系统）
足以让他在这一世xxxxx（改变命运）。

【前世遗憾】
他永远不会忘记前世的xxxxx（遗憾/仇恨/错过的人）
这一世，他发誓xxxxx（复仇/守护/弥补）。

【章节钩子】
当他踏入xxxxx（地点）的那一刻，
命运的齿轮，开始转动……

【示例】
他原本是21世纪最顶尖的特工，
却在一次任务中被最信任的人背叛，
死在了自己人的枪下。

再次睁开眼睛，
他发现自己重生到了一个陌生的世界。

这是一个以武魂定命运的世界。
在这个世界，每个人在六岁时都会觉醒武魂，
武魂的品质，决定了一个人的上限。

而他，重生在了同名同姓的少年身上。
这个少年，是远近闻名的废物，
先天魂力为零，武魂是路边随处可见的蓝银草。

父亲在他出生时就失踪了，
母亲独自将他养大，
却在三天前因病去世。

"这是……让我替这个孩子活下去？"
他闭上眼睛，感受着涌入脑海的记忆。

下一瞬，他猛地睁开眼睛。

因为他在记忆中看到了一个名字——
那个背叛他、杀死他的组织。
他们竟然也存在于这个世界。

"既然让我重活一次……"
他握紧拳头，眼中闪过一丝冰冷的杀意。

"这一世，我不会再信任任何人。"

（但首先，他需要变强。）
```

## 二、场景模板

### 2.1 情感场景模板

```markdown
【模板：生死守护】

【触发条件】：一方陷入危机

【场景设定】
地点：xxxxx
氛围：xxxxx（紧张/危机/绝望）
旁观者：xxxxx（可有可无）

【危机描写】
"xxxxx！"（惊慌的呼喊）
xxxxx（致命攻击/危机）正在袭来，
而她却xxxxx（愣住/躲避不及/为了保护某人）。

【守护反应】
他xxxxx（反应速度描写），
在xxxxx（几乎不可能的时间）挡在她面前。
"想伤她，先过我这关！"

【攻击/受伤描写】
xxxxx（攻击效果），
但他xxxxx（咬牙/不退/承受），
xxxxx（鲜血/伤口）染红了衣衫。

【情感升华】
"你为什么……"她眼眶泛红。
他没有回答，只是转身，将她紧紧抱住。

"因为你是我的命。"

【效果/转折】
就在此时，xxxxx（援军/转机/爆发）出现，
xxxxx（战局变化）。

【示例】
"小舞！"唐三瞳孔骤缩。

那道黑色的光芒如毒蛇般射向小舞，
而她正背对着攻击，根本来不及躲避。

下一瞬，蓝银皇武魂骤然绽放。
唐三的身体如闪电般掠出，
在小舞惊愕的目光中，挡在了她身前。

"想伤她——"
他的声音低沉而坚定。
"先过我这关！"

黑色光芒轰然击中他的后背。
剧痛如潮水般涌来，他咬紧牙关，鲜血从嘴角溢出。
但他的身形，纹丝不动。

"三哥！"小舞惊呼出声，泪水夺眶而出。

唐三转过身，看着她泪流满面的脸，
轻轻伸出手，擦去她脸上的泪痕。

"别哭。"
他的声音温柔得不像话。
"我说过，我的命是你的。"

就在此时——
一道璀璨的金光从他体内爆发而出。
那是……十万年魂环的气息！
```

### 2.2 身份揭露模板

```markdown
【模板：身份揭露】

【铺垫】
在过去的xxxxx（时间）里，
他一直xxxxx（隐藏身份/低调行事），
直到xxxxx（事件）发生。

【引爆点】
"xxxxx（某关键人物）来了！"
所有人的目光都集中在xxxxx（身份揭露者）身上。

【震惊反应】
当众人看到xxxxx（证据/真相）时，
xxxxx（反应描写：震惊/难以置信/哗然）

【打脸环节】
"你不是说他是废物吗？"
"你说他永远不可能成为xxxxx吗？"
"现在呢？"

【主角反应】
他只是淡淡一笑，
或者，他终于不再掩饰，
露出xxxxx（真实身份/气势）

【效果描写】
霎时间，xxxxx（压迫感/气势/变化），
让所有人xxxxx（跪下/震惊/臣服）

【示例】
在过去的三年里，
唐三一直隐藏着自己的双生武魂。

直到这一天的到来。

"宗主驾到！"

星斗大森林的宗主——九十六级封号斗罗，
亲自来到了史莱克学院。
众人的目光都集中在这位传奇人物身上。

而唐三，就站在人群中，
用那双平静如水的眼睛，看着来人。

"你就是唐三？"
宗主目光一扫，落在他身上。
"听说是你，杀了我宗门的弟子？"

此言一出，众人哗然。
所有人开始议论纷纷。
"什么？唐三杀了宗主弟子？"
"他不过是个魂王，怎么可能……"
"完了，这下他死定了……"

然而就在这时，
一道冰冷的声音响起：

"是我杀的。"

众人循声望去，
只见唐三缓缓走出人群，
背后，八个魂环骤然绽放。

红、红、红、红、红、红、红、红。
八个十万年红色魂环！

"你……你说什么？！"
宗主瞪大了眼睛，不敢置信。

"我说——"
唐三的嘴角勾起一抹冷笑。
"你宗门弟子，该死。"

霎时间，一股恐怖的气息从他身上爆发而出。
那是……神的气息！

宗主脸色骤变，下意识后退一步。
"你、你是……"

"唐门门主，唐三。"
"记住这个名字。"
```

## 三、对话模板

### 3.1 深情告白模板

```markdown
【模板：深情告白】

【场景】月下/湖边/花海/星空
【氛围】静谧/浪漫/心动
【时机】战斗结束/危机解除/独处时刻

【他开口】
"你知道吗？"
【她回应】
"嗯？"
【他认真】
"从第一次见到你的那一刻起……"
【停顿，让氛围发酵】
【她的反应】
"……然后呢？"
【他直视她的眼睛】
"然后我就知道，这辈子，完了。"

【或选择更直接的版本】
"我没什么能给你的。"
"但这条命，是你的。"
"这颗心，也是你的。"
"从始至终，都是。"

【她的反应】
沉默 → 泪水 → 点头/扑入怀中

【收尾金句】
"你愿意……相信我吗？"

【示例】
月光如水，洒落在湖面上。
微风轻拂，吹起她的蝎子辫。

"小舞。"
"嗯？"
"我想……有些话，早该告诉你了。"

小舞转过身，看着他的眼睛。
那双眼睛里，有着从未见过的认真。

"第一次在诺丁学院见到你的时候……"
唐三顿了顿，目光温柔得不像话。
"我就知道，你这辈子逃不掉了。"

"什、什么啊……"小舞脸颊微红，却没有躲开。

"蓝银皇告诉我，你是我的另一半。"
"昊天锤告诉我，你是我必须守护的人。"
"而我的心告诉我——"

他轻轻握住她的手，
十指相扣。

"小舞，我爱你。"

"比这世界上任何的一切，都爱你。"

湖面上，月光倒映着两个紧紧相拥的身影。

从那一刻起，他们再也没有分开过。
```

### 3.2 霸气宣言模板

```markdown
【模板：霸气宣言】

【场景】对峙/宣战/当众
【对象】敌人/嘲讽者/全世界
【核心】宣示主权/表明立场/霸气回应

【经典句式】

【面对嘲讽】
"你们说我是废物？"
"那就睁大眼睛看好了——"
"什么叫……天才！"

【面对威胁】
"想动我的人？"
"先问问我的拳头答不答应。"

【面对群嘲】
"你们可以一起上。"
"一个一个来太浪费时间了。"

【面对强敌】
"今日，我xxx，要与你一战。"
"不是你死，就是我亡。"

【面对质疑】
"我知道你们不信。"
"没关系。"
"因为结果，会替我回答。"

【示例】
史莱克学院门口，
数十名武魂殿的魂师将唐三团团围住。

"唐三，你杀了武魂殿的圣子。"
为首的魂斗罗冷冷开口。
"今日，你逃不掉了。"

唐三站在包围圈中央，
脸上没有丝毫惧色。

"我从没想过要逃。"

"你们要战，那便战。"

话音落下，
蓝银皇武魂骤然绽放，
昊天锤浮现掌心，
八红一金，九个魂环同时亮起。

"没错。"

"今日，我要让所有人知道——"

"动我唐三在乎的人，"
"就要做好死的准备。"

他抬起昊天锤，
遥遥指向那魂斗罗。

"武魂殿的杂碎，"
"受死吧！"
```

## 四、战斗场景模板

### 4.1 标准团战模板

```markdown
【模板：标准团战】

【战前】
"来了！"
唐三眼神一凝，看着远处的黑影。

是敌人。
而且，不止一个。

【排兵布阵】
"沐白，正面。"
"竹清，左翼。"
"奥斯卡，香肠。"
"荣荣，增益。"
"胖子，火力覆盖。"
"小舞，跟我。"

众人点头，各自散开。

【试探】
"让我先试试他们的深浅！"
戴沐白大喝一声，
邪眸白虎武魂附体，
第一魂技——白虎烈光波！

"轰！"
对面那名魂圣抬手挡下，
却只是后退了三步。

"魂圣中期，比我预想的强。"戴沐白皱眉。

【交锋】
"第二波！"
唐三大喝一声。

马红俊的凤凰啸天击轰然落下，
朱竹清的幽冥连斩紧随其后，
宁荣荣的七宝琉璃塔绽放出璀璨光芒——
"九宝有名，四曰攻！"

众人的攻击力瞬间提升三成！

【危机】
但就在这时——
敌人后方走出两人。

两名魂斗罗。

"糟了……"戴沐白脸色一变。

【逆转】
"别慌。"
唐三的声音冷静而坚定。
"奥斯卡，镜像肠。"
"给我！"

奥斯卡扔过一根香肠，
唐三一口吞下。

下一瞬——
他的身形骤然消失。

"什么？！"

当众人反应过来时，
唐三已经出现在敌方后排。
手中，正是那把诸葛神弩。

"嗖嗖嗖——！"

十二道寒芒齐发，
瞬间洞穿了两名魂斗罗的防御！

【收尾】
"不可能……"
那魂斗罗瞪大眼睛，难以置信。

"没什么不可能。"
唐三居高临下，看着倒在地上的敌人。
"记住我的名字——"
"唐三。"

战斗，结束。
```

## 五、生成器使用指南

### 5.1 模板套用步骤

```
1. 选择模板类型（开篇/场景/对话/战斗）
2. 复制模板到创作区
3. 按【】内提示填充内容
4. 检查是否符合唐三风格特征
5. 根据剧情需要微调
```

### 5.2 风格校准要点

| 要素 | 检查项 |
|------|--------|
| **节奏** | 每段不超过5行，长短句交替 |
| **对话** | 简短有力，符合角色性格 |
