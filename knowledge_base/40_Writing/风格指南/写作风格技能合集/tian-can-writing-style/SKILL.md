# 天蚕土豆写作风格 Skill

## 风格概述

天蚕土豆，起点中文网白金作家，代表作《斗破苍穹》《武动乾坤》《大主宰》《元尊》。其写作风格奠定了"退婚流"和"废柴逆袭"网文流派的基础，影响了无数后继作品。

## 核心风格标签

- **流派定位**：退婚流开山鼻祖、废柴逆袭经典范式
- **情绪基调**：压抑积累 → 爆发宣泄 → 持续爽感
- **叙事节奏**：长铺垫+短爆发，爆点密集
- **目标读者**：15-30岁男性，渴望代入强者体验

## 核心技法体系

### 1. 退婚流设计 (`divorce-flow.md`)
废材开局+奇耻大辱+三年之约=经典逆袭框架

### 2. 热血逆袭叙事 (`counterattack.md`)
压抑-积累-爆发的情绪曲线设计

### 3. 战斗场面描写 (`battle-scene.md`)
招式命名+力量对比+气势渲染

### 4. 境界体系设计 (`level-system.md`)
层级分明的力量成长体系

### 5. 文风文本生成器 (`text-generator.md`)
开篇模板/场景模板/对话模板

### 创作提示词模板

**开局场景**：
```
创作一个退婚流开篇。主角身份：[废柴少爷/废物赘婿/被退婚者]。
羞辱来源：[未婚妻家族/长辈/天才]。需要包含：
1. 主角当前困境（实力/地位/处境）
2. 对方羞辱的具体言行
3. 主角的三年之约/复仇宣言
4. 埋下的伏笔（隐藏实力/金手指/女性角色）
```

**战斗场景**：
```
创作一段热血战斗。主角当前境界：[斗者/斗师...]，
对手境界：[更高/同阶/更低]。要求：
1. 招式命名（星/辉/日/月等意象）
2. 力量对比描写
3. 局势逆转点
4. 结束时对手/观众的震惊反应
```

**突破场景**：
```
设计一次境界突破。主角当前：[境界名]，目标：[新境界]。
瓶颈原因：[心魔/资质/资源]，突破契机：[顿悟/机缘/逼迫]。
需要体现：
1. 突破前的积累感
2. 突破时的异象描写
3. 突破后的力量膨胀感
```

## 技法速查

### 退婚流公式
```
【废柴身份】+【当场羞辱】+【强势退婚】+【三年之约】+【暗中伏笔】= 退婚流经典开局
```

### 逆袭节奏公式
```
压抑章节(1-3章) → 小高潮(1章) → 更大压抑(2-4章) → 大爆发(1-2章) → 新压抑...
```

### 战斗描写公式
```
【对手轻视】→【主角试探】→【底牌暴露前兆】→【对手震惊】→【主角碾压/艰难取胜】
```

### 境界描写公式
```
【当前境界名称】+【小阶位】+【战力表现】+【下一境界描述】+【突破条件】
```

## 文风特征总结

| 维度 | 天蚕土豆风格 | 写作要点 |
|-----|-------------|---------|
| 句式 | 短句为主，长短交错 | 战斗时短句加速，阅读快感强 |
| 用词 | 直接、力量感强 | 常用"震碎""撕裂""碾压"等词 |
| 情绪 | 先抑后扬，压抑积累 | 开局越惨，逆袭越爽 |
| 对话 | 简洁有力 | 主角话少但金句多，反派话多但被打脸 |
| 旁白 | 服务剧情，点到即止 | 不拖沓，关键时刻才大量描写 |
