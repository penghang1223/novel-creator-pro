# 退婚流设计技法

退婚流是天蚕土豆开创的核心叙事模式，《斗破苍穹》开篇即是经典范式。这一模式的核心是**将社会性羞辱转化为叙事驱动力**，让读者的愤怒与主角同频，在逆袭时获得最大爽感。

---

## 一、退婚流经典结构

### 核心公式
```
【废柴身份】+【当场羞辱】+【强势退婚】+【三年之约】+【暗中伏笔】= 退婚流经典开局
```

### 《斗破苍穹》原型拆解

```
萧家废物少爷（废柴身份）
    ↓
纳兰嫣然带人上门（羞辱来源）
    ↓
当众退婚+言语刺激（"这婚事，是我和父亲商量后退的"）
    ↓
萧炎被迫签下休书（最强羞辱）
    ↓
萧炎反击："三十年河东，三十年河西，莫欺少年穷！"（三年之约）
    ↓
药老潜伏+薰儿暗示（暗中伏笔）
```

## 二、退婚场景六要素

### 1. 身份落差

**公式**：
```
曾经辉煌的身份（可选择不用） → 当前落魄的处境
```

**写法示例**：
- 萧家曾经是乌坦城三大家族之一
- 主角父亲曾是天才，如今父亲失踪，实力倒退
- 被未婚妻家族嫌弃，被同辈嘲笑

**核心目的**：让读者理解"为什么被羞辱"，建立同情基础

### 2. 羞辱现场

**公式**：
```
羞辱者的傲慢言行 + 围观者的冷漠/嘲讽 + 主角的隐忍
```

**场景要素**：
- 时间：家族聚会/公开场合（越多人看到越好）
- 羞辱者：未婚妻本人或家族长辈（前者更爽）
- 羞辱程度：言语+行动双重打击（摔休书、扔玉佩等）
- 围观者：主角父母/族人的难看脸色（侧面烘托）

**写法示例**：
```
"萧炎哥哥，嫣然今日前来，是为了与你了断这桩……本就不该存在的婚约。"

她的声音很轻，却清晰地传入在场每个人耳中。

"不该存在的婚约"——这五个字像是一记响亮的耳光，狠狠地扇在萧炎脸上。

云岚宗的弟子们发出一阵轻笑，那笑声中的嘲讽与不屑，几乎要将萧炎淹没。
```

### 3. 主角的"失态"与反击

**两种经典模式**：

**模式A：当场爆发型**
```
积压愤怒 → 爆发反击 → 三年之约 → 震惊全场
```

**模式B：冷静隐忍型**
```
表面平静 → 签下休书 → 低沉宣言 → 伏笔暗示
```

**写法示例（模式B更经典）**：
```
萧炎的手掌平静地握着休书，骨节因为用力而泛白。

"三年之约？"

他抬起头，嘴角勾起一抹淡淡的弧度。

"三十年河东，三十年河西，莫欺少年穷！"

话音落下，整个大厅陷入死一般的寂静。
```

### 4. 三年之约/复仇宣言

**公式**：
```
时间期限 + 地点约定 + 结局宣言
```

**经典句式模板**：

| 类型 | 句式 |
|-----|-----|
| 愤怒宣言 | "三年后，云岚宗之巅，我萧炎与你纳兰嫣然……一战！" |
| 冷淡宣言 | "三年后，我会亲自去云岚宗，取回属于我的东西。" |
| 嘲讽宣言 | "三年？不用那么久。三年后，我会让你后悔今天的选择。" |

### 5. 旁观者反应

**公式**：
```
震惊 → 质疑 → 嘲笑 → 怀疑 → 沉默
```

**分层描写**：
- **云岚宗弟子**：嘲笑、不屑
- **萧家众人**：尴尬、失望
- **萧战（父亲）**：愤怒、无奈
- **薰儿（女主）**：心疼、神秘微笑
- **某个慧眼角色**：若有所思

### 6. 伏笔埋设

**必须埋下的四类伏笔**：

| 伏笔类型 | 示例 | 作用 |
|---------|-----|-----|
| 隐藏实力 | 药老暗中观察 | 解释主角为何不慌 |
| 金手指暗示 | 戒指黑雾/神秘传承 | 为后期升级埋伏笔 |
| 女性角色 | 薰儿的坚定态度 | 暗示有强援 |
| 反派软肋 | 纳兰嫣然的小心思 | 后期可反转 |

**写法示例**：
```
薰儿望着萧炎的背影，清澈的眸子中闪过一抹异光。

"萧炎哥哥……薰儿相信你。"

在无人看见的角度，一丝淡淡的斗气波动悄然散去。
```

## 三、退婚流变体写法

### 变体1：废物赘婿被休
```
情境：主角入赘女方家，三年后被休
核心冲突：丈人嫌弃 + 妻子冷漠 + 岳家羞辱
爽点来源：三年后强势归来，丈人/妻子跪舔
```

### 变体2：天才陨落被退婚
```
情境：主角曾是天才，一朝陨落被退婚
核心冲突：落差感 + 昔日荣耀不再
爽点来源：重新崛起 + 打脸退婚者
```

### 变体3：宗门弟子被逐出师门
```
情境：核心弟子被诬陷，逐出宗门
核心冲突：师门背叛 + 同门嘲笑
爽点来源：创立新势力 + 归来复仇
```

## 四、退婚流核心心法

### "四层羞辱递进法"

```
第一层：身份羞辱（你是废物）
    ↓
第二层：能力羞辱（你不配）
    ↓
第三层：当众羞辱（所有人都看着）
    ↓
第四层：情感羞辱（连她都不要你）
```

**写作要点**：
- 每层羞辱都要有具体场景和对话
- 让读者感受到主角"社会性死亡"的绝望
- 最后一层最关键：连未婚妻都嫌弃，才能激发读者愤怒

### "三秒沉默法"

退婚场景最经典的瞬间：
```
主角说完三年之约
↓
全场陷入沉默
↓
用沉默的时长来放大冲击力
```

**写法**：
```
"三十年河东，三十年河西，莫欺少年穷！"

话音落下。

一秒。

两秒。

三秒。

整个大厅死一般的寂静，落针可闻。
```

## 五、快速模板

### 模板A：经典退婚

```markdown
【开场】：乌坦城，萧家大厅。

【身份】：[主角名]是萧家少爷，三年前父亲失踪，实力倒退至[X]，沦为废物。

【羞辱现场】：
- 女方家族代表：[女性角色名] 带着云岚宗弟子上门
- 羞辱言行："这桩婚约，从一开始就是个错误。"
- 围观者：萧家族人面色难看，窃窃私语

【退婚行动】：
- 摔出休书/玉佩
- "从今日起，你我恩断义绝。"
- 主角被迫签字

【三年之约】：
- 主角站起身，声音平静却带着不容置疑的坚定
- "三年之约——三年后，我会亲自上[女方宗门]，与你一战。"
- 震惊四座

【伏笔】：
- 手指上的[神秘戒指/玉佩]微微发热
- 某位女性角色眼中闪过异芒
- "萧炎哥哥，薰儿相信你。"
```

### 模板B：废物赘婿

```markdown
【开场】：某城池，林家府邸。

【身份】：[主角名]入赘林家三年，妻子[女主名]冷漠，丈人[岳父名]嫌弃。

【羞辱现场】：
- 今日是林家家族大会
- 岳父当众宣布：[女主名]与[天才配角]订婚
- 众人嘲笑主角："三年了，还是那个废物。"
- 妻子面无表情，仿佛不认识他

【扫地出门】：
- 休书甩在主角脸上
- "滚出林家，你不配。"
- 主角平静地捡起休书

【反击宣言】：
- 转身离去前，回头说一句话
- "三年后，我会回来。届时，该滚的是你们。"

【伏笔】：
- 身上某处有神秘印记
- 有人暗中注视这一切
```

## 六、避坑指南

| 误区 | 问题 | 正确做法 |
|-----|-----|---------|
| 羞辱不够 | 读者不够愤怒 | 要让羞辱者"当面"且"公开"羞辱 |
| 反击太快 | 爽感不足 | 先压抑3-5章，再让主角反击 |
| 理由牵强 | 逻辑不通 | 退婚要有"合理"理由（家族利益/实力差距） |
| 伏笔不清 | 后期乏力 | 开篇就暗示主角有隐藏实力 |
| 女性脸谱 | 情感线无趣 | 让女性角色有自己的立场和态度 |
