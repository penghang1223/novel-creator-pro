# 文风文本生成器

本文件提供天蚕土豆风格的各类场景模板，可直接套用或根据需要进行修改。

## 一、开篇模板

### 1.1 经典退婚流开篇

```markdown
## 模板A：废物少爷被退婚

[地名]，是一个平凡的小镇。

然而今日的[家族名]府邸，却格外热闹。

因为——[女性角色名]来了。

[家族名]的少主，[主角名]，三年前还是[地名]第一天才。

但自从[原因]后，他的实力不进反退，从[巅峰境界]跌落到[废物境界]。

从此，"废物"二字，便成了他的标签。

"[主角名]，今日我来，是为了与你解除婚约。"

[女性角色名]的声音清冷，眼神中带着居高临下的傲慢。

"这桩婚约，从一开始就是[长辈名]的一厢情愿。"

"现在的你……根本不配。"

她的声音不大，却清晰地传入在场每个人的耳中。

周围响起一阵窃窃私语。

"[主角名]真是可怜啊……"

"当年多风光，现在连未婚妻都来退婚了。"

"废物就是废物，还指望什么？"

[主角名]低着头，看不清表情。

他的手指微微颤抖——

是愤怒，是屈辱，更是……

压抑到极点的杀意。

"三年。"

他终于开口，声音平静得可怕。

"三年后，我会亲自上[宗门名]，与你……一战。"

话音落下，全场哗然。

"哈！"

[配角名]忍不住笑出声来。

"就凭你这个废物，还敢挑战[女性角色名]？"

"你知道她现在是什么境界吗？"

"[主角名]，我劝你还是认清现实吧。"

[主角名]缓缓抬起头。

他的眼中，没有愤怒，没有悲伤。

只有一片冰冷的平静。

"现实？"

他轻声道。

"那就让现实……来证明一切吧。"

三年之约，就此立下。

没人知道，在那个废物少爷的体内——

有什么东西，正在悄然觉醒。
```

### 1.2 废物赘婿开篇

```markdown
## 模板B：入赘三年被扫地出门

[家族名]，在[地名]城也算有头有脸。

然而今日的家族大会，却成了[主角名]的受辱现场。

"今日，我要宣布一件事。"

[岳父名]端坐主位，声音洪亮。

"从今日起，[主角名]与我[家族名]再无瓜葛。"

"这桩婚约，正式解除。"

话音落下，周围响起一阵哄笑。

"终于要赶走这个废物了！"

"三年了，连[妻子名]的房门都没进去过。"

"也不看看自己什么德行，还想高攀我们[家族名]？"

[主角名]站在人群中央，面无表情。

三年。

整整三年。

三年前，他被未婚妻退婚，走投无路之际，入了[家族名]的门。

本以为能安稳度日。

却没想到，这三年……

比在地狱还要煎熬。

受尽白眼。

尝遍冷暖。

连下人都能随意羞辱他。

而他的妻子——[妻子名]，三年间对他视若无睹。

甚至从未正眼看过他一次。

"[主角名]，这是你的休书。"

一张纸甩在他脸上。

[岳父名]居高临下地俯视着他。

"拿着它，滚吧。"

[主角名]没有动。

他只是弯腰，捡起了那张休书。

然后——

他笑了。

"滚？"

他的声音很轻，却让所有人都听得清清楚楚。

"三年前，有人让我滚。"

"我滚了，滚进了[家族名]。"

"三年后，又有人让我滚。"

"那么——"

他抬起头，露出一双漆黑如墨的眼眸。

"三年后，我会让整个[地名]城知道——"

"当年让我滚的人……"

"会跪着求我回来。"
```

### 1.3 陨落天才开篇

```markdown
## 模板C：三年前的第一天才

[地名]城，有一个无人不知的名字——[主角名]。

三年前，他是[地名]城第一天才。

十二岁觉醒[特殊体质]，十五岁突破[大境界]，被誉为[天才之名]。

无数势力向他抛出橄榄枝。

[女性角色名]的家族，也在其中。

婚约，就此立下。

然而——

三年前的那一夜，一切都变了。

那一夜，发生了什么，无人知晓。

只知道第二天醒来，[主角名]的[特殊体质]消失了。

他的境界，从[巅峰境界]一路跌落到[废物境界]。

从此，天才沦为废物。

而当年那些追求他的势力，纷纷消失。

至于那桩婚约……

"[主角名]，这桩婚约，作废吧。"

[女性角色名]的父亲[岳父名]，今日亲自上门。

"我女儿如今是[大宗门名]的弟子，与你……"

"不是一个世界的人了。"

[主角名]站在门口，沉默不语。

曾经，他意气风发。

曾经，她对他仰慕有加。

曾经，他们郎才女貌。

而如今——

她成了宗门天骄，而他成了废物弃子。

"[岳父名]，我记得三年前，您可是主动来提亲的。"

[主角名]轻声道。

"那时候，您说我是[地名]城百年不遇的天才。"

"说我日后必成大器。"

"说我与令爱是天作之合。"

[岳父名]脸色微变："那是……"

"那是什么？"

[主角名]打断他。

"那是看走了眼？"

"还是——"

"你们[家族名]，只会锦上添花，从不会雪中送炭？"

[岳父名]脸色铁青。

"[主角名]，你放肆！"

"现在的你，有什么资格说这种话？"

"资格？"

[主角名]笑了。

"三年前，你们[家族名]以我为荣。"

"三年后，你们[家族名]以我为耻。"

"很好。"

"那就让时间来证明——"

"今日你们弃我如敝履，他日我让你们高攀不起。"

"这桩婚约，我认。"

"但退婚……得由我来退。"

话音落下——

他转身离去。

只留下一个倔强的背影。

三年后，[地点]之巅。

他会让她知道——

什么叫真正的天才。
```

## 二、战斗场景模板

### 2.1 实力碾压型

```markdown
## 模板：对手轻视→主角爆发→碾压全场

[对手名]负手而立，脸上挂着玩味的笑容。

"萧炎？"

他上下打量着眼前的少年。

"就是你，要挑战[对手宗门名]？"

"也不撒泡尿照照自己什么德行。"

周围响起一阵哄笑。

[对手名]的手下纷纷附和：

"老大，跟他废话什么？"

"直接废了他就是。"

"就是就是，让这个废物知道什么叫天高地厚！"

[对手名]摆摆手，示意手下安静。

"萧炎是吧？我给你一个机会。"

他居高临下地说。

"跪下，叫三声爷爷，我可以考虑……"

"留你一条狗命。"

萧炎没有说话。

他只是静静地站在那里，看着眼前这个嚣张的男人。

"不说话？"

[对手名]冷笑。

"看来是吓傻了——"

话音未落。

"轰！"

一股恐怖的气势，骤然从萧炎体内爆发！

[对手名]脸色大变。

"这股气息……这是……"

"斗……斗王？！"

萧炎缓缓抬起手掌。

"你问我凭什么挑战[对手宗门名]？"

"现在，你知道了。"

"接下来——"

他的眼中闪过一丝冷芒。

"该你跪下了。"
```

### 2.2 绝境翻盘型

```markdown
## 模板：被围杀→濒死→激发潜能→反杀

"咳……"

斗气……几乎耗尽。

"杀了他！"

他的手下蜂拥而上。

萧炎咬紧牙关，艰难地站起身。

然而——

"砰！"

一道剑光划过，他的胸口再添一道伤口。

"萧炎哥哥！"

远处传来薰儿的声音。

"别过来！"

萧炎嘶声喊道。

他的身体，已经到了极限。

脑海中，无数画面闪过。

三年的隐忍。

"怎么可能——"

"这股气息……是……"

"斗皇？！"

萧炎缓缓站起身，黑发飞舞，衣衫猎猎作响。

"三十年前，你们[家族名]逼死了我的父亲。"

"三年前，你们[家族名]毁了我的婚约。"

"今日——"

他抬起头，露出一双漆黑如深渊的眼眸。

"该还债了。"
```

## 三、境界突破模板

### 3.1 普通突破

```markdown
## 模板：积累→瓶颈→顿悟→突破

一个月。

整整一个月的苦修。

萧炎几乎将所有的时间都用在了修炼上。

日出而作，日落而息。

每天除了吃饭睡觉，就是修炼。

而他的努力，终于要看到成果了。

"嗡……"

他体内的斗之气旋缓缓旋转，一丝多余的斗气被缓缓凝聚。

"就差一点……"

他屏住呼吸，引导着斗气冲击那道无形的屏障。

一下……

两下……

三下……

"还是不行……"

萧炎皱起眉头。

明明能量已经足够，为什么就是突破不了？

"小家伙，你的心不静。"

药老的声音在脑海中响起。

"你在想那个纳兰嫣然对吧？"

萧炎沉默了。

是的。

他不得不承认。

这一个月来，那个女人的身影，一直萦绕在他心头。

那日的羞辱，那日的嘲讽，那日的退婚……

每每想起，他就无法平静。

"愤怒吗？"药老问道。

"愤怒。"萧炎低声道。

"那就对了。"

药老的声音带着一丝笑意。

"将这份愤怒，化为你的动力。"

"冲破那道屏障。"

萧炎闭上眼睛。

纳兰嫣然……

你说我配不上你？

你说我连你的剑都接不下？

"总有一天——"

他低声道。

"我会让你后悔今日的选择。"

"而今天……就是第一步！"

话音落下——

"轰！"

一道闷响从他体内传出！

斗之气旋猛然加速旋转！

一道道斗气如同洪流，冲向那道屏障！

"咔嚓！"

屏障出现裂纹。

"咔嚓！"

裂纹越来越大。

"碎！"

萧炎猛然睁开眼睛。

"轰！！！"

屏障，轰然碎裂！

一股比之前强大数倍的气息，从他体内席卷而出！

"突破了……"

他握紧拳头，感受着体内澎湃的力量。

二星斗者。

他，终于突破了！
```

### 3.2 关键境界突破

```markdown
## 模板：关键瓶颈→危机触发→生死顿悟→境界飞跃

斗灵。

这是萧炎目前面临的最大的瓶颈。

从斗师到斗灵，需要的不只是能量的积累，更需要对斗气的领悟。

"小家伙，你的积累已经足够了。"

药老说道。

"但要突破斗灵，需要的不仅仅是这些。"

"你需要领悟斗气凝形的真谛。"

"什么是斗气凝形？"萧炎问道。

"就是将无形的斗气，凝聚成有形的形态。"

"你需要在脑海中，构建一个完整的意象。"

"这个意象，将成为你斗灵境界的根基。"

构建意象……

萧炎陷入沉思。

火焰？

不对。

风雷？

也不对。

那么……

他想到了什么。

"有了。"

他盘膝而坐，开始凝聚斗气。

一道虚幻的火焰在他掌心缓缓浮现。

不对，太模糊了。

他皱起眉头，加大输出。

火焰逐渐凝实，但还是不够。

"还不够……"

萧炎额头冒汗。

"需要更多的能量……"

就在此时——

"萧炎！"

薰儿的声音从远处传来，带着惊恐。

"有人偷袭！"

萧炎猛然睁开眼睛。

一道凌厉的剑光，正朝他直射而来！

此刻，正是突破的关键时刻！

退，则前功尽弃！

进，则身死道消！

"萧炎！躲开！"

薰儿的声音带着哭腔。

然而——

萧炎没有躲。

他的眼中，反而闪过一丝明悟的光芒。

"我明白了……"

他低声道。

"火焰的真谛，不是温度，不是形态——"

"而是燃烧！"

"是焚尽一切的决心！"

话音落下——

"轰！！！"

一道璀璨的火焰柱，从他掌心冲天而起！

火焰柱中，一道虚幻的莲座若隐若现。

"这是……"

薰儿愣住了。

"火焰凝形？！"

萧炎缓缓站起身，身上的气息已然大变。

斗灵。

他，成功了。
```

## 四、对话场景模板

### 4.1 三年之约对话

```markdown
## 模板：退婚场景完整对话

【纳兰嫣然开口】

纳兰嫣然深吸一口气，从怀中取出一卷卷轴。

"萧炎，今日我来，是为了这桩婚约。"

"我知道，这对于你来说可能很突然，但……"

"但什么？"萧炎淡淡问道。

纳兰嫣然咬了咬牙："这桩婚约，我要退掉。"

【全场哗然】

"退婚？"

"纳兰家的小姐要退婚？"

"萧家少爷被退婚了？"

议论声四起。

萧战脸色铁青，萧玉等人面面相觑。

只有萧炎，神色平静。

"理由呢？"他问。

纳兰嫣然直视着他："萧炎，我知道你曾经是天才，但现在的你……"

"已经配不上我了。"

"我是云岚宗的内门弟子，未来前途无量。"

"而你，只是乌坦城的一个废物。"

"这样的婚约，对我来说是一种侮辱。"

【萧炎的回应】

萧炎沉默了片刻。

然后，他笑了。

"侮辱？"

他站起身，与纳兰嫣然对视。

"纳兰小姐，三年前，是你们纳兰家主动来提亲的。"

"那时候，你们纳兰家可没有嫌弃我是'废物'。"

纳兰嫣然脸色微变。

萧炎继续说道：

"三年前，我是乌坦城第一天才，你们纳兰家以与我定亲为荣。"

"三年后，我实力倒退，你们纳兰家就说我配不上你。"

"很好。"

"这很现实。"

"那我也现实地告诉你——"

他拿起那卷退婚书，看都没看，就签上了自己的名字。

"退婚，我萧炎认了。"

"但——"

他将卷轴扔回纳兰嫣然手中。

"三年后，我会亲自去云岚宗，与你一战。"

"届时，如果你输了……"

他的眼中闪过一丝锐利的光芒。

"我要你，为今日的羞辱，付出代价。"

【三年之约成立】

"萧炎！"

纳兰家族的领头人站起身，怒道：

"你一个废物，也敢——"

"聒噪。"

萧炎淡淡地打断他。

"这是我和纳兰嫣然之间的事，与你无关。"

"三年之约，就这么定了。"

"怎么，你们云岚宗不敢接？"

全场死寂。

纳兰嫣然死死地盯着萧炎。

最终，她点了点头：

"好。"

"三年之约，我纳兰嫣然接了。"

"三年后，云岚宗之巅，我等你。"

"希望到那时，你不要让我太失望。"
```

### 4.2 打脸嘲讽对话

```markdown

"啧啧，我儿子三年前就已经超过你了。"

"废物就是废物，再怎么挣扎也没用。"

萧炎没有说话，只是静静地看着他。

"怎么，不说话？"

[配角名]凑近他，声音压低：

"告诉你，我儿子如今可是七星斗者了。"

"你这一辈子，也别想追上他。"

"放弃吧，废物。"

萧炎依然没有说话。

他的沉默，在[配角名]看来是认怂。

"果然是个废物，连反驳的勇气都没有。"

他啐了一口，转身离去。

"真没劲，还以为能看场好戏呢。"

"算了算了，别理这个废物了。"

众人散去。

萧炎站在原地，嘴角缓缓勾起一抹弧度。

"七星斗者……"

他轻声自语。

"真巧。"

"我也是七星斗者。"

【关键比赛】

三日后，家族大比。

"萧炎对萧恒！"

裁判的声音响起。

萧恒——正是那个嘲讽萧炎的配角的儿子。

"萧炎？"

萧恒走上擂台，看到萧炎的名字，笑了。

"没想到你还真敢来。"

"认输吧，废物。"

"我怕一不小心，伤了你这条狗命。"

萧炎缓步走上擂台。

他的表情，依然平静。

"萧恒，我记得三天前，你父亲说我永远追不上你。"

"是的。"萧恒傲然道。

"那你猜猜，我现在是什么境界？"

萧恒一愣。

下一瞬——

"轰！"

一股气势从萧炎体内爆发！

七星斗者！

萧恒脸色大变。

"这、这怎么可能——"

"怎么不可能？"

萧炎一拳轰出。

"你父亲说我是废物？"

"那今天，就让你见识一下——"

"废物的拳头！"

"砰！"

萧恒被一拳轰飞，重重地砸在擂台边缘。

"你父亲说我永远追不上你？"

萧炎缓步走来。

"现在呢？"

"你还觉得我是废物吗？"

萧恒口吐鲜血，满脸惊恐。

"你、你作弊——"

"作弊？"

萧炎蹲下身，与他对视。

"境界是我自己的，跟你有什么关系？"

"还是说——"

"你们父子俩，只敢在实力低微的人面前嚣张？"

"遇到真正的强者，就只剩下叫嚷着'作弊'了？"

萧恒的脸色青一阵白一阵。

萧炎站起身，居高临下地看着他。

"记住今日的教训。"

"下次嘲讽别人之前——"

"先搞清楚自己的分量。"
```
