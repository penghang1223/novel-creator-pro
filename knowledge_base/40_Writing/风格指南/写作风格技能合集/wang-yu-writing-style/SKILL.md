# 忘语写作风格Skill

## 风格定位

**作者背景**：忘语，起点中文网白金作家，凡人流网文开山鼻祖
**代表作**：《凡人修仙传》《魔天记》《玄界之门》
**核心定位**：资质平庸主角的逆袭之路，修炼体系严谨，世界观庞大精密

---

## 核心风格特征

| 特征 | 具体表现 |
|------|----------|
| **凡人流开创** | 主角资质平庸，非天才型；稳扎稳打，不开挂；资源靠积累，步步为营 |
| **修炼体系严谨** | 境界划分清晰（炼气→筑基→结丹→元婴→化神等）；功法有出处；丹药有丹方；法宝有品阶 |
| **世界观庞大** | 人界→灵界→仙界多层结构；宗门派系林立；种族众多；地理设定详尽 |
| **情节跌宕** | 危机与机遇并存；小高潮不断，大高潮震撼；反转合理；节奏张弛有度 |
| **代入感强** | 平凡人视角；成长过程真实可感；配角有血有肉；情感描写克制但真挚 |

## 技法体系

### 1. 凡人流技法（mortal-flow.md）
- 主角设定公式：平庸资质 + 机缘巧合 + 谨慎性格 + 坚持不懈
- 资源获取模式：步步为营，不取巧
- 越阶战斗逻辑：智取、符箓、法宝、阵法等外物辅助
- 核心心法：闷声发大财，低调成大道

### 2. 修炼体系设计（cultivation-system.md）
- 境界体系：九层炼气、三层筑基（初期/中期/后期）等递进结构
- 功法体系：功法来源、功法限制、功法进阶
- 丹药体系：主药辅药、药效、副作用、炼制难度
- 法宝体系：品阶划分、威能限制、认主机制

### 3. 世界观结构（world-structure.md）
- 三界架构：人界（低阶）-灵界（中阶）-仙界（高阶）
- 势力分布：宗门、家族、散修、妖族、海域
- 资源分布：灵脉、秘境、古修遗址
- 地图设计：从局部到整体的渐进展开

### 4. 情节设计技法（plot-design.md）
- 升级节奏：N章一小坎，N章一大关
- 冲突设计：夺宝、宗门恩怨、种族大战、飞升劫难
- 副本类型：秘境探险、宗门大比、遗迹探宝
- 悬念设置：伏笔埋设、悬念回收、剧情反转

### 5. 文风文本生成器（text-generator.md）
- 开篇模板：穿越/出身→困境→机缘→转折
- 场景描写：修炼场景、战斗场景、市井场景
- 对话风格：简洁有力、利益交换、师徒/同门/散修不同语气
- 战斗描写：招式+法宝+灵力消耗+心理变化

## 使用方法

### 方式一：整篇创作
```
输入：主角设定（姓名、出身、资质）、世界观设定、修炼体系
输出：符合忘语风格的完整章节
```

### 方式二：单场景生成
```
输入：场景类型（修炼/战斗/交易/对话）、当前境界、对手/环境信息
输出：符合忘语风格的场景描写
```

### 方式三：技法咨询
```
输入：具体问题（如"如何设计筑基期主角的第一次生死危机"）
输出：忘语风格的处理方案+原文示例
```

### 方式四：风格迁移
```
输入：任意小说片段或设定
输出：转换为忘语风格的改写版本
```

## 质量标准

### 符合忘语风格的核心指标
1. **主角非天才**：没有天生灵根或特殊体质，或虽有但被压制/隐藏
2. **资源需积累**：不靠奇遇一步登天，靠积少成多
3. **战斗有代价**：越阶挑战需要付出代价，不是轻松碾压
4. **体系自洽**：修炼境界、功法丹药、法宝威能前后一致
5. **节奏稳健**：不急于求成，张弛有度

### 避雷指南
- ✗ 主角开局满灵根/混沌体/逆天天赋
- ✗ 战斗无消耗，战完还能活蹦乱跳
- ✗ 等级突飞猛进，三章从凡人到大能
- ✗ 敌人无脑降智，纯粹送经验
- ✗ 女主倒贴，后宫无脑扩张
