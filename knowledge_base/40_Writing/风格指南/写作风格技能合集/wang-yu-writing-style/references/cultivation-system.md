# 修炼体系设计详解

## 一、修炼体系设计原则

### 核心原则
1. **逻辑自洽**：境界高低决定战力高低，例外要有合理解释
2. **递进清晰**：每一层境界都要有明确的意义和门槛
3. **资源对应**：境界提升需要对应的资源和时间
4. **体系平衡**：不能让某一境界的某项能力过于bug

## 二、境界体系设计

### 2.1 经典凡人流境界体系

```markdown
# 人界篇（入门级）

## 炼气期（9层）
- 入门境界，吸纳天地灵气
- 第1-3层：感应灵气，打通经脉
- 第4-6层：灵气循环，可使用低阶法术
- 第7-9层：灵气凝练，可炼制法器
- 寿元：凡人级别（100岁左右）
- 标志性能力：御物飞行（需法器）

## 筑基期（3个小境界）
- 真正踏入修仙之路
- 筑基初期：丹田凝聚，可使用上品法器
- 筑基中期：灵气液化，实力大增
- 筑基后期：接近结丹，底蕴积累
- 寿元：200岁左右
- 标志性能力：凝气化形（不需法器飞行）

## 结丹期（3个小境界）
- 丹田结丹质的飞跃
- 结丹初期：丹成初凝，可炼制灵器
- 结丹中期：丹气合一
- 结丹后期：大圆满，准备凝婴
- 寿元：500岁左右
- 标志性能力：领域雏形

## 元婴期（3个小境界）
- 神魂凝聚，神识大增
- 元婴初期：元婴出窍，神识范围大增
- 元婴中期：元婴稳固，可夺舍
- 元婴后期：大修士，可在局部区域呼风唤雨
- 寿元：1000岁左右
- 标志性能力：瞬移

## 化神期（人界巅峰）
- 接触飞升门槛
- 化神初期/中期/后期
- 人界无敌，但受天地限制无法存进
- 寿元：2000岁左右
- 最终目标：飞升灵界

# 灵界篇（中级）

境界：化神 → 炼虚 → 合体 → 大乘 → 渡劫 → 真仙

每境界特点：
- 炼虚期：虚实转化，可入虚空
```

## 三、功法体系设计

### 3.1 功法等级划分

```markdown
# 功法品阶表

| 品阶 | 等级 | 修炼速度 | 威力 | 副作用 | 稀有度 |
|------|------|----------|------|--------|--------|
| 黄阶 | 低阶功法 | 慢 | 弱 | 无 | 烂大街 |
| 玄阶 | 中阶功法 | 中等 | 中等 | 可能有 | 较常见 |
| 地阶 | 高阶功法 | 快 | 强 | 修炼有门槛 | 珍稀 |
| 天阶 | 顶级功法 | 极快 | 极强 | 苛刻条件 | 罕见 |
| 仙阶 | 仙人功法 | 超凡 | 逆天 | 难以想象 | 传说 |

# 常见功法来源
1. 宗门传承（最常见）
2. 前辈遗物（秘境/遗址）
3. 坊市购买（需要灵石）
4. 意外获得（奇遇剧情）
5. 自创改良（高手专属）
```

### 3.2 功法设定模板

```markdown
# 示例：基础功法"小云雨诀"

## 基本信息
- 品阶：黄阶上品
- 属性：水属性功法
- 适合灵根：水、土灵根
- 修炼速度：中等偏慢
- 特点：灵力柔和，持久力强

## 功法内容
- 总层数：9层
- 第1-3层：引气入体，灵气行于经脉
- 第4-6层：灵气可外放，形成云雾
- 第7-9层：云雨相生，灵力生生不息

## 配套法术
- 小云雨术（基础）：凝聚水汽，滋润灵药
- 云雾术（中阶）：制造云雾，遮蔽视线
- 大云雨术（高阶）：召唤云雨，范围攻击

## 优缺点
- 优点：灵力持久，适合消耗战；配套法术实用
- 缺点：攻击力一般；水属性克星是土属性

## 修炼要求
- 入门门槛：双属性灵根即可
- 修炼资源：普通灵石即可
- 进阶方向：可进阶为"玄水诀"（需筑基丹）
```

## 四、丹药体系设计

### 4.1 丹药等级划分

```markdown
# 丹药品阶表

| 品阶 | 名称 | 效果 | 副作用 | 炼制难度 |
|------|------|------|--------|----------|
| 下品 | 丹丸 | 效果弱 | 可能有丹毒 | 低 |
| 中品 | 灵丹 | 效果正常 | 丹毒较少 | 中等 |
| 上品 | 妙丹 | 效果增强 | 几乎无丹毒 | 高 |
| 极品 | 天丹 | 效果翻倍 | 无副作用 | 极难 |
| 仙品 | 仙丹 | 逆天效果 | 无 | 只存传说 |

# 丹毒设定（重要！）
- 丹毒是丹药的副产物
- 积累过多会影响修炼
- 需要定期化解（清毒丹/打坐）
- 高阶丹药丹毒少，但不等于没有
```

### 4.2 核心丹药类型

```markdown
# 类型一：增进修为类（最核心）

## 炼气期
- 聚气丹：基础增进修为，炼气期适用
- 培元丹：巩固根基，减少修为不稳
- 凝气丹：突破瓶颈，炼气巅峰专用

## 筑基期
-筑基丹：突破筑基必备，极其珍贵
-培婴丹：巩固筑基，提升修炼速度
-凝婴丹：冲击筑基巅峰

## 结丹期
- 结金丹：突破结丹必备，一丹难求
- ...

## 设计要点
- 每个大境界至少3种丹药
- 境界越高，丹药越珍贵稀有
- 核心突破丹药要极其珍贵
```

```markdown
# 类型二：辅助战斗类

## 恢复类
- 回气丹：快速恢复灵力
- 疗伤丹：治疗伤势
- 醒神丹：解除精神类攻击

## 增益类
- 凝神丹：短时间内提升神识
- 爆发丹：短时间内提升战力（副作用大）
- 疾风丹：短时间内提升速度

## 设计要点
- 恢复类最常用
- 增益类必有副作用
- 战斗前要准备，但不要太多
```

```markdown
# 类型三：特殊功能类

- 破境丹：强行突破境界（副作用极大）
- 洗髓丹：改善灵根资质（极其珍贵）
- 护魂丹：保护神魂，防夺舍
- 隐息丹：隐藏修为气息

## 设计要点
- 特殊功能类不能破坏平衡
- 使用条件要苛刻
- 要有替代方案或代价
```

### 4.3 丹方模板

```markdown
# 示例：聚气丹丹方

## 名称：聚气丹
## 适用境界：炼气期
## 品阶：下品/中品/上品

## 原料

- 辅药：凝露花 × 2
- 辅药：黄精 × 3
- 药引：灵泉水 × 少许

## 炼制要点

- 所需火焰：普通灵火即可
- 炼制时间：约3个时辰
- 成功率：六成（熟练后可提高）

- 炼气1-3层：服用后提升修炼速度约30%

- 炼气7-9层：服用后提升修炼速度约10%

## 副作用
- 可能产生少量丹毒
- 连续服用效果递减
- 建议每服用10颗后休息数日

## 市场参考价
- 下品聚气丹：5块下品灵石
- 中品聚气丹：15块下品灵石
- 上品聚气丹：50块下品灵石
```

## 五、法宝体系设计

### 5.1 法宝品阶划分

```markdown
# 法宝品阶表

| 品阶 | 别称 | 威能 | 认主要求 | 稀有度 |
|------|------|------|----------|--------|
| 法器 | 法器 | 最低 | 无 | 常见 |
| 灵器 | 灵器 | 中等 | 筑基以上 | 较稀有 |
| 宝器 | 宝器 | 强 | 结丹以上 | 珍稀 |
| 通灵法宝 | 通灵 | 极强 | 元婴以上 | 罕见 |
| 古宝 | 古宝 | 不定 | 视情况 | 偶有发现 |
| 仙器 | 仙器 | 逆天 | 真仙以上 | 传说 |

# 威能设定
- 法器：比凡人武器强数倍
- 灵器：可承载灵力，威力大增
- 宝器：附加特殊威能，可成长
- 通灵法宝：已产生器灵/灵性
- 仙器：法则之力，凡人难以驾驭
```

### 5.2 法宝类型

```markdown
# 攻击类
- 飞剑类：最经典，御剑杀人
- 宝塔类：可攻可守
- 印玺类：以势压人
- 珠串类：范围攻击

# 防御类
- 盾牌类：硬抗攻击
- 护甲类：穿戴防护
- 钟罩类：范围防御
- 符箓类：一次性防御

# 辅助类
- 飞行类：提升速度
- 储物类：存放物品
- 探测类：探查敌情
- 隐匿类：隐藏气息

# 特殊类
- 阵法类：布阵困敌
- 傀儡类：操控作战
- 炼丹/炼器类：辅助炼制
```

### 5.3 法宝设定模板

```markdown
# 示例：青竹蜂云剑

## 基本信息
- 品阶：灵器（可进阶）
- 类型：飞剑
- 数量：一套十二柄
- 主材料：灵竹、青铜
- 炼制者：万剑一（失传）

## 外形
- 剑身细长如竹叶
- 通体青翠，隐有云纹
- 剑柄刻有"蜂云"二字
- 御使时如蜂群出云

## 威能
- 单剑：相当于普通灵器飞剑
- 成套：十二剑合璧，威能倍增
- 剑阵：可布"蜂云剑阵"，困敌杀敌

## 使用要求
- 最低境界：筑基期
- 灵力消耗：中等
- 御剑距离：与神识相关
- 配套功法："御剑术"（附赠）

## 特殊属性
- 套装加成：剑数越多，威能越强
- 可成长性：可不断温养提升
- 隐藏属性：集齐十二柄后另有玄机（伏笔）

## 来历
- 原为万剑宗镇宗之宝
- 万剑宗覆灭后流落民间
- 主角通过机缘获得
```
