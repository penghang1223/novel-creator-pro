# 凡人流技法详解

## 一、凡人流核心定义

凡人流是一种主角不依赖天赋奇遇、稳扎稳打成长的网文流派。忘语凭借《凡人修仙传》开创此流派，影响了此后十余年的仙侠网文创作。

### 核心公式
```
凡人流主角 = 平庸资质 + 机缘巧合 + 谨慎性格 + 坚持不懈 + 步步为营
```

---

## 二、主角设定技法

### 2.1 资质设计（核心中的核心）

**资质等级体系**：
| 资质类型 | 修炼速度 | 社会地位 | 典型代表 |
|----------|----------|----------|----------|
| 天灵根 | 100% | 天之骄子 | 各大宗门核心弟子 |
| 真灵根 | 60-80% | 天才弟子 | 内门精英 |
| 伪灵根 | 20-40% | 普通弟子/散修 | 凡人流主角 |
| 废灵根 | <10% | 底层散修 | 边缘角色 |

**凡人流主角资质模板**：
```markdown
# 模板1：伪灵根型（最经典）
- 四属性杂灵根或五属性伪灵根
- 修炼速度慢，同龄人筑基你还在炼气
- 宗门不重视，只能靠自己
- 代表：《凡人修仙传》韩立

# 模板2：被压制型
- 虽有灵根但被封印/压制/受损
- 表面废柴，实则有隐藏潜力
- 需要特殊条件解除限制
- 代表：《魔天记》柳鸣

# 模板3：后天改造型
- 开局灵根平庸
- 通过后天手段（丹药/功法/秘术）改造
- 改造过程艰难，代价巨大
- 代表：《玄界之门》石牧
```

### 2.2 性格设定

**必备性格特质**：
1. **谨慎内敛**：不见兔子不撒鹰，不确定安全绝不冒险
2. **心思缜密**：观察入微，善于发现细节和破绽
3. **坚韧不拔**：遭遇挫折不放弃，能屈能伸
4. **低调行事**：闷声发大财，绝不张扬

**性格塑造技巧**：
```markdown
# 通过决策体现谨慎
主角遇到机缘：
- 普通人：直接冲上去拿
- 天才流主角：研究一下再拿
- 凡人流主角：观察环境→确认无陷阱→确认无他人→确认能否带走→最后才拿

# 通过语言体现低调
- 天才流："区区筑基期，我挥手即灭！"
- 凡人流："在下只是路过，不想惹事。"
```

### 2.3 身世背景

**推荐出身类型**：
| 出身类型 | 优势 | 劣势 | 适用场景 |
|----------|------|------|----------|
| 偏远山村凡人 | 白纸一张，可塑性强 | 没有资源背景 | 经典开局 |
| 小门派弟子 | 有基础修炼知识 | 天赋不受重视 | 宗门流 |
| 破落家族子弟 | 有传承残篇 | 家族没落受欺 | 复仇流 |
| 底层散修 | 自由度最高 | 资源极度匮乏 | 流浪升级流 |

## 三、资源获取模式

### 3.1 核心原则

**凡人流资源观**：
1. **不取巧**：每一点资源都需要付出代价
2. **积少成多**：无数小资源积累成大资源
3. **取舍智慧**：知道什么该拿，什么不该拿
4. **长远规划**：为未来储备，不过度消耗当下

### 3.2 资源获取类型

```markdown
# 类型一：勤勉积累型（最凡人流）
- 日复一日打坐修炼
- 种植灵药、炼制丹药
- 猎杀低阶妖兽，一点一点攒
- 优点：稳，缺点：慢

# 类型二：机缘巧合型（适度）
- 偶尔捡到前辈遗物
- 误入秘境获得传承
- 关键：机缘不能太多太大
- 每次机缘都要付出代价

# 类型三：利益交换型
- 用自己的优势（炼丹/炼器/阵法）换取
- 建立人脉获得资源
- 关键：等价交换，童叟无欺

# 类型四：险中求富型
- 探索危险秘境
- 与妖兽搏命
- 关键：险是真实的险，不是装出来的
```

### 3.3 资源管理技巧

```markdown
# 资源分配公式
总资源 = 必要消耗（修炼）+ 储备（未来）+ 交易筹码（换取稀缺）

# 经典凡人流情节
1. 获得10颗聚气丹
2. 自己用3颗修炼（消耗6颗原料药）
3. 卖掉3颗换取灵石
4. 用灵石买自己缺的辅助材料
5. 剩下4颗作为储备

# 切忌
- 不要一口气全部用掉
- 不要看到好东西就买
- 不要为了面子浪费资源
```

## 四、越阶战斗逻辑

### 4.1 核心原则

**凡人流越战公式**：
```
越阶战胜 = 外物辅助（40%）+ 环境利用（20%）+ 战术智慧（30%）+ 运气成分（10%）
```

**绝对禁止**：
- 纯靠拳头硬碰硬打赢（那是天才流的玩法）
- 不付出任何代价就赢了
- 轻松碾压，越一个大境界如喝水

### 4.2 外物辅助体系

```markdown
# 法宝类
- 威力大但消耗灵力多
- 或有使用次数限制
- 或有后遗症（反噬、虚弱）
示例：一次性消耗品"天雷子"，可重创高阶敌人，但极其珍贵

# 符箓类
- 封印了法术的纸符
- 激发快，使用方便
- 数量有限，越用越少
示例：金刚符（防御）、困兽符（控制）、天火符（攻击）

# 阵法类
- 提前布置，可困敌可防御
- 需要材料和时间
- 对布阵者实力要求较低
示例：最基本的"两仪阵"困住比自己高一阶的敌人

# 丹药类
- 瞬间提升战力的丹药
- 必有副作用
- 或有使用次数限制
示例：燃灵丹（瞬间提升一层实力，但事后虚弱三天）
```

### 4.3 敌人轻敌战术

```markdown
# 经典情节模板
1. 主角炼气期vs筑基期敌人
2. 筑基期敌人轻视："区区炼气小辈，找死！"
3. 主角故意示弱，往预设战场退
4. 敌人追击，进入阵法范围
5. 符箓+法宝连发，打敌人措手不及
6. 趁敌人慌乱，祭出杀手锏
7. 成功重创/击杀敌人
8. 自己也付出代价：灵力耗尽、受伤、损失宝物

# 心理描写要点
- 敌人越轻视越好（但不能无脑降智）
- 主角内心的算计要清晰展现
- 战斗中的临场应变要有逻辑
```

### 4.4 战后处置

```markdown
# 战后必做事项
1. 检查敌人遗物（小心陷阱）
2. 处理尸体（防止被追踪）
3. 恢复状态（尽快离开危险区域）
4. 清点收获（评估值不值）
5. 复盘战斗（总结经验教训）

# 凡人流主角不会做的事
- ✗ 战后得意忘形，大声炫耀
- ✗ 不检查就收敌人的储物袋
- ✗ 原地休息不管周围环境
- ✗ 马上找人分享战利品
```

## 五、处世哲学

### 5.1 核心心法

**忘语风处世三则**：

```markdown
# 第一则：闷声发大财
- 得了好处不要到处说
- 低调低调再低调
- 永远留一手

# 第二则：好汉不吃眼前亏
- 打得过就打，打不过就跑
- 留得青山在，不怕没柴烧
- 面子不值钱，命才值钱

# 第三则：等价交换
- 不贪小便宜
- 也不让别人占自己便宜
- 交易讲究双赢
```

### 5.2 人际关系处理

```markdown
# 散修交往原则
- 以利益为核心
- 不交心，只交易
- 必要时可合作，但随时准备翻脸

# 宗门处世原则
- 低调做事，不出风头
- 与人为善，不轻易树敌
- 但被欺负也不退缩

# 师徒关系
- 师父对徒弟：传道授业，但也防着徒弟超越自己
- 徒弟对师父：尊重但有保留，有自己的小心思
```

### 5.3 危机应对

```markdown
# 危机分级与应对

# 等级一：能避则避
- 感觉到危险就绕路
- 不凑热闹，不看热闹

# 等级二：避无可避
- 冷静分析局势
- 寻找脱身机会
- 必要时牺牲部分利益保命

# 等级三：被迫应战
- 利用一切可利用的资源
- 设计陷阱/利用环境
- 做好最坏打算

# 等级四：死地求生
- 激发潜能，孤注一掷
- 或有隐藏底牌
- 或有外力介入
```

## 六、技法速查表

```markdown
# 主角设定速查
[ ] 资质是否平庸？ → 伪灵根/废灵根/被压制
[ ] 性格是否谨慎？ → 不冒进、不张扬、心思缜密
[ ] 出身是否底层？ → 凡人/小门派/没落家族
[ ] 有无隐藏机缘？ → 有，但需要代价才能用

# 资源获取速查
[ ] 是否通过努力积累？ → 慢慢攒，不一步登天
[ ] 每次获得是否付出代价？ → 必须等价交换
[ ] 是否留有储备？ → 永远不全用光
[ ] 是否低调处理？ → 闷声发大财

# 战斗设计速查
[ ] 是否借助外物？ → 法宝/符箓/阵法/丹药
[ ] 是否利用环境？ → 地形、天气、布置
[ ] 是否有敌人轻敌？ → 筑基vs炼气，敌人不能太聪明
[ ] 战后是否付出代价？ → 灵力耗尽/受伤/损失宝物
[ ] 战后是否谨慎处理？ → 检查、清点、离开

# 处世风格速查
[ ] 是否闷声发大财？ → 不炫耀、不张扬
[ ] 是否能屈能伸？ → 打得过就打，打不过就跑
[ ] 是否等价交换？ → 不贪便宜，也不吃亏
```
