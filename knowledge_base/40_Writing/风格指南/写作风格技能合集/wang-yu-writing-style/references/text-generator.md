# 文风文本生成器

## 一、开篇模板

### 1.1 经典凡人修仙传式开篇

```markdown
## 模板A：山村少年型

### 结构
[出身环境] → [发现异常] → [初步接触] → [转折契机]

### 示例
天南，越国，七玄门外山门。

一个身着粗布衣衫的少年，正蹲在灶台前，往火堆里添着枯枝。

少年名叫韩立，今年刚满十五岁，是七玄门下属村子里最不起眼的少年。没有灵根，没有背景，甚至连身材都比同龄人瘦小几分。

"韩立，别烧火了，快过来！"远处传来师兄的喊声。

韩立站起身，拍拍手上的灰，正要跑过去，忽然感觉怀里一沉。

他低头一看，不知何时，怀中多了一个巴掌大小的翠绿小瓶。

"这是……"

少年的命运，从这一刻开始转折。

---

### 模板要素解析
- 出身：越不起眼越好（建立同情）
- 环境：具体到地名宗门（建立真实感）
- 异常：某个契机打破平静（推动剧情）
- 转折：暗示后续发展（留下钩子）
```

```markdown
## 模板B：宗门底层型

### 结构
[宗门日常] → [遭遇轻视] → [意外发现] → [暗下决心]

### 示例
落云宗，外门杂役堂。

"又一个废物，都三个月了还在炼气一层徘徊。"

身后传来几声嗤笑，韩姓少年假装没听见，继续低头清扫着石阶上的落叶。

他叫韩厉，今年十六岁，三年前被测出四属性杂灵根后收入外门。三年来，眼看着同期入门的师兄弟一个个突破炼气三层、四层，而他却始终卡在第一层。

不是他不努力。

是灵根太差，宗门发放的聚气丹，效果对他来说微乎其微。

就在他弯腰捡起一片落叶时，指尖忽然触到冰凉坚硬的东西——

是一枚不知何时遗落在石缝中的古朴玉牌。

"这是……"

少年眼中闪过一丝异色。
```

```markdown
## 模板C：穿越者型（带凡人流改良）

### 结构
[穿越背景] → [异世处境] → [发现特殊] → [谨慎试探]

### 示例
张玄原本只是个普通的上班族，一觉醒来，发现自己躺在一间破旧的木屋中。

脑海中的记忆告诉他，这里是天南大陆，一个修仙者的世界。而他这具身体的原主人，是一个小门派的外门弟子，同样资质平庸，同样不受重视。

"穿越也就穿越了，怎么穿到这种开局？"张玄苦笑。

但他很快发现，这具身体虽然资质差，丹田却隐隐有些异常——似乎有一团微弱的绿光蛰伏其中。

张玄没有声张，只是若无其事地继续做着杂役任务，暗中观察试探。

谨慎，是他能活到今天的唯一本钱。
```

### 1.2 开篇速查表

```markdown
# 开篇必检项
[ ] 主角出身是否足够低？（建立同情基础）
[ ] 资质是否平庸？（符合凡人流）
[ ] 环境是否具体？（有真实感）
[ ] 是否有转折契机？（推动剧情）
[ ] 是否留下悬念？（吸引继续读）
[ ] 字数是否适中？（300-800字）

# 开篇避雷
✗ 开局就无敌
✗ 开局就有逆天天赋
✗ 开局就一大堆设定
✗ 开局就打架
✗ 主角性格过于张扬
```

## 二、场景描写模板

### 2.1 修炼场景

```markdown
## 模板：闭关修炼型

### 结构
[环境描写] → [入定状态] → [灵气运转] → [微妙变化] → [出关感受]

### 示例
破旧的山洞中，韩立盘膝坐在一块平整的青石上。

四周的禁制阵法是他亲手布置的，可以隔绝神识探查。洞内昏暗，只有几块下品灵石散发出微弱的荧光。

闭上双眼，韩立按照"无名功法"的路线，开始缓缓引导灵气入体。

一缕缕稀薄的灵气从灵石中被抽取出来，沿着经脉缓缓运转。每转一圈，都会有一丝杂质被提炼出来，化作黑气从毛孔中排出。

一个时辰……两个时辰……三个时辰……

不知过了多久，韩立睁开眼，眼中闪过一丝无奈。

三个时辰的修炼，又只增加了相当于呼吸一两下的灵力。若是拥有单属性灵根的天才，同样的时间怕是要比这多数十倍不止。

但他早已习惯了这种进度。

资质不够，就用时间来凑。

他从怀中取出一个粗布袋，里面是他这三个月积攒下来的聚气丹。

"还剩十二颗……够用一个月了。"

韩立喃喃自语，重新闭上眼睛。
```

```markdown
## 模板：突破关头型

### 结构
[准备充分] → [进入状态] → [遭遇瓶颈] → [艰难突破] → [尘埃落定]

### 示例
外门弟子居住的静室中，韩立正襟危坐。

桌上摆着三样东西：一枚泛着淡淡灵光的筑基丹，一瓶回气丹，以及一张记录着突破要点的符纸。

深吸一口气，韩立将筑基丹送入口中。

丹药入腹，瞬间化作一股滚烫的药力，如同一头蛮牛般冲向他堵塞的丹田入口。

痛！

韩立紧咬牙关，引导药力冲击那层看不见的屏障。

一下……两下……十下……

不知撞击了多少次，那层屏障终于出现了一丝裂痕。

"就是现在！"

韩立将早已含在口中的回气丹咬碎，大量灵气顺着打开的缺口涌入丹田——

轰！

仿佛有什么东西破碎了，又仿佛有什么东西重新建立。

当他再次睁开眼时，感觉整个世界都不一样了。灵气在体内的运转比以往顺畅了十倍，就连空气中的游离灵气都清晰可见。

"筑基……成功了。"
```

### 2.2 战斗场景

```markdown
## 模板：智取强敌型

### 结构
[敌我态势] → [示弱诱敌] → [引入陷阱] → [连番攻击] → [险胜代价]

### 示例
筑基初期的黑衣人冷冷看着面前的少年。

"炼气九层？也敢来趟这浑水？"

韩立面色苍白，脚步踉跄地后退几步，像是受了不轻的伤。他手中紧紧握着一张符箓，眼神中闪过一丝"惊恐"。

"前辈饶命，小的只是路过，绝无冒犯之意！"

黑衣人嗤笑一声，大步走来："路过？从你看到我杀人那一刻起，你就已经是死人了。"

就在他逼近到三丈之内时，韩立眼中的惊恐忽然消失。

取而代之的，是冰冷的算计。

"爆！"

随着他一声低喝，脚下泥土中埋藏的三张困兽符同时激发，一道黄光瞬间将黑衣人困在原地。

"什么？！"

黑衣人挥剑猛劈，却一时半刻挣脱不开。

而韩立早已祭出藏在袖中的天竹蜂云剑，十二道绿光齐齐刺向对方。

"你……"

黑衣人大骇，拼尽全力挡下十剑，却被剩下两剑刺穿了肩胛和腹部。

"你早就布好了陷阱！"他捂着伤口，满脸不可置信。

"前辈太过自信。"韩立淡淡道，又祭出一张天雷符，"在下只是碰巧发现此地适合布阵而已。"

轰！

一声巨响，黑衣人倒在血泊中。

而韩立自己也单膝跪地，脸色惨白——为了催动三张困兽符，他的灵力已经消耗了七八成。

"还好……赌对了。"

---

### 模板要素说明
- 敌强我弱：必须承认实力差距
- 示弱诱敌：利用敌人轻敌心理
- 陷阱准备：体现主角谨慎性格
- 连番攻击：法宝、符箓、阵法配合
- 险胜代价：灵力耗尽、受伤、损失宝物
```

```markdown
## 模板：追逐逃生型

### 结构
[危机降临] → [判断形势] → [选择路线] → [设置阻碍] → [险死还生]

### 示例
"站住！"

身后传来怒吼，三道遁光正以极快的速度追来。

韩立没有回头，只是将手中最后一张疾风符贴在腿上，脚下的速度又快了三分。

但他知道，这样下去迟早会被追上。

前方是一片茂密的竹林，韩立灵机一动，遁光一转，冲入竹林之中。

"想用地形拖延？做梦！"

身后追兵紧随而入。

就在他们穿过一片竹笋时，韩立忽然停下，双手掐诀。

"起！"

早在他进入竹林时就悄然埋下的困兽符阵瞬间激发，将三名追兵困在原地。

"又是阵法？！"

"符箓有限，这次困不了你们太久。"韩立冷笑一声，"但够我跑了。"

他没有选择继续逃遁，而是反其道而行之，直接遁入地下——他早就探测过，这片竹林下面有一条地下暗河。

噗通一声，韩立跳入暗河中，被水流卷向远方。

等他再次浮出水面时，已经在百里之外。

---

### 战斗描写技巧
1. **先承认差距**：炼气打筑基，实力就是差距
2. **展现智取**：不是硬拼，是智取
3. **消耗资源**：符箓、法宝、丹药都是消耗品
4. **展现代价**：战后必然虚弱
5. **不完美胜利**：可能还有后患
```

### 2.3 坊市场景

```markdown
## 模板：坊市淘宝型

### 结构
[坊市环境] → [摊位浏览] → [发现异常] → [讨价还价] → [暗中交易]

### 示例
落云坊市，纵横十余里的修仙者聚集地。

韩立压低斗笠，混在人群中缓缓前行。

街道两旁摆满了各种摊位，有卖灵药的，有卖符箓的，也有卖一些来路不明的"古物"的。

他没有急着出手，而是先逛了一圈，大致摸清了各种物品的行情。

作为散修，他最清楚——在坊市这种地方，不懂装懂和露富都是大忌。

"这位道友，要不要看看？"一个尖嘴猴腮的摊主招呼道。

韩立停下脚步，目光扫过摊位上的物品。

大多是些普通货色，正要离开时，一枚暗淡无光的玉简引起了他的注意。

"这个怎么卖？"

"哦，这个啊，五块下品灵石。"摊主漫不经心地说，"据说是从某个古修遗址里捡的，但里面什么都没有。"

韩立拿起玉简，神识探入——

确实是一枚废弃的玉简，内容早已被抹去。

但他注意到，玉简的材质并非普通货色，而是某种已经绝迹的上古灵玉。

这玩意儿，就是当废品卖也值五块灵石。

"三块。"韩立面无表情地还价。

"道友说笑了，这可是……"

"四块。"韩立打断他，转身就走。

"哎哎哎，成交成交！"

韩立嘴角微微上扬，将玉简收入怀中，继续往前走去。

闷声发大财，这才是散修的生存之道。
```

## 三、对话风格

### 3.1 不同身份对话特点

```markdown
# 散修对话（利益驱动型）
特点：直接、警惕、随时准备翻脸

"这株百年灵芝，多少灵石？"
"五百。"
"太贵了，四百。"
"低于四百不卖。"
"成交。"

核心：一切以利益为核心，没有废话

---

# 宗门弟子对话（身份意识型）
特点：注意身份、讲究分寸、暗藏机锋

"这位师弟是哪个峰的？"
"在下外门弟子，暂无峰归属。"
"哦？外门弟子能来藏经阁？"
"持任务令牌而来，还请师兄过目。"

核心：身份决定态度，对上恭敬对下傲慢

---

# 师徒对话（传承保护型）
特点：表面严厉，实则关怀；传道授业，但也防着

"师父，弟子想学这门秘术。"
"这门秘术要求极高，你现在还不行。"
"可是……"
"可是什么？没有筑基就想要秘术？回去修炼！"
（实则：这秘术太危险，他还没到学的时候）

核心：师父话里有话，徒弟心里有数

---

# 高阶修士对话（高高在上型）
特点：惜字如金，不屑解释，实力碾压

"你是何人？"
"晚辈……"
"蝼蚁之辈，不值一问。滚。"
"是是是……"

核心：境界决定话语权
```

### 3.2 对话模板库

```markdown
# 经典凡人流对话模式

## 试探性对话
"道友面生得很，不知是哪里人士？"（打听来历）
"在下不过是一介散修，四处游历罢了。"（不透露底细）
"散修？那可辛苦，不像我们宗门弟子，资源都有宗门供给。"（试探背景）
"各有各的难处。"（不卑不亢）

## 交易对话
"道友这件法器，看着品相不错，多少出手？"（先问价）
"这件灵器乃是在下本命之物，不卖。"（先拒绝试探）
"哦？那若是在下拿筑基丹来换呢？"（加码试探）
"这……道友稍等，容在下考虑考虑。"（动摇）

## 威胁对话
"你最好识相点，把东西交出来。"
"阁下是谁？可知杀人夺宝的后果？"
"后果？这里是荒郊野外，谁知道是我干的？"
"……阁下想要什么，在下交出便是。"（能屈能伸）

## 告别对话
"今日与道友交易愉快，后会有期。"
"后会有期。对了，道友最好小心些，那东西……算了，多说无益。"
"道友此话何意？"
"没什么，在下言尽于此。"（留下悬念）
```

## 四、情绪描写

### 4.1 紧张情绪

```markdown
# 危机来临型

韩立感觉后背一凉。

神识中，那个原本在十余里外的身影，正在飞速接近。

不好！

他没有犹豫，直接从储物袋中取出一张疾风符贴在腿上，同时祭出飞剑。

"想跑？"

冰冷的声音从身后传来。

韩立没有回头，只是将遁光催动到极致。

他很清楚，筑基对炼气而言，就是碾压。就算他拼尽全力，也只能争取一线生机。

"若是能逃到那处阵法中……"

前方三里处，是他早先布置的一处困阵。若能进入阵中，或许还有一线机会。

但对方的速度明显比他更快。

一里……半里……

韩立咬紧牙关，额头上渗出冷汗。

距离阵法入口还有百丈！

"留下吧！"

身后传来一声冷哼，一道剑光直刺他后心。

---

技巧要点：
- 危机感要层层递进
- 主角心理描写要真实
- 行动决策要合理
- 给出一线希望
```

### 4.2 压抑情绪

```markdown
# 资质自卑型

韩立站在人群最后面，看着前方那些意气风发的师兄弟们领取宗门发放的筑基丹。

三年了。

同期入门的弟子，如今已经有七成突破筑基，剩下的也都在冲击的最后阶段。

而他，依然是炼气三层。

"韩师弟，别灰心，大道漫漫，筑基只是起点而已。"一个师兄拍拍他的肩膀安慰道。

"多谢师兄。"韩立挤出一个笑容。

他知道对方是好意。

但他也知道，灵根资质这东西，就是修仙路上最大的鸿沟。

他四属性杂灵根，修炼速度比单灵根慢上百倍。就算有足够的丹药支撑，突破筑基的概率也不足一成。

"一成就一成。"韩立握紧拳头，"别人用一年，我就用十年。十年不够，我就用一百年。"

资质不够，就用时间来凑。

这是他唯一的选择。
```

### 4.3 情绪转换

```markdown
# 从压抑到爆发型

压抑：
韩立一言不发地走出坊市，斗笠压得很低。

他知道那摊主在坑他，但他没有证据。而且就算有证据，散修告宗门弟子，谁会信？

这种事他见得太多了。

爆发：
"站住！"

忽然，一个身影拦在他面前。

"刚才那个玉简，我出双倍价钱，你卖不卖？"

韩立抬起头，发现是坊市中的一个地头蛇，专门做低价收、高价卖的勾当。

"不卖。"他平静地说。

"别敬酒不吃吃罚酒。"

"我说不卖，就是不卖。"韩立依然平静，但语气中多了几分锋芒。

"小子，你知道我是谁吗？"

"不知道，也不想知道。"韩立绕过对方，"我只是个散修，没什么可失去的。你若想动手，我接着便是。"

对方愣了一下，似乎没想到一个炼气期的散修敢这么硬气。

"算你狠。"他冷哼一声，转身离开。

---

技巧要点：
- 压抑要有具体原因
- 爆发要有触发点
- 但爆发也要有底线（不是无脑爽）
```

## 五、综合生成模板

### 5.1 完整章节生成流程

```markdown
# 章节生成五步法

## 第一步：确定章节目标
- 本章要推进什么？（境界提升/获得宝物/结识人物/解决危机）
- 本章处于整体结构的哪个位置？（开局/中段/高潮前）
- 本章字数要求？（2000-4000字）

## 第二步：设计情节单元
- 核心事件是什么？（一件具体的事）
- 配角有哪些？（1-2个即可）
- 冲突点在哪？（争夺/误会/利益）

## 第三步：确定场景类型
- 修炼场景（闭关/突破/服药）
- 战斗场景（追杀/被追杀/比试）
- 社交场景（交易/结交/打探）
- 冒险场景（探索/寻宝/历练）

## 第四步：填充描写模板
- 开篇环境描写（1-2段）
- 中间情节推进（对话+动作+心理）
- 结尾留下钩子（新危机/新机遇/新人物）

## 第五步：检查凡人流特征
- 主角资质是否体现？（资质差，要慢慢来）
- 资源获取是否困难？（要付出代价）
- 行事风格是否谨慎？（不冒进，不张扬）
- 战后是否留有代价？（不完美胜利）
```
