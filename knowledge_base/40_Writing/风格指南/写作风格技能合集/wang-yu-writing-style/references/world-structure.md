# 世界观结构详解

## 一、世界架构设计

### 核心原则
1. **层次分明**：下界→中界→上界的递进关系
2. **空间隔离**：各界之间有明确屏障，非轻易可越
3. **资源差异**：境界越高，资源越丰富/危险
4. **势力分布**：各方势力均衡，无绝对霸主

---

## 二、三界架构

### 2.1 人界篇

```markdown
# 人界设定

## 基础信息
- 等级：下界
- 灵气浓度：稀薄
- 最高境界：化神期（巅峰不可存进）
- 特点：凡人与修士共存，宗门林立

## 地理结构
- 陆地（主体）：约占三成
  - 中原地带：宗门最多，实力最强
  - 北域冰原：苦寒之地，散修聚集
  - 南疆十万大山：妖兽乐园
  - 西域荒漠：资源匮乏，人迹罕至
  - 东海群岛：海外修士势力
- 海洋（主体）：约占七成
  - 浅海：低阶妖兽活动区
  - 深海：中高阶妖兽领域，人类禁地
  - 海底秘境：偶尔出世
- 秘境/遗迹
  - 上古遗迹：蕴含古修传承
  - 空间裂缝：随机出现，风险机遇并存
  - 界中界：独立空间，需特殊条件进入

## 势力分布
- 顶级势力（化神坐镇）
  - 超级宗门：3-5个，掌控大片资源
  - 大型宗门：10-20个，一方霸主
- 中层势力（元婴/结丹）
  - 中型宗门：百来个，割据一方
  - 大家族：依附宗门或有独立地盘
- 底层势力
  - 小门派：散落于各地
  - 散修联盟：松散组织
  - 坊市势力：商业联盟

## 飞升条件
- 境界：必须达到化神后期大圆满
- 条件：渡过小天劫/触发飞升之光
- 代价：大部分人飞升失败，魂飞魄散
- 结果：成功者飞升灵界
```

### 2.2 灵界篇

```markdown
# 灵界设定

## 基础信息
- 等级：中界
- 灵气浓度：浓郁
- 最高境界：大乘期
- 特点：各族林立，仙人后裔众多

## 地理结构
- 灵域：灵气最浓郁之地，大势力占据
- 圣山：传说中的修炼圣地
- 万灵海：各族混居之地
- 蛮荒古地：上古凶兽盘踞
- 飞升者聚集区：人界飞升者落脚之地

## 主要种族
- 人族：最大种族，繁衍能力强
- 妖族：妖兽开智化形
- 灵族：天地灵气凝聚而生
- 冥族：幽冥之地生灵
- 圣族：上古仙人后裔，血脉强大

## 势力格局
- 圣殿级势力：大乘期坐镇
- 王朝级势力：合体期统治
- 宗门级势力：炼虚期为核心
- 种族联盟：共同对抗外族
```

### 2.3 仙界篇

```markdown
# 仙界设定

## 基础信息
- 等级：上界
- 灵气浓度：混沌灵气
- 最高境界：道祖/仙帝级
- 特点：法则显化，寿元无尽

## 特殊设定
- 真仙满地走，大罗多如狗
- 法则感悟决定地位
- 仙脉、仙药遍布
- 仙魔大战遗留下来的古战场
```

### 2.4 跨界设定

```markdown
# 飞升机制
- 人界→灵界：化神后期渡劫飞升
- 灵界→仙界：大乘期渡真仙劫飞升
- 飞升限制：境界不够无法强渡
- 飞升代价：虚弱期/随机传送/记忆模糊

# 下界设定
- 人界→下界（下下界）：封印记忆/实力
- 偶尔有真仙下凡，但代价极大
- 上界对下界有干涉限制
```

## 三、势力设计

### 3.1 宗门势力设计

```markdown
# 宗门层级结构

## 顶级宗门（化神坐镇）
- 规模：弟子过万
- 地盘：占据灵脉
- 底蕴：上古传承
- 标志：护宗大阵
- 行事：超然物外，轻易不干涉世俗

## 大型宗门（元婴坐镇）
- 规模：弟子数千
- 地盘：中型灵脉
- 传承：完整功法体系
- 资源：可炼制元婴丹等高阶丹药

## 中型宗门（结丹坐镇）
- 规模：弟子数百
- 传承：有所残缺
- 目标：培养核心弟子突破
- 竞争：区域内相互竞争

## 小型宗门/家族
- 规模：弟子数十
- 传承：单一功法
- 生存：依附大势力或偏安一隅
```

```markdown
- 依附：弱者依附强者生存
```

### 3.3 势力冲突类型

```markdown
# 利益冲突
- 灵脉争夺：谁占谁修炼快
- 秘境归属：上古遗迹谁有资格进
- 弟子争夺：好苗子被别宗抢走
- 坊市控制：商业利益分配

# 理念冲突
- 正邪之争：正道vs魔道（但不要太脸谱化）
- 种族矛盾：人族vs妖族
- 飞升派vs留守派：要不要冒险飞升

# 历史恩怨
- 宗门仇杀：某代弟子结仇，延续至今
- 灭门之仇：曾经的灭门惨案
- 传承争夺：某上古传承引发血战
```

## 四、地图设计

### 4.1 地图展开原则

```markdown
# 渐进展开法
1. 先展示主角活动区域（10-50里范围）
2. 随着实力提升，逐渐扩展（百里→千里→万里）
3. 化神期后接触整个大陆
4. 飞升后进入灵界，开启新地图
5. 仙界同理

# 地图信息分层
- 已知区域：主角去过的、探索过的
- 传闻区域：听说过的，信息不完全
- 未知区域：没去过，不知道有什么
- 禁地区域：实力不够不能去
```

```markdown
- 迷雾谷：危险区域，有妖兽盘踞

- 筑基期：可进迷雾谷，可参与拍卖
- 结丹期：可争夺遗迹，可开宗立派
```

### 4.3 秘境设计

```markdown
# 秘境类型

## 天然秘境
- 形成原因：天地自然演化
- 特点：规模不等，资源有限
- 进入条件：空间裂缝/特殊时间/钥匙

## 上古遗迹
- 形成原因：上古大能遗留
- 特点：可能有传承，危险与机遇并存
- 进入条件：通常需要钥匙或特殊条件
- 典型内容：功法、法宝、丹药、阵法

## 宗门秘境
- 形成原因：宗门前辈开辟
- 特点：有考验，有传承
- 进入条件：宗门弟子/特定身份
- 典型内容：试炼、传承、资源储备

## 秘境设计模板
# 秘境名：虚天殿

## 基础信息
- 类型：上古遗迹
- 位置：漂浮空间，不固定
- 开启时间：每百年开启一次
- 开启条件：持有虚天令

## 内部结构
- 外层（炼气-筑基）：灵药园、妖兽区
- 中层（筑基-结丹）：功法阁、炼器室
- 内层（结丹-元婴）：传承殿、藏宝阁
- 核心（元婴以上）：虚天丹房

## 危险等级
- 危险来源：上古禁制、残留妖兽、争夺者
- 危险程度：与区域对应境界相符
- 生存要点：不可贪心，适可而止

## 收益预估
- 低阶区：聚气丹、法器、基础功法
- 中阶区：筑基丹、灵器、中阶功法
- 高阶区：结金丹、灵器、古宝
- 核心区：虚天丹（突破瓶颈圣药）
```

## 五、资源分布

### 5.1 核心资源类型

```markdown
# 灵脉资源
- 灵脉等级：微型→小型→中型→大型→巨型
- 作用：提升灵气浓度，加速修炼
- 争夺原因：谁占谁修炼快

# 灵药资源
- 等级：凡品→灵品→仙品
- 用途：炼丹、直接服用
- 采集：野外/人工种植

# 矿石资源
- 等级：凡矿→灵矿→仙矿
- 用途：炼器、布阵
- 典型：精铁矿、灵铜矿、天晶矿

# 妖兽资源
- 价值：妖丹、皮毛、骨血
- 猎取：野外/养殖场
- 危险：越强越危险

# 特殊资源
- 传承：功法、秘术
- 秘宝：古宝、残器
- 材料：珍稀炼器/炼丹材料
```

### 5.2 资源分布规则

```markdown
# 核心规则
1. 资源分布与灵气浓度正相关
2. 高阶资源必然伴随高阶危险
3. 核心资源被大势力占据
4. 散修只能获取边角料
5. 秘境是打破格局的机会

# 典型分配
- 顶级灵脉：顶级宗门占据
- 中级灵脉：大型宗门占据
- 低级灵脉：小型宗门/家族占据
- 无灵脉区域：散修活动区
- 危险秘境：中大型势力开发
- 普通秘境：散修冒险区
```

## 六、综合设计速查

```markdown
# 世界观速查表

## 架构设计
[ ] 三界设定是否清晰？（人界→灵界→仙界）
[ ] 各界灵气浓度/最高境界是否明确？
[ ] 跨界机制（飞升/下凡）是否合理？

## 势力设计
[ ] 势力层级是否分明？（顶级→中层→底层）
[ ] 各势力实力是否均衡？（不一家独大）
[ ] 势力关系是否复杂？（非单纯正邪）
[ ] 势力冲突是否有根由？（利益/理念/历史）

## 地图设计
[ ] 地图是否渐进展开？（随实力提升）
[ ] 地理特征是否多样？（山/海/平原/荒漠）
[ ] 关键地点是否有意义？（灵药园/遗迹/坊市）
[ ] 地图信息是否分层？（已知/传闻/未知）

## 资源设计
[ ] 资源类型是否多样？（灵脉/灵药/矿石/妖兽）
[ ] 资源与势力是否挂钩？（强占好资源）
[ ] 资源获取是否有门槛？（实力不够别想）
[ ] 是否有打破格局的机遇？（秘境/遗迹）

## 细节填充
[ ] 各势力是否有独特文化/规矩？
[ ] 是否有贸易/坊市体系？
[ ] 是否有情报/悬赏系统？
[ ] 是否有善恶/名声机制？
```
