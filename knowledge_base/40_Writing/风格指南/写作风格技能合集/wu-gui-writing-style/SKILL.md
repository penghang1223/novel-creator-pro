# 爱潜水的乌贼写作风格技能

> 硬核规则流 × 悬疑智斗 × 群像封神 × 克苏鲁蒸汽朋克

## 技能概述

本技能旨在模拟**爱潜水的乌贼**的写作风格，核心代表作为《诡秘之主》《一世之尊》《奥术神座》《长夜余火》。乌贼风格以**硬核规则流**著称：逻辑自洽、细节严谨、设定与剧情严丝合缝，形成完美的叙事闭环。

### 核心风格定位

| 维度 | 特征 | 典型体现 |
|------|------|----------|
| **规则体系** | 硬核严谨、逻辑闭环 | 22条神之途径、魔药体系、扮演法 |
| **叙事基调** | 克苏鲁质感、诡异神秘 | 绝望中寻找希望，克制而有张力 |
| **世界观** | 蒸汽朋克、维多利亚风 | 《诡秘》贝克兰德、《奥术》浮空城 |
| **人物塑造** | 群像封神、无工具人 | 塔罗会全员崛起，各有成长弧光 |
| **剧情设计** | 智斗悬疑、抽丝剥茧 | 伏笔遍布、草蛇灰线、终局大回收 |
| **人文内核** | 底层关怀、人性光辉 | 对小人物的悲悯，对正义的坚守 |

## 核心技法体系

### 1. 硬核规则设计（world-rules.md）

**核心理念**："设定即法律，漏洞即罪过"

乌贼的规则体系是网文界的天花板，每一个设定都有完整的逻辑支撑：
- **可量化**：非凡特性守恒定律、魔药消化机制
- **可推演**：从基础规则可推导出无数应用场景
- **有代价**：每个能力都有明确限制，避免无限叠加
- **自洽性**：规则之间相互印证，形成严密闭环

### 2. 魔药/能力体系设计（magic-system.md）

**核心理念**："能力即枷锁，选择即代价"

以《诡秘》为代表的魔药体系：
- **途径唯一性**：同途径晋升不可共存（黑皇帝例外）
- **扮演法机制**：消化魔药需要扮演对应角色
- **失控风险**：急于求成会导致精神污染
- **非凡特性守恒**：总量恒定，新旧更替有代价

### 3. 悬疑智斗技法（mystery-suspense.md）

**核心理念**："伏笔是给读者的礼物，解谜是给读者的奖赏"

乌贼的悬疑设计哲学：
- **信息不对称**：读者与主角共享视角，谨慎获取信息
- **误导与真相**：每个谜题都有合乎逻辑的误导
- **终局回收**：前期细节在关键时刻爆发
- **克制呈现**：不故弄玄虚，信息密度恰到好处

### 4. 群像塑造技法（group-portrait.md）

**核心理念**："没有工具人，只有活生生的人"

塔罗会群像的成功密码：
- **独立动机**：每个角色都有自己的人生目标
- **成长弧光**：从配角到主角的蜕变轨迹
- **能力互补**：不同角色的能力解决不同问题
- **情感羁绊**：成员间的情感纽带真实可信

### 5. 文风文本生成器（text-generator.md）

**核心理念**："严谨缜密，克制有张力"

乌贼的文风特征：
- **西式叙事**：贴合维多利亚/欧式背景
- **细节密度**：环境、服饰、心理描写精准
- **克苏鲁氛围**：诡异感渗透字里行间
- **情绪克制**：高潮时反而更加冷静

## 使用指南

### 适用场景

| 场景 | 适用指数 | 说明 |
|------|----------|------|
| 玄幻/奇幻世界观构建 | ★★★★★ | 硬核规则设计的最佳舞台 |
| 悬疑/智斗小说创作 | ★★★★★ | 伏笔系统是乌贼的核心竞争力 |
| 群像小说写作 | ★★★★☆ | 多视角叙事需要强大架构能力 |
| 蒸汽朋克/克苏鲁题材 | ★★★★★ | 氛围营造是乌贼的强项 |
| 都市异能/超能力战斗 | ★★★★☆ | 能力体系设计可借鉴魔药模型 |

### 不适用场景

- 快餐式无脑爽文（乌贼风格克制，爽感延迟）
- 龙傲天/无敌流（乌贼主角都有成长过程）
- 纯言情/甜宠文（感情戏非核心卖点）
- 短篇创作（乌贼是长篇大师）

### 调用方式

本技能提供以下子模块：

```
references/
├── world-rules.md      # 硬核规则设计技法（核心必读）
├── magic-system.md     # 魔药/能力体系设计
├── mystery-suspense.md # 悬疑智斗技法
├── group-portrait.md   # 群像塑造技法
└── text-generator.md   # 文风文本生成器
```

**建议阅读顺序**：
1. 首先通读 `world-rules.md`（规则设计是根基）
2. 然后根据需要深入 `magic-system.md` 或 `mystery-suspense.md`
3. `group-portrait.md` 和 `text-generator.md` 作为辅助参考

## 典型作品分析

### 《诡秘之主》—— 硬核规则流的巅峰

**世界观架构**：
- 22条神之途径，220种职业序列
- 每条途径9个序列，能力递进清晰
- 唯一性、旧日、古神等高阶设定

**悬疑设计**：
- 主线谜题：灰雾之上的主宰是谁？
- 单元谜题：每个副本都是独立推理故事
- 细节伏笔：第一章就有全书线索

**群像成功**：
- 塔罗会：正义、倒吊人、世界、星星、月亮...
- 配角高光：阿兹克、邓恩、莎伦...

### 《一世之尊》—— 东方武侠与无限流融合

**规则创新**：
- 命运之力，因果网络
- 彼岸设定，时间线收束

**叙事结构**：
- 单元副本与主线交织
- 主角成长与宇宙真相同步揭开

### 《奥术神座》—— 科学与魔法碰撞

**设定亮点**：
- 魔法即是公式，解读即是力量
- 半疯设定，知识诅咒

**叙事创新**：
- 以"论文"形式展示能力成长
- 科学史融入魔法史

## 创作检查清单

使用乌贼风格创作时，请对照以下检查点：

### 规则设计检查
- [ ] 每条规则是否有明确的边界和限制？
- [ ] 规则之间是否自洽？能否相互推导？
- [ ] 能力代价是否明确？是否存在无代价能力？
- [ ] 是否有信息不对称的盲区设计？

### 悬疑设计检查
- [ ] 每个谜题是否都有合乎逻辑的误导？
- [ ] 伏笔是否在埋下后适当距离才回收？
- [ ] 解谜过程是否有足够的推理快感？
- [ ] 读者是否能基于已有信息做出猜测？

### 群像设计检查
- [ ] 每个重要角色是否有独立动机？
- [ ] 配角的高光时刻是否独立于主角？
- [ ] 角色之间是否有真实的情感联结？
- [ ] 是否避免了工具人陷阱？

### 文风检查
- [ ] 是否贴合世界观背景（西式/中式）？
- [ ] 氛围营造是否统一（克苏鲁/仙侠/科幻）？
- [ ] 情绪表达是否克制而有张力？
- [ ] 细节描写是否精准且有意义？
