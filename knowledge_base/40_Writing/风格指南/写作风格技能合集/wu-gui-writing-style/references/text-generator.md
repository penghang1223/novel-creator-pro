# 文风文本生成器

> "严谨缜密，克制有张力" —— 乌贼文风核心特征

## 概述

乌贼的文风在网文界独树一帜，其特点是**西式叙事贴合背景、细节密度精准、克苏鲁氛围渗透、情绪表达克制而有张力**。与许多网文的"直白爽快"不同，乌贼的文字更有"质感"，让读者在字里行间感受到作者的世界观和美学追求。

## 核心文风特征

### 1. 西式叙事风格

**核心理念**：叙事风格必须贴合世界观背景。

**乌贼实践**（《诡秘之主》）：
```
维多利亚时代特征：
- 称呼：绅士、小姐、夫人、阁下
- 用词：礼貌、正式、有时代感
- 句式：偏欧式长句，从句嵌套
- 礼仪：注重社交礼仪
- 服饰：详细描述（燕尾服、蕾丝、手套等）

语言示例：
"克莱恩·莫雷蒂先生，不知您对这次事件有何看法？"
（而非："克莱恩，你觉得这事儿咋样？"）

对话示例：
"尊敬的班森先生，我代表皇家学会向您致以最诚挚的歉意，
并承诺将在三日内完成对这件法器的全面检测。"
```

**西式叙事模板**：
```
人物出场描写：
[外貌] + [服饰细节] + [时代特征动作] + [社交礼仪]

示例：
一位身穿深蓝色燕尾服的中年绅士快步走来，
他戴着考究的单片眼镜，手中轻摇着一柄银质手杖，
向周围的路人微微颔首致意，
步伐优雅而从容，
彰显出上流社会的教养与身份。

对话描写：
[正式称呼] + [礼貌用语] + [委婉表达] + [含蓄情感]

示例：
"尊敬的莎伦小姐，" 克莱恩站起身，微微躬身，
"对于您的慷慨相助，我心中充满了感激。
不知我是否能在将来某个合适的时刻，
为您做些什么以表谢意？"
```

### 2. 细节密度控制

**核心理念**：精准而丰富的细节，不冗余但有意义。

**乌贼实践**：
```
细节类型：
1. 环境细节：营造氛围，暗示信息
2. 服饰细节：反映身份、状态、时代特征
3. 行为细节：揭示性格、心理
4. 物品细节：推动剧情，埋伏笔
5. 声音细节：增强真实感

细节密度控制：
- 重要场景：高密度（2-3句/段）
- 过渡场景：中密度（1-2句/段）
- 快节奏场景：低密度（0-1句/段）
```

**细节描写模板**：
```
环境细节：
[整体氛围] + [具体元素A] + [具体元素B] + [感官感受]

示例：
清晨的贝克兰德笼罩在一层薄薄的灰雾中，
煤烟的味道与海风的咸腥交织在空气里，
远处的工厂烟囱冒着黑烟，
整座城市仍在沉睡中，
等待着新一天的开始。

服饰细节：
[整体风格] + [具体材质] + [颜色搭配] + [细节装饰] + [功能/象征]

示例：
奥黛丽穿着一件淡粉色的蕾丝长裙，
裙摆蓬松，边缘绣着精美的银线花纹，
手腕上戴着一串珍珠手链，
脖子上挂着祖母留下的吊坠，
整个人看起来既优雅又活泼，
完美契合了上流社会年轻淑女的形象。

行为细节：
[具体动作] + [动作方式] + [伴随表情/生理反应]

示例：
克莱恩将塔罗牌一张张摆在桌上，
动作轻柔而慎重，
每一张牌都放得整整齐齐，
他的手指微微颤抖，
呼吸也放得很慢，
仿佛在进行某种神圣的仪式。
```

### 3. 克苏鲁氛围营造

**核心理念**：诡异感渗透在字里行间，而非直接描写恐怖。

**乌贼实践**：
```
氛围营造手法：
1. 间接描写：不直接写恐怖，而是写环境/他人的反应
2. 感官描写：侧重听觉、嗅觉、触觉，而非视觉
3. 留白：留给读者想象空间
4. 反差：用日常的异常暗示恐怖
5. 累积：小异常逐渐累积，形成压迫感

氛围递进：
Level 1：轻微异常（环境不对劲）
Level 2：中度的恐惧（他人异常反应）
Level 3：深层的压抑（直接接触诡异存在）
```

**克苏鲁氛围模板**：
```
Level 1 轻微异常：
[正常环境] + [微小但明显的异常] + [主角的困惑]

示例：
克莱恩走进小巷，
路灯昏暗，墙壁上长满青苔，
一切看起来都很正常，
但他隐约听到，
在巷子的深处，
传来了某种类似呢喃的声音，
像是有人在低语，
又像是风在呼啸，
分辨不清。

Level 2 中度恐惧：
[异常环境] + [他人的异常反应] + [主角的警惕]

示例：
街道上空无一人，
所有的店铺都关着门，
窗帘紧闭，
仿佛整条街都在害怕什么。

克莱恩看到一位妇人，
正趴在自家窗户上向外张望，
她的脸色苍白，
眼神中充满了恐惧，
当看到克莱恩时，
她迅速缩回屋内，
"砰"地一声关上了窗户。

Level 3 深层压抑：
[直接接触诡异] + [感官体验] + [心理影响]

示例：
那东西就在眼前，
克莱恩看不清它的具体形态，
只能感受到，
某种庞大而古老的存在，
正悬浮在虚空中。

他的皮肤感到刺痛，
像是被无数细小的针刺着，
脑海中出现了混乱的呓语，
心脏剧烈跳动，
本能地想要逃离，
但他知道，
已经太晚了。
```

### 4. 情绪克制的张力

**核心理念**：最激烈的情绪，用最克制的文字表达。

**乌贼实践**：
```
情绪克制技巧：
1. 动作代替直接描写：用身体动作表现情绪
2. 环境烘托：用环境变化暗示情绪
3. 对比反差：平静的表象下，内心波澜
4. 节奏控制：情绪爆发时反而放慢节奏
5. 细节聚焦：聚焦某个细节，忽略其他

情绪类型与克制方式：
- 愤怒：不说"愤怒"，而写"握紧拳头，指节泛白"
- 恐惧：不说"害怕"，而写"心跳加速，呼吸困难"
- 悲伤：不说"痛苦"，而写"声音低沉，眼神空洞"
- 激动：不说"激动"，而写"身体微微颤抖，呼吸急促"
```

**情绪克制模板**：
```
情绪克制 - 愤怒：
[平静的外表] + [微小的身体反应] + [压抑的内心]

示例：
克莱恩坐在椅子上，
身体挺得笔直，
双手放在膝盖上，
一动不动。

"我知道了。"

他说道，声音平稳，

但他的右手食指，
正紧紧扣住桌沿，
指节已经泛白。

愤怒在胸腔中燃烧，
但他不能表现出来，
至少现在不能。

情绪克制 - 悲伤：
[日常的动作] + [轻微的异常] + [深层的痛苦]

示例：
克莱恩站起身，
走到窗前，
拉开窗帘，
看着外面的街道。

"她走了。"

他轻声说道，

眼神却没有焦距，
仿佛穿透了墙壁，
看向某个遥远的地方。

窗外的阳光正好，
照在他的脸上，
但他感觉不到温暖。
```

## 场景描写范例

### 场景1：战斗场面

**乌贼式战斗描写特征**：
```
- 侧重智斗而非单纯的武力比拼
- 侧重策略而非招式
- 侧重后果而非过程
- 克制渲染，不过度热血
```

**范例**：
```
克莱恩看着面前的敌人，
脑中迅速分析着局势。

对方是一名序列7的魔术师，
擅长火焰和幻术，
正面硬拼的话，
自己几乎没有胜算。

必须智取。

他左手一挥，
几张纸牌飞出，
在空中排成一个图案。

"魔术。"

对方轻笑一声，
抬手一指，
火焰瞬间吞噬了纸牌。

"这就是你的手段？"

就在这时，
克莱恩的身影消失在原地。

下一秒，
一把匕首出现在对方背后，
直指后心。

魔术师的幻术范围有限，
克莱恩早已计算好了，
在对方施展火焰魔法时，
利用短暂的视觉死角，
完成侧身绕后。

"不！"

对方惊呼，
想要转身，
但匕首已经刺入。

鲜血喷涌，
对方倒在地上，
眼神中仍带着惊愕。

他没想到，
被当作"弱者"的占卜家，
竟然如此果断狠辣。
```

### 场景2：悬疑场景

**范例**：
```
房间内一片黑暗，
只有月光从窗户照进来，
在地板上投下细长的影子。

克莱恩站在门前，
深吸一口气，
推开了门。

"吱呀——"

门轴发出刺耳的声音。

房间里没有人，
但桌子上的东西变了。

原来放着的文件不见了，
取而代之的，
是一张黑色的塔罗牌。

"死神"。

克莱恩走到桌前，
拿起那张牌。

这不是普通的塔罗牌，
卡片上散发着一股冰冷的气息，
像是刚从冰窖里拿出来一样。

这是什么意思？
警告？
威胁？
还是...

克莱恩将牌收好，
环视房间。

其他地方没有异常，
只有这张牌，

一个信号。

有人在监视自己。

而且，
对方很强。
```

### 场景3：情感场景

**范例**：
```
奥黛丽站在窗前，
看着贝克兰德的夜景。

远处，
工厂的烟囱冒着黑烟，
工人们在夜幕下忙碌，
为了生活而挣扎。

"这个世界..."
她轻声自语，

"真的很不公平。"

她转身，
看着镜子里的自己。

穿着华丽的裙子，
戴着精致的饰品，
住在舒适的房子里。

而那些工人，
那些穷人，
却连最基本的温饱都无法保证。

"我能做什么呢？"

奥黛丽问自己。

她只是一个普通的大小姐，
没有特殊能力，
没有强大势力。

但她能感受到，
内心深处的那种冲动，
那种想要改变什么的冲动。

或许，
从小事开始。

或许，
从身边的人开始。

她深吸一口气，
眼神逐渐坚定。

"至少，
我可以尝试。"
```

## 文风模仿技巧

### 技巧1：句式结构

**欧式句式特征**：
```
- 长句为主，从句嵌套
- 逻辑严密，层次清晰
- 状语从句频繁使用
- 定语从句修饰名词

示例：
克莱恩，作为一个刚来到这个世界的外来者，
对这里的一切都充满了好奇，
尤其是那些神秘的，
充满未知的事物。

而当他第一次接触到魔药时，
那种震撼，
至今仍深深印在他的脑海中。
```

### 技巧2：用词选择

**正式/时代感用词**：
```
避免：太、很、特别
使用：相当、颇为、尤为

避免：觉得、想
使用：认为、思索、思考

避免：说、讲
使用：说道、陈述、表达

避免：看起来
使用：似乎、仿佛、显露出
```

### 技巧3：段落结构

**乌贼式段落特征**：
```
- 段落适中（3-5句/段）
- 逻辑连贯
- 层次分明
- 细节丰富但不冗余

结构模板：
[总起句] + [细节展开1] + [细节展开2] + [收尾句]

示例：
克莱恩走进房间，
这是一个典型的贝克兰德中产阶级住宅。
地板上铺着深红色的地毯，
墙上挂着几幅油画，
家具都是实木制作，
透着一股沉稳的气息。
他环顾四周，
确认没有异常后，
才放松下来。
```

## 乌贼式文风速成

**核心口诀**：
- **一贴合**：叙事贴合世界观背景
- **二细节**：精准而丰富的细节
- **三氛围**：克苏鲁氛围渗透字里行间
- **四克制**：情绪克制而有张力
- **五质感**：字里行间要有"质感"

**快速练习方法**：
1. 选取《诡秘》一个精彩片段
2. 尝试用不同文风重写
3. 对比差异，体会乌贼式文风特点
4. 选择一个原创场景，尝试用乌贼式文风格式写

**日常写作检查**：
每写完一章，问自己：
- 这章的场景是否有"乌贼味"？
- 细节是否丰富而不冗余？
- 氛围是否到位？
- 情绪是否克制？

如果是，很好！
如果不是，调整哪里？
