# 硬核规则设计技法

> "设定即法律，漏洞即罪过" —— 乌贼规则设计核心理念

## 概述

乌贼的规则体系是网文界的天花板，其核心特点是**逻辑自洽、细节严谨、设定与剧情严丝合缝**。与大多数网文的"设定为剧情服务"不同，乌贼的规则是"剧情必须服从设定"，这种倒置体现了真正的硬核精神。

## 核心设计原则

### 1. 可量化原则

**定义**：规则必须能够用数字或明确边界来界定，不能模糊处理。

**乌贼实践**（《诡秘之主》）：
- 序列0-9，共10个等级
- 22条神之途径，每途径唯一
- 非凡特性守恒：总量不变，旧的不去新的不来
- 魔药消化百分比：可以用数字衡量进度

**设计模板**：
```
能力等级体系：
- 一级：XXX（量化指标：力量X斤，速度X米/秒）
- 二级：XXX（量化指标：...）
- 三级：XXX（量化指标：...）

资源守恒公式：
[初始总量] - [消耗量] = [剩余总量]
```

### 2. 可推演原则

**定义**：读者或角色能基于已知规则推导出未知应用。

**乌贼实践**：
- 知道"占卜"可以预测未来 → 推导出"反占卜"的防御手段必须存在
- 知道"刺客"途径擅长暗杀 → 推导出"猎人"途径擅长追踪
- 知道"扮演法"能加速消化 → 推导出"过度扮演"的负面后果

**设计模板**：
```
基础规则A + 基础规则B = 推论C

示例：
规则1：非凡者死亡后非凡特性会析出
规则2：同途径特性可以融合
推论3：高序列者可以通过吸收低序列特性晋升
```

### 3. 代价明确原则

**定义**：每个能力都有明确限制或代价，不存在无限制能力。

**乌贼实践**：
- 魔药晋升需要时间消化（急躁会导致失控）
- 扮演法需要契合角色（强行扮演会精神污染）
- 封印器物有反噬风险（使用越强代价越大）
- 跨越途径有失控风险（不是想吃就吃）

**代价类型清单**：
| 代价类型 | 示例 | 设计要点 |
|----------|------|----------|
| 时间代价 | 消化需要时间 | 不能速成 |
| 精神代价 | 失控/污染风险 | 高收益伴随高风险 |
| 物质代价 | 稀有材料消耗 | 限制获取途径 |
| 能力代价 | 使用后有冷却 | 不能连续使用 |
| 身份代价 | 扮演法限制行为 | 能力即枷锁 |

### 4. 自洽闭环原则

**定义**：规则之间相互印证，形成严密闭环，无矛盾无漏洞。

**乌贼实践**：
- 非凡特性守恒 + 序列0唯一 → 旧日必须争夺唯一性
- 扮演法加速消化 + 失控风险 → 顶级存在都是"疯子"或"极端者"
- 封印器物有代价 + 需要力量对抗 → 正神教会也用封印而非毁灭

**自洽性检查**：
```
矛盾检测清单：
□ 规则A与规则B是否存在逻辑矛盾？
□ 主角使用能力X时，是否有其他角色能反制？
□ 高阶能力是否碾压低阶能力？（如果是，是否有越阶机制？）
□ 最强存在是否受到某种制约？（否则故事无法展开）
```

## 规则构建方法论

### 第一步：核心规则提取

找出你的世界观最核心的1-3条规则，这是整个体系的基石。

**模板**：
```
世界观核心规则（最多3条）：
1. [规则1描述]
2. [规则2描述]
3. [规则3描述]
```

**案例**（《诡秘之主》简化版）：
```
核心规则：
1. 非凡特性守恒：总量不变，序列越高数量越少
2. 途径唯一：同途径高序列者不能共存（黑皇帝例外规则）
3. 扮演法：消化魔药需要扮演对应角色
```

### 第二步：规则展开

从核心规则推导出次级规则，形成树状结构。

**模板**：
```
核心规则1
├── 次级规则1.1
│   ├── 具体规则1.1.1
│   └── 具体规则1.1.2
├── 次级规则1.2
│   └── 具体规则1.2.1
└── 次级规则1.3

核心规则2
├── ...
```

### 第三步：规则补完

检查是否有规则覆盖不到的场景，补完漏洞。

**漏洞检测问题**：
1. 最弱的规则承受者如何生存？
2. 最强的规则使用者如何被制约？
3. 规则之间是否有冲突？
4. 是否有"无代价"的例外？（必须给出合理解释）

### 第四步：代价设计

为每个重要能力设计明确的代价。

**代价设计检查**：
- [ ] 每个高收益能力是否有对应代价？
- [ ] 代价是否足够让人"肉疼"但不致死？
- [ ] 是否有规避代价的合理方式？（如扮演法规避失控）
- [ ] 代价是否会影响角色决策？

## 经典案例解析

### 案例1：《诡秘之主》魔药体系

**核心设计**：
```
途径体系：22条途径 → 220种序列职业
序列层次：9个序列（0-9）+ 旧日/真神/天使
唯一性：每个途径最多1个序列0
```

**规则自洽演示**：
- 序列9 → 序列8 → ... → 序列0 → 旧日
- 每晋升一次，需要消化魔药
- 消化方式：扮演法（加速）或时间（慢速）
- 失控风险：消化不完全+急于晋升
- 特性守恒：死亡后特性析出，可被他人吸收

**逻辑闭环**：
```
问题：高序列者越来越多，序列9越来越少？
回答：非凡特性总量守恒，高序列由低序列晋升而来
问题：高序列者死亡后特性去哪？
回答：析出后可能被他人吸收或污染环境
问题：序列0唯一，那序列1呢？
回答：可以有多个序列1（唯一性仅限序列0）
```

### 案例2：《一世之尊》命运体系

**核心设计**：
```
命运网络：每个存在的命运相互交织
因果律：善恶有报，但不是即时
彼岸设定：超越时间线，收束可能性
```

**规则自洽演示**：
- 小虾米也有命运（众生平等）
- 大能可以拨弄命运但不能消除（否则因果断裂）
- 彼岸可以回溯时间但有代价（天道反噬）
- 命运纠缠：相关者命运相互影响

## 规则设计常见错误

### 错误1：能力无代价

**错误示例**：
```
主角获得"瞬移"能力，无冷却无消耗无限制
```

**正确做法**：
```
主角获得"短距离瞬移"能力：
- 距离限制：最多10米
- 冷却：使用后需3秒恢复
- 代价：每次使用消耗精神力
- 副作用：连续使用会导致眩晕
```

### 错误2：规则与剧情矛盾

**错误示例**：
```
设定：真神之下皆蝼蚁
剧情：真神出场后，主角靠小聪明逃跑了3次
```

**正确做法**：
```
设定：真神之下皆蝼蚁
补充设定：真神不能随意出手（各方势力制约）
或剧情处理：主角从未正面逃跑，都是靠特殊道具/地形/规则漏洞
```

### 错误3：后期补丁设定

**错误示例**：
```
前期：火焰只能被水熄灭
后期：主角获得"神级火焰"，可以烧穿水
```

**正确做法**：
```
前期：火焰只能被水熄灭
补充设定：神级火焰本质是"概念之火"，非物质可以熄灭
伏笔埋设：前期暗示有超越常规的火焰存在
```

## 规则设计速查表

| 设计环节 | 检查要点 | 是/否 |
|----------|----------|-------|
| 核心规则 | 是否足够简洁（1-3条）？ | |
| 规则展开 | 次级规则是否覆盖主要场景？ | |
| 代价设计 | 每个能力是否都有代价？ | |
| 自洽检查 | 规则之间是否矛盾？ | |
| 漏洞检测 | 是否有无法解释的场景？ | |
| 剧情适配 | 规则是否支持精彩剧情？ | |
| 读者友好 | 规则是否易于理解记忆？ | |

## 进阶技巧

### 1. 规则嵌套

将多个简单规则组合成复杂场景。

```
简单规则：
- 规则A：击中要害必死
- 规则B：非凡者比普通人强10倍
- 规则C：防御型非凡者可以护住要害

复杂场景：
主角用规则A的必然性制造危机，但对手用规则C规避，
主角再用规则B的速度优势抢在规则C生效前完成击杀
```

### 2. 规则暗示

不直接告诉读者规则，而是通过剧情暗示。

```
不推荐：
"根据非凡特性守恒定律，高序列者的诞生必然伴随低序列者的减少"

推荐：
"教会最近招募的新人越来越少，资深非凡者私下议论纷纷，
有人说是因为'材料'越来越难找了..."
```

### 3. 规则反转

设计规则时要考虑"反规则"的可能性。

```
规则：序列越高越强
反规则场景：序列0必须沉睡，否则世界毁灭
结果：序列0是"最强废物"
```

---

**核心口诀**：
- **一核心**：找准1-3条核心规则
- **二展开**：从核心推导出次级规则
- **三代价**：每个能力必须有代价
- **四自洽**：规则之间必须自洽
- **五检验**：用剧情检验规则的戏剧性
