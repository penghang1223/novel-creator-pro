# 我吃西红柿写作风格技能

> 技能定位：玄幻网文创作辅助，专注于"爽文标杆"的体系构建与节奏把控

## 作者概述

- **作者名**：我吃西红柿（笔名"番茄"）
- **平台**：起点中文网白金作家
- **核心成就**：《星辰变》《盘龙》《吞噬星空》《雪鹰领主》四部代表作均创千万级阅读
- **行业地位**：玄幻升级流商业化标杆，起点打赏纪录保持者

---

## 核心风格特征

### 1. 玄幻体系构建（骨架）
- 完整的多层级境界体系（通常9层）
- 每层境界有明确的名称、特征、战力量化
- 功法、法宝、势力与境界体系紧密绑定
- **代表案例**：《星辰变》的"仙人体系"从金丹→元婴→渡劫→大乘→天仙→神王

### 2. 热血升级节奏（血肉）
- "三章一小架、五章一大架"的战斗密度
- 每场战斗必有明确收益：境界突破/宝物获得/势力扩张
- 越级挑战是核心爽点，胜负比例约为"七胜二平一负"
- **代表案例**：《盘龙》主角林雷每次跨越等级击败对手的酣畅感

### 3. 鸿蒙宇宙世界观（经络）
- 多部作品共享同一至高世界观（鸿蒙掌控者→主神→位面）
- 《星辰变》→《盘龙》→《吞噬星空》形成严谨的宇宙传承
- 读者在作品中找到彩蛋会产生"宇宙联动"的爽感
- **代表案例**：《盘龙》结尾揭示与《星辰变》的宇宙关联

### 4. 主角成长弧线（灵魂）
- 初期平凡出身+特殊天赋/奇遇
- 成长过程保持"困境-突破-新困境"螺旋上升
- 情感线简洁，常以"默默守护型女主"为主
- 最终成就至高点，且常带有"守护家人/故土"的情感动机

### 5. 商业化叙事节奏（皮相）
- 每章结尾留钩子（战斗悬念/情报获取/身份揭示）
- 每20-30章完成一个阶段性故事弧
- 信息密度高，几乎没有纯过渡的"水章节"
- 主角永远在"做大事"的路上

---

## 核心技法总结

| 技法类别 | 核心理念 | 应用要点 |
|---------|---------|---------|
| **体系设计** | 先建骨架后填肉 | 9层境界→每层3小阶→境界对应势力 |
| **升级节奏** | 战斗即收益 | 每战必有收获，每收获必有新挑战 |
| **世界观联动** | 宇宙大于单本 | 设计至高概念，让多部作品共享 |
| **主角塑造** | 强但有羁绊 | 战力强+守护弱小的情感锚点 |
| **章节结构** | 钩子永不停 | 结尾必须留悬念，禁止断在平静处 |

## 使用方法

### 方法一：整本规划
1. 调用`references/system-design.md`设计境界体系
2. 调用`references/upgrade-pace.md`规划升级节点
3. 调用`references/shared-universe.md`设计宇宙观架构
4. 调用`references/protagonist-growth.md`设计主角成长线
5. 调用`references/text-generator.md`生成正文

### 方法二：单点强化
- 需要设计玄幻体系 → 专注读取`system-design.md`
- 需要把控升级节奏 → 专注读取`upgrade-pace.md`
- 需要设计世界观 → 专注读取`shared-universe.md`
- 需要设计主角 → 专注读取`protagonist-growth.md`
- 需要生成具体文本 → 专注读取`text-generator.md`

### 方法三：风格迁移
1. 读取所有references文件理解技法
2. 将目标题材的特征填入模板
3. 生成符合"番茄风"的定制内容

## 技法速查表

```
【境界设计公式】
[底层境界名] → [中层境界名] → [高层境界名] → [顶级境界名]
     ↓              ↓              ↓              ↓
  凡人势力      小宗门/家族     大宗门/帝国     至高神/天道

【战斗公式】
越3级挑战 → 小胜（获得宝物） → 触发新剧情
越5级挑战 → 惨胜（付出代价） → 实力飞跃
同级别挑战 → 险胜（展现智谋） → 稳固地位

【章节公式】
开头：承接上章钩子（1-3句）
发展：3-5个情节点推进
高潮：战斗/冲突/突破
结尾：抛出新钩子（疑问/危机/机遇）
```
