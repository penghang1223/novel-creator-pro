# 共享世界观构建技法

> 核心原则：宇宙大于单本，彩蛋连接读者

### 1.2 宇宙关联案例

```
【《星辰变》→《盘龙》→《吞噬星空》宇宙传承】

《星辰变》结局：
├─ 秦羽成为新的鸿蒙掌控者
├─ 创造"星辰变宇宙"
└─ 在宇宙中留下传承

《盘龙》设定：
├─ 玉兰大陆所在宇宙
├─ 主神对应星辰变中的"神王"级别
├─ 鸿蒙掌控者林雷
└─ 暗示与星辰变宇宙的关联

《吞噬星空》设定：
├─ 宇宙海概念（多个宇宙）
├─ 起源大陆（至高存在汇聚地）
└─ 真神→虚空真神→永恒真神体系
    （与星辰变的神王→掌控者体系呼应）

【彩蛋设计】
├─ 《盘龙》中出现"星辰变"字样
├─ 《吞噬星空》中提及"秦羽"传说
└─ 读者发现彩蛋时产生"宇宙联动"快感
```

## 二、世界观设计公式

### 2.1 世界观三层次

```
【层次一：至高设定】（贯穿所有作品）
├─ 定义：宇宙最高法则，不可违背
├─ 示例：鸿蒙空间、因果法则、时间长河
└─ 作用：为所有作品提供共同基础

【层次二：位面设定】（单部作品核心）
├─ 定义：该作品独特的世界结构
├─ 示例：仙界/神界/地狱三界、十二星海
└─ 作用：构建单部作品的独特魅力

【层次三：区域设定】（单本局部）
├─ 定义：具体地图/势力范围
├─ 示例：青石镇、落云宗、南海妖域
└─ 作用：提供具体故事发生场所
```

### 3.2 位面穿梭设定

```
【位面穿梭五种方式】

方式一：境界突破自动飞升
├─ 条件：达到某境界后自动飞升
├─ 特点：被动触发，主角无法选择
└─ 爽点：飞升瞬间的震撼感

方式二：主动飞升
├─ 条件：积累足够资源/达到标准
├─ 特点：主角可控，可延迟或提前
└─ 爽点：掌控命运的优越感

方式三：位面传送阵
├─ 条件：找到传送阵并付出代价
├─ 特点：可往返，但有冷却时间
└─ 爽点：获得珍贵传送阵的获得感

方式四：秘境探险
├─ 条件：进入限时秘境
├─ 特点：可获得上位面资源
└─ 爽点：秘境夺宝的紧张刺激

方式五：被迫降临
├─ 条件：被强者追杀/传送失败
├─ 特点：被动，往往带来奇遇
└─ 爽点：绝处逢生的反转快感
```

## 四、世界观与剧情联动

### 4.1 世界观推动剧情

```
【世界观→剧情触发】

触发器一：位面压制
├─ 设定：高境界进入低境界位面会受压制
├─ 剧情：强者伪装潜入，主角发现破绽
└─ 爽点：以弱胜强的智谋展示

触发器二：位面法则
├─ 设定：某位面禁止杀戮/禁止使用某力量
├─ 剧情：主角被困，需用智慧脱身
└─ 爽点：规则内战斗的智斗快感

触发器三：位面战争
├─ 设定：多位面之间的战争
├─ 剧情：主角卷入，成为关键棋子
└─ 爽点：大规模战斗的史诗感

触发器四：位面融合
├─ 设定：两个位面即将碰撞/融合
├─ 剧情：争夺融合后的主导权
└─ 爽点：资源重组带来的机会
```

### 4.2 势力宇宙观

```
【势力层级宇宙观】

【宇宙级势力】
├─ 掌控者级势力（1-3个）
│   ├─ 名称示例：鸿盟、混沌神殿
│   ├─ 成员：掌控者本人+大圆满
│   └─ 作用：决定宇宙走向
│
├─ 纪元级势力（5-10个）
│   ├─ 名称示例：真神殿、轮回阁
│   ├─ 成员：宇宙最强者+真神
│   └─ 作用：震慑各宇宙

【主神级势力】
├─ 大神域/神朝
│   ├─ 首领：半步至高/巅峰神王
│   ├─ 成员：神王数十、尊者数百
│   └─ 范围：横跨数个位面

【宗门级势力】
├─ 圣地/仙宗
│   ├─ 首领：仙帝/神王初期
│   ├─ 成员：金仙/大乘数百
│   └─ 范围：单个位面或星域
```

## 五、彩蛋设计技法

### 5.1 彩蛋类型

```
【彩蛋类型对照表】

┌──────────────┬──────────────────┬──────────────────────┐
│    类型      │      表现        │      示例            │
├──────────────┼──────────────────┼──────────────────────┤
│ 人物彩蛋     │ 提及他书主角     │ "那位传说中的秦羽..." │
├──────────────┼──────────────────┼──────────────────────┤
│ 物品彩蛋     │ 出现他书神物     │ "盘龙戒指"           │
├──────────────┼──────────────────┼──────────────────────┤
│ 地点彩蛋     │ 关联他书位面     │ "通往星辰变大千世界" │
├──────────────┼──────────────────┼──────────────────────┤
│ 法则彩蛋     │ 共享修炼法则     │ "时间法则与吞噬星空" │
├──────────────┼──────────────────┼──────────────────────┤
│ 术语彩蛋     │ 通用设定术语     │ "主神、位面"等       │
└──────────────┴──────────────────┴──────────────────────┘
```

### 5.2 彩蛋植入时机

```
【彩蛋植入时机】

时机一：升级关键点
├─ 示例：突破时感受到"星辰变"功法的共鸣
└─ 效果：暗示作品关联

时机二：获得宝物时
├─ 示例：获得一块刻有"林"字的玉佩
└─ 效果：埋下后续伏笔

时机三：回忆/传说中
├─ 示例：长辈提及"上古时期有一位掌控者..."
└─ 效果：建立历史纵深

时机四：位面穿梭时
├─ 示例：通过传送阵时看到其他位面的景象
└─ 效果：拓展世界观版图

时机五：敌人身份揭示
├─ 示例：敌人竟然是另一个宇宙的强者
└─ 效果：扩大冲突格局
```

## 六、世界观检查清单

```
【世界观自检】

□ 最高设定是否贯穿全书？
□ 位面层级是否清晰？
□ 穿越位面的条件是否明确？
□ 世界观是否限制了某些战斗/能力？
□ 是否有独特的法则/规则？
□ 是否为续作留下伏笔空间？

【关联性检查】

□ 各势力与位面是否对应？
□ 资源分布是否合理？
□ 时间流速是否有设定？
□ 传送/飞升机制是否自洽？
□ 主角移动路径是否清晰？

【彩蛋检查】

□ 是否埋设了跨作品彩蛋？
□ 彩蛋是否足够隐蔽（不喧宾夺主）？
□ 彩蛋是否有后续展开空间？
□ 彩蛋是否增加趣味而非困惑？
```

## 七、快速生成模板

### 模板：完整宇宙设定

```
【宇宙名称】：鸿蒙仙域

【起源】：鸿蒙初开，孕育三千大道。有一位无名存在以身化道，
         成为天道意志，后被称为"鸿蒙道祖"。

【构成】：
├─ 起源大陆：至高存在汇聚地，永恒不灭
├─ 主位面：仙界、神界、魔界三足鼎立
├─ 附属位面：三千中千世界
└─ 边缘位面：无数小千世界/凡界

【法则】：
├─ 最高法则：因果法则（善恶有报）
├─ 修行法则：吸收灵气，感悟大道
└─ 限制法则：位面压制（高境界入低位面受限）

【传承】：
├─ 鸿蒙道祖消失后，留有"鸿蒙金榜"
├─ 金榜收录三千大罗，标注排名
└─ 掌控金榜者，可号令仙域

【势力】：
├─ 鸿蒙神殿（道祖遗留，掌控金榜）
├─ 三大仙朝（仙界/神界/魔界各一）
├─ 圣地联盟（联合抗衡仙朝）
└─ 散修势力（自由联盟）

【位面关系】：
├─ 凡界→修真界→仙界：层层飞升
├─ 各界时间流速：1:10:100
└─ 飞升池：自动传送至下一位面
```

---

*技法要点：设计宇宙时着眼"可扩展性"，让每部作品都是宇宙的一角。*
