# 文风文本生成器

> 核心原则：模板是骨架，填充是血肉，风格是灵魂

## 一、番茄文风特征

### 1.1 语言风格特点

```
【番茄式语言风格】

词汇选择：
├─ 简洁有力：少用华丽辞藻
├─ 具体数字：多用"十万斤""三千里"量化
├─ 动词精准：一剑劈出、一拳轰杀
└─ 四字短句：常用四字一组增强节奏感

句式特点：
├─ 短句为主：一句一段常见
├─ 节奏明快：战斗描写尤其明显
├─ 悬念句式：常用"然而..." "就在这时..."
└─ 感叹强调：常用"竟然" "居然" "不过"
```

### 1.2 经典句式库

```
【开篇过渡句】

├─ "然而，就在这时..."
├─ "却不知，在距离此地不远处..."
├─ "就在众人以为尘埃落定时..."
├─ "就在他准备离开时..."
└─ "让他意想不到的是..."

【战斗描写句】

├─ "一拳轰出，十万斤巨力爆发！"
├─ "剑光一闪，鲜血飞溅！"
├─ "仅仅一招，便分出了胜负！"
├─ "此人，竟然恐怖如斯！"
└─ "他虽只是筑基境，却有金丹战力！"

【情绪描写句】

├─ "心中一沉，脸色微变"
├─ "瞳孔骤缩，难以置信"
├─ "倒吸一口凉气，浑身发颤"
├─ "眼中闪过一抹寒光，杀意凛然"
└─ "嘴角勾起一抹冷笑"

【收益确认句】

├─ "收获颇丰！"
├─ "竟然还有意外收获！"
├─ "这枚丹药，价值连城！"
├─ "这道功法，正是他梦寐以求的！"
└─ "境界突破，实力暴涨！"
```

## 二、开篇生成模板

### 2.1 黄金三章模板

```
【第一章：命运转折】

┌─────────────────────────────────────────────────────────┐
│ 开头（100-200字）                                       │
│ "青云镇，叶家。"                                        │
│ "又是一个下雨天。"                                       │
│ "叶尘站在破旧的屋檐下，看着屋外的雨幕，眼神平静。"       │
│ "今年十六岁的他，却仍旧停留在淬体三重。"                │
│ "在叶家这样的三流家族中，十六岁还未突破后天，便是废物。"  │
│ "更何况，他还是家主——"                                  │
│ "——失踪了十一年的家主的儿子。"                          │
├─────────────────────────────────────────────────────────┤
│ 发展（500-800字）                                       │
│ • 交代家族地位（被大房欺压）                            │
│ • 交代主角处境（废物、母亲早亡、父亲失踪）              │
│ • 遇到契机（获得传承/发现秘密/遇见高人）                │
├─────────────────────────────────────────────────────────┤
│ 结尾钩子（100-200字）                                   │
│ "就在他触碰玉简的瞬间——"                                 │
│ "轰！"                                                  │
│ "一道金光从他眉心迸发！"                                │
│ "这是什么？！"                                          │
│ "紧接着，一道苍老的声音在他脑海中响起："                │
│ "小家伙，你的灵魂，很适合继承老夫的剑道……"              │
└─────────────────────────────────────────────────────────┘
```

### 2.2 不同开局类型

```
【开局类型A：废物逆袭型】

"丹田破碎，修炼十年仍在淬体境——"
"叶尘被称为'青云镇第一废物'。"
"然而无人知晓，他体内封印着一道上古剑魂。"
"直到今日，那道剑魂终于觉醒……"

【开局类型B：天才陨落型】

"十二岁筑基，十四岁金丹——"
"林风曾是青羽门第一天才。"
"然而三年前的一场变故，让他修为尽失，沦为外门杂役。"
"今日，是宗门大比之日。"
"也是他等待三年的复仇之时……"

【开局类型C：异界穿越型】

"李云怎么也没想到，自己会在玩游戏的途中穿越。"
"而且穿越到了这个名为'沧澜大陆'的玄幻世界。"
"成了某个小宗门的外门弟子。"
"还好，随身带着的游戏系统还能用……"
```

## 六、章末钩子模板

### 6.1 钩子类型库

```
【钩子类型库】

类型一：悬念钩子
├─ 模式："就在他准备离开时，身后传来一个声音——"
├─ 效果：引发读者好奇

类型二：危机钩子
├─ 模式："然而，他不知道的是，一双眼睛正盯着他……"
├─ 效果：制造紧张感

类型三：冲突钩子
├─ 模式："就在这时，大长老走了过来，脸上带着冷笑——"
├─ 效果：预示冲突

类型四：收获钩子
├─ 模式："打开宝箱，里面竟然躺着——一枚仙丹？！"
├─ 效果：满足感+期待

类型五：身份钩子
├─ 模式："此人竟然是失踪多年的……"
├─ 效果：身份揭示的期待

类型六：世界观钩子
├─ 模式："却不料，这小小的青云镇背后，隐藏着惊天秘密……"
├─ 效果：拓展世界观
```
