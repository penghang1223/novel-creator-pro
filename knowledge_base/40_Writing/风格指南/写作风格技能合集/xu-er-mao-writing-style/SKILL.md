# 徐二家的猫写作风格 Skill

> 番茄小说金番作家，入行10年，代表作《请叫我鬼差大人》《从前有座镇妖关》《仙人之上》《第四监牢》

## 风格概述

**核心理念**："先有环境，才有的人，而非先有的人，再有的环境。"

徐二家的猫的写作风格以**女频热血+悲情叙事+群像刻画**为核心，擅长用朴实的语言构建宏大世界观，用小人物的悲欢反衬大场景的悲壮。她的小说不是"一个人拯救世界"，而是"千千万万普通人共同描绘的热血篇章"。

### 风格标签
- 女频热血 | 悲情叙事 | 群像刻画 | 家国情怀 | 反套路
- 导演视角 | 情绪真实 | 伏笔密布 | 角色立人设先行

---

## 核心技法总结

### 1. 导演视角（非主角焦点）

**核心理念**：把自己当成"导演"而非"主演"，主角是见证世界的"摄像机"。

**操作要点**：
- 场景内人物控制在5人以内
- 用"远景/近景/特写"镜头切换展现氛围
- 主角在"第三人角度"观察小人物的反应
- 通过小人物的表现侧面烘托宏大场景

**典型场景**：
> 城池摇摇欲坠，士兵前赴后继死在城外，主角还在赶来的路上。此时用普通女孩的视角——双手颤抖、眼中含泪、却依然捡起地上的枪——来展现绝望中的热血。

### 2. 小人物塑造法

**核心理念**：每个人都是自己世界的主角，配角不是背景板。

**操作要点**：
- 给每个配角设计"日常细节"（比如爱吃章鱼烧）
- 用"日常反差"强化悲壮感（末世中想吃章鱼烧的奢望）
- 配角临终台词要贴合人设，而非喊口号
- 配角牺牲时"短短两章，他就是这本书的主角"

**代表案例**：
- 张子良以身养剑，数十年忍受痛苦，只为斩出那一剑
- 阿泰躲在房间，一半黑暗，一半阳光
- "好久都没吃过章鱼烧了……"

### 3. 环境育人法

**核心理念**：先构建环境，角色会在这个环境下"自然生长"出来。

**操作要点**：
- 先设计世界观背景（如人族式微的末世）
- 根据环境推断会诞生什么类型的人
- 正面人物：顶着压力努力抗争
- 普通人物：害怕但依然行动
- 不完美人物：自私与正义并存

**案例**：
> "人族式微，自然会走出先驱者，负重前行。所以会有孙英雄、钟玉书这样的人。同样，也会有禹永言这样的人为人族赴死。至于余生，一个从罪城走出来的孩子，性格孤僻些，情商低一些，才是合理的。"

### 4. 情绪真实法

**核心理念**：情绪到位时一气呵成，不修改。

**操作要点**：
- 情绪波动大的场景（如刀子情节）要一气呵成
- "最初的情绪迸发，才是最真实的"
- 写完不要回头修改遣词造句
- 承认"写得不是最完美的，但一定是最真实的情绪"

**适用场景**：
- 角色牺牲的高光时刻
- 情感爆发的名场面
- 情绪浓烈的对白

### 5. 性格贯穿法

**核心理念**：人物性格决定行为，不让人物做违背性格的事。

**操作要点**：
- 设定好人物的核心性格特征
- 遇到事件时先想"这个性格的人会怎么做"
- 用"不贪财了"暗示角色即将下线
- 反派也要有自己坚持的信念

**案例**：
> "一个贪财，但却心中有正义感的人，面对这种情况，会如何去做，说什么样的话……只有代入进去，才会让一切显得十分自然，合理，而并非纸片人。就像是如果有一天，许元清不贪财了……只有一种可能，就是他……要下线了。"

### 6. 伏笔钩子系统

**核心理念**：掀开一个伏笔，同时埋两个新伏笔。

**操作要点**：
- 每个钩子之间要"串联"而非孤立
- 保持少量但精彩的伏笔
- 掀伏笔时让读者"巧妙知道答案"而非"展示作者智慧"
- 长线背景+短线副本交叉进行

**节奏公式**：
```
小高潮（3-4章）→ 铺垫（1-2章）→ 大高潮（1章）→ 过渡（1-2章）→ 新钩子
```

### 7. 反套路叙事

**核心理念**：不写蠢的套路，写自己觉得有趣的东西。

**常用反套路**：
- 不写"一个人拯救一座城"，写"千万人共同守护"
- 不写"主角无敌"，写"主角也很艰难"
- 不写"非黑即白"，写"灰色地带的真实人性"
- 不写"工具人反派"，写"有自己信念的反派"

## 使用方法

### 适用场景
1. 创作女频热血/都市高武/灵异类小说
2. 需要群像刻画的复杂剧情
3. 追求"虐心"但"热血"并存的情感节奏
4. 构建有深度的世界观（非空壳设定）

### 使用步骤

**Step 1：确定世界观**
```
[环境背景] → [推演会出现什么类型的人] → [主角定位]
```

**Step 2：设计核心角色**
```
[角色性格] → [核心动机] → [他会做什么选择]
```

**Step 3：构建场景**
```
[场景设定] → [5人以内的关键角色] → [镜头切换设计]
```

**Step 4：编写情节**
```
[小人物切入] → [侧面烘托] → [情绪高潮] → [角色归宿]
```

### 禁忌事项
- ❌ 不要让主角"突然睿智"一口气解释所有伏笔
- ❌ 不要让反派"坏得毫无逻辑"
- ❌ 不要让配角成为纯粹的"送装备工具人"
- ❌ 不要堆砌钩子导致节奏崩塌
- ❌ 不要为了辞藻牺牲情绪真实
