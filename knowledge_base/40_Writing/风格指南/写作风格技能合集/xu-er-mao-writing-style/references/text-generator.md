# 文风文本生成模板

> "网文，永远没有固定的公式可言。每个人，也都有每个人自己的风格。只要写自己擅长的，喜欢的，就好。适合自己的，就是最完美的公式。"

本文件提供徐二家的猫风格的文本生成模板，包含开篇、场景、对话、情绪高潮等多种类型。

---

## 一、开篇模板

### 类型1：悬念式开篇

```
【公式】
异常/诡异的现象 + 悬念 + 主角视角切入

【模板】
[异常现象]
那天的月亮，是红色的。

[悬念]
没有人知道为什么。
但从那天起，一切都变了。

[主角视角]
张清源看着窗外。
他总觉得，有什么事情要发生。
```

### 类型2：氛围式开篇

```
【公式】
宏观背景 + 核心设定 + 主角处境

【模板】
镇妖关外，尸山血海。

城墙上，老兵靠在墙根，抽着旱烟。
"又死了一批。"他说。
"习惯就好。"

余罪城。
这里是流放之地。
活着，是偶然。
死，才是常态。

而他，余生，就是从这里走出来的。
```

### 类型3：反套路式开篇

```
【公式】
颠覆认知的设定 + 主角的处境

【模板】
（不后宫，不套路，不无敌……）

这是苏安醒来后看到的第一行字。
刻在一块破旧的木板上。
歪歪扭扭的，像是谁用指甲划出来的。

"这是什么鬼地方？"
他摸了摸自己的脸。
还在。
没死。
那就好。

但下一秒，他就意识到——
这地方，可能比死了还糟糕。
```

## 二、场景模板

### 场景1：守城战（小人物视角）

```
【模板结构】
定场 → 小人物出场 → 绝境 → 反差细节 → 收尾

【正文】

城墙上，血已经没过脚踝。

老王头蹲在角落里，抽着旱烟。
他是城门口卖包子的。
城破那天，他把最后几个包子塞给了逃跑的孩子。

"老子这辈子，就蒸包子这点本事。"他嘀咕着，抄起了菜刀。

"下辈子，谁他妈还当包子。"
"谁他妈还当包子啊……"

他冲了上去。

没有人记得他叫什么。
但那天的城墙上，
有一个卖包子的，
和一个士兵一起，
挡在了孩子面前。
```

### 场景2：英雄谢幕

```
【模板结构】
铺垫 → 触发 → 高光 → 遗言 → 名言收尾

【正文】

张子良站在那里。

风吹过。

他的头发全白了。

"我有一愿。"他说。

"望人族无忧。"

剑光起。

"我有一剑。"

"斩世间不平。"

他向前踏出一步。

剑出。

天地变色。

"此剑过后——"

"人族无忧。"

他倒下了。

"诸君……"

"且听龙吟。"

（风声呼啸，掩盖了所有人的哭声）
```

### 场景3：日常温情

```
【模板结构】
日常场景 → 细节 → 温暖 → 留白

【正文】

"吃饭了。"

她把碗放在桌上。

还是那几道菜。
还是那个味道。

他吃了一口。

没说话。

但眼睛有点热。

窗外的风吹进来，带着花香。

"明天还走吗？"她问。

"嗯。"

"那就……"她顿了顿，"早点睡。"

她转身进了里屋。

他看着她的背影。

筷子握了很久。
```

### 场景4：废土氛围

```
【公式】
破败 + 诡异 + 悬念

【正文】

仙庭废墟。

锈迹斑斑的铁棍插在地上。

风吹过，发出呜咽般的声音。

像是在哭。

又像是在诉说什么。

"走吧。"向导说，"这里不能久留。"

"那些仙人……"有人问。

向导没回答。

只是加快了脚步。

远处，无头的神明在虚空中行走。

他的脖子上，空空荡荡。

但仿佛，有什么东西，本该在那里。
```

## 三、对话模板

### 类型1：热血式对话

```
【公式】
简短 + 有力 + 节奏感

【示例】

"杀——！"
"杀！"
"杀！"

号角吹响。

城门大开。

老将军一马当先。

身后，是密密麻麻的人。

有老有少。

有残有缺。

但每个人的眼睛里，都燃着火。

"今天，"老将军喊道，"我们不死不还！"

"不死不还！"

"不死不还！"

"不死——不还——！"
```

### 类型2：悲情式对话

```
【公式】
日常 + 暗示 + 告别 + 留白

【示例】

"保重。"

"你也是。"

他伸出手，想拍拍他的肩膀。

又放下了。

"下次回来，"他说，"请你喝酒。"

"好。"

他转身走了。

走了很远。

才回头。

城墙上的那个人，已经不见了。

他愣了一下。

然后继续走。

没再回头。
```

### 类型3：反差式对话

```
【公式】
不正经的语气 + 正经的事

【示例】

"喂，老头，你怕不怕？"

老王头抽了口旱烟。

"怕？"他嘿嘿一笑，"老子这辈子，什么没见过？"

"那你——"

"就是有点遗憾。"他打断道，"下辈子的包子，不知道还能不能那么香。"

他把烟杆在鞋底磕了磕。

"行了，别婆婆妈妈的。"他抄起菜刀，"替我看着点，我先去投个胎。"
```

### 类型4：悬疑式对话

```
【公式】
神秘 + 暗示 + 不说破

【示例】

"你知道吗？"他忽然说。

"什么？"

"那扇门后面……"他看着远处的废墟，"藏着这个世界的真相。"

"什么真相？"

他笑了笑。

"等你打开就知道了。"

"但是——"

他顿了顿。

"有些真相，知道了，反而更痛苦。"

"你确定想知道吗？"
```

## 四、情绪高潮模板

### 类型1：刀子收割

```
【模板结构】
触发 → 震惊 → 悲痛 → 铭记

【正文】

他死了。

就那么死了。

没人知道他叫什么名字。

没人知道他从哪里来。

他们只看到——
一个卖包子的老头，
和一个士兵，
挡在了城门口。

挡在了孩子们面前。

很久以后，
有人问他为什么。

没人回答。

但城墙上，多了一个包子摊。

每天清晨，
都有人把第一笼包子，
放在城墙上。

不卖。

只供。
```

### 类型2：热血爆发

```
【模板结构】
压抑 → 临界 → 爆发 → 宣言

【正文】

城墙上，尸体堆成山。

还活着的人，不多了。

但没有人退。

"还有多少人？"老将军问。

"报告——"年轻的士兵看了眼名单，"还能动的，三十二人。"

"够了。"

老将军笑了。

他举起剑。

"三十二人，守一座城！"

"守一座城！"

"够不够？！"

"够！！！"

号角再次吹响。

三十二个人。

向妖兽发起了冲锋。

"今天——"

老将军的声音在风中回荡。

"我镇妖关——寸土不让！"
```

### 类型3：温情治愈

```
【模板结构】
冷漠 → 触动 → 融化 → 改变

【正文】

他不信任何人。

从罪城出来的人，都这样。

"吃吗？"一个女孩递过来一个包子。

他没接。

"有毒？"他问。

女孩愣了一下。

然后笑了。

"有毒。"她说，"毒死你的那种毒。"

他看着她。

她也看着他。

"吃不吃？"

"……吃。"

他接过包子。

咬了一口。

很香。

很久没吃过这么香的东西了。

"好吃吗？"

"……还行。"

他没说的是：

这是他这辈子，吃过最好吃的东西。
```

## 五、人物弧线模板

### 模板1：学长型（励志配角）

```
【开场】
吊车尾，被人嘲笑。
"就这？还想觉醒？"
他没说话。
只是默默走开了。

【发展】
每天训练到最晚。
每次都是最后一名。
但他从不放弃。

【转折】
"你不适合这条路。"导师说。
"我知道。"他笑了笑。
"但我想试试。"

【高光】
他用自己的方式，守护了想守护的人。
"够了吗？"他问。
没有人回答。
但他看到了，那些孩子们的眼睛。

【归宿】
他倒下了。
但他的名字，被刻在了城墙上。

（纵使流星转瞬逝，亦能片刻压星河！）
```

### 模板2：阿泰型（悲情配角）

```
【开场】
沉默，不说话。
总是躲在角落里。

【发展】
有人试图接近他。
他拒绝了。
"别靠近我，"他说，"我会害了你。"

【转折】
有人看到了他房间里的光。
一半黑暗，一半阳光。

【高光】
他用自己的方式，救了所有人。

【归宿】
他消失了。
没有人知道他去了哪里。
但有人说，在某个角落，
有时候，能看到一个影子。
一半黑暗，一半阳光。
```

### 模板3：反派型

```
【开场】
反派登场。
所有人都恨他。

【发展】
他做了很多坏事。
但偶尔——
有时候——
他的眼神里，会闪过什么。

【转折】
真相揭晓。
"你们不懂。"他说。
"有些事，总要有人做。"

【归宿】
他坚持到了最后。
没有人原谅他。
但有人记住了他。
"他是坏人，"人们说，"但他……是个有骨气的坏人。"
```

## 六、技法速查

### 热血场景关键词
- 杀、冲、挡、守
- 寸土不让、死战不退
- 万家灯火、岁岁平安
- 诸君、且听

### 悲情场景关键词
- 沉默、转身、没回头
- 风吹过、光暗交界
- 好久没……了
- 下辈子、如果有来生

### 悬念场景关键词
- 那扇门后面……
- 真相是……
- 没有人知道
- 从那天起，一切都变了

### 日常场景关键词
- 吃饭了、吃完了
- 还行、不难吃
- 早点睡、保重

## 七、写作口诀

```
情绪到位一气成，遣词造句随后扔。
主角不是唯一人，配角也有自己命。
小人物里有大义，反差细节最戳心。
热血悲情一线牵，刀子里面藏希望。
```

## 八、禁忌清单

- ❌ 不要喊口号式的"热血"
- ❌ 不要突然的情绪爆发（无铺垫）
- ❌ 不要让所有配角同时高光
- ❌ 不要堆砌华丽辞藻（朴实更真实）
- ❌ 不要让对话"演"得太明显
- ❌ 不要说满情感（留白更有力）
- ❌ 不要让反派"纯粹邪恶"
- ❌ 不要忘记配角的"日常"
