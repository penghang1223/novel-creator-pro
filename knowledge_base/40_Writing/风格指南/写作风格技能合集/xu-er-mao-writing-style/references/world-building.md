# 世界观构建技法

> "不要写太复杂的世界观，不要写太多的角色。"

世界观是故事的"容器"，但徐二家的猫的世界观不是空壳——每一个设定背后都有逻辑，有人性的挣扎，有故事的张力。

---

## 一、世界观构建原则

### 核心原则
1. **服务于剧情**：世界观是为故事服务的，不是炫技的
2. **简洁有力**：用最少的设定讲最清晰的世界
3. **真实感**：让读者相信这个世界"存在"
4. **留白艺术**：不要一次性交代所有设定

### 禁区
- ❌ 不要写"说明书式世界观"（设定堆砌）
- ❌ 不要让设定"用完就丢"（要与剧情关联）
- ❌ 不要写"非黑即白"的世界（要有灰色地带）
- ❌ 不要让主角"无敌"于这个设定

## 二、徐二家的猫的世界观类型

### 类型1：都市高武（《镇妖关》）

```
【核心设定】灵气复苏，妖兽横行，人族式微
【关键元素】镇妖关、罪城、觉醒者
【社会结构】镇妖关将士 vs 普通百姓
【核心矛盾】守护 vs 生存
```

**世界观构建步骤**：
1. **核心矛盾**：人族与妖兽的生存之争
2. **地理概念**：镇妖关（前线）vs 城市（后方）
3. **阶层划分**：觉醒者 vs 普通百姓
4. **制度设计**：守关的规矩、功勋系统
5. **日常细节**：百姓生活、军队文化

### 类型2：灵异地府（《鬼差大人》）

```
【核心设定】永夜过后，恐怖复苏，地府现代化
【关键元素】邮局、邮车、鬼差
【世界观特色】将地府"职场化"
【核心矛盾】阳间 vs 阴间，人 vs 鬼
```

**世界观构建步骤**：
1. **核心设定**：恐怖复苏的背景
2. **新秩序**：地府的管理制度
3. **职业分化**：鬼差的日常工作
4. **规则设计**：抓鬼指标、满意度考核
5. **讽刺元素**：现代职场 vs 传统鬼怪

### 类型3：废土修真（《仙人之上》）

```
【核心设定】远古仙庭沦为废墟，仙人沉睡与复苏
【关键元素】废土、神明、诡异
【核心矛盾】仙凡关系、力量追逐
【特色】无头神明、铁棍悲鸣
```

**世界观构建步骤**：
1. **历史背景**：仙庭为何崩塌？
2. **现状**：废土世界的生活状态
3. **力量体系**：天道规则、觉醒者
4. **势力分布**：各方势力的立场
5. **悬念设计**：仙庭覆灭的真相

## 三、世界观与人物的关系

### 核心法则
**"先有环境，才有的人，而非先有的人，再有的环境。"**

### 环境育人三步法

```
【Step 1】设定环境背景
    ↓
【Step 2】推演：这种环境下会诞生什么类型的人？
    ↓
【Step 3】选择：你的角色应该属于哪一类？
```

### 案例分析

**《镇妖关》世界观 → 人物推演**

```
环境：人族式微，妖兽横行，镇妖关是人族防线

推演结果：
- 先驱者：顶着压力，努力抗争 → 孙英雄、钟玉书
- 赴死者：为人族赴死 → 禹永言
- 普通人：在末世挣扎 → 城中的百姓
- 罪人：被流放/被边缘化 → 主角余生
- 守护者：用生命守护他人 → 镇妖关将士
```

### 环境与性格的对应

| 环境 | 可能的性格 | 案例 |
|------|-----------|------|
| 末世挣扎 | 谨慎、算计、不信任人 | 余生 |
| 太平盛世 | 乐观、热血、有理想 | 赵青衣 |
| 大家族 | 城府深、懂得权衡 | 许元清 |
| 军队 | 直接、重义气 | 老兵们 |

## 四、世界观细节填充法

### 三层细节法

| 层次 | 内容 | 示例 |
|------|------|------|
| 表层 | 视觉、听觉感受 | 城墙上的血迹、喊杀声 |
| 中层 | 社会运行规则 | 功勋制度、升迁规则 |
| 深层 | 价值观、信仰 | "万家灯火"的信念 |

### 细节来源

**生活观察法**（徐二家的猫的方法）：
> "我在看电视剧、刷短视频时，时常会因为某句话发呆。"

1. 观察现实生活的职业、场景
2. 想象它们在"设定世界"中是什么样子
3. 给这些场景设计"反差细节"

**案例**：
```
现实：卖菜
↓ 放到废土世界
废土：卖菜大哥为什么要卖菜？躲避仇家？大隐隐于市？
↓ 进一步设计
这个卖菜大哥，实力比主角高，但为什么会在这卖菜？
如果他缺钱，为什么缺钱？
↓ 结果
一个"小人物"的人设就出来了
```

## 五、世界观的"独特性"设计

### 反套路世界观

**《仙人之上》的六个"不"**：
- 不后宫
- 不套路
- 不无敌
- 不系统
- 不无脑
- 不爽文

**设计思路**：读者想看什么，我就"不"什么

### 特色世界观要素

| 要素 | 传统设定 | 徐二家的猫的特色 |
|------|---------|----------------|
| 地府 | 阴森恐怖 | 现代化职场 |
| 仙界 | 逍遥自在 | 要考编、打卡、写述职报告 |
| 战争 | 英雄无敌 | 小人物撑起防线 |
| 反派 | 纯粹的恶 | 有自己的信念和坚持 |

## 六、世界观节奏控制

### 世界观展现节奏

```
开篇（10%）：核心设定1-2个
中期（40%）：逐步展开更多设定
高潮（30%）：设定与剧情深度结合
后期（20%）：设定收尾，揭示真相
```

### 世界观展现方法

**方法1：场景带出**
> 通过具体场景展现世界是什么样的

**方法2：人物对话**
> 通过角色讨论带出设定

**方法3：主角视角**
> 主角初来乍到，用他的眼睛看世界

**方法4：事件驱动**
> 通过某个事件揭示某个设定

### 禁忌
- ❌ 不要"开篇说明书"（直接介绍世界观）
- ❌ 不要让设定"一次性全部揭露"
- ❌ 不要让设定"与剧情脱节"
- ❌ 不要让设定"太完美"（要有漏洞/争议）

## 七、世界观构建模板

### 模板1：都市高武世界观

```
【背景】灵气复苏X年，人族与妖兽共存
【地理】前线（镇妖关）vs 后方（城市）
【阶层】觉醒者 vs 普通百姓
【核心机构】镇妖军、墨学院、罪城
【关键规则】觉醒制度、功勋系统
【核心信念】"万家灯火，岁岁平安"
【隐藏真相】（悬念伏笔）
```

### 模板2：灵异地府世界观

```
【背景】永夜过后，恐怖复苏
【机构】邮局、邮车、地府系统
【职业】鬼差的日常工作
【规则】抓鬼指标、满意度考核
【讽刺元素】现代职场文化 vs 传统鬼怪
【核心人物】主角张清源
【隐藏真相】（悬念伏笔）
```

### 模板3：废土修真世界观

```
【背景】远古仙庭崩塌，仙人沉睡
【现状】仙庭废墟凌驾于九天之上
【新势力】觉醒的凡人、复苏的仙人
【核心元素】无头神明、残缺天道
【势力分布】各方势力的立场
【核心悬念】仙庭覆灭的真相
【隐藏真相】（长线伏笔）
```

## 八、世界观检验清单

写完世界观后，用这些问题检验：

1. **这个世界的核心矛盾是什么？**
2. **普通人是怎么生活的？**
3. **这个世界的"日常"是什么样的？**
4. **主角在这个世界中处于什么位置？**
5. **这个世界有什么"讽刺"或"反转"的点？**
6. **设定和剧情是否深度结合？**

## 九、世界观灵感收集

### 徐二家的猫的灵感来源

> "我有一个标签为'我和他们'的文档，其中大概有200多个人物的设定。"

**日常灵感收集**：
- 电视剧里的某个场景
- 短视频里的某句话
- 小说里的某个设定
- 新闻里的某个事件
- 弹幕/评论里的某个点子

**灵感处理流程**：
```
灵感触发（某个场景）
    ↓
发散思维（如果在我的书中……）
    ↓
细节完善（他为什么在这里？他在做什么？）
    ↓
保存/丢弃（好就保存，不好就格式化）
```
