# 文风文本生成器

> 模板是骨架，填充是血肉，风格是灵魂

---

## 一、开篇生成模板

### 1.1 标准开篇模板

**结构**：悬念场景 → 核心问题 → 人物困境

```
【悬念场景】
[描述一个反直觉/令人不安的场景]

【核心问题】
[抛出一个直指核心的问题]

【人物困境】
[建立主角即将面临的抉择/挑战]
```

**模板填充示例**：

```
【悬念场景】
晨祷的钟声响了七遍，但祭坛上的圣火依然没有点燃。
跪伏的信徒们开始骚动，有人低声祈祷，有人瑟瑟发抖。

【核心问题】
罗格站在人群最后，冷冷地看着这一切。
神也会迟到吗？
还是说——神已经不想回应这些祈祷了？

【人物困境】
三天后，北方领主的军队就会抵达。
届时，这些虔诚的信徒会发现，他们祈祷了一辈子的神，
根本不会来救他们。
而他，需要在这之前，想出活命的办法。
```

### 1.2 人物立传式开篇

**结构**：人物画像 → 核心特质 → 命运暗示

```
【人物画像】
[用2-3个意象勾勒人物轮廓]

【核心特质】
[点明人物的"灰色"本质]

【命运暗示】
[暗示人物未来的走向]
```

**模板填充示例**：

```
【人物画像】
罗格不是好人。
他贪婪、狡猾、善于欺骗。
他有一双很会笑的眼睛，笑起来的时候像是阳光下的湖水，
清澈得让人以为看到了善良。

【核心特质】
但罗格知道，那清澈是假的。
那是他戴了二十年的面具。
面具之下，是他从不示人的算计。

【命运暗示】
至于这副面具还能戴多久——
那要看这个世界的恶意，还有多少耐心。
```

### 1.3 世界观展示开篇

**结构**：世界异象 → 运行规则 → 凡人处境

```
【世界异象】
[描述一个反常的世界现象]

【运行规则】
[通过现象揭示世界的运作逻辑]

【凡人处境】
[建立普通人在这个世界中的渺小]
```

**模板填充示例**：

```
【世界异象】
天裂了。
不是比喻，是真的裂开了一道缝隙。
从那道缝隙中，有金色的光倾泻而下，
像是什么东西在天穹之外，正俯视着这个世界。

【运行规则】
神术师们说，这是神迹。
每一次天裂，都意味着有信徒的祈祷被听见。
但没人说的是——
每一次祈祷被回应，都有人在付出代价。
而那代价，从来不是神来承担。

【凡人处境】
罗格看着那裂开的天空，想的是另一个问题：
如果神真的存在，
那么在天穹的另一边，
是否也有什么东西，正在看着神？
```

### 1.4 经典开篇句式库

```
【句式一：悖论开场】
"这是一个没有英雄的世界。
或者说，这是一个只有假装英雄的骗子的世界。"

【句式二：灰色开场】
"他不是好人。
但在这个世界上，好人活不过三天。"

【句式三：危机开场】
"当第一只恶魔出现在王城广场时，
罗格正在数他刚从贵族口袋里偷来的金币。
他抬起头，看了那恶魔一眼。
然后继续数。"

【句式四：真相开场】
"所有人都以为，神是慈悲的。
直到他们发现，神只是太饿了。
饿得等不及用虔诚慢慢喂养。"
```

## 二、场景生成模板

### 2.1 祭坛/神殿场景

**结构**：辉煌 → 阴影 → 真相

```
【辉煌】
[描写祭坛/神殿的华丽壮观]
    ↓
【阴影】
[在辉煌中发现不和谐的细节]
    ↓
【真相】
[揭示这辉煌背后的代价/谎言]
```

**模板填充示例**：

```
【辉煌】
圣殿的金顶在阳光下燃烧。
那不是真的火焰，而是一种被凝固的光，
每一道光线都像是在歌唱，歌唱着神的慈悲与伟大。
跪伏的信徒们泪流满面，以为自己终于被拯救。

【阴影】
但罗格站在人群最后，注意到了一些细节：
那些流泪的信徒，眼眶是空洞的。
不是悲伤的空洞，而是——失去了什么的空洞。
像是一个被掏空的壳。

【真相】
他突然明白了。
神术的代价不是来世的报应，而是今生的蚕食。
每一次神术降临，都在吞噬祈祷者的某一部分。
也许是记忆，也许是情感，也许是——
让他们之所以成为"他们"的东西。
而他们不知道。
或者说，他们选择不知道。
```

### 2.2 深渊/黑暗场景

**结构**：感知 → 诱惑 → 恐惧

```
【感知】
[描写对深渊/黑暗的感知——往往从听觉或触觉开始]
    ↓
【诱惑】
[深渊的低语/展示它能给予的东西]
    ↓
【恐惧】
[揭示深渊真正的可怕之处——不是力量，而是真实]
```

**模板填充示例**：

```
【感知】
黑暗中有声音。
不是风声，不是脚步，而是——
更低沉的东西。
像是什么东西在呼吸，在等待，在呼唤。

【诱惑】
"我可以给你力量。"
那声音说。
"你不需要祈祷，不需要献祭，不需要对任何人低头。
只需要迈出一步。
只要一步。
你就能得到你想要的一切。"

【恐惧】
罗格没有动。
他盯着那片黑暗，不是恐惧，而是——
某种奇异的熟悉感。
深渊也在看着他。
它认出了他。
不是罗格这个名字，不是他做过的事，而是——
他内心深处那些见不得光的东西。
那些他自己都不愿承认的欲望。
在深渊面前，他无处躲藏。
这才是深渊最可怕的地方：
不是吞噬你的身体，而是剥开你的灵魂。
让你看见那个你一直假装不存在的自己。
```

### 2.3 战斗场景

**结构**：对峙 → 交锋 → 转折

```
【对峙】
[双方对立的姿态/环境描写]
    ↓
【交锋】
[战斗过程的简短呈现——侧重心理而非动作]
    ↓
【转折】
[出人意料的转折——往往与智慧而非力量有关]
```

**模板填充示例**：

```
【对峙】
高大的骑士挡住了去路，银色的铠甲在阳光下闪闪发光。
他举起长剑，剑尖直指罗格的咽喉。
"亵渎者，跪下。"

【交锋】
罗格笑了。
他从来不和骑士正面交手。
不是因为打不过，而是因为——
他不需要打得过。

【转折】
"你确定要在这里动手吗？"罗格歪了歪头，
"这里是圣殿前三十步。再往前一步，就是禁区。
而我身后三十步，就是教会主教的车队。
你杀了我，主教会看见。
你不杀我，我会在主教面前说，是你在禁区动手。
你觉得，以你今天的行为——
三年后你还能活着吗？"

骑士的手微微颤抖。

"所以，"罗格摊开双手，"让我们都假装什么都没发生？
我往左，你往右。
皆大欢喜。"
```

### 2.4 日常/酒馆场景

**结构**：表象 → 暗流 → 交易

```
【表象】
[普通日常的描写——往往带着讽刺]
    ↓
【暗流】
[环境/细节暗示更大的世界]
    ↓
【交易】
[主角参与一个灰色交易]
```

**模板填充示例**：

```
【表象】
酒馆的黄昏和别处没什么不同。
醉汉在角落里胡言乱语，旅人在吧台前吹嘘自己的冒险。
空气中弥漫着劣质麦酒和烤肉的混合气味。
以及，某种不易察觉的东西。
也许是谎言。
也许是比谎言更危险的东西。

【暗流】
罗格注意到角落里那个戴兜帽的人。
他坐了三个小时，只点了一杯水。
在这个酒馆里，只喝水的人只有两种：
逃犯，或者杀手。
而这个人的手指一直在桌面上轻轻敲击。
三长两短。
那是某个地下组织的暗号。

【交易】
"朋友，"罗格在他对面坐下，
"如果你在等什么人，也许我可以帮忙。
不过——"
他搓了搓手指，
"情报是有价格的。"
```

## 三、对话生成模板

### 3.1 利益博弈对话

**结构**：试探 → 亮牌 → 拉锯 → 成交/破裂

```
【试探】
双方互相试探底线

【亮牌】
亮出各自的需求/筹码

【拉锯】
讨价还价/心理博弈

【成交/破裂】
达成协议或谈崩
```

**模板示例**：

```
【试探】
"我想我们需要谈谈。"对方开口。

"我们？"罗格挑眉，"我们有什么需要谈的吗？"

"关于北境的事。"

"北境有什么事？"

【亮牌】
对方沉默片刻，然后说：
"你想要什么？"

"你想要什么？"罗格反问。

"......平安。"对方终于说，"北境的军队三日后就到。
我想平安地离开。"

"平安，"罗格玩味地重复，"这个价格可不便宜。"

【拉锯】
"我可以给你这个。"对方推过来一份文件。
罗格扫了一眼——北境的布防图。
"不够。"

"你还要什么？"

"你的承诺。"罗格说，"从今天起，你欠我一个人情。"

"什么程度的人情？"

"我说了算的程度。"

【成交/破裂】
对方的脸涨红了，但他最终点了点头。
"成交。"
"成交。"罗格伸出手，两人握手。
他注意到对方的手心在出汗。
每个人都有自己的价码。
区别只是，有些人卖得贵一些，有些人——
根本不知道自己在卖什么。
```

### 3.2 心理交锋对话

**结构**：质问 → 闪避 → 逼近 → 真相

```
【质问】
直指核心问题

【闪避】
试图转移话题/否认

【逼近】
不依不饶，追问到底

【真相】
被迫说出真相或暴露弱点
```

**模板示例**：

```
【质问】
"你为什么要杀他？"

"我没有。"罗格否认得很快。

【闪避】
"那你那天为什么在场？"
"碰巧路过。"
"碰巧？在一个从没有人碰巧路过的地方？"

【逼近】
"他的死对谁有好处？"对方步步紧逼。
"这个问题，"罗格倒了一杯酒，"你想问的其实不是这个吧。"

"那我想问什么？"

"你想问的是——我是不是一直在利用你。"

【真相】
沉默。
漫长的沉默。
然后罗格笑了。
"答案是：是的。"
"从我们认识的第一天起，你就是我计划的一部分。"
"他该死。你有用。所以我借刀杀人。"
"不满意？"
"可惜，这就是我。"
```

### 3.3 哲学对话模板

**结构**：问题 → 否定 → 追问 → 沉默

```
【问题】
提出一个哲学性问题

【否定】
否定表面的答案

【追问】
追问更深层的问题

【沉默】
留下没有答案的沉默
```

**模板示例**：

```
【问题】
"你说神是慈悲的。"她问，"但为什么还有这么多苦难？"

【否定】
"苦难是考验。"神父回答，"通过考验的人会得到救赎。"

"那没通过的呢？"

"......"

【追问】
"那他们的苦难是白受的吗？"
"那些死去的孩子，那些被折磨的灵魂——"
"他们只是没有通过考验，所以活该？"
"这叫什么慈悲？"

【沉默】
神父没有回答。
不是因为他没有答案。
而是因为他的答案，会砸碎她最后的信仰。
但有些真相，不需要由他来揭开。
她迟早会自己发现。
在这个世界上，慈悲和残忍，往往只有一线之隔。
而那条线，由谁来画？
谁都不知道。
```

## 四、内心独白模板

### 4.1 欲望独白

**结构**：渴望 → 代价评估 → 自我说服/放弃

```
【渴望】
对某物的强烈欲望

【代价评估】
评估获取它的代价

【自我说服/放弃】
说服自己去做/不去做
```

**模板示例**：

```
他想要那块地。
那块黄金般的土地，出产黄金般的麦子，养育黄金般的人生。
他想要。

但代价是什么？
和领主的友谊？和教会的默契？还是自己越来越难以维持的"好人"形象？

他闭上眼睛。
那欲望像一只野兽，在胸口撕咬。

也许——只是一次而已。
也许——没有人会知道。
也许——

他睁开眼睛。
放弃了那个念头。
不是因为他有底线，而是因为那块地的风险太高。
总有一天，他会找到一个更好的机会。
或者，总有一天，他会变得不在乎风险。
但不是今天。
今天，他还不想看见那个自己。
```

### 4.2 挣扎独白

**结构**：触碰 → 回忆闪回 → 抉择

```
【触碰】
某事触动了内心

【回忆闪回】
过去的某个相关记忆

【抉择】
做出选择
```

**模板示例**：

```
她的眼睛很像她。
这是罗格第一次注意到的事情。

那天阳光很好，她坐在窗边看书。
光落在她的侧脸上，勾勒出一个他以为已经忘记的轮廓。

他想起了另一个人。
很多年前，另一个女人也有这样的眼睛。
那双眼睛最后充满了恐惧和绝望——
因为他。

他移开了视线。
不再看她。

有些事情，不是不可以。
而是做了之后，他就再也没有借口假装自己还是个人了。
```

### 4.3 哲思独白

**结构**：观察 → 抽象 → 追问

```
【观察】
观察某个现象/场景

【抽象】
将现象上升到抽象概念

【追问】
提出一个没有答案的问题
```

**模板示例**：

```
这个世界充满了谎言。
有些谎言是善意的，有些是恶意的。
但本质上，它们没有区别——
都是为了让人接受那些不愿意接受的事实。

神说，信仰得救。
教会说，服从得救。
领主说，纳税得救。

但罗格已经学会了问一个问题：
谁来救那些说谎的人？

也许他们也需要被救赎。
也许他们才是最深陷泥沼的人。
也许——

不。
他停止了这个念头。
想太多是会死人的。
在这个世界上，活得最好的从来不是最聪明的，
而是最懂得什么时候该停止思考的。
```

## 五、章节结尾模板

### 5.1 悬念式结尾

```
【未解之谜】
"...而那个问题的答案，就藏在那扇门的背后。"

【危险逼近】
"...他不知道的是，就在他转身的瞬间，身后的阴影中，
有什么东西，正在睁开眼睛。"

【选择悬置】
"...这个决定，他还需要时间。
但时间这种东西——
往往是这个世界上最奢侈的。"
```

### 5.2 哲思式结尾

```
【真相揭示】
"...这时他才明白，原来从头到尾，
他以为自己在对抗的，其实从来不是真正的敌人。
真正的敌人，是他自己。"

【循环暗示】
"...命运像是一个圆环，无论走多远，最终都会回到起点。
只是那时候的他们，已经不是出发时的他们了。"

【留白收束】
"...故事到这里本该结束，但罗格知道——
真正的故事，才刚刚开始。
或者说，从未开始过。
因为所有人，都活在命运的夹缝中，
等待着一个永远不会到来的转折点。"
```

### 5.3 情感式结尾

```
【微光闪烁】
"...但就在那一刻，他决定活下去。
不是因为有什么值得期待的，
而是因为——
还没有完全变成那个他不想成为的人。"

【苦涩释然】
"...他笑了。
苦涩的、释然的、带着某种疲惫的笑。
这就是他选择的道路。
没有回头的路。
唯一的安慰是——
他不是一个人走在这条路上。"

【孤独宣言】
"...酒馆渐渐空了。
他一个人坐在角落，看着窗外的夜色。
这世界有很多路。
有些通向光明，有些通向黑暗。
而他走的这条路——
只通向自己。
好与不好，都是他应得的。"
```

## 六、创作工具箱

### 6.1 欲望词典

```
【权力的别称】
- 王座
- 巅峰
- 俯瞰众生的视角
- 让所有人低头的能力
- 不再需要说谎的地位

【财富的别称】
- 金色的麦田
- 流金的岁月
- 堆满金币的地窖
- 让儿子不必像父亲一样活着的资本
- 购买"选择"的能力

【爱情的别称】
- 唯一的光
- 不需要理由的牵挂
- 在黑暗中依然想握住的手
- 唯一能让他感觉自己还是个人的东西
```

### 6.2 意象速查

```
【黑暗系列】
深渊、虚空、阴影、黑夜的眼睛、无星的苍穹
凝固的墨、挖去光明的空洞

【光明系列】
```
