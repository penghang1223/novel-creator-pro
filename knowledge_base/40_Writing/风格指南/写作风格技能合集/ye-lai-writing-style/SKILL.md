# 夜来风雨声丶写作风格技能

> **适用场景**：创作恐怖无限流小说、密室逃脱副本、人性博弈悬疑故事
> **风格定位**：诡谲悬疑、沉浸式压迫感、波浪式节奏

---

## 风格概述

夜来风雨声丶是番茄小说平台的金番恐怖无限流作家，代表作《诡舍》《天不应》累计45万粉丝。其风格以**层层递进的压迫感**和**诡谲精密的副本设计**著称，被誉为"恐怖无限流天花板"。

### 核心风格标签
| 标签 | 含义 |
|------|------|
| 血门世界 | 诡异的门作为副本入口，门后是独立恐怖空间 |
| 规则即死亡 | 违反规则必死，规则本身是最大陷阱 |
| 人性博弈 | 恐怖不仅是鬼怪，更是人心 |
| 密室逃脱 | 有限空间内的生存与推理 |
| 呼吸感节奏 | 紧张→喘息→再紧张的波浪式推进 |

---

## 核心技法速查

### 技法一：恐怖氛围营造
- **五感联觉**：用听觉、嗅觉、触觉放大恐惧（不止视觉）
- **静默压迫**：死寂比尖叫更恐怖
- **细节腐烂**：发霉、血渍、腐臭的微观描写
- **时间错觉**：让读者分不清过了多久，模糊时间感

### 技法二：诡谲副本设计
- **门扉意象**：每扇门都是生死边界
- **空间折叠**：看似正常的空间暗藏玄机
- **规则闭环**：进入→探索→触雷→破局→逃脱
- **NPC陷阱**：不是所有NPC都是友军

### 技法三：悬疑推理技法
- **信息碎片化**：不一次性给全信息
- **误导与反转**：让读者以为找到答案，结果是陷阱
- **旁观者视角**：用其他角色的反应暗示危险
- **线索埋伏**：前文埋下看似无用的细节

### 技法四：恐怖规则设计
- **规则的两面性**：表面规则保护你，暗藏规则杀死你
- **时间压力**：倒计时制造紧迫感
- **资源稀缺**：道具、钥匙、信息都是稀缺资源
- **代价机制**：获得道具必有代价

### 技法五：波浪式节奏
- **大波浪**：章与章之间的紧张度起伏
- **小波浪**：每章内的三段式节奏
- **喘息点**：每3000字左右设置一个情绪释放点
- **高潮叠嶂**：连续的小高潮比单一高潮更刺激

## 使用方法

### 基础使用（直接调用）

```
使用"夜来风雨声"风格，创作一个[密室逃脱]场景的开篇
要求：
- 主角刚进入一个诡异的房间
- 包含恐怖氛围描写
- 至少一条隐藏规则
- 300字以内
```

### 进阶使用（参考技法文档）

1. **明确技法需求**：根据创作需要，选择对应的技法文档
2. **参考模板生成**：在`references/text-generator.md`中找到对应模板
3. **组合使用**：多个技法文档可以组合使用

### 技法文档索引

|------|------|----------|
| `horror-atmosphere.md` | 氛围营造技法 | 需要渲染恐怖气氛时 |
| `dungeon-design.md` | 副本设计技法 | 设计新副本时 |

## 创作检查清单

使用本技能时，可参考以下检查项：

### 氛围检查
- [ ] 是否调动了至少3种感官？
- [ ] 是否有静默/死寂的段落？
- [ ] 细节描写是否足够"脏"和"真实"？

### 副本检查
- [ ] 副本是否有明确的边界？
- [ ] 是否设计了至少3条规则（表面+暗藏）？
- [ ] 是否有"看似有用实则致命"的陷阱？

### 节奏检查
- [ ] 每3000字是否有喘息点？
- [ ] 是否有时间压力？
- [ ] 高潮是否被递进而非一次性释放？

### 悬念检查
- [ ] 是否给读者提供了"错误答案"的线索？
- [ ] 关键信息是否被分散在多处？
- [ ] 是否有"回头看才懂"的伏笔？
