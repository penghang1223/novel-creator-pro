# 诡谲副本设计技法

> **核心理念**：副本不是布景板，是精密运转的死亡机器

---

## 一、门扉意象系统

### 核心原理
**"门"是夜来风雨声风格中最核心的意象符号——每一扇门都是生死边界。**

### 门的设计层级

#### 1. 入口门（进入副本）
```
❌ 普通写法：
他推开门，走进了一个阴森的房间。

✓ 夜来风雨声风格：
他的手刚碰到门把手——
门自己开了。
不是"被推开"的。
是"被邀请"的。
门缝里透出昏黄的光，
像是里面有人在等你。
等你很久了。
```

**入口门设计要点**：
- 门要"主动"打开，暗示副本有自己的意志
- 门内透出的光要有"引诱感"
- 留一个"回头看"的细节（门外的世界变了）

#### 2. 陷阱门（表面正确实则致命）
```
场景：三条走廊，尽头各有一扇门

✓ 陷阱门设计：

左边的门最干净，门口有箭头指示"安全出口"。
中间的门贴满了符纸，上面写着"禁止入内"。
右边的门最普通，什么标记都没有。

大多数人会选左边。
因为它看起来最安全。

但你注意到没有——
左边的门下面，有黑色的液体正在往外渗。
而右边那扇门上，
刻着一个名字。
是你认识的名字。
你的名字。
```

#### 3. 逃生门（看似逃脱实则更深的陷阱）
```
✓ 逃生门陷阱：

镜子里有扇门。
我认识那扇门——那是卫生间的门。
我刚从那里出来。
所以——
我是从镜子里走出来的？
我回头看身后。
身后是卧室。
但卧室的墙上，
有一面镜子。
镜子里映出的卧室——
没有人。
没有我。
```

### 门的三种状态
| 状态 | 表现 | 含义 |
|------|------|------|
| 紧闭 | 无法打开或有封印 | 通往核心真相 |
| 半开 | 透出光/声音/气味 | 引诱进入 |
| 敞开 | 无阻碍通过 | 已进入更深层的陷阱 |

## 二、空间折叠技法

### 核心原理
**恐怖空间不是越大越好，而是"看似正常"的空间里暗藏不可能。**

### 技法拆解

#### 1. 平面折叠（艾舍尔式空间）
```
场景：走廊的尽头是另一条走廊的尽头

✓ 折叠描写：

走廊很长。
我数着脚步走，走了大约三十步。
尽头是另一条走廊的入口。
我继续走。
又走了三十步。
又是另一条走廊。
我停下脚步。
因为我发现了不对劲的地方。
这条走廊的墙上，
有一个我刚才走过的痕迹。
我的脚印。
还在往前走。
但我明明停下来了。
```

#### 2. 垂直折叠（上下颠倒）
```
场景：天花板和地板一样真实

✓ 垂直空间错乱：

我发现不对劲的时候，是在往上爬梯子。
梯子很长，我爬了很久。
终于碰到了天花板。
不对——
那不是天花板。
那是另一块地板。
我伸出手，撑住边缘，把自己拉上去。
然后我看到了上面房间的布局。
和下面的一模一样。
只是——
家具都在天花板上。
倒挂着。
而最恐怖的是——
那张倒挂的床上，
躺着一个人。
正在看着我。
```

#### 3. 镜像空间
```
场景：现实和镜中世界的差异

✓ 镜像异常：

我在镜子里看到自己。
但镜子里的我，动作比我慢了一拍。
我抬手，镜子里的我也抬手。
但慢了。
只有一点点。
我停下来。
镜子里的我没有停。
还在抬手。
还在继续那个动作。
还在——
看着镜子里我的位置。
我现在的真实位置。
它知道我在动。
它在学我。
但它在看我。
```

## 三、副本闭环设计

### 核心原理
**每个副本必须有完整的"进入→探索→触雷→破局→逃脱"闭环。**

### 五阶段设计模板

#### 阶段1：进入（Into）
```
触发条件：接触某扇门/进入某个区域
异常感知：发现世界规则变了
初始设定：给玩家3分钟"正常"时间

✓ 范例：

"当你踏出电梯的那一刻，灯灭了。
不是故障——是切换。
你能感觉到空气变了。
温度、湿度、甚至是气味，
全都变了。
这是另一个地方。
或者说——是同一个地方的另一面。
手机没有信号。
手腕上多了一行字。
倒计时开始了。"
```

#### 阶段2：探索（Explore）
```
探索三要素：
- 环境线索：墙上的字、地上的痕迹、物品的位置
- 规则暗示：前人留下的警告或提示
- 危险预警：某些区域明显"不能去"

✓ 探索节奏：

第一次探索（浅层）：发现表面规则
第二次探索（中层）：发现规则漏洞
第三次探索（深层）：发现真正的规则
```

#### 阶段3：触雷（Trigger）
```
触雷类型：
1. 主动触雷：玩家主动违反规则
2. 被动触雷：规则被触发（时间到/到达某处）
3. 连环雷：违反A规则导致触发B规则

✓ 触雷描写：

他看到了那行字。
"不要在23:00后照镜子。"
他下意识看了一眼手表。
22:59。
然后是23:00。
镜子里——
镜子里的他——
刚才那一秒，没有和他一起动。
他在23:00的那一秒，停止了。
而镜子里的他——
笑了。
```

#### 阶段4：破局（Breakthrough）
```
破局要素：
- 关键道具：能打破规则的物品
- 隐藏规则：找到真正的规则
- 代价交换：获得什么必须失去什么

✓ 破局设计：

我找到了规则漏洞。
规则说"不能回头"。
但它没说——
不能"低头"。
我趴在地上，用手指摸索着地面，
一点一点地往前爬。
直到我绕过了那个转角。
规则没有杀死我。
但我知道——
它记住我了。
因为在转角的那面墙上，
多了一个字。
我的名字。
```

#### 阶段5：逃脱（Escape）
```
逃脱类型：
1. 物理逃脱：找到门/出口
2. 规则逃脱：完成规则要求的条件
3. 代价逃脱：用道具/信息交换逃脱

逃脱设计要点：
逃脱不应该太顺利
最后时刻要有"差点失败"的紧张感
```

## 四、NPC陷阱设计

### 核心原理
**不是所有NPC都是友军——有些NPC本身就是副本的一部分。**

### NPC类型设计

#### 1. 假帮助者
```
✓ 假帮助者设定：

她穿着护士服，看起来很和善。
"我在这里工作很久了，"她说，"我知道安全的地方。"
她指着走廊尽头的门。
"那扇门是安全的，通往下个区域。"
她看起来很可信。
但你注意到——
她走路的时候，脚后跟从不沾地。
而且她的影子，
比正常人的要深。
```

#### 2. 沉默观察者
```
✓ 沉默NPC：

角落里坐着一个老人。
他不说话，只是看着你。
其他人都躲着他。
你问他这是什么情况。
他不回答，只是看着你。
然后他伸出三根手指。
指了指地板。
指了指天花板。
指了指你。
你不懂他的意思。
后来你才知道——
他指的是三个字：
"活下去"。
他做到了。
你不知道他用多少人的命换来的提示。
```

#### 3. 人皮伪装者
```
✓ 伪装者揭示：

他看起来很正常。
说话、走路、表情，都很正常。
但我注意到一个问题。
他的衣领下——
有缝线的痕迹。
像是有人把一整块皮肤缝上去的。
我假装低头系鞋带，
从下往上看他的脸。
他的下巴下面——
有一道拉链。
是那种衣服上的拉链。
拉开之后——
里面是空的。
他不是人。
他是一层皮。
一层正在学习"怎么做人"的皮。
```

### NPC危险等级表
| 等级 | 表现 | 真实身份 | 应对策略 |
|------|------|----------|----------|
| 1 | 友善帮助 | 陷阱引路人 | 不可完全信任 |
| 2 | 中立观望 | 同样困在这里的人 | 有限合作 |
| 3 | 沉默警告 | 知道真相的人 | 尝试解读暗示 |
| 4 | 敌意明显 | 副本的守卫/猎手 | 绝对危险 |
| 5 | 模仿正常 | 人皮伪装者 | 无法分辨 |

## 五、空间设计清单

### 副本空间类型
```
【高恐惧空间】
- 封闭空间：房间、柜子、电梯、地下室
- 垂直空间：高楼、深井、悬崖
- 循环空间：无尽的走廊、旋转木马

【中恐惧空间】
- 日常生活空间：教室、办公室、商场（熟悉感被打破）
- 过渡空间：走廊、楼梯（连接不同区域）
- 藏身处：床底、柜子、角落（躲藏与被发现）

【低恐惧空间】
- 开阔空间：广场、操场（危险无处不在的无力感）
- 明亮空间：太亮了反而可疑
- 安静空间：应该有声音却没有
```

### 空间设计陷阱清单
```
✓ 检查项：
[ ] 空间是否有"不应该存在的角度"？
[ ] 是否有门窗数量不匹配的情况？
[ ] 是否有人留下了"只有后来者才能看懂"的痕迹？
[ ] 是否有某种东西在"填补"人类留下的空缺？
[ ] 时间在这个空间里是否正常？
[ ] 是否有空间"吞掉"了某些东西（脚步声消失、光线被吸收）？
```

## 六、场景组合模板

### 模板一：第一个诡异房间
```
【新手房模板】

基础设定：
- 大小：约20平米的封闭房间
- 进门状态：门在身后关上
- 初始线索：墙上的字/手表上的倒计时
- 核心道具：某样"看起来有用但可能致命"的物品

✓ 标准结构：

1. 视觉锁定（10秒内抓住读者）
   "天花板上的裂缝正在渗出黑色的液体。"

2. 感官扩展（30秒内建立沉浸感）
   "空气冰冷，带着铁锈和腐烂的甜腻。"

3. 规则暗示（60秒内给出核心信息）
   "墙上用血写着几个字：'23:00之前必须离开这个房间。'"

4. 时间压力（立即制造紧迫感）
   "手表显示：22:15。"

5. 异变开始（打破"正常"的幻象）
   "然后灯灭了。"
```

### 模板二：逃生走廊
```
【走廊模板】

✓ 三段式恐怖走廊：

第一段：看似正常
"走廊很长，尽头有一扇门。
灯光昏暗，但还在亮着。
地板上有脚印，不止一个人的。
往前走吧，门就在前面。"

第二段：开始异常
"走了很久，但门没有更近。
我低头看地板。
我的脚印旁边，多了一排。
有人在跟着我。
但我身后没有人。"

第三段：退路消失
"我回头。
身后的门不见了。
只剩下一面墙。
墙上贴满了照片。
照片上的人——
都是我。"
```
