# 恐怖规则设计技法

> **核心理念**：规则不是为了让你活，是为了让你死得更明白

---

## 一、规则的双面性设计

### 核心原理
**最好的规则不是"不许做X"，而是"做了X你会死——但不做X你也会死"。**

### 技法拆解

#### 1. 表面规则 vs 隐藏规则
```
【规则对比表】

表面规则："23:00之前必须离开房间"
表面效果：给出时间限制，制造紧迫感

隐藏规则："离开房间后不能再回来"
隐藏效果：离开后才发现重要的东西落在里面

真实规则："真正危险的不是23:00，而是23:00的时候你回头看了一眼"
真实效果：规则本身是陷阱，遵守规则的人反而触发了真正的死亡条件
```

#### 2. 规则漏洞
```
✓ 规则漏洞设计：

规则："不要打开第三扇门。"
但规则没说——
不能从里面打开。
我绕到第三扇门的背后。
门背面有一个锁。
我转动锁，门开了。
门后——
是我进来的那扇门。
而我进来的那扇门背后，
现在站着一个人。
在朝我笑。
但我进来的时候，
那扇门后面明明没有人。
```

#### 3. 规则升级
```
✓ 递进式规则：

第一阶段：
"不要在走廊里奔跑。"
——制造压抑感

第二阶段：
"不要在走廊里奔跑。"
"如果听到脚步声，也不要停。"
——限制应对方式

第三阶段：
"不要在走廊里奔跑。"
"如果听到脚步声，也不要停。"
"如果你已经停下来了——"
——规则在读取你的状态

第四阶段：
规则消失了。
不是没有规则。
是规则不需要被写出来了。
因为你已经——
成为了规则的一部分。
```

## 二、规则结构设计

### 经典规则格式
```
【标准规则格式】

抬头：规则标题
正文：具体条文
附加：隐藏条件
代价：违反后果

✓ 范例：

┌─────────────────────────────────┐
│  宿 舍 规 则（第三条）           │
├─────────────────────────────────┤
│ 1. 熄灯时间是22:00              │
│ 2. 熄灯后不要看窗户              │
│ 3. 如果听到敲门声，不要开门      │
│                                  │
│ ※ 补充条款：                    │
│ 如果敲门声持续三分钟以上，       │
│ 请检查门锁是否完好。             │
│                                  │
│ 违反后果：                       │
│ [以下内容已被涂黑]               │
└─────────────────────────────────┘

解读：
- 22:00-某个时间点是危险期
- 窗户里有什么东西
- 三分钟的敲门声=特殊信号
- 被涂黑的内容才是真正的规则
```

### 规则复杂度层级
```
Level 1：单一规则（容易记忆，容易违反）
"不要照镜子。"

Level 2：双重规则（制造选择困境）
"不要照镜子。"
"也不要闭眼。"

Level 3：连锁规则（前一条触发后一条）
"不要照镜子。"
"但如果你已经照了——"
"不要看你自己的脸。"

Level 4：循环规则（回到起点）
"不要照镜子。"
"但如果你已经照了——"
"不要看你自己的脸。"
"除非你的脸不在镜子里。"
"如果你的脸不在镜子里——"
"不要回头确认。"
```

## 三、时间压力设计

### 核心原理
**时间是恐怖小说中最有力的武器——它逼迫角色做出不理智的决定。**

### 时间压迫类型

#### 1. 倒计时型
```
✓ 倒计时压迫：

"你还有30秒。"
我的手里握着那把钥匙。
门在十米之外。
三十秒，够了。
我开始跑。
二十秒。
门越来越近。
十秒。
我伸出手——
门把手上多了一行字。
"请在3秒内输入正确密码。"
五秒。
我根本不知道密码。
三秒。
我的手按在门上。
一秒。
门上的字变了。
"时间到。"
门消失了。
不是打开——
是消失了。
门后的空间，
正在往我这边蔓延。
```

#### 2. 时间循环型
```
✓ 循环压迫：

"我回到了原点。
时间回到了原点。
但有些东西变了。
墙上的血手印多了一个。
地上的尸体少了一具。
我看了一眼手表。
22:59。
但我进来的时候——
也是22:59。
不对。
我看了一眼血手印。
最后那只手——
是我的。"
```

#### 3. 时间剥夺型
```
✓ 时间剥夺：

"时间变慢了。
不是错觉。
真的变慢了。
一秒像一小时那么长。
我听见自己的心跳。
砰——
停一秒。
砰——
停一秒。
有什么东西在看着我。
它的时间是正常的。
它在等我。
等我这一秒过去。
等我变脆弱。
等我变成它的——
猎物。"
```

### 时间压力组合模板
```
【时间压迫模板】

第一阶段（充裕）：
"还有十分钟。不急。"

第二阶段（紧迫）：
"只有五分钟了。加快速度。"

第三阶段（危机）：
"只剩一分钟。快！"

第四阶段（突破）：
"时间到。"
"不对——还剩三十秒。"
"有什么东西来了。"

第五阶段（转折）：
"我放弃了时间。
我开始无视它。
然后我发现——
它也无视了我。
不是暂停。
是——
它在用另一种方式计时。"
```

## 四、资源稀缺设计

### 核心原理
**恐怖的核心不是"有什么"，而是"没有什么"。**

### 稀缺资源类型

#### 1. 道具稀缺
```
✓ 道具稀缺设计：

架子上有五把钥匙。
但门有六道。
这意味着——
有一个人拿不到钥匙。
那个人会是谁？
我不知道。
但钥匙在架子上。
架子上的钥匙越来越少。
因为每一道门后面，
都有人没有出来。
```

#### 2. 信息稀缺
```
✓ 信息稀缺设计：

墙上有很多字。
但我只能看清一部分。
其他部分被血覆盖了。
我用手擦。
越擦越多。
血的来源——
是我的手。
不对。
血是从墙里渗出来的。
墙上的字正在消失。
被血覆盖的字——
是唯一的线索。
而我——
正在把线索抹掉。
```

#### 3. 空间稀缺
```
✓ 空间稀缺设计：

这个房间只能容纳三个人。
但我们有四个人。
所以必须有一个人——
站在外面。
"你出去。"
"为什么是我？"
"因为……"
因为什么？
为什么她看着我的眼神变了？
为什么她后退了一步？
为什么——
她在把我往外推？
"因为你刚才——"
刚才怎么了？
"你刚才没有呼吸。"
我没有呼吸——
从什么时候开始的？
从什么时候——
我变成了"那三个人"中的一个？
```

## 五、代价机制设计

### 核心原理
**没有免费的午餐。每一个"获得"都必须有"付出"。**

### 代价类型

#### 1. 即时代价
```
✓ 即时代价：

"你获得了钥匙。"
"代价：你的影子消失了。"

"你获得了门卡。"
"代价：你的左眼看不见了。"

"你获得了地图。"
"代价：地图上会实时显示你的位置——"
"以及那个东西的位置。"
```

#### 2. 延迟代价
```
✓ 延迟代价：

"你获得了逃脱的机会。"
代价？
没有代价。
太便宜了。
你不应该这么幸运。
三天后——
你收到了一封信。
是你自己的字迹。
上面写着：
"代价是你不会记得自己是谁。"
你低头看镜子。
镜子里——
是一张陌生的脸。
那张脸正在——
对你笑。
```

#### 3. 传递代价
```
✓ 传递代价设计：

"你想救他吗？"
"想。"
"那就付出代价吧。"
"什么代价？"
"你的一部分。"
"哪一部分？"
"等价的。"
等价交换。
所以——
当他的伤痊愈的时候，
你身上多了一道伤。
当他活下来的时候，
你开始——
变得虚弱。
当他完全康复的那一天，
你会在镜子里——
看到他。
用你的身体，
呼吸着你的空气，
站在你本该站的位置。
而你——
变成了一个幽灵。
只能看，不能碰。
永远地。
```

## 六、规则悖论设计

### 核心原理
**最好的规则是那种"遵守也死，不遵守也死"的悖论。**

### 悖论类型

#### 1. 选择悖论
```
✓ 选择悖论：

规则："你可以选择离开。"
规则补充："但离开的人必须留下一个人。"
规则补充补充："留下的人会被留在镜子里。"

所以：
选择离开 = 找人替死
不离开 = 困死在这里

无论怎么选——
都有人会死。
```

#### 2. 观察悖论
```
✓ 观察悖论：

规则："不要看镜子。"
但如果你不照镜子——
你就不知道自己变成了什么。
所以你必须照镜子。
但规则说了不要照镜子。
所以——
当你发现自己变成怪物的时候，
你已经违反了规则。
当你还没发现自己变成怪物的时候，
镜子已经记住了你。
因为你——
偷看了。
```

#### 3. 认知悖论
```
✓ 认知悖论：

规则："不要相信任何人。"
但如果所有人都遵守这条规则——
那就没有人能相信任何人的"不要相信任何人"。
所以——
那条规则——
是谁写的？
是那个东西吗？
它写了一条规则，
让你不能相信任何人——
包括它写下的那条规则。
它——
它就是规则本身。
```

## 七、规则恐怖场景模板

### 模板一：发现规则场景
```
【规则发现场景模板】

✓ 标准结构：

1. 发现线索
"墙上刻着字。
我用手指摸了摸。
不是刻上去的。
是用指甲——
一个一个抠出来的。"

2. 阅读规则
"规则一：不要在熄灯后睁开眼睛。
规则二：不要回应任何声音。
规则三：如果你已经违反了规则一——
请假装你还在睡着。"

3. 意识到问题
"我看了一眼窗户。
灯灭了。
窗外——
有东西在看着我。
它知道我的眼睛是睁开的。
它知道我在看它。
而我现在——
不能闭上眼睛。
因为闭上眼睛，就说明我醒了。
说明我违反了规则。
它——
在等我闭眼。"

4. 规则反馈
"然后——
灯亮了。
是它打开的灯。
它在告诉我——
你被发现了。
现在你可以睁开眼睛了。
也可以闭上眼睛了。
因为规则已经——
更新了。"
```

### 模板二：规则陷阱场景
```
【规则陷阱场景模板】

✓ 标准结构：

1. 找到规则
"我找到了规则手册。
上面写着：'规则七：不要打开第三层抽屉。'"

2. 找到抽屉
"第三层抽屉是锁着的。
需要钥匙。"

3. 找到钥匙
"钥匙在第一层抽屉里。
第一层抽屉是开着的。"
太好了。
我伸手进去。
摸到了钥匙。
冰凉的。
上面有字。
我凑近看——
字是：
'请锁好抽屉。'"

4. 意识到陷阱
"我低头看。
第一层抽屉——
现在是第三层。
三变成了三。
不是三变成了二。
是三——
变成了三。
而我——
正握着钥匙，
站在第三层抽屉前面。"
```
