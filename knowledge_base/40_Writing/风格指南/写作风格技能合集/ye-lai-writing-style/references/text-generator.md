# 文风文本生成器

> **核心理念**：模板不是枷锁，是骨架——血肉需要你自己填

## 一、开篇生成模板

### 模板1：密室进入型
```
【开篇模板A：直接进入】

[触发元素] + [异常感知] + [规则暗示] + [悬念钩子]

触发元素：电梯门打开/推开房门/醒来
异常感知：空间/气味/温度不对
规则暗示：墙上的字/手表上的信息/听到的声音
悬念钩子：某个不合理的地方/即将发生的事

✓ 范例：

电梯门打开的时候，我闻到了一股腐烂的甜腻。
不是垃圾房的那种。
是那种——
已经死去很久的东西，
在温暖的环境里发酵的味道。
我下意识看了一眼手表。
23:15。
然后我愣住了。
因为我进电梯的时候——
也是23:15。
不是时间停止。
是——
我根本没有走出去。
这个电梯——
是循环的。
墙上的楼层按钮在闪烁。
1, B1, 2, B1, 3, B1……
B1在不断地重复。
而我刚才——
明明按的是1楼。
```

### 模板2：规则揭示型
```
【开篇模板B：规则开篇】

[规则展示] + [场景描写] + [规则执行] + [违背后果]

规则展示：用特殊排版呈现规则
场景描写：规则适用的环境
规则执行：有人在遵守规则
违背后果：有人违背了规则

✓ 范例：

┌────────────────────────────────┐
│  宿 舍 规 则                    │
│  请在22:00前回到房间            │
│  熄灯后请保持安静               │
│  如果听到敲门声——               │
│  [此处字迹模糊]                 │
└────────────────────────────────┘

这是贴在宿舍门口的规则。
我看了一眼手表。
21:58。
还有两分钟。
我加快脚步往房间走。
走廊尽头有一个人也在往这边走。
我们同时看到了对方。
然后——
灯灭了。
22:00。
我站在走廊中央，
一动不动。
因为我听到了敲门声。
从我的房间门口传来。
但我还没到那里。
那是——
我的房间。
那敲门的是——
谁？
```

### 模板3：时间压迫型
```
【开篇模板C：倒计时型】

[紧急状态] + [时间压力] + [空间描述] + [选择困境]

紧急状态：正在被追赶/时间紧迫
时间压力：具体的倒计时数字
空间描述：被困住的环境
选择困境：两条路，两个可能

✓ 范例：

我在跑。
手表显示22:57。
规则说23:00之前必须回到房间。
我还有三分钟。
三分钟够我跑三百米。
但这个走廊——
比我记忆中的长。
像是被什么东西拉长了。
我看了一眼墙上的门牌号。
101, 102, 103……
我刚才经过的是103。
现在经过的——
还是103。
不对。
我停下脚步。
墙上的103下面，
多了一行字。
字是血红色的。
"不要停下来。"
我抬头。
走廊尽头——
有人在看我。
那东西——
长着我的脸。
手表响了。
23:00。
```

## 二、场景描写模板

### 场景类型1：诡异房间
```
【房间场景模板】

视觉 → 听觉 → 嗅觉 → 触觉 → 异常细节

✓ 完整范例：

[视觉]
房间不大，大概十五平米。
但天花板很高，高到灯光照不上去，
留下一片黑暗。
墙纸是暗红色的，像是干涸的血迹。
上面有规律的图案——
不，不是图案。
是手印。
一个一个叠在一起的手印。

[听觉]
很安静。
太安静了。
连空气流动的声音都没有。
像是这个房间——
被什么东西封住了。

[嗅觉]
然后我闻到了。
一股腐烂的味道。
不是浓烈的。
是那种——
已经渗进墙壁里的、若有若无的臭味。
像是这里死过人，
但尸体已经不见了。

[触觉]
我伸出手，摸了摸墙壁。
墙纸是潮湿的。
有些地方软得像烂泥。
我的手陷了进去。
拔出来的时候——
指尖是黑色的。
不是脏。
是——
有什么东西在里面。

[异常细节]
我低头看墙。
刚才我摸的地方，
出现了一行字。
不是我写的。
是墙壁自己——
浮现出来的。
"欢迎回家。"
我从来没来过这里。
但它——
认识我。
```

```
是湿的。
我低头看。
我的鞋底——
是干的。
那脚印是谁的？

[异常细节]
墙壁上有照片。
一排一排的照片。
照片里的人——
都在看我。
我加快脚步。
不看他们。
但我能感觉到——
他们的眼睛在跟着我转。

[危险暗示]
然后我听到了声音。
脚步声。
不是我的。
在我身后。
越来越近。
我不敢回头。
但我听到那个声音——
停在了我身后。
很近。
近到我能感觉到——
有呼吸打在我的后颈上。

[循环陷阱]
我开始跑。
一直跑。
跑到我再也跑不动。
然后我停下来。
抬头看。
墙上写着：
"欢迎回来。"
我的脚印——
就在我脚下。
我绕了一圈。
回到了原点。
但不是"刚进来"那种原点。
是——
刚才那个东西——
就在我前面。

```

```
✓ 完整范例：

[入口关闭]

没有声音。

一明一灭。
一明一灭。

[空间异常]
我按下了关门键。
门关上了。
电梯继续上升。
6, 7, 8……
```

## 三、对话生成模板

### 对话类型1：诡异NPC对话
```
【NPC对话模板】

正常寒暄 → 微妙的异常 → 隐藏的警告 → 最后的暗示

✓ 完整范例：

[正常寒暄]
"你好，你是新来的住户吧？"
是隔壁的邻居，一个中年女人。
她笑得很和善。
"欢迎欢迎。"

[微妙的异常]
"请问有什么需要注意的吗？"
她愣了一下。
笑容还在，但眼神变了。
"需要注意的？"
她低下头。
"没什么特别的。"
"就是——"
她凑近了一点。
声音变小了。
"不要在晚上12点后照镜子。"

[隐藏的警告]
"为什么？"
她没有回答。
只是看着我笑。
那个笑容——
不太对。
太整齐了。
像是画上去的。
"因为——"
她说。
"你会在镜子里看到——"
"看到什么？"
"看到——"
她突然停住了。
眼神恢复了正常。
"没什么。"
她转身要离开。
"记住就好。"

[最后的暗示]
她走了几步，又停下来。
回头看着我。
"对了。"
"不要相信任何人说的'不要照镜子'。"
"因为——"
她笑了笑。
"如果有人告诉你不要照镜子——"
"说明他已经照过了。"
"而且他看到的——"
"是你。"
```

### 对话类型2：规则传递对话
```
【规则传递对话模板】

发现者 → 追问 → 规则内容 → 追问后果 → 沉默/消失

✓ 完整范例：

[发现者]
"墙上有字。"
他指着墙壁。
上面用血写着几行字：
"规则一：不要离开房间。"
"规则二：不要相信任何人。"
"规则三：不要——"

[追问]
"第三是什么？"
我凑近看。
第三行——
被刮掉了。
只剩下黑色的痕迹。
"不知道。"
另一个人说。
"我来的时候就已经这样了。"

[规则内容]
"那你们遵守了前两条吗？"
没人回答。
气氛突然变得诡异。
"为什么不回答？"
我追问。
沉默。
然后——
第二个人开口了。
"因为——"
他看着我。
"我们已经违反了。"

[追问后果]
"违反会怎样？"
我刚问完，就后悔了。
因为他笑了。
那种笑——
不是正常人的笑。
"违反会怎样？"
他重复我的问题。
"你很快就会知道了。"
他指了指窗户。
我转头看。
窗户——
变黑了。
不是外面天黑了。
是有什么东西——
贴在窗户上。
把光挡住了。

[沉默/消失]
我回过头。
刚才那个说话的人——
不见了。
房间里有五个人。
现在只剩四个。
但没人提他去了哪里。
好像——
没人记得他。
只有我——
还记得他的笑容。
那个不是人类的笑容。
```
