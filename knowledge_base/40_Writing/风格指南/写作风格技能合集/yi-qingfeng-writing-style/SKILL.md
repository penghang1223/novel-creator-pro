| 维度 | 特征 |
|------|------|
| **平台定位** | 番茄小说·金番作家·103万粉丝 |

## 核心技法体系

### 一、沙雕开局法则（5W1H模型）

```
W(hat):  卖什么不重要，重要的是"反差感"
W(ho):   主角是普通人，但行为要"不正常"
W(hy):   越离谱的理由越好，越能引发好奇
W(hence): 看似搞笑的开局，埋下世界观伏笔
H(ow):   节奏要快，笑点要密集，第一章就要炸
```

**核心口诀**：「开局不沙雕，读者全跑掉」

### 二、轻松叙事三不原则

| 原则 | 错误示范 | 正确示范 |
|------|----------|----------|
| 不压抑 | 连续吃瘪、委屈憋屈 | 及时反转、立刻打脸 |
| 不虐心 | 暗恋多年无回应 | 直接表白或被表白 |
| 不灌水 | 三章还没出新手村 | 三章打完新手BOSS |

### 三、世界观构建公式

```
沙雕外壳 + 完整逻辑 + 深层设定 = 弈青锋世界观

表面：荒诞、搞笑、不正经
底层：完整的力量体系、势力划分、背景故事
核心：隐藏的悲剧/阴谋/伏笔
```

### 四、人物塑造公式

```
搞笑人设 = 沙雕表面 + 反差萌点 + 隐藏深度

示例：
表面：话痨系统、抖M恶魔、不靠谱系统
反差：关键时刻靠得住、背后有故事
深度：笑声下藏着眼泪或野心
```

## 使用方法

### 场景1：开局设计

1. 打开 `references/humor-design.md`
2. 选取「反套路开场」模板
3. 套用「开局三要素」生成开头
4. 检查是否符合「沙雕+悬念」双轨

### 场景2：情节设计

1. 根据当前节奏选择技法：
   - 需要笑点 → `humor-design.md` → 玩梗技巧
   - 需要爽点 → `easy-narrative.md` → 升级打脸节奏
   - 需要深度 → `world-building.md` → 伏笔埋设
2. 结合多个技法使用，效果翻倍

### 场景3：人物设计

1. 打开 `character-funny.md`
2. 选择人物类型模板
3. 设计「沙雕表层+反差萌点+隐藏深度」
4. 用对话/行为展示人设

### 场景4：写作辅助

1. 打开 `references/text-generator.md`
2. 选择对应场景模板（开篇/场景/对话/打脸）
3. 填入具体设定
4. 生成初稿后用技法文件优化

## 核心心法

> **「让读者笑着看下去，比哭着看下去更难」**
> 
> 沙雕不是目的，是手段。让读者在轻松愉快的氛围中追更，在哈哈哈中追到最新章，在不知不觉中被世界观震撼。
> 
> **最高境界**：读者以为在看沙雕文，看到最后发现是神作。
