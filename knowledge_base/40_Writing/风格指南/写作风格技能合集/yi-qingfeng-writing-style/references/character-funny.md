# 搞笑人设塑造技法

> 核心心法：「最让人印象深刻的人，是笑着哭的人」

---

## 一、人物三层结构

### 1.1 冰山模型

```
┌─────────────────────────────────────┐
│           表层（一眼可见）            │
│  口头禅/行为模式/外表特征/搞笑方式    │
│  → 读者第一眼看到的"沙雕人设"        │
├─────────────────────────────────────┤
│           中层（互动中了解）          │
│  能力/背景/性格/立场/关系            │
│  → 通过剧情慢慢展示的"立体人设"      │
├─────────────────────────────────────┤
│           深层（揭秘时震撼）          │
│  隐藏的过去/内心伤痛/真实目的/深层动机│
│  → 后期揭示的"有故事的人设"          │
└─────────────────────────────────────┘

核心理念：表面让人喜欢，深层让人震惊
```

### 1.2 展示节奏

| 层次 | 展示时机 | 展示方式 | 篇幅 |
|------|----------|----------|------|
| **表层** | 第一章 | 口头禅/行为/外貌 | 100字内 |
| **中层** | 前50章 | 通过事件/对话/战斗展示 | 贯穿全文 |
| **深层** | 50-150章 | 通过揭秘/回忆/转折揭示 | 高潮章节 |

## 二、人物类型库

### 2.1 主角类型

| 类型 | 特点 | 笑点来源 | 爽点来源 | 范例 |
|------|------|----------|----------|------|
| **沙雕流** | 天生搞笑 | 自身言行 | 沙雕方式成功 | 自带笑点 |
| **吐槽流** | 毒舌属性 | 吐槽他人 | 嘴炮打脸 | 靠说话赢 |
| **淡定流** | 波澜不惊 | 反应反差 | 淡定打脸 | 面瘫型 |
| **认真流** | 一本正经 | 认真干沙雕事 | 正经赢 | 认真型 |

**主角设计公式**：
```
主角 = 【沙雕表面】+ 【隐藏实力/背景】+ 【核心原则】

示例：
沙雕表面：爱开玩笑、爱吐槽、爱搞事
隐藏实力：隐藏身份/血脉/能力
核心原则：有自己的底线/追求/执念
```

### 2.2 系统/NPC类型

| 类型 | 特点 | 笑点来源 | 互动方式 |
|------|------|----------|----------|
| **抖M系统** | 被主角欺负 | 系统被怼/认怂 | 主角 vs 系统 |
| **沙雕系统** | 任务很沙雕 | 系统本身的设定 | 完成任务 |
| **毒舌系统** | 喜欢嘲讽主角 | 系统怼主角 | 互怼 |
| **正经系统** | 认真工作型 | 与主角的沙雕形成反差 | 认真配合 |

**系统设计公式**：
```
系统 = 【外表】+ 【性格】+ 【隐藏设定】

示例：
外表：萌萌哒/酷酷/没有形象
性格：抖M/毒舌/正经
隐藏设定：真正的身份/目的
```

### 2.3 配角类型

| 类型 | 作用 | 笑点模式 | 与主角关系 |
|------|------|----------|------------|
| **沙雕队友** | 搞笑+辅助 | 搭档互怼/组合笑料 | 兄弟/闺蜜 |
| **正经配角** | 衬托+推动 | 反差笑点 | 竞争/合作 |
| **反派沙雕** | 反派搞笑担当 | 作死式嘲讽 | 被打脸 |
| **神秘大佬** | 伏笔+震惊 | 前期正经后期沙雕/前期沙雕后期正经 | 导师/坑 |

## 三、人物设计模板

### 3.1 沙雕人设模板

```
【模板结构】

名字：（要有梗/记忆点）
口头禅：（沙雕/搞笑/标志性的）
外表特征：（一眼能认出来的）
行为模式：（固定的搞笑行为）
核心反差：（表面沙雕/深层认真or强大）
隐藏设定：（后期揭秘）

【示例】

名字：大力
口头禅："我这一拳下去，你可能会死"
外表：普通青年，但眼神很认真
行为：认真对待每件沙雕的事
反差：看似沙雕，实则深藏不露
隐藏：曾是顶级强者的转世
```

### 3.2 深度人设模板

```
【模板结构】

表层设定：
- 名字/外貌/口头禅
- 表面性格/表面目的

中层设定：
- 真实性格
- 真实能力
- 真实背景

深层设定：
- 隐藏的过去/伤痛
- 真正的动机
- 与主角的关系深层

【示例】

表层：搞笑恶魔，抖M体质，喜欢认怂
中层：最强恶魔，真实实力被封印
深层：曾与主角有羁绊，为了主角自封实力
```

### 3.3 人物关系设计

```
【常见关系类型】

1. 兄弟型
   - 日常互怼
   - 关键时刻靠谱
   - 关系铁到互损

2. 主仆型（系统/宠物）
   - 表面主仆，实际沙雕
   - 系统/宠物其实很强
   - 互动充满笑点

3. 师徒型
   - 师父很沙雕
   - 徒弟很正经
   - 沙雕教出正经徒弟

4. 对手型
   - 双方都很强/都很沙雕
   - 竞争中成长
   - 最终惺惺相惜

【关系设计技巧】

关系要"动"：
- 不是静态的朋友/敌人
- 关系要随着剧情发展变化
- 前期可能是敌人，后期是朋友

关系要有"梗"：
- 有专属的互动模式
- 有专属的称呼
- 有专属的回忆
```

## 四、人设展示技法

### 4.1 快速立人设（第一章）

```
【快速人设公式】

一句话人设：用一个场景/动作/对话展示核心人设

示例：
"【沙雕系统】系统：'恭喜宿主获得SSR级神器！'主角：'这不就是个挖耳勺吗？'系统：'这是一个能挖出宇宙的挖耳勺。'"

要素：
- 口头禅/语言风格
- 核心性格（通过行为展示）
- 与主角的关系
- 笑点基调

字数：50-100字即可完成初步人设
```

### 4.2 人设加深（日常互动）

```
【日常立人设】

方式1：通过吐槽立人设
A吐槽B的某个特点 → B的反应 → 形成记忆点

方式2：通过事件立人设
面对某个情况 → 角色如何反应 → 展示性格

方式3：通过回忆立人设
NPC提起往事 → 展示角色另一面 → 埋设伏笔

方式4：通过能力立人设
使用能力时 → 展示性格/习惯 → 形成标签
```

### 4.3 深层揭秘技法

```
【揭秘时机】

- 大战之后
- 遇到危机
- 回忆触发点
- 主角质疑

【揭秘方式】

方式1：直接揭露
通过对话/回忆直接说明深层设定

方式2：行为暗示
关键时刻的行为暴露真实性格

方式3：他人视角
通过其他角色的认知揭露真相

方式4：对比揭露
表层和深层形成强烈对比

【揭秘节奏】

- 不能太早（没有积累）
- 不能太晚（读者忘了）
- 要有铺垫（多次暗示）
- 要有爆发（揭秘时情绪到位）
```

## 五、人物刻画技巧

### 5.1 对话设计

```
【沙雕对话公式】

1. 正话反说
   "你是我见过最强的对手" → "你是我见过最弱的"

2. 一本正经说沙雕
   "根据我的计算，你有0.0001%的胜率" → "那我就是那0.0001"

3. 前后反差
   前面很嚣张 → 后面秒认怂

4. 谐音梗/双关语
   利用角色名字/能力名做梗

5. Call back
   之前的对话/事件再次出现，产生笑点
```

### 5.2 动作设计

```
【动作设计公式】

动作 + 内心OS + 结果 = 搞笑效果

示例：
动作：主角摆了个自认为很帅的姿势
内心：内心独白很正经/很中二
结果：结果很沙雕/很尴尬

公式扩展：
沙雕动作 + 认真态度 + 强大效果 = 装逼打脸
普通动作 + 搞笑态度 + 普通效果 = 日常搞笑
```

### 5.3 内心独白设计

```
【内心独白类型】

类型1：吐槽型
- 对当前情况吐槽
- 对他人行为吐槽
- 自我吐槽

类型2：中二型
- 自认为很帅
- 自认为很酷
- 实际上很尴尬

类型3：分析型
- 认真分析局势
- 分析对手
- 但分析结论很沙雕

类型4：纠结型
- 内心两个小人在打架
- 纠结要不要做某事
- 纠结结果很搞笑
```

## 六、人物检查清单

### 6.1 主角检查

```
□ 口头禅/语言风格有记忆点吗？
□ 外表特征一眼能认出来吗？
□ 核心性格通过行动展示了吗？
□ 有反差萌点吗？（表面+深层）
□ 有隐藏设定吗？（后期揭秘）
□ 与其他角色的关系清晰吗？
□ 笑点来源明确吗？
□ 爽点来源明确吗？
```

### 6.2 配角检查

```
□ 有存在的必要吗？（推动剧情/提供笑点）
□ 与主角的关系有发展吗？
□ 有自己的目标/立场吗？
□ 有自己的笑点模式吗？
□ 后期有发展空间吗？
□ 可以被记住吗？（区别于其他配角）
```

### 6.3 反派检查

```
□ 有威胁感吗？（不能太弱）
□ 有性格特点吗？（沙雕/阴险/中二）
□ 有自己的逻辑吗？（为什么是反派）
□ 会成长吗？（与主角共同进步）
□ 被打脸时够爽吗？
□ 后期会洗白/有反转吗？
```

## 七、实战模板

### 7.1 系统登场模板

```
【系统登场模板】

场景：主角获得系统
字数：300-500字

结构：
1. 系统出现（100字）
   - 方式要特别/搞笑
   - 立刻建立系统的性格

2. 系统自我介绍（100字）
   - 用沙雕方式介绍功能
   - 穿插笑点

3. 主角反应（100字）
   - 吐槽/接受/质疑
   - 展示主角性格

4. 第一个任务（200字）
   - 任务本身很沙雕
   - 但奖励很正经
   - 设置钩子

示例：
"叮！恭喜宿主获得'沙雕系统'！"
"本系统致力于让宿主用沙雕的方式走上人生巅峰！"
"......"主角沉默三秒，"所以我绑了个沙雕？"
"叮！检测到宿主吐槽系统，奖励新手大礼包！"
"是否打开？"
"打开。"
"恭喜获得：大力饮料×1，'我大力了'技能×1，沙雕称号×1！"
```

### 7.2 沙雕队友登场模板

```
【队友登场模板】

场景：新队友加入
字数：500-800字

结构：
1. 铺垫（100字）
   - 为什么会出现新队友
   - 制造期待

2. 初次登场（200字）
   - 用一个场景展示人设
   - 口头禅/行为模式

3. 与主角互动（300字）
   - 互怼/吐槽
   - 形成组合
   - 设置后续笑点

4. 留下悬念（200字）
   - 暗示队友有隐藏
   - 设置钩子

示例：
新队友登场，开口第一句沙雕台词
↓
主角吐槽
↓
两人互怼
↓
发现意外共同点（都沙雕）
↓
暗示队友背景不凡
```

---

*核心原则：人物是让读者记住你的书的最重要因素。一个好的沙雕人设让读者记住你，一个有深度的沙雕人设让读者爱上你的书。*
