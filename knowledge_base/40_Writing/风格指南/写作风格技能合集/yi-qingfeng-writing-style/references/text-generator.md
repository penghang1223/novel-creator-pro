# 弈青锋文风文本生成器

> 核心心法：「模板是骨架，填充是血肉，改编是灵魂」

---

## 一、开篇生成器

### 1.1 黄金开篇模板

```
【模板结构：5段式开篇】

┌─ 第1段：场景建立（100-150字）─┐
│ 建立时间、地点、氛围            │
│ 用沙雕方式描述                  │
│ 环境描写要简洁                  │
└─────────────────────────────────┘
     ↓
┌─ 第2段：金手指登场（100-150字）─┐
│ 系统/能力出现的契机              │
│ 用幽默方式呈现                  │
│ 立刻建立主角与系统的互动模式     │
└─────────────────────────────────┘
     ↓
┌─ 第3段：人设展示（100-150字）─┐
│ 通过对话/内心展示主角性格         │
│ 至少1个笑点                     │
│ 口头禅/行为模式的雏形           │
└─────────────────────────────────┘
     ↓
┌─ 第4段：冲突/目标（100-150字）─┐
│ 明确本章/本段的核心冲突          │
│ 主角面临的问题/挑战             │
│ 目标明确                        │
└─────────────────────────────────┘
     ↓
┌─ 第5段：钩子设置（50-100字）─┐
│ 结尾设悬念                       │
│ 引发好奇                        │
│ 让读者想看下一章                 │
└─────────────────────────────────┘

总字数：500-800字（建议第一章3章内完成）
```

### 1.2 开篇模板库

#### 模板A：地摊流开局
```
【适用场景】系统流、卖货流、搞笑流

【模板】
穿越/觉醒 + 获得【地摊系统】+ 地摊开业 + 第一单出奇效

【填充示例】
{{主角}}穿越到{{世界}}，本以为要逆天改命，结果获得一个"地摊系统"。

"叮！欢迎使用地摊系统！本系统致力于让宿主靠摆地摊走上人生巅峰！"

{{主角}}看着新手礼包里的"大力饮料"×3，嘴角抽搐。

"这...这玩意儿有用？"

第一单，{{主角}}把大力饮料卖给了一个看起来很虚的路人甲。

三天后，路人甲成了本地最强者，到处宣扬"喝了大力，天下第一"。

{{主角}}看着自己的账户余额："......继续摆摊。"

【可替换元素】
- 主角：可以是任意穿越者/觉醒者
- 世界：玄幻大陆/都市异能/仙侠世界
- 商品：大力饮料/大聪明药水/幸运星符咒
- 第一单客户：可以是隐藏大佬/可爱少女/逗比反派
```

#### 模板B：沙雕系统开局
```
【适用场景】系统文、轻松流、吐槽流

【模板】
觉醒 + 沙雕系统出现 + 第一个沙雕任务 + 主角沙雕应对

【填充示例】
{{主角}}觉醒的时候，天空没有异象，大地没有震动，就是普普通通的醒了过来。

然后脑海中响起一个声音：

"叮！恭喜宿主觉醒！您获得了——呃......系统好像出了点问题......"

{{主角}}："......"

"抱歉，刚才系统卡了，重新来一遍。"

"叮！恭喜宿主觉醒，获得'最强沙雕系统'！本系统将帮助宿主成为最沙雕的......沙雕！"

"......所以我觉醒了个沙雕？"

"叮！检测到宿主吐槽系统，触发惩罚机制！"

"惩罚内容：宿主必须完成一个沙雕任务！"

【可替换元素】
- 系统性格：抖M/毒舌/沙雕/正经
- 惩罚任务：可以是任意沙雕内容
- 系统外观：虚拟形象/无形象/声音
```

#### 模板C：反差流开局
```
【适用场景】废柴流、转世流、高手流

【模板】
表面废柴身份 + 隐藏背景暗示 + 遇到第一个冲突 + 即将打脸

【填充示例】
在{{地名}}，没有人不知道{{主角}}的名字——倒不是因为他是天才，而是因为他是最废物的那个。

"{{主角}}？哦，那个连广场舞大妈都打不过的废物啊。"

{{主角}}每次听到这种评价，都只是笑笑。

他没说的是，他其实是{{隐藏身份}}的{{身份}}，这次下凡是来{{目的}}的。

不过现在，他只想安静地当个废柴。

直到今天——

{{冲突事件}}，那个欺负他三年的人又来了。

"废物，今天怎么不跑了？"

{{主角}}抬起头，露出一个意味深长的笑容。

"今天不跑了。"

"因为......我饿了。"

【可替换元素】
- 隐藏身份：上古大能转世/顶级世家子弟/神明分身
- 废柴原因：封印/修炼特殊功法/伪装
- 冲突事件：可以是任意打脸场景
```

### 1.3 开篇检查清单

```
□ 300字内有笑点？
□ 500字内金手指/系统出现？
□ 有完整的人设雏形？
□ 有明确的目标/冲突？
□ 结尾有钩子/悬念？
□ 没有大段设定/背景介绍？
□ 节奏够快？
□ 主角性格突出？
```
