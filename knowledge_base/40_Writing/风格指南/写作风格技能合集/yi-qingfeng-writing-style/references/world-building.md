# 世界观构建技法

> 核心心法：「沙雕是皮，设定是骨，故事是魂」

---

## 一、弈青锋世界观结构

### 1.1 三层世界模型

```
┌─────────────────────────────────────┐
│           表层（沙雕外壳）            │
│  看似荒诞的设定、搞笑的能力、不正经的NPC │
│  例：卖大力系统、沙雕恶魔            │
├─────────────────────────────────────┤
│           中层（完整逻辑）            │
│  力量体系、势力划分、世界规则          │
│  例：等级制度、资源体系、历史背景      │
├─────────────────────────────────────┤
│           深层（隐藏真相）            │
│  隐藏的悲剧、埋藏的阴谋、终极伏笔      │
│  例：世界的真相、主角的宿命、反派的过去 │
└─────────────────────────────────────┘

核心理念：表层让读者笑着读，中层让读者相信这个世界，
          深层让读者被震撼
```

### 1.2 层级展示节奏

| 阶段 | 展示层级 | 方式 | 篇幅 |
|------|----------|------|------|
| **前期**（1-50章） | 表层为主 | 搞笑、轻松 | 70% |
| **中期**（50-150章） | 表+中层 | 逐渐展开设定 | 50%+30% |
| **后期**（150章+） | 中+深层 | 揭秘、震撼 | 40%+50% |
| **高潮**（大结局） | 全层展示 | 真相大白 | 完整呈现 |

## 二、力量体系设计

### 2.1 沙雕力量体系模板

#### 模板A：「接地气」型
```
核心理念：最厉害的东西往往最不起眼

力量来源：日常生活/废品/常见物品
力量表现：看似普通实则逆天

示例：
- "大力"：一瓶普通的饮料，喝了力气变大
- "垃圾分类"：分类能力成为最强技能
- "网购"：网络购物能力，买到神器

优势：容易引发共鸣，笑点密集
劣势：后期升级需要突破日常感
```

#### 模板B：「反差」型
```
核心理念：最强的东西有最拉胯的名字

设定思路：
- 名字很沙雕，实力很强大
- 外表很可爱，内核很恐怖
- 效果很离谱，原理很正经

示例：
- "沙雕大法"：名字沙雕，威力最强
- "表情包攻击"：用表情包打败敌人
- "嘴炮"：说话就能造成真实伤害

优势：反差感强，记忆点深
劣势：需要平衡笑点和战斗力
```

#### 模板C：「系统」型
```
核心理念：系统本身成为世界观的一部分

系统类型：
- 沙雕系统（系统很沙雕）
- 抖M系统（系统被主角欺负）
- 反套路系统（任务都很离谱）

示例：
《开局地摊卖大力》的系统：
- 卖东西就能变强
- 卖的东西都很沙雕
- 但效果都很逆天

优势：易于设计剧情推进
劣势：容易套路化
```

### 2.2 等级体系设计

```
【基础原则】
1. 等级要有特色名字（不用1234）
2. 每个等级要有专属标志/特征
3. 升级要有明确标准
4. 不同等级之间有明显差距感

【推荐格式】

┌─ 等级名称 ─┬─ 标志特征 ─┬─ 差距感 ─┐
│ 青铜       │ 有专属光效 │ 小怪级别 │
│ 白银       │ 有光效+特效│ 精英级别 │
│ 黄金       │ 有特效+称号│ 强者级别 │
│ 钻石       │ 有特效+领域│ 巨头级别 │
│ 王者       │ 有特效+世界│ 传说级别 │
└───────────┴───────────┴─────────┘

【弈青锋风格改良】
- 等级名字要有梗/梗化
- 升级方式要沙雕+正经结合
- 升级过程要展示主角性格
```

### 2.3 能力设计公式

```
【能力命名】沙雕感 + 强大感的平衡

命名公式：
[沙雕前缀/形容词] + [正经名词] = 沙雕感能力名
[正经前缀/形容词] + [沙雕名词] = 反差感能力名

示例：
沙雕前缀：沙雕、逗比、搞笑、不正经
正经前缀：神、天、元、太古

沙雕感能力：
- "沙雕无敌拳"
- "不正经剑法"
- "逗比领域"

反差感能力：
- "神级大力术"
- "太古沙雕大法"
- "天元搞笑拳"

【能力展示】先搞笑后震撼

展示公式：
1. 名字很搞笑 → 建立期待反差
2. 效果很离谱 → 打破预期
3. 实际上很强 → 建立认知
4. 还有隐藏效果 → 埋下伏笔
```

## 三、势力与势力关系

### 3.1 势力设计模板

```
【基础势力模板】

势力名称：（要有记忆点/梗）
势力性质：（正/邪/中立/搞笑）
势力特点：（用什么方式搞笑/有什么沙雕点）
势力实力：（强/中/弱，与搞笑程度无关）
隐藏秘密：（让势力有深度）

【示例模板】

【沙雕势力】
名称：逗比宗（谐音梗）
性质：表面沙雕，实际很强
特点：收徒标准很沙雕（看谁更沙雕）
实力：顶级宗门
秘密：上古大能建立的，表面搞笑实际在培养真正的强者

【正经势力】
名称：青云门
性质：名门正派
特点：严肃认真，一本正经
实力：顶级宗门
秘密：高层其实知道逗比宗是真正强者
```

### 3.2 势力关系设计

```
【核心关系公式】

势力A ←(关系)→ 势力B
  ↓           ↓
【表层关系】 【深层关系】

示例：
表层：逗比宗是笑话，青云门是正道
深层：逗比宗是隐藏boss，青云门是明面担当

【常见势力关系】
- 正邪对立（表）- 实际合作（深）
- 世仇关系（表）- 共同阴谋（深）
- 搞笑担当（表）- 真正强者（深）
```

### 3.3 势力展示节奏

| 阶段 | 展示内容 | 展示方式 | 深度 |
|------|----------|----------|------|
| 开局 | 主角所在势力 | 日常+搞笑 | 浅 |
| 前期 | 1-2个对立势力 | 冲突+战斗 | 中 |
| 中期 | 3-5个势力 | 纵横捭阖 | 中深 |
| 后期 | 所有势力 | 合纵连横+揭秘 | 深 |

## 四、世界观展开技法

### 4.1 展开节奏设计

```
【三阶段展开法】

第一阶段：盲人摸象（1-30章）
- 只展示世界的一小部分
- 读者和主角一起探索
- 用局部暗示整体

第二阶段：拼图游戏（30-100章）
- 碎片逐渐增多
- 主角经历多个势力/区域
- 世界观慢慢完整

第三阶段：真相大白（100章+）
- 隐藏设定揭露
- 主角发现真相
- 世界观完整闭环
```

### 4.2 展示技巧

#### 技巧1：景点式展示
```
方法：每个地点展示一个世界设定

示例：
- 主角来到市场 → 展示经济体系
- 主角来到宗门 → 展示等级制度
- 主角来到遗迹 → 展示历史背景

优点：自然不突兀，场景融合好
```

#### 技巧2：冲突式展示
```
方法：通过战斗/竞争展示力量体系

示例：
- 通过战斗展示等级差距
- 通过比试展示能力体系
- 通过争夺展示资源体系

优点：生动印象深刻，战斗爽点+设定同步
```

#### 技巧3：闲聊式展示
```
方法：通过NPC对话展示背景

示例：
NPC1："听说那个遗迹里封印着..."
NPC2："别说了，那是被封印的..."
NPC3："我怎么听说的是..."

优点：信息密度高，可以埋设多个伏笔
```

#### 技巧4：系统式展示
```
方法：通过系统面板展示设定

示例：
系统：【检测到新区域：XXX】
系统：【该区域危险等级：XXX】
系统：【区域特产：XXX】

优点：信息清晰，减少对话水字数
```

### 4.3 伏笔埋设系统

```
【伏笔类型】

类型1：剧情伏笔
- 埋设：某个NPC说的话
- 回收：后期揭示真相
- 适用：阴谋、真相、背景故事

类型2：能力伏笔
- 埋设：某个能力/物品
- 回收：关键时刻发挥
- 适用：金手指、主角成长

类型3：人物伏笔
- 埋设：某个角色的细节
- 回收：后期揭示身份/关系
- 适用：隐藏身份、血缘关系、命运

类型4：世界观伏笔
- 埋设：某个看似无意义的设定
- 回收：揭示世界的真相
- 适用：核心设定、最终boss、世界秘密

【伏笔管理】

埋设原则：
- 有埋必有收
- 埋的浅收的快，埋的深收的慢
- 重要伏笔要多次暗示

回收节奏：
- 小伏笔：1-10章内回收
- 中伏笔：10-50章回收
- 大伏笔：50章+回收
```

## 五、世界观设计检查清单

### 5.1 设计阶段检查

```
□ 力量体系完整吗？（等级/能力/资源）
□ 势力体系合理吗？（有正有邪有中立）
□ 地理设定清晰吗？（有多少个区域）
□ 历史背景存在吗？（世界的过去）
□ 核心矛盾存在吗？（世界的主要冲突）
□ 有隐藏真相吗？（让后期有爆发点）
□ 设定有记忆点吗？（能让人记住的梗/设定）
```

### 5.2 写作阶段检查

```
□ 设定与剧情融合了吗？（不单独写设定章）
□ 笑点与世界观结合了吗？（沙雕外壳）
□ 中后期有揭秘空间吗？（深层设定）
□ 主角成长空间够吗？（从弱到强）
□ 势力冲突有戏剧性吗？（矛盾推动剧情）
```

## 六、实战模板

### 6.1 新地图/新区域开场模板

```
【模板结构】

1. 场景建立（200字）
   - 新地点的外观
   - 与之前地点的差异
   - 用沙雕方式描述

2. 设定展示（500字）
   - 该区域的特点/规则
   - 通过NPC或场景暗示
   - 穿插1-2个笑点

3. 冲突/任务（1000字）
   - 新任务/新敌人
   - 展示新力量体系
   - 收获与伏笔

4. 结尾钩子（300字）
   - 本章收获
   - 新悬念/新威胁
   - 期待感

字数：约2000字
```

### 6.2 世界观揭秘章节模板

```
【模板结构】

1. 铺垫（500字）
   - 触发揭秘的条件
   - 暗示即将揭示的内容
   - 紧张感/期待感

2. 揭示（1000字）
   - 真相/秘密展示
   - 信息密度高
   - 可以有1-2个反转

3. 反应（500字）
   - 主角/配角的反应
   - 与之前伏笔呼应
   - 情绪爆发

4. 后续影响（500字）
   - 对后续剧情的影响
   - 新的目标/威胁
   - 埋设新伏笔

字数：约2500字
```

*核心原则：世界观是让读者沉浸的框架，沙雕是吸引读者的外衣。最好的世界观是读者读完都不知道你埋了多少设定在里面。*
