# 一月九十秋写作风格技能

## 风格概述

**一月九十秋**，番茄小说金番作家（22万粉丝），代表作《诸神愚戏》。其风格以"克苏鲁+末日欺诈"为核心，主打"智斗反转"与"规则即武器"的高概念创作，以反套路著称。

### 核心风格公式

```
克苏鲁恐怖 × 赛博朋克 × 民俗元素 = 末世欺诈美学
谎言成真能力 + 规则漏洞利用 = 以凡人之躯戏耍神明
```

---

## 四大核心技法

### 1. 高概念世界观设计
将不可名状的克苏鲁神明与人类规则体系融合，创造"神明可被欺骗"的颠覆性设定。

### 2. 欺诈成神系统
构建"谎言成真"类能力体系，主角通过发现、利用规则漏洞实现越级挑战。

### 3. 智斗反转技法
多层反转结构，每一场战斗都是心理博弈，规则本身成为武器。

### 4. 末日背景构建
末世生存与神明博弈交织，资源匮乏与人性考验并行。

## 风格检测清单

创作时可对照以下清单进行自检：

| 要素 | 是否具备 | 说明 |
|------|----------|------|
| 神明的不可名状感 | □ | 神明应有超越人类认知的特征 |
| 规则体系的完整性 | □ | 能力有明确限制和漏洞 |
| 反转的必然性 | □ | 反转应基于前文埋下的伏笔 |
| 末日氛围的压抑感 | □ | 资源匮乏、生死一线的紧张感 |
| 智斗的烧脑感 | □ | 读者应能参与到博弈中 |
| 反套路的新鲜感 | □ | 避免传统升级打怪套路 |
