# 末日背景设计

## 设计理念

**一月九十秋**的末日不是简单的"世界毁灭"，而是"规则崩坏后的世界"。神明仍然存在，但它们的规则不再庇护人类。末日是背景，更是主角生存策略的来源。

### 末日背景的三层构建

```
┌─────────────────────────────────────────┐
│         【表层】末日的表现形式             │
│     天灾、资源枯竭、规则崩坏               │
├─────────────────────────────────────────┤
│         【中层】末日下的人类处境           │
│   新秩序的建立、生存规则的变化             │
├─────────────────────────────────────────┤
│         【深层】末日的成因与真相           │
│   与神明的关联、隐藏的希望                 │
└─────────────────────────────────────────┘
```

## 末日的五种类型

### 类型一：神明休眠型

```
特征：神明仍然存在，但进入"休眠"
影响：规则失去效力，旧秩序崩塌
机遇：神明的监控减弱，反抗成为可能
```

```markdown
【设计模板】
末日后，天空裂开了一道缝。
从那道缝里，涌出了[某种现象]。

从那天起，神明不再回应祈祷。
不是因为祂们死了——
而是因为祂们"睡着了"。

沉睡的原因：[某个关键信息]
沉睡的持续时间：[某种限制]
醒来后会发生什么：[伏笔]
```

### 类型二：规则冲突型

```
特征：多个神明的规则相互冲突
影响：某些区域规则重叠，某些区域无规则
机遇：规则冲突产生"灰色地带"
```

```markdown
【设计模板】
[神明A]的信徒踏入[神明B]的领地。
[神明A]的规则："不可伤害信徒"
[神明B]的规则："入侵者必诛"

当两个规则相遇——
[展示冲突的结果]

这种冲突产生的区域，被称为"灰色地带"。
在灰色地带里，[某种可能性]成为现实。
```

### 类型三：信仰崩溃型

```
特征：神明依赖信仰维持存在
影响：人类不再信仰，神明力量衰退
机遇：神明变弱了，但仍未消亡
```

```markdown
【设计模板】
"神需要信仰。"
[某个角色的台词]
"就像人需要食物一样。"
"但现在——"

主角看向窗外。
那里有一座废弃的神殿。
曾经，香火鼎盛。
现在，蛛网密布。

"人类学会了不祈祷。"
"不是因为勇敢。"
"而是因为——"
"祈祷没有用。"
```

### 类型四：末世天灾型

```
特征：末日以自然灾害的形式呈现
影响：生存环境极度恶化
机遇：在极端环境中，某些能力被放大
```

```markdown
【设计模板】
【末日历·第三年】

天空的颜色：[描述]
太阳的出现频率：[描述]
可耕种土地的面积：[描述]
人类的平均寿命：[描述]

在这片土地上，"活着"本身就是一种奢侈。

但即便如此——
仍然有人在挣扎。
仍然有人在希望。
仍然有人在寻找——
改变这一切的方法。
```

### 类型五：神弃之地型

```
特征：神明不愿/无法踏足的区域
影响：规则在这里失效
机遇：唯一人类可以喘息的地方
```

```markdown
【设计模板】
"神明不喜欢这里。"
向导说。

"为什么？"主角问。

"因为这里的规则是——"
向导指了指脚下。
"'神明不可干涉'。"
"不是'不能'，是'不可'。"
"是祂们自己加给自己的限制。"

"为什么祂们要限制自己？"

向导沉默了很久。
"这就是为什么这里是'神弃之地'。"
"也是为什么——"
"只有这里，还有人活着。"
```

## 末日氛围营造技法

### 技法一：对比反衬

```markdown
【公式】
曾经美好的事物 vs 现在的残骸
= 末日的残酷

【示例】
窗外曾经是一片麦田。
金色的麦浪，在风中起伏。
现在——
是一片灰烬。
偶尔有几株杂草从灰烬中钻出。
顽强地绿着。
像是在嘲笑什么。
```

### 技法二：细节暗示

```markdown
【公式】
一个细小的物件 + 它的"前世今生"
= 末日的人情味

【示例】
主角路过一栋废墟。
废墟里有一张照片。
照片上是一个家庭。
笑容灿烂。
旁边写着：[某种文字]

主角没有停留。
他只是把照片捡起来。
放在一个避风的地方。

"入土为安。"他说。
"照片也算。"
```

### 技法三：规则倒置

```markdown
【公式】
末日前的"常识" vs 末日后的"常识"
= 世界已经变了

【示例】
末日前："太阳下山了，该睡觉了。"
末日时："太阳下山了，该躲起来了。"

末日前："遇到危险，喊救命。"
末日时："遇到危险，闭嘴。"

末日前："人应该互相帮助。"
末日时："——"

没有人说话。
因为在末日里，"帮助"有时候意味着——
"一起死。"
```

### 技法四：希望微光

```markdown
【公式】
压抑到底 + 一丝希望
= 让人想读下去的动力

【示例】
末日第三年。
一切都糟透了。
但——
远处有一座灯塔。
灯塔还亮着。

"那是什么？"

"不知道。"
"有人说，那里有[某种东西]。"

"你信吗？"

沉默了很长时间。

"……不管信不信，"
"至少——"
"那是唯一一个，还亮着的灯。"
```
