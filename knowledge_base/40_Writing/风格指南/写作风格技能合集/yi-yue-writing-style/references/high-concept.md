# 高概念世界观设计

## 设计理念

**一月九十秋**的世界观核心是"神明可被欺骗"。打破传统克苏鲁"不可战胜、不可理解"的设定，引入"规则漏洞"概念，让凡人有对抗神明的可能。

### 核心设计公式

```
【不可名状】+ 【可被理解】+ 【存在漏洞】= 一月九十秋式神明
```

---

## 世界观架构

### 1. 神明层级的三重结构

```
┌─────────────────────────────────────────┐
│           【表层】人类可接触的规则        │
│   神明的"契约"、信徒的祈祷、神迹的代价   │
├─────────────────────────────────────────┤
│           【中层】神明运行规律            │
│   能力体系的限制、力量来源的依赖          │
├─────────────────────────────────────────┤
│           【深层】神明的本质与限制        │
│   神明的"职责边界"、存在的前提条件        │
└─────────────────────────────────────────┘
```

**设计要点**：
- 表层给主角"钻空子"的机会
- 中层揭示能力体系的内在逻辑
- 深层暗示神明并非全知全能

### 2. 融合元素的配方

| 元素 | 作用 | 一月九十秋式运用 |
|------|------|-----------------|
| 克苏鲁 | 不可名状的恐惧 | 神明的外在形态超越人类认知 |
| 赛博朋克 | 规则与系统的复杂性 | 能力体系的数字化/规则化呈现 |
| 民俗/克系本土化 | 文化代入感 | 融入本土神话元素进行解构 |

### 3. 世界观设计的五步法

```
Step 1: 确定神明的"职责边界"
    ↓ 神明掌管什么？有什么绝对不能做的事？
Step 2: 设定"规则代价"
    ↓ 人类使用神明力量需要付出什么？
Step 3: 设计"规则漏洞"
    ↓ 在代价和收益之间寻找逻辑缝隙
Step 4: 构建"信仰体系"
    ↓ 信徒如何传递信息？信息是否会被扭曲？
Step 5: 埋设"末日背景"
    ↓ 为什么现在人类需要对抗神明？
```

## 高概念场景设计模板

### 模板一：神明交易场景

```markdown
【场景要素】
- 神明的外在呈现：[外观描写，越不可名状越好]
- 交易的规则：[神明给出的条件]
- 隐藏的漏洞：[主角发现的逻辑漏洞]
- 交易的代价：[通常很荒诞但细思极恐]

【示例框架】
"祂没有脸——或者说，有太多的脸。
那些脸像是被揉皱又展开的纸，每一张都在说话，又什么都说不清。

'凡人，你想要什么？'

[主角提出的要求]

'可以。'
无数张嘴同时开合，'但你必须[付出代价]——'
[代价描述]

他忽然明白了什么。
[漏洞解析]
"
```

### 模板二：规则体系展示场景

```markdown
【场景要素】
- 能力的名称：[要有规则感/契约感]
- 激活条件：[需要满足什么？]
- 能力效果：[具体能做到什么]
- 使用限制/代价：[什么情况下不能使用/需要付出什么]

【示例框架】
"【守夜人守则·第七条】
当你在黑暗中看见第三只眼睛，即可在眼睛闭合的瞬间消失。

前提：
一、消失距离不得超过目视范围的三倍
二、消失后必须立刻说出所见之物的"真名"
三、每日仅限使用三次

代价：
你的影子会记住这一次。
"
```

### 模板三：末日世界观呈现场景

```markdown
【场景要素】
- 末日的表现形式：[天灾/神罚/资源枯竭/规则崩坏]
- 普通人的生存状态：[日常的绝望感]
- 新秩序/规则：[主角所处环境的规则]
- 隐藏的希望：[为什么反抗是可能的]

【示例框架】
"末日后第三年。
天空是灰色的，像被稀释的墨汁。
太阳每个月只出现两三次，每次不超过三个小时。
其余时间，是永无止境的'迷时'——

在迷时中游荡的东西，我们称之为'迷神'。
它们不是神，但会回应祈祷。
只不过，回应祈祷的方式是——

[某种恐怖的细节]

这就是'神弃之地'。
神明不愿踏足的地方。
或者说，它们没法在这里维持'神明'的状态。
"
```

## 世界观检查清单

- [ ] 神明是否有明确的"职责边界"？
- [ ] 神明的力量是否有代价？
- [ ] 代价与收益之间是否存在逻辑漏洞？
- [ ] 凡人对抗神明的理论可能性是什么？
- [ ] 末日背景是否与神明存在形成因果关系？
- [ ] 规则体系是否足够复杂但不失公平？

## 经典案例拆解：《诸神愚戏》世界观

| 要素 | 《诸神愚戏》设计 | 可借鉴点 |
|------|-----------------|---------|
| 神明定义 | 神明是"规则的人格化" | 将能力体系抽象化 |

| 反抗可能 | "欺骗神明"的核心设定 | 给出具体的方法论 |
