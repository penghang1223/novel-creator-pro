# 文风文本生成器

## 设计理念

**一月九十秋**的文风特点是：克苏鲁式不可名状的恐惧、末日生存的压抑感、智斗反转的烧脑感、以及偶尔的黑色幽默。整体基调冷峻、克制，但偶有温情的瞬间。

### 文风四要素

```
【冷峻】克苏鲁式客观描述，克制情感表达
【压抑】末日生存的绝望感贯穿始终
【烧脑】智斗对话充满逻辑博弈
【黑色幽默】绝望中的人性闪光
```

## 一、开篇生成模板

### 模板一：末日氛围开篇

```markdown
【模板要素】
- 时间设定：末日后第X年
- 环境描写：灰色的世界
- 主角状态：某种生存状态
- 核心悬念：暗示主线

【生成框架】

末日后第[数字]年。
[X]月。
[X]日。

这是[某种计数方式]。

"为什么要记录日期？"新人问。
"[因为]，"
"[老手]回答，"
"'[不是为了记住，而是为了——]'"
"[老手看向窗外。]"
"[窗外是——描述]。"
```

### 模板二：神明降临开篇

```markdown
【模板要素】
- 神明的出场：不可名状的恐怖
- 环境反应：异常现象
- 主角视角：初见/已知
- 规则暗示：某种"规则"即将出现

【生成框架】

那天，天空裂开了一道缝。
不是比喻。
是真的裂开。
像是被什么东西——撕开的。

裂缝里伸出了[某种描述]。
[2-3句话描写那个"东西"，越不可名状越好]

然后，它开口了。
或者，那算是"开口"。
[描述"说话"的方式]

"——[第一句话，或者沉默]"

整个城市都听见了。
但没有人听懂。
只有我——
[主角的反应/理解/或困惑]
```

### 模板三：规则展示开篇

```markdown
【模板要素】
- 规则来源：某个神明/系统/契约
- 规则的呈现方式：文字/口述/显现
- 主角的理解：第一反应
- 悬念：规则的漏洞在哪里？

【生成框架】

[规则名称]·第[数字]条

[完整展示规则内容]

规则的最后一行写着：
"[某种限制或代价]"

主角盯着那些字。
看了很久。

"有问题。"他低声说。
"哪里有问题？"[旁边的人问]
"这里——"他指着[某个词/某句话]
"这个[词/句]的定义是——"
"[重新定义]"

所以，实际上——
"[重新解读后的规则]"
```

当你放弃时，它又——

是直接在脑子里响起的。

[心理]

不是疼。
是某种……共振。
好像你的脑子里有什么东西——
在回应它。

[规律]

## 三、智斗对话模板

### 模板一：规则质疑对话

```markdown
【对话结构】
1. 提出质疑
2. 引用规则
3. 指出漏洞
4. 逻辑论证
5. 等待反应/逼迫回应

【生成框架】

"等等。"
主角抬手。

"您说'[原话]'，"
"那请问——"
"'[关键词]'的定义是什么？"

[沉默]

"是'[常规定义]'吗？"
"还是说——"
"'[另一种可能的定义]'？"

[对手的微表情变化]

"如果按照'[另一种定义]'理解，"
"那'[原规则的推论]'——"
"就不成立了。"

[对手的反应]

"您不说话？"
"是默认了？"
"还是——"
"您也发现这个问题了？"
```

### 模板二：逻辑陷阱对话

```markdown
【对话结构】
1. 设置前提
2. 引导推理
3. 得出荒谬结论
4. 反转归谬

【生成框架】

"我问你一个问题。"
主角说。

"如果您'[行为 A]'，"
"那么，根据规则'[X]'——"
"'[结论 1]'。"

"反过来，如果您不'[行为 A]'，"
"那么，根据规则'[Y]'——"
"'[结论 2]'。"

[停顿]

"而'[结论 1]'和'[结论 2]'——"
"是矛盾的。"

[观察对手的反应]

"所以，有两种可能："
"第一，您的'[某个前提]'是错的。"
"第二——"
"'[规则 X]'或'[规则 Y]'本身——"
"有问题。"

"您觉得是哪一种？"
```

### 模板三：信息诈欺对话

```markdown
【对话结构】
1. 表面信息
2. 暗示另一层含义
3. 观察解读
4. 利用解读结果

【生成框架】

"我知道你在想什么。"

主角说。
声音平静。
像是在陈述天气。

"你在想——"
"'这个人知道多少？'"
"'他是不是在骗我？'"
"'如果我在骗他，我该怎么利用？'"

[停顿]

"但你错了。"
"不是因为你猜错了。"
"而是因为——"
"'[你猜的那个]'根本不重要。"

[对手的困惑]

"真正的问题是——"
"'[真正的关键信息]'。"
"而这个，你不知道。"

[观察对手的反应：想知道？假装不在乎？]

"想知道吗？"
主角笑了笑。
"但代价是——"
"'[某种代价]'。"
```

## 综合运用示例

### 示例：完整智斗高潮段落

```markdown
"规则是这么写的——"

主角把那张泛黄的纸展示出来。

"'【守夜人公约·第三条】
守夜人不得主动攻击迷神。
如有违背，取消守夜人资格，永不恢复。'"

"所以？"对手冷笑，"你想用这条规则来——"

"等等。"主角打断他，"问题不在'攻击'。"

"那在哪？"

"'迷神'的定义。"

主角指着纸上的那两个字。

"'迷神'，即'在迷时中游荡的神明造物'。"

"这有什么问题？"

"问题在于——"主角笑了，"现在不是'迷时'。"

他把纸收起来。

"'迷时'的定义是'无光时段'。"
"而现在——"

他指了指窗外。
那里，灰色的太阳正在升起。

"有太阳。"
"所以，现在不是'迷时'。"
"所以，这些东西——"

主角看向那些游荡的身影。

"不是'迷神'。"
"只是——'迷时制造的东西'。"

"所以——"

"规则第三条，不适用。"

"我可以攻击它们。"

"而它们——也可以攻击我。"

"公平。"

他抽出刀。

"来吧。"
```

## 注意事项

1. **克苏鲁描写克制点到为止**：不要过度描写，保持神秘感
2. **末日氛围持续但有层次**：压抑中要有微光
3. **智斗逻辑严密**：漏洞要经得起推敲
4. **黑色幽默适度**：绝望中的温情的不是无脑搞笑
5. **网文节奏把控**：每2000-3000字一个情绪起伏点
