### 与 orchestrator 中风格裁决链的对接

在 `novel_creation_promax/references/orchestrator.md` 中声明的风格裁决链，新增24个风格技能后的裁决规则：

```
项目初始化 → style_dna_extractor.py 提取DNA（定量基线）
     ↓
创作前选择 → 风格索引（本文档）选定作者风格 → 读取对应 SKILL.md
     ↓
创作中遵守 → DNA约束 + 对应作者的 text-generator.md
     ↓
创作后检查 → style_calibrator.py 校准偏差（定量裁决）
```

### 风格禁忌（禁止混用）

| 冲突组合 | 原因 | 后果 |
|---------|------|------|
| 孔二狗 × 古龙 | 市井口语 vs 诗意语言 | 风格割裂、人物崩坏 |
| 当年明月 × 古龙 | 说书人唠叨 vs 极简留白 | 叙事节奏冲突 |
| 猫腻 × 孔二狗 | 精致细腻 vs 粗犷直白 | 文风不统一 |
| 烽火 × 天蚕土豆 | 慢热炖文 vs 快节奏打脸 | 节奏完全相反 |
| 古龙 × 烽火 | 极简诗意 vs 华丽典雅 | 语言质感冲突 |

## 五、使用指南

### 场景1：用户指定作家风格
```
用户："用烽火戏诸侯的风格写"
→ 读取：knowledge_base/40_Writing/风格指南/写作风格技能合集/feng-huo-writing-style/SKILL.md
→ 按需读取 references/ 下的对应技法文档
→ 使用 text-generator.md 生成内容
```

### 场景2：用户指定题材但没选风格
```
用户："写一部修真小说"
→ 推荐：耳根（情感细腻）、忘语（凡人流）、辰东（史诗悬念）
→ 让用户选择或默认耳根风格
```

### 场景3：用户想要特定感觉但不知道作家
```
用户："写一个搞笑轻松的"
→ 匹配：卖报小郎君（轻松探案）、弈青锋（沙雕搞笑）、会说话的肘子（脑洞热血）
```

### 场景4：完结复盘后发现风格漂移
```
→ 运行 style_calibrator.py 对比 style_dna.json
→ 偏差≥0.3警告，≥0.5必须重写
→ 对照对应作家的 SKILL.md 检查清单逐项修正
```
