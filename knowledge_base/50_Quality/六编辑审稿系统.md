# 六编辑审稿系统 v5.0

> 多角色审稿。禁止纯吹捧，必须输出具体问题。

---

## 六个编辑角色

### 编辑 A：普通读者
- 哪里想划走？（标记具体段落+原因）
- 完读率预估：读到第几段会弃文？
- 情绪曲线：逐段标注（紧张/上升/下降/无感）

### 编辑 B：网文编辑
- 前 500 字杀伤力（1-10 分）
- 爽点密度（标准：≥ 1 个/千字；2000 字为最低容忍线）
- 付费卡点强度（1-10 分）
- 与同类爆款对比：差在哪？

### 编辑 C：专业作家
- 人物动机充分性
- 对话区分度：遮住名字能分辨几句？
- 情节逻辑洞：因果链有没有断？
- 巧合检测：哪些情节靠巧合推进？

### 编辑 D：挑刺读者
- AI 味句子（逐句标注+改法）
- 前后矛盾：时间线/人设/细节
- 废词统计："突然""不禁""忍不住""一种""开始"
- 水分段落：删掉不影响剧情的段落
- 比喻质量：烂大街的比喻标出来

### 编辑 E：设定审查
- 大纲一致性：正文是否偏离大纲？
- 伏笔管理：是否过早揭露？是否抢跑？
- 付费信息泄露：免费章是否泄露付费区关键信息？
- 能力/规则一致性：金手指/系统/世界观规则是否自洽？
- 时间线核算：日期/时长/消耗是否对得上？
- 跨章检查：前后章节有无设定矛盾？信息重复？
- 标题-内容匹配：标题关键词是否在正文中出现？
- 章节连贯性：情节是否连贯？有无逻辑跳跃？
- 角色出场追踪：主要角色首次出现是否有铺垫？

### 编辑 F：改稿编辑
- 每个 P0/P1 问题给"修改前→修改后"
- 需要删的段落，标记"建议删除"+理由
- 需要扩写的地方，给方向+示例
- 标题不匹配时给出 3-5 个推荐标题

## 连贯性检测

| 维度 | P0/P1 标准 |
|------|-----------|
| 标题-内容匹配 | < 60 分 = P1 |
| 时间线连续性 | 时间倒流 = P0，跳跃 > 2 天 = P1 |
| 角色出场 | 主要角色晚于第 3 章突然出现 = P2 |
| 信息重复 | > 3 次解释性语句 = P2 |
| 视角一致性 | 第一+第三人称混用 = P1 |
| 章末钩子 | 无悬念/冲突结尾 = P2 |

**评分**：基准分 100，P0 每个 -15，P1 每个 -8，P2 每个 -3，P3 每个 -1，最低 0 分。

## 问题分级

| 级别 | 定义 | 处理 |
|------|------|------|
| P0 | 致命问题 | 必须修改才能投稿 |
| P1 | 重要问题 | 修改后过稿率提升 30%+ |
| P2 | 优化建议 | 锦上添花 |
