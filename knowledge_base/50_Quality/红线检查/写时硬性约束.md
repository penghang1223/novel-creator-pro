# 写时硬性约束

**作用**：写作过程中必须实时遵守的硬性指标。审计工具是最终验证，不是返工工具。
**原则**：写完即达标，审计一次过。

---

## 写时计数器（边写边数）

### 1. 字数

| 平台 | 要求 | 写作目标 |
|------|------|----------|
| 番茄 | 2800-3200中文字符 | 写到3000字符左右 |
| 七猫 | 3000-4000字 | 写到3500字左右 |
| 起点 | 2000-3000字 | 写到2500字左右 |

**执行方法**：写完每个场景后**用python实际计数**，不要靠脑子里估算（实测估算偏差可达50%以上）。

```bash
python -c "import re; f=open('文件路径','r',encoding='utf-8').read(); print(len(re.findall(r'[一-鿿]', ''.join([l for l in f.split(chr(10)) if l.strip() and not l.startswith('#')]))))"
```

如果当前场景结束时总字数还差500+，在下一个场景补充细节、心理活动、环境描写。

### 2. 比喻（像）：≤5次

**执行方法**：写的时候心里计数。用到第4次时，后续改用其他修辞手法（拟人、通感、借代、对比）或直接白描。

### 3. 连续对话：≤8行

**执行方法**：每写5-6行纯对话后，必须插入一行叙事（动作/心理/环境）。**不要等写到10+行再回头改**，写的时候就控制节奏。

典型模式：
```
"对话1。" — 动作描写
"对话2。" — 对话3
"对话4。" — 心理/环境描写（打断连续）
"对话5。" — 对话6
"对话7。" — 叙事
```

### 4. 短句占比：≤50%

**执行方法**：每写3-4个短句后，主动写1个中句（15-30字）或长句（30字+）。短句用于动作和节奏，中长句用于心理和描写。

### 5. 单句成行：≤200次

**执行方法**：短句独行是节奏工具，不是默认格式。连续3个以上单句成行后，合并或写一段。

## 绝对禁止（写作时即避免）

### 6. 精确计时（全禁用）

**禁止**：`停了一秒`、`沉默了两秒`、`看了五秒`、`过了三秒`、`愣了两秒`、`等了几秒`、`在手里看了两秒`、`零点几秒后`、`恰好三秒`、`整整一瞬`、`等了足足五分钟`

**替代方案**：沉默片刻、没说话、静了好一会儿、一瞬间、转眼之间、顿了顿

### 7. 陈词滥调·全网毒词（直接禁用）

`嘴角勾起一抹笑`、`邪魅一笑`、`嘴角抽搐`、`天旋地转`、`倒吸一口凉气`、`瞳孔猛地一缩`、`瞳孔骤缩`、`心头一震`、`如遭雷击`、`呼吸一窒`、`喉咙发紧`、`灵魂深处的悸动`、`一股暖流涌上心头`、`一股寒意涌上心头`、`面色一沉`、`脸色骤然一变`、`神色复杂`、`一言不发静静伫立`、`身形一顿`

### 8. AI生硬连接（禁用→替换）

| 禁用 | 替换 |
|------|------|
| 然而、尽管如此 | 但是、不过、可 |
| 总而言之、综上所述 | 直接删 |
| 不仅如此，他还 | 他不光…还… |
| 在这一刻、此时此刻 | 这一刻、这会儿 |

### 9. AI烂俗修辞（全禁用）

`仿佛看穿了他的灵魂`、`时间仿佛凝固了`、`空气突然安静下来`、`气氛瞬间凝固`、`像被电流击中一般`、`一股寒意从脚底直窜头顶`、`声音如银铃般清脆`、`夜色如墨`、`往事涌上心头`

### 10. AI心理描写（禁用→替换）

| 禁用 | 替换 |
|------|------|
| 心中暗自思忖 | 他想 |
| 心中不禁涌起一阵XX | 只觉得心头发堵 |
| 一股莫名的情绪在胸中蔓延 | 说不上来是什么滋味 |
| 内心翻江倒海 | 心里乱作一团 |
| 脑海中闪过一个念头 | 忽然想到 |

### 11. 禁止词

绝对不能出现：`象征着`、`标志着`、`代表着`、`体现着`、`折射出`、`见证了`、`恍然大悟`、`不约而同`、`难以置信`

### 12. AI味词（零容忍）

`切面`、`旁白`、`镜头`、`转场`、`他是一个`、`从而`、`以此`、`进一步凸显`、`这表明`、`这说明`、`这反映了`、`总而言之`、`不言而喻`、`一定程度上`、`然而`、`总之`

### 13. 冗余修饰词（尽量少用）

`略显`、`稍稍`、`略微`、`些许`、`缓缓地`、`慢慢地`、`静静地`、`莫名的`、`不知为何`、`极其`、`无比`

### 14. 安全白名单（可正常使用，别清零）

**可以有**：`突然`、`微微`、`沉默`、`感觉`、`觉得`、`嘴角`、`很`、`特别`、`看到`、`听见`、`抬头`、`低头`、`好像`、`似乎`、`仿佛`、`顿了顿`、`愣了下`

**核心原则**：这些词人也会用，不要刻意清除，控制到自然密度即可。过度清除导致文本不自然。

## 写作节奏检查点

写到以下节点时暂停自检：

| 检查点 | 位置 | 检查内容 |
|--------|------|----------|
| 写前 | 0字 | 已查写作知识路由表，确定本章场景类型，已读对应必读文件 |
| 场景1结束 | ~500字 | 比喻计数、是否有精确计时 |
| 场景2结束 | ~1500字 | 字数是否达标进度、对话是否连续超5行 |
| 场景3结束 | ~2500字 | 短句占比、字数缺口 |
| 全文写完 | ~3000字 | 全部指标最终确认 |

**自检清单**（全写完后逐项确认）：
- [ ] 写前已查知识路由表，读了本章场景类型的必读文件？
- [ ] 中文字符 ≥ 2800？
- [ ] 比喻(像) ≤ 5次？
- [ ] 连续对话 ≤ 8行？
- [ ] 短句占比 ≤ 50%？
- [ ] 无精确计时表达？
- [ ] 无禁止词/AI味词？
- [ ] 前300字有冲突/悬念/动作？
- [ ] 章末有悬念/断章钩子？
- [ ] 摘要JSON中 knowledge_references 填写了本章引用的所有文件？
- [ ] 运行引用计数更新：`python .claude/memory/references/update_reference_count.py --novel-dir "novel_output/{平台}/{书名}" --count-file ".claude/memory/references/file_reference_count.json"`

## 与审计工具的关系

- **写时约束** = 写作过程中的实时规则（本文档）
- **写后审计** = 最终验证，应一次通过
- 如果审计发现问题 = 写时约束没有执行到位 = 流程失误
- 审计不通过时，先检查是哪个写时约束被跳过了，而不是直接改稿
