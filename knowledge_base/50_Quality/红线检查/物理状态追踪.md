# 物理状态追踪 (Physical State Tracking)

**版本**：1.0
**创建日期**：2026-04-27
**来源**：《废婿觉醒》Ch1 逻辑硬伤复盘（粥稀/糊矛盾、12块钱重复花）

---

## 问题根因

LLM 逐 token 生成，没有"世界模型"。局部连贯 ≠ 全局连贯。

**典型表现**：
- 前面说"稀汤寡水"，后面说"看糊了"——同一锅粥不可能同时稀和糊
- 前面说"12块买了泡面"，后面又去买泡面——钱已经花了
- 人物身上有钱/物品，后面动作不追踪

---

## 执行规则

### 每章写前：列物理状态清单

| 检查项 | 填写内容 |
|--------|----------|
| 人物身上有多少钱 | |
| 场景里的物品状态 | |
| 人物当前位置 | |
| 当前时间 | |
| 物品的前后状态一致性 | |

### 写中：逐句对照

- 不改变物理状态除非剧情需要
- 提到钱时检查金额是否与上一步一致
- 提到物品时检查状态是否与前文矛盾（稀≠糊）
- 人物移动时检查位置是否连贯

### 写后：审计追加检查

- 全文搜索钱/物品相关描述，确认无矛盾
- 确认人物位置变化有交代
- 确认时间线连贯
