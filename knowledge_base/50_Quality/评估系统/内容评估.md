## 评估理念

**核心原则**：正文是作品的最终呈现，决定读者是否愿意追更。

正文评估回答的问题不是"这段文字写得漂不漂亮"，而是：
- 读者愿不愿意看下去？
- 这段文字有没有传达想要的效果？
- 有没有破坏读者体验的问题？

**与前一阶段的区别**：

| 对比项 | 细纲设计评估 | 正文创作评估 |
|-------|-------------|-------------|
| 核心问题 | 这一章好不好看？ | 这段文字愿不愿意看？ |
| 评估重点 | 事件、冲突、爽点 | 节奏、人物、语言、执行一致性 |
| 评估粒度 | 章节规划 | 具体文字 |
| 判断标准 | 可直接写/需优化/有问题 | 通过/需修改/有硬伤 |

## 评估模式

### 逐章评估

每章完成后立即评估，适合主节点章节、重要章节。

### 批量评估

批量创作完成后统一评估，适合灵活区章节、过渡章节。

**批量评估报告**：
```
【批量评估报告】

■ 批量概况
  章节范围：第X章 - 第Y章
  总字数：XXXX字
  主节点章节：[章节列表]
  灵活区章节：[章节列表]

■ 逐章评估摘要

| 章节 | 类型 | 综合判断 | 主要问题 |
|------|------|---------|---------|
| 第X章 | 灵活区 | 通过 | 无 |
| 第X+1章 | 灵活区 | 需修改 | 节奏偏慢 |
| 第X+2章 | 主节点M2 | 通过 | 无 |

■ 主节点执行检查
  M2（第X+2章）：✓ 一致
  M3（第Y章）：✓ 一致

■ 需修改章节
  1. 第X+1章：[问题描述] → [修改建议]

■ 灵活区调整记录
  | 章节 | 差异说明 |
  |------|---------|
  | 第X章 | 增加过渡对话 |

■ 综合判断
  通过：X章 | 需修改：Y章 | 有硬伤：0章
```

## 评估维度

### 维度一：开篇吸引力

**核心问题**：开头是否抓人？

| 检查项 | 具体问题 |
|-------|---------|
| 切入速度 | 是否快速进入情节？有没有过多铺垫？ |
| 钩子效果 | 开头是否能吸引读者继续往下看？ |
| 代入感 | 读者是否能快速代入场景？ |
| 与细纲一致 | 是否实现了细纲设计的开头钩子？ |

**判断等级**：抓人 / 一般 / 慢热

### 维度二：节奏流畅度

**核心问题**：阅读是否流畅？

| 检查项 | 具体问题 |
|-------|---------|
| 信息密度 | 信息是否过多或过少？ |
| 段落节奏 | 段落长短是否合适？有没有大段文字？ |
| 事件推进 | 事件推进是否流畅？有没有跳跃或拖沓？ |
| 阅读体验 | 读者会不会觉得累或无聊？ |

**判断等级**：流畅 / 有问题

### 维度三：人物表现

**核心问题**：人物是否鲜活？

| 检查项 | 具体问题 |
|-------|---------|
| 行为合理 | 人物行为是否符合人设？ |
| 对话自然 | 对话是否自然？有没有"不像人说的话"？ |
| 性格展现 | 人物性格是否通过行为/对话展现出来？ |
| 情感真实 | 人物的情感反应是否真实？ |

**判断等级**：鲜活 / 一般 / 有问题

### 维度四：场景描写

**核心问题**：场景是否有画面感？

| 检查项 | 具体问题 |
|-------|---------|
| 画面感 | 读者能否想象出场景？ |
| 描写程度 | 描写是否过多或过少？ |
| 描写重点 | 描写是否聚焦于重要元素？ |
| 氛围营造 | 场景氛围是否到位？ |

**判断等级**：到位 / 不足 / 过多

### 维度五：爽点落地

**核心问题**：爽点是否写到位？

| 检查项 | 具体问题 |
|-------|---------|
| 爽点呈现 | 爽点是否清晰呈现？读者能否感知到？ |
| 铺垫效果 | 铺垫是否到位？爽点爆发是否有力？ |
| 情绪调动 | 爽点是否调动了读者情绪？ |
| 与细纲一致 | 是否实现了细纲设计的爽点？ |

**判断等级**：到位 / 不足 / 未落地

### 维度六：语言质量

**核心问题**：语言是否通顺？

| 检查项 | 具体问题 |
|-------|---------|
| 错别字 | 是否有错别字？ |
| 语病 | 是否有语法错误？ |
| 表达清晰 | 表达是否清晰？有没有歧义？ |
| 用词准确 | 用词是否准确？有没有不当表达？ |

**判断等级**：通顺 / 有问题

### 维度七：承诺校验

**核心问题**：正文是否完成了细纲的目标？

| 检查项 | 核心问题 |
|-------|---------|
| 事件完成 | 是否完成了细纲规划的核心事件？ |
| 冲突呈现 | 是否呈现了细纲设计的冲突？ |
| 钩子落地 | 是否实现了细纲设计的钩子？ |
| 爽点落地 | 是否实现了细纲设计的爽点？ |

**判断等级**：完成 / 部分完成 / 未完成

### 维度八：主节点执行检查

**核心问题**：主节点章节是否按细纲严格执行？

**适用范围**：仅【主节点】章节需要此项评估

| 检查项 | 具体问题 |
|-------|---------|
| 核心事件完成 | 主节点核心事件是否完整呈现？ |
| 爽点落地 | 主节点爽点是否按设计落地？力度是否足够？ |
| 钩子设置 | 开头/结尾钩子是否到位？ |
| 执行一致性 | 与细纲规划是否一致？有无偏离？ |
| 后续影响 | 是否影响后续主节点的铺垫？ |

**判断等级**：一致 / 灵活调整 / 主节点偏离

**注意**：
- 主节点章节必须严格按细纲执行，偏离需标记
- 灵活区章节此项评估为"不适用"

## 硬伤清单

| 硬伤类型 | 具体问题 | 后果 |
|---------|---------|-----|
| **开篇劝退** | 开头拖沓、无聊、让人看不下去 | 读者直接弃书 |
| **人物崩坏** | 人物行为严重违背人设 | 读者出戏，弃书 |
| **逻辑漏洞** | 情节逻辑不通 | 读者吐槽，弃书 |
| **节奏崩坏** | 极度拖沓或极度赶工 | 阅读体验极差 |
| **爽点翻车** | 爽点写成雷点或毒点 | 读者反感 |
| **主节点偏离** | 主节点章节偏离细纲规划 | 后续剧情崩坏风险 |
| **大量语病** | 错别字、语病过多 | 降低阅读体验 |

## 判断标准

| 判断 | 条件 | 后续处理 |
|-----|-----|---------|
| **通过** | 无硬伤 + 节奏流畅 + 爽点/钩子至少一项落地 + 主节点执行一致 | 可以发布或进入下一章 |
| **需修改** | 无硬伤 + 有改进空间 | 修改后重新评估或直接使用 |
| **有硬伤** | 有硬伤 或 承诺未完成 或 主节点偏离 | 必须修改硬伤后重新评估 |

**主节点章节额外判断**：
- 主节点偏离 → 必须标记，按偏差处理流程处理
- 灵活调整 → 记录差异，继续写作

**快速判断**：
- 开头能看下去 ✓
- 没有严重的人物/逻辑问题 ✓
- 节奏不拖沓 ✓
- 有爽点或钩子 ✓
- 无硬伤 ✓
- 主节点执行一致（如适用）✓
→ 通过

## 优化建议方法

### 开篇劝退

**问题表现**：开头拖沓、无聊、让人看不下去

**修复方向**：
1. **删除冗余**：删掉不必要的铺垫、背景介绍
2. **前置冲突**：把冲突提前到开头
3. **制造悬念**：让读者想知道接下来会发生什么
4. **增加信息量**：开头要有足够的信息量抓住读者

**开篇优化技巧**：
```
- 从动作切入，而非背景介绍
- 从对话切入，而非心理描写
- 从冲突切入，而非日常描写
- 从悬念切入，而非平铺直叙
```

### 人物崩坏

**问题表现**：人物行为严重违背人设

**修复方向**：
1. 回顾人物设定：性格、动机、缺陷
2. 找出违背人设的具体行为
3. 修改行为或给出合理的理由

**人物塑造技巧**：
```
- 通过行为展现性格，而非直接描写
- 对话要符合人物身份和性格
- 人物的反应要符合情感逻辑
- 重要决定要有足够的动机支撑
```

### 逻辑漏洞

**问题表现**：情节逻辑不通

**修复方向**：
1. 找出逻辑漏洞的具体位置
2. 分析漏洞产生的原因
3. 补充必要的铺垫或解释
4. 或修改情节避免漏洞

**常见逻辑漏洞**：
```
- 人物知道不该知道的事
- 人物忽略显而易见的选择
- 时间线混乱
- 因果关系断裂
- 设定前后矛盾
```

### 节奏崩坏

**问题表现**：极度拖沓或极度赶工

**修复方向**：
1. **极度拖沓**：
   - 删除重复描写
   - 删除无关对话
   - 压缩过渡段落
   - 增加事件密度

2. **极度赶工**：
   - 增加细节描写
   - 增加人物反应
   - 补充必要铺垫
   - 拆分为多章

**节奏控制参考**：
```
- 每段不超过3-5句话
- 每章开头不超过200字进入情节
- 重要场景要慢，过渡场景要快
- 爽点爆发前要铺垫，爆发后要释放
```

### 爽点翻车

**问题表现**：爽点写成雷点或毒点

**修复方向**：
1. **铺垫不足**：增加前期压抑和铺垫
2. **爆发无力**：增强爽点的呈现力度
3. **节奏错误**：调整铺垫和爆发的节奏
4. **情绪调动失败**：增加情感描写

**爽点写作技巧**：
```
- 铺垫要足够：让读者期待
- 压抑要到位：让读者憋屈
- 爆发要有力：让读者爽快
- 反应要充分：让读者看到爽点的效果
```

### 主节点偏离

**问题表现**：主节点章节偏离细纲规划

**修复方向**：
1. 确认偏离类型：核心事件改变 / 爽点改变 / 走向改变
2. 评估影响范围：是否影响后续主节点
3. 按偏差处理流程处理：
   - 参考 `../novel_creation_promax/references/stages/04-outline/deviation-handling.md`
   - 编辑介入，用户确认
   - 记录偏离，更新细纲执行记录

**主节点执行要点**：
```
- 核心事件不可跳过
- 爽点设计必须落地
- 钩子设置必须到位
- 人物表现符合规划
- 偏离需编辑介入确认
```

### 大量语病

**问题表现**：错别字、语病过多

**修复方向**：
1. 通读全文，标记问题
2. 逐项修改
3. 再次通读确认

**常见语病类型**：
```
- 错别字
- 主谓不一致
- 成分缺失
- 搭配不当
- 语序不当
- 重复累赘
- 指代不明
```
