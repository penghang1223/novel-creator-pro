# 工业级评分体系

> 100分制六维评分，可落地自动判断"这章能不能发 / 要不要重写"。来源：novel-review技能体系。

---

## 一、总评分结构（100分制）

```
总分 = 商业(25) + 结构(20) + 人物设定(15) + 连续性(15) + 表现力(15) + 逻辑合规(10)
```

---

## 二、各维度详细评分

### 1️⃣ 商业性（25分）

| 子项 | 分值 | 检查要点 |
|------|------|----------|
| 标题吸引力 | 5分 | 有钩子(冲突/反差/悬念)=2分，题材传达清晰=1分，点击欲=1分，平台风格=1分 |
| 开头钩子 | 5分 | 前1000字进入冲突=2分，前3章有核心事件=1分，让人想继续看=1分，避免世界观堆砌=1分 |
| 爽点密度 | 10分 | 有情绪起伏=3分，爽点有效=3分，打脸/反转成立=2分，持续刺激=2分 |
| 章节结尾钩子 | 5分 | 每章结尾有悬念=3分，悬念吸引继续读=2分 |

**商业性总评标准**：
- 20-25分：强上头，有追读潜力
- 15-19分：可读但不爆
- 10-14分：一般，可能扑街
- <10分：大概率扑街

### 2️⃣ 结构（20分）

| 子项 | 分值 | 检查要点 |
|------|------|----------|
| 主线清晰度 | 5分 | 主线目标清晰=2分，主线贯穿全文=2分，主线易理解=1分 |
| 单章结构完整 | 5分 | 每章有明确目标=2分，每章有冲突=2分，每章有结果=1分 |
| 节奏合理 | 5分 | 快慢合理=2分，信息释放均衡=2分，爽点间隔合理=1分 |
| 高潮分布 | 5分 | 高潮分布合理=2分，高潮有铺垫=2分，高潮足够震撼=1分 |

**结构总评标准**：
- 16-20分：结构优秀，骨架稳固
- 12-15分：结构良好，有少量问题
- 8-11分：结构一般，有明显问题
- <8分：结构混乱

### 3️⃣ 人物与设定（15分）

| 子项 | 分值 | 检查要点 |
|------|------|----------|
| 人物动机清晰 | 5分 | 主角动机明确=2分，动机合理=2分，动机足够强=1分 |
| 人物一致性 | 5分 | 性格稳定=2分，不OOC=2分，行为符合性格=1分 |
| 世界观合理性 | 5分 | 规则清晰=2分，规则自洽=2分，规则被正确使用=1分 |

**人物总评标准**：
- 12-15分：人物立得住，设定自洽
- 9-11分：人物一般，设定有瑕疵
- 6-8分：人物有问题，设定有矛盾
- <6分：人物是工具人，设定崩塌

### 4️⃣ 连续性（15分）⚠️ AI最容易崩的点

| 子项 | 分值 | 检查要点 |
|------|------|----------|
| 时间线一致 | 5分 | 无矛盾=3分，时间跨度合理=1分，事件顺序正确=1分 |
| 人物关系一致 | 5分 | 关系前后一致=3分，关系发展自然=2分 |
| 伏笔与记忆 | 5分 | 伏笔不遗忘=2分，伏笔不冲突=2分，事件被记住=1分 |

**连续性总评标准**：
- 12-15分：连续性完美
- 9-11分：连续性良好，有少量瑕疵
- 6-8分：连续性有问题
- <6分：连续性严重错误，读者失去信任

**一票否决**：严重时间线矛盾或伏笔严重冲突，扣5分

### 5️⃣ 表现力（15分）

| 子项 | 分值 | 检查要点 |
|------|------|----------|
| 画面感 | 5分 | 画面感强=2分，描写具体=2分，场景有画面=1分 |
| 情绪表达 | 5分 | 情绪到位=2分，情绪有层次=2分，情绪真实=1分 |
| 对话质量 | 5分 | 对话自然=2分，对话推动剧情=2分，符合人物性格=1分 |

**AI味对表现力的影响**：
- AI味评分≥7分 → 表现力扣5分
- AI味评分5-6分 → 表现力扣2分
- AI味评分3-4分 → 表现力扣1分

**表现力总评标准**：
- 12-15分：表现力极强，像人写的
- 9-11分：表现力强
- 6-8分：表现力一般
- <6分：表现力差，像AI写的

### 6️⃣ 逻辑与合规（10分）⚠️ 一票否决项

| 子项 | 分值 | 检查要点 |
|------|------|----------|
| 因果逻辑 | 5分 | 因果成立=3分，行为合理=1分，推理/战斗自洽=1分 |
| 合理性 | 3分 | 不强行推进=2分，行为有动机=1分 |
| 合规风险 | 2分 | 无违规内容=1分，无敏感词=1分 |

**一票否决**：
- 有违规内容 → 扣10分，禁止发布
- 有敏感词 → 扣5分

**逻辑总评标准**：
- 8-10分：逻辑完美，合规
- 5-7分：逻辑一般，有瑕疵
- 2-4分：逻辑有问题
- <2分：逻辑混乱，不可发布

## 三、自动决策规则

### 🟢 可发布（直接用）
```
总分 ≥ 85
且无High严重问题
且合规风险不存在
```

### 🟡 优化后发布
```
总分 70-84
或存在 ≤2个High问题
且合规风险不存在
```
**操作**：做局部修改

### 🔴 必须重写
```
总分 < 70
或商业性 < 15
或结构 < 12
或连续性 < 10
```
**操作**：不要修，直接重写

### ⚫ 禁止发布（硬规则）
```
合规风险存在
或连续性严重错误（<8分）
```
**操作**：禁止发布

## 四、问题等级定义

### High（致命）- P0弃书级
- 影响阅读：开头拖沓、节奏混乱
- 逻辑崩：时间线矛盾、设定冲突
- 无钩子：开头无冲突、结尾无悬念

### Medium（重要）- P1流失级
- 影响体验但不致命：人物扁平、对话生硬
- 爽点稀疏、节奏问题

### Low（优化）- P2优化级
- 文风：语言单一、修饰词堆砌
- 细节：画面感不足、细节描写少

## 五、修改优先级（必须遵守）

### 顺序1：商业问题（不吸引人）
1. 开头钩子：前1000字引入冲突
2. 爽点密度：增加爽点
3. 章节钩子：增加悬念

### 顺序2：结构问题（看不下去）
1. 节奏：调整节奏，删除无效剧情
2. 主线：明确主线目标

### 顺序3：连续性（崩）
1. 时间线：修复时间线矛盾
2. 设定：修复设定冲突

### 顺序4：逻辑
1. 因果：强化因果关系
2. 行为：让行为合理

### 顺序5：表现 & 文风
1. 画面感：增加细节描写
2. 对话：让对话自然

**顺序错了 = 白改**

## 七、常见弃书点（12条）

> 以下问题会导致读者在对应阶段弃书，审稿时必须逐条检查。

### 开篇弃书点（前3章致命）

1. **开篇拖沓** — 前1000字无冲突/前3章平淡/开头大量设定说明/主角目标模糊
2. **标题误导** — 标题与内容不符/无法传达题材/无吸引力/不符合平台风格
3. **主角无吸引力** — 性格模糊/动机不明/行为不合理/无成长

### 中期弃书点（3-30章）

4. **节奏拖沓** — 剧情推进慢/大量无关情节/连续平淡期过长/爽点间隔过长
5. **爽点不足** — 长期无爽点（超过15章）/爽点力度不足/爽点无效（自嗨）
6. **角色OOC** — 行为不符合性格/突然崩坏/逻辑矛盾/无成长
7. **逻辑崩坏** — 剧情逻辑矛盾/因果关系不成立/行为不合理/推理错误

### 长期弃书点（30章后）

8. **连续性崩坏** — 时间线矛盾/设定前后冲突/人物关系不一致/伏笔被遗忘
9. **爽点重复** — 同类型爽点/套路化打脸/反转缺乏新意
10. **设定崩塌** — 规则被打脸/设定前后矛盾/设定被滥用或遗忘

### AI写作特有弃书点

11. **明显AI痕迹** — 句式单一/连接词过度/情感浅表/细节不足
12. **连续性问题** — 时间线混乱/角色状态不一致/设定冲突/事件被遗忘

### 平台特有弃书点

| 平台 | 特有弃书点 |
|------|-----------|
| 起点 | 升级体系崩/打脸重复/世界观太小 |
| 晋江 | 感情线拖沓/误会过多/角色扁平 |
| 番茄 | 节奏慢/爽点稀疏/结局仓促 |
| 豆瓣 | 思想浅薄/文学性差/现实感弱 |

### 平台专属审核标准（审稿时按目标平台逐项检查）

#### 起点（男频长篇）
- 升级体系：路线清晰 / 难度合理 / 有成就感 / 有新能力
- 世界观规模：有层次 / 势力完整 / 可扩展 / 设定自洽
- 金手指设计：合理 / 有成长性 / 限制明确 / 与剧情结合
- 打脸节奏：频率合理 / 对象有层次 / 方式有新意 / 有后续影响
- 长篇能力：支撑百万字 / 世界观可扩展 / 成长有持续动力 / 有足够反派BOSS
- ❌ 升级太快 / 世界观太小 / 金手指无敌 / 打脸重复套路化

#### 晋江（女频长篇）
- 感情线质量：CP人设鲜明 / 起点合理 / 节奏自然 / 有高潮
- 甜虐比例：甜点密度 / 虐点设置 / 甜文8:2或虐文3:7 / 转换自然
- 角色魅力：男女主有魅力 / 配角有记忆点 / 反派有层次 / 成长弧线
- 细节描写：互动丰富 / 情感细腻 / 场景唯美 / 有想象空间
- ❌ 感情线慢热 / 误会反复 / 角色扁平 / 虐点无理由为虐而虐

#### 番茄（新媒体短篇）
- 节奏把控：快速切入 / 紧凑 / 冲突密集 / 不拖沓
- 爽点密度：密集 / 强度足够 / 类型多样 / 无空窗
- 章节长度：1000-1500字 / 独立目标 / 小高潮 / 不一分为二注水
- 完整性：起承转合 / 明确结局 / 伏笔回收 / 字数合理
- ❌ 开篇拖沓 / 爽点稀疏 / 章节过长 / 结局仓促

#### 七猫（新媒体短篇）
- 代入感：贴近读者 / 情境真实 / 情感共鸣 / 有想象空间
- 爽点类型：打脸 / 逆袭 / 复仇 / 爱情
- 黄金三章：第1章强冲突 / 第2章金手指展现 / 第3章明确主线
- 结局满足感：满足期待 / 无遗憾 / 有反转 / 有余韵
- ❌ 代入感弱 / 爽点不足 / 黄金三章失败 / 结局不满足

#### 飞卢（极快节奏爽文）
- 极致爽感：密集 / 强烈 / 类型多样 / 无空窗
- 超快节奏：极快开篇 / 节奏极快 / 冲突极密 / 不拖沓
- 系统设计：有趣 / 强大 / 可持续 / 任务合理
- ❌ 爽点不足 / 节奏慢 / 系统无聊 / 更新困难

#### 知乎（短篇故事）
- 故事性：有趣 / 有新意 / 记忆点 / 传播力
- 反转设计：有铺垫 / 震撼 / 合理 / 次数合适
- 话题性：争议点 / 共鸣点 / 社交价值 / 传播潜力
- 篇幅控制：2000-8000字 / 紧凑 / 不注水
- ❌ 故事无趣 / 反转无力 / 无话题性 / 篇幅失控

#### 豆瓣（严肃文学）
- 思想深度：社会议题 / 人性思考 / 哲学思辨 / 独特观点
- 文学性：语言特色 / 修辞丰富 / 叙事技巧 / 文学价值
- 现实主义：反映现实 / 批判性 / 建设性 / 真实性
- 人物复杂度：有矛盾 / 有成长 / 有层次 / 动机合理
- ❌ 思想浅薄 / 文学性差 / 现实感弱 / 人物扁平
