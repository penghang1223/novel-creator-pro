## 每章生成前检查

### 1. 信息回顾

**回顾前3章关键信息**
- 主角当前状态：实力、位置、心理状态、人际关系
- 当前情节进度：处于哪个阶段，主要冲突是什么
- 已埋伏笔：有哪些伏笔需要提及或回收

**回顾方法**
- 快速浏览前3章的结尾部分
- 提取关键信息：人物状态、当前冲突、待解决事项
- 记录要点：主角现在在哪里？在做什么？面临什么挑战？

### 2. 情节类型确认

**情节类型定义**
- 推进型：推动剧情发展，推进冲突升级
- 展开型：展开人物关系，展开世界观
- 爽点型：释放爽点，满足读者期待
- 过渡型：连接两个高潮，调整节奏
- 情感型：展现人物情感，深化人物关系

**避免连续使用相同类型**
- 连续3章使用同一情节类型时，必须调整
- 建议节奏：推进→展开→爽点→过渡→推进...

**情节类型检查清单**
- [ ] 前一章是什么类型？
- [ ] 前两章是什么类型？
- [ ] 本章是否与前两章类型不同？
- [ ] 如果连续使用，是否已调整情节侧重点？

### 3. 爽点类型确认

**爽点类型**
- 扮猪吃虎、越级碾压、身世揭秘
- 反派打脸、资源垄断、荣耀加身
- 复仇闭环、情感升温

**避免单调重复**
- 连续3章使用同一爽点类型时，必须调整
- 建议：每5章内包含至少3种不同爽点类型

**爽点类型检查清单**
- [ ] 本章是否有爽点？
- [ ] 爽点类型是什么？
- [ ] 前两章的爽点类型是什么？
- [ ] 本章爽点类型是否与之前不同？

### 4. 字数目标确认

**字数要求**
- 目标：1500-2000字
- 最低：1500字
- 理想：1700-1900字

**字数分配**
- 开头：100-200字
- 核心：1000-1500字
- 结尾：200-300字

### 5. 状态快照

**主角当前状态**
- 实力等级：[如筑基初期]
- 位置：[如宗门广场]
- 心理状态：[如刚获胜，心情复杂]
- 人际关系：[与反派关系恶化，与部分长老关系缓和]

**当前阶段**
- 开篇：第1-10章（建立形象，引入冲突）
- 发展：第11-50章（实力提升，冲突升级）
- 高潮：第51章-终章（最终决战，结局）

**待解决冲突**
- 主要冲突：[如与宗门长老的对峙]
- 支线冲突：[如家族内部的反对声音]
- 待解决：[在本章需要推进哪些冲突]

## 每章生成后检查

### 基础检查

**字数检查**
- [ ] 字数是否≥1500字？
- [ ] 如果不足，哪些部分可以扩充？
- [ ] 优先扩充：心理描写、细节描写、对话

**情节连贯性检查**
- [ ] 本章开头是否与上一章结尾衔接？
- [ ] 情节推进是否合理？
- [ ] 因果关系是否清晰？
- [ ] 时间线是否正确？

**人物一致性检查**
- [ ] 主角性格是否一致？
- [ ] 反派性格是否一致？
- [ ] 配角行为是否符合设定？
- [ ] 人物关系是否有矛盾？

**爽点效果检查**
- [ ] 爽点是否达到预期？
- [ ] 铺垫是否充分？
- [ ] 爆发是否有力？
- [ ] 反应是否真实？

### 质量评分

**情节质量（满分25分）**
- 情节推进是否合理（5分）
- 冲突设计是否有张力（5分）
- 爽点是否达到预期（10分）
- 悬念设置是否有效（5分）

**人物质量（满分25分）**
- 主角形象是否鲜明（10分）
- 配角是否有存在感（5分）
- 反派是否有压迫感（5分）
- 人物关系是否合理（5分）

**语言质量（满分25分）**
- 对话是否符合人物性格（10分）
- 描写是否有画面感（10分）
- 是否有文青式表达（5分）

**节奏质量（满分25分）**
- 节奏是否合适（10分）
- 是否有拖沓（10分）
- 悬念设置是否有效（5分）

**总评分**
- 优秀：90-100分
- 良好：80-89分
- 合格：70-79分
- 需修改：70分以下

### 每5章检查

**人物一致性深度检查**

**主角一致性**
- [ ] 性格是否保持一致？
- [ ] 说话风格是否统一？
- [ ] 行为模式是否合理？
- [ ] 成长路径是否按计划？

## 常见质量问题与解决

### 1. 字数不足

**问题原因**
- 情节推进太快
- 描写过于简略
- 对话过于简单

**解决方法**
- 增加心理描写
- 增加环境描写
- 增加动作细节
- 扩展对话内容
- 增加配角视角

### 2. 情节拖沓

**问题原因**
- 无效对话太多
- 重复描写
- 主线推进缓慢

**解决方法**
- 删除无效对话
- 精简描写
- 加快主线推进
- 增加冲突事件

### 3. 爽点不够爽

**问题原因**
- 铺垫不足
- 爆发力不够
- 反应不够真实

**解决方法**
- 增加反派的嚣张描写
- 增加主角的压抑描写
- 增加爆发时的视觉冲击
- 增加配角的震惊反应

### 4. 人物崩坏

**问题原因**
- 性格前后矛盾
- 行为不符合设定
- 人物关系混乱

**解决方法**
- 重新审视人物设定
- 增加行为动机的解释
- 调整后续发展方向

---

**记住**：质量是作品的生命线。定期检查、及时修正，才能保证作品的稳定性。
