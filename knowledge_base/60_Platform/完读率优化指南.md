# 完读率优化指南

> 完读率是番茄最重要的指标，直接影响推荐量和收益。

---

## 完读率的本质

完读率 = 读完第N章的读者 / 读了第N章的读者

读者为什么**没读完**某一章：

| 原因 | 占比 | 解决方法 |
|------|------|----------|
| 章末没有钩子 | ~30% | 每章结尾必须有悬念/反转/预告 |
| 章节太长 | ~20% | 保持2800-3200字，不要超3500 |
| 内容注水 | ~20% | 每章必须推进至少1个事件 |
| 章节开头无聊 | ~15% | 前3行必须有吸引力 |
| 文笔/排版差 | ~10% | 审计通过+段落不要太长 |
| 其他 | ~5% | — |

---

## 章末钩子设计

### 六种高效钩子

| 类型 | 示例 | 机制 |
|------|------|------|
| 信息差 | 读者知道主角不知道的事 | "赵天宇不知道的是，他面前这个被嘲笑的人，三天后会拥有一百万。" |
| 悬念 | 打开一扇门/收到一条消息 | "林辰推开门——客厅里的灯亮着。沙发上坐着一个人。" |
| 反转 | 预期落空 | "他打开手机银行。余额：187,462.50。" |
| 威胁 | 对手开始行动 | "赵天宇拿起电话：'帮我查一个人。'" |
| 情感 | 触动人心的瞬间 | "朵朵说：'爸爸，等我长大了，我帮你赚好多钱。'" |
| 系统 | 能力解锁/升级 | "叮——透视之眼Lv2已解锁。" |

### 钩子强度分级

| 级别 | 说明 | 使用频率 |
|------|------|----------|
| 强钩子 | 重大反转/威胁/揭秘 | 每5-10章1次 |
| 中钩子 | 悬念/系统升级/情感触发 | 每2-3章1次 |
| 弱钩子 | 推进事件/小悬念 | 每章至少1次 |

**规则**：每章至少1个弱钩子。连续3章只有弱钩子时，第4章必须来一个中/强钩子。

## 章节开头优化

读者在章末决定要不要读下一章，在**章头3行**决定要不要继续读这一章。

### 好的章头

```
✅ 直接进入事件："林辰的手机响了——是猎头。"
✅ 直接进入冲突："赵天宇把文件摔在桌上。"
✅ 直接进入悬念："他打开U盘，屏幕闪了一下蓝光。"
```

### 差的章头

```
❌ 环境铺垫："清晨的阳光透过窗帘照进来……"
❌ 回忆开头："林辰想起三天前……"
❌ 概括性开头："这一天对林辰来说意义重大。"
```

**规则**：章头3行内必须出现**角色+动作/事件**，不用环境/回忆/概括开头。

## 内容密度控制

### 每章最低事件数

| 章节类型 | 最少事件数 | 说明 |
|----------|-----------|------|
| 推进章 | 1个主事件 | 核心剧情推进 |
| 日常章 | 2个小事件 | 情感/互动/细节 |
| 爽点章 | 1个大事件 | 打脸/逆袭/暴赚 |
| 铺垫章 | 1个暗线事件 | 表面平静，暗流涌动 |

### 注水检测

以下内容算注水：

| 注水类型 | 表现 | 防御 |
|----------|------|------|
| 重复描写 | 同一场景写了两遍 | 写完后通读检查 |
| 无意义对话 | 对话没有推进关系/信息/冲突 | 每句对话问"这句删了有影响吗" |
| 过度心理 | 角色想了500字但没有行为 | 心理描写控制在2行内 |
| 环境堆砌 | 环境描写超过5行不带角色 | 环境描写必须和角色互动 |
| 设定科普 | 用整段解释世界观/系统 | 设定融入剧情 |

## 排版对完读率的影响

手机阅读时，排版直接影响阅读体验：

| 排版问题 | 影响 | 规则 |
|----------|------|------|
| 段落太长 | 手机上一屏看不到段尾→划走 | 每段 ≤ 4行 |
| 对话不分行 | 找不到谁说的 | 每句对话单独一行 |
| 没有空行 | 密密麻麻→视觉疲劳 | 场景转换必须空行 |
| 一行太长 | 需要横滑→体验差 | 每行 ≤ 35字 |

---

## 自检清单

每章写完后：

- [ ] 章末有钩子（至少弱钩子级别）？
- [ ] 章头3行有角色+动作/事件？
- [ ] 本章推进了至少1个事件？
- [ ] 没有重复描写/无意义对话/过度心理？
- [ ] 每段 ≤ 4行，每行 ≤ 35字？
- [ ] 场景转换有空行分隔？
