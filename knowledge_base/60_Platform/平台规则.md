## 二、番茄小说规则（流量最大）

### 2.1 平台特点

**优势**：
- 字节跳动流量支持，用户基数大
- 新人曝光机会多，签约门槛相对较低
- 广告分成模式，首秀数据定生死

**风格偏好**：
- 爽文、快节奏、强冲突
- 系统流、签到流、脑洞文
- 对话占比高，减少大段描写

**2026爆文方向**：
- 男频Top5：都市战神 > 赘婿逆袭 > 玄幻脑洞 > 系统流 > 无敌流
- 女频Top5：年代甜宠 > 萌宝 > 虐渣打脸 > 重生逆袭 > 团宠
- 新兴：规则怪谈、末日生存、AI题材

### 2.2 写作规范

**✅ 必须做**：
1. 前3章必须有1-2个爽点（打脸/逆袭/金手指）
2. 每章末尾留钩子（悬念/反转）
3. 快节奏推进，拒绝慢热铺垫
4. 情绪要强烈（愤怒→爽→期待）
5. 对话占比高，减少大段描写

**❌ 不能做**：
1. 慢热铺垫（读者3章内不追读就流失）
2. 长篇世界观设定（读者没耐心）
3. 复杂多线叙事（免费读者不追）
4. 断更（流量清零，每月仅1天请假）

### 2.3 番茄注意事项

| 类型 | 事项 |
|------|------|
| 🔴 红线 | 断更=流量清零，每月仅1天请假 |
| 🔴 红线 | 同一作者每月仅1部作品享全勤 |
| 🟡 风险 | 首秀数据定生死，10万字是生死线 |
| 🟡 风险 | 编辑可能是机器人"番番"，沟通效率低 |
| 💡 技巧 | 新人前10万字有流量扶持期 |
| 💡 技巧 | 每章末尾必须留钩子 |
| 💡 技巧 | 听读收益>200元才能领全勤奖 |

### 2.4 AI写作特别提示

番茄对AI内容是灰色地带，建议人工精修去AI味后再投。

## 三、七猫小说（保底最稳）

### 3.1 平台特点

**平台定位**：保底友好，稳定收入
**风格偏好**：爽文、种田文，下沉市场为主

### 3.2 写作规范

| 项目 | 规定 |
|------|------|
| **签约门槛** | 2万字可投稿 |
| **章节字数** | 建议每章3000-4000字 |
| **日更要求** | 必须日更4000字 |
| **精品签保底** | 千字20起步，大神千字1000 |
| **全勤奖** | 千字6元 |
| **收益模式** | 作品期保底→成熟期超保底后分成 |

**🔴 红线**：用无关文字占章节=恶劣行为，关小黑屋90天！
**🔴 红线**：断更直接影响保底评审

**✅ 七猫特色**：
1. 精品路线：对质量要求高于番茄
2. 2026新增"新人训练营"，降低入门门槛
3. 千字20起保底，不容易砍保底
4. 长篇为王：百万字以上更容易变现
5. 节奏可稍慢于番茄，但不能拖沓

**⚠️ 隐藏要求**：
- 过稿要求高，需要看历史成绩
- 审稿时间较长
- 纯新人过稿难度较高

## 四、知乎盐选（短篇之王）

### 4.1 平台特点

**平台定位**：付费阅读，短篇为主
**风格偏好**：第一人称叙述、真实感、情绪共鸣、反转设计

### 4.2 写作规范

| 项目 | 规定 |
|------|------|
| **短篇投稿** | 全稿8000字起投，上限10万字 |
| **长篇投稿** | 总篇幅10万-30万字，投稿字数不低于3万字 |
| **审核周期** | 20天（超时可问盐选小助手） |
| **扣税规则** | 统一扣5%个税，到手95% |
| **收益构成** | 付费阅读分成+会员分成+版权分成 |

### 4.3 盐选结构公式（必须遵守）

| 节点 | 要求 | 示例 |
|------|------|------|
| 前200字 | 拎主线+找看点 | 直接抛核心事件/冲突 |
| 前1000字 | 明确主角欲望+动机 | 为什么主角要做这件事 |
| 前3000字 | 预埋悬念 | 让读者产生"然后呢" |
| 前1/3或1/2 | 设置大转折或小高潮 | 颠覆读者预期 |

**✅ 盐选特色**：
1. 第一人称叙述（代入感强）
2. 真实感（像发生在身边的事）
3. 情绪共鸣（读者能感同身受）
4. 反转设计（至少2-3次反转）
5. 结局留白或和解（不要太圆满）

**🔴 禁止**：
1. AI拼内容（明确禁止，封号风险）
2. 刷量（取消收益）
3. 抄袭（零容忍）

**🟡 风险**：审核周期20天，超时需主动问盐选小助手

## 五、起点中文网（男频龙头）

### 5.1 平台特点

**平台定位**：付费阅读，精品导向
**风格偏好**：深度、世界观完整、智斗、人物塑造立体

|------|------|
| **签约门槛** | 编辑邀约/投稿 |
| **章节字数** | 建议2000-3000字 |
| **日更要求** | 日更4000字 |
| **总字数** | 30万字起 |
| **收益模式** | 订阅分成 |

**✅ 起点特色**：
1. 世界观构建要扎实（读者很挑剔）
2. 升级体系要有新意（不能老套）
3. 人物塑造要立体（非工具人）
4. 可以慢热，但要有亮点
5. 注重细节和逻辑自洽
6. IP改编经验丰富，适合长期发展

**⚠️ 注意**：
- 🔴 红线：连续两月VIP有效更新<6万字=违约
- 🔴 红线：入V后月均必须4000字/天
- 🟡 风险：签约后版权归平台，作者保留署名权
- 🟡 风险：1000-1999字按1000字计算
- 💡 技巧：入V后3个月内可拿创作补贴最高4500元/月
- 💡 技巧：20%自有平台订阅稿酬扶持
- 💡 技巧：IP改编经验丰富，可争取影视分成

## 十四、签约前必查清单

签约前花10分钟检查以下事项，比写完后踩坑重写好100倍：

- [ ] 版权归属是否清晰
- [ ] 日更要求是否能做到
- [ ] 全勤奖门槛是否合理
- [ ] 合同是否有自动续约条款
- [ ] 平台对AI内容的态度
- [ ] 历史成绩是否影响过稿
- [ ] 收益模式是否透明
- [ ] 是否有隐藏扣费/分成

## 十五、AI写作安全操作手册

最安全方式：AI出初稿→人工精修→投稿

| 步骤 | 操作 | 目的 |
|------|------|------|
| Step 1 | AI生成初稿 | 提高效率 |
| Step 2 | 人工重写开头200字 | 确保原创性 |
| Step 3 | 修改AI痕迹（重复句式/僵硬对话） | 去AI味 |
| Step 4 | 加入个人经历/细节 | 增加真实感 |
| Step 5 | 全文通读+润色 | 确保文风统一 |
| Step 6 | 用原创检测工具检查 | 避免抄袭风险 |

**特别注意**：知乎盐选明确禁止AI拼内容，投稿前必须人工精修到无法检测出AI痕迹的程度。

## 十六、黄金三章法则

### 16.1 核心结构

```
第1章：Who（主角是谁）+ Why（为什么有趣）
第2章：How（怎么做到的/能力展示）
第3章：Wow（第一个高潮/打脸）
```

### 16.2 三章详解

**第一章：建立**
- 主角出场（身份、处境）
- 核心冲突/危机
- 金手指暗示或觉醒
- 留下悬念钩子

**第二章：展开**
- 能力/金手指详细展示
- 第一次小试牛刀
- 与反派的初次交锋
- 持续推进的悬念

**第三章：爆发**
- 第一个高潮点
- 第一次爽点/打脸
- 建立信心和优势
- 为后续埋下伏笔

### 16.3 检验标准

- [ ] 读者能记住主角是谁
- [ ] 读者知道故事讲什么
- [ ] 读者想知道后续发展
- [ ] 有让人"想看下去"的钩子

### 16.4 反例提醒

**错误开局**：
- 大段世界观介绍
- 与主角无关的场景
- 冗长的背景铺垫
- 过于平淡的开局

**正确做法**：
- 主角第一时间出场
- 冲突/危机立刻出现
- 信息逐步释放
- 节奏紧凑
