# 番茄数据监控指南

> 来源：网文写作实战技巧大全（2026版）
> 适用：番茄/七猫等推荐算法驱动平台

## 关键指标

| 指标 | 说明 | 健康值 | 优化方法 |
|------|------|--------|----------|
| **读完率** | 读完本章的用户占比 | >60% | 优化断章、增加爽点 |
| **加入书架率** | 收藏转化 | >10% | 提升内容质量 |
| **日读人数** | 每日阅读人数 | 持续增长 | 保持更新 + 优化开头 |
| **段评数** | 每章评论数 | >50条 | 制造讨论点 |
| **分享率** | 用户分享行为 | >5% | 制造情感共鸣 |

## 数据异常应对

| 异常 | 可能原因 | 应对 |
|------|----------|------|
| 读完率下降 | 章节平淡 / 断章无效 | 检查最近3章，增加爽点 |
| 收藏率下降 | 内容质量下滑 | 回顾大纲，找回主线 |
| 日读人数停滞 | 推荐位到期 | 优化数据，等新推荐 |
| 评论减少 | 缺乏讨论点 | 制造争议 / 悬念 |
| 分享率下降 | 缺乏情感共鸣 | 增加情感戏 / 金句 |

| 平台 | 爽点密度 | 说明 |
