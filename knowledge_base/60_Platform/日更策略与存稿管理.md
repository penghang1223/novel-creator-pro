# 日更策略——不断更就是胜利

> 来源：网文写作实战技巧大全（2026版）by 望舒
> 适用：番茄/七猫等免费平台长篇网文

## 日更字数规划

| 阶段 | 字数 | 时间 | 说明 |
|------|------|------|------|
| **准备期** | 存稿3万字 | 1周 | 开书前存稿，应对突发 |
| **新书期** | 日更4000-6000字 | 2-3小时/天 | 冲首秀，越更越快起量 |
| **稳定期** | 日更4000字 | 2小时/天 | 保持全勤，领全勤奖 |
| **爆发期** | 日更6000-8000字 | 3-4小时/天 | 推荐位期间加更 |

## 写作时间管理

| 时间段 | 建议 | 说明 |
|--------|------|------|
| **早晨** | 写新章 | 头脑清醒，适合创作 |
| **中午** | 修改/存稿 | 碎片时间，适合修改 |
| **晚上** | 写新章/发布 | 整块时间，集中输出 |

## 断更应对策略

| 情况 | 应对 |
|------|------|
| 生病/急事 | 提前请假（每月仅1天） |
| 卡文 | 写过渡章/日常章，不断更 |
| 没时间 | 提前存稿，应对突发 |
| 灵感枯竭 | 看竞品/读者评论/热搜找灵感 |

## 存稿策略

```
目标：始终保持3万字存稿
方法：
1. 日更4000字，实际写5000字，多1000字存入稿库
2. 30天后存稿 = 3万字
3. 突发情况用存稿顶替
```

## 核心原则

1. **日更是第一原则，断更=流量清零**
2. **先写3万字存稿，再开书**
3. **坚持写到50万字+，越长越赚钱**
