# 番茄收益与推荐机制

> 知道番茄怎么赚钱、怎么推荐，写作时才知道什么指标最重要。

---

## 收益模式

番茄小说是**免费阅读+广告分成**模式：

| 收益来源 | 说明 |
|----------|------|
| 广告分成 | 读者看广告产生的收入按比例分给作者 |
| 全勤奖 | 日更达标有额外奖励 |
| 完本奖 | 完结后根据数据给一次性奖励 |

**核心结论**：作者赚多少钱 = 读者数 × 人均阅读时长 × 广告展示次数。所以**完读率和追读率**是最重要的指标。

---

## 推荐池机制

番茄的推荐不是人工选书，是**算法推荐池**：

```
新书入库 → 小流量测试（100-500曝光）→ 数据达标 → 进入更大推荐池
                                          → 数据不达标 → 停止推荐
```

### 关键数据指标

| 指标 | 定义 | 达标线 | 说明 |
|------|------|--------|------|
| 完读率 | 读完第N章/读了第N章 | >40% | **最重要**，直接决定推荐量 |
| 追读率 | 连续3天阅读的读者占比 | >20% | 表示读者粘性 |
| 书架收藏率 | 加入书架/看到推荐 | >5% | 表示推荐封面和简介吸引力 |
| 停留时长 | 单次阅读时长 | >15分钟 | 表示内容有吸引力 |

### 推荐池层级

| 层级 | 曝光量 | 进入条件 |
|------|--------|----------|
| 新书池 | 100-500 | 新书发布 |
| 初级池 | 1000-5000 | 完读率>40%，追读率>20% |
| 中级池 | 5000-50000 | 初级池数据持续达标（通常1-2周） |
| 大池 | 50000+ | 中级池数据爆发 |

## 对写作的直接影响

### 完读率 → 章末钩子

完读率 = 读者读完这一章的比例。章末没有钩子 → 读者划走 → 完读率下降 → 推荐量下降。

**写作规则**：每章结尾必须有钩子，类型参考 `网文读者行为模式.md`。

### 追读率 → 日更节奏

追读率 = 读者连续回来阅读。日更比隔日更能维护追读率。

**写作规则**：保持日更，存稿至少3-5章缓冲。

### 书架率 → 书名+简介

读者在推荐列表看到的是**书名+简介+封面**，3秒内决定要不要点。

**写作规则**：书名要有钩子（"被裁员后，我觉醒了XXX"），简介要浓缩核心卖点。

### 前3章 → 存活率

前3章是新书存活的关键。番茄读者在前3章的流失率最高。

**写作规则**：前3章必须有至少2个爽点，第1章前300字必须有冲突/悬念/动作。
