| 类型 | 标签 | 说明 |

| 💡 建议 | `#suggestion` | 读者的建议 |

| 🤔 悬念 | `#suspense` | 读者猜测剧情 |
| 💕 角色爱 | `#character-love` | 对某个角色的喜爱 |

## 📊 使用方式

1. **写前查看**：动笔前看看读者喜欢什么、讨厌什么
2. **避坑指南**：毒点评论 → 更新红线检查规则
3. **风格调整**：好评类型 → 强化对应风格
4. **角色调整**：人气排行 → 调整戏份
