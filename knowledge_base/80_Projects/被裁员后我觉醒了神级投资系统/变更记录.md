## 变更控制规则

### 必须记录的变更类型

| 类型 | 示例 |
|------|------|
| 主线变更 | 改变关键事件顺序、删除/新增主线事件 |
| 人物变更 | 改名、改性格、改背景、新增/删除角色 |
| 能力变更 | 系统等级规则修改、新增/删除能力 |
| 卷结构变更 | 章节重排、合并/拆分卷 |
| 伏笔变更 | 删除已埋伏笔、改变回收章节 |
| 设定变更 | 世界观规则、经济体系、地理设定 |

### 不需要记录的

- 每章内的文字润色、措辞修改
- 单章内的场景调整（只要不改变剧情走向）
- 错别字/格式修复

### 变更流程

1. 想改 → 停下来
2. 说清三件事：原设计是什么、想改成什么、为什么更好
3. 用户确认
4. 执行修改
5. 写入本文件
6. 更新所有受影响的文件
