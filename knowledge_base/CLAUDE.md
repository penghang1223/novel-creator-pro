## 🎯 怎么用这些文件

当主人要求写小说或讨论创意时，你应该：

1. **先查 CLAUDE.md**（就是本文件）了解知识库结构
2. **根据任务类型读取对应文件**：
   - 选方向/定题材 → 读 `00_Inbox/` 中的创意方案
   - 写正文 → 读 `00_Inbox/小说写作指南.md` + `小说创作工作流.md`
   - 毒舌/搞笑风格 → 读 `00_Inbox/毒舌知识库.md` + `毒舌AI示例库.md` + `315条神回复.md`
   - 平台相关 → 读对应平台调研报告
   - 大纲/章节 → 读 `00_Inbox/章节大纲_*.md`

3. **不要一次性全读**！按需读取，避免浪费上下文
