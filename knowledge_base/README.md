## 使用规范

### 写前读取
开始创作前，根据当前小说的题材和风格，读取对应的知识文件：
- 都市文 → `10_WorldBuilding/题材知识库/都市.md`
- 悬疑文 → `10_WorldBuilding/题材知识库/悬疑.md`
- 毒舌风格 → `40_Writing/风格指南/毒舌风格.md` + `70_Corpus/毒舌语料/`

### 写后更新
剧情导致角色状态变化时，更新 `80_Projects/{小说名}/` 中的对应文件。

### 质量检查
每章完成后执行 `50_Quality/` 中的检查流程：
1. 章节前检查（9问）
2. 红线系统（三级红线）
3. 评估系统评分

### 语料使用
需要毒舌/搞笑内容时，从 `70_Corpus/` 中随机抽取灵感，不要照搬原文。

### 平台发布

发布前阅读 `60_Platform/` 中对应平台的规则和商业情报。

## 创作工作流

立项 → 题材知识库 → 创意策划 → 角色设定 → 大纲规划

细纲 → 记忆初始化 → 正文写作（章前检查 → 写作 → 审计）

质量评估 → 记忆回填 → 发布 → 复盘

详见 `40_Writing/工作流v2.md`
