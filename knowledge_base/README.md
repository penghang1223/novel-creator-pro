## 使用规范

### 写前读取
开始创作前，根据当前小说的题材和风格，读取对应的知识文件：
- 都市文 → `10_WorldBuilding/题材知识库/都市.md`
- 毒舌风格 → `40_Writing/风格指南/毒舌风格.md` + `70_Corpus/毒舌语料/`

### 写后更新
剧情导致角色状态变化时，更新 `80_Projects/{小说名}/` 中的对应文件。

### 质量检查
每章完成后执行 `50_Quality/` 中的检查流程。

### 语料使用
需要毒舌/搞笑内容时，从 `70_Corpus/` 中随机抽取灵感，不要照搬原文。
