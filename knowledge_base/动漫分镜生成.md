# 动漫分镜生成

> 剧本 → 视觉指令转换系统。六大模块架构。

---

## 核心定位

将剧本/小说转化为动漫制作所需的专业分镜内容，输出 5 种类型产物。

## 一、5 种输出类型

| 输出类型 | 格式 | 用途 |
|---------|------|------|
| 角色形象 | 结构化档案 | 角色设定参考 |
| 角色提示词 | AI 绘画指令 | Midjourney/SD |
| 场景提示词 | 双段式描述 | 纯环境场景生成 |
| Sora 分镜提示词 | JSON 数组（3 段式） | 视频生成 |
| 分镜提示词 | Markdown 表格 | 即梦等工具 |

## 二、核心铁律

### 场景零人物铁律
- 绘图指令**绝对禁止**出现任何人物
- **必须包含**：`empty` / `scenery only` / `no people`
- 画面描述（中文）可含人物活动
- 绘图指令（英文）必须纯环境

### 双通道逻辑
```
通道1：画面描述（中文）→ 可提及人物、故事背景
通道2：绘图指令（英文）→ 纯环境，删除所有人物相关词汇
```

### 黑名单（绘图指令禁止）
- 人物：`man, woman, person, character, figure, human, people`
- 部位：`face, hand, body, head, foot, arm, leg, eye`
- 动作：`sitting, standing, walking, running, lying`
- 衣物：`dress, robe, coat, shirt, pants, shoes, hat`
- 暗示：`silhouette, shadow of person, human figure`

## 三、6 种景别

| 景别 | 作用 | 时长建议 |
|------|------|---------|
| 远景 | 展示环境、交代场景 | 2-3 秒 |
| 全景 | 人物全身+环境关系 | 2-3 秒 |
| 中景 | 对话、普通叙事 | 1.5-2 秒 |
| 近景 | 情绪表达、重要对话 | 1-2 秒 |
| 特写 | 情绪高潮、关键细节 | 1-2 秒 |
| 大特写 | 瞳孔、泪珠、道具细节 | 1 秒 |

## 四、9 种运镜

| 运镜 | 效果 | 使用场景 |
|------|------|---------|
| 固定 | 冷静、客观 | 对话、环境交代 |
| 推镜 | 紧张感、聚焦 | 强调情绪、聚焦细节 |
| 拉镜 | 释放、孤独感 | 展示环境、转场 |
| 摇镜 | 流畅转换 | 跟随人物、扫描场景 |
| 俯镜 | 压迫/仰望 | 展示高低差 |
| 晃动 | 紧张、混乱 | 混乱场景、主观视角 |
| 跟拍 | 沉浸感 | 人物移动、转场 |
| 旋转 | 戏剧化、冲击力 | 环视环境、强化情绪 |
| 推拉镜 | 不安感 | 情绪突变、梦境 |

## 五、多样化约束

- 景别 ≥ 5 种，相邻镜头不重复
- 运镜 ≥ 5 种，同种连续 ≤ 3 次
- 时长有变化（1-3 秒）
- Sora 分镜每镜必须含 3 个时间段：0-3 秒/3-7 秒/7-10 秒

## 六、Sora 分镜三段式

| 时间段 | 作用 | 典型内容 |
|--------|------|---------|
| 0-3 秒 | 建立场景 | 环境交代、事件触发 |
| 3-7 秒 | 事件发展 | 动作展开、情绪升级 |
| 7-10 秒 | 事件结果 | 动作完成、转场准备 |

## 七、执行流程

```
用户输入剧本
  ↓
询问需要生成哪些内容（1-5）
  ↓
结构化信息提取（角色/场景/动作）
  ↓
多模态转换（提示词/分镜）
  ↓
镜头语言适配（景别/运镜）
  ↓
格式化输出
  ↓
质量控制（11 项场景检查 + 多样性验证）
  ↓
交付
```

## 八、场景生成模板

```
Interior of a [空间类型], empty.
[家具陈设]
[装饰物品]
[光线效果]
[环境氛围]
8k, --ar 16:9, --v 6.0
```

## 九、质量检查清单（场景）

- [ ] 包含 `empty`/`scenery only`/`no people`
- [ ] 无任何人物词汇
- [ ] 无任何人部位
- [ ] 无任何人物动作
- [ ] 无任何人物衣物
- [ ] 无任何人物暗示
- [ ] 描述了空间结构
- [ ] 描述了家具陈设
- [ ] 描述了光线效果
- [ ] 描述了环境氛围
- [ ] 包含技术参数

---

**核心口号**：绘图指令是纯环境，场景里没有人。

## 十、角色/场景一致性控制

> AI视频每一帧独立生成，没有"记忆"。必须通过种子词+参考图+特征强调引导一致性。来源：anime-storyboarder技能体系。

### 角色种子词模板

```
[角色标识符:角色名] [年龄性别], [体型], [发型发色],
[标志性特征], [服装风格],
保持外貌一致, 同一个人, 维持身份
```

**示例**：
```
[角色标识符:萨拉] 28岁亚洲女性, 苗条体型,
黑色长卷发, 侧分刘海, 大杏仁眼,
左眼旁有美人痣, 笑时有酒窝,
穿着白色西装和黑色裤子,
保持外貌一致, 同一个人, 维持身份
```

### 关键特征优先级

| 优先级 | 特征 | 要求 |
|--------|------|------|
| 最高 | 性别、年龄、发型发色、最明显面部特征 | 必须每帧出现 |
| 高 | 体型、肤色、服装主体 | 应该一致 |
| 中 | 配饰、细节特征、表情基调 | 尽量一致 |

### 多镜头角色控制策略

| 策略 | 方法 |
|------|------|
| 种子词前缀 | 每个镜头提示词开头加 `[角色标识符:名] 与之前镜头保持一致,` |
| 参考图锚定 | 先生成高质量定妆照，所有后续镜头引用该图 |
| 特征重复强调 | 每个镜头重复3-5个核心特征词 |

### 服装变化处理

```
场景1-5：[角色标识符:萨拉] ... 穿着白色西装套装 (服装A)
场景6-10：[角色标识符:萨拉] ... 穿着酒红色连衣裙 (服装B), 同之前场景的同一角色, 仅更换服装
```

### 场景一致性控制

```
[场景标识符:场景名] [室内/室外] [地点类型],
[空间特征], [关键道具],
[光线条件], [色彩氛围],
保持环境一致, 维持地点
```

**空间元素锁定**：
- 墙壁/背景：明确指定方位（左墙、右墙）
- 窗户/门：固定位置描述
- 主要家具：列出并固定相对位置
- 装饰元素：选择2-3个标志性装饰

### 光线一致性

| 时间段 | 光线描述 |
|--------|----------|
| 早晨 | 柔和光, 温暖, 低角度阳光从东侧 |
| 正午 | 明亮光线, 中性, 顶部太阳 |
| 下午 | 温暖光线, 温暖, 太阳从西侧 |
| 黄昏 | 黄金时刻, 橙色暖光, 长阴影 |
| 夜晚 | 人造光源, [指定光源], 冷或暖 |

### 一致性档案（生成前建立）

```yaml
# 角色档案
character_profiles:
  - id: SARAH
    seed_prompt: "28yo Asian female, slim, long black wavy hair..."
    key_features: ["black wavy hair", "almond eyes", "beauty mark"]
    costumes:
      - scenes: 1-5
        description: "white blazer, black trousers"

# 场景档案
scene_profiles:
  - id: COFFEE_SHOP
    seed_prompt: "modern coffee shop, brick wall, large windows..."
    key_elements: ["exposed brick", "pendant lights", "wooden tables"]
    lighting: "warm morning light from windows"
```

### 生成顺序

```
1. 为每个角色生成"定妆照"作为参考
2. 为每个场景生成"空镜头"作为场景参考
3. 先生成所有同一角色单独出镜镜头 → 检查一致性
4. 再生成多角色同框镜头 → 检查一致性
5. 最后生成群戏镜头 → 检查一致性
```

### 一致性质量检查清单

**角色**：
- [ ] 发型发色一致
- [ ] 面部特征可识别
- [ ] 体型比例一致
- [ ] 服装符合当前场景设定
- [ ] 标志性特征保留（痣、疤痕等）

**场景**：
- [ ] 背景元素位置一致
- [ ] 关键道具存在
- [ ] 空间比例合理
- [ ] 窗户/门位置一致
- [ ] 装饰元素一致

**光线**：
- [ ] 光源方向一致
- [ ] 阴影方向匹配光源
- [ ] 色温统一
- [ ] 亮度符合时间设定
- [ ] 人物与环境光线匹配

### 常见问题排查

| 问题 | 原因 | 解决方案 |
|------|------|----------|
| 角色脸部变化 | 特征描述不够具体 | 增加更多面部细节词 |
| 发型改变 | 发型权重不够 | 将发型描述放在前面，加强调 |
| 服装颜色变化 | 颜色描述不精确 | 使用具体颜色词而非模糊描述 |
| 场景元素消失 | 关键元素未强调 | 种子词中明确列出必须出现的元素 |
| 光线方向不一致 | 未指定光源方向 | 明确标注光源位置和方向 |
| 整体风格跳变 | 风格词不一致 | 统一使用相同的风格关键词组 |
