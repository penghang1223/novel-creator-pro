# 开场钩子与标题库

## 概览

开场钩子是抓住读者的第一道门槛，必须在前100字内出现，直接抛出异常，不铺垫背景，一句话抓住读者注意力。

## 使用建议

### 选择原则

**1. 根据题材选择对应的钩子**

- 都市怪谈：选择都市怪谈钩子
- 侦探悬疑：选择侦探悬疑钩子
- 科幻：选择黑镜式科幻钩子
- 情感：选择情感爆裂钩子
- 职场：选择职场复仇钩子
- 爽文：选择身份错位钩子

**2. 钩子必须在前100字出现**

- 不要铺垫背景
- 不要介绍人物
- 直接抛出异常
- 一句话抓住读者

**3. 标题要吸引人点击**

- 使用"日常物+反常动因+悬问/后果"公式
- 暗示故事的核心冲突
- 不要完全剧透反转
- 制造好奇心和期待感

### 钩子设计技巧

**技巧1：违背常识**

- 描述一个违背日常逻辑的场景
- 让读者产生"这不可能"的反应
- 立即产生"为什么"的疑问

**技巧2：信息不对等**

- 读者知道的信息比人物多（制造焦虑）
- 人物知道的信息比读者多（制造悬念）
- 信息不对称引发好奇心

**技巧3：时间倒错**

- 现在发生未来才能发生的事
- 过去的信息影响现在
- 时间的错位制造神秘感

**技巧4：身份错位**

- 主角的身份不是表面那样
- 他人的认知与事实不符
- 身份揭秘是核心冲突

**技巧5：规则破坏**

- 现实世界的规则被打破
- 产生无法解释的现象
- 规则的破坏引发危机

### 标题生成技巧

**技巧1：数字对比**

- 《第1001次死亡》
- 《第0号嫌疑人》
- 《3个人的谎言》
- 《1个真相》

**技巧2：矛盾并置**

- 《活着的尸体》
- 《透明的秘密》
- 《温柔的谋杀》
- 《安静的尖叫》

**技巧3：省略疑问**

- 《谁杀了他？》
- 《她去哪了？》
- 《为什么是我？》
- 《真的有鬼吗？》

**技巧4：名词+动词**

- 《时间停止》
- 《记忆消失》
- 《身份曝光》
- 《真相浮现》

### 高级技巧

**技巧1：钩子与标题的呼应**

钩子和标题要形成呼应关系，让读者看到标题就想点击，看到钩子就想继续。

**技巧2：钩子与核心冲突的绑定**

钩子必须直接指向故事的核心冲突，而不是无关紧要的细节。

**技巧3：钩子的后续铺垫**

钩子抛出后，前1-3章要不断强化这个异常，同时逐步揭示背后的真相。

**技巧4：钩子的反转设计**

钩子表面看是A，真相其实是B。读者以为是这样的，结果完全不是。

**技巧5：钩子的情感绑定**

钩子不仅要制造悬念，还要绑定情感。让读者既想知道真相，又担心人物命运。

### 常见错误

**错误1：钩子出现太晚**

在前100字内没有钩子，一直在铺垫背景和人物。

**错误2：钩子不够异常**

描述的是日常场景，没有违背常识或制造悬念。

**错误3：钩子与核心冲突无关**

钩子很吸引人，但与故事主线没有直接关系。

**错误4：标题过于直白**

标题直接揭示了反转，没有悬念感。

**错误5：钩子后续没有呼应**

钩子抛出后，后续情节没有强化或解释这个钩子。

### 钩子强度分级

**A级（最强）**：直接违背常识，制造强烈震撼

- "我看到了自己的葬礼。"
- "电梯停在了12层——这栋楼只有11层。"

- "外卖员看着我，'你确定住在这儿？这栋楼没人住'。"

- "快递单上的签收人，是我三年前的签名。"
- "旧手机收到了一条短信，发送者是我已故的奶奶。"

- "邻居家的猫，每到午夜就会对着墙角叫。"
- "玩具熊的眼睛，看着我移动了。"

## 总结

开场钩子是抓住读者的关键，必须：

1. **快**：在前100字内出现
2. **异常**：违背常识或制造悬念
3. **直接**：不铺垫背景，直接抛出
4. **相关**：与核心冲突直接相关
5. **延续**：后续情节要呼应和强化

标题要：

1. **吸引**：使用"日常物+反常动因+悬问/后果"公式
2. **暗示**：暗示核心冲突，但不完全剧透
3. **好奇**：制造好奇心，引导点击
4. **简洁**：简洁有力，记忆点强

记住：钩子和标题的目标是让读者从"随便看看"变成"必须读完"。
