## 评估理念

**核心原则**：大纲是故事的骨架，决定作品能走多远。

结构规划评估回答的问题不是"这个故事精不精彩"，而是：
- 这个故事能讲下去吗？
- 有没有写到一半就讲不下去的风险？
- 节奏安排是否合理？

**与前一阶段的区别**：

| 对比项 | 设定评估 | 结构规划评估 |
|-------|---------|-------------|
| 核心问题 | 能不能写？ | 能不能讲下去？ |
| 评估重点 | 自洽性、可操作性 | 主线清晰度、节奏合理性 |
| 失败后果 | 写不下去 | 讲不下去、烂尾 |
| 判断标准 | 可用/需补充/有硬伤 | 可用/需调整/有硬伤 |

## 评估维度

### 维度一：主线清晰度

**核心问题**：读者知道主角要干什么吗？

| 检查项 | 具体问题 |
|-------|---------|
| 目标明确 | 主角的终极目标是什么？读者能说出来吗？ |
| 阻力明确 | 谁在阻碍主角？为什么阻碍？ |
| 终点明确 | 故事的结局方向是什么？主角最终会怎样？ |
| 阶段目标 | 每个阶段主角在追求什么？ |

**判断等级**：清晰 / 模糊 / 不明确

### 维度二：节奏设计

**核心问题**：高潮分布是否合理？

| 检查项 | 具体问题 |
|-------|---------|
| 开篇节奏 | 前三章是否有足够吸引力？是否有小高潮？ |
| 高潮分布 | 大高潮的位置是否合理？间隔是否恰当？ |
| 张弛有度 | 有没有连续高潮导致的疲劳？有没有连续平淡导致的流失？ |
| 完本规划 | 是否有明确的完本节点？能否收得住？ |

**判断等级**：合理 / 有问题

### 维度三：结构完整性

**核心问题**：故事结构是否完整？

| 检查项 | 具体问题 |
|-------|---------|
| 开头设计 | 开头是否切入到位？是否铺垫过多？ |
| 发展设计 | 主角成长路径是否清晰？升级节奏是否合理？ |
| 高潮设计 | 高潮是否有铺垫？是否有足够的张力？ |
| 结局设计 | 结局是否呼应开头？是否满足读者期待？ |

**判断等级**：完整 / 需补充 / 有缺失

### 维度四：支线管理

**核心问题**：支线是否服务于主线？

| 检查项 | 具体问题 |
|-------|---------|
| 支线数量 | 支线是否过多？读者会不会迷失？ |
| 支线作用 | 每条支线是否服务于主线？有没有无关支线？ |
| 支线收束 | 支线是否有收束计划？会不会烂尾？ |
| 支线节奏 | 支线是否会打断主线节奏？ |

**判断等级**：可控 / 有风险 / 失控风险

### 维度五：篇幅预估

**核心问题**：这个故事能写多长？

| 检查项 | 具体问题 |
|-------|---------|
| 素材储备 | 目前的素材能支撑多少字？ |
| 扩展空间 | 如果要写更长，有扩展空间吗？ |
| 压缩空间 | 如果要写更短，能压缩吗？ |
| 平台匹配 | 篇幅是否符合目标平台的要求？ |

**判断等级**：合理 / 偏长 / 偏短

### 维度六：承诺校验

**核心问题**：大纲是否兑现了创意和设定阶段的承诺？

| 检查项 | 核心问题 |
|-------|---------|
| 钩子落地 | 大纲是否设计了展现核心钩子的情节？ |
| 卖点兑现 | 大纲是否安排了体现核心卖点的章节？ |
| 爽点规划 | 大纲是否规划了爽点的出现节奏？ |
| 设定支撑 | 大纲是否充分利用了设定阶段的成果？ |

**判断等级**：兑现 / 部分兑现 / 偏离

## 硬伤清单

| 硬伤类型 | 具体问题 | 后果 |
|---------|---------|-----|
| **主线不明** | 不知道主角要干什么，没有终点 | 读者流失，作者写不下去 |
| **节奏崩坏** | 开篇慢热/中期拖沓/后期赶工 | 读者弃书 |
| **高潮缺失** | 全文没有明确的高潮点 | 读者无感 |
| **支线失控** | 支线太多、支线不收、支线喧宾夺主 | 主线被淹没，读者迷失 |
| **篇幅失控** | 没有完本规划，写到哪算哪 | 烂尾或太监 |
| **承诺偏离** | 大纲偏离了创意/设定阶段的方向 | 读者预期落空 |

```
  核心阻力：[谁在阻碍]
  结局方向：[故事走向]
  阶段划分：[几个阶段，每阶段目标]

  开篇节奏：[前三章安排]
  高潮节点：[大高潮位置]
  张弛分析：[是否合理]

■ 结构完整性：[完整/需补充/有缺失]
  ✓ [已设计]

■ 支线管理：[可控/有风险/失控风险]
  支线数量：[XX条]
  支线清单：[每条支线的目的]

  预估字数：[XX万字]

■ 承诺校验：[兑现/部分兑现/偏离]

  ✓ 无硬伤

  ✗ [硬伤2：具体描述]

■ 需要调整的部分：

  1. [问题项]

  【必须修复】

```

## 判断标准

| 判断 | 条件 | 后续处理 |
|-----|-----|---------|
| **可用** | 无硬伤 + 主线清晰 + 节奏合理 + 承诺兑现 | 生成大纲文档，进入确认环节 |
| **需调整** | 无硬伤 + 有部分问题需优化 | 调整后重新评估 |
| **有硬伤** | 存在硬伤 或 承诺偏离 | 必须修复硬伤后重新评估 |

## 优化建议方法

### 主线不明

**问题表现**：不知道主角要干什么，没有终点

**修复方向**：
1. 明确主角的终极目标（想要什么）
2. 明确核心阻力（谁在阻碍）
3. 设计阶段目标（短期/中期/长期）
4. 确定故事结局方向

### 节奏崩坏

**问题表现**：开篇慢热/中期拖沓/后期赶工

**修复方向**：
1. **开篇慢热**：前置冲突，减少铺垫，加快进入主线
2. **中期拖沓**：插入新冲突/新支线/新地图，打破重复
3. **后期赶工**：提前规划收束节点，预留足够的收尾章节

**节奏设计参考**：
```
- 前3章：小高潮，确立主角目标和困境
- 前10章：第一个小目标达成
- 每30-50章：一个阶段性高潮
- 每100章：一个大高潮
```

### 高潮缺失

**问题表现**：全文没有明确的高潮点

**修复方向**：
1. 确定故事的最高潮是什么事件
2. 设计高潮前的铺垫和积累
3. 确保高潮有足够的情感冲击力
4. 高潮后给予读者"释放"的空间

### 支线失控

**问题表现**：支线太多、支线不收、支线喧宾夺主

**修复方向**：
1. **支线太多**：删除与主线无关的支线，合并相似支线
2. **支线不收**：为每条支线设计收束节点
3. **支线喧宾夺主**：缩减支线篇幅，让支线服务于主线

**支线管理原则**：
- 每条支线必须有存在的理由（推进主线/塑造人物/铺垫伏笔）
- 每条支线必须有收束计划
- 支线篇幅不应超过同阶段主线的1/3

### 篇幅失控

**问题表现**：没有完本规划，写到哪算哪

**修复方向**：
1. 明确目标篇幅（短篇/中篇/长篇）
2. 规划完本节点（主线目标达成时）
3. 预留扩展空间（如果要写更长）
4. 设计备选结局（如果要提前完本）

**篇幅规划参考**：
```
- 短篇：30-50万字，适合番茄、知乎
- 中篇：100-200万字，适合多数平台
- 长篇：300万字以上，适合起点
```

### 承诺偏离

**问题表现**：大纲偏离了创意/设定阶段的方向

**修复方向**：
1. 回顾创意评估报告中的核心钩子和卖点
2. 回顾设定评估报告中的关键设定
3. 确保大纲中有体现这些核心要素的章节
4. 如果大纲更好，考虑更新创意/设定方案
