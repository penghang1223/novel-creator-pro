## 概述

### 什么是偏差

偏差是指正文创作与细纲规划之间的差异。

| 偏差类型 | 定义 | 严重程度 |
|---------|------|---------|
| 灵活区调整 | 不涉及主节点的差异 | 低 - 正常范围 |
| 主节点偏离 | 涉及主节点的差异 | 高 - 需要干预 |

### 偏差处理的必要性

| 问题 | 解决方案 |
|------|---------|
| 写着写着就偏了 | 及时识别偏差类型 |
| 不知道能不能继续 | 根据偏差类型决定处理方式 |
| 主节点偏离导致后续崩坏 | 编辑介入，用户确认 |

## 偏差类型判断

### 判断流程

```
检测到细纲与正文存在差异

↓

判断差异是否涉及主节点？
├── 涉及主节点 → 主节点偏离
│   └── 编辑介入，用户确认
│
└── 不涉及主节点 → 灵活区调整
    └── 记录差异，继续写作
```

### 判断标准

| 判断项 | 灵活区调整 | 主节点偏离 |
|--------|-----------|-----------|
| 是否涉及主节点？ | 否 | 是 |
| 是否影响后续主节点？ | 否 | 是或可能 |
| 是否改变故事走向？ | 否 | 是 |
| 是否改变人物关系？ | 轻微变化 | 重大变化 |
| 是否改变实力等级？ | 否 | 是 |

### 典型场景

| 场景 | 偏差类型 | 说明 |
|------|---------|------|
| 增加一个过渡情节 | 灵活区调整 | 不影响主节点 |
| 调整配角出场顺序 | 灵活区调整 | 不影响主节点 |
| 主角提前突破境界 | 主节点偏离 | 改变实力等级 |
| 跳过关键冲突 | 主节点偏离 | 影响后续主节点 |
| 改变高潮结果 | 主节点偏离 | 影响故事走向 |

## 处理流程

### 灵活区调整处理流程

```
检测到灵活区调整

↓

记录差异
├── 更新细纲执行记录
├── 说明差异内容
└── 标注为"灵活区调整"

↓

继续写作
```

### 主节点偏离处理流程

```
检测到主节点偏离

↓

编辑介入
├── 标识偏离类型
├── 评估影响范围
└── 提供处理建议

↓

用户确认
├── 接受偏离 → 更新细纲，继续写作
├── 修正正文 → 按细纲重写
└── 暂停讨论 → 暂停创作
```

## 灵活区调整处理

### 触发条件

- 当前章节类型为【灵活区】或【过渡】
- 正文与细纲存在差异
- 差异不涉及主节点

### 处理步骤

1. **识别差异**：对比细纲与正文，列出差异点
2. **评估影响**：确认差异不影响后续主节点
3. **记录差异**：在细纲执行记录中记录
4. **继续写作**：按正文实际情况继续

### 记录格式

```markdown
## 第X章执行记录

**章节类型**：【灵活区】

| 项目 | 细纲规划 | 实际执行 | 差异说明 |
|-----|---------|---------|---------|
| 主要内容 | 铺垫宗门环境 | 增加了一个小冲突 | 增加冲突让节奏更紧凑 |

**执行状态**：✓ 灵活区调整（已记录）
```

## 主节点偏离处理

### 触发条件

- 当前章节类型为【主节点】
- 正文与细纲存在差异
- 或灵活区调整影响了后续主节点

### 编辑介入

当检测到主节点偏离时，编辑角色介入：

```markdown
【编辑】
━━━━━━━━━━━━━━━━━━━━━━━━━━━━
检测到主节点偏离

■ 偏离信息
  章节：第X章
  主节点：M3 - 与反派第一次正面冲突
  偏离类型：跳过关键冲突

■ 偏离内容
  细纲规划：主角与反派正面冲突，打脸反派
  实际执行：主角避开了冲突，选择隐忍

■ 影响评估
  - 后续主节点M4（外门大比）将失去铺垫
  - 主角人物弧光可能受影响
  - 读者期待可能落空

■ 处理建议
  1. 接受偏离：更新后续细纲，调整M4的铺垫
  2. 修正正文：按细纲重写，保留冲突情节
  3. 部分修正：在后续章节补充冲突铺垫

请选择处理方式：
━━━━━━━━━━━━━━━━━━━━━━━━━━━━
```

### 用户确认后处理

| 用户选择 | 处理方式 |
|---------|---------|
| 接受偏离 | 更新细纲执行记录，标记为"主节点偏离-已接受"，更新后续细纲 |
| 修正正文 | 按细纲重写该章节，更新细纲执行记录为"已修正" |
| 部分修正 | 在后续章节补充铺垫，更新细纲执行记录 |

### 记录格式

```markdown
## 第X章执行记录

**章节类型**：【主节点】M3

| 项目 | 细纲规划 | 实际执行 | 差异说明 |
|-----|---------|---------|---------|
| 主要内容 | 与反派正面冲突 | 避开冲突，选择隐忍 | 主节点偏离 |

**执行状态**：⚠ 主节点偏离
**用户决策**：接受偏离
**后续调整**：需更新后续细纲，在M4前补充铺垫
```
