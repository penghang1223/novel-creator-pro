## 评估方法

采用**"钩子驱动+风险扫描"评估法**，按网文编辑视角评估创意可行性。

核心问题：
- 这个创意能火吗？
- 为什么能火？
- 有什么风险？

## 评估维度

### 维度一：核心钩子

**核心问题**：能不能在3秒内抓住读者？

| 评估项 | 核心问题 | 好的标准 |
|-------|---------|---------|
| 一句话能说清吗 | 创意能不能用一句话概括？ | 能，且让人想继续问"然后呢" |
| 有没有反差感 | 设定有没有制造冲突和期待？ | 有反常识/反直觉的设定 |
| 有没有悬念 | 读者会不会好奇接下来发生什么？ | 开局就埋下让人想知道答案的问题 |
| 有没有代入感 | 主角的处境是否能让读者共情？ | 困境/目标/身份至少有一个能代入 |
| 有没有情绪钩子 | 读者是否会产生强烈情绪？ | 会担心/期待/愤怒/好奇 |

**判断等级**：强 / 中 / 弱

### 维度二：卖点分析

**核心问题**：这书卖给谁？卖点是什么？

| 评估项 | 核心问题 | 好的标准 |
|-------|---------|---------|
| 受众清晰吗 | 目标读者是谁？男频/女频？年龄？ | 明确知道是写给谁看的 |
| 类型明确吗 | 是什么类型？符合类型惯例吗？ | 类型清晰，符合读者预期 |
| 平台适配吗 | 适合哪个平台？符合平台调性吗？ | 了解起点/番茄/晋江的读者偏好差异 |
| 卖点一句话能说清吗 | 读者为什么要追这本书？ | 有明确的追更理由 |
| 有对标作品吗 | 最接近的成功作品是什么？ | 能说出对标，且知道自己差异在哪 |

**判断等级**：清晰 / 模糊

### 维度三：爽点设计

**核心问题**：读者看这本书能获得什么快感？

| 评估项 | 核心问题 | 好的标准 |
|-------|---------|---------|
| 爽点类型清晰吗 | 逆袭？升级？打脸？装逼？ | 至少有一个核心爽点类型 |
| 爽点能持续吗 | 这个爽点能支撑多少章？ | 能延伸出持续的爽感 |
| 节奏有设计吗 | 爽点的密度和强度有考虑吗？ | 不是想到哪写到哪 |
| 有无疲劳风险 | 同样的爽点会不会看腻？ | 有变化和升级的空间 |

**判断等级**：明确 / 不明确

### 维度四：金手指

**核心问题**：主角的特殊之处有趣吗？好写吗？

| 评估项 | 核心问题 | 好的标准 |
|-------|---------|---------|
| 有记忆点吗 | 金手指能让读者记住吗？ | 独特、好理解、有梗 |
| 有成长空间吗 | 能支撑长期升级吗？ | 不是一次性外挂 |
| 有限制吗 | 没有限制的金手指会崩 | 有代价或限制 |
| 好展开吗 | 能方便地制造剧情吗？ | 金手指能主动触发事件 |
| 与主角弧光匹配吗 | 金手指是否服务于主角成长？ | 金手指推动/阻碍主角成长，形成弧光 |

**判断等级**：有记忆点 / 一般 / 无

### 维度五：风险扫描

**核心问题**：这书有什么坑？

| 风险类型 | 具体问题 | 危险信号 |
|---------|---------|---------|
| 设定崩风险 | 力量体系会不会后期崩？ | 没有明确的等级上限 |
| 剧情崩风险 | 有没有挖坑不填的可能？ | 伏笔太多，收不回来 |
| 读者流失风险 | 什么情况下读者会弃书？ | 开篇慢热/中期重复/后期烂尾 |
| 同质化风险 | 和现有作品太像吗？ | 没有差异点，读者凭什么看你的？ |

## 评估报告格式

```
【创意评估报告】

■ 核心钩子：[强/中/弱]
  一句话概括：[创意的一句话描述]
  钩子分析：[这个钩子为什么能/不能抓住读者]
  反差/悬念/代入/情绪：[具体分析]
  判断：[通过/不通过]

■ 卖点分析：[清晰/模糊]
  目标读者：[谁会看这本书]
  目标平台：[起点/番茄/晋江/其他]
  核心卖点：[读者追更的理由]
  对标作品：[最接近的成功作品]
  差异点：[与对标的区别]

■ 爽点设计：[明确/不明确]
  核心爽点类型：[逆袭/升级/打脸/甜宠/...]
  持续性：[能支撑多久]
  变化空间：[会不会疲劳]

■ 金手指：[有记忆点/一般/无]
  金手指设定：[具体是什么]
  成长空间：[能否支撑升级]
  限制/代价：[有无限制]
  与主角弧光关系：[如何服务于主角成长]

■ 风险扫描：
  ✓ [通过项]
  ⚠ [警告项]
  ✗ [致命伤]

■ 综合判断：[能火/能签有隐患/能签/有救/劝退]

■ 核心问题：[最需要解决的1-3个问题]

■ 优化建议：
  【必须修复】
  1. [问题] → [具体修复方案]
  
  【建议优化】
  1. [问题] → [具体修复方案]
  
  【可选提升】
  1. [问题] → [具体修复方案]
```

## 判断标准

| 判断 | 条件 | 后续处理 |
|-----|-----|---------|
| **能火** | 钩子强 + 卖点清晰 + 爽点明确 + 无致命伤 + 有传播点 | 进入确认环节 |
| **能签有隐患** | 钩子通过 + 卖点清晰 + 有可控风险 | 进入确认环节，需标注风险点 |
| **能签** | 钩子通过 + 卖点爽点及格 + 无致命伤 | 进入确认环节 |
| **有救** | 有亮点 + 有可修复的问题 | 提供优化方案，重新评估 |
| **劝退** | 钩子不通过 或 有致命伤 | 建议换创意或大改 |

**核心原则**：有一项特别强，其他及格就行。但有一项是致命伤，其他再好也救不了。

## 致命伤清单

| 致命伤 | 说明 |
|-------|-----|
| 钩子太弱 | 开篇抓不住人，读者不会给机会 |
| 卖点不清 | 不知道卖给谁，不知道读者追什么 |
| 同质化严重 | 和现有作品没区别，没有看的理由 |
| 设定会崩 | 力量体系没上限，后期必然崩 |
| 没有爽点 | 读者追更图什么？没答案 |

## 优化建议方法

### 新颖性不足时

```
1. 反转法：把常见套路反过来
   - 例：穿越成主角 → 穿越成反派
   - 例：主角升级打怪 → 主角开局满级逐渐失去力量

2. 融合法：两个常见元素组合
   - 例：修仙 + 模拟器
   - 例：都市 + 克苏鲁

3. 换角法：换一个视角或身份
   - 例：从配角视角讲故事
   - 例：从反派视角讲故事

4. 极端法：把某个特征放大到极致
   - 例：主角不是天才，是绝对的天才
   - 例：不是弱，是开局就弱到极致
```

### 可行性不足时

```
1. 补充冲突：必须有明确的对抗力量
   - 问：谁在阻碍主角？
   - 问：主角想要什么？为什么得不到？

2. 补充目标：主角必须有清晰的目标
   - 短期目标是什么？
   - 长期目标是什么？

3. 补充阻力：目标实现需要障碍
   - 外部阻力：敌人、环境
   - 内部阻力：性格缺陷、心理障碍
```

### 市场性不足时

```
1. 明确受众：这部作品写给谁看？
   - 男频/女频？
   - 年龄层？
   - 阅读偏好？

2. 提炼爽点：读者能获得什么快感？
   - 逆袭爽？升级爽？恋爱甜？烧脑刺激？

3. 对标分析：最接近的成功作品是什么？
   - 读者为什么喜欢那部？
   - 我们能学到什么？

4. 平台适配：目标平台的调性是什么？
   - 起点：长篇稳定性、体系完整
   - 番茄：快节奏、爽点密集
   - 晋江：情感细腻、人物塑造
```

### 差异化不足时

```
1. 找对标：最像的三部作品是什么？
   - 和它们有什么相同点？
   - 能有什么不同点？

2. 做减法：去掉最老套的元素
   - 哪些设定是必须的？
   - 哪些可以替换？

3. 做加法：加入独特元素
   - 独特的设定
   - 独特的风格
   - 独特的叙事方式
```
