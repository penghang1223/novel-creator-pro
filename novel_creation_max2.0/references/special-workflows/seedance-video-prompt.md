# Seedance 视频提示词转换指南 (Video Prompt Conversion Guide)

> 将小说剧情片段转换为 Seedance 2.0 视频生成提示词的结构化方法

---

## 一、功能概述

将小说剧情片段转换为 Seedance 2.0「全能参考模式」的视频生成提示词，支持：
- 中文/英文剧情文本
- 人物、场景、动作抽取
- 结构化提示词输出
- 镜头语言设计

**触发场景**：
- 用户说"剧情转视频""转视频提示词""场景转提示词"
- 用户希望将小说片段可视化为视频

---

## 二、使用方式

### 2.1 输入格式

直接提供剧情文本，例如：
```
夜晚的老城区街巷，小雨。男主独自缓慢行走，偶尔停下靠在斑驳墙面，抬头看路灯，轻叹。
```

### 2.2 输出格式

生成的提示词包含以下7个结构：

```
1. 技术参数兜底
   - 时长、画幅、画质、帧率
   - 稳定性说明

2. 主体描述
   - 角色身份、外貌/服装
   - 前后一致性保证

3. 动作序列
   - 慢、连、稳的动作链条
   - 避免大幅快速运动

4. 场景环境与光影
   - 地点、时间、天气
   - 光影特征与环境动态元素

5. 镜头语言
   - 景别、运镜方式
   - 焦点切换

6. 技术约束
   - 面部稳定不变形
   - 无闪烁、无穿模
   - 无帧间风格漂移

7. 参考素材占位
   - @Image/@Video/@Audio 占位说明
```

---

## 三、转换流程

智能体执行以下步骤：

1. **解析剧情文本**：提取人物、场景、动作、情绪、氛围
2. **构建技术参数**：根据场景复杂度选择时长、画幅等
3. **生成主体描述**：将人物描述转化为视觉化描述
4. **编排动作序列**：将剧情动作转化为慢、连、稳的镜头动作链
5. **设计场景光影**：补充环境细节和氛围渲染
6. **设计镜头语言**：根据叙事节奏设计景别和运镜
7. **添加技术约束**：确保视频生成质量

## 四、完整示例

### 输入剧情

```
夜晚的老城区街巷，小雨。男主独自缓慢行走，偶尔停下靠在斑驳墙面，抬头看路灯，轻叹。
镜头先平稳跟拍，再缓慢推近至面部特写，焦点顺滑切换。
暖黄路灯光，雨丝飘落，地面倒影，氛围孤寂。
整段动作连贯、面部稳定不变形，画面无闪烁。
```

### 生成提示词

```
【技术参数】
时长：12秒 | 画幅：16:9 横屏 | 画质：2K超清 | 帧率：24fps电影帧率

【主体】
男性角色，30岁左右，穿着深色风衣，面容疲惫但坚毅，保持角色前后一致性

【动作序列】
缓慢行走 -> 偶尔停顿 -> 靠墙 -> 抬头 -> 看路灯 -> 轻叹
动作偏慢、连贯稳定、可跟拍

【场景环境与光影】
- 地点：老城区街巷，雨夜
- 光线：暖黄路灯光，雨丝，地面倒影
- 氛围：孤寂、沉思
- 环境动态：雨丝飘落，灯光微晃

【镜头语言】
- 开场：中景跟拍
- 中段：缓慢推进
- 结尾：面部特写，焦点顺滑切换

【技术约束】
面部稳定不变形 | 无闪烁 | 无穿模 | 无帧间风格漂移

【参考素材】
@Image：[上传角色参考图]
@Video：[上传动作参考]
@Audio：[上传环境音，如雨声]
```

## 五、镜头语言参考

### 5.1 景别选择

| 景别 | 说明 | 适用场景 |
|------|------|----------|
| 特写 | 面部或细节 | 情感表达、关键道具 |
| 近景 | 胸部以上 | 对话、内心活动 |
| 中景 | 膝盖以上 | 日常互动、动作展示 |
| 全景 | 全身+环境 | 场景建立、氛围渲染 |
| 远景 | 大环境 | 世界观展示、孤寂感 |

### 5.2 运镜方式

| 运镜 | 效果 | 适用场景 |
|------|------|----------|
| 推镜头 | 聚焦、强调 | 关键发现、情绪爆发 |
| 拉镜头 | 展现环境、孤立感 | 角色孤独、场景全貌 |
| 跟拍 | 伴随、沉浸 | 角色行走、追逐 |
| 横摇 | 展示空间 | 场景切换、环境展示 |
| 升降 | 权力感、渺小感 | 登场、俯瞰 |

### 5.3 动作设计原则

- **慢**：动作放慢，确保画面稳定
- **连**：动作之间连贯，无跳跃
- **稳**：避免大幅快速运动，减少变形
