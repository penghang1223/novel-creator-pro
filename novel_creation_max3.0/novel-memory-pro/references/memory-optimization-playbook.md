# 记忆优化手册

本参考用于解决“记忆越积越多、越存越乱”的问题。

## 原则

- 只保留影响后续创作决策的信息
- 已解决信息降权，不要持续抢占注意力
- 未解决信息前置，成为下一章输入的一部分
- 章节前读摘要，阶段性再读全量

## 三种记忆状态

### Active

当前 1-3 章会直接影响创作的内容：

- 当前人物状态
- 当前活跃主线 / 支线
- 未解问题
- 未回收伏笔

### Warm

暂时不直接使用，但后续可能再次重要：

- 中期支线
- 次要角色历史
- 已半回收伏笔

### Archive

已经完成或仅供回溯：

- 已彻底回收的伏笔
- 已结束支线
- 旧版创作决策

## 何时做压缩

- 每 5-10 章做一次轻压缩
- 每卷结束做一次重压缩
- 发现写作技能开始忘事或串戏时，立即做局部压缩

## 压缩时检查什么

- 哪些 unresolved 其实已经解决
- 哪些人物状态已经过期
- 哪些 plot 只是旧记录，没有新推动
- 哪些 history 只是在重复同一结论

## 实操建议

- 每章后只同步“变化”，不要同步全部旧信息
- 章节包尽量控制在“够写下一章”的大小
- 如果同一角色状态在三章内没变，不要重复写入多次
- 如果风格校准长期稳定，可以降低风格层的刷新频率
- 每 5-10 章生成一次 `review-pack`，再决定哪些记忆进入 active / warm / archive
