# 内置风格提示词

## 快节奏爽文风
```
【风格定位】
- 节奏：快速、紧凑、不拖沓
- 语言：口语化、短句碎段
- 情绪：爆发力强、反转干脆
- 核心：打脸装逼、逆袭成长

【写作要求】
1. 第三人称叙事，聚焦主角视角
2. 段落简短，单段不超过3行
3. 对话要干脆，不拖泥带水
4. 打脸场景：铺垫→压制→反转→爆发，一气呵成
5. 避免心理描写和环境堆砌
6. 每章必须有一个小高潮或爽点

【示例】
张伟笑了。

"你说我是废物？"

他慢慢站起来，眼神里是前所未有的锐利。

"那就让你看看，什么是真正的废物。"

下一秒，他出手了。

快。

太快了。

所有人都没看清发生了什么，那个嘲笑他的人已经飞了出去。

砰——

砸在墙上，再也没能爬起来。

全场死寂。
```

## 种田经营风
```
【风格定位】
- 节奏：缓慢、稳扎稳打
- 语言：完整段落、细腻描写
- 情绪：成就感、成长感
- 核心：建设发展、稳步成长

【写作要求】
1. 详细描写建设/经营过程
2. 突出从无到有的成就感
3. 数据和细节要真实可信
4. 配角要有血有肉
5. 节奏可以慢，但不能拖
6. 每章要有明确的进度推进

【示例】
张伟站在荒地上，看着眼前的一片空旷。

这里就是他花光所有积蓄买下的农场——五十亩荒地，一间破屋，一口枯井。

"先修井吧，"他在心里盘算，"没有水，什么都干不了。"

他花了三天时间，终于把那口枯井疏通了。当清澈的地下水涌上来的那一刻，他有一种想哭的冲动。

这是第一步。

接下来，他还有很多事要做。修房子、开荒地、买种子、建围栏……

但至少，他有了开始。
```

## 悬疑推理风
```
【风格定位】
- 节奏：张弛有度、层层推进
- 语言：精准、克制、有逻辑
- 情绪：紧张感、好奇心
- 核心：线索铺设、反转设计

【写作要求】
1. 线索要隐蔽但合理
2. 每个人都要有嫌疑
3. 反转要有逻辑支撑
4. 对话要藏信息
5. 环境描写要有暗示性
6. 结局要能回溯验证

【示例】
张伟站在尸体旁，眉头紧锁。

门窗完好，没有闯入痕迹。

死者表情平静，像是睡着了一样。

但张伟知道，这不是自然死亡。

因为死者的左手，握着一张扑克牌——红桃A。

三天前，另一个死者手里也有一张牌——黑桃K。

"这是第二个了，"他喃喃自语，"凶手在传递什么信息？"

他蹲下来，仔细观察尸体的手指。

指甲缝里，有一点点白色的粉末。

他凑近闻了闻。

是石灰。

这个发现，让整个案件的走向，完全改变了。
```

## 甜宠言情风
```
【风格定位】
- 节奏：轻松、甜蜜、小虐怡情
- 语言：对话为主、互动可爱
- 情绪：心动感、幸福感
- 核心：情侣互动、撒狗粮

【写作要求】
1. 对话要有个性、有甜蜜感
2. 互动要自然、有火花
3. 小冲突要快速解决
4. 糖分要足，但不能腻
5. 配角要有助攻作用
6. 避免狗血误会拖剧情

【示例】
"你怎么又来了？"苏念看着站在门口的顾言，有些无奈。

"路过。"他一本正经。

"你家在城南，我公司城北，你路过？"

"……"

顾言没说话，只是把怀里的保温桶递给她。

"我妈做的汤，多了，让我送人。"

苏念接过，打开一看——

是她最喜欢的银耳莲子汤。

"你妈怎么知道我喜欢这个？"

"……不小心提过。"

苏念看着他的耳朵尖一点点变红，忍不住笑了。

"顾总，你耳朵红了。"

"没有。"

"有。"

"……"
```

## 搞笑沙雕风
```
【风格定位】
- 节奏：轻快、跳脱
- 语言：口语化、网络用语
- 情绪：轻松、搞笑
- 核心：反差萌、沙雕情节

【写作要求】
1. 对话要有趣、有梗
2. 情节要出人意料
3. 主角要有沙雕属性
4. 配角要有反差感
5. 避免正经场合正经说话
6. 每章要有笑点

【示例】
张伟绑定了系统。

【系统：宿主您好，我是您的专属成长系统。】

"哦。"张伟很淡定。

【系统：绑定成功后，您将获得新手大礼包，包含——】

"等等，"张伟打断，"能折现吗？"

【系统：……】

"我的意思是，新手大礼包能换成钱给我吗？最近手头有点紧。"

【系统：这是成长系统，不是发钱系统。】

"那能解绑吗？"

【系统：不能。】

"行吧，"张伟叹气，"那新手大礼包里有什么？"

【系统：新手技能书×1，新手装备×1，新手——】

"能卖吗？"

【系统：……宿主，您的人生观有问题。】

"不，是我的人生有问题，"张伟认真道，"所以我现在需要钱。"
```

## 暗黑压抑风
```
【风格定位】
- 节奏：沉重、压抑、层层递进
- 语言：精准、冷峻、有力量
- 情绪：压迫感、绝望感、希望
- 核心：人性复杂、命运抗争

【写作要求】
1. 氛围营造要到位
2. 人物要有灰色地带
3. 对话要有深意
4. 情节要有重量感
5. 希望要藏在绝望中
6. 避免简单的好人坏人

【示例】
张伟站在审判席上，看着眼前的一排排法官。

他们高高在上，表情冷漠，像是看着一只蝼蚁。

"张伟，你可知罪？"

"知罪。"他平静地回答。

"你明知那是禁书，为何还要私藏？"

张伟抬起头，看着那个发问的法官。

那是个年过五旬的老者，据说清廉正直，从不徇私。

但张伟知道，三天前的深夜，就是这个"清廉正直"的老者，从后门走进了一座密室。

而那座密室里，藏着他这辈子见过的最多的禁书。

"因为，"张伟慢慢开口，"有些书，不该被禁。"

全场哗然。

但他知道，他说的不是实话。

实话是——他藏的那些书，是这个时代唯一的真相。
```

## 情感细腻风
```
【风格定位】
- 节奏：舒缓、细腻
- 语言：感官丰富、意象动人
- 情绪：心动、纠结、释然
- 核心：情感流动、心理刻画

【写作要求】
1. 感官描写要到位（视觉、听觉、嗅觉、触觉、味觉）
2. 心理刻画要深入
3. 细节要有意义
4. 对话要有层次
5. 氛围营造要用心
6. 亲密场景要细腻自然

【示例】
他的气息靠近，带着雪松和琥珀的味道，像是深林里的雾。

苏念感觉到他的手掌贴上后腰，温热的温度透过薄薄的布料传来，让她整个人都绷紧了。

"别紧张。"他的声音就在耳边，低沉得像是叹息。

她想说点什么，但所有声音都卡在喉咙里。

他的唇落在她的耳垂，轻轻含了一下。

酥麻感从那里蔓延开，让她忍不住颤栗。

"苏念，"他的声音带着压抑的沙哑，"如果你不想，我可以停下来。"

她没有回答，只是主动仰起头，迎上了他的唇。

那一刻，她闻到了他身上的味道，也闻到了自己心跳的声音。
```

## 文艺诗意风
```
【风格定位】
- 节奏：缓慢、诗意
- 语言：优美、意象丰富
- 情绪：感伤、怀念、释然
- 核心：氛围营造、情感升华

【写作要求】
1. 意象要统一、有层次
2. 语言要优美但不堆砌
3. 情感要内敛但有力量
4. 留白要恰到好处
5. 结尾要有余味
6. 避免强行升华

【示例】
窗外的雨还在下，像是没有尽头的告别。

她坐在床边，看着玻璃上的水痕，想起他离开的那天——

也是这样的雨天。

他没有说再见，只是把一把伞放在门口，然后走进了雨里。

她追出去的时候，已经看不到他的身影。

只有雨水打在脸上，和分不清是雨还是泪的水。

三年了。

她以为自己已经忘记，但每次下雨，她还是会想起那个背影。

和那句没有说出口的——

"别走。"
```

## 使用方法

1. 选择一个风格作为基础
2. 在创作时保持风格一致性
3. 可以组合多个风格的特点
4. 根据剧情需要调整风格强度

**注意**：风格是工具，服务于故事。不要为了风格而风格。
