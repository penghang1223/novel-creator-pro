# 角色卡标准模板（13 维度）

> 角色卡是写作的发动机，不是百科词条。每一条必须能直接指导写作行为。
> 标注 `[写时生成]` 的字段不在角色文件中存储，由知识包按章节动态生成。

---

## 一、基础画像

| 字段 | 说明 |
|------|------|
| 姓名 | |
| 当前身份 | 社会位置（如：落魄赘婿 / 村长 / 会长） |
| 隐藏身份 | 与表面身份对立的真面目（如：资本黑手 / 穿越者 / 觉醒NPC） |
| 外貌特征1 | 识别/记忆点（如：白衣长发） |
| 外貌特征2 | 可触发剧情的特征（如：眉心伤疤 / 封印纹身 / 缺失的手指） |
| 核心性格 | 主标签 + 对立特质（如：极度理性 vs 情感压抑失控） |

**核心渴望 / 核心恐惧（必须成对且冲突）：**
- 渴望：
- 恐惧：
- → 两者冲突才有戏（如：渴望被认可 vs 恐惧暴露真实身份）

**价值观底线：**
- 绝不做的事（如：不杀无辜 / 不背叛同伴 / 不说真名）
- → 行为选择的硬约束。剧情打破底线时必须有充分触发

**写作约束：** 所有行为必须符合性格冲突 + 不突破底线（除非剧情明确打破）。

## 二、行为指纹

| 情境 | 行为 | 备注 |
|------|------|------|
| 紧张时 | | |
| 放松时 | | |
| 愤怒时 | | |
| 思考时 | | |
| 危险时 | | |
| 撒谎时 | | 关键——暴露角色的伪装能力 |
| 标志性道具 | | 必须能反复出现，形成记忆点 |

**写作约束：** 同一情绪优先调用固定动作，形成"遮住名字仍可辨认"的角色辨识度。

## 三、对话声纹

| 字段 | 说明 |
|------|------|
| 语速 | 快 / 慢 / 控制型顿挫 |
| 句式习惯 | 短句 / 反问 / 不完整句 / 命令句 |
| 常用表达 | 1-2 个口头禅，避免滥用 |
| 隐藏表达方式 | 话里有话 / 不说重点 / 反向表达 |
| 禁用词 | 绝对不会说的话（防 OOC 强约束） |

**写作约束：** 对话必须"遮住名字仍可辨认是谁说的"。

---

## 四、动机逻辑链（发动机）

**核心驱动（只能选 1-2 个）：** 控制欲 / 生存 / 情感 / 利益 / 复仇

**目标层级：**
- 长期目标（人生）：不轻易改变（如：复仇 / 权力 / 自由）
- 中期目标（本卷）：阶段性成果（如：进入核心圈 / 拿到关键资源）
- `[写时生成]` 短期目标（本章）：当前立即行动目的，必须能完成或失败

**优先级排序（必须明确）：**
→ 例：控制权 > 安全 > 利益 > 感情

**行为选择原则：**
| 场景 | 反应 |
|------|------|
| 遇到机会 | 优先扩大优势 / 稳住局面 |
| 遇到威胁 | 反击 / 规避 / 转移风险 |
| 遇到不确定 | 试探 / 观望 / 直接下注 |

**禁止行为（硬规则）：**
- 不做无收益行为
- 不做违背核心目标的选择
- 不在未确认安全前暴露底牌

**写作约束：** 每一个行动必须能解释为"达成目标"或"符合优先级规则"，否则判定为 OOC。

## 五、决策模型

| 字段 | 说明 |
|------|------|
| 优先级排序 | 与第四章一致，如：控制权 > 利益 > 感情 > 面子 |
| 风险偏好 | 保守 / 平衡 / 激进 |
| 是否撒谎 | 习惯 / 必要时 / 从不 |
| 是否借刀杀人 | 是 / 否 |
| 是否留后手 | 永远 / 偶尔 / 从不 |
| 极端情况选择 | 保命 / 翻盘 / 同归于尽 |

**写作约束：** 决策必须符合优先级排序，否则视为 OOC。

| 对象 | 表面态度 | 真实态度 | 利用点 | 防备点 |
|------|---------|---------|--------|--------|
| A | | | | |
| B | | | | |

**隐藏关系：** 旧识 / 仇人 / 血缘 / 利益同盟

**关系变化触发条件：**

## 八、反差开关（记忆点核心）

| 字段 | 说明 |
|------|------|
| 表层人设 | 对外展示的形象（如：温和 / 废物 / 老实人） |
| 真实人设 | 内在真实面目（如：冷血操盘者 / 极端理性） |
| 反差触发条件 | 什么情况下暴露真实面 |
| 反差表现形式 | 语言变化（语速/用词突变）+ 行为变化（直接/果断/暴力） |

**写作约束：** 反差必须"逐步揭露"，禁止一上来全开。

---

## 九、信息掌握层级（悬念系统）

| 层级 | 内容 |
|------|------|
| 已知信息 | 角色知道的 |
| 误判信息 | 角色以为是真的但实际是错的 |
| 隐藏信息（读者知道） | 读者知道但角色不知道的（制造期待感） |
| 隐藏信息（仅作者知道） | 最深层秘密 |

**写作约束：** 行为只能基于"已知 + 误判"，不能用上帝视角。

---

## 十、失败成本（张力来源）

| 字段 | 说明 |
|------|------|
| 失败代价 | 失去金钱 / 地位 / 关系 / 性命（必须具体） |
| 可承受范围 | 可 / 不可 |
| 连锁反应 | 失败 → 被追杀 / 暴露 / 崩盘 |
| 底线行为 | 最后手段：逃跑 / 杀人 / 背叛 |

**写作约束：** 成本越具体，剧情越紧张（必须量化）。

---

## 十一、剧情权限（控场器）

| 字段 | 说明 |
|------|------|
| 是否主导剧情 | 是 / 否 |
| 可影响范围 | 小事件 / 局部剧情 / 主线推进 |
| 不能解决最终谜题 | ✓ |
| 不能压制主角成长 | ✓ |
| 不能提前揭露核心设定 | ✓ |

**写作约束：** 权限外行为一律禁止（防配角抢戏 / 主角无敌过早）。

---

## 十二、成长轨迹

| 字段 | 说明 |
|------|------|
| 当前阶段 | 初期 / 上升 / 巅峰 / 崩塌 |
| 阶段标签 | 青涩 / 老练 / 冷血 / 疯狂 |
| 成长弧线类型 | 成长 / 堕落 / 救赎 / 平坦 |
| 起点 | 初始状态 |
| 终点（目标） | 目标状态 |

**本卷成长点：** 学会信任 / 学会牺牲 / 学会控制

**关键转折点：**
- ChN：事件 → 变化

**性格变化边界（关键）：**
- 哪些不会变（核心底色）
- 哪些可以变（策略/表达）

**写作约束：** 成长是"调整权重"，不是"换性格"。

---

## 十三、本章动态约束 `[写时生成]`

> 不在角色文件中存储，由知识包按章节动态生成。

| 字段 | 说明 |
|------|------|
| 当前状态 | 位置 / 时间 / 身体状态（受伤/疲惫/正常） |
| 本章目标 | 必须具体（如：套话 / 试探 / 拖时间） |
| 本章秘密 | 不能说出口的事 |
| 本章矛盾行为 | 本章必须出现一次"违和但合理"的行为 |
| 当前情绪（主导） | 压抑 / 冷静 / 暴躁 / 崩溃边缘 |
| 情绪掩饰程度 | 完全隐藏 / 部分外露 / 无法控制 |

**写作约束（最重要）：** 本章所有行为必须服务"本章目标"，否则删除。

## 使用指南

### 角色文件（静态）存哪些维度？

| 维度 | 存储 | 说明 |
|------|------|------|
| 一、基础画像 | ✓ | 身份/外貌/渴望恐惧/底线 |
| 二、行为指纹 | ✓ | 固定动作模式 |
| 三、对话声纹 | ✓ | 语速/句式/禁词 |
| 四、动机逻辑链 | ✓ | 驱动/目标/优先级/禁止 |
| 五、决策模型 | ✓ | 风险偏好/极端选择 |
| 六、关系张力图 | ✓ | 对关键人物的态度 |
| 七、情绪触发器 | ✓ | 正向/负向/禁区 |
| 八、反差开关 | ✓ | 表层/真实/触发条件 |
| 九、信息掌握层级 | ✓ | 已知/误判/隐藏 |
| 十、失败成本 | ✓ | 代价/连锁/底线 |
| 十一、剧情权限 | ✓ | 影响范围/限制 |
| 十二、成长轨迹 | ✓ | 阶段/转折/边界 |
| 十三、本章动态约束 | ✗ | 写时由知识包生成 |

### 知识包按章节生成什么？

知识包 Step C（读取出场人物档案）从角色文件提取：
- 矛盾特质（来自 §一 核心性格）
- 行为指纹（来自 §二）
- 声纹特征（来自 §三）
- 本章适用的动机优先级（来自 §四）

然后动态生成 §十三（本章动态约束），注入写作 prompt。

### 与写作宪法的关系

| 宪法条款 | 对应角色卡维度 |
|---------|--------------|
| 第五条：矛盾特质 | §一 核心性格（主标签+对立特质） |
| 第五条：行为指纹 | §二（唯一化动作） |
| 第四条：对话六要素 | §三（声纹）+ §二（行为锚点） |
| 第五条：情感表达优先级 | §七（触发器驱动，非直白命名） |
