## 封面规范

### 平台要求
| 平台 | 尺寸 | 格式 | 大小限制 |
|------|------|------|---------|
| 番茄小说 | 600×800 | JPG/PNG | ≤500KB |
| 起点 | 200×280 | JPG/PNG | ≤200KB |
| 飞卢 | 200×280 | JPG/PNG | ≤200KB |
| 晋江 | 200×280 | JPG/PNG | ≤200KB |

### 基本要素
- 书名：清晰可见，占据封面1/3左右
- 作者名：较小，置于底部或角落
- 主图：与题材相关的视觉元素
- 背景：烘托氛围，不喧宾夺主

## 设计风格

### 男频风格
**特点**：霸气、热血、冲击力强

**元素**：
- 人物剪影/背影
- 武器/装备
- 城市天际线
- 能量光效
- 深色背景

**示例场景**：
- 都市重生：现代都市夜景+人物剪影
- 玄幻修仙：山峰+剑+光芒
- 末世废土：废墟+武器+硝烟

---

### 女频风格
**特点**：唯美、浪漫、色调柔和

**元素**：
- 人物特写
- 花卉/装饰元素
- 古风元素（古装）
- 柔光效果
- 浅色背景

**示例场景**：
- 现代言情：人物剪影+城市灯光
- 古代宫斗：古风女子+宫廷元素
- 霸道总裁：西装男+都市背景

## 文字排版

### 书名排版
- 字体：根据题材选择（男频用粗黑体，女频用圆体或楷体）
- 大小：占据封面1/3左右
- 位置：上方居中或左上角
- 效果：可加描边、阴影、渐变

### 作者名排版
- 字体：较细的字体
- 大小：约为书名的1/3
- 位置：底部居中或右下角
- 效果：简单清晰

### 排版示例
```
┌────────────────────┐
│                    │
│   重生之商海风云   │  ← 书名（大字）
│                    │
│                    │
│   [人物/场景图片]  │  ← 主图
│                    │
│                    │
│     作者：XXX      │  ← 作者名（小字）
└────────────────────┘
```

## 题材参考

### 都市重生
- 主图：城市天际线/人物剪影
- 配色：金+黑+深蓝
- 氛围：都市、奋斗、逆袭
- 关键词：重生、商战、财富

### 玄幻修仙
- 主图：山峰/剑/光芒
- 配色：紫+金+黑
- 氛围：神秘、强大、长生
- 关键词：修仙、突破、长生

### 现代言情
- 主图：人物剪影/城市灯光
- 配色：粉+白+浅蓝
- 氛围：浪漫、甜蜜、心动
- 关键词：爱情、相遇、心动

### 古代宫斗
- 主图：古风女子/宫廷元素
- 配色：红+金+深红
- 氛围：权谋、争斗、逆袭
- 关键词：宫斗、权谋、宠爱

## 使用脚本生成封面

### 脚本调用
```bash
python scripts/generate_cover.py --title "书名" --author "作者名" --background 背景图路径
```

### 参数说明
- `--title`：书名（必填）
- `--author`：作者名（必填）
- `--background`：背景图路径（可选，无则使用默认背景）
- `--style`：风格（可选：male/female，默认根据题材自动判断）
- `--output`：输出路径（可选，默认保存到 assets/novels/）

### 示例
```bash
# 男频封面
python scripts/generate_cover.py --title "重生之商海风云" --author "张三" --style male

# 女频封面
python scripts/generate_cover.py --title "穿书后我成了白月光" --author "李四" --style female
```

---

**记住**：封面是读者第一眼看到的，要和内容匹配，要有吸引力，但不要过度夸张。
