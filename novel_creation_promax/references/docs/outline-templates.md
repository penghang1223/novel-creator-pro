## 章节大纲模板

### 单章大纲模板
```
第X章：章节名
【核心事件】
本章发生的核心事件是什么？（一句话概括）

【场景设定】
- 地点：XXX
- 时间：XXX
- 出场人物：XXX

【剧情发展】
1. 开场（约500字）：XXX
   - 钩子：如何吸引读者？
   - 承接：与上一章如何衔接？

2. 中段（约1500字）：XXX
   - 冲突：本章的主要矛盾
   - 爽点：本章的爽点设计

3. 结尾（约500字）：XXX
   - 悬念：如何吸引读者看下一章？

【爽点设计】
- 爽点类型：打脸/收获/突破/反转/其他
- 具体表现：XXX

【情绪曲线】
平静 → 紧张 → 爆发 → 满足

【伏笔设置】（可选）
- 埋下：XXX
- 预计回收：第X章
```

### 批量章节规划
```
【第1-10章：开篇】
- 第1章：主角出场+设定展示+第一个悬念
- 第2章：展开设定+第一个小冲突
- 第3章：第一个小高潮
- 第4-6章：日常推进+世界观展开
- 第7-8章：矛盾升级
- 第9-10章：第一卷高潮+悬念

【第11-20章：发展】
...

【第21-30章：转折】
...
```

## 完整示例

### 示例：都市重生爽文

#### 基本信息
```
【小说名称】重生之商海风云
【题材类型】都市重生
【核心爽点】先知优势+逆袭打脸+财富积累
【字数规划】200万字（预计5卷）
【更新节奏】日更2章，每章2000字
【风格定位】快节奏爽文风
```

#### 第一卷大纲
```
【第一卷：觉醒与起航】（第1-40章，约8万字）
【核心冲突】
重生归来，主角要弥补前世遗憾，从底层逆袭，但面临资金短缺、人脉不足、前仇家打压等困境。

【主要爽点】
1. 开局爽点：重生得知彩票号码，获得第一桶金
2. 中段爽点：提前布局，截胡前仇家的商机
3. 结尾爽点：公司初具规模，打脸曾经看不起自己的人

【关键事件】
1. 重生获知彩票号码，获得启动资金（第1-3章）
2. 提前布局房地产，低价买入未来黄金地段（第4-10章）
3. 与前世仇家初次交锋，小胜一场（第11-15章）
4. 创立公司，招揽前世人才（第16-25章）
5. 商战初试，截胡仇家大单（第26-35章）
6. 第一卷高潮：公司年会上，让仇家当众出丑（第36-40章）

【人物出场】
- 主角：张伟（重生前是打工族，重生后决心创业）
- 女主：苏念（前世错过，今生要守护）
- 配角：老刘（前世大佬，今生提前结交）
- 反派：陈浩（前世仇人，今生主要对手）

【本卷目标】
获得第一桶金，创立公司，打响知名度

【情感曲线】
重生惊喜 → 资金困境 → 商机出现 → 商战交锋 → 初战告捷
```

#### 章节细化（第1-5章）
```
第1章：1998年的阳光
【核心事件】张伟重生回到1998年，发现自己躺在高中时代的床上

【场景设定】
- 地点：张伟老家卧室
- 时间：1998年夏天的早晨
- 出场人物：张伟、张母（声音）

【剧情发展】
1. 开场：张伟睁开眼，发现环境陌生又熟悉，意识到重生了
2. 中段：回忆前世遗憾（创业失败、错过真爱、父母早逝），决心改变
3. 结尾：想起1998年那期的彩票号码，决定去买

【爽点设计】
- 爽点类型：重生爽
- 具体表现：主角获得重来一次的机会，读者期待他的逆袭

【情绪曲线】
困惑 → 震惊 → 激动 → 决心

---

第2章：第一桶金
【核心事件】张伟用仅有的零钱买彩票，中了五百万

【场景设定】
- 地点：彩票站、银行
- 时间：当天
- 出场人物：张伟、彩票站老板、银行柜员

【剧情发展】
1. 开场：张伟翻遍房间找到零钱，跑去彩票站
2. 中段：填写号码时的紧张，彩票站老板的质疑
3. 结尾：彩票中奖，前往领奖

【爽点设计】
- 爽点类型：收获爽
- 具体表现：五百万到手，有了启动资金

【情绪曲线】
紧张 → 期待 → 狂喜

---

第3章：规划未来
【核心事件】张伟开始规划未来，决定从房地产切入

【场景设定】
- 地点：张伟卧室
- 时间：中奖后第二天
- 出场人物：张伟

【剧情发展】
1. 开场：张伟盘点手中资金，规划使用方案
2. 中段：回忆前世记忆，找出未来最有价值的投资方向
3. 结尾：决定先买入一块未来会升值的地皮

【爽点设计】
- 爽点类型：先知爽
- 具体表现：主角知道未来走势，读者期待他的布局

【情绪曲线】
冷静 → 分析 → 决断

---

第4章：第一块地
【核心事件】张伟低价买入一块未来黄金地段的地皮

【场景设定】
- 地点：城郊荒地、中介所
- 时间：一周后
- 出场人物：张伟、中介、村民

【剧情发展】
1. 开场：张伟来到城郊，看中一块荒地
2. 中段：与村民谈判，以极低价格拿下
3. 结尾：地皮到手，未来这里会建起商业中心

【爽点设计】
- 爽点类型：布局爽
- 具体表现：低价买入未来升值百倍的地皮

【伏笔设置】
- 埋下：这块地未来会被政府征收，建设商业中心
- 预计回收：第20章左右

【情绪曲线】
观察 → 谈判 → 成功

---

第5章：仇人相见
【核心事件】张伟偶遇前世仇人陈浩

【场景设定】
- 地点：高中校园
- 时间：开学日
- 出场人物：张伟、陈浩、苏念

【剧情发展】
1. 开场：张伟到学校报到，偶遇陈浩
2. 中段：陈浩依旧嚣张，张伟内心冷笑（我知道你的未来）
3. 结尾：苏念出场，张伟决心这一世要好好守护她

【爽点设计】
- 爽点类型：铺垫爽
- 具体表现：仇人出现，为后续打脸做铺垫

【伏笔设置】
- 埋下：苏念对张伟有好感，但张伟前世没察觉
- 预计回收：第15章左右

【情绪曲线】
平静 → 冷笑 → 决心
```

## 大纲检查清单

### 开篇检查
- [ ] 主角是否在前三章出场？
- [ ] 核心设定是否清晰？
- [ ] 第一个爽点是否在第三章内出现？
- [ ] 读者是否有继续看下去的欲望？

### 剧情检查
- [ ] 每章是否有推进？
- [ ] 爽点分布是否均匀？
- [ ] 是否有伏笔？是否有回收？
- [ ] 反派是否有智商？

### 人物检查
- [ ] 主角人设是否一致？
- [ ] 配角是否有独立人格？
- [ ] 反派是否有动机？
- [ ] 关系是否合理？

### 结局检查
- [ ] 是否解决了核心冲突？
- [ ] 是否有续写空间？
- [ ] 读者是否满意？

---

**记住**：大纲是骨架，写作时可以灵活调整，但核心冲突和爽点不要偏离。
