## 评估理念

**核心原则**：细纲是章节的蓝图，决定每一章好不好看。

细纲评估回答的问题不是"这个大纲好不好"，而是：
- 这一卷的主节点是否清晰？
- 这一章有没有东西写？
- 这一章读者愿不愿意看？
- 这一章有没有推进故事？

**与前一阶段的区别**：

| 对比项 | 结构规划评估 | 细纲设计评估 |
|-------|-------------|-------------|
| 核心问题 | 能不能讲下去？ | 这一章好不好看？ |
| 评估重点 | 主线清晰度、节奏合理性 | 主节点规划、爽点设计 |
| 评估粒度 | 整体结构 | 本卷整体 + 单章 |
| 判断标准 | 可用/需调整/有硬伤 | 可直接写/需优化/有问题 |

## 评估层级

细纲评估分为两个层级：

### 层级一：本卷整体评估

**评估时机**：本卷主节点规划完成后，章节细纲填充前

**评估重点**：
- 主节点规划是否合理
- 主节点类型是否齐全
- 爽点节奏分布是否均匀

### 层级二：单章细纲评估

**评估时机**：每章细纲设计完成后

**评估重点**：
- 事件清晰度
- 冲突强度
- 钩子设置
- 爽点设计（主节点章节重点）

## 评估维度

### 本卷整体评估维度

#### 维度一：主节点规划

**核心问题**：本卷主节点是否清晰合理？

| 检查项 | 具体问题 |
|-------|---------|
| 主节点数量 | 本卷有几个主节点？数量是否合理？（通常3-5个） |
| 主节点类型 | 是否包含开篇锚点、高潮事件、卷末收束？ |
| 主节点位置 | 主节点分布是否均匀？是否过于集中？ |
| 主节点清晰 | 每个主节点的事件描述是否清晰？ |

**判断等级**：合理 / 需调整 / 有问题

#### 维度二：爽点节奏

**核心问题**：本卷爽点分布是否合理？

| 检查项 | 具体问题 |
|-------|---------|
| 爽点分布 | 主节点爽点是否均匀分布？ |
| 爽点类型 | 爽点类型是否多样？是否单调？ |
| 爽点力度 | 高潮事件的爽点是否足够强？ |
| 灵活区补充 | 灵活区是否需要补充小爽点？ |

**判断等级**：合理 / 需补充 / 爽点不足

---

### 单章细纲评估维度

#### 维度三：事件清晰度

**核心问题**：这一章发生什么？

| 检查项 | 具体问题 |
|-------|---------|
| 核心事件 | 这一章的主要事件是什么？一句话能说清吗？ |
| 事件推进 | 这一章推进了什么？主线/人物/设定？ |
| 事件必要性 | 这个事件是否必须？能否删掉？ |
| 事件完整 | 事件是否有头有尾？是否悬而未决？ |

**判断等级**：清晰 / 模糊 / 不明确

#### 维度四：冲突强度

**核心问题**：这一章有没有冲突？

| 检查项 | 具体问题 |
|-------|---------|
| 冲突存在 | 这一章有没有冲突？ |
| 冲突类型 | 人物冲突/内心冲突/环境冲突？ |
| 冲突强度 | 冲突够不够强？读者会不会紧张？ |
| 冲突解决 | 冲突是否得到解决或推进？ |

**判断等级**：强 / 中 / 弱 / 无

#### 维度五：节奏控制

**核心问题**：这一章的信息密度是否合理？

| 检查项 | 具体问题 |
|-------|---------|
| 信息量 | 这一章信息量是否适中？太多/太少？ |
| 情节密度 | 事件是否太多/太少？ |
| 篇幅预估 | 这一章预计多少字？是否合理？ |
| 阅读体验 | 读者会不会觉得拖沓/赶进度？ |

**判断等级**：合理 / 偏密 / 偏疏

#### 维度六：钩子设置

**核心问题**：这一章能否留住读者？

| 检查项 | 具体问题 |
|-------|---------|
| 开头钩子 | 章节开头是否有吸引点？ |
| 过程钩子 | 章节中间是否有悬念？ |
| 结尾钩子 | 章节结尾是否有留悬念？读者想看下一章吗？ |
| 钩子自然 | 钩子是否自然？是否生硬？ |

**判断等级**：有钩子 / 钩子弱 / 无钩子

#### 维度七：爽点设计

**核心问题**：这一章有没有爽点？

| 检查项 | 具体问题 |
|-------|---------|
| 爽点存在 | 这一章有没有爽点？ |
| 爽点类型 | 打脸/升级/逆袭/装逼/甜宠？ |
| 爽点铺垫 | 爽点是否有足够的铺垫？ |
| 爽点力度 | 爽点够不够爽？读者会不会有反应？ |

**判断等级**：有爽点 / 爽点弱 / 无爽点

**注意**：
- 主节点章节：【必须有爽点】，且爽点力度要强
- 灵活区章节：可以无爽点，但连续灵活区不宜超过3章
- 过渡章节：可以无爽点

#### 维度八：人物表现

**核心问题**：人物在这一章的表现是否合理？

| 检查项 | 具体问题 |
|-------|---------|
| 行为合理 | 人物行为是否符合人设？ |
| 动机清晰 | 人物为什么要这么做？ |
| 人物推进 | 人物是否有成长或变化？ |
| 人物记忆点 | 人物是否有让人印象深刻的言行？ |

**判断等级**：合理 / 有问题

#### 维度九：承诺校验

**核心问题**：细纲是否支撑大纲的目标？

| 检查项 | 核心问题 |
|-------|---------|
| 主线推进 | 这一章是否推进了主线？ |
| 节奏符合 | 这一章是否符合大纲的节奏规划？ |
| 设定一致 | 这一章是否与设定保持一致？ |
| 承诺兑现 | 这一章是否在兑现创意阶段的承诺？ |

**判断等级**：支撑 / 部分支撑 / 偏离

## 硬伤清单

### 本卷整体硬伤

| 硬伤类型 | 具体问题 | 后果 |
|---------|---------|-----|
| **主节点缺失** | 缺少开篇锚点或卷末收束 | 故事结构不完整 |
| **主节点模糊** | 主节点事件描述不清晰 | 执行时方向不明 |
| **爽点分布不均** | 前半卷或后半卷无爽点 | 读者流失 |
| **高潮疲软** | 高潮事件爽点力度不足 | 读者失望 |

### 单章细纲硬伤

| 硬伤类型 | 具体问题 | 后果 |
|---------|---------|-----|
| **事件不明** | 不知道这一章要写什么 | 写不出来，卡文 |
| **无冲突** | 这一章平淡无冲突 | 读者无聊，弃书 |
| **无钩子** | 开头不吸引，结尾不留悬念 | 读者流失 |
| **主节点无爽点** | 主节点章节没有爽点设计 | 主节点失效，读者期待落空 |
| **人物崩** | 人物行为与人设矛盾 | 读者出戏 |
| **节奏失衡** | 信息过密或过疏 | 阅读体验差 |
| **偏离大纲** | 与大纲规划不符 | 故事走向失控 |

## 评估报告格式

### 本卷整体评估报告

```
【细纲评估报告 · 本卷整体】

■ 本卷信息
  卷名：第X卷 [卷名]
  章数：[XX章]
  预计字数：[XX万字]

■ 主节点规划：[合理/需调整/有问题]
  主节点数量：[X个]
  主节点列表：
    M1 [开篇锚点] 第X章 - [事件描述]
    M2 [关键转折] 第X章 - [事件描述]
    M3 [高潮事件] 第X章 - [事件描述]
    M4 [卷末收束] 第X章 - [事件描述]
  
  主节点问题：
    ✓ 无问题
    或
    ⚠ [问题1：具体描述]
    ⚠ [问题2：具体描述]

■ 爽点节奏：[合理/需补充/爽点不足]
  主节点爽点分布：
    M1：[爽点类型] - [爽点内容]
    M2：[爽点类型] - [爽点内容]
    M3：[爽点类型] - [爽点内容]
    M4：[爽点类型] - [爽点内容]
  
  灵活区补充建议：
    ✓ 无需补充
    或
    ⚠ 第X-X章灵活区建议补充小爽点

■ 硬伤扫描：
  ✓ 无硬伤
  或
  ✗ [硬伤1：具体描述]
  ✗ [硬伤2：具体描述]

■ 综合判断：[可直接填充章节/需调整主节点/有问题]

■ 优化建议：
  【必须修复】
  1. [问题] → [具体修复方案]
  
  【建议优化】
  1. [问题] → [具体修复方案]
```

## 判断标准

### 本卷整体判断标准

| 判断 | 条件 | 后续处理 |
|-----|-----|---------|
| **可直接填充章节** | 主节点规划合理 + 爽点节奏合理 + 无硬伤 | 可以开始填充章节细纲 |
| **需调整主节点** | 主节点规划有问题 或 爽点分布不均 | 调整主节点规划后重新评估 |
| **有问题** | 主节点缺失 或 高潮疲软 | 必须修复问题后重新评估 |

### 单章细纲判断标准

| 判断 | 条件 | 后续处理 |
|-----|-----|---------|
| **可直接写** | 无硬伤 + 事件清晰 + 有冲突/钩子/爽点至少一项 | 可以开始撰写正文 |
| **需优化** | 无硬伤 + 有改进空间 | 优化后重新评估或直接撰写 |
| **有问题** | 有硬伤 或 偏离大纲 或 主节点无爽点 | 必须修复问题后重新评估 |

## 优化建议方法

### 主节点规划优化

1. **主节点缺失**
   - 检查是否缺少开篇锚点 → 建议在第1-3章补充
   - 检查是否缺少高潮事件 → 建议在卷中或卷末补充
   - 检查是否缺少卷末收束 → 建议在卷末补充

2. **主节点位置不合理**
   - 主节点过于集中 → 建议重新分布
   - 主节点间距过大 → 建议在中间补充小高潮或关键转折

3. **主节点事件模糊**
   - 参考 `references/coherence/main-node.md` 完善事件描述

### 爽点节奏优化

1. **主节点爽点不足**
   - 参考 `references/coherence/main-node.md` 中的"爽点设计"章节
   - 确保高潮事件的爽点力度足够

2. **灵活区过于平淡**
   - 在连续灵活区中间补充小爽点
   - 爽点类型可以是：小打脸、小升级、小逆袭、小甜宠

### 单章细纲优化

1. **如果是事件问题**：
   - 不明确：回看大纲，确认这一章在整体中的位置和作用
   - 不必要：考虑删掉或合并到其他章节

2. **如果是冲突问题**：
   - 无冲突：考虑增加人物冲突或内心冲突
   - 冲突弱：考虑提高冲突的紧迫性或后果

3. **如果是爽点问题**：
   - 主节点无爽点：必须补充爽点设计
   - 爽点弱：考虑增加铺垫或提高爽点力度
   - 灵活区无爽点：评估是否需要补充小爽点

4. **如果是大纲问题**：评估是否需要更新大纲
