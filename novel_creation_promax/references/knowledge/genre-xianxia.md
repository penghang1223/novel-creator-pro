# 仙侠小说

## 核心特点

- 东方神话与道教文化背景
- 修仙问道的主线
- 仙界与人界的双重视角
- 追求长生与超脱

## 常见元素

- 修仙体系（练气、筑基、金丹等）
- 仙界宗门
- 炼丹炼器
- 劫难与飞升

## 与玄幻的区别

| 对比项 | 仙侠 | 玄幻 |
|-------|-----|-----|
| 背景 | 东方神话体系 | 完全架空世界 |
| 体系 | 修仙境界 | 战斗力等级 |
| 氛围 | 逍遥超脱 | 热血战斗 |
| 核心追求 | 长生飞升 | 力量巅峰 |

## 创作要点

```
修仙体系 → 传统境界要尊重、创新要合理
文化底蕴 → 融入道教元素、增强氛围感
超脱感   → 仙人的格局与世俗不同
情感     → 仙侠中的情更加超脱或深刻
```
