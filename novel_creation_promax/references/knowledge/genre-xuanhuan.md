# 玄幻小说

## 核心特点

- 异世界或架空世界背景
- 完整的力量等级体系
- 主角从弱小到强大的成长线
- 金手指/特殊能力设定

## 常见元素

- 修炼体系（等级、境界）
- 天材地宝/神器
- 宗门势力/家族
- 奇遇与机缘
- 热血战斗

## 读者期待

- 爽快的战斗场面
- 清晰的力量对比
- 持续的成长感
- 打脸复仇桥段

## 创作要点

```
力量体系 → 等级明确、对比清晰、升级有迹可循
世界观   → 自洽完整、有探索感、留有扩展空间
主线设计 → 目标明确、阻力递进、高潮有层次
```

## 典型结构

1. 开篇：主角困境 + 金手指觉醒
2. 发展：快速成长 + 初露锋芒
3. 扩展：更大舞台 + 更强敌人
4. 高潮：终极对决 + 世界危机
5. 结局：成就巅峰 + 开放未来
