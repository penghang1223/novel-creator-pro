# 言情小说

## 核心特点

- 情感线为主线
- 男主女主的双人戏份
- 情感发展与冲突
- HE（Happy Ending）为读者主流期待

## 常见类型

- 现代言情：都市情感故事
- 古代言情：架空或历史背景
- 仙侠言情：修仙背景下的爱情
- 青春校园：校园纯爱故事

## 读者期待

- 情感的细腻描写
- 男主的魅力展现
- 撒糖情节（甜蜜互动）
- 误会与解开的过程

## 创作要点

```
人设魅力 → 男主有吸引力、女主有特点
情感推进 → 节奏合理、不拖沓不仓促
冲突设计 → 误会要能解开、阻力要有逻辑
甜蜜时刻 → 定期撒糖、满足读者期待
```

## 经典情节模式

1. 相遇：命中注定的初遇
2. 相知：逐渐了解与靠近
3. 相恋：确认心意
4. 危机：误会或外部阻力
5. 解开：消除障碍
6. 相守：结局
