## 节奏把控

### 张弛有度

- 高潮之后必有缓冲
- 连续爽点会造成审美疲劳
- 适当压抑是为更大爆发做准备

### 章节节奏

| 章节位置 | 内容建议 |
|---------|---------|
| 开头 | 场景切入、悬念设置 |
| 前1/3 | 推进剧情、铺垫冲突 |
| 中段 | 冲突升级、信息释放 |
| 后1/3 | 小高潮或悬念收尾 |
| 结尾 | 留钩子、期待下章 |

### 篇幅控制

- 单章字数：2000-4000字
- 小剧情单元：3-5章
- 大剧情单元：10-20章（一卷）

### 节奏调节技巧

```
加速：短句、快节奏事件、多切换场景
减速：长描写、内心戏、对话展开
```

## 冲突升级

### 冲突层次

1. **个人层面**：主角的个人困境与成长
2. **人际层面**：与他人的矛盾与关系
3. **社会层面**：与社会规则/势力的对抗
4. **世界层面**：涉及世界存亡的重大危机

### 升级原则

- 后期敌人 > 前期敌人
- 新冲突在旧冲突解决前铺垫
- 避免冲突重复，每次升级要有新意

### 反派设计

```
小反派（3-5章解决） → 中反派（一卷解决） → 大反派（全书主线）
```

### 冲突类型

| 类型 | 特点 | 示例 |
|-----|-----|-----|
| 生存冲突 | 生死存亡 | 被追杀、资源争夺 |
| 利益冲突 | 资源/地位 | 争夺宝物、职位竞争 |
| 情感冲突 | 爱/恨/恩/仇 | 情敌、复仇、报恩 |
| 理念冲突 | 价值观对立 | 正邪之争、道路之争 |

---

**使用建议**：在结构规划阶段参考本章节，确保故事节奏合理、冲突层次清晰。
