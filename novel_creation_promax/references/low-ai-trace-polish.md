# 低AI痕迹润色指南 (Low-AI-Trace Polish Guide)

> 识别AI写作痕迹并提供人类化改写技法的专项指南

---

## 一、AI痕迹特征识别

### 1.1 常见AI特征

- 过度使用"首先、其次、最后"
- 机械的因果连接词
- 过于完美的修辞
- 缺乏个人风格的对话
- 信息堆砌感强
- 情绪表达过于直白
- 场景描写面面俱到、缺乏取舍

### 1.2 AI痕迹自查清单

- [ ] 是否频繁出现"首先/其次/然后/最后"？
- [ ] 是否大量使用"不禁""竟然""居然"？
- [ ] 对话是否过于完整、缺少口语化断裂？
- [ ] 心理描写是否过于直白？
- [ ] 修辞是否堆砌过度？
- [ ] 是否存在信息面面俱到的问题？

## 二、人类化重写技巧

### 技巧1：打破机械结构

```
AI风格：
首先，主角走进了森林。其次，他发现了一条小路。最后，他找到了宝藏。

人类风格：
森林很深。
他走了很久，才在一片荆棘后面发现那条小路。
宝藏就在路的尽头。
```

**要点**：去除序数词和因果连接词，用断句和场景切换替代。

### 技巧2：增加细节纹理

```
平淡叙述：
他很累。

细节描写：
他靠在墙上，腿在发抖。汗水顺着脖子流下来，浸湿了衣领。

过于流畅：
她优雅地走到窗前，轻轻推开窗户，望着远方的山峦，陷入了深深的沉思。

有意停顿：
她走到窗前。
推开窗。
山在远处。
她没在看山。
```

**要点**：用具体感官细节替代抽象描述；用短句制造节奏停顿。

### 技巧3：对话自然化

```
AI对话：
"你好，"他说，"我是来自远方的旅行者。"
"很高兴认识你，"她回应，"我叫Alice。"

人类对话：
"你谁啊？"
"……旅行者。"
"哦。Alice。"
```

**要点**：
- 对话要省略、断裂、有潜台词
- 避免完整句式，用口语化表达
- 适当使用省略号和沉默

### 技巧4：情绪表达间接化

```
直接表达：
他非常紧张，心跳加速。

间接暗示：
他攥紧了拳头。手心全是汗。

心理描写直白：
她感到悲伤，眼泪止不住地流下来。

行为暗示：
她背过身去，肩膀在抖。
```

**要点**：用动作、微表情、环境变化暗示情绪，而非直接说出情绪名称。

## 三、润色优化方法

### 3.1 节奏优化

| 场景 | 技巧 | 示例 |
|------|------|------|
| 动作场面 | 增加短句短段落 | `他冲出去。门在身后炸开。` |
| 情感场景 | 使用较长句子 | 深入心理描写 |
| 叙述段落 | 混合长短句 | 保持阅读节奏 |
| 对话处理 | 简洁有力 | 避免冗长解释 |

### 3.2 描写增强

**感官细节**：
- 视觉：颜色、形状、光影
- 听觉：声音、语调、静默
- 触觉：温度、质感、疼痛
- 嗅觉：气味、氛围
- 味觉：食物、情绪

**环境烘托**：
- 用环境反映人物心境
- 天气作为情绪符号
- 意象复现形成符号

**动作细节**：
- 通过具体动作展现状态
- 用动作代替心理描写
- 微表情传递情感

### 3.3 对话优化

| 原则 | 说明 |
|------|------|
| 个性化 | 每个角色有独特说话方式 |
| 自然化 | 符合口语习惯，避免文艺腔 |
| 信息量 | 每句对话都有意义 |
| 潜台词 | 善用隐含信息 |

### 3.4 语言精炼

- **删除冗余**：去除重复、啰嗦的表达
- **替换陈词**：用更精准、生动的词汇
- **调整句式**：变换句式结构，避免单一
- **统一风格**：确保全文语言一致

```markdown
## 润色建议

2. 第X段：[具体修改建议]

## 润色后复查
- [ ] AI痕迹是否减少？

- [ ] 整体是否更流畅？
```
