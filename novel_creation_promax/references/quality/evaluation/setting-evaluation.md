## 评估理念

**核心原则**：不追求"优秀"，追求"没有硬伤"。

设定评估回答的问题不是"这个设定好不好"，而是：
- 这个设定能写吗？
- 会不会写到一半崩掉？
- 有没有给自己挖坑？

**与创意评估的区别**：

| 对比项 | 创意评估 | 设定评估 |
|-------|---------|---------|
| 核心问题 | 能不能火？ | 能不能写？ |
| 评估重点 | 市场性、吸引力 | 自洽性、可操作性 |
| 失败后果 | 写了没人看 | 写不下去、后期崩坏 |
| 判断标准 | 能火/能签/有救/劝退 | 可用/需补充/有硬伤 |

## 评估维度

### 维度一：自洽性

**核心问题**：设定之间有没有矛盾？

| 检查项 | 具体问题 |
|-------|---------|
| 世界观规则 | 核心规则是否前后一致？有没有相互冲突的设定？ |
| 力量体系 | 等级划分是否合理？能力边界是否清晰？ |
| 人物行为 | 人物的行为是否符合已建立的人设和动机？ |
| 因果逻辑 | 事件之间的因果关系是否成立？ |

**判断等级**：通过 / 有问题

### 维度二：完整性

**核心问题**：设定够不够支撑写作？

| 检查项 | 具体问题 |
|-------|---------|
| 关键设定 | 世界观核心要素是否完整？ |
| 力量等级 | 等级划分是否完整？有没有空白地带？ |
| 人物动机 | 主要人物的动机是否清晰？ |
| 核心冲突 | 故事的核心冲突是否明确？ |

**判断等级**：完整 / 需补充

### 维度三：可操作性

**核心问题**：这个设定好写吗？

| 检查项 | 具体问题 |
|-------|---------|
| 挖坑风险 | 有没有给自己挖坑的设定？ |
| 限制程度 | 有没有限制太死写不下去的地方？ |
| 展开空间 | 设定能否方便地展开剧情？ |
| 卡点预判 | 哪些地方可能卡住写不下去？ |

**判断等级**：好写 / 有风险 / 难写

### 维度四：扩展性

**核心问题**：能支撑多长篇幅？

| 检查项 | 具体问题 |
|-------|---------|
| 力量体系空间 | 等级能支撑多少级升级？有没有上限？ |
| 世界观空间 | 世界有多大？能探索多少内容？ |
| 人物成长空间 | 主角能成长多少？有没有成长终点？ |
| 剧情延展空间 | 主线能延伸出多少支线？ |

**判断等级**：充足 / 一般 / 不足

### 维度五：记忆负担

**核心问题**：设定会不会太复杂？

| 检查项 | 具体问题 |
|-------|---------|
| 设定数量 | 核心设定有多少个？读者能记住吗？ |
| 势力数量 | 有多少个势力？会不会太多？ |
| 人物数量 | 主要人物有多少？读者能分清吗？ |
| 前后矛盾风险 | 设定太多会不会导致前后矛盾？ |
| 呈现方式 | 能否用事件自然展现，而非设定堆砌？ |

**判断等级**：适中 / 偏重 / 过重

### 维度六：承诺校验

**核心问题**：设定是否兑现了创意阶段的承诺？

| 检查项 | 核心问题 |
|-------|---------|
| 钩子支撑 | 设定是否支撑了创意阶段确定的核心钩子？ |
| 卖点兑现 | 设定是否支撑了创意阶段确定的核心卖点？ |
| 爽点落地 | 金手指/力量体系是否能产出创意阶段承诺的爽点？ |
| 平台适配 | 设定是否符合目标平台的调性和读者预期？ |

**判断等级**：兑现 / 部分兑现 / 偏离

## 硬伤清单

| 硬伤类型 | 具体问题 | 后果 |
|---------|---------|-----|
| **力量体系崩** | 等级没有上限、能力没有限制、后期战力膨胀 | 后期写不下去，战力崩坏 |
| **世界观矛盾** | 核心规则前后冲突 | 读者弃书，逻辑漏洞 |
| **人物动机不清** | 主角为什么这么做？说不清 | 读者无法代入 |
| **金手指过强** | 无敌流没有限制 | 没有张力，爽感递减 |
| **金手指过弱** | 没有成长空间 | 升级线断了 |
| **设定过载** | 世界观太复杂、势力太多 | 作者记不住，读者看不懂 |
| **关键设定缺失** | 力量等级没设计、反派没设计 | 写到一半卡住 |
| **承诺偏离** | 设定偏离了创意阶段确定的核心钩子/卖点 | 读者预期落空 |

## 评估报告格式

```
【设定评估报告】

■ 自洽性检查：[通过/有问题]
  ✓ [自洽的地方]
  ⚠ [潜在问题]
  ✗ [矛盾点]

■ 完整性检查：[完整/需补充]
  ✓ [已完成的设定]
  □ [缺失的设定]

■ 可操作性检查：[好写/有风险/难写]
  ✓ [好写的地方]
  ⚠ [可能卡住的地方]
  ✗ [给自己挖的坑]

■ 扩展性检查：[充足/一般/不足]
  力量体系空间：[能支撑多少级]
  世界观空间：[能探索多少内容]

■ 记忆负担：[适中/偏重/过重]
  核心设定数量：[XX个]
  是否需要简化：[是/否]
  呈现方式建议：[如何用事件自然展现]

■ 承诺校验：[兑现/部分兑现/偏离]
  钩子支撑：[是否支撑核心钩子]
  卖点兑现：[是否兑现核心卖点]
  爽点落地：[能否产出承诺的爽点]

■ 硬伤扫描：
  ✓ 无硬伤
  或
  ✗ [硬伤1：具体描述]
  ✗ [硬伤2：具体描述]

■ 综合判断：[可用/需补充/有硬伤]

■ 需要补充的设定：
  【必须补充】
  1. [缺失项]
  
  【可选补充】
  1. [缺失项]

■ 优化建议：
  【必须修复】
  1. [问题] → [具体修复方案]
  
  【建议优化】
  1. [问题] → [具体修复方案]
  
  【可选提升】
  1. [问题] → [具体修复方案]
```

## 判断标准

| 判断 | 条件 | 后续处理 |
|-----|-----|---------|
| **可用** | 无硬伤 + 完整性达标 + 可操作 + 承诺兑现 | 生成设定文档，进入确认环节 |
| **需补充** | 无硬伤 + 有缺失设定 或 承诺部分兑现 | 补充缺失设定后重新评估 |
| **有硬伤** | 存在硬伤 或 承诺偏离 | 必须修复硬伤后重新评估 |

## 优化建议方法

### 力量体系崩

**问题表现**：等级没有上限、能力没有限制

**修复方向**：
1. 设定明确的等级上限
2. 为能力设定代价或限制
3. 设计更高维度的敌人或挑战（需谨慎，避免新的战力膨胀）

**修复原则**：
- 优先从内部找限制（代价、冷却、条件）
- 而非从外部找敌人（更高维度）

### 世界观矛盾

**问题表现**：核心规则前后冲突

**修复方向**：
1. 梳理所有核心规则，找出矛盾点
2. 统一规则体系，删除冲突设定
3. 如果无法统一，考虑设定为"表面规则"和"真实规则"

### 人物动机不清

**问题表现**：主角为什么这么做？说不清

**修复方向**：
1. 补充人物的背景故事
2. 明确人物的核心欲望
3. 设计触发人物动机的关键事件

### 金手指过强/过弱

**问题表现**：
- 过强：无敌流没有限制
- 过弱：没有成长空间

**修复方向**：
- 过强：增加代价、限制、冷却时间
- 过弱：增加进化路线、解锁新能力

**平衡性测试**：
脑推几个关键场景，验证金手指是否好用：
1. 主角陷入绝境时，金手指能如何帮助？
2. 主角成长时，金手指如何升级？
3. 金手指的限制在哪些场景会触发？

### 设定过载

**问题表现**：世界观太复杂、势力太多

**修复方向**：
1. 合并相似势力
2. 删除非核心设定
3. 将部分设定推迟到后续卷再展开
4. 用事件自然展现设定，而非设定堆砌

### 关键设定缺失

**问题表现**：力量等级没设计、反派没设计

**修复方向**：
1. 列出必须完成的设定清单
2. 优先补充影响主线的关键设定
3. 其他设定可在写作过程中补充

### 承诺偏离

**问题表现**：设定偏离了创意阶段确定的核心钩子/卖点

**修复方向**：
1. 回顾创意评估报告中的核心钩子和卖点
2. 调整设定以支撑核心钩子和卖点
3. 如果设定更好，考虑更新创意方案
