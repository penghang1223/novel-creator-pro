# 追读力分类法 (Reading Power Taxonomy)

> 追读力 = 读者"想看下一章"的驱动力。本文件将其结构化为 3 个维度：钩子类型、爽点模式、微兑现类型。
> 与 `review-skill/references/review-dimensions.md` 维度5（追读力）和题材 `.profile.yaml` 联动。

---

## Part A: 6 种钩子类型 (H1-H6)

章末钩子是追读力的第一驱动力。每章结尾至少使用 1 种。

| ID | 类型 | 效果 | 典型写法 |
|----|------|------|---------|
| H1 | 悬念钩子 | 抛出问题不给答案 | "门后面是一个她绝对没想到的人。" |
| H2 | 身份揭示钩子 | 撕开伪装/展示底牌 | "他摘下面具，露出一张——" |
| H3 | 冲突升级钩子 | 引入更高风险 | "电话那头沉默了三秒，然后说：'还有一件事没告诉你。'" |
| H4 | 情感临界钩子 | 卡在情感爆发前一刻 | "她嘴唇动了动，最终什么也没说。" |
| H5 | 反转预兆钩子 | 暗示反向发展 | "他不知道的是，这杯酒里——" |
| H6 | 倒计时钩子 | 显示剩余时间 | "距离爆炸还有四分钟。" |

### 使用规则
- 每章结尾至少 1 种，优先使用题材偏好类型
- 不要连续 3 章使用同一种钩子类型
- H1（悬念）是最通用的兜底选项
- H6（倒计时）适合玄幻/仙侠（天劫倒计时）和悬疑（破案倒计时）

## Part B: 8 种爽点模式 (C1-C8)

爽点是追读力的"正反馈"来源。每章至少 1 个小爽点。

| ID | 模式 | 核心爽点 | 典型场景 |
|----|------|---------|---------|
| C1 | 强者装弱 | 实力突然曝光 | 被瞧不起的人亮出真实身份/实力 |
| C2 | 信息差碾压 | 精准操作认知碾压 | 主角知道别人不知道的关键信息 |
| C3 | 追妻火葬场 | 反向拒绝情绪反转 | 被抛弃的人反过来拒绝追求者 |
| C4 | 隐忍反击 | 持续压抑后一次爆发 | 长期被欺负的人一朝清算 |
| C5 | 借力打力 | 反派反噬智力爽 | 用敌人自己的手段击败敌人 |
| C6 | 等级突破 | 量变质变实力飞跃 | 修炼/能力等级提升 |
| C7 | 真相揭示 | 线索串联谜底揭晓 | 多条线索汇聚指向真相 |
| C8 | 承诺兑现 | 长期铺垫一次性回收 | 早期伏笔/承诺在关键时刻回收 |

### 爽点流水线（通用）

```
建立期待 → 加深压抑 → 制造误判 → 延迟释放 → 反转爆发 → 余波扩散
```

每个爽点模式都应尽量走完流水线。强度公式：

```
爽点强度 =（压抑值 × 悬念值）× 反转差值 ÷ 释放延迟
```

### 使用规则
- 每章至少 1 个小爽点（可以是任意模式的轻量版）
- 每 3 章至少 1 个中等爽点（走完流水线 3 步以上）
- 每 10 章至少 1 个大爽点（走完完整流水线）
- 爽:压比例按题材 profile 设定（默认 7:3）

## Part C: 7 种微兑现类型 (M1-M7)

微兑现 = 小型的正反馈/信息释放，维持读者的"小满足感"。与爽点不同，微兑现不需要完整流水线。

| ID | 类型 | 频率 | 说明 |
|----|------|------|------|
| M1 | 伏笔回收 | 每 5-10 章 | 回收一个小伏笔/小暗示 |
| M2 | 能力展示 | 每章可有 | 展示主角的一项能力/特长 |
| M3 | 关系推进 | 每 1-2 章 | 人物关系有微小进展 |
| M4 | 信息释放 | 每章至少 1 次 | 释放一条新信息（世界观/真相/背景） |
| M5 | 情绪释放 | 跟随爽点 | 读者积压的情绪得到释放 |
| M6 | 智力验证 | 每 3-5 章 | 主角的判断/推理被验证正确 |
| M7 | 日常锚点 | 每 2-3 章 | 日常生活细节，给读者"喘息" |

### 债务管理
- 微兑现是"承诺"的一种形式，未及时回收 = 债务堆积
- 读者积攒的"债务"不宜超过 3 个未回收
- 超过 3 个 → 触发追读力下降预警

### 使用规则
- 每章至少 1 个微兑现（优先 M4 信息释放，最轻量）
- 不要一章内超过 3 个微兑现（会显得"赶进度"）
- M7（日常锚点）用于高张力章节后的缓冲，不可省略

## Part D: 题材映射表

不同题材偏好不同的 H/C/M 组合。`.profile.yaml` 中的 `reading_power` 和 `cool_point.preferred_types` 字段即从此表取值。

| 题材 | 偏好钩子 (H) | 偏好爽点 (C) | 偏好微兑现 (M) |
|------|-------------|-------------|---------------|
| 都市 | H1, H3, H5 | C1, C2, C4 | M2, M4, M6 |
| 言情 | H4, H1, H2 | C3, C1, C8 | M3, M5, M7 |
| 玄幻 | H3, H6, H1 | C6, C1, C4 | M2, M4, M6 |
| 仙侠 | H6, H3, H2 | C6, C5, C4 | M2, M1, M4 |
| 悬疑 | H1, H5, H2 | C7, C2, C5 | M4, M6, M1 |
