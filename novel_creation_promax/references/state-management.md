## 概述

### 为什么需要状态管理

| 问题 | 解决方案 |
|-----|---------|
| 新开对话无记忆 | 状态文件持久化存储 |
| 不知道写到哪了 | 入口文件记录当前进度 |
| 设定忘记/矛盾 | 设定文档统一管理 |
| 长篇前后矛盾 | 三层记忆架构保障连贯性 |

### 核心原则

- **持久化**：所有创作内容落盘存储
- **可恢复**：新会话可读取状态继续
- **自包含**：入口文件包含恢复所需的完整信息
- **渐进加载**：先读入口文件，按需加载更多

## 三层记忆架构

```
┌─────────────────────────────────────────────────────┐
│                 永恒记忆 = 02-设定                   │
│  世界观、力量体系、人物档案、势力设定                 │
│  （创作阶段产出，写作阶段只读引用）                   │
└─────────────────────────────────────────────────────┘
                          ↓ 引用
┌─────────────────────────────────────────────────────┐
│                 阶段记忆 = 00-记忆/状态记录           │
│  当前进度、人物状态、时间线、伏笔、细纲执行           │
│  （写作阶段动态更新）                                │
└─────────────────────────────────────────────────────┘
                          ↓ 临时
┌─────────────────────────────────────────────────────┐
│                 工作记忆 = 00-记忆/工作记忆           │
│  近期摘要、临时笔记                                  │
│  （写作时加载，写完后更新/清理）                      │
└─────────────────────────────────────────────────────┘
```

| 记忆层级 | 目录位置 | 内容 | 更新频率 |
|---------|---------|-----|---------|
| **永恒记忆** | 02-设定/ | 世界观、人物档案、力量体系 | 极少修改 |
| **阶段记忆** | 00-记忆/状态记录/ | 当前进度、人物状态、时间线、伏笔、细纲执行 | 每章更新 |
| **工作记忆** | 00-记忆/工作记忆/ | 近期摘要、临时笔记 | 每次写作时 |

## 状态文件格式

### 创作状态.md（入口文件）

这是**快速恢复入口**，新会话时读取此文件即可恢复创作状态。

```markdown
# 创作状态

## 基本信息

- 小说名称：[名称]
- 类型定位：[类型]
- 创建时间：[日期]
- 最后更新：[日期]

## 当前状态

- 当前阶段：[创意孵化/设定构建/结构规划/细纲设计/正文创作]
- 当前卷：[第X卷]
- 当前章节：第X章
- 下一步操作：[具体操作，如"继续撰写第11章"]

## 阶段完成情况

| 阶段 | 状态 | 完成时间 | 产出文档 |
|-----|------|---------|---------|
| 创意孵化 | ✓/○/- | | 01-创意/创意文档.md |
| 设定构建 | ✓/○/- | | 02-设定/ |
| 结构规划 | ✓/○/- | | 03-结构/ |
| 细纲设计 | ✓/○/- | | 04-细纲/ |
| 正文创作 | ○ | | 05-正文/ |

## 关键决策记录

| 日期 | 阶段 | 决策内容 | 编辑判断 |
|-----|-----|---------|---------|

## 快速恢复

新会话继续创作，请说："继续创作《[小说名称]》"
```

### 当前进度.md

```markdown
# 当前进度

## 基本信息

- 当前章节：第X章
- 细纲状态：第一卷已完成

## 卷目进度

| 卷 | 细纲 | 正文进度 | 状态 |
|---|-----|---------|-----|
| 第一卷 | ✓ | X/60章 | 进行中 |
| 第二卷 | 待规划 | - | 待开始 |
| 第三卷 | 待规划 | - | 待开始 |

## 阶段性目标

- 当前目标：[本卷目标]
- 下一里程碑：[主节点或事件]
```

## 状态恢复流程

### 新会话恢复

```
用户："继续创作《XXX》"

↓

读取入口文件
└── ./小说创作/00-记忆/创作状态.md

↓

根据当前阶段加载必要文件
├── 创意/设定/结构/细纲阶段：加载对应阶段文档
└── 正文创作阶段：
    ├── 00-记忆/状态记录/当前进度.md
    ├── 00-记忆/状态记录/人物状态表.md
    ├── 00-记忆/工作记忆/近期摘要.md
    └── 04-细纲/[当前卷]细纲.md（如需要）

↓

输出恢复确认
└── 当前状态摘要 + 下一步操作建议
```

### 恢复确认格式

```markdown
【作者】
━━━━━━━━━━━━━━━━━━━━━━━━━━━━
已恢复创作状态

■ 当前状态
  小说：《XXX》
  阶段：正文创作
  进度：第一卷 第X章

■ 最近进展
  [简要描述最近1-2章的内容]

■ 下一步
  继续撰写第X章，细纲规划如下：
  [简要描述本章规划]

可以开始了吗？
━━━━━━━━━━━━━━━━━━━━━━━━━━━━
```

## 归档机制

### 归档时机

| 时机 | 操作 |
|------|------|
| 卷末完成 | 创建卷末总结，归档到对应卷目录 |
| 新卷开始 | 清理工作记忆，准备新卷状态 |

### 归档内容

```
./小说创作/00-记忆/归档/
└── 第一卷/
    └── 卷末总结.md
```

### 卷末总结格式

```markdown
# 第一卷卷末总结

## 概要

- 章节范围：第1-60章
- 字数：约XX万字
- 完成时间：[日期]

## 主线完成情况

| 主节点 | 规划内容 | 执行情况 | 偏差说明 |
|--------|---------|---------|---------|
| M1 | 开篇锚点 | ✓ | 无偏差 |
| M2 | 关键转折 | ✓ | 灵活调整 |
| M3 | 高潮事件 | ✓ | 无偏差 |
| M4 | 卷末收束 | ✓ | 无偏差 |

## 人物状态变化

| 人物 | 卷初状态 | 卷末状态 | 主要变化 |
|-----|---------|---------|---------|
| 主角 | 炼气三层 | 筑基初期 | 突破两个大境界 |

## 伏笔回收情况

- 已回收：X个
- 待回收：X个（将延续到第二卷）

## 经验总结

[本卷创作的经验教训]
```

### 不归档的内容

| 文件 | 处理方式 |
|------|---------|
| 创作状态.md | 不归档，持续更新 |
| 状态记录/*.md | 不归档，继续累积 |
| 工作记忆/*.md | 可选择性清理 |
