# 三阶段知识过滤

> 借鉴 AI_NovelGenerator：外部知识进入知识库前，必须经过三阶段过滤，避免矛盾信息污染创作。

## 流程

```
原始素材（文章/教程/案例）
    │
    ▼
Stage 1: 冲突检测
    │  新内容与现有知识库有无矛盾？
    │  有 → 标记冲突，暂停入库
    │  无 → 进入 Stage 2
    │
    ▼
Stage 2: 价值评估
    │  这条信息对创作有多少实际帮助？
    │  高（可执行规则/技法/模板）→ 进入 Stage 3
    │  中（启发性但需改写）→ 标记"需改写"，进入 Stage 3
    │  低（纯理论/鸡汤/与创作无关）→ 拒绝入库
    │
    ▼
Stage 3: 分类入库
    │  按内容身份分配存储路径
    │  原创 → space/crafted/
    │  收集 → space/found/
    │  同步到知识库对应目录
    │
    ▼
完成
```

## Stage 1: 冲突检测

扫描现有知识库中同题材/同主题的已有内容，检查：

| 检查维度 | 具体内容 |
|----------|---------|
| 题材矛盾 | 新素材推荐的写法与已有题材 profile 冲突（如题材要求爽:压=7:3，新素材建议5:5） |
| 红线矛盾 | 新素材建议的技法违反红线系统（如建议使用绝对禁止词） |
| 设定矛盾 | 新素材的世界观规则与已有设定冲突 |
| 技法矛盾 | 新素材推荐的技法与写作宪法/速查卡矛盾 |

**有冲突时**：不直接拒绝，生成冲突报告，列出：
1. 冲突双方的原文出处
2. 冲突的具体点
3. 建议的取舍方案
4. 由用户确认如何处理

## Stage 2: 价值评估

评估标准：

| 等级 | 标准 | 处理方式 |
|------|------|---------|
| **A - 可执行** | 明确的规则/模板/检查清单/阈值，可直接应用 | 直接入库 |
| **B - 启发性** | 案例分析/经验分享/思路参考，需改写为可执行规则 | 标记"需改写"，入库但标记待处理 |
| **C - 低价值** | 纯理论/鸡汤/过于泛化的建议/与网文无关 | 拒绝入库，不占用存储 |

**评估问题**：
1. 这条信息能不能直接指导"下一章怎么写"？
2. 能不能转化为一条写前检查项或约束规则？
3. 如果删掉这条信息，会不会影响创作决策？

## Stage 3: 分类入库

沿用 CLAUDE.md 的知识摄入闭环分类规则，此处不再重复。

新增要求：每条入库知识必须附带：
- `source`: 来源 URL 或文件路径
- `ingest_date`: 摄入日期
- `value_grade`: Stage 2 评估等级（A/B）
- `conflict_checked`: Stage 1 是否通过（true/false）
- `rewrite_needed`: 是否需要改写（true/false）

## 与 ingest.py 的联动

`ingest.py --auto-classify` 时自动执行：
1. 调用冲突检测（对比同目录已有文件）
2. 价值评估（基于内容关键词密度 + 结构化程度）
3. 自动分类入库

手动模式下，三阶段由 AI 在对话中执行，不调用脚本。
