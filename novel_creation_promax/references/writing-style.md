## 核心原则

### 网文写作的本质
- **目的**：让读者获得阅读快感
- **特点**：根据风格不同，可快可慢、可简可繁
- **核心**：服务于故事和读者体验

### 五大基础要求
1. ✅ 视角统一（第三人称或第一人称，全书保持一致）
2. ✅ 语言符合人物设定
3. ✅ 段落节奏与情节配合
4. ✅ 情绪真实可信
5. ✅ 细节服务于故事

## 叙事视角

### 第三人称（推荐）
**优点**：
- 全知视角，便于展开多线剧情
- 客观冷静，适合爽文、玄幻、都市等
- 容易控制节奏

**示例**：
```
张伟看着眼前的银行卡，愣住了。

一千万。

他这辈子都没见过这么多钱。
```

### 第一人称
**优点**：
- 代入感强
- 适合心理描写
- 适合言情、悬疑、日记体

**示例**：
```
我看着银行卡上的数字，手心开始出汗。

一千万。

这笔钱来得太突然，我甚至有些不敢相信。
```

### 视角选择建议
| 题材 | 推荐视角 | 原因 |
|------|---------|------|
| 爽文/玄幻 | 第三人称 | 便于展开打脸、战斗场景 |
| 言情/都市情感 | 两者皆可 | 看作者习惯 |
| 悬疑/推理 | 第三人称 | 需要多视角铺陈线索 |
| 日记体/回忆录 | 第一人称 | 增强真实感 |

## 语言风格

### 直白口语化（快节奏网文首选）
**适用**：爽文、系统流、重生文

```
"卧槽，这小子哪来的钱？"

"不会是借的高利贷吧？"

周围人议论纷纷。

张伟没理会，直接刷卡。

"滴——"

支付成功。
```

### 文艺诗意化（情感向、氛围向）
**适用**：言情、文艺风、情感小说

```
窗外的雨还在下，敲打着玻璃，像是某种无言的告别。

她坐在床边，手指抚过那张泛黄的照片，记忆像潮水一样涌来。

三年了，她以为自己已经忘记，但雨声还是把她拉回了那个夏天。
```

### 细腻感官化（情感小说、亲密场景）
**适用**：情感细腻、成人向内容

```
他的气息靠近，带着雪松和琥珀的味道，像是深林里的雾，危险又诱惑。

她感觉到他的手掌贴上后腰，温热的温度透过薄薄的布料传来，让她整个人都绷紧了。

"别紧张。"他的声音就在耳边，低沉得像是叹息。
```

### 禁止的文青式表达（通用）
| 问题类型 | 错误示例 | 改进方向 |
|---------|---------|---------|
| 过度心理描写 | 他的内心翻涌着难以言表的复杂情绪 | 用动作或对话展现 |
| 堆砌形容词 | 美丽动人的她穿着华丽的长裙 | 精简，保留核心信息 |
| 强行升华 | 这一刻，他明白了生命的真谛 | 删掉，或用具体事件体现 |
| 陈词滥调 | 时光荏苒，岁月如梭 | 具体写出时间流逝的方式 |

## 段落结构

### 快节奏风格
**特点**：短句、碎段、留白

```
重生了。

张伟睁开眼，盯着天花板看了半天。

熟悉的吊灯，熟悉的墙纸，还有熟悉的——

"儿子，起床了！今天要迟到了！"

他妈的声音从楼下传来。

他愣了三秒，然后猛地坐起来。

1998年。

他真的回到了1998年。
```

### 慢节奏风格
**特点**：完整段落、环境描写、心理刻画

```
重生后的第一夜，张伟躺在床上久久无法入睡。

窗外的月光很亮，照在他熟悉的旧房间里。墙上贴着他初中时代的海报，书桌上堆着还没写完的暑假作业——一切都像是停留在1998年的那个夏天。

他想起上辈子的自己，庸庸碌碌一辈子，到死也没能实现任何梦想。而现在，他有了重来一次的机会。

"这一次，"他在心里默默发誓，"我一定要活得不一样。"
```

## 开篇规范

### 黄金三章原则
- 第一章：主角出场 + 核心设定 + 第一个小悬念
- 第二章：展开设定 + 第一个小冲突
- 第三章：第一个小高潮 + 钩子（让读者想继续看）

### 开篇钩子类型
| 类型 | 示例 | 适用题材 |
|------|------|---------|
| 悬念式 | "我死了三次，这是第四次醒来。" | 悬疑、奇幻 |
| 反转式 | "所有人都以为我是废物，直到那天我亮出了实力。" | 爽文、逆袭 |
| 情感式 | "她走的那天，我连再见都没说出口。" | 言情、情感 |
| 动作式 | 枪声响起的那一刻，他知道自己必须逃。 | 动作、谍战 |
| 日常式 | 早高峰的地铁上，他看到了十年没见的初恋。 | 都市、言情 |

## 情绪推动

### 情绪曲线
```
平静 → 紧张 → 冲突 → 爆发 → 释放 → 新的平衡
```

### 爽文的情绪节奏
```
压抑 → 更压抑 → 爆发 → 爽感
```

### 情感文的情绪节奏
```
平静 → 心动 → 纠结 → 冲突 → 释然
```

## 不同风格指南

### 快节奏爽文风
- 第三人称
- 短句碎段
- 打脸装逼要干脆
- 情绪爆发要强烈
- 避免冗长描写

### 种田经营风
- 第三人称或第一人称
- 完整段落
- 细水长流的成长
- 详细的建设过程
- 适度的日常感

### 悬疑推理风
- 第三人称
- 线索铺设要隐蔽但合理
- 反转要有逻辑支撑
- 节奏张弛有度
- 避免硬伤

### 甜宠言情风
- 两人称皆可
- 互动甜蜜细腻
- 糖分充足
- 小虐怡情
- 避免狗血误会

### 情感细腻风
- 两人称皆可
- 感官描写丰富
- 心理刻画深入
- 氛围营造到位
- 细节真实动人

## 示例对照

### 爽文风格
```
"张伟，你被开除了！"

经理把辞退书摔在他脸上。

张伟捡起来，看了一眼，然后笑了。

"开除？"

他把辞退书撕成碎片，洒在地上。

"老子不干了。"

转身离开，背影潇洒。

身后，经理的脸色难看到了极点。

因为他不知道，张伟刚刚绑定了神豪系统，下一秒账户就会多出一个亿。
```

### 情感风格
```
苏念坐在咖啡厅的角落，盯着窗外的人流。

玻璃上映出她的倒影——鹅蛋脸、杏眼、微卷的长发散在肩上。28岁的她，看起来比实际年龄要小一些。

"小姐，您的咖啡。"

服务员的声音打断了她的思绪。

"谢谢。"她端起杯子，抿了一口。

苦。

就像现在的生活。

三天前，她亲眼看到男友搂着别的女人走进酒店。那一刻，她没有冲上去质问，只是默默转身离开。

因为她知道，有些事情，问了也没用。
```

---

**记住**：风格没有优劣，只有适合不适合。选择最适合你故事的写法，然后保持一致。
