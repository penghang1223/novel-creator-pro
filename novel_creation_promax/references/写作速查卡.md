## 一、写前：章节结构与节奏

### 1.1 单章节奏模板（3000字/章）

| 段落 | 字数 | 占比 | 功能 |
|------|------|------|------|
| **开头承接** | 300字 | 10% | 承接上章悬念 / 引出新冲突 |
| **发展推进** | 1500字 | 50% | 推进剧情，埋下伏笔 |
| **章节高潮** | 1000字 | 33% | 本章节点 / 小爽点 / 反转 |
| **结尾断章** | 200字 | 7% | 新悬念 / 卡章，引导点下一章 |

### 1.2 核心原则

1. **开头300字必须有冲突** — 不能用环境描写或日常开场
2. **每章至少一个情绪高潮点**
3. **章末必须卡在悬念/冲突处** — 平淡断章=读者弃文
4. **爽:压 = 7:3**

### 1.3 有效断章位置

- 悬念最高处："门开了，里面竟然是——"
- 打脸前一刻："他冷笑一声，说出了那个名字..."
- 新冲突出现："就在这时，手机响了..."
- 情感高潮："她终于说出了那句..."
- 身份揭示前："他摘下面具，露出一张熟悉的脸..."

### 1.4 无效断章（绝对不能犯）

- 日常描写后断章 / 大段设定后断章 / 平淡对话后断章 / 环境描写后断章 / 主角心理活动后断章（无新信息）

### 1.5 卡章公式

```text
冲突升级（本章）→ 高潮前一刻（断章）→ 下一章释放
```

### 1.6 5章张力模板

```text
章1（推进）：张力6 — 新事件发生
章2（铺垫）：张力4 — 准备+人物关系
章3（铺垫）：张力5 — 准备+小冲突
章4（高潮）：张力8-9 — 冲突爆发
章5（过渡）：张力2-3 — 余波+新方向
```

### 1.7 张力提升7技法

倒计时 / 信息不对称 / 小失误 / 打断节奏 / 沉默拉长 / 转移焦点 / 不可逆选择

### 1.8 张力检查清单

- 读者是否同时看到了两种冲突的可能性？
- 有没有时间压力或两难选择？
- 有没有信息差在起作用？
- 高潮中有没有人付出代价或冒风险？
- 高潮之后有没有"余震"段落？（至少100字）
- 有没有用具体动作/细节制造张力，而不是用形容词？

## 二、写中Pass 1：对话六要素

**每段对话场景至少覆盖2-3个要素：**

| 要素 | 说明 | 示例 |
|------|------|------|
| 1. 表情/微反应 | 瞳孔收缩、嘴唇发白、眉心拧紧、喉结滚动 | 必须有 |
| 2. 心理独白 | 表里张力，口是心非 | "这礼物太贵重了"（但心里盘算能卖多少钱） |
| 3. 听觉细节 | 音量/音色/语速的物理属性 | "声音沙哑得像砂纸磨过" |
| 4. 环境烘托 | 氛围背景板，或与对话反衬 | 窗外烟花震耳，他凑耳边说"我们结束了" |
| 5. 节奏/留顿 | 省略号=未尽之意，破折号=被打断，动作停顿 | "我以为……我以为你会站在我这边" |
| 6. 倾听者反应 | 对方的非语言反应比说话人更重要 | "我要结婚了"→他刀尖在盘子上划出刺耳锐响 |

### 对话9项自查清单

- [ ] 表情/微反应
- [ ] 心理独白或口是心非（至少1处）
- [ ] 感官细节——听觉/嗅觉/触觉（至少1处）
- [ ] 环境烘托（至少1处）
- [ ] 节奏停顿——省略号/破折号/打断（至少1处）
- [ ] 倾听者反应（至少1处）
- [ ] 声纹识别（不看标签能分辨谁在说话）
- [ ] 冲突阻力（至少一方有不配合/信息差/权力角力）
- [ ] 冰山留白（至少1处话里有话）

## 三、写中Pass 1：对话五大技法

### 3.1 动作锚点代替"他说/她问"

```text
❌ 张三说"你迟到了"。李四说"路上堵车"。
✅ 张三抬腕看表，眉头锁成"川"字："你迟到了。"
```

### 3.2 拒绝有问必答

回避/沉默/转移话题/言行不一。说什么≠想什么。

### 3.3 环境打断对话

窗外的雨噼里啪啦打在玻璃上。"我们要分开了。"声音很轻。

### 3.4 制造冲突和打断

抢话/打断/吞吞吐吐。每段对话场景至少一方有阻力。

### 3.5 三种对话张力模式

- **冰山理论**（暧昧/冷战）：嘴上说"今晚吃什么"，实际在说"要不要离婚"
- **权力博弈**（审讯/谈判）：上位者做别的事，对话长短体现压迫感
- **暴力前夜**（争吵前夕）：讽刺+带刺幽默，物理距离逼近

### 对话4条负约束

- 禁止写"他感到很愤怒"——必须通过动作表现
- 禁止使用"你好""请问""谢谢"等礼貌用语
- 禁止让角色完整回答对方的问题
- 禁止使用"他说""她问道"作为对话标签

## 四、写中Pass 1：人味写作

### 4.1 情绪表达优先级

```text
行为表现 > 生理反应 > 心理活动 > 直接命名（最差）
```

### 4.2 矛盾特质模型

每个核心人物必须有至少一组矛盾特质。不是"有时候A有时候B"，而是"同时是A也是B"。

### 4.3 偏差行为原则

**不要让人物"正确地行动"，要让人物"像人一样行动，然后刚好赢了"。**

### 4.4 对话三要素（每段对话至少满足两项）

- 没说完的话："你知不知道那天我——算了。"
- 答非所问："你爱我吗？""今晚吃了吗？"
- 情绪转移：想关心，说出来是"你穿这么少不冷吗"

## 五、写中Pass 1：爽点设计

### 5.1 爽点强度公式

```text
爽点强度 =（压抑值 × 悬念值）× 反转差值 ÷ 释放延迟
```

### 5.2 爽点流水线

```text
① 建立期待 → ② 加深压抑 → ③ 制造误判 → ④ 延迟释放 → ⑤ 反转爆发 → ⑥ 余波扩散
```

### 5.3 密度规则

- **每章**：至少1个小爽点（打脸/吐槽/反杀）
- **每3章**：1个中爽点（阶段性胜利）
- **每10章**：1个大爽点（重要转折/突破）
- **每30章**：1个超大爽点（卷末高潮）

### 5.4 核心爽点模块（选1-2个叠加）

| 模块 | 触发 | 爽点 | 结果 |
|------|------|------|------|
| 强者装弱 | 低身份环境 | 实力突然曝光 | 震惊+反差崩塌 |
| 信息差碾压 | 他人无知 | 精准操作 | 认知碾压 |
| 追妻火葬场 | 失去后觉醒 | 反向拒绝 | 情绪反转 |
| 隐忍反击 | 持续压迫 | 一次爆发 | 压抑释放 |
| 借力打力 | 敌人强大 | 反派反噬 | 智力爽 |

## 六、写中Pass 1：潜台词技法

### 6.1 五种潜台词

1. **指桑骂槐**：表面说A，实际说B。用具体事实暗示，不直接说情绪
2. **顾左右而言他**：被问关键问题时故意回答其他内容。回避本身就是回答
3. **言行不一**：嘴上否定，身体诚实。"我才不关心你"→把伞塞到他手里
4. **信息差**：读者比角色知道得多/少/各知一半
5. **反话正说**：表面意思和真实意思相反。"你走了也好"（挽留）

### 6.2 动作流大纲模板（写对话前先填）

```text
出场角色：A, B
表面话题：他们在聊什么
真实议题：实际在冲突什么
A的目标 / B的目标
A不能说什么 / B不能说什么
动作流：试探→回避→加压→反击/崩溃→张力升级→结局
```

### 6.3 冰山理论核心

说出来的只占1/8。**永远不写角色的内心定义。** 用行为/感官/注意力变化来暗示。

## 七、写后Pass 2：去AI化

### 7.1 "每段三刀"法则

每一段必须完成：
1. **删**一句解释
2. **加**一个动作
3. **断**一个句子

### 7.2 八大核心技法

1. **结构破坏**：长→短→极短→停。打碎整齐感
2. **断句控制**：单句成段 / 半句断开 / 非完整表达
3. **行为替代情绪**："他很愤怒"→"他把杯子放重了一点"
4. **对话降级**：不完整 / 不礼貌 / 不解释。"你好请问你是谁"→"你谁？"
5. **信息删减**：能删的解释句/总结句/因果句全删。能让读者自己懂的全部删掉
6. **无效细节**：插入"没用但真实"的细节。门卡了一下，他用脚顶开
7. **认知偏差**：人物必须看错/误判/犹豫
8. **风格扰动**：同一段内允许口语+文学混用，冷静+情绪跳变

### 7.3 节奏控制

| 场景 | 句式 |
|------|------|
| 动作 | 短句 |
| 紧张 | 极短句 |
| 情绪 | 稍长句 |
| 过渡 | 混合 |

## 八、去AI化：20条硬性禁止

### 宣传腔与通稿腔
1. 禁止"令人叹为观止/充满活力/开创性/卓越非凡"类营销式形容

### 夸大意义
2. 禁止把事实硬抬成"关键时刻/历史转折/时代缩影"

### 尾巴句假装深刻
3. 禁止"从而/以此/确保/进一步凸显/这表明/这说明/这反映了"

### 挑战展望模板
4. 禁止"尽管…但…仍…未来…"成段套壳

### 高频AI惯用词
5. 禁止"此外/至关重要/深入探讨/强调/关键/复杂性/格局/赋能/打造"成串出现

### 金句口号
6. 禁止那种"听起来很能摘抄"的句子收束段落

### 过度对称
7. 禁止"既要…又要…""一方面…另一方面…"整齐句式滥用

### 模糊堆叠
8. 禁止"可能/或许/一定程度上"堆叠。不确定就给边界，确定就直接给结论

### 虚假跨度
9. 禁止随手写"从…到…"制造宏大感

### 标点滥用
10. 禁止过度使用括号、冒号、破折号

### 表情符号
11. 禁止emoji入正文

### 陪聊谄媚
12. 禁止"希望对你有帮助/好问题/太棒了"类口吻

### 形容词堆叠
13. 禁止连续使用3个以上形容词描述同一人物

### 人物介绍句式
14. 禁止用"他是一个……的人"做人物介绍

### 脸谱化
15. 禁止人物所有行为都与其主标签一致

### 纯对话无动作
16. 纯对话超过3轮必须插入动作/环境细节

### 最优选择
17. 禁止角色总做"最优选择"。让人做愚蠢的、冲动的、自相矛盾的决定

### 表演式感动
18. 禁止人物说的话太"正确"、动作太"完美"、情感转变太"突然"

### 逻辑完整
19. 禁止所有对话都逻辑完整、表达完美

### 节奏一致
20. 禁止所有人说话节奏一样（短句/长句/口头禅要有差异）

## 九、套路预判（写前必查）

### 常见套路+绕开策略

| 套路 | 典型表现 | 绕开策略 |
|------|----------|----------|
| TR-01 英雄救美 | 主角恰好出现救人 | 救了但方式不体面/被救者不领情 |
| TR-03 反派降智 | 反派突然变蠢 | 不降智，用其他方式赢 |
| TR-05 绝地翻盘 | 最绝望时刻突然反转 | 翻盘但不完全，留更大问题 |
| TR-06 打脸爽点 | 看不起主角的人被打脸 | 打脸有代价，或被看穿意图 |
| TR-08 感情升温 | 互动后关系更近 | 更近同时出现新距离感 |
| TR-09 深夜谈心 | 角色掏心窝子 | 谈心但不真诚，有人隐瞒 |
| TR-12 意外转折 | 一切顺利突然出事 | 转折有伏笔 |
| TR-14 沉默对峙 | 两人对视沉默然后爆发 | 不对视，或沉默中一方先笑 |

### 原创性加分项（每章至少1项）

- 反预期细节（愤怒的人反而笑了一下）
- 视角偏移（关键场景从配角视角写一句）
- 信息差利用（让读者比角色知道得多或少一点）
- 留白（不说破某个情绪/事件）
- 日常穿插（紧张场景中插入完全日常的动作）
