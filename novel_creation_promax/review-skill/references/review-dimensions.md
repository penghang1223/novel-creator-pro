# 审查维度标准

> 审稿时的评分依据。每个维度直接引用知识库原文的具体规则。
> **核心原则：审稿用知识库原文，不用速查卡。** 速查卡是写时快参照，审稿需要原文的完整规则+案例。

## 一、对话质感（满分10分）

### 来源文件

- `knowledge_base/40_Writing/03_人物与对话/对话质感完整框架.md`
- `knowledge_base/40_Writing/03_人物与对话/AI对话丰满化技法.md`
- `knowledge_base/40_Writing/03_人物与对话/人味写作指南.md`

### 检查清单

#### 六要素覆盖（基础层）

从正文中抽取 2-3 段对话场景，逐项检查：

| 要素 | 检查方法 | 达标标准 |
|------|---------|---------|
| 1. 表情/微反应 | 对话中是否有瞳孔收缩/嘴唇发白/眉心拧紧/喉结滚动等微反应 | 每段对话至少1处 |
| 2. 心理独白 | 是否有口是心非/表里张力（嘴上说A，心里想B） | 至少1处 |
| 3. 听觉细节 | 是否有声音的物理属性描写（沙哑/尖锐/像砂纸磨过/音量变化） | 至少1处 |
| 4. 环境烘托 | 对话场景是否有环境描写（反衬或烘托） | 至少1处 |
| 5. 节奏/留顿 | 是否有省略号/破折号/动作停顿 | 至少1处 |
| 6. 倾听者反应 | 是否有听话人的非语言反应（比说话人更重要） | 至少1处 |

#### 进阶检查

| 检查项 | 方法 | 达标标准 |
|--------|------|---------|
| 声纹识别 | 删掉所有"某某说"，能否分辨谁在说话 | 主要角色可区分 |
| 冲突阻力 | 每段对话是否至少一方有不配合/信息差/权力角力 | 每段至少1处 |
| 冰山留白 | 是否有话里有话/潜台词 | 至少1处 |

#### 负约束检查（人味写作指南 + AI对话技法）

| 禁止项 | 检查 |
|--------|------|
| "他感到很愤怒"类情绪直说 | 是否用行为/生理表现代替 |
| "你好""请问""谢谢"等礼貌用语 | 是否被替换为角色口吻 |
| 角色完整回答对方的问题 | 是否有回避/转移/答非所问 |
| "他说""她问道"作为对话标签 | 是否用动作锚点代替 |
| 纯对话超过3轮无动作 | 每3轮对话是否插入动作/环境/感官 |

#### 干涩检测5问（潜台词与张力技法.md）

对抽取的对话场景逐段回答：
1. 这段对话里，角色有没有没说出口的真实意图？
2. 遮住说话人名字，能猜出是谁说的吗？
3. 这段对话有没有至少一个动作锚点？
4. 角色有没有回避/转移/反答某个问题？
5. 只看行为描写，能猜出大概在说什么吗？

### 评分标准

| 分数 | 条件 |
|------|------|
| 9-10 | 六要素覆盖≥4项，声纹清晰可辨，有潜台词，干涩检测≥4项"是" |
| 7-8 | 六要素覆盖≥3项，基本有声纹区分，干涩检测≥3项"是" |
| 5-6 | 六要素覆盖≥2项，对话有基本动作锚点 |
| 3-4 | 六要素仅1项或缺失，对话干瘪像文字记录 |
| 1-2 | 纯对话无描写，无声纹，无冲突，无潜台词 |

## 二、爽点节奏（满分10分）

### 来源文件

- `knowledge_base/40_Writing/04_场景与描写/爽点设计.md`
- `knowledge_base/40_Writing/04_场景与描写/潜台词与张力技法.md`
- `knowledge_base/40_Writing/06_质量校验/套路预判+绕开机制.md`

### 检查清单

#### 爽点密度检查

| 规则 | 检查方法 | 达标标准 |
|------|---------|---------|
| 每章≥1小爽点 | 本章是否有打脸/吐槽/反杀/信息反转/暧昧升温 | 有明确的小爽点 |
| 爽:压=7:3 | 本章压抑段落和释放段落的字数比例 | 大致7:3，不能全压或全爽 |

#### 爽点强度检查（爽点设计.md 公式）

```
爽点强度 =（压抑值 × 悬念值）× 反转差值 ÷ 释放延迟
```

- **压抑值**：主角被压制程度（被羞辱/被误解/被剥夺）
- **悬念值**：信息不对称程度（隐藏底牌/世界观未揭示）
- **反转差值**：前后落差（身份反转/实力反转/认知反转）
- **释放延迟**：爽点拖多久才给（延迟出手/分段爆发）

检查本章是否走完了流水线：建立期待→加深压抑→制造误判→延迟释放→反转爆发→余波扩散

#### 潜台词检查

| 检查项 | 方法 | 达标标准 |
|--------|------|---------|
| 口是心非 | 角色嘴上说A实际做B | 至少1处 |
| 话里有话 | 表面说天气实际说关系 | 至少1处 |
| 五种潜台词 | 指桑骂槐/顾左右而言他/言行不一/信息差/反话正说 | 至少使用1种 |

#### 套路检测（套路预判+绕开机制.md）

检查本章是否踩了以下常见套路：

| 套路 | 典型表现 | 检查 |
|------|----------|------|
| TR-01 英雄救美 | 主角恰好出现救人 | 是否踩了？绕开了吗？ |
| TR-03 反派降智 | 反派突然变蠢 | 是否踩了？ |
| TR-05 绝地翻盘 | 最绝望时刻突然反转 | 翻盘是否有代价/留更大问题？ |
| TR-06 打脸爽点 | 看不起主角的人被打脸 | 打脸有代价或被看穿？ |
| TR-08 感情升温 | 互动后关系更近 | 更近同时有新距离感？ |
| TR-12 意外转折 | 一切顺利突然出事 | 转折有伏笔？ |

#### 原创性加分项（每章至少1项）

- 反预期细节（愤怒的人反而笑了一下）
- 视角偏移（关键场景从配角视角写一句）
- 信息差利用（让读者比角色知道得多或少一点）
- 留白（不说破某个情绪/事件）
- 日常穿插（紧张场景中插入完全日常的动作）

### 评分标准

| 分数 | 条件 |
|------|------|
| 9-10 | 有明确爽点+走完流水线+爽:压合理+无套路+有原创性加分 |
| 7-8 | 有爽点+基本走完流水线+爽:压大致合理 |
| 5-6 | 有爽点但弱/爽:压失衡/踩了套路但有绕开 |
| 3-4 | 爽点模糊/节奏偏平/踩套路无绕开 |
| 1-2 | 无爽点/全压抑无释放/纯套路堆砌 |

## 三、章节结构（满分10分）

### 来源文件

- `knowledge_base/40_Writing/02_节奏与结构/每章节奏公式与卡章技巧.md`
- `knowledge_base/40_Writing/02_节奏与结构/张力曲线设计.md`

### 检查清单

#### 节奏模板检查（3000字/章）

| 段落 | 字数 | 占比 | 检查 |
|------|------|------|------|
| 开头承接 | ~300字 | 10% | 前300字是否有冲突？（不能用环境/日常开场） |
| 发展推进 | ~1500字 | 50% | 是否推进了剧情？是否埋了伏笔？ |
| 章节高潮 | ~1000字 | 33% | 是否有本章节点/小爽点/反转？ |
| 结尾断章 | ~200字 | 7% | 是否卡在有效断章位置？ |

#### 断章有效性检查

**有效断章**（至少踩中1种）：
- 悬念最高处："门开了，里面竟然是——"
- 打脸前一刻："他冷笑一声，说出了那个名字..."
- 新冲突出现："就在这时，手机响了..."
- 情感高潮："她终于说出了那句..."
- 身份揭示前："他摘下面具，露出一张熟悉的脸..."

**无效断章**（绝对不能犯）：
- 日常描写后断章
- 大段设定后断章
- 平淡对话后断章
- 环境描写后断章
- 主角心理活动后断章（无新信息）

#### 卡章公式检查

```
冲突升级（本章）→ 高潮前一刻（断章）→ 下一章释放
```

本章是否走完了这个公式？

#### 张力曲线检查（张力曲线设计.md）

| 检查项 | 方法 | 达标标准 |
|--------|------|---------|
| 三层高潮 | 是否有表层冲突+中层矛盾+底层暗流 | 高潮场景至少2层 |
| 张力技法 | 是否使用了倒计时/信息差/小失误/打断/沉默/转移/不可逆选择 | 至少1种 |
| 高潮代价 | 高潮中是否有人付出代价或冒风险 | 必须有 |
| 高潮余波 | 高潮后是否有余震段落（≥100字） | 必须有 |
| 禁止写法 | 是否用了形容词堆叠/所有角色做正确的事 | 不得踩禁 |

#### 节奏禁忌检查

| 禁忌 | 检查 |
|------|------|
| 连续3章无爽点 | 结合前几章判断 |
| 连续5章纯对话 | 本章是否有纯对话>5轮？ |
| 大段设定说明 | 是否有超过200字的纯设定段落？ |
| 高潮后无余韵 | 高潮后是否有缓冲段落？ |

### 评分标准

| 分数 | 条件 |
|------|------|
| 9-10 | 开头有冲突+节奏模板基本符合+断章有效+卡章公式完整+张力3层+有余波 |
| 7-8 | 开头有冲突+断章有效+基本有高潮+有余波 |
| 5-6 | 开头无明显冲突但有信息引入+断章基本可接受 |
| 3-4 | 断章无效/无高潮/节奏偏平 |
| 1-2 | 日常开场+平淡断章+无冲突+无高潮 |

## 四、去AI化（满分10分）

### 来源文件

- `knowledge_base/40_Writing/05_降AI痕迹/降低AI痕迹.md`
- `knowledge_base/50_Quality/红线检查/红线系统.md`

### 检查清单

#### AI味三层识别（降低AI痕迹.md）

**表层特征**（快速扫描）：

| 特征 | 检查 |
|------|------|
| 连接词过多 | "首先/其次/因此/然后/此外/然而/综上" |
| 情绪直说 | "紧张/愤怒/感动/震惊/愤怒/委屈" |
| 对话完整 | 问→答→回应，全闭环无打断 |
| 修辞工整 | 排比、对仗、句式整齐 |
| 描写过全 | 像在"说明"而不是"展示" |

**结构层特征**（段落扫描）：

| 特征 | 检查 |
|------|------|
| 段落长度平均 | 段落长度是否有变化（长→短→极短→停） |
| 句式重复 | 是否全是主谓宾句式 |
| 节奏恒定 | 有无快慢变化（动作用短句、情绪用长句） |
| 信息均匀分布 | 信息密度是否有高低起伏 |

**认知层特征**（行为检查）：

| 特征 | 检查 |
|------|------|
| 人物不犯错 | 角色是否有误判/犹豫/冲动 |
| 推理无偏差 | 思维过程是否过于合理 |
| 情节过于合理 | 是否有巧合/意外/非理性选择 |
| 没有误解/犹豫/停顿 | 角色是否总是正确行动 |

#### "每段三刀"法则检查（降低AI痕迹.md）

每段必须完成：
1. **删**一句解释 → 检查是否有可删除的因果句/总结句/解释句
2. **加**一个动作 → 检查是否有"无效但真实"的细节
3. **断**一个句子 → 检查是否有非完整表达/半句断开

#### 八大核心技法检查

| 技法 | 检查 |
|------|------|
| 结构破坏 | 长→短→极短→停，打碎整齐感 |
| 断句控制 | 单句成段/半句断开/非完整表达 |
| 行为替代情绪 | "他很愤怒"→"他把杯子放重了一点" |
| 对话降级 | 不完整/不礼貌/不解释 |
| 信息删减 | 能删的解释句全删 |
| 无效细节 | 插入"没用但真实"的细节 |
| 认知偏差 | 人物看错/误判/犹豫 |
| 风格扰动 | 同一段内允许口语+文学混用 |

#### AI词检查

参考 `scripts/post_write_audit.py` 的自动检测结果。审稿时重点检查脚本覆盖不了的：
- 通用动作（笑了笑/皱了皱眉/叹了口气）是否被替换为角色行为指纹
- 计时器心理（"想了一秒/沉默了十秒"）是否有遗漏
- 是否有超过3次的重复场景描写

#### 红线检查（红线系统.md）

| 级别 | 检查项 | 后果 |
|------|--------|------|
| 一级 | 原创性/人称一致性/性别姓名 | 一票否决 |
| 二级 | 风格漂移/OOC/剧情矛盾/伏笔丢失 | 必须修复 |
| 三级 | 字数/结构/悬念密度 | 优化建议 |

### 评分标准

| 分数 | 条件 |
|------|------|
| 9-10 | 无表层AI特征+结构有变化+人物有偏差+"每段三刀"达标+无红线违规 |
| 7-8 | 偶有AI词但不影响阅读+结构基本有变化+无红线违规 |
| 5-6 | 有明显AI词但可接受+结构略平+无一级红线 |
| 3-4 | AI词较多+结构平+有二级红线问题 |
| 1-2 | 严重AI味+踩一级红线 |
