# 创意文档

## 基本信息

- **作品名称**：我发疯后全世界都正常了
- **类型定位**：都市 / 反内卷 / 喜剧 / 治愈 / 轻奇幻
- **目标平台**：番茄小说（新品类）
- **题材标签**：发疯文学 + 反内卷 + 喜剧 + 治愈 + 轻奇幻
- **预计篇幅**：120-150万字（约600章，2000字/章）

## 核心创意

- **一句话概括**：女主确诊"情绪过敏症"——对一切不合理的事过敏，必须发出来才能好。她开始"合法发疯"，一发疯，周围扭曲的关系反而恢复正常了。她不是疯子，她是社会的过敏原检测仪。

## 核心钩子

- **反差感**：发疯 = 治愈。别人发疯是破坏，她发疯是修复。"疯子治好了正常人"——强烈的反常识设定。
- **悬念**：情绪过敏症是什么病？谁给她诊断的？治好了会怎样？
- **代入感**：职场PUA、道德绑架、催婚相亲、家庭吸血——每个场景读者都在经历。
- **情绪钩子**：读者会有"她替我做了我不敢做的事"的爽感 + "原来不是我有问题"的治愈感。

## 主角设定

- **姓名**：许知意（暂定）
- **年龄**：26岁
- **身份**：一线城市新媒体公司运营
- **性格**：平时温和随和、社恐型、习惯性忍让；确诊后被迫发疯，发疯时极度犀利、逻辑碾压、幽默感极强（反差萌）
- **目标**：短期：活下去（不发疯会过敏加重）→ 中期：帮身边人摆脱扭曲关系 → 长期：弄清楚自己到底是什么
- **缺陷**：前期不懂拒绝、讨好型人格、对冲突极度恐惧

## 卖点分析

- **目标读者**：25-40岁职场人群，被内卷和扭曲关系困扰的人
- **核心卖点**：情绪代偿爽感。读者追更的理由是"看她替我怼那些不敢怼的人"
- **对标作品**：发疯文学在抖音/小红书已有传播基础，网文赛道相对空白
- **差异点**：不是纯爽文，有治愈内核；有轻奇幻悬念线；不是无差别发疯而是"精准打击"

## 爽点设计

- **核心爽点类型**：打脸（反怼道德绑架者）+ 治愈（关系恢复正常）+ 搞笑（发疯方式创意十足）
- **持续性**：每个社会痛点 = 一个爽点单元。职场线 → 家庭线 → 朋友线 → 社会线 → 终极真相线
- **变化空间**：发疯方式从被动→主动→战略→传染，有明确升级路径

## 风险提示

- ⚠ "发疯"模式如果每次都一样会疲劳——需要设计发疯方式的创意升级和剧情深度的递进
- ⚠ 轻奇幻线（过敏症来源）需要前期铺垫，后期揭晓不能像机械降神
- ⚠ 番茄平台要求快节奏——治愈内核必须用爽的外壳包裹，不能慢热
- ⚠ 女主不能变成无差别攻击的泼妇，每次发疯必须有理有据

## 编辑评估结果

- **判断**：能火
- **关键建议**：
  1. 前三章必须出现第一次发疯和爽点（番茄适配）
  2. 设计发疯递进机制，避免模式重复疲劳
  3. 前期埋伏笔、设计配角被传染情节、给女主加反差萌特征
