# 卷一：废婿觉醒 — 逐章细纲

> Ch1-Ch60 | ~18万字 | 每章~3000字
> 核心情绪线：压抑(Ch1-2) → 觉醒(Ch2-3) → 爽快(Ch4-5) → 成长(Ch6-35) → 紧张(Ch36-60)

## 第一幕：觉醒与自证（Ch1-Ch12）

### Ch1：赘婿的命

| 字段 | 内容 |
|------|------|
| **核心事件** | 林辰被大舅哥苏大强推下楼梯，撞到头，觉醒估值之眼 |
| **情绪** | 压抑→震惊 |
| **钩子类型** | 悬念型（金光入眼，看到破碗上标价"¥1,200,000"） |
| **对话占比** | ≥35% |

**场景规划**：

1. **开场**（对话驱动）：岳母王丽华在餐桌前骂林辰——"这碗粥是你熬的还是倒的？三年了，连个粥都熬不好。" 林辰沉默喝粥。苏大强靠在门框上看笑话。
2. **楼梯冲突**（对话+动作）：苏大强故意撞林辰——"让让，废物。" 林辰侧身让路，苏大强反手一推。林辰滚下楼梯，头撞到墙角。
3. **觉醒**（内心+视觉）：金光闪过。睁开眼，视线里所有物品上方都悬浮着金色数字。桌上的破碗——"¥1,200,000"。椅子——"¥380"。手机——"¥2,400"。
4. **悬念收尾**：林辰盯着那个破碗。这是他三年来每天用来盛粥的碗。120万？不可能。

**要点**：
- 前500字必须有冲突（岳母骂+大舅哥推）
- 觉醒场景要短促有力，不超过300字
- 章末钩子要强——"万物皆有价"

### Ch2：这碗值一百万

| 字段 | 内容 |
|------|------|
| **核心事件** | 林辰偷偷拿碗去鉴定，确认是明清官窑真品 |
| **情绪** | 紧张→兴奋 |
| **钩子类型** | 预告型（鉴定师说："你还有别的东西要鉴定吗？"） |
| **对话占比** | ≥35% |

**场景规划**：

1. **偷碗出门**（对话+紧张）：林辰趁岳母出门买菜，用报纸包好碗塞进背包。出门时苏大强问："你干嘛去？""买菜。""你有钱买菜？"林辰没理他。
2. **鉴定中心**（对话驱动核心场景）：林辰走进鉴定中心，前台要200鉴定费。他只有15块。僵持中，张主任路过——注意到碗的包浆——主动要求看看——"这碗……你从哪弄来的？" 鉴定过程：张主任用放大镜看底款、胎质、釉面，边看边讲解（自然融入鉴宝术语）。
3. **确认真品**（爽点）：张主任宣布"明宣德青花缠枝莲纹碗，市场价80-120万。" 林辰表面平静，内心翻涌。
4. **钩子收尾**：张主任递名片——"你要是想出手，我可以帮你联系买家。不过……" 他看着林辰，"你的眼睛，很特别。"

**要点**：
- 鉴定过程必须用对话呈现（张主任讲解，林辰提问）
- 张主任"眼睛很特别"是伏笔（F03）
- 章末钩子不要用写景收尾

### Ch3：到账一百万

| 字段 | 内容 |
|------|------|
| **核心事件** | 碗卖出100万，林辰拿到第一桶金 |
| **情绪** | 兴奋→平静→爽快 |
| **钩子类型** | 悬念型（陌生电话："林先生，古玩城有个东西，你应该来看看。"） |
| **对话占比** | ≥30% |

**场景规划**：

1. **交易过程**（对话驱动）：张主任介绍买家——一个戴金表的中年人。两人讨价还价。中年人："80万。" 林辰："120万。" 中年人："你一个赘婿，懂什么古董？" 林辰平静地说："明宣德青花，存世不到20件。80万，你转手就能赚50万。" 中年人愣了一下，最终100万成交。
2. **到账**（爽点）：手机震动——银行短信：到账1,000,000.00元。林辰看着屏幕上的数字，手指微微发抖。三年了。他终于有钱了。
3. **小爽延续**：林辰走进一家鞋店。导购迎上来——"先生随便看看。"语气礼貌，眼神在说"你买不起"。林辰："那双，42码。" 导购愣了。试完鞋，林辰刷卡——穿着新鞋走出店门。
4. **钩子收尾**：手机响了。陌生号码。"林先生，古玩城有件东西，你应该来看看。你父亲以前……" 信号断了。

**要点**：
- 交易过程要有来有回的对话博弈
- "你父亲以前"是重要钩子——父亲线索启动
- 买鞋场景不超过200字，不要膨胀

### Ch4：岳母变脸

| 字段 | 内容 |
|------|------|
| **核心事件** | 林辰回家亮出余额，岳母态度180度转变 |
| **情绪** | 爽快→痛快 |
| **钩子类型** | 危机型（苏大强躲在角落打电话："他好像有钱了……"） |
| **对话占比** | ≥35% |

**场景规划**：

1. **回家**（对话驱动）：岳母正在厨房骂骂咧咧——"那个废物又跑出去了，饭也不做……" 林辰推门进来。岳母转身就要骂。
2. **亮余额**（打脸爽点）：林辰把手机屏幕转向岳母——"妈，我想给家里买点东西。" 岳母瞟了一眼屏幕，骂声卡在喉咙里。1,000,000.00。她的眼睛瞪大了。"你……你哪来的钱？""运气好，捡了个漏。" 林辰语气平静。
3. **岳母变脸**（对话+爽感）：岳母态度瞬间反转——"哎呀小辰啊，你看你也不早说，饿了吧？妈给你热饭……" 苏大强从客厅探头："什么情况？" 岳母瞪他一眼："你管什么情况！你妹妹嫁了个好老公！"
4. **钩子收尾**：苏大强脸色铁青，悄悄溜到阳台打电话。林辰的余光瞥见了。他没动声色。晚上，苏大强的房门关着，隐约传出声音："他好像有钱了……"

**要点**：
- 岳母变脸要夸张，反差越大越爽
- 苏大强打电话是伏笔（他背后有人）
- 对话要写出岳母的势利嘴脸

### Ch5：家族聚会（上）

| 字段 | 内容 |
|------|------|
| **核心事件** | 苏家家族聚会，亲戚们嘲讽林辰，林辰淡定应对 |
| **情绪** | 压抑→期待 |
| **钩子类型** | 预告型（"明天，你把那幅画带来鉴定。"） |
| **对话占比** | ≥35% |

**场景规划**：

1. **入场**（对话驱动）：苏家老宅。亲戚们围坐一圈。二婶："哟，这不是咱们苏家的上门女婿吗？"三叔："听说最近在外面跑？找到工作了？" 林辰微笑不语。
2. **苏大强发难**：苏大强当众说："我听说你在外面搞什么古董？那玩意儿可不是谁都能玩的。" 亲戚们哄笑。"要不这样，明天聚会上，你带件东西来，让大伙儿开开眼？"
3. **苏清雪出场**（感情线）：苏清雪从楼上下来。全场安静了一瞬。她看了林辰一眼——不是冷漠，是探究。"你确定？"她问苏大强。"确定啊，让他证明一下自己嘛。" 苏清雪没说话，转身走了。上楼前，她低声对林辰说了两个字："别去。"
4. **钩子收尾**：林辰看着苏清雪的背影。三年了，她第一次主动跟他说话。虽然只有两个字。他笑了笑。"明天见。"他对苏大强说。

**要点**：
- 苏清雪"别去"是关键——暗示她知道什么
- 亲戚群像要鲜明但不重复（二婶势利、三叔看热闹、四姑装好人）
- 章末钩子要有期待感

### Ch6：家族聚会（下）

| 字段 | 内容 |
|------|------|
| **核心事件** | 林辰带"破画"到场，鉴定后价值50万，全场打脸 |
| **情绪** | 期待→痛快→震撼 |
| **钩子类型** | 反转型（苏清雪发来短信："你从哪弄到那幅画的？"） |
| **对话占比** | ≥35% |

**场景规划**：

1. **嘲讽升级**：林辰带着一幅"破画"到场。画框歪了，画布发黄。亲戚们笑疯了——"这是从垃圾堆捡的吧？""100块都不值！" 苏大强得意洋洋。
2. **鉴定打脸**（对话驱动）：林辰请来的鉴定师（张主任介绍的朋友）仔细看画——"清末海派画家吴昌硕的早期作品。市场价……40-60万。" 全场死寂。苏大强的脸僵了。
3. **亲戚变脸**：二婶第一个反应过来——"哎呀我就说小辰有眼光！"三叔："这孩子深藏不露啊！" 岳母笑得合不拢嘴。
4. **苏清雪的反应**：苏清雪站在二楼栏杆旁，看着楼下的闹剧。她的嘴角微微上扬。手机屏幕亮了——她给林辰发了一条短信："你从哪弄到那幅画的？"
5. **钩子收尾**：林辰看到短信，没回。他抬头看向二楼。苏清雪转身进了房间。门关了。但她笑了。三年来第一次。

**要点**：
- 打脸要狠，但林辰保持风度（不嘚瑟）
- 苏清雪的笑容是感情线重要节点
- 画的来历不需要本章解释（留悬念）

### Ch7：老杨

| 字段 | 内容 |
|------|------|
| **核心事件** | 林辰在古玩市场遇到老杨（隐退鉴宝大师），开始学习鉴宝 |
| **情绪** | 好奇→敬畏 |
| **钩子类型** | 悬念型（老杨看着林辰的眼睛："你这双眼睛……从什么时候开始的？"） |
| **对话占比** | ≥35% |

**场景规划**：

1. **古玩市场初探**：林辰第一次逛古玩市场。五十米视野内，满眼的金色数字。地摊上的铜炉——¥800。旁边的玉佩——¥200,000。他看到了一个标价¥500的鼻烟壶，头顶的数字是¥80,000。
2. **遇到老杨**（对话驱动）：林辰正要买鼻烟壶，一只手按住了他的手腕。"小伙子，这东西你看走眼了。"一个头发花白的老头。"这不是清中期的，是民国仿品。包浆是做旧的。" 林辰用估值之眼看了看——数字确实是¥80,000。但老杨说得有理有据。
3. **鉴宝教学**（对话核心）：老杨蹲在地摊旁，给林辰讲了十分钟——怎么看包浆、怎么辨别底款、怎么看胎质。"鉴宝这行，凭的是眼力，不是运气。" 林辰听着，心里起了波澜。
4. **钩子收尾**：老杨站起来要走。林辰问："您怎么称呼？" 老杨头也不回："姓杨。这市场里的人都叫我老杨。"他走了两步，突然回头——盯着林辰的眼睛看了三秒。"你这双眼睛……从什么时候开始的？" 林辰后背一凉。

**要点**：
- 老杨的教学要融入真实鉴宝知识，但不枯燥
- 老杨看穿林辰的眼睛是大伏笔
- 这章建立师徒关系的开端

### Ch8：第一次主动捡漏

| 字段 | 内容 |
|------|------|
| **核心事件** | 林辰用估值之眼+老杨教的知识，成功捡漏一个铜香炉 |
| **情绪** | 紧张→爽快 |
| **钩子类型** | 预告型（赵磊："辰哥，明天有个更大的摊……"） |
| **对话占比** | ≥35% |

**场景规划**：

1. **选目标**（对话+策略）：林辰在市场里转了一圈。用估值之眼扫描。大部分东西价格和标价差不多——没什么捡漏空间。但他注意到一个角落里的铜香炉。摊主标价2000。头顶数字：¥85,000。
2. **砍价博弈**（对话核心）：林辰蹲下来假装随意看——"这香炉什么来路？" 摊主："祖传的，清中期。" 林辰用老杨教的方法检查——包浆自然，底款清晰，但有一处小瑕疵。他指着瑕疵砍价——"这里有个磕口，2000太贵了。" 最终800成交。
3. **转手获利**（爽点）：林辰把香炉带到张主任那里。确认是清中期铜器，市场价6-8万。当天就有买家出7万。林辰口袋里又多了7万。
4. **赵磊出场**：一个瘦高个凑过来——"兄弟，你刚才是不是捡了个漏？我看你从那摊上拿了个香炉……" 他自我介绍：赵磊，跑腿的，对古玩市场门清。"辰哥，你要是想捡大漏，明天跟我走。有个摊主进了批新货，里面有好东西。"
5. **钩子收尾**：林辰看着赵磊。这个人眼神里有种热切。"什么好东西？" 赵磊压低声音："我听说……是一批从老宅子里挖出来的。"

**要点**：
- 砍价过程要对话化，有来回博弈
- 赵磊出场自然，不做作
- "老宅子里挖出来的"制造悬念

### Ch9：LV2升级

| 字段 | 内容 |
|------|------|
| **核心事件** | 成功鉴定物品累计达50件，估值之眼升级LV2（视野扩大到50米） |
| **情绪** | 兴奋→震撼→警觉 |
| **钩子类型** | 危机型（升级瞬间眼睛剧痛，差点在街上晕倒） |
| **对话占比** | ≥30% |

**场景规划**：

1. **跟着赵磊去新摊**（对话驱动）：赵磊带林辰来到市场深处一个不起眼的摊位。摊主是个秃头中年人，面前摆着一堆"新货"。
2. **扫货**（爽点）：林辰用估值之眼扫了一遍——三个铜钱（¥15,000，标价100）、一个砚台（¥45,000，标价500）、一对玉镯（¥120,000，标价2000）。他不动声色地全部买下。
3. **升级**（高潮）：当累计收益数字跳过100,000的瞬间——金光暴涨。林辰的眼前一阵刺痛。视野范围从5米猛地扩展到50米。整个市场的物品价格一览无余。头晕目眩。
4. **副作用**：林辰扶着墙站住。赵磊："辰哥你怎么了？" "没事……有点晕。" 他的眼睛在灼烧。但他看到了——50米外一个摊位上，有一个标价¥300,000的碗，头顶数字却是¥0。
5. **钩子收尾**：¥0？什么意思？林辰揉了揉眼睛。数字还在。碗看起来很普通——粗瓷大碗，釉色暗淡。但估值之眼说它一文不值，摊主却标了30万。这不是捡漏——这是个陷阱。有人在用假货骗人。

**要点**：
- 升级要伴随副作用（限制设定的落地）
- ¥0的碗是鉴宝知识的运用（假货识别）
- 不是所有高标价都是好东西——反转预期

### Ch10：赝品陷阱

| 字段 | 内容 |
|------|------|
| **核心事件** | 林辰识破赝品骗局，反过来教训骗子 |
| **情绪** | 警觉→机智→爽快 |
| **钩子类型** | 悬念型（骗子背后的人——"赵家的人"首次出现） |
| **对话占比** | ≥35% |

**场景规划**：

1. **观察**（对话+分析）：林辰靠近那个标价30万的碗。摊主立刻热情推销——"这可是宋汝窑的！你看这天青色……" 林辰假装看碗，实际在观察摊主。估值之眼确认：¥0。假货。
2. **智取**（对话核心）：林辰没有直接揭穿。他问了几个专业问题——"汝窑的开片怎么形成的？""这个底款是哪个窑口的？" 摊主答不上来，支支吾吾。旁边有其他买家在听。有人开始怀疑。
3. **揭穿**：林辰拿出手机，搜了一张真汝窑的照片——"真正的汝窑，开片是这样的。你这个……是喷釉做旧的。" 摊主脸色变了。其他买家纷纷散开。
4. **钩子收尾**：摊主恶狠狠地瞪着林辰——"你等着。" 林辰转身要走，赵磊拉住他——"辰哥，这人我认识。他背后是赵家的人。" "赵家？" "赵天霸。北京那个。古玩四大家族之一。"

**要点**：
- 识破赝品要用知识+估值之眼结合（不是光靠金手指）
- "赵家"首次提及，埋下中期反派
- 骗子的威胁是后续冲突的伏笔

### Ch11：苏清雪的试探

| 字段 | 内容 |
|------|------|
| **核心事件** | 苏清雪第一次主动找林辰谈话，试探他的变化 |
| **情绪** | 紧张→微妙→期待 |
| **钩子类型** | 反转型（苏清雪递给他一张名片——"这是我的号码。有事打给我。"） |
| **对话占比** | ≥40% |

**场景规划**：

1. **偶遇**（对话驱动）：晚上，林辰在阳台抽烟。苏清雪从客厅走来。两人第一次独处。沉默了十秒。苏清雪先开口——"你最近变了。" 林辰："哪变了？" 苏清雪："说不上来。眼神不一样了。"
2. **试探**（对话核心）：苏清雪问了几个问题——"你哪来的钱？""你在外面做什么？""那个碗……是真的？" 林辰一一回答，不卑不亢。苏清雪看着他，像是在评估一份商业计划书。
