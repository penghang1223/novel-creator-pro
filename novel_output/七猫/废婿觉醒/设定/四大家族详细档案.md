# 鉴宝四大家族 详细档案

## 总览

四大家族掌控全国古玩、玉石、字画、杂项市场，各有所长，互相制衡。表面是商业竞争，暗地里与"暗网鉴宝圈"（沈万山）有不同程度的勾连。

---

## 赵家（古玩/瓷器）

| 字段 | 内容 |
|------|------|
| 家主 | 赵天霸 |
| 年龄 | 55岁 |
| 根据地 | 北京琉璃厂 |
| 年营收 | 约3亿 |
| 家族历史 | 清末民初起家，祖上是宫廷御窑的管事太监 |

### 核心成员
- **赵天霸**：家主。霸道、阴险、不择手段。靠低价收购赝品、高价卖真品的手段起家。外表粗犷，但内心极细。
- **赵文博**：赵天霸之子，30岁，留学回来，表面斯文，实际比父亲更阴。负责家族的"暗线"操作。
- **老鬼**：赵家的首席鉴定师，70岁，国家级鉴定师。赵天霸花钱"养"的，但老鬼有自己的原则——只鉴定真品，不参与造假。

### 弱点
- 赵天霸学历低，文化圈的人看不起他
- 赵文博有赌瘾（后来被林辰利用）
- 家族内部有分裂——老派重"真"，新派重"利"

### 与暗网关系
赵天霸不知道暗网的存在，但赵文博私下通过中间人与暗网有接触——他想用暗网的资金扩大家族势力，架空父亲。

### 下场
卷四被林辰击败。赵天霸破产前说："你以为你赢了？真正的玩家还没出场。"

## 钱家（玉石/翡翠）

| 字段 | 内容 |
|------|------|
| 家主 | 钱万通 |
| 年龄 | 62岁 |
| 根据地 | 云南瑞丽 / 缅甸 |
| 年营收 | 约5亿（四大家族最高） |
| 家族历史 | 祖上是马帮商人，从缅甸运玉石起家 |

### 核心成员
- **钱万通**：家主。精明、务实、重规矩。做生意讲究"一口价，不磨嘴"。对林辰的态度是"先观察，后出手"。
- **钱小满**：钱万通的女儿，28岁，在云南经营翡翠原石市场。性格泼辣，行事果断。
- **缅甸老刀**：钱家在缅甸的合作伙伴，控制一条翡翠原石走私线（灰色地带，非暗网）。

### 弱点
- 缅甸政局不稳，原石供应链随时可能断裂
- 钱小满与父亲有经营理念分歧——她想转型做线上直播卖玉
- 钱万通年纪大了，身体不好

### 与暗网关系
钱家与暗网没有直接关系，但"缅甸老刀"的走私线偶尔被暗网利用——钱万通不知情。

## 孙家（书画/字画）

| 字段 | 内容 |
|------|------|
| 家主 | 孙文博 |
| 年龄 | 58岁 |
| 根据地 | 上海 / 苏州 |
| 年营收 | 约2亿 |
| 家族历史 | 祖上是苏州画院的画师，后转为字画收藏和交易 |

### 核心成员
- **孙文博**：家主。儒雅、有学问、爱收藏。表面是文化人，实际手段不软。擅长用"人情"做生意——请客吃饭、送字画、办展览。
- **孙小雨**：孙文博的女儿，26岁，美院毕业，经营一家画廊。对林辰有好感（感情线支线）。
- **方老师**：孙文博请的仿画大师，能仿明清所有名家的画。孙文博用他仿的画做"人情"送给客户——不违法，因为仿画不入拍卖。

### 弱点
- 孙文博的文化圈人脉是双刃剑——文人最重面子，一旦被当众打脸，反噬极大
- 方老师有野心——他想用自己的仿画换真迹

### 与暗网关系
孙家与暗网没有关系，但方老师私下接暗网的"高仿"订单——孙文博不知情。

## 李家（杂项/奇珍）

| 字段 | 内容 |
|------|------|
| 家主 | 李藏锋 |
| 年龄 | 65岁 |
| 根据地 | 广州 / 香港 |
| 年营收 | 约3.5亿 |
| 家族历史 | 祖上是广州十三行的买办，后来转做杂项收藏 |

### 核心成员
- **李藏锋**：家主。老谋深算，表面和气，下手最狠。四大家族里唯一一个知道"暗网鉴宝圈"存在的人。
- **李少白**：李藏锋之子，32岁，在香港经营拍卖行。表面正经，实际是暗网在香港的"白手套"。
- **陈素秋**：李藏锋的妹妹，60岁，隐居东莞。她是陈素华（林远山师父）的后人，知道估值之眼的秘密。

### 弱点
- 李少白与暗网的勾连是定时炸弹
- 陈素秋知道太多——她知道李少白的暗网身份，也知道林远山是被害的
- 李家内部有分裂——李藏锋想洗白，李少白想深入暗网

### 与暗网关系
李家是唯一与暗网有直接联系的家族。李少白是暗网在香港的资金通道。但李藏锋本人反对——他怕引火烧身。


## 江州市势力分布

### 地理

```
江州市（架空城市，位于华东）
├── 东城区（老城区）
│   ├── 潘家园古玩市场
│   ├── 半日闲茶舍（张怀远常去的地方）
│   └── 文化产业园（林辰中标的地块）
├── 西城区（新城区）
│   ├── 苏氏集团总部
│   ├── 苏家别墅
│   └── 林辰住的"客房"
├── 南城区（商业区）
│   ├── 玉石交易中心
│   └── 江州文物鉴定中心（张怀远单位）
└── 北城区（工业区）
    ├── 废弃厂房
    └── 林家老宅（已废弃，林辰父母曾经的住所）
```

### 势力

| 势力 | 据点 | 代表人物 | 实力 |
|------|------|----------|------|
| 苏家 | 西城区 | 苏清雪（实权）/苏明远（名义） | 中 |
| 潘家园古玩圈 | 东城区 | 老杨（隐退）、赵磊（信息枢纽） | 弱（散兵游勇） |
| 四大家族驻江州办事处 | 南城区 | 各派一个代理人 | 强（背后是大家族） |
