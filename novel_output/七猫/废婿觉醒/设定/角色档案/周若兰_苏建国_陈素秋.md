# 周若兰

## 基本信息

| 字段 | 内容 |
|------|------|
| 姓名 | 周若兰 |
| 性别 | 女 |
| 年龄 | 死时40岁（2008年车祸） |
| 身份 | 林远山之妻，林辰之母，中学语文教师 |

## 外貌

中等身高，偏瘦，留着齐肩短发。不化妆，皮肤偏黄——长期操劳的结果。笑的时候眼角有细纹，眼睛很亮，像林辰。常穿素色衣服——白衬衫、灰色裤子、平底鞋。

## 性格

温和但有韧性。她不是那种强势的女人——但也不软弱。林远山常年在外跑古玩，家里的事情几乎都是她一个人扛。她不抱怨，但会在夜里偷偷哭——林辰小时候听到过。

## 背景

师范毕业后分配到江州市第三中学教语文。1988年经人介绍认识林远山。她对古玩一窍不通，但欣赏林远山"对一件东西的认真"。

1989年结婚，1990年生下林辰。

林辰18岁时，她送他去大学报到。在火车站，她抱了林辰一下——那是她最后一次抱他。

## 与林辰的关系

林辰与母亲的关系比与父亲更亲密。林远山常年在外，周若兰是林辰童年和少年时期最重要的人。

她教林辰认字、背诗、写作文。林辰的文学天赋来自母亲——周若兰年轻时也想当作家，写了十几篇短篇小说，投了无数次稿，只发表过一篇。

林辰入赘苏家时，周若兰已经去世两年。她没有看到儿子受辱的那一天。

## 死亡

2008年与林远山同车，刹车失灵坠崖。

**车祸前最后通电话**：打给林辰（当时在大学）。"小辰，妈和你爸这几天有事，不在家。你照顾好自己。"

这是林辰听到的母亲最后一句话。

# 苏建国

## 基本信息

| 字段 | 内容 |
|------|------|
| 姓名 | 苏建国 |
| 性别 | 男 |
| 年龄 | 1938-2015（享年77岁） |
| 身份 | 苏家老爷子，江州早期地产商人 |

## 外貌

矮胖，秃顶，两鬓白发。常穿中山装或老式西装。说话声音洪亮，笑起来露出金牙。

## 性格

精明、强势、说一不二。白手起家，从倒卖土地到文化投资，什么赚钱做什么。但他有一个底线：不碰违法的东西。这也是他后来与沈万山保持距离的原因。

## 背景

1958年，20岁的苏建国从农村来到江州，在建筑工地做小工。1980年代改革开放，他第一个倒卖土地——当时还没有"土地使用权"的概念，他钻了政策的空子，赚了第一桶金。

1990年代，他成立了苏氏集团，涉足地产、文化投资、艺术品交易。

## 与林远山的恩怨

1998年，苏建国找到林远山，想借他的眼力收一批"老货"。林远山鉴定后发现全是赝品，拒绝出具鉴定书。

苏建国转而找到沈万山——沈万山出具了"真品"鉴定书，苏建国大赚一笔。但苏建国事后知道那批货是假的——沈万山利用了他。

从此苏建国恨沈万山，也恨林远山——他认为林远山"明明看出来却不早说"。

## 债务局

2003年，苏建国设了一个局：

1. 他以"文化交流"为名，邀请林远山参与一次大型文物征集活动
2. 活动需要"资金"，苏建国借给林远山300万
3. 借款协议中嵌入了高额利息和违约金条款——林远山没仔细看就签了
4. 活动"失败"，林远山需要还300万+利息=450万
5. 林远山还不起，苏建国提出"以子入赘抵债"

苏建国为什么这么做：
1. 他知道林远山有"特殊能力"（虽然不知道具体是什么）
2. 他想把林远山的后代留在身边，监视能力的传承
3. 沈万山暗示过林远山这一脉"不一般"，苏建国想利用这个"不一般"

但苏建国没有料到：
1. 林远山2008年就死了
2. 林辰等了十几年才觉醒能力
3. 苏清雪对林辰的态度不是冷漠而是被迫——这为后来的反转埋下伏笔

## 临终遗言

2015年，苏建国病危。临终前叫来苏清雪（当时16岁）：

"你嫁给林辰。这是你爷爷——不，这是我欠林家的。债务一笔勾销。"

苏清雪答应了。不是因为孝顺，是因为她从小就知道：这个家是她说了算的——但前提是听爷爷的话。

## 与蛇绕古币标志的关系

苏建国不认识这个标志。他只知道沈万山在用。他害怕沈万山，所以与沈万山保持距离——但"债务局"是他自己做的决定，与沈万山无关。

## 外貌

清瘦，白发，穿素色唐装。常年吃素，面色苍白但精神很好。手上戴一串菩提子手串——陈素华传下来的。

## 背景

陈素秋是陈素华弟弟的孙女。陈素华晚年隐居云南时，陈素秋曾去探望过，听过陈素华讲聚古斋的故事。她知道估值之眼的存在，也知道沈万山被逐出师门的事。

成年后嫁给李家的旁支，后来离婚。李藏锋是她的亲哥哥。她知道李少白在做暗网的事——但一直不敢说。

## 她知道什么

1. 林远山是被害的（不是车祸）
2. 沈万山是凶手
3. 林辰可能也觉醒了能力
4. 李少白是暗网在香港的资金通道
5. 聚古斋印章的另一半在文化产业园地下室

## 为什么不说

- 她怕沈万山——沈万山害死过林远山，不介意再杀一个老太太
- 她怕连累哥哥一家——李藏锋虽然反对暗网，但如果公开揭发，李家也会被牵连
- 她在等"对的人"——陈素华说过，如果有一天聚古斋的传人出现了，她会出手

## 与林辰的交集

Ch50+：林辰通过老杨找到陈素秋。陈素秋看到林辰的第一眼就确认了他的身份——"你眼睛的颜色，跟你爸一样。"

她交给林辰三样东西：
1. 陈素华留下的一封信
2. 一份沈万山暗网的交易记录复印件
3. 菩提子手串（陈素华遗物）
