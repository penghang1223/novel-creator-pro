# 张怀远

## 基本信息

| 字段 | 内容 |
|------|------|
| 姓名 | 张怀远 |
| 性别 | 男 |
| 年龄 | 45岁 |
| 身份 | 江州市文物鉴定中心主任 |
| 职称 | 国家二级鉴定师 |

## 外貌

中等身材，微胖，戴一副金丝眼镜。头发梳得整齐，但发际线已经退到头顶。穿深色夹克或西装，不打领带。手指短粗，不像鉴宝师的手。

## 性格

圆滑但不势利，懂得在体制内生存，也有自己的底线。他不是坏人，但也不是圣人——他会帮有潜力的人，因为他知道"投资"比"施舍"更值。

**矛盾性**：体制内混了二十年，说话永远留三分余地。但遇到真东西的时候，他会忘乎所以——这是鉴宝师的本能压过了官场习惯。

## 背景

1998年从省文物鉴定学校毕业，分配到江州市文物鉴定中心。从科员干到主任，花了二十年。能力不差但不出彩——他不是那种一眼能定真假的顶级鉴定师，但胜在经验丰富，什么类型的东西都见过。

最大的遗憾：他一辈子没有"捡过漏"——从来没有以低价买到真货。这是他心里的一根刺。

## 认识林辰

Ch2：林辰拿着破碗来鉴定中心，张怀远第一眼看到碗的时候手就开始发抖。不是因为他多厉害——而是那个碗太好了，好到让他作为一个干了二十年的鉴定师都激动。

他注意到林辰不是普通的"捡漏者"——一个二十出头、穿着五十块钱衣服的赘婿，怎么能在潘家园的地摊上发现百万级的官窑？

但他没有追问——干这行二十年，他知道有些问题不该问。

## 与林辰的关系

张怀远是最早发现林辰"不一般"的人之一。他不像老杨那样直接点破，而是通过"投资"的方式——帮林辰介绍人脉、提供鉴定背书、在体制内为他铺路。

他的动机不是纯粹的善意：
1. 他相信林辰身上有故事，他想看到结局
2. 他想通过林辰弥补自己"没捡过漏"的遗憾——林辰就是他职业生涯里最大的"漏"
3. 他有一种直觉：林辰未来会成大器，现在帮一把，以后有回报

## 个人生活

妻子在省城当中学老师，两地分居。有一个女儿，15岁，在省城读高中。张怀远每个月回去两次。

他最大的爱好是周末去潘家园逛——不买东西，就是看。看货，也看人。

## 与老杨的关系

张怀远知道老杨的身份——二十年前鉴宝圈最厉害的人之一。但他不知道老杨为什么退圈。他尊重老杨，从不在老杨面前提"当年"两个字。

老杨和张怀远之间有默契：张怀远帮林辰铺体制内的路，老杨教林辰鉴宝的真本事。
