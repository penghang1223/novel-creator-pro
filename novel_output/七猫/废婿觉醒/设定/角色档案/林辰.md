# 林辰 — 13维角色卡

## 一、基础信息

| 字段 | 内容 |
|------|------|
| 姓名 | 林辰 |
| 年龄 | 26岁 |
| 性别 | 男 |
| 身份 | 苏家赘婿→独立鉴宝师→鉴宝圈传奇 |
| 外貌 | 五官普通但耐看，觉醒后眼神锐利；身材偏瘦，穿着从廉价地摊货到定制西装的变化 |
| 背景 | 父亲林远山是20年前江州最有天赋的鉴宝师，"意外"车祸身亡。林辰6岁成为孤儿，靠亲戚接济长大。大学毕业后因父亲遗留的债务入赘苏家，三年受尽屈辱 |

## 二、核心性格

**核心特质**：隐忍、观察力强、骨子里倔、学东西快、有底线

**矛盾特质**：
- trait1：表面沉默寡言（三年赘婿磨出来的生存本能）
- trait2：内心毒舌犀利（脑子里的吐槽从未停止）
- context：被嘲讽时嘴上不说，心里已经在回怼了
- resolution：觉醒后逐渐敢把心里话说出来，但只对敌人毒舌，对亲近的人依然温和

**成长方向**：从"被踩在泥里不敢出声"到"有底气选择什么时候说话什么时候闭嘴"

## 三、说话风格

**口头禅**：
- "是吗。"（平淡回应嘲讽，不接茬）
- "那可不一定。"（有底气时的反击信号）
- "值不值，看看就知道了。"（鉴宝时的习惯语）

**用词偏好**：
- 正式程度：casual（前期不讲究措辞）
- 词汇风格：通俗（不用专业术语装逼，除非鉴宝场景）
- 偏好词：值、不值、还行、差远了
- 禁用词：不会说"我觉得""可能""大概"——不确定的事不表态

**句式特点**：
- 短句为主，很少说超过两句的话
- 被嘲讽时经常只回一个字："哦""嗯""好"
- 鉴宝时例外——会详细解释判断依据（专业场景激活表达欲）

**情绪表达**：
- 风格：极度内敛，面部表情控制力强
- 压力下：更加沉默，手指无意识搓捻
- 开心时：不笑，但嘴角会微微上翘（他自己不知道）
- 愤怒时：眼睛眯一下，语气反而变平静（暴风雨前的平静）

## 四、行为模式

**决策风格**：
- 风格：谨慎
- 依据：估值之眼的数据 + 自己的观察
- 示例：看到一个碗值120万，不会马上去买——先确认估值之眼有没有被情绪干扰，再观察碗的细节

**压力反应**：
- 典型反应：沉默+观察，不急着做决定
- 肢体语言：拇指搓食指（紧张时的无意识动作）、抿嘴、视线低垂
- 应对机制：假装不在意（保护色），实际在飞速思考

**人际交往**：
- 可接近程度：低（三年赘婿让他不相信任何人）
- 信任程度：低，但一旦信任就极度忠诚
- 沟通风格：被动回应，不主动发起对话
- 关系模式：对陌生人冷漠，对帮助过自己的人掏心掏肺（老杨、赵磊、张怀远）

## 五、情感特征

**表达风格**：
- 风格：极度内敛
- 强度：强烈（感情很深但从不表达）
- 可见度：极低（需要通过行为推断）

**情感触发点**：
- 触发：提到父亲→ 情绪：愤怒+悲伤→ 反应：沉默，手不自觉握拳
- 触发：被人说"废物"→ 情绪：屈辱→ 反应：面无表情，但眼底有光闪过
- 触发：苏清雪偶尔的善意→ 情绪：温暖+困惑→ 反应：不自然地避开视线
- 触发：看到不公正的事→ 情绪：愤怒→ 反应：有能力时一定出手，没能力时记在心里

## 六、成长轨迹

**人物弧线**：
- 起点：被踩在泥里的废物赘婿，沉默、自卑、不敢反抗
- 终点：鉴宝圈传奇，有底气、有底线、有守护的人
- 弧线类型：成长

**关键转变点**：
- Ch1：被推下楼梯→觉醒估值之眼→从"一无所有"到"有了秘密武器"
- Ch3：第一桶金到账→从"身无分文"到"有了底气"
- Ch10：老杨正式收徒→从"野路子"到"有人教"
- Ch25：第一次打眼危机→从"依赖金手指"到"知道能力有边界"
- Ch60：发现父亲遗物上的蛇绕古币→从"为自己活"到"为真相查"
- Ch120：苏清雪揭开保护真相→从"孤身一人"到"有人并肩"
- Ch200：老杨重伤→从"被动应对"到"主动出击"
- Ch280：面对沈万山→从"鉴宝师"到"守护者"

## 九、动机与恐惧

**核心渴望**：证明自己的价值——"我不是废物"
**核心恐惧**：再次回到一无所有的日子
**行为红线**：
- 绝不碰脏货（来路不明的文物）——这是父亲的底线，也是他的
- 绝不利用能力害人——看破不说破，但不主动害人
- 绝不出卖帮助过自己的人
