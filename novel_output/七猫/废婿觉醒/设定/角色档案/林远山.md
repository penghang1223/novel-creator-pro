# 林远山 — 13维角色卡

## 一、基础信息

| 字段 | 内容 |
|------|------|
| 姓名 | 林远山 |
| 年龄 | 去世时42岁（2008年） |
| 性别 | 男 |
| 身份 | 民间鉴宝师，估值之眼血脉传人，陈素华弟子 |
| 外貌 | 中等身材偏瘦，常年穿白衬衫或中山装；黑框圆眼镜，镜片很薄；手指修长指甲极短（鉴宝师习惯）；左眉上方有一道浅疤 |
| 背景 | 江州最有天赋的鉴宝师之一。与沈万山同拜陈素华为师。估值之眼能力极弱（血脉稀释三百年），但靠二十年经验积累了精准口碑。2008年被沈万山安排"意外"车祸身亡 |

## 二、核心性格

**核心特质**：沉稳、正直、对古玩有近乎痴迷的热爱、不善表达但行动力强

**矛盾特质**：
- trait1：对古玩极其敏锐（一眼能看出真假年代）
- trait2：对人情世故极其迟钝（看不穿苏建国的局，签了"以子入赘"的协议）
- context：他的全部智慧都给了古玩，留给生活的地方一片空白
- resolution：他的"笨"间接导致了林辰入赘的命运——这是他一生最大的遗憾

**成长方向**：已故角色，通过回忆和遗物展现完整的人物弧线——从"正直到天真"到"用命守护真相"

## 三、说话风格

**口头禅**：
- "值不值，看看就知道了。"（林辰继承了这句话）
- "有些东西的价值，不是钱能衡量的。"（核心理念）
- "鉴宝鉴的是文化，不是钱。"（师父教的，他也这样教）

**用词偏好**：
- 正式程度：mixed
- 词汇风格：文雅（读书人气质）
- 偏好词：真、假、值、传承
- 禁用词：不说"差不多"——鉴宝不能差不多

**句式特点**：
- 话少但精准——一句顶别人十句
- 对妻子和儿子说话会多几个字（虽然还是不多）
- 鉴定时会详细解释判断依据——这是他的习惯

**情绪表达**：
- 风格：极度内敛（林辰的性格遗传自他）
- 压力下：更加沉默，手指摩挲眼镜腿
- 开心时：嘴角微动（和林辰一模一样）
- 愤怒时：眯眼+语气变平静（和林辰一模一样）

## 四、行为模式

**决策风格**：
- 风格：谨慎但在原则问题上绝不退让
- 依据：眼力+良心
- 示例：苏建国让他给赝品出鉴定书——他拒绝了，即使得罪了人

**压力反应**：
- 典型反应：沉默+独自思考
- 肢体语言：摩挲眼镜腿、抿嘴
- 应对机制：把压力转化为行动——收集证据、暗中调查

**人际交往**：
- 可接近程度：低（话少的人不好接近）
- 信任程度：中等（他信任好人，但看不穿坏人）
- 沟通风格：简洁、直率、不绕弯子
- 关系模式：对家人温和但不善表达，对同行尊重但保持距离，对沈万山从兄弟到决裂

## 五、情感特征

**表达风格**：
- 风格：极度内敛
- 强度：深沉（爱很深但从不说出口）
- 可见度：极低（需要通过行动推断）

**情感触发点**：
- 触发：看到好东西（真品古董）→ 情绪：兴奋+敬畏→ 反应：手发抖，忘记一切
- 触发：有人让他造假→ 情绪：愤怒→ 反应：直接拒绝，不给面子
- 触发：林辰叫他"爸"→ 情绪：温暖→ 反应：不自然地摸摸儿子的头
- 触发：发现沈万山走私国宝→ 情绪：愤怒+悲伤→ 反应：沉默，然后开始收集证据

## 六、成长轨迹

**人物弧线**（通过回忆展现）：
- 起点：有天赋但能力弱的民间鉴宝师
- 终点：用命守护真相的殉道者
- 弧线类型：悲剧英雄

**关键事件**：
- 年轻时拜陈素华为师→学鉴宝基本功
- 与沈万山决裂→师兄弟反目
- 拒绝给苏建国的赝品出鉴定书→结下恩怨
- 被苏建国设"债务局"→签下以子入赘协议
- 在云南发现沈万山走私线→开始收集证据
- 2008年被安排"车祸"→与妻子一同遇难

## 九、动机与恐惧

**核心渴望**：守护——守护真品、守护文化、守护家人
**核心恐惧**：林辰走上沈万山的路——用能力做坏事
**行为红线**：
- 绝不给赝品出鉴定书——这是师父教的第一课
- 绝不碰脏货——来路不明的东西不碰
- 发现不公一定要揭发——即使代价是生命
