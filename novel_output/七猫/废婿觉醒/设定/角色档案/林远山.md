# 林远山

## 基本信息

| 字段 | 内容 |

| 姓名 | 林远山 |
| 性别 | 男 |
| 年龄 | 死时42岁 |
| 身份 | 民间鉴宝师，估值之眼血脉传人 |
| 妻子 | 周若兰 |
| 儿子 | 林辰 |

## 外貌

中等身材，偏瘦，常年穿白衬衫或中山装。鼻梁上架一副黑框圆眼镜，镜片很薄。手指修长，指甲剪得很短——鉴宝师的习惯。左眉上方有一道浅疤，年轻时在古玩市场被人打了留下的。

## 性格

沉稳、寡言、对古玩有近乎痴迷的热爱。对家人温和但不善表达——他爱周若兰和林辰，但不会说"爱"这个字，只会用行动表示：给儿子买书，陪妻子散步，在雨天多带一把伞。

## 能力

估值之眼，但能力极弱。原因：民国时期的觉醒，血脉已经稀释了三百年，能力退化严重。

**林远山的能力表现**：
- 只能模糊感知物品的"大致年代"，看不到具体价值数字
- 视野范围只有3米
- 持续使用15分钟就会头痛
- 无法判断真伪，只能感觉"年代感"

尽管能力弱，林远山靠二十年的经验积累，成为江州一带小有名气的鉴宝师。他的口碑是"眼力准，不贪"——从不故意抬高估价赚差价。

## 师承与背景

**师父**：陈素华（1912-1987），民国鉴宝大师，杨无咎血脉的旁支。她是林远山的师姑，实际承担了师父的角色。

**师弟**：沈万山（本书终极反派）——同一批拜入陈素华门下的师兄弟。沈万天资高，但心术不正，利用鉴宝能力做文物走私生意。陈素华将其逐出师门，但沈万山的能力比林远山强得多。

## 与苏建国的恩怨

苏建国是江州早期的地产商人，靠倒卖土地起家。1998年，他找到林远山，想借他的眼力收一批"老货"。

林远山鉴定后发现这批货全是赝品，拒绝出具鉴定书。苏建国转而找到沈万山——沈万山出具了"真品"鉴定书，苏建国大赚一笔。

但沈万山留了一手：他偷偷在交易文件中嵌入了"蛇绕古币"标志——这是他的私人标记，也是后来"暗网鉴宝圈"的雏形。

2003年，苏建国设局让林远山"借"了一笔钱（实际是用于一次大型鉴定活动），然后用高利贷条款逼林远山还不上。林远山被迫签下"以子入赘抵债"的协议——林辰刚满18岁，刚考上大学。

## 死亡真相

**表面**：2008年，林远山夫妇在从云南回江州的路上遭遇车祸。车辆坠崖，夫妻二人当场死亡。

**真相**（卷五揭示）：

1. 林远山在云南瑞丽发现了一批走私翡翠原石，源头指向沈万山
2. 他悄悄收集了证据——几份交易文件和照片，封在了文化产业园地下室的铁箱子里
3. 沈万山通过苏建国得知了林远山的行动
4. "车祸"是沈万山安排的——刹车线被剪断
5. 苏建国知情但没有阻止——他害怕林远山查出当年债务局的事
6. 林辰当时20岁，在江州读大学，对一切毫不知情

## 留给林辰的东西

1. **能力**：估值之眼（虽然血脉稀释，但林辰觉醒后能力比父亲强得多）
2. **铁箱子里的证据**：拓片、光绪年间笔记——这些是林远山留给后人的
3. **一块玉佩**：林辰随身携带，是他18岁生日时父亲送的。玉佩上刻着一个极小的标志——蛇绕古币（林远山当时不知道这意味着什么）

## 与蛇绕古币标志的关系

蛇绕古币标志最初是沈万山的私人标记。林远山生前并不知道这个标志的完整含义——他只知道这个标志经常出现在可疑的交易文件上。

文化产业园地下室铁箱子里的拓片，是林远山临死前最后一批收藏。他意识到这个标志背后有一个更大的网络，但来不及深入调查就被害了。
