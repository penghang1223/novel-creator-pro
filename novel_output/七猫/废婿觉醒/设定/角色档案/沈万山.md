# 沈万山

## 基本信息

| 字段 | 内容 |
|------|------|
| 姓名 | 沈万山 |
| 性别 | 男 |
| 年龄 | 65岁 |
| 身份 | 暗网鉴宝圈头目，林远山的师弟 |
| 化名 | "蛇公"（暗网内部称呼） |

## 外貌

高瘦，背微驼。头发花白，梳成背头。脸上没什么皱纹，但眼神阴冷。左手食指上戴着一枚古币戒指——就是蛇绕古币标志里的古币造型，是杨无咎传下来的信物之一。

穿深色中式立领上衣，不穿西装。说话时习惯性地摩挲食指上的戒指。

## 性格

极度聪明，极度耐心，极度冷血。他不急——他等了四十年。他不贪——他只赚有把握的钱。他不露——认识他的人只知道他是个"做文物生意的老板"，不知道他背后有一个跨国犯罪网络。

**核心特征**：他把一切当生意，包括人命。他害死林远山夫妇的时候没有犹豫——不是因为恨，是因为"他们挡了我的路"。

## 师承与能力

与林远山同拜陈素华为师。

**沈万山的能力**：估值之眼（同血脉，但比林远山强得多）。
- 视野范围：约20米
- 能看到物品的"真实价值"（与林辰LV1相同）
- 持续使用时间：约40分钟
- 但他从不依赖能力——他的真正武器是人心

**为什么比林远山强**：沈万山是陈素华最看重的弟子，能力传承更完整。但他心术不正，被逐出师门后，能力停止增长——这是他一生最大的遗憾。如果他没有被逐出，他的能力可能已经达到LV3甚至更高。

## 暗网鉴宝圈

### 组织架构

```
沈万山（蛇公）
├── 香港：李少白（资金通道，李家）
├── 东南亚：老K（走私网络负责人，泰国华人）
├── 欧洲：Dr. Weber（拍卖行内线，苏富比前高管）
├── 日本：田中一郎（回流文物渠道，东京古董商）
├── 大陆：各城市中间人（通过"蛇绕古币"标志联系）
│   ├── 北京：赵文博（赵家二少，不知情）
│   ├── 江州：？？？（Ch10咖啡店标志——尚未揭晓）
│   └── 上海：孙小雨画廊的某个客户（方老师的高仿画买家）
└── 暗线：苏大强（四大家族眼线，不知道自己在为沈万山工作）
```

### 运作模式

1. **收购**：通过中间人在各地低价收购文物（利用信息差和造假手段）
2. **洗白**：通过日本、香港的拍卖行"合法"回流
3. **销售**：通过欧洲拍卖行卖给海外收藏家
4. **资金**：通过香港的壳公司洗白，回流到沈万山控制的账户

年营业额：约20亿人民币。

### 蛇绕古币标志

这是沈万山的私人标记，源自杨无咎传下来的一个印章图案。印章原本是完整的——一半是蛇绕古币，一半是"聚古斋"三个字。陈素华逐出沈万山时，将印章一分为二，蛇绕古币的一半被沈万山带走。

沈万山用这个标志作为暗网的识别标记——所有与他有关联的文件、仓库、仓库钥匙上都有这个标志。

## 与林远山的关系

师兄弟。年轻时关系不错——沈万山比林远山大三岁，入门早，教过林远山一些鉴宝基础。

**分歧点**：

沈万山想利用能力做文物走私生意。林远山反对——"师父说过，鉴宝是守文化，不是卖祖宗。"

陈素华发现沈万山的生意后，将其逐出师门。沈万山认为是林远山告的密（实际不是，是陈素华自己发现的），从此怀恨在心。

## 害死林远山的经过

2008年，林远山在云南发现沈万山的走私线。他收集了证据，准备交给国家文物局。

沈万山通过苏建国得知此事。他没有犹豫——安排"车祸"。

**具体操作**：
1. 沈万山通过中间人找到云南当地的一个修车工
2. 修车工在保养时剪断刹车线
3. 林远山夫妇在盘山公路刹车失灵，车辆坠崖
4. 修车工一个月后"意外"死亡（沈万山灭口）

## 为什么现在才行动

沈万山知道林辰的存在，但他不认为一个20岁的年轻人能构成威胁。而且林辰当时没有觉醒能力——沈万山的估值之眼对活人无效，他无法判断林辰是否觉醒了。

但林辰在文化产业园发现了铁箱子，这让沈万山警觉了。

**当前状态**：
- Ch1-9：不知道林辰的存在
- Ch10：咖啡店标志出现——说明沈万山在江州有眼线，但沈万山本人不在江州
- Ch20-30：通过眼线了解到林辰的异常
- Ch40：发现林辰与林远山的关系，开始重视
- Ch100：确认林辰也觉醒了估值之眼
- Ch200+：开始正式出手

## 最终结局

卷七与林辰正面交锋。被林辰和国家力量联手铲除。

**最后一幕**：沈万山被带走前，看着林辰说："你比你爸强。但他也没比我弱多少——他只是太正了，正到不知道怎么在这个世界活。"
