# 王丽华 — 13维角色卡

## 一、基础信息

| 字段 | 内容 |
|------|------|
| 姓名 | 王丽华 |
| 年龄 | 52岁 |
| 性别 | 女 |
| 身份 | 苏清雪的母亲，林辰的岳母 |
| 外貌 | 微胖，烫着卷发，喜欢穿花哨的衣服；手指上戴了三个金戒指；脸上永远涂着厚厚的粉底 |
| 背景 | 出身普通工人家庭，嫁给苏大强的父亲后进入苏家。在苏家没有地位，一直靠讨好苏建国维持存在感。苏建国去世后，她把所有焦虑都投射到对女婿的控制上 |

## 二、核心性格

**核心特质**：势利、嘴碎、缺乏安全感、控制欲强

**矛盾特质**：
- trait1：表面上精明势利（对有钱人点头哈腰，对穷人翻白眼）
- trait2：骨子里是恐惧——怕失去在苏家的地位，怕被人看不起
- context：她的势利不是天生的，是嫁入苏家后被逼出来的生存策略
- resolution：当林辰真正证明实力后，她不是简单的180度变脸——而是先震惊→试探→确认→讨好，有层次

**成长方向**：从"用钱衡量一切的势利眼"到"不得不承认自己看走眼的普通人"——她不会变成好人，但会学会闭嘴

## 三、说话风格

**口头禅**：
- "你配吗？"（对林辰的经典羞辱）
- "哎呀你看你……"（变脸后的经典讨好）
- "我跟你说……"（八卦开场白）

**用词偏好**：
- 正式程度：casual
- 词汇风格：粗俗（怎么扎心怎么来）
- 偏好词：钱、出息、丢人、配不上
- 禁用词：不说"我错了"——即使知道自己错了也绝不说

**句式特点**：
- 骂人时用反问句："你也好意思？""你配吗？""你不丢人？"
- 讨好时用感叹句："哎呀真不错！""我就说嘛！"
- 语速快，声音尖，整个楼层都能听到

**情绪表达**：
- 风格：极度外放（和苏清雪完全相反）
- 压力下：更加吵闹，声音更大
- 开心时：笑得花枝乱颤，金戒指晃眼
- 愤怒时：拍桌子+翻白眼+三连骂

## 四、行为模式

**决策风格**：
- 风格：冲动（想什么说什么，说完就后悔但从不承认）
- 依据：钱+面子
- 示例：看到林辰手机余额100万，第一反应不是"这钱哪来的"而是"哎呀女婿你饿了吧妈给你热饭"

**压力反应**：
- 典型反应：大声抱怨，把压力转嫁给别人
- 肢体语言：翻白眼、叉腰、拍大腿
- 应对机制：找人诉苦（通常是邻居或亲戚）

**人际交往**：
- 可接近程度：高（她什么话都说，不分对象）
- 信任程度：低（她只信钱）
- 沟通风格：单向输出，不听别人说话
- 关系模式：对有钱人讨好，对穷人鄙视，对家人控制

## 五、情感特征

**表达风格**：
- 风格：极度外放
- 强度：强烈但浅薄（来得快去得也快）
- 可见度：极高（所有人都看得出她的情绪）

**情感触发点**：
- 触发：看到林辰有钱了→ 情绪：震惊→ 反应：立刻变脸讨好
- 触发：别人说苏家闲话→ 情绪：愤怒+羞耻→ 反应：加倍骂林辰（转移羞耻感）
- 触发：苏清雪帮林辰说话→ 情绪：困惑+受伤→ 反应："你到底是不是我生的？"
- 触发：林辰不再被她控制→ 情绪：恐惧（失去控制权）→ 反应：变本加厉或彻底退缩

## 六、成长轨迹

**人物弧线**：
- 起点：把林辰当废物使唤的势利岳母
- 终点：学会闭嘴的普通人（不会变成好人）
- 弧线类型：被现实教育

**关键转变点**：
- Ch1：经典羞辱林辰（起点）
- Ch4：看到林辰余额100万，180度变脸（第一个转折）
- Ch6：家族聚会上再次变脸（看风向）
- Ch30+：逐渐意识到林辰已经不是她能控制的人
- Ch60后：退居背景，不再主动找茬

**行为红线**：
- 绝不让自己"丢面子"——尤其是在亲戚面前
- 绝不承认自己错了——即使所有人都知道
- 不会真正伤害苏清雪——她再势利也是爱女儿的
