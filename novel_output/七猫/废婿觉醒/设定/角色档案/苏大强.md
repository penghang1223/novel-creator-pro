# 苏大强 — 13维角色卡

## 一、基础信息

| 字段 | 内容 |
|------|------|
| 姓名 | 苏大强 |
| 年龄 | 30岁 |
| 性别 | 男 |
| 身份 | 苏清雪的大哥，苏氏集团副总（虚职）→ 赵家/古泉会的眼线 |
| 外貌 | 高壮，剃着板寸头，脖子上戴着金链子；手臂上有纹身（后来被蛇绕古币纹身覆盖）；穿名牌但品味差——花衬衫+皮夹克 |
| 背景 | 苏家唯一的男丁，从小被宠坏。不学无术，赌博欠下巨额债务，被赵家利用成为安插在苏家的棋子。他以为自己在"为苏家做事"，实际是别人的工具 |

## 二、核心性格

**核心特质**：自大、短视、被利用而不自知、骨子里懦弱

**矛盾特质**：
- trait1：表面上嚣张跋扈（在苏家作威作福，欺负林辰）
- trait2：背后是赵家的棋子（赌博欠债被抓住把柄）
- context：他的"恶"不是天生的，是无能+被利用的结果
- resolution：被揭穿后彻底崩溃——因为他一直以为自己才是掌控者

**成长方向**：从"以为自己很厉害的跳梁小丑"到"认清自己只是棋子的可怜人"

## 三、说话风格

**口头禅**：
- "废物。"（对林辰的经典称呼）
- "你知道我爸是谁吗？"（万能挡箭牌）
- "你等着。"（输了之后的经典放话）

**用词偏好**：
- 正式程度：casual
- 词汇风格：粗俗+装腔作势
- 偏好词：废、丢人、滚、老子
- 禁用词：不说"对不起"——被逼到绝路才会说

**句式特点**：
- 命令句为主："你给我……""你去……""你别……"
- 威胁时用反问："你信不信我……""你知道后果吗？"
- 喝酒后话特别多，什么都往外说

**情绪表达**：
- 风格：极度外放，藏不住事
- 压力下：喝酒、发脾气、摔东西
- 开心时：吹牛、请客、摆阔
- 愤怒时：动手（但只对弱于自己的人）

## 四、行为模式

**决策风格**：
- 风格：冲动（先做后想，做了就后悔但死不承认）
- 依据：面子+眼前利益
- 示例：赵家让他监视林辰，他觉得"这不就是帮朋友个忙嘛"——完全没意识到自己在当间谍

**压力反应**：
- 典型反应：逃避——喝酒、赌博、找人撒气
- 肢体语言：挠头、踱步、砸东西
- 应对机制：打电话找赵家的人求助（不知道自己在越陷越深）

**人际交往**：
- 可接近程度：中等（对"哥们"很热情）
- 信任程度：低（他信任赵家的人，但赵家只是在利用他）
- 沟通风格：粗暴、直接、不过脑子
- 关系模式：对赵家的人点头哈腰，对苏家的人颐指气使，对林辰极度鄙视

## 五、情感特征

**表达风格**：
- 风格：外放
- 强度：强烈但不稳定（今天恨你明天求你）
- 可见度：极高（所有情绪都写在脸上）

**情感触发点**：
- 触发：林辰表现出能力→ 情绪：嫉妒+恐惧→ 反应：加倍打压
- 触发：苏清雪帮林辰→ 情绪：愤怒+受伤→ 反应："你胳膊肘往外拐！"
- 触发：被赵家威胁→ 情绪：恐惧→ 反应：更加听话
- 触发：被苏家赶出去→ 情绪：屈辱+愤怒→ 反应："你们等着！"

## 六、成长轨迹

**人物弧线**：
- 起点：在苏家作威作福的废物大少爷
- 终点：被揭穿后一无所有的可怜人
- 弧线类型：堕落（不是变坏，是一直在坏的路上越走越远）

**关键转变点**：
- Ch1：推林辰下楼梯（起点——纯粹的恶）
- Ch4-5：家族聚会上嘲讽林辰→被打脸
- Ch66-70：断辰雅斋货源→被苏清雪清理
- Ch115-120：被赵铭利用→家族审判→被逐出
- Ch159：揭露在给古泉会执法堂做事
- Ch274：古泉会解散后回到苏家下跪

| 囂张时 | 挺胸+下巴抬高+双手插兜 | 典型的装腔作势 |

## 八、反差开关

| 表层 | 真实 | 触发条件 |
|------|------|---------|
| 嚣张的苏家大少 | 被赵家控制的棋子 | 赵家的人出现时 |
| 欺负林辰是出于鄙视 | 实际是嫉妒（林辰比他有能力） | 林辰做成他做不到的事时 |
| 为苏家着想 | 实际在出卖苏家利益 | 被揭穿时 |
| 天不怕地不怕 | 其实最怕被赶出苏家 | 苏清雪真正发怒时 |

## 九、动机与恐惧

**核心渴望**：被认可——作为苏家唯一的男丁，他想证明自己有价值
**核心恐惧**：被抛弃——被苏家赶出去，被赵家抛弃，一无所有
**行为红线**：
- 不会真的伤害苏清雪——她是他妹妹（虽然嘴上不承认）
- 不会主动杀人放火——他胆子没那么大
- 被逼到绝路会反咬赵家——但那时候已经太晚了
