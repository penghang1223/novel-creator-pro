# 苏清雪 — 13维角色卡

## 一、基础信息

| 字段 | 内容 |
|------|------|
| 姓名 | 苏清雪 |
| 年龄 | 25岁 |
| 性别 | 女 |
| 身份 | 苏家大小姐→苏氏集团CEO→林辰妻子 |
| 外貌 | 冷艳型美女，五官精致但总带着距离感；笑起来有酒窝（极少笑）；穿着简约干练，偏爱白色和灰色 |
| 背景 | 苏家唯一的正统继承人，从小被当作"家族资产"培养。被迫执行爷爷遗愿嫁给林辰，但暗中观察了他三年 |

## 二、核心性格

**核心特质**：独立、理性、观察力极强、有商业野心、外冷内热

**矛盾特质**：
- trait1：表面上对林辰冷淡（三年几乎不交流）
- trait2：暗中一直在观察他有没有变化（从未真正放弃过他）
- context：她知道爷爷的遗愿背后有目的，不确定林辰是否值得信任
- resolution：当林辰展现出真正的实力后，她开始主动靠近

**成长方向**：从"被家族操控的棋子"到"自己做选择的人"——最终选择站在林辰一边

## 三、说话风格

**口头禅**：
- "你想多了。"（否认关心对方时）
- "跟我没关系。"（实际上很在意时的口头禅）
- "说重点。"（不耐烦或掩饰情绪时）

**用词偏好**：
- 正式程度：mixed（工作场合正式，私下偶尔放松）
- 词汇风格：文雅（用词精准，不啰嗦）
- 偏好词：效率、结果、方案、底线
- 禁用词：不说"我怕""我不行""帮帮我"——示弱是她的禁区

**句式特点**：
- 陈述句为主，很少用问句
- 偶尔用反问句表达不满："你觉得呢？"
- 对林辰说话会不自觉多说几个字（她自己没发现）

**情绪表达**：
- 风格：极度含蓄，面部表情控制力强
- 压力下：更加冷静，语速不快但每个字都很重
- 开心时：不笑，但会做一些小事（给林辰倒水、多看一眼）
- 愤怒时：语气变轻，反而更可怕

## 四、行为模式

**决策风格**：
- 风格：果断（商业决策）/ 谨慎（人际关系）
- 依据：数据+直觉
- 示例：看到林辰的变化，不会直接问——而是通过侧面渠道查证

**压力反应**：
- 典型反应：更加冷静，进入"战斗模式"
- 肢体语言：食指轻敲桌面、抿嘴、视线集中在一点
- 应对机制：独自开车兜风（她唯一的情绪出口）

**人际交往**：
- 可接近程度：极低（苏氏集团CEO的气场让人不敢靠近）
- 信任程度：极低（三年赘婿生活让她学会了不信任任何人）
- 沟通风格：直接、简洁、不废话
- 关系模式：对下属严格但公平，对家人有义务感但无亲近感，对林辰从冷漠到好奇到信任

## 五、情感特征

**表达风格**：
- 风格：极度内敛
- 强度：强烈（内心感情丰富但从不外露）
- 可见度：极低（需要通过行为细节推断）

**情感触发点**：
- 触发：林辰展现出真实能力→ 情绪：惊讶+欣赏→ 反应：不动声色地多看几眼
- 触发：家族逼迫她做决定→ 情绪：愤怒+无奈→ 反应：表面服从，暗中按自己的来
- 触发：有人欺负林辰（在她面前）→ 情绪：不悦→ 反应：用气场镇住对方
- 触发：林辰拒绝她的帮助→ 情绪：受伤（罕见的脆弱）→ 反应：冷着脸走开

## 六、成长轨迹

**人物弧线**：
- 起点：被家族操控的冷艳总裁，对林辰无感
- 终点：主动选择站在林辰身边的伴侣
- 弧线类型：成长

**关键转变点**：
- Ch4-5：第一次注意到林辰变了（语气、眼神不一样了）
- Ch20：第一次主动帮林辰（用苏氏集团资源提供信息），但不明说
- Ch60：第一次公开站在林辰一边（家族内部大震动）
- Ch120：揭开真相——她一直在暗中保护林辰（家族有人想害他）
- Ch180：与林辰真正并肩作战

## 八、反差开关

| 表层 | 真实 | 触发条件 |
|------|------|---------|
| 冷漠的总裁 | 其实很在意林辰 | 林辰遇到危险时 |
| 服从家族安排 | 暗中按自己的计划行事 | 家族压力越大越叛逆 |
| 不需要任何人 | 渴望有人真正懂她 | 林辰某次无意中说中她心事 |
| 商业女强人 | 也有脆弱的时候 | 独自一人在车里时 |

## 九、动机与恐惧

**核心渴望**：自由——不被家族、爷爷遗愿、社会期待所束缚
**核心恐惧**：被迫做一辈子不想做的事（包括这段婚姻）
**行为红线**：
- 绝不出卖自己的判断力——即使家族施压
- 绝不示弱——尤其是对林辰（前期）
- 绝不伤害无辜的人——这是她和家族某些人的分界线
