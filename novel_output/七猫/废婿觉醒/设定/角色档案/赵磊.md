# 赵磊

## 基本信息

| 字段 | 内容 |
|------|------|
| 姓名 | 赵磊 |
| 性别 | 男 |
| 年龄 | 28岁 |
| 身份 | 古玩市场跑腿小哥 → 林辰公司CEO |
| 籍贯 | 江州本地人 |

## 外貌

矮壮，一米六八，一百六十斤。圆脸，笑起来露出两颗虎牙。穿一件洗得发白的牛仔夹克，左袖口有一道口子——帮人搬东西的时候刮的。手上全是茧子，指关节粗大。

## 性格

热情、嘴碎、仗义。认识市场里所有人——摊主、保安、城管、派出所的人都能叫上名字。他的价值不在于专业能力，而在于"信息"。他知道谁手里有好货，谁在卖假货，谁最近手头紧要出手，谁家昨天吵架了。

**矛盾性**：看起来是个没文化的跑腿，但记性极好——过目不忘。他能记住市场里每件货的来龙去脉，谁卖给谁、多少钱、什么时候的事。这不是天赋，是他跑了五年腿练出来的。

## 背景

初中毕业，父亲赵建国是农贸市场的杀鱼工，母亲在家带孩子。赵磊18岁出来打工，干过搬运工、快递员、外卖员，最后留在了潘家园古玩市场做跑腿——帮人搬货、送货、看摊、传话。一天赚八十到一百二。

他住在一个六人间的出租屋里，每个月房租五百。梦想是"攒够钱开一家自己的小店"，但五年了只攒了两万三。

## 认识林辰的经过

Ch11：林辰第一次来潘家园，赵磊帮他搬东西。林辰看他搬东西时注意到一个细节——赵磊搬东西不是瞎搬，他会先看每件东西的价值，然后轻拿重放。这说明他对古玩有基本的鉴别能力。

林辰请他喝了瓶水。赵磊随口说了几句市场里的"行情"——谁最近收了好货，谁在卖假货。林辰意识到这个人的信息价值远超他的工资。

## 经典台词

"辰哥，你当初为什么信我？"
"因为你的价值，不止你看到的那么多。"

"这市场里，最不值钱的是货，最值钱的是消息。"

"我记性好不是天生的。是跑了五年腿，每一笔买卖我都记在心里——哪年哪月谁卖给谁多少钱，我全知道。"

## 与四大家族的关系

赵磊不认识四大家族的人，但他认识他们派来江州的"眼线"——那些人经常在市场上转悠，打听消息。赵磊能第一时间告诉林辰"某某家族的人来了"。

## 弱点

- 没有文化，不懂商业运作（后来通过学习弥补）
- 太重感情——有时候会因为"哥们义气"做出不理智的决定
- 家里穷——父亲生病需要钱时，他会陷入困境（林辰帮他解决）
