# 陈素华

## 基本信息

| 字段 | 内容 |
|------|------|
| 姓名 | 陈素华 |
| 性别 | 女 |
| 年龄 | 1912-1987（享年75岁） |
| 身份 | 民国鉴宝大师，杨无咎血脉旁支，林远山和沈万山的师父 |

## 外貌（根据老照片）

瘦小，穿民国时期的蓝布旗袍。头发盘成髻，插一根银簪。面容清癯，目光锐利。手上没有首饰——她认为"鉴宝的人手上不该戴东西，影响手感"。

## 背景

1912年生于苏州一个古玩商家庭。父亲陈守正是清末苏州最大的古玩商之一，与杨无咎后人有往来。陈素华从小接触古玩，六岁就能分辨明清瓷器的区别。

1930年代，她继承了父亲的店铺"守古斋"。抗战期间，她冒死保护了一批国宝级文物，不让日本人拿走。这件事让她在鉴宝圈声名远播。

1950年代，她把店铺交给侄子经营，自己隐居云南，收徒传授鉴宝之术。

## 与估值之眼的关系

陈素华本人没有觉醒估值之眼——她的血脉太淡了。但她能"感知"到谁有这个能力。她教林远山和沈万山鉴宝，是因为她"看"到了他们身上的潜质。

**她教的不只是技术**：
1. **眼力**：通过大量实物训练，培养对年代、材质、工艺的敏感度
2. **手感**：闭着眼睛摸一件东西，通过重量、温度、表面质感判断材质
3. **气味**：真品和赝品的气味不同——老瓷器有淡淡的"土腥味"，新书画有墨香，老书画有纸陈味
4. **心性**："鉴宝先鉴己。心贪则眼盲。"

## 逐出沈万山

1978年，陈素华发现沈万山利用能力做文物走私。她没有犹豫，当着他的面做了一件事：

把沈万山入门时送她的拜师帖撕了。

"你不是我的徒弟。"

然后她找到林远山，说了一句话："你师弟走了邪路。我教了你这么多，不是为了让你跟他一样。记住——鉴宝鉴的是文化，不是钱。"

## 临终遗言

1987年，陈素华在云南病逝。临终前，她把杨无咎传下来的印章（蛇绕古币+聚古斋）交给林远山，说：

"这东西你收着。你这一脉是正脉，将来会有人用它找到对的人。"

然后又说了一句：

"你的能力弱，但你儿子——如果他有的话——可能不一样。血脉这东西，隔代才跳。"

## 对后续剧情的影响

- 老杨认识陈素华——他是陈素华晚年的朋友之一
- 李藏锋的妹妹陈素秋是陈素华的后人
- 沈万山被逐出师门后，一直对陈素华怀恨在心
- 林远山的能力虽然弱，但陈素华教他的"鉴宝基本功"极其扎实——这也影响了林辰的成长方式
