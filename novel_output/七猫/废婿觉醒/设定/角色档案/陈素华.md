# 陈素华 — 13维角色卡

## 一、基础信息

| 字段 | 内容 |
|------|------|
| 姓名 | 陈素华 |
| 年龄 | 1912-1987（享年75岁） |
| 性别 | 女 |
| 身份 | 民国鉴宝大师，杨无咎血脉旁支传人，林远山和沈万山的师父 |
| 外貌 | 瘦小，穿民国蓝布旗袍；头发盘成髻插一根银簪；面容清癯目光锐利；手上不戴任何首饰——"鉴宝的人手上不该戴东西，影响手感" |
| 背景 | 1912年生于苏州古玩商家庭，父亲陈守正是清末苏州最大古玩商之一。六岁能分辨明清瓷器。1930年代继承"守古斋"。抗战期间冒死保护国宝级文物不让日本人拿走，声名远播。1950年代隐居云南收徒。能"感知"谁有估值之眼的潜质，但本人血脉太淡未觉醒。1978年发现沈万山走私后将其逐出师门。1987年病逝，临终将聚古斋印章交给林远山 |

## 二、核心性格

**核心特质**：严厉、正直、眼光毒辣——她一辈子只做一件事：守护真正的鉴宝传承

**矛盾特质**：
- trait1：表面上是瘦弱的老太太（穿蓝布旗袍，走路要拄拐杖）
- trait2：骨子里是鉴宝圈最锋利的刀（逐出沈万山时毫不犹豫，撕拜师帖的那一刻手都没抖）
- context：她对徒弟的爱是用严厉表达的——越看重的弟子要求越高
- resolution：逐出沈万山是她一生最痛苦的决定——她不是不爱这个徒弟，是不能容忍传承被玷污

**成长方向**：已故角色，通过回忆和遗物展现完整弧线——从"守护传承的大师"到"用最后的力量指明正脉"

## 三、说话风格

**口头禅**：
- "鉴宝先鉴己。心贪则眼盲。"（对徒弟的教诲——核心理念）
- "鉴宝鉴的是文化，不是钱。"（林远山继承了这句话）
- "你眼睛的颜色，不一样。"（她判断血脉传承的方式）

**用词偏好**：
- 正式程度：formal（旧式读书人的说话方式）
- 词汇风格：古雅（带民国腔，用词简洁但有分量）
- 偏好词：真、假、传承、正脉、心性
- 禁用词：不说"差不多"——和林远山一样

**句式特点**：
- 短句+判断句为主——"你不行。""这个假的。""记住。"
- 教训人时反而话多——详细解释为什么错
- 临终时语气变软——唯一的温柔时刻

**情绪表达**：
- 风格：严厉内敛（很少笑，但笑的时候眼睛会亮）
- 压力下：更加沉默，目光变得更加锐利
- 开心时：罕见——看到徒弟有进步时嘴角微动
- 愤怒时：不发火——用行动表达（撕拜师帖比骂人更狠）

## 四、行为模式

**决策风格**：
- 风格：果断（看准了就做，不犹豫）
- 依据：眼力+心性判断——她看人和看古董用同一种能力
- 示例：逐出沈万山只用了三秒决定——"我看到他手上的戒指，就知道他用能力做了什么"

**压力反应**：
- 典型反应：沉默+闭眼——在心里重新评估
- 肢体语言：手指轻敲桌面、目光移向远方
- 应对机制：用行动代替语言——她从不解释，只做

**人际交往**：
- 可接近程度：低（她选徒弟，不是徒弟选她）
- 信任程度：高（一旦信任就毫无保留——但信任的门槛极高）
- 沟通风格：简洁、直接、不留情面——但出发点永远是为你好
- 关系模式：对林远山严格但慈爱，对沈万山从器重到决裂，对老杨是同辈尊重

## 五、情感特征

**表达风格**：
- 风格：极度内敛（旧式女性的克制+大师的威严）
- 强度：深沉（对传承的爱超越对个人的爱）
- 可见度：低（通过她亲手教的动作和遗物展现）

**情感触发点**：
- 触发：看到真品→ 情绪：敬畏→ 反应：双手合十（旧式礼节）
- 触发：发现徒弟说谎→ 情绪：失望→ 反应：沉默三天不说话
- 触发：沈万山被逐出→ 情绪：痛苦→ 反应：当晚独自坐了一夜
- 触发：临终见林远山→ 情绪：释然+不舍→ 反应：罕见地握了徒弟的手

## 六、成长轨迹

**人物弧线**：
- 起点：天赋异禀的古玩商之女
- 终点：守护传承至最后一刻的宗师
- 弧线类型：传奇导师

**关键事件**：
- 六岁分辨明清瓷器→天赋初显
- 抗战期间冒死护宝→确立"守护传承"的人生信条
- 1950年代隐居收徒→找到林远山和沈万山
- 1978年逐出沈万山→一生最痛苦的决定
- 1987年临终交印→"你这一脉是正脉"

## 九、动机与恐惧

**核心渴望**：守护传承——杨无咎的鉴宝之术不能断在她手里
**核心恐惧**：传承被玷污——沈万山用能力做坏事，是对师父最大的背叛
**行为红线**：
- 绝不收心术不正的徒弟——宁缺毋滥
- 绝不妥协赝品——抗战时宁可得罪日本人也不交出真品
- 传承必须给正脉——"血脉这东西，隔代才跳"
