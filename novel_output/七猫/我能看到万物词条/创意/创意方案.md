# 《我能看到万物词条》创意方案

> 类型：男频都市脑洞/反差+无敌流
> 目标平台：七猫小说（男读者为主）
> 目标篇幅：100-150万字（约400-500章）
> 变现路径：长篇连载 + 短剧 + AI漫剧
> 创作日期：2026-04-26

## 一句话故事

一个底层外卖员被雷劈后觉醒"万物词条"能力——能看到所有人和物品头顶浮动的信息标签，从此靠信息差碾压，在都市异能世界一路逆袭登顶。

---

## 核心差异化卖点

| 卖点 | 说明 |
|------|------|
| **词条系统** | 白→绿→蓝→紫→金→红六级颜色，天然进度条+期待感 |
| **信息差碾压** | 不是主角更强，而是主角"知道得更多"——男频核心爽 |
| **反差萌** | 高冷女总裁的词条是[猫奴][社恐]；反派大佬的词条是[怕老婆][恐高] |
| **可升级** | LV1看基础 → LV2看隐藏 → LV3看未来 → LV4修改词条 |
| **喜剧+战斗双引擎** | 词条既能搞笑（找猫/捡漏），又能战斗（弱点打击） |

## 能力规则（硬设定）

### 万物词条

**江野能看到万物的浮动信息标签。**

**规则：**
- 每个人/物有3-8个词条
- 词条颜色：白（普通）→ 绿（优秀）→ 蓝（稀有）→ 紫（史诗）→ 金（传说）→ 红（禁忌）
- LV1（觉醒）：看基础词条（身份、情绪、状态）
- LV2（约15章解锁）：看隐藏词条（弱点、秘密、欲望）
- LV3（约100章解锁）：看"未来词条"（如果继续当前状态，3年后会变成什么样）
- LV4（约250章解锁）：修改词条（消耗巨大，每次修改后虚弱）
- 限制：过度使用会头痛欲裂，看到满屏词条重叠
- 克制：存在"无词条者"——能屏蔽词条观察的异能者

## 主题

**表层**：底层逆袭，信息差碾压的爽文。
**内核**：当你能看到所有人的"标签"，你是选择利用他们，还是理解他们？最终江野选择"超越词条"——不再用标签定义人，而是用真心对待每个人。
