# 第20章 第一次反击

江野没有立刻回城中村。

林清雪的司机把他送到了她公寓的楼下——一个高档小区，门口有保安，进出需要刷卡。大堂里铺着大理石，墙上挂着一幅真正的画——不是仿品。词条：[真品·当代画家·价值：约15万·品质：绿]。

十五万。一幅画。

他站在楼下，看着司机把车开走，然后低头看了看手里的那把钥匙。

银色的，很小。林清雪说"遇到危险就来"——但她不知道的是，江野的每一天都在危险中。只是他不说。

他没有上楼。

他把钥匙放进口袋里，骑上自己的电动车，回了城中村。不是不信任林清雪——是他不习惯住在别人的地方。城中村的房间虽然小，但是他的。旧手表、衣柜里的碗、胖子震耳欲聋的呼噜声——这些都是他的。

第二天，他正常上班。

右手缠着绷带，不太方便搬货。但孙凯帮他安排了文书工作——整理仓库的出入记录、核对配送清单。这样他反而有更多的时间去查看那些加密的数据。

仓库的办公室里有一台电脑。老旧的，开机要三分钟。屏幕的边角有一块坏掉的像素点，像是一个永远擦不掉的污点。词条：[联想台式机·使用6年·硬盘坏道：3处·品质：白]。

他打开电脑，登录了林氏的内部系统。他的权限很低——仓库管理员级别，只能看到出入库记录。但足够了。

中午吃饭的时候，他给苏小鱼发了一条微信：[赵铁柱你认识吗？]

三分钟后，苏小鱼回复了：[认识啊。物流部主管。怎么了？]

[帮我查一下他的背景。]

[！！！你要我黑他？]

[不是黑。就看看你能查到什么。公开的就行。]

[好！给我半小时！]

江野放下手机，拿起桌上的盒饭。米饭、土豆丝、一块肉。食堂的饭菜，十块钱一份。和昨天在林清雪办公室看到的那些东西比起来——十二万的沙发、十五万的画、三千块一斤的茶——像是两个世界。

但他吃得很香。

下午两点，苏小鱼发来了结果：

```
赵铁柱，42岁。
2018年加入林氏集团，任职物流部副主管。
2021年升任主管。
入职前：江城安保公司·特工（3年）
再之前：退役军人（8年）
```

退役军人。安保公司。特工。

赵铁柱的背景不普通。一个退役军人，在安保公司做了三年"特工"，然后进入林氏的物流部——从副主管一路升到主管。

这不是正常的职业路径。

正常的人不会从"安保公司特工"跳到"物流部副主管"。这两个行业没有任何关联。除非——这个"物流部"只是一个掩护。

江野把赵铁柱和异能者联盟联系在了一起。安保公司的"特工"——很可能是异能者联盟的外围人员。赵铁柱被安排在林氏的物流部，就是为了利用林氏的物流体系传输异能者相关的情报和物品。

而赵铁柱——就是那个绕过林清雪权限的人。

江野没有立刻行动。他需要一个计划。

第一步：确认XC货物里到底是什么。

第二步：收集赵铁柱的证据。

第三步：把这些信息交给林清雪——或者异能者联盟——或者两者。

但他更倾向于自己先弄清楚。

当天下午，他利用LV2的能力，对仓库进行了一次全面扫描。

他站在仓库中间，闭上眼睛，集中注意力，把感知范围开到最大。

仓库里的空气有一股灰尘和纸箱的味道。头顶的日光灯发出嗡嗡的声音——有一只快坏了，一闪一闪的，让人心烦。

词条像潮水一样涌进来——

[货物·普通·品质：白]×326
[货物·加密硬盘·来源：异能者联盟·品质：蓝]×5
[货物·精密仪器·来源：未知·品质：蓝]×7
[监控摄像头·运行中·存储位置：本地服务器·加密·品质：绿]×8
[隐藏摄像头·运行中·位置：货架B3上方·未被记录·品质：绿]

隐藏摄像头。

江野睁开眼睛。

仓库里有一个不在官方记录里的摄像头。藏在货架B3的上方，对着那12件XC货物的隔离区。

谁装的？

他走到货架B3下面，抬头看了一眼。摄像头的词条显示：[安装时间：3个月前·控制方：赵铁柱·数据流向：外部服务器·品质：绿]。

赵铁柱。

他不仅利用物流体系传输物品，还在仓库里装了隐藏摄像头，监控那些货物的存取过程。

这意味着——有人在远程监视仓库。

江野的心跳快了一拍。他不能在仓库里待太久。他扫了一眼就离开了，装作在检查货物。

回到办公室，他给苏小鱼发了第二条微信：[你之前说的那些加密数据——能追踪到外部服务器吗？]

[可以试试。为什么？]

[仓库里有一个隐藏摄像头。数据流向外部服务器。帮我找到那个服务器的地址。]

[！！！你那边也出事了？！]

[别问。查。]

三分钟后，苏小鱼回复：[找到了！外部服务器的IP地址是：192.168.45.137。但这个IP不在林氏的内网里——它在江城的一个数据中心。]

[能查到是谁租的吗？]

[给我十分钟！]

江野放下手机，靠在椅背上。

办公室的窗外是仓库的景象——叉车在来回跑，工人在搬货，孙凯在对着一张清单皱眉。

他看了一眼孙凯的词条。[仓库主管·情绪：认真·今日工作量：78%·品质：白]。

七十八%。孙凯今天也很忙。

二十天前，他还在暴雨里送外卖，担心超时和差评。

现在他在调查一个异能者情报网络。

赵铁柱。陈默然。林清雪。林家。异能者联盟。XC货物。加密硬盘。隐藏摄像头。

这些碎片在他脑子里搅成一团。但他能看到一条线——一条从他被雷劈那天就开始的线。

雷劈不是意外。陈默然说"从你被雷劈的那天开始"——这意味着有人在关注他。或者说，有人在等他觉醒。

但他不知道是谁。

他看了一眼自己的词条。

[观测者血脉·觉醒进度：5%·品质：灰]。

5%。路还很长。

但至少在往前走。

窗外的太阳快落山了。仓库里的光变成了金黄色——像是蜂蜜倒在纸箱上。

江野的右手绷带下，伤口在隐隐作痛。他看了一眼——纱布上有一点血迹。不严重，但证明昨晚的事是真的。

不是梦。

他拿起手机，苏小鱼还没有回复"是谁租的服务器"。

办公室里的钟显示四点二十。墙上的钟，老式的，挂在那个坏掉的日光灯旁边。钟的滴答声和日光灯的嗡嗡声混在一起，形成一种奇怪的声音——像是有人在用指甲挠玻璃。

他站起来，在仓库里走了一圈。

货架B3。隐藏摄像头的位置。他抬头看了一眼——那个摄像头还在那里，红色的指示灯在闪。

词条：[运行状态：正常·录像中·存储：已满73%·下次传输：今晚22:00·品质：绿]。

今晚十点。摄像头会在十点把数据传出去。

江野看了一眼自己的手机。现在是四点三十。

他有一个想法——如果他在十点之前破坏掉这个摄像头，赵铁柱就会知道有人发现了。打草惊蛇。

但如果他不破坏——他可以监控谁在接收数据。

他需要苏小鱼帮他做一个反向追踪。

他拿出手机，又发了一条微信：[你能不能做一个反向追踪？就是有人连接那个服务器的时候，你能追踪到对方的IP吗？]

苏小鱼秒回：[理论上可以。但需要时间写脚本。你为什么问这个？]

[今晚十点有用。帮我写一个。]

[！！！今晚十点？？？江野你是不是又在搞什么危险的事？]

[不是。就是看看。]

[你每次说"看看"都不是看看！]

江野笑了一下。他把手机放回口袋。

苏小鱼说的没错。他每次说"看看"都不是看看。

但这次不一样。他不是在"看看"——他是在计划一次反击。

赵铁柱在监视仓库。

那江野也监视回去。

他看了一眼自己的词条。

[观测者血脉·觉醒进度：5%·品质：灰]。

5%。如果他能看到更多——如果他能破解赵铁柱的信息屏蔽——他就能看到更多东西。

但现在不行。他需要等。

等苏小鱼的脚本。

等今晚十点。

等那个连接外部服务器的人出现。

下班的时候，孙凯叫住了他。

"江野，你的右手——没事吧？"

"小伤。"

孙凯看了他一眼，没再多问。但他的词条显示：[对江野的态度：关心+好奇·品质：白]。

江野骑电动车出了仓库。天色已经半黑了——江城的天黑得早，冬天的时候，五点不到就暗了。

他路过了一家面馆。招牌上的灯亮了一半——"老张拉面"，"面"字的灯灭了，只剩"老张拉"。词条：[面馆·营业中·今日客流量：87·口碑：4.2分·品质：白]。

他停下来，吃了一碗面。牛肉面，十二块。面条很粗，汤很浓，牛肉切得薄薄的三片。

他吃面的时候，手机震动了一下。

苏小鱼：[脚本写好了！反向追踪脚本，已经部署在林氏的测试服务器上。今晚十点会自动运行。]

[好。]

[江野！！！你到底在查什么？！]

[一个内鬼。]

[！！！]

[别告诉任何人。]

[……好。但你小心点。]

江野吃完面，付了钱，骑上电动车走了。

面馆老板的词条在他离开的时候闪了一下：[明日食材已备好·面粉：50斤·牛肉：15斤·品质：白]。

五十斤面粉，十五斤牛肉。够明天用的。

江野的脑子里突然冒出一个想法——如果他能看到更多人的词条，他就能看到更多秘密。

但不是现在。他的觉醒进度只有5%。

他回到城中村的时候，天已经完全黑了。四楼走廊的灯又坏了——上一次坏的时候他还是个普通人。现在他还是个普通人，只是能看到普通人看不到的东西。

他打开门。胖子在床上翻了个身，呼噜声停了一秒，然后又响了起来。

江野把钥匙放在桌上——那把银色的、林清雪给他的钥匙。

它在月光下闪了一下。

江野躺在床上，闭上眼睛。右手的伤口在隐隐作痛，像是有人在提醒他——你卷入了一个很大的局。
