# 世界观设定：大周朝

## 时代背景

架空历史"大周朝"，类似唐朝的开放风气+明清的后宫制度。

- **政治**：皇帝昏庸沉迷享乐，朝政由几位皇子把持
- **社会风气**：相对开放，女子可经商、读书，但嫡庶之分依然严格
- **军事**：摄政王萧墨寒手握重兵，是皇帝最忌惮也最倚重的臣子

## 社会结构

```
皇帝（昏庸）
├── 大皇子（早夭）
├── 二皇子（文弱，中立）
├── 三皇子（终极反派，野心勃勃）
├── 四皇子（萧墨寒同母弟，支持萧墨寒）
└── 其他皇子/公主

摄政王萧墨寒（先帝托孤，手握兵权）
├── 王妃沈知意（女主）
├── 柳侧妃（反派，被收买）
├── 王府管家（被收买下毒）
└── 青霜（知意贴身丫鬟，武力担当）

沈家
├── 沈父（攀附权贵，出卖庶女）
├── 沈母（嫡母，看不起庶女）
├── 沈知柔（嫡女，本该嫁王爷）
├── 沈知意（庶女，女主，生母已故）
└── 沈家与三皇子勾结

太后
├── 表面严厉试探知意
├── 实际是萧墨寒的暗中盟友
└── 后期揭晓：一直在暗中保护萧墨寒
```

## 读心术规则

- **触发条件**：对方"情绪波动"时才能听到
- **距离限制**：3米以内
- **副作用**：读心过度会头痛
- **听到内容**：是"真实想法"，不是谎言
- **升级路径**：
  - 阶段一：听到情绪化心声（被动），额头发热体感
  - 阶段二：主动触发读心+听到深层心声（第30章），太阳穴剧痛体感
  - 阶段三：屏蔽他人/只读特定人（第250章），眉心可控体感
