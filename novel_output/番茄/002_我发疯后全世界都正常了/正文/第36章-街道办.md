# 第36章 街道办

早上八点五十分。街道办事处门口。

许知意第一个到。她八点四十就出了门，从小区东门走到街道办事处，用了三分半钟。她在门口等了七分钟。

老王第二个到。他穿了一件深色的夹克，拉链拉到胸口的位置。手里拎着一个牛皮纸文件袋。文件袋鼓鼓囊囊的，边角被折过几次，看起来已经用过很多次了。

"签了多少？"许知意问。

"六十七个。"老王把文件袋晃了晃，"十六栋楼，我跑了整整一个上午。有些户家里没人，我在门上贴了纸条。有些户家里有人但不愿意签，说'别惹事'。有些户家里有人也签了。"

"哪些人不愿意签？"

"大多是租户。他们说物业费是房东的事，跟他们没关系。还有些老年人，说'算了算了，几十块钱的事'。"

"但最终还是签了六十七个。"

"对。十六栋楼，平均每栋楼四个。不多。但够用。"老王的声音很稳。他是一个退休的中学教师，教数学的。他说话的时候，带着一种数学老师特有的笃定——数字不会骗人。

张姐第三个到。她背了一个黑色的相机包。相机包很大，看起来不便宜。

"你带相机了？"许知意问。

"带了。"张姐拍了拍相机包，"单反。整个过程都拍下来。"

"为什么要拍？"

"万一他们不认账呢？"张姐的理由很简单，"证据。我们递交材料的过程，也是证据。"

赵阿姨最后一个到。她拎着一个布袋。布袋里装着四个保温杯。她走路不快，但每一步都很稳。七十岁的人了，背还是直的。

"我自己磨的豆浆。"赵阿姨把保温杯拿出来，一人分了一个，"跑了一早上，喝口热的。"

四个保温杯。四个陌生人。四种不同的身份。退休教师、家庭主妇、退休街道干部、二十八岁的办公室职员。

因为一张通知，走到了一起。

许知意背着她那个帆布包。包里是打印好的举报材料——通知照片、法律依据、业主签名、合同复印件。一共十二页。昨天晚上她打印了两份。一份交给街道办，一份自己留着备份。

她用夹子把材料装订好。封面上用黑笔写了四个大字："举报材料"。字体很工整。每一笔都很用力。

街道办事处在小区东门外面，步行三分钟。一栋两层的小楼，门口挂着一块铜牌——"阳光街道办事处"。铜牌下面有一块电子显示屏，滚动播放着标语——"和谐社区，共建共享"。

她们走进去。一楼大厅里有三个窗口——"民政服务"、"社会保障"、"信访接待"。

信访接待在第三个窗口。窗口后面坐着一个四十岁左右的男人。穿一件深蓝色的工作服，胸口绣着"阳光街道"四个字。

老王走上前。

"同志，我们要反映一个问题。"

男人抬起头。"什么问题？"

"物业涨价。没有走合法程序。我们业主不认可。"

男人看了一眼他们身后的三个人。又看了一眼老王手里的文件袋。

"材料带了吗？"

"带了。"老王把文件袋递进去。

男人打开文件袋，把里面的材料拿出来。十二页。一页一页地看。看得很仔细。每看一页，他的表情就会变一点。看通知照片的时候，他的眉头皱了一下。看法律依据的时候，他的表情松了一点——他知道这些法律条文。看业主签名的时候，他的目光在"六十七个签名"那行字上多停留了两秒。

翻到最后一页的时候，他停住了。最后一页是许知意自己写的——一份简短的陈述，说明了事情的经过和她的诉求。没有情绪化的语言。只有事实和时间线。

"这个是你们自己写的？"

"对。"许知意说，"事实陈述和诉求。"

男人把材料收好，放在抽屉里。然后他在电脑上敲了几下。不知道在输入什么。

"等一下。"他站起来，走到后面的办公室。

四个人站在窗口前等了五分钟。大厅里很安静。只有电子显示屏在滚动播放标语。"和谐社区，共建共享"、"为人民服务"、"信访工作是党和政府联系群众的桥梁"。

赵阿姨喝了一口豆浆。老王看了看手表。张姐把相机拿出来，调到了录像模式。许知意站在最前面，看着那个男人消失的方向。

男人回来了。后面跟着一个五十岁左右的女人。穿一件灰色的西装外套，戴一副眼镜。她的头发梳得很整齐，脸上有一种长期在基层工作的人才有的表情——不是疲惫。是一种见过很多事、处理过很多矛盾之后的平静。

"这位是我们街道办的副主任，李主任。"男人介绍。

李主任点了点头。"你们反映的问题，我已经看了材料。"

"收到是什么意思？"张姐问，"是'已受理'的意思，还是'会处理'的意思？"

李主任笑了一下。不是敷衍的笑。是一种认真的、带着一点无奈的笑。

"你问得直接。"她说，"那我直接回答——我们会处理。但不是我们今天能处理的事。"

"为什么？"许知意问。

"因为物业涨价涉及到多个部门。街道办没有执法权。我们需要把这个情况报给住建局和市场监管局。他们会介入调查。"

"调查需要多久？"

"法定期限是三十个工作日。"

许知意算了算。三十个工作日，加上周末，大概是一个半月。六月一号是涨价的执行日期。三十个工作日之后，已经是七月中旬了。

"六月一号之前的这段时间怎么办？"许知意问，"物业已经开始按新标准收费了。"

"如果物业在法定程序未完成的情况下擅自提高收费标准，业主有权拒绝交纳提高部分的费用。"李主任的语气很确定，"这一点，法律是明确的。"

"但物业不会听我们的。"赵阿姨说，"他们说涨了就涨了。不交就断水断电。"

"断水断电是违法的。"李主任的语气变了，变得硬了一些，"如果物业采取断水断电等强制措施，你们可以立刻报警。同时我们会介入协调。我们街道办虽然没执法权，但有协调权。"

她把一张名片递给许知意。名片上写着"李秀兰，阳光街道办事处副主任"。下面有一行手写的小字——"有问题直接联系我"。

许知意接过名片。名片是纸质的，边角有些磨损。说明这张名片已经用了很久了。

"李主任，"她说，"我们不是来闹事的。我们是来走程序的。"

"我知道。"李主任说，"你们的材料很齐全。法律依据、证据、签名，都有。而且你们的陈述很客观，没有情绪化的语言。这说明你们不是情绪化地来闹，是有准备地来反映问题。"

她看了许知意一眼。

"但我要提醒你一件事。"

"什么？"

"物业公司是华安城市服务集团的子公司。华安城市服务集团的控股股东是市城投集团。国有独资。"

"我知道。"

"你知道就好。"李主任说，"这意味着——这个案子不是一个小物业公司的问题。是一个国资系统的问题。处理起来会比普通案件更复杂。"

"但我们反映的问题是合法的。"

"对。问题本身是合法的。但处理的过程会慢。因为涉及到国资企业，需要更多的审批和协调。"

许知意点了点头。

"我理解。但我们会在法定期限内跟进。"

"好。"李主任说，"有任何进展，我会联系你。"

四个人走出街道办事处。

天已经完全亮了。阳光从东边照过来，照在街道办事处的铜牌上。铜牌在阳光下闪着光。门口的电子显示屏还在滚动播放标语。"和谐社区，共建共享"。

许知意看了看手机。九点半。整个过程用了四十分钟。

"怎么样？"张姐问，"算不算成功？"

许知意想了一下。

"材料递交了。街道办受理了。法律规定了我们有权拒绝交费。李主任给了名片，可以直接联系。"

"但不确定什么时候有结果。"老王说。

"对。不确定。"许知意说，"但这不重要。重要的是——我们做了。我们走了第一步。"

四个人站在街道办事处门口，互相看了一眼。

四个小时前，他们还在各自的家里。老王在十六栋三单元602，正在挨家挨户敲门要签名。张姐在十二栋1105，正在检查相机电量。赵阿姨在一栋1202，正在磨豆浆。许知意在十五栋601，正在打印举报材料。

四个小时后，他们站在同一个地方。刚刚完成了一件他们各自都以为"只有我在做"的事。

这不是巧合。这是系统制造的裂缝。裂缝里长出了东西。

张明华说，行动不是一个人做所有事。是让愿意做的人，把他们的力量汇集起来。

今天，他们把力量汇集了。

赵阿姨把布袋里的保温杯拿出来，一人分了一个。豆浆还是热的。杯壁烫手。

"喝了。"她说，"接下来还有的忙。"

许知意拧开杯盖，喝了一口。豆浆很甜。不是很甜。是一种很淡的、恰到好处的甜。

她把杯盖拧回去，把保温杯放进帆布包。

然后她拿出手机，在业主群里发了一条消息。

"材料已递交。街道办受理。三十个工作日出结果。期间大家有权拒绝交纳提高部分的物业费。有任何问题，直接联系我。"

消息发出去之后，群里安静了十秒。

然后有人回了一个"收到"。

然后是第二个"收到"。

第三个。第四个。第五个。

许知意看着这些"收到"。一个，两个，三个，四个，五个。

不是二十个。不是三十个。但够了。

这五个"收到"，代表着五户家庭。五户家庭代表着一百多个人。一百多个人代表着一种力量——不是暴力。不是威胁。是一种更稳的、更硬的、更长久的力量。

是"我知道了，我不接受"的力量。

许知意把手机收进口袋。她看了看身边的三个人。老王，张姐，赵阿姨。三个人也在看她。
