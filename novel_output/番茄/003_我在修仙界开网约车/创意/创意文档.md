# 《我在修仙界开网约车》创意文档

## 一句话简介

现代程序员穿越修仙界，靠开网约车接单升级，顺便收了剑仙和魔尊两个男人。

## 核心卖点

| 卖点 | 说明 |
| ---- | ---- |
| **现代梗反差** | 程序员思维做修仙生意：五星好评、会员制、差评申诉、拼车模式 |
| **系统流升级** | 载客=修为，网约车等级=修炼境界，读者有明确期待感 |
| **双男主修罗场** | 高冷路痴剑仙谢无妄 vs 霸道奶狗魔尊霍惊野，互相吃醋但不明说 |
| **创始人身份反转** | 女主不是普通穿越者，是系统创始人转世 |
| **修仙界交通革命** | 打破传送阵垄断，改变三界格局 |

## 对标作品

| 对标作品 | 借鉴点 |
| -------- | ------ |
| 《穿成恶毒女配后我开起了便利店》 | 现代思维降维打击古代 |
| 《我家系统又双叒叕抽风了》 | 系统吐槽搞笑 |
| 《剑尊今天吃醋了吗》 | 高冷男主反差萌 |

## 目标读者

女频读者，喜欢系统流、甜宠、搞笑、双男主修罗场、事业线+感情线并重。

## 核心钩子

- **开头3章**：程序员猝死穿越 + 绑定网约车系统 + 首单接到醉酒魔尊
- **持续钩子**：每章一个奇葩订单 + 修罗场升级 + 系统真相逐步揭示
- **长线悬念**：女主为什么是创始人转世？三百年前发生了什么？

## 差异化

市场上修仙网约车题材几乎没有。"网约车"是现代人最熟悉的日常概念，放在修仙界产生天然反差感，同时修仙交通（传送阵）确实是一个合理的商业痛点。
