# 第4章 五星好评的力量

林小满蹲在醉仙楼门口的台阶上，面前悬浮着半透明的系统面板。

面板上有三块区域。每块区域之间隔着一道细细的光线，跟手机App的分割线一个效果。

左边是修为面板。

【当前修为：376/500（练气一层）】

【下一境界：练气二层（需要500修为）】

【距离突破还需：124修为】

中间是订单面板。记录着她跑过的每一单、拿到的每一个评价，还有系统自动统计的好评率。

【已完成订单：3】

【好评率：100%】

【平均评分：5.0】

右边是背包面板。

【普通灵石：0】

【极品灵石：1】

【系统道具：无】

她把面板拉大，当数据仪表盘看。跟穿越前看的监控面板一个布局——左边核心指标，中间业务数据，右边资源状态。

"小灵，修为是怎么算的？"

"订单基础报酬 + 乘客打赏 + 评价加成 = 总修为收入。五星好评可触发1.2倍系数。"

"也就是说，如果乘客给了五星，我多拿20%？数据准确。那差评呢？"

"一星评价将扣除50%基础修为。连续三次差评，系统扣除宿主100修为作为惩罚。"

"差评扣修为？"林小满吹了声口哨，悬在面板上方的手指微微一顿，目光在面板上来回扫了两遍。她没急着说话，心里算了算概率——如果一星差评扣50%，连续三次就是150修为打水漂，再加上100点惩罚，足够把她打回练气一层。

"天行系统以订单质量为核心考核指标。数量不是唯一标准，质量同样重要。"

林小满点了点头。这套设计逻辑她认可。

"所以你鼓励我服务好每一个乘客，拿五星好评。"

"可以这么理解。"

她靠在台阶上，看着面板上的数据。

3单，全部五星。这是完美开局。

但完美不能当饭吃。3单全五星听起来漂亮，实际拿到手的修为加起来也就400点出头。离筑基还差十万八千里。

"小灵，我要怎么变强？"

"完成更多订单，积累修为，提升境界。"

"具体来说——我现在练气一层，到练气二层需要多少修为？"

"124修为。以当前订单平均收入估算，需要完成3-4单同等质量的订单。"

"三四单。"林小满掰了掰手指头，"一单十几二十里路，跑一趟来回半个时辰。一天跑十单，三天就能突破。"

她抬头看着面板上的数字，嘴角带着一丝笑意。

"理论可行。但需注意宿主灵力消耗上限。连续传送会导致灵力透支，建议每3单休息一个时辰。"

林小满脸上的笑意收敛了。

"你们系统还管疲劳驾驶？这规定是关心我还是怕我把你的传送精度搞砸？"

"天行系统关注宿主健康状况。灵力透支严重时，传送精度会下降15-30%，可能导致位置偏移。"

"位置偏移是什么意思？"

"原本应该传送到目的地门口，可能偏移到十丈外，甚至更高。"

林小满想起穿越前看过的那些疲劳驾驶事故报道，后背凉了一下。

"也就是说，我累了就可能把你传到人家房顶上？"

"从概率上来说，有此可能。"

林小满决定不挑战这个概率。

她从台阶上站起来，拍了拍裤子上的灰。台阶上落了一层细细的桂花花瓣，不知道是哪棵树飘下来的。东华城的早晨很安静，巷子里偶尔传来马蹄声和叫卖声。空气中飘着早点摊的香味——不是煎饼果子，是一种她没见过的面食，蒸笼里白汽冒出来，带着甜甜的桂花味。

"小灵，这地方有早市？"

"东华城城东有早市，每日辰时开市。"

"辰时是几点？"

"大约早上七点到九点。"

"那现在呢？"

"卯时三刻，约六点四十五分。"

林小满摸了摸肚子。

从穿越到现在，她没吃过东西。猝死前的最后一餐是办公室冰箱里的半盒寿司——现在想来那可能是她这辈子吃的最后一顿地球食物。

"我能买东西吃吗？"

"需要灵石。宿主当前拥有0灵石。"

"那极品灵石呢？"

"极品灵石属于高级货币，普通商户无法找零。建议先完成订单获得普通灵石后再购买食物。"

"也就是说我现在身上一分钱没有，连个包子都买不起。"

"数据准确。"

林小满盯着远处冒着白汽的蒸笼，目光挪不开。肚子适时地叫了一声。她穿越前没来得及吃晚饭，猝死的时候胃里只有半杯冷掉的咖啡。现在那杯咖啡早就代谢完了，胃里空空如也。

"行吧，先跑单。"

她低头看了看系统面板。

【新订单】

出发地：东华城·灵草堂
目的地：城南·王家巷
乘客：王大锤
距离：12里
预计传送耗时：1息
报酬：10-30修为

等等，这单不是刚接了吗？

"小灵，这单我接过了吧？"

"订单状态：已完成。当前无新订单。"

"那面板上怎么还显示？"

"系统面板刷新延迟。正在修复……修复完成。"

面板闪了一下，那个订单消失了。

林小满站在台阶上等。

一息。两息。三息。

十息过去了，没有新订单。三十息。林小满开始数巷子对面墙上的蚂蚁。

"小灵，订单呢？"

"当前区域需求较低，正在搜索附近可用订单……"

"搜索要多久？"

"无法确定。取决于区域内修仙者传送需求频率。"

"也就是说我现在要干等？"

"建议宿主利用等待时间熟悉东华城环境。"

林小满从台阶上走下来，光着脚踩在青石板上。脚底板已经不是黑的了——练气一层的灵力在皮肤表面形成了一层微弱的光膜，自动隔离了污垢。

"小灵，我脚不脏了？"

"练气一层灵力外溢，可形成基础防护层。宿主可感知周围环境中的灵力流动。"

她低头看了看脚底。确实，青石板上那些灰黑色的痕迹被一层淡淡的白光隔开了。等于穿了一双隐形鞋。

"那我不用买鞋了？"

"灵力防护层仅能隔离污垢，无法替代鞋子。筑基期以上可灵力凝物，但无修士会这么做——灵石能买到更好的鞋。"

林小满的嘴角抽了抽。今晚不跟这个系统说话了。

她在巷子里走了两步，试着感知灵力流动。小灵说练气一层能感知环境中的灵力——她闭上眼睛，集中注意力。

一开始什么反应都没有。

然后，很微弱地，她捕捉到了一丝暖意。从脚下的青石板传上来，沿着经脉往上走，到丹田位置停住了。

"那就是环境中的游离灵力。宿主可通过冥想吸收。"

"冥想怎么操作？"

"闭上眼，集中注意力于丹田，引导游离灵力进入经脉。"

林小满照着做了三分钟，双手搭在膝盖上保持打坐姿势，闭目凝神地感受着经脉中微弱的暖流流动。

"小灵，我怎么看不到进度条？"

"灵力吸收效率取决于天赋和境界。宿主当前练气一层，每小时可吸收约1点修为。"

"一小时一点？那我要吸到练气二层得——"

"约124小时，不眠不休。"

"那还不如跑单。"

"数据准确。完成一单同质量订单约需一刻钟，可获得10-30修为。效率约为冥想的20-60倍。"

林小满睁开眼睛，拍了拍手。

结论很明确了：跑单比冥想快得多。她不是来修仙的，她是来跑单的。把修仙当成打工，心态就不一样了——这不是什么逆天改命的奇遇，这是一份有KPI有绩效考核有差评扣款的工作。她是一个被系统绑定的网约车司机，不是传统修仙者。老老实实打坐不如多接几单。

她靠在巷子口的墙上，等订单。墙砖是青灰色的，摸上去凉凉的，表面有一层薄薄的灵力涂层。她用手指划了一下，涂层被蹭掉了一小块，露出里面粗糙的石面。

"东华城的建筑都有灵力涂层？"

"高级区域的建筑都有基础灵力防护。醉仙楼所在的一级区域防护等级最高。"

"那城墙呢？"

"东华城城墙由复合灵力阵法构成，可抵御金丹期以下修士的直接攻击。"

林小满把手缩了回来。金丹期以下都防不住，她一个练气一层的小司机还是老实待着比较好。

东华城的早晨越来越热闹。远处的街上传来马蹄声，小贩的吆喝声，讨价还价的声音。她听不太懂那些词——什么"聚气丹""凝元散""低阶灵符"——但大概能猜到是修仙界的日常用品。

这个世界有它自己的节奏。传送阵、灵石、修为、宗门、散修。她是一个异类，一个带着地球程序员思维闯进来的人。

但异类有异类的活法。

"小灵。"

"在。"
林小满翻开面前的系统面板，修为数据在面板上安静地跳动着。

"帮我算一笔账。"她伸出手，在空中比划着，仿佛在画一个Excel表格。

"请说。"

"按照目前每单平均30修为来算，我一天能跑多少单？一个月能攒多少？多久能到筑基？"

"以每日工作八个时辰计算，每小时完成2单，每单平均30修为——每日可获修为约480点。每月约14400点。从练气一层到筑基需要约124点，预计3日内突破练气二层。"

"三天练气二层。那筑基呢？"

"练气二层到筑基需要约500修为，以当前效率约需15日。"

十五天。林小满在心里盘算着，从零开始到筑基只需要半个月，这个速度放在地球上大概相当于从入职到升总监的节奏。

"半个月筑基。"林小满点了点头，"还行，比在地球上从P5升到P6快。"

"宿主所述P5、P6为何种境界？"

"你别管了。"

她笑了一下。她靠在巷子口的墙砖上，用手指蹭了蹭砖面上的灵力涂层，看着远处蒸笼冒出来的白汽发了会儿呆。

她正准备查看有没有新订单——面板忽然闪了一下，淡蓝色的光映在她脸上。

【新订单】

出发地：东华城·百味楼
目的地：城北·天机阁分坛
乘客：未知
距离：25里
预计传送耗时：2息
报酬：80灵石

"小灵，这个报酬怎么是灵石不是修为？"

"部分高价值订单以灵石作为报酬。灵石可在系统中以1:10比例转化为修为。"

"80灵石就是800修为？"

"数据准确。此订单质量较高。"

林小满的视线钉在"80灵石"四个字上，半天没挪开。

一单80灵石，顶之前三四单的总和。

"接。"

【订单已接受】

【正在规划传送路线……】

【路线规划完成。起点：百味楼门口。】

【请宿主前往起点位置。】

小箭头指向城西方向。

林小满从墙上直起身，光着脚踩上青石板，开始小跑。

百味楼。名字听着就是个好地方。能在东华城开酒楼的地方，档次都不会太低。

希望这次乘客不要又是一个喝醉的。

一个魔尊已经够她受的了。再来一个，她怕自己扛不住。
