# 主线结构

## 全书结构（40章试水版）

```
卷一：新手司机上线（1-40章）
  核心目标：活下来，开始接单，建立口碑
  核心冲突：零起步 → 天机阁初次注意到异常
  天机阁阶段：第一阶段（无视→注意）
  卷末状态：名声传开，天机阁主陆玄明亲自关注
  修为进度：练气一层 → 练气二层 → 筑基初期
  主节点：5个（M1开篇锚点、M2双男主同车、M3身份伏笔、M4中爽打脸、M5卷末悬念）
```
