# 世界观设定 V3（接单驱动型修仙引擎）

## 核心定义

```
修仙界 = 一个由"传送需求驱动"的动态订单生态
```

世界本身在不断产生订单，而不是"世界里有系统"。系统是订单生态的接入端口。

---

## 一、世界的本质

修仙界是一个被"传送需求"驱动的世界：
- 修士需要移动（寻宝、求道、逃命、交易）
- 但移动被垄断——天机阁控制所有传送阵
- 垄断造成低效、腐败、权力寻租
- 系统出现 = 绕过垄断 = 世界开始重构

**本质故事**：不是修仙故事，是**平台经济打垄断**的故事。

---

## 二、天行系统的真正杀招

天行系统最可怕的能力不是传送，而是：

```
它可以绕开"现有世界规则"
```

| 天机阁（垄断方） | 天行系统（平台方） |
| --------------- | ----------------- |
| 固定传送阵 | 动态路径 |
| 权力审批 | 自动接单 |
| 资源垄断 | 流量分配 |
| 人情规则 | 评分规则 |

**核心冲突**：控制稳定 vs 自由效率

## 三、订单生成系统（剧情引擎）

### 订单5大来源（剧情源头）

| 类型 | 来源 | 爽点 |
| ---- | ---- | ---- |
| ① 生存订单 | 散修逃命、被追杀、紧急撤离 | 救命+反杀 |
| ② 利益订单 | 运送资源、抢夺灵脉、商业竞争 | 资源碾压 |
| ③ 权力订单 | 宗门调动、战争部署、核心人物转移 | 权力介入 |
| ④ 禁忌订单 | 偷渡仙界、进入冥界、运送禁物 | 规则突破 |
| ⑤ 因果订单 | 与三百年前事件相关、与前世记忆相关 | 世界观解锁 |

### 每一单的标准剧情结构

```
接单 → 发现异常 → 冲突升级 → 利用系统反转 → 评价结算 → 影响世界
```

**每一单 = 一次"规则被撬动"**

## 六、陆玄明：旧系统守门人

**不是背叛者，是秩序守护者。**

### 他的逻辑
- 传送必须被控制
- 否则三界会崩
- 他的天机阁不是贪婪，而是责任

### 女主的逻辑
- 传送应该自由
- 效率优先
- 系统天然正义

### 核心冲突
```
控制稳定 vs 自由效率
```

**最终结局**：不是打败他，而是说服他——自由传送不会毁灭世界。

## 七、爽点流水线（工业级）

### 每10章必须有

| 类型 | 触发条件 | 爽点 |
| ---- | -------- | ---- |
| 小爽 | 一单完成 | 客户震惊 |
| 中爽 | 影响一个势力 | 格局扩大 |
| 大爽 | 改变规则 | 绕开天机阁 |
| 爆点 | 揭露系统秘密/前世信息 | 世界观解锁 |

### 爽点公式

```
爆点 = 压抑值 × 认知反差 × 社会场景公开性
```

## 八、三阶段剧情规划

### 第一阶段（1-50章）：市场占领
- 跑单升级，从散修到宗门
- 建立口碑和服务差异化
- 天机阁无视

### 第二阶段（50-150章）：格局颠覆
- 宗门开始用系统
- 垄断崩溃初现
- 陆玄明注意到主角

### 第三阶段（150+章）：规则重构
- 三界传送权战争
- 系统真实身份揭露
- 主角成为规则制定者

## 十二、三百年前的秘密（伏笔主线）

**创始人**：林小满前世，来自现代世界，创造了天行系统

**封印事件**：三百年前，三界通道暴走，创始人封印天行大阵，系统被封存

**陆玄明**：创始人最信任的弟子，创始人的理念是"传送应该自由"，但他走上了"必须控制才能稳定"的路

**天机阁**：陆玄明建立，用垄断维持稳定，等待创始人转世

**女主的使命**：不是重建系统，而是证明——自由传送不会毁灭世界
