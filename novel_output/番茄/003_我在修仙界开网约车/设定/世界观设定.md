## 核心系统：修仙界网约车

**系统名称**：天行系统（创始人：林小满前世）

**系统AI**：小灵

**核心规则**：
- 接单 = 获得修为
- 好评 = 额外奖励（修为/灵石/道具）
- 差评 = 扣除修为10%
- 连续差评 = 系统惩罚
- 完成里程碑 = 解锁新功能（拼车、VIP、跨界面等）

**系统功能解锁路径**：
| 等级 | 解锁功能 |
| ---- | -------- |
| 练气一层 | 基础传送 |
| 练气二层 | 拼车模式 |
| 练气三层 | VIP私密订单 |
| 筑基 | 跨城传送 |
| 金丹 | 跨界面传送 |
| 元婴 | 司机招募 |

## 三百年前的秘密（伏笔）

**创始人**：林小满的前世，来自同一个现代世界。

**创始之碑**：古神遗迹中的石碑，刻有创始人的手书。

**封印事件**：三百年前，创始人封印了"天行大阵"，阻止了三界通道暴走。随后系统被封存。

**陆玄明的背叛**：创始人最信任的弟子陆玄明，在封印完成后试图掌控系统，被创始人反制。他因此产生了"必须掌控系统才能保护世界"的执念。

**天机阁垄断**：陆玄明发现传送阵技术后，建立天机阁垄断修仙界交通，等待创始人转世出现。
