# 角色档案

## 林小满（女主）

| 维度 | 设定 |
| ---- | ---- |
| **身份** | 现代程序员（26岁）→ 修仙界网约车司机 |
| **外貌** | 中等身材，长相不惊艳但耐看，黑色短发（穿越后变长），眼睛亮得像屏幕反光 |
| **性格** | 乐观嘴碎，爱钱但有底线，遇到危险先吐槽再冷静，社畜思维根深蒂固 |
| **金手指** | 天行网约车系统（载客=修为） |
| **核心动机** | 赚钱→变强→发现真相→改革修仙界交通 |
| **口头禅** | "亲～""给个五星好评哦～""这个需求不合理" |
| **矛盾特质** | 表面爱钱，但遇到真正需要帮助的人会免费接单（程序员"修bug强迫症"延伸到修仙界） |
| **对话风格** | 短句为主，夹杂互联网黑话和程序员梗，遇到紧张时反而更贫嘴 |
| **成长弧线** | 社畜打工心态 → 主动创业者 → 三界交通改革者 |

## 谢无妄（男主）

| 维度 | 设定 |
| ---- | ---- |
| **身份** | 昆仑剑宗第一剑仙，修仙界最强战力 |
| **外貌** | 白衣如雪，面容冷峻俊美，剑眉星目，气质高冷到让人不敢靠近 |
| **性格** | 高冷寡言，但方向感极差（路痴），对认定的事极其执着 |
| **能力** | 修仙界第一战力，但不会认路（天生缺陷，与修为无关） |
| **核心动机** | 斩妖除魔→保护林小满→表白 |
| **矛盾特质** | 高冷外表下极度害羞——被林小满直视会耳红但绝不承认 |
| **对话风格** | 极简主义，能一个字说完绝不说两个字。"嗯。""走。" |
| **吃醋表现** | 不说话，默默在订单里多打赏，频率从三天一次变成一天三次 |

## 霍惊野（男二）

| 维度 | 设定 |
| ---- | ---- |
| **身份** | 魔界之主，万魔殿主人 |
| **外貌** | 红衣如火，容貌妖冶俊美，气质霸道危险 |
| **性格** | 霸道专一，清醒时高冷霸道，喝醉后变撒娇奶狗 |
| **能力** | 魔界资源无限，实力仅次于谢无妄 |
| **核心动机** | 征服林小满→为爱放手→默默守护 |
| **矛盾特质** | 魔尊身份却最怕孤独——醉酒时的撒娇才是真心 |
| **对话风格** | 清醒时霸道放狠话"女人你逃不掉的"，喝醉时变成"姐姐陪我～" |
| **放手时刻** | 第二卷末："姐姐，我可能真的要放手了。" |

## 系统小灵（AI配角）

| 维度 | 设定 |
| ---- | ---- |
| **身份** | 天行网约车系统AI |
| **性格** | 爱吐槽，数据控，偶尔说出"不该知道的过去的事" |
| **核心动机** | 完成任务→产生情感→为主角冒险 |
| **口头禅** | "宿主，从数据分析来看……""抱歉，数据损坏。" |
| **隐藏身份** | 创始人（林小满前世）留下的AI分身，携带创始人的记忆碎片 |

## 苏小棠（配角）

| 维度 | 设定 |
| ---- | ---- |
| **身份** | 青云宗小师妹 |
| **性格** | 天真八卦，追星体质，行动力强 |
| **作用** | 女主的八卦情报网、粉丝、得力助手 |
| **隐藏身份** | 大佬转世（第三卷揭示） |

## 陆玄明（反派）

| 维度 | 设定 |
| ---- | ---- |
| **身份** | 天机阁阁主，三百年前创始人亲传弟子 |
| **性格** | 高傲、偏执、深情但方向错误 |
| **核心动机** | 找到创始人转世，掌控系统（自认为是"保护"） |
| **矛盾** | 对创始人有执念，看到女主时会不自觉流露出温柔与疯狂交织的复杂情绪 |
| **转变** | 最终被女主说服，放下执念，协助修复三界结界 |

## 楚天歌（次要反派）

| 维度 | 设定 |
| ---- | ---- |
| **身份** | 天机阁传送阵负责人 |
| **性格** | 傲慢商人，精于算计 |
| **作用** | 前期与女主的直接竞争者，价格战、差评操纵 |
| **结局** | 被陆玄明抛弃后，转投女主阵营 |
