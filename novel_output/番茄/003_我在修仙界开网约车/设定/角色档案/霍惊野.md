# 霍惊野（男二）

## 基本信息

| 字段 | 内容 |
| --- | --- |
| 身份 | 魔界之主，万魔殿主人 |
| 外貌 | 红衣如火，容貌妖冶俊美，气质霸道危险 |
| 性格 | 清醒时霸道锐利，醉酒后变撒娇奶狗 |
| 能力 | 魔界顶级战力，实力仅次于谢无妄 |

## 矛盾特质

- 霸道外表下对女主有"投资"心态——不是占有，而是期待
- 清醒时高冷，醉酒后奶狗——双重人格反差
- 知道女主是创始人转世，但选择不直接说破，而是用行动表达

## 核心设定

- 核心动机：找到创始人转世→验证她是否是那个人
- 对话风格：霸道直接，偶尔说挑衅的话
- 吃醋表现：暗中增加订单频率，用"投资"名义给女主资源
- 万魔殿令牌：第10章赠予女主，作为在魔界的通行保障
- 关键台词："你知道你是谁吗？"（第7章）/ "我看好你。"（第10章）
