# 深夜公墓乘客 — 世界观与设定

## 故事背景

- **地点**：江城（虚构城市）
- **时间**：现代
- **时间线**：深夜至凌晨为主要叙事时段

## 主角设定

### 主角（网约车司机）
- **身份**：网约车夜班司机
- **背景**：普通打工人，因经济压力选择夜班
- **特点**：
  - 理性务实，相信科学
  - 但逐渐被卷入无法解释的事件
  - 第一人称视角

## 力量体系

无超自然力量，纯悬疑推理向：
- 主角依靠观察力、逻辑推理
- 信息差是核心博弈工具
- 行车记录仪、手机、论坛等现代工具

## 关键地点

| 地点 | 作用 |
|------|------|
| 西郊公墓 | 故事起点，神秘事件核心 |
| 精神卫生中心 | 赵医生所在地 |
| 出租车公司 | 行业背景交代 |
| 储物柜 | 线索中转站 |
| 废弃精神病院 | 重要转折点 |
| 深夜电台 | 信息获取渠道 |

## 核心道具

- 行车记录仪（关键证据来源）
- 手机（订单记录、通讯）
- 储物柜钥匙（线索道具）
- 录音设备（证据收集）
