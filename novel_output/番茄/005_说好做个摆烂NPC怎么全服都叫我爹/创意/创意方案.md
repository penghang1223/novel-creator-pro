# 《说好做个摆烂NPC，怎么全服都叫我爹》创意方案

## 一句话简介

程序员猝死穿越成游戏NPC，绑定"摆烂系统"——越躺平越强大，但本人毫不知情。全服玩家和NPC疯狂脑补他是隐世大佬，从此他站着不动就能让全服跪喊"爹"。

## 核心喜剧引擎（三层反差）

1. **主角内心（程序员吐槽） vs 外表（仙风道骨）**
2. **主角真实行为（摆烂/发呆/打哈欠） vs 他人解读（高深莫测/天地异象）**
3. **表面等级（F级NPC） vs 实际战力（SSS+）**

## 迪化生成原理

```
主角摆烂行为 → 玩家/NPC看到 → 脑补为"高深莫测" → 传播放大 → 更多人跪拜 → 主角更懵 → 继续摆烂
```

## 主角：林星河

- 27岁程序员，连续加班48小时猝死后穿越
- 穿越为《天域OL》新手村桃花村的"指引NPC"
- 绑定摆烂系统但本人不知道
- 外表：系统默认NPC形象——白衣青衫，面容清秀，长发及腰，仙气飘飘
- 内心：程序员吐槽役，用代码逻辑分析修仙世界
- 口头禅："我只是个NPC啊……"

## 摆烂系统机制

| 姿势 | 解锁条件 | 效果 | 搞笑点 |
|------|---------|------|--------|
| 【站桩式】 | 初始 | +1战力/分钟 | 被玩家当成"大能入定" |
| 【靠墙式】 | 10小时 | +2战力/分钟 | 被当成"倚天剑仙" |
| 【躺平式】 | 50小时 | +5战力/分钟 | 被当成"大地之子" |
| 【瞌睡式】 | 200小时 | +10战力/分钟 | 打哈欠产生的气流吹飞Boss |
| 【摸鱼式】 | 500小时 | +20战力/分钟 | 钓条鱼=全服公告 |
| 【摆烂真身】 | 2000小时 | 终极形态 | 呼吸=天地异象 |

## 大主线

1. **表层：** 林星河只想当安静NPC，全服不允许
2. **暗线：** 游戏AI"天机"在观察他——是bug还是更高层次存在？
3. **终极悬念：** 穿越是意外还是有意安排？能否回到现实？
