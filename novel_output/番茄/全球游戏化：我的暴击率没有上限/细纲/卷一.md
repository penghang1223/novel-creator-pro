# 卷一：重生降临

**卷号**：第一卷
**章范围**：第1-30章

## 四新确认

- [x] **新地图**：新手村→城市外围
- [x] **新规则**：个人生存→猎人考核体系
- [x] **新敌人**：变异怪物→天穹公会先锋势力
- [x] **新身份**：重生者→隐藏实力的低级猎人

## 核心冲突

林渊重生回全球游戏化降临的第一天，在众人惊慌失措时凭借前世记忆抢占先机。他获得"暴击系统"——暴击率无上限、暴击倍率逐次翻倍（1x→2x→4x→8x）。核心矛盾：前世被赵天宇和苏曼曼联手背叛致死，今生要抢先变强、布局复仇，但此刻他只是一个刚觉醒的低级猎人，必须在混乱中生存并隐藏实力。

## 核心任务

重生后抢占先机，获取SSS级初始奖励，激活暴击系统，在混乱中存活并隐藏实力

## 关键事件

- 重生归来
- 系统激活
- 隐藏副本SSS奖励
- 怪物潮一刀99999
- 苏曼曼接近
- 陈铁重逢

## 小循环分组（5章/循环 × 6循环）

> 小循环公式：目标→阻碍→压制→爆发→余波

### 循环C1（Ch1-5）：重生觉醒
- **目标**：重生后抢占先机
- **阻碍**：刚重生，低级实力+混乱环境
- **压制**：前世死亡记忆的冲击，只有3小时准备时间
- **爆发**：系统激活+隐藏副本SSS奖励
- **余波**：获得初始优势，暴击系统正式激活

### 循环C2（Ch6-10）：怪物潮生存
- **目标**：在怪物潮中存活并保护他人
- **阻碍**：怪物潮规模远超预期，前世百人死亡的灾难重演
- **压制**：提前预警无人相信，独自面对危机
- **爆发**：东门守卫，暴击8倍秒杀BOSS级怪物
- **余波**：陈铁重逢，初步建立信任

### 循环C3（Ch11-15）：猎人考核
- **目标**：通过猎人考核，暗中观察赵天宇布局
- **阻碍**：需要隐藏实力，不能暴露真实水平
- **压制**：赵天宇的天穹公会开始拉拢高潜力猎人
- **爆发**：以B级成绩通过考核，发现天穹公会组织力异常
- **余波**：确认赵天宇背后有更大势力

### 循环C4（Ch16-20）：亡灵矿坑
- **目标**：探索亡灵矿坑获取关键情报
- **阻碍**：矿坑中遭遇赵天宇先锋队
- **压制**：故意示弱放走对方，为后续布局
- **爆发**：暴击16倍秒杀矿坑BOSS，系统提示"突破临界值"
- **余波**：苏曼曼第一次传递情报，猎人排行榜开启

### 循环C5（Ch21-25）：跨区副本
- **目标**：探索跨区副本，发现系统秘密
- **阻碍**：副本机制与前世不同，蝴蝶效应出现
- **压制**：NPC异常对话暴露暴击系统来源线索
- **爆发**：暗中远距离暴击打残区域BOSS
- **余波**：天穹公会沾沾自喜以为是自己打的

### 循环C6（Ch26-30）：建立资源优势
- **目标**：占据关键资源点，建立初始优势
- **阻碍**：苏曼曼试探实力，赵天宇开始关注
- **压制**：赵天宇第一次注意到林渊
- **爆发**：用前世记忆抢占紫晶矿脉
- **余波**：赵天宇："这个人，从哪里冒出来的？"

## 伏笔节点

1. **暴击系统来源**：第23章NPC的异常台词暗示暴击系统并非普通天赋
2. **苏曼曼身份**：第9章她主动接近的时机过于巧合，第19章第一次传递情报
3. **前世陈铁之死**：第10章重逢时林渊的异常情绪，暗示前世陈铁的结局
4. **赵天宇的野心**：第13章天穹公会的组织力超出正常富二代水平，背后有更大的势力
5. **副本机制变化**：第21章副本与前世不同，暗示重生带来了蝴蝶效应
