# 卷三：暗流涌动

**卷号**：第三卷
**章范围**：第61-90章

## 四新确认

- [x] **新地图**：城市全域→影兽巢穴
- [x] **新规则**：团队作战→势力对抗
- [x] **新敌人**：影兽→影盟（幕后组织浮出水面）
- [x] **新身份**：揭穿间谍后的赵天宇公开对手

## 核心冲突

苏曼曼的间谍身份彻底暴露，林渊完成对她的反杀。同时"影盟"（Shadow Society）——一个隐藏在各大公会背后的神秘组织浮出水面，赵天宇的天穹公会不过是影盟的前台。林渊发现自己前世的死亡不只是赵天宇个人的背叛，背后有更深层的阴谋。赵天宇第一次认真对待林渊这个对手。

## 核心任务

揭穿苏曼曼真面目，与赵天宇正式对抗，暴击领域觉醒

## 关键事件

- 揭穿苏曼曼
- 赵天宇宣战
- 暗影会曝光
- 暴击领域觉醒
- 排行榜争夺白热化

## 小循环分组（5章/循环 × 6循环）

> 小循环公式：目标→阻碍→压制→爆发→余波

### 循环C1（Ch61-65）：苏曼曼陷阱
- **目标**：反向利用苏曼曼设局
- **阻碍**：苏曼曼发现零队实力远超情报，加大传递频率
- **压制**：故意暴露假弱点，引诱赵天宇围剿
- **爆发**：零队被"逼入绝境"，实则蓄势待发
- **余波**：围剿部队进入陷阱区

### 循环C2（Ch66-70）：揭穿间谍
- **目标**：当众揭穿苏曼曼，打击天穹公会声望
- **阻碍**：苏曼曼试图以感情牌求饶
- **压制**：赵天宇震怒（不是因为苏曼曼，而是因为布局被看穿）
- **爆发**：林渊当众揭穿："你的汇报频率，每周三和周日"
- **余波**：苏曼曼被逐出，猎人论坛曝光

### 循环C3（Ch71-75）：赵天宇试探
- **目标**：应对赵天宇的正式试探
- **阻碍**：赵天宇亲自约见，表面"误会可以谈"
- **压制**：被真正情报力量盯梢
- **爆发**：对话中林渊句句诛心，带着跟踪者兜了三天
- **余波**：影盟第一次被提及

### 循环C4（Ch76-80）：深渊裂隙+影兽
- **目标**：探索第二次深渊裂隙，对抗影兽
- **阻碍**：裂隙规模比第一次大十倍，影兽不属于任何图鉴
- **压制**：影兽被影盟暗中操控，数量庞大
- **爆发**：暴击128倍斩杀影兽首领
- **余波**：获得"影盟印记"，与系统核心碎片有共鸣

### 循环C5（Ch81-85）：影盟监控
- **目标**：研究影盟印记，应对影盟监控
- **阻碍**：影盟已经在监控林渊的暴击数据
- **压制**：系统弹出警告"共鸣度23%，注意隐藏"
- **爆发**：周芸觉醒"净化之光"，零队积分飙升到第8名
- **余波**：赵天宇私下联系影盟请求"处理掉林渊"

### 循环C6（Ch86-90）：暗中蓄力
- **目标**：隐藏实力，暗中招募新成员
- **阻碍**：影盟回应"此人暴击数据异常，继续观察"
- **压制**：系统层面的监视越来越紧
- **爆发**：招募两名前世死于赵天宇之手的潜力猎人
- **余波**：回忆前世死亡——"这一世，每一步都不同了"

## 伏笔节点

1. **影盟的真正目的**：第75-76章首次出现，操控猎人公会的目的不明
2. **系统共鸣度警告**：第87章暴击系统提示"注意隐藏"，暗示系统本身有意识
3. **影兽与系统核心**：第81-82章影盟印记与系统核心碎片共鸣，两者同源
4. **周芸的隐藏天赋**：第83章"净化之光"对影兽特效，暗示她与系统核心有关联
5. **赵天宇与影盟的关系**：第85章赵天宇需要请求影盟，说明他并非影盟高层
