# 卷四：势力争锋

**卷号**：第四卷
**章范围**：第91-120章

## 四新确认

- [x] **新地图**：控制区→公会战战场
- [x] **新规则**：势力对抗→公会战争
- [x] **新敌人**：天穹公会+影兽军团
- [x] **新身份**：区域守护者候选人

## 核心冲突

猎人世界进入势力割据阶段，大型公会之间的战争全面爆发。林渊的零队从中型势力跃升为不可忽视的力量，直接挑战天穹公会的霸主地位。同时，陈铁前世的记忆碎片开始觉醒——他隐约记起自己曾为保护林渊而死的画面。赵天宇不再把林渊当小角色，开始调动力量全面打压。

## 核心任务

大规模公会战，扩大势力范围，暴击崩解觉醒

## 关键事件

- 大规模公会战
- 陈铁前世回忆揭露
- 赵氏内部分裂苗头
- 暴击崩解觉醒

## 小循环分组（5章/循环 × 6循环）

> 小循环公式：目标→阻碍→压制→爆发→余波

### 循环C1（Ch91-95）：公会联盟大会
- **目标**：争夺区域守护者名额
- **阻碍**：赵天宇公开反对，投票中微弱劣势落选
- **压制**：赵天宇赢了面子
- **爆发**：提前布局让支持者拿下另外两个区域
- **余波**：赵天宇赢了面子却输了里子

### 循环C2（Ch96-100）：公会战第一阶段
- **目标**：守住控制区
- **阻碍**：天穹联合两大公会围攻零队
- **压制**：零队利用地形和陷阱拖延
- **爆发**：暴击连锁觉醒，战场清屏（第100章里程碑）
- **余波**：联盟军撤退

### 循环C3（Ch101-105）：陈铁记忆觉醒
- **目标**：巩固战果，应对陈铁异常
- **阻碍**：陈铁战后昏迷，前世记忆碎片涌来
- **压制**：林渊意识到蝴蝶效应影响到他人
- **爆发**：零队守住控制区，猎人论坛炸锅
- **余波**：陈铁醒来——"我好像梦到过这件事"

### 循环C4（Ch106-110）：双生裂隙
- **目标**：探索双生裂隙，确认暴击唯一性
- **阻碍**：BOSS能复制猎人技能
- **压制**：BOSS复制了暴击技能
- **爆发**：暴击倍率不可复制，512倍秒杀，唯一性确认
- **余波**：赵天宇获得影兽军团控制权

### 循环C5（Ch111-115）：反抗联盟
- **目标**：组建反抗联盟对抗赵天宇影兽军团
- **阻碍**：赵天宇武力收编中小公会
- **压制**：影兽军团实力暴增
- **爆发**：周芸净化之光能切断影兽控制链接
- **余波**：制定"断链计划"

### 循环C6（Ch116-120）：巅峰碰撞
- **目标**：执行断链计划，正面挑战赵天宇
- **阻碍**：赵天宇全力应战
- **压制**：影兽军团三分之一反噬但仍强大
- **爆发**：1024倍暴击vs赵天宇全力一击，半城毁灭
- **余波**：影盟："我们知道"——赵天宇确认林渊是重生者

## 伏笔节点

1. **陈铁前世记忆觉醒**：第104-106章，重生的蝴蝶效应影响到了他人
2. **暴击系统唯一性**：第109-110章，暴击系统不可复制，暗示它是系统级别的存在
3. **影盟知道重生**：第120章影盟的回应暗示他们对"重生者"有了解甚至有经验
4. **周芸净化之光的来源**：第114章她的能力与影兽相克，可能与系统核心有关
5. **赵天宇的真实实力**：第119章能与1024倍暴击平手，他的力量来源不简单
