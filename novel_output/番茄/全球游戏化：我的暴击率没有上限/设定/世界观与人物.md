# 全球游戏化：我的暴击率没有上限 设定

## 世界观

### 核心设定
某一天，全球所有人同时收到系统提示——"全球游戏化启动"。现实世界变成游戏化世界：怪物从虚空中诞生，人类觉醒猎人天赋，等级、技能、装备、副本成为新的生存法则。

### 社会结构变化
- **游戏化前**：现代社会，资本、学历、人脉决定地位
- **游戏化后**：猎人等级成为新的社会阶层。S级猎人地位超越亿万富翁，普通人沦为底层
- **过渡期**：最初的1-2周是混乱期，政府勉强维持秩序，猎人公会逐渐接管部分管理职能

### 核心场景
- 江城：新一线城市，游戏化后成为东部猎人重镇
- 猎人公会：接任务、评级、交易的中心
- 副本入口：散布在城市各处，难度从E到SSS
- 地下竞技场：灰色地带，暗中博弈

### 术语表
| 术语 | 含义 |
|------|------|
| 猎人 | 觉醒天赋的人类，可进入副本、击杀怪物获取经验 |
| 天赋 | 游戏化时觉醒的初始能力（火系、重装战士、治愈系等） |
| 系统 | 绑定在个人身上的辅助系统，提供属性面板、技能树、背包 |
| 副本 | 独立空间，内有怪物和Boss，通关可获得装备/经验/金币 |
| 暴击率 | 攻击触发暴击的概率，暴击伤害=基础伤害×暴击倍数 |
| 暴击倍数 | 暴击时的伤害倍数，林渊的系统每次暴击后翻倍 |
| 公会 | 猎人自组的团队组织，可接高级团队任务 |
| 猎人公会 | 官方管理机构，由系统生成，负责猎人注册和任务发布 |

## 金手指规则

### 暴击系统
- **来源**：重生者专属隐藏系统，游戏化降临时自动绑定
- **核心机制**：暴击率无上限 + 暴击倍数每次翻倍
- **倍数重置**：离开战斗30分钟后重置为1x
- **体力消耗**：倍数越高消耗越大，但可以通过升级和装备减轻
- **特殊效果随等级解锁**：暴击回响（回血）、暴击连锁（AOE）、暴击领域（光环）、暴击崩解（秒杀）
- **不可被检测、偷取、复制**：重生者的专属属性
