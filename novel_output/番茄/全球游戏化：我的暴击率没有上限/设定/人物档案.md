## 一、林渊（主角）

### 四维动机模型

| 维度 | 内容 |
|------|------|
| **欲望** | 证明自己不是废物——这辈子要站在顶端，让前世看不起他的人闭嘴 |
| **恐惧** | 重蹈覆辙：再次被信任的人从背后捅刀。深层恐惧是"我果然不配被真心对待" |
| **创伤** | 前世被苏曼曼潜伏两年取得信任，最终在关键副本中被背刺，赵天宇亲手终结他。死前看到两人相拥的画面——不是愤怒，是"我怎么这么蠢" |
| **缺陷** | 过度防备（一朝被蛇咬）——对所有人留三分，可能错过真心想帮他的人；内心深处自卑（觉得自己就是底层命，系统只是运气） |

**内部冲突**：
- 欲望 vs 恐惧 = 想组建队伍变强，但不敢信任任何人
- 欲望 vs 缺陷 = 想站在顶端，但内心觉得自己"不配"
- 创伤 → 恐惧 = 前世的背叛导致今生对亲密关系的回避

**动机→行为链条**：
```
被背叛致死（创伤）→ 怕再次被捅刀（恐惧）→ 对所有人冷淡防备（行为模式）
→ 独狼作风，拒绝组队（缺陷）→ 想变强但缺乏队友配合（欲望受阻）→ 内心矛盾
```

### 现实锚点（游戏化前）

- **职业**：外卖骑手，日均跑40-50单，月入6000-9000（看单量和天气）
- **为什么是骑手**：二本毕业后干过一年程序员，996扛不住+公司裁员，找不到下一份工作只能先跑外卖过渡。"先跑着，找到工作就辞"——一跑就是半年
- **居住**：城中村合租房，月租1000，和陈铁合租
- **家庭**：父母在老家三线城市，父亲开小五金店，母亲做家政。普通家庭，无背景
- **日常**：早7点出门，跑到晚9点。回家后刷手机、偶尔打游戏。存款不到2万
- **代入感设计**：读者打开外卖app就能看到林渊这样的人——穿着黄/蓝制服骑电驴，在城中村和写字楼之间穿梭

### 角色弧线（复合弧线）

| 阶段 | 卷范围 | 内在状态 | 外在表现 |
|------|--------|----------|----------|
| **初始** | 卷一 | 封闭、防备、"谁都别靠近我" | 独狼刷怪，拒绝一切组队邀请 |
| **动摇** | 卷二 | 陈铁的无条件信任让他不适应 | 开始默许陈铁跟在身边 |
| **冲突** | 卷三-四 | 苏曼曼再次出现，创伤被激活 | 冷酷对待苏曼曼，但内心并非无感 |
| **低谷** | 卷五 | 某次因防备过度伤害了真心对他的人 | 孤立无援的至暗时刻 |
| **解冻** | 卷六 | 意识到"防备所有人=惩罚自己" | 开始真正接纳零号小队成员 |
| **蜕变** | 卷七 | 从"不信任任何人"到"选择性信任" | 愿意为队友冒险，但依然不天真 |
| **终局** | 卷八 | 接受自己值得被真心对待 | 建立真正的团队，而非独狼 |

### 行为指纹

- 重生后表面平静，但对每个前世认识的人都先暗中观察再下判断
- 战斗时冷静计算暴击倍数，不是无脑莽——骑手生涯练出的路线规划能力在副本中变成了战术直觉
- 对陈铁不设防（只有这个人前世到死都站在他身边）
- 对陌生人默认冷淡，但不会主动伤害
- 独处时偶尔发呆——不是回忆仇恨，是在想"如果前世没有遇到苏曼曼，会不会不一样"
- **标志动作**：思考时会无意识地用手指敲击桌面（骑手等单时养成的习惯）

### 声纹档案

- 句式偏短，不爱废话——"行""随便""你定"
- 口头禅："无所谓"（表面淡定，实际是自我保护机制）
- 对仇人：语气平淡到可怕，越平静越危险
- 对陈铁：正常兄弟聊天，偶尔互损，"铁子你脑子是不是被杠铃砸过"
- 独白风格：第一人称简短利落，不自怨自艾

### OOC禁止清单

- ❌ 不会在不了解对方立场时就掏心掏肺
- ❌ 不会在公开场合暴露系统能力细节
- ❌ 不会对苏曼曼产生真正的感情（前世记忆太深，即使她有苦衷也无法原谅）
- ❌ 不会突然圣母——复仇是核心驱动力，但不会滥杀无辜
- ❌ 不会放弃陈铁——这是他唯一无条件信任的人

### 游戏体系定位

| 维度 | 设计 |
|------|------|
| **天赋类型** | 暴击系统（重生者专属隐藏系统，不在常规天赋体系内） |
| **战斗定位** | 高爆发单体输出，不适合群战持久战 |
| **技能树方向** | 暴击倍数→暴击回响(吸血)→暴击连锁(溅射)→暴击领域(光环)→暴击崩解(概率秒杀) |
| **装备倾向** | 轻甲/敏捷型（骑手习惯速度和灵活性，不喜欢笨重装备） |
| **战斗风格** | 数据流+战术流——精确计算倍数+利用地形路线（骑手直觉），不是无脑莽 |
| **数值控制** | 倍数指数增长但有体力消耗限制（50倍以上需咬牙硬撑）+ Boss暴击抵抗 + 离战30分钟重置 |

**防单机化设计**：
- 独狼弧线不等于单机——林渊可以在"不信任人"的同时"利用其他人"
- 卷二起必须有与公会/其他猎人的互动线（竞争首杀、公会战、排行榜争夺）
- 林渊的重生记忆让他知道"哪些势力未来会壮大"，可以有策略地接触/利用
- 零号小队只是核心圈，外围需要有竞争者/合作者/中立势力

**首杀/首通情节锚点**：
- 卷一：前世被别人抢走的SSS级初始隐藏副本首通——今世抢回
- 卷二：某个前世没人打通的副本首通——确立声望
- 后续：每个关键副本的首通/首杀都是林渊证明自己的节点

## 二、赵天宇（S级终极反派）

### 反派设计（S级·黑暗镜像）

**反派公式**：强度 = 动机合理性(9) × 能力匹配度(9) × 行为一致性(9) × 主角关联度(10) = S级

| 维度 | 设计 |
|------|------|
| **核心动机** | 证明自己配得上"赵"这个姓氏——他爸赵明远一辈子没认可过他 |
| **核心信念** | "所有人都可以被操控，区别只在于用什么筹码" |
| **恐惧来源** | 被遗忘、被证明是"废物"——赵明远曾当着董事会说过"你不如我" |
| **能力边界** | 智商极高、资源碾压、政治手腕强。但缺乏真正的战斗天赋（暗系掌控者偏辅助/控制，不是正面硬刚型） |
| **致命弱点** | 傲慢——从心底看不起"底层"，认为林渊不配当对手；对父亲认可的渴望让他在关键时刻会做出情绪化决策 |

### 与林渊的镜像关系

- **镜像对立**：林渊从底层往上爬（骑手→最强猎人），赵天宇从顶层往下控制（财阀→想成"神"）。两人都想"证明自己"，但方式完全相反
- **核心信念对立**：林渊→"实力+忠诚才是力量"，赵天宇→"控制+恐惧才是力量"
- **戏剧张力**：林渊前世死在赵天宇手里不是因为实力不够，而是因为信任了不该信任的人。今生赵天宇在资源上依然碾压林渊，但林渊有暴击系统+重生信息

### 四维动机模型

| 维度 | 内容 |
|------|------|
| **欲望** | 成为超越规则的存在——不仅是财阀继承人，而是游戏化世界的"神" |
| **恐惧** | 被证明只是个靠爹的废物，失去一切掌控权 |
| **创伤** | 赵明远从不认可他——从小被当作"接班人"培养，但从未被当作"儿子"爱过。成年后赵明远在董事会上当众说"你还不够格" |
| **缺陷** | 傲慢+无法信任任何人（因为他自己就是靠操控别人上位的，所以认为所有人都是棋子） |

**内部冲突**：
- 欲望 vs 恐惧 = 想成"神"，但怕失败后连现有的一切都失去
- 创伤 → 缺陷 = 父亲的否定让他无法建立真正的信任关系
- 欲望 vs 缺陷 = 想要忠诚的下属，但只懂得用利益和恐惧控制人

### 角色弧线（负向弧线·堕落型）

| 阶段 | 卷范围 | 内在状态 | 外在表现 |
|------|--------|----------|----------|
| **初始** | 卷一 | 理性、自信、一切在掌控中 | 幕后操控，通过苏曼曼观察林渊 |
| **试探** | 卷二 | 发现林渊异常强大，产生兴趣 | 派手下试探，开始收集情报 |
| **对抗** | 卷三-四 | 多次被林渊挫败，傲慢受损 | 亲自下场，投入更多资源 |
| **失控** | 卷五-六 | 发现林渊的暴击系统超出理解 | 开始不择手段，做出非理性决策 |
| **疯狂** | 卷七 | 底牌尽出，孤注一掷 | 赌上一切，行为模式崩塌 |
| **终结** | 卷八 | 彻底疯狂或彻底认清现实 | 最终对决 |

### 声纹档案

- 句式较长，喜欢用反问句："你觉得你有什么资格跟我谈条件？"
- 口头禅："你不懂""这是为了你好""我给你的，你才能拿"
- 控制他人时：用最温柔的语气说最狠的话
- 失控时：语速变快，句式变短，暴露出压抑的暴躁

### OOC禁止清单

- ❌ 不会亲自动手脏自己的手（前期），除非对手已经超出他能操控的范围
- ❌ 不会在没有把握时挑衅强者
- ❌ 不会在外人面前表现出恐惧
- ❌ 不会无条件信任任何人——包括他自己的父亲

### 游戏体系定位

| 维度 | 设计 |
|------|------|
| **天赋类型** | 暗系掌控者（控制/削弱型，非正面硬刚） |
| **战斗定位** | 控场+削弱，靠手下输出，自己做幕后指挥 |
| **技能树方向** | 暗影束缚→精神操控→领域压制→暗系召唤 |
| **装备倾向** | 豪华——用钱堆出来的顶级装备，但操作水平一般 |
| **战斗风格** | 战术流——擅长利用信息差和人数优势围攻，1v1不是林渊对手 |
| **核心弱点** | 缺乏正面战斗的实战经验——他习惯让别人替他打 |

**反派游戏化设计**：
- 赵天宇的"强"来自资源碾压（装备/人数/情报），不是个人操作
- 这让林渊每次1v1赢他都有"降维打击"的爽感
- 但赵天宇会用"公会战/围攻/阴谋"来弥补个人战力不足
- 他的失败模式：不是被打败，是被林渊的信息差（重生记忆）拆穿阴谋

## 三、苏曼曼（伪女主·反派内线）

### 四维动机模型

| 维度 | 内容 |
|------|------|
| **欲望** | 活下去、过好日子——逃离赵天宇的控制，但也舍不得已经习惯的物质生活 |
| **恐惧** | 怕赵天宇（被威胁/被抛弃）、怕穷（不想回到拮据的日子） |
| **创伤** | 原生家庭有把柄在赵天宇手上（比如父亲赌博欠赵氏集团高利贷，赵天宇"帮"她解决了，代价是为他做事） |
| **缺陷** | 自私怯懦、过度依赖外力——总想靠别人改变命运，而非靠自己 |

**内部冲突**：
- 欲望 vs 恐惧 = 想逃离赵天宇，但怕失去现有的一切
- 创伤 → 缺陷 = 家庭债务让她习惯了"被安排"，丧失了自主决策的勇气
- 欲望 vs 缺陷 = 想要自由，但不敢付出自由的代价

**动机→行为链条**：
```
父亲欠债被赵天宇"帮忙"（创伤）→ 怕失去赵天宇的庇护（恐惧）
→ 服从安排接近林渊（行为模式）→ 内心对林渊有真实好感但不敢反抗赵天宇（矛盾）
→ 前世选择背叛林渊（缺陷驱动）→ 今生林渊看穿一切，她的处境更难
```

### 群像功能

- **复仇线触发器**：林渊仇恨的具象化载体
- **道德灰色地带**：不是纯恶人，有自己的苦衷，但苦衷不能洗白背叛
- **赵天宇控制力的展示窗口**：通过苏曼曼，读者看到赵天宇有多可怕

### 角色弧线（负向弧线·沉沦型）

| 阶段 | 卷范围 | 状态 |
|------|--------|------|
| **初始** | 卷一 | 像前世一样接近林渊，但林渊反应完全不同 |
| **困惑** | 卷二 | 发现林渊变了，不确定他是否知道真相 |
| **挣扎** | 卷三 | 赵天宇施压 vs 林渊的冷淡，两头不是人 |
| **选择** | 卷四 | 在关键节点做出选择（被赵天宇操控 or 背叛赵天宇） |
| **后果** | 卷五+ | 无论选哪条路，都必须承受代价 |

### 行为指纹

- 说话温柔、会撒娇——但林渊重生后能听出"表演感"
- 遇到危险下意识找人保护，而不是自己解决
- 独处时会发呆、叹气——内心知道自己在做坏事，但说服自己"没办法"
- 对林渊有真实的愧疚感，但不足以让她做出牺牲

### OOC禁止清单

- ❌ 不会突然变聪明——她不是谋略家，她是被操控的工具人
- ❌ 不会突然觉醒反抗赵天宇——除非有足够强的外部触发
- ❌ 不会对林渊完全无感——前世两年相处，有真实感情，只是不够多

### 游戏体系定位

| 维度 | 设计 |
|------|------|
| **天赋类型** | 火系法师（远程AOE输出） |
| **战斗定位** | 中后排范围伤害，单体爆发一般 |
| **技能树方向** | 火球术→烈焰风暴→陨石坠落→火系领域 |
| **装备倾向** | 赵天宇提供的资源堆出来的装备，品质不差但不属于她自己挣来的 |
| **战斗风格** | 中规中矩——赵天宇帮她铺好了升级路线，缺乏自主战术判断 |
| **戏剧功能** | 火系的"破坏力"与她内心的"怯懦"形成反差——她能放火但不敢反抗赵天宇 |

## 四、陈铁（核心搭档）

### 四维动机模型

| 维度 | 内容 |
|------|------|
| **欲望** | 保护兄弟、把健身房开起来、证明自己不是"只会练肌肉的傻大个" |
| **恐惧** | 被在乎的人抛弃（父亲小时候跑了）、被看不起（"四肢发达头脑简单"） |
| **创伤** | 父亲在他12岁时离家出走，母亲独自把他拉扯大。他恨不负责任的人 |
| **缺陷** | 太直、太冲——容易被人激将，关键时刻可能因冲动惹麻烦 |

**内部冲突**：
- 欲望 vs 恐惧 = 想证明自己有脑子，但一激动就用拳头说话
- 创伤 → 行为模式 = 父亲的抛弃让他极度重视忠诚和义气
- 欲望 vs 缺陷 = 想开健身房当老板，但管理需要耐心，他最缺的就是耐心

### 群像功能

- **信任锚点**：林渊唯一不设防的人，读者通过陈铁看到林渊"人"的一面
- **武力担当**：前排坦克，保护队友
- **节奏调节器**：直率性格和暴躁脾气自带喜感，调节紧张节奏
- **不可替代性**：删除陈铁→林渊变成纯独狼→读者看不到他柔软的一面→角色扁平化

### 角色弧线（正向弧线·成长型）

| 阶段 | 卷范围 | 状态 |
|------|--------|------|
| **初始** | 卷一 | 冲动、莽撞、只认拳头 |
| **跟随** | 卷二 | 无条件跟林渊，但不明白为什么林渊变这么厉害 |
| **考验** | 卷三-四 | 面对强敌，蛮力不够用，被迫动脑子 |
| **成长** | 卷五-六 | 学会听林渊的战术安排，从"莽"变成"猛而不莽" |
| **成熟** | 卷七-八 | 能独当一面，不再是林渊的"跟班"而是"搭档" |

### 行为指纹

- 说话大声、直来直去，不拐弯抹角
- 生气时会捏拳头、咬牙，但不会真的对兄弟动手
- 对林渊有近乎盲目的信任——"渊子说什么就是什么"
- 对陌生人先凶后善——看起来不好惹，熟了之后掏心掏肺
- **标志动作**：用拳头捶自己胸口（健身房的习惯，表示"交给我"）

### 声纹档案

- 句式短、语气冲："说那么多干嘛，干就完了"
- 口头禅："操""怕个屁""你行不行，不行我来"
- 对林渊："渊子"（专属昵称），偶尔损他但绝不允许别人损
- 对敌人：话不多，直接动手

### OOC禁止清单

- ❌ 不会背叛林渊——这是人设基石
- ❌ 不会突然变弱——健身教练的身体素质远超普通人
- ❌ 不会变得精于算计——他可以成长，但本质还是直肠子
- ❌ 不会对队友发火——他的暴脾气只对外人

### 游戏体系定位

| 维度 | 设计 |
|------|------|
| **天赋类型** | 重装战士（高防御高血量坦克） |
| **战斗定位** | 前排肉盾+仇恨吸引，保护后排输出 |
| **技能树方向** | 盾牌格挡→嘲讽→钢铁之躯→守护领域 |
| **装备倾向** | 重甲大盾——视觉上就是"人形堡垒" |
| **战斗风格** | 操作流——靠身体本能和格斗经验，不擅长计算但反应极快 |
| **成长设计** | 从"只会硬扛"到"学会走位和拉仇恨"——对应角色弧线从莽撞到有勇有谋 |

## 五、周芸（核心配角·治愈系）

### 四维动机模型

| 维度 | 内容 |
|------|------|
| **欲望** | 救人——用治愈天赋证明"学医是有用的"，证明自己存在的价值 |
| **恐惧** | 救不了人——眼睁睁看着人死在面前而自己无能为力 |
| **创伤** | 实习时一个病人死在手术台上——不是她的错，但她在场，那种无力感刻进骨子里 |
| **缺陷** | 过度共情——看到人受伤会冲上去，有时不顾自身安危 |

**内部冲突**：
- 欲望 vs 恐惧 = 想救人，但怕再次经历"救不了"的无力感
- 创伤 → 缺陷 = 手术台的无力感让她过度补偿，见到伤者就无法袖手旁观
- 欲望 vs 缺陷 = 想当合格的治愈者，但太容易把自己搭进去

### 群像功能

- **情感锚点**：主角团队的软肋——保护周芸=保护团队续航能力
- **不可替代后勤**：没有治愈系→团队无法持续作战→副本通关率暴跌
- **道德镜鉴**：她的纯粹（救人不问回报）反衬林渊的防备和赵天宇的冷酷

### 角色弧线（平弧线·坚守型）

| 阶段 | 卷范围 | 状态 |
|------|--------|------|
| **初始** | 卷一-二 | 在混乱中救治伤者，一个人忙不过来 |
| **加入** | 卷三 | 加入零号小队，有了稳定的"被需要"感 |
| **考验** | 卷四-五 | 面对"该不该救敌人"的道德困境 |
| **坚守** | 卷六-七 | 坚持"救人是本能"，但学会了区分"救人"和"纵恶" |
| **影响** | 卷八 | 她的纯粹影响了林渊——让他相信世界上还有不需要防备的人 |

### 行为指纹

- 说话轻声细语，但涉及救人时语气坚定
- 随身带着简易医疗包——游戏化后变成治愈法杖
- 面对伤者会自动进入"医生模式"，冷静、专业
- 独处时会翻医学教材——即使世界已经游戏化，她还是保留着学医的习惯
- **标志动作**：救人前会说"忍一下，马上就好"（实习时养成的习惯）

### OOC禁止清单

- ❌ 不会见死不救——即使对方是敌人，也会先救人再做判断
- ❌ 不会变得冷血——平弧线角色的核心就是"不变"
- ❌ 不会成为战斗力担当——她的定位是辅助，不是输出
- ❌ 不会对林渊产生超出队友的感情（至少前中期），她的关注点始终是"救人"

### 游戏体系定位

| 维度 | 设计 |
|------|------|
| **天赋类型** | 治愈系辅助（奶妈+辅助buff） |
| **战斗定位** | 后排治疗+状态净化，团队续航核心 |
| **技能树方向** | 单体治愈→群体治愈→净化debuff→复活(高级)→生命领域 |
| **装备倾向** | 轻甲+法杖——优先堆治愈效果和蓝量 |
| **战斗风格** | 纯辅助——零输出，必须有人保护。被近身=死 |
| **不可替代性** | 游戏化世界中治愈系极度稀缺（<1%的天赋），没有她团队无法持续刷副本 |

## 七、行为逻辑一致性检查

写任何角色的关键行为时，用这个公式检验：

```
行为 = 动机(他想要什么) × 处境(他面对什么) × 性格(他是这样的人)
```

### 行为决策树（适用于所有角色）

```
Q1: 这个选择涉及他的欲望吗？
  → 是：他会倾向选择（除非恐惧更强）
  → 否：看Q2

Q2: 这个选择涉及他的恐惧吗？
  → 是：他会倾向回避（除非欲望/创伤足够强）
  → 否：看Q3

Q3: 这个选择涉及他的创伤吗？
  → 是：会触发防御机制（回避/攻击/否认）
  → 否：按正常性格反应

Q4: 他现在的情绪状态？
  → 冷静：按理性决策
  → 激动：会做出比平时更极端的选择
  → 绝望：会选择"反正都这样了"的选项
```

### 常见OOC防御

| 模式 | 防御规则 |
|------|----------|
| 主角突然圣母 | 如果要让林渊做"心软"的事，必须先给触发事件（如看到对方也有苦衷的证据） |
| 反派突然变蠢 | 赵天宇的失败必须来自信息差（林渊有重生记忆），不是智商下降 |
| 配角突然消失 | 每章更新 novel_state.json 的角色状态，检查活跃角色是否合理缺席 |
| 能力忽高忽低 | 核心能力写入角色档案，每次使用时检查一致性 |

## 八、游戏体系与世界观融合设计

> 来源：knowledge_base/10_WorldBuilding/题材知识库/游戏.md

### 战斗描写三流派平衡

每场战斗必须选择主风格，不能三种平均分配：

| 流派 | 适用角色 | 描写重点 |
|------|----------|----------|
| **数据流** | 林渊（暴击数字可视化） | 穿插伤害面板，"-99999！暴击！"的视觉冲击 |
| **操作流** | 陈铁（走位+格斗本能） | 微操、走位、预判，体现身体素质优势 |
| **战术流** | 林渊（战前布局）+ 赵天宇（阴谋） | 战前布局、临场指挥、信息差博弈 |

### 数值增长曲线控制

暴击倍数指数增长（1→2→4→8→16...）是核心卖点，但必须防止数值崩坏：

| 阶段 | 倍数范围 | 控制机制 |
|------|----------|----------|
| 卷一 | 1x-4x | 初期怪物弱，不需要高倍数 |
| 卷二 | 4x-32x | 开始遇到需要叠倍数的精英怪 |
| 卷三-四 | 32x-512x | Boss有暴击抵抗，需要叠到阈值才能破防 |
| 卷五-六 | 512x-8192x | 体力消耗成为硬限制，50倍以上每刀都在咬牙 |
| 卷七-八 | 8192x+ | 只在最终决战时突破极限，平时被封印/限制 |

**控制原则**：
- 倍数越高→体力消耗越大→不能无限叠
- Boss有暴击抵抗→倍数必须高到阈值才能破防→不是"越高越好"而是"刚好够用"
- 离战30分钟重置→防止跨场景积累
- 叙事上：高倍数=林渊在拼命，不是在开挂→保留紧张感

### 防单机化设计

游戏知识包警告："如果主角全程单机，缺乏与其他玩家的互动、竞争或合作，会失去网游的味道。"

**设计策略**：
- 核心圈（零号小队）：林渊+陈铁+周芸，每章至少两人同时出场
- 竞争圈：其他猎人/公会争夺首杀和排名——林渊不能什么都是第一
- 社交圈：猎人公会、交易市场、情报商人——林渊即使不信任人也需要在这些场所活动
- 敌对圈：赵天宇的势力网——通过"对手在做什么"来展示世界是活的

### 经典情节模式锚点

| 模式 | 对应剧情 | 卷 |
|------|----------|----|
| 首杀/首通 | 抢回前世被夺的SSS级隐藏副本首通 | 卷一 |
| 首杀/首通 | 打通前世没人过的副本，全服公告 | 卷二 |
| 建帮/国战 | 零号小队→正式公会→大规模公会战 | 卷三-四 |
| 全知全能 | 重生记忆抢资源、预判敌人行动 | 全书 |
| 退役复出 | 不适用（林渊是重生不是退役），但有"从底层重新崛起"的变体 | 卷一 |
