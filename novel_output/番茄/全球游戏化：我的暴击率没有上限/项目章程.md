# 全球游戏化：我的暴击率没有上限 项目章程

## 一、项目基本信息

| 项目 | 内容 |
|------|------|
| 书名 | 全球游戏化：我的暴击率没有上限 |
| 平台 | 番茄小说 |
| 题材 | 系统流 × 游戏入侵 × 重生 |
| 目标字数 | 70-80万字（240章） |
| 目标读者 | 16-28岁男性 |
| 节奏要求 | 3000-4000字/章，快节奏，每章有钩子 |

## 二、核心目标

1. 番茄平台签约上架，进入热门推荐
2. 完结时字数达到70万字以上
3. 保持每章2800-3200中文字符（番茄红线）
4. 每章至少1个爽点或悬念钩子

## 三、范围与红线

### 必须做到
- 每章正文写完后统计中文字符数，低于2800禁止交付
- 角色行为必须通过四维动机模型检查（欲望/恐惧/创伤/缺陷）
- 暴击倍数增长有控制（体力消耗+Boss暴击抵抗+离战重置）
- 伏笔必须按时回收，不能遗漏

### 绝对禁止
- 林渊不能突然圣母——复仇是核心驱动力
- 赵天宇的失败必须来自信息差，不是智商下降
- 苏曼曼不能突然变聪明——她是被操控的工具人
- 陈铁不能突然变弱或背叛林渊
- 不能出现不符合2026年常识的科技/社会设定
- 所有角色名禁止包含"默"字
