# 谢无妄（男主）

## 基本信息

| 字段 | 内容 |
| --- | --- |
| 身份 | 昆仑剑宗第一剑仙，修仙界最强战力 |
| 外貌 | 白衣如雪，面容冷峻俊美，剑眉星目，气质高冷到让人不敢靠近 |
| 性格 | 高冷寡言，但方向感极差（路痴），对认定的事极其执着 |
| 能力 | 修仙界第一战力，但不会认路（天生缺陷，与修为无关） |

## 矛盾特质

- 高冷外表下极度害羞——被林小满直视会耳红但绝不承认
- 实力超出系统检测范围，但在网约车上乖乖听话
- 吃醋时不说话，默默在订单里多打赏

## 核心设定

- 核心动机：斩妖除魔→保护林小满→暗中守护
- 对话风格：极简主义，能一个字说完绝不说两个字。"嗯。""走。""小心点。"
- 吃醋表现：不说话，默默增加订单频率，从三天一次变成一天三次
- 关键台词："小心点。"（第8章，警告）/ "不收影响判断。"（打赏时）
