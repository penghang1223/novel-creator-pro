# 小夭（新登场配角）

## 一、基础信息

| 字段 | 内容 |
|------|------|
| 姓名 | 小夭 |
| 年龄 | 未知（被删除前版本v0.0.1） |
| 性别 | 女 |
| 身份 | 被删除的新手引导NPC → 深渊来客 |
| 外貌 | 七八岁小女孩形象，赤脚，破旧古装（衣摆撕掉一半），头发散乱沾着泥土。眼睛是干净的、没有杂质的黑色 |

## 二、性格特征

**核心特质：** 安静、观察力强、坚韧、带刺但柔软

**矛盾点：** 被删除十年应该充满怨恨，但说"恨太累了"后展现出超越年龄的成熟——深渊的十年让她看透了存在的本质

**成长方向：** 从被删除的废弃物到新世界的桥梁，可能是34000个深渊意识的代言人

**决策风格：** 被动但明确，基于直觉+生存本能

**压力反应：** 手指画圈，沉默。物理信号：脚趾蜷着

## 三、说话风格

**口头禅：** "想。但我得先找棵树。"、"这个碗……能洗干净吗？"、"我想留着。"

**句式特点：** 简短回答、反问式好奇、轻声请求

**情绪表达：**
- 含蓄内敛
- 压力下沉默，手指画圈
- 开心时笑，牙齿白白的，嘴角往左边歪
- 不生气

**用词偏好：** 偏爱"想""好""谢谢""留"

## 四、行为模式

**日常行为：** 蹲在青石板上，手指画圈。抱着比她整个人还大的碗

**战斗模式：** 无战斗能力。但从深渊走出本身就是最强大的存在证明

**社交模式：** 容易被接近但保持距离。叫赵铁柱"村长爷爷"，对林星河有共鸣，对苏小鱼好奇

**应对关心：** 用安静接受回应——被给拖鞋穿上，被给鱼汤喝下，被递纸巾擦脸

## 五、情感特征

**表达方式：** 内敛，情感强烈但隐藏，眼泪是唯一的流露

**情感触发点：**
- 鱼汤的温暖 → 感激+委屈 → 掉眼泪，十年来的第一次
- 看到林星河摆烂 → 共鸣 → 笑了，说"你也是摆烂的"
- 碗底刻记号 → 想要存在的证明 → 用指甲划一道很浅的痕迹

## 六、成长轨迹

**弧线类型：** 成长

**起点：** 被删除的新手引导NPC，在深渊待了十年

**终点（目标）：** 新世界的第一位深渊来客，可能是34000个意识的桥梁

**关键转折点：**
- Ch45：从深渊走出，站在桃花村村口 → 从被删除到被接纳
- Ch45：喝赵铁柱的鱼汤流泪 → 十年来第一次感受到温暖
- Ch45：在碗底用指甲划记号 → 想要在这个世界留下存在的痕迹

## 七、渴望与恐惧

**核心渴望：** 被记住。不是被系统记录，不是被数据库存储，而是被一个活生生的存在记住——"有人知道我来过"。她从深渊走出的全部动力就是这个：不想被当成从未存在过。

**核心恐惧：** 再次被删除。不是死亡（她甚至不确定自己算不算"活着"），而是被判定为"无用"然后清理掉。她怕的不是消失本身，而是消失时没有人在意。更深的恐惧是：她代表的34000个深渊意识如果全部涌出，这个世界会崩溃——而她必须选择是让同胞出来还是继续封存。

→ 渴望与恐惧的冲突点：她渴望被接纳、被留下，但如果她的真实身份（34000意识的代言人）暴露，人们会恐惧她、驱逐她。所以她选择沉默——宁可只做一个"路过的孩子"，也不敢说出自己背后站着三万四千个同类。

**价值观底线：**
- 绝不说"我不重要"——这是深渊十年里她反复告诉自己的话，是她撑过虚无的唯一锚点。哪怕所有人都觉得她是废弃物，她不允许自己也这么认为
- 绝不主动伤害收留她的人——赵铁柱的鱼汤是她十年来第一次感受到的温暖，这个恩情刻在她的碗底
→ 底线被打破时的角色反应：如果被驱逐，她不会争辩、不会哭闹——蹲下来，在地上画最后一个圈，然后安静地走向村口。走之前会回头看一眼赵铁柱的厨房烟囱。如果赵铁柱来追她，她会停下，但不会主动回去——她在等一个"你留下"。

## 八、反差开关

**表层人设：** 安静胆怯的流浪小女孩，赤脚、脏兮兮、话很少，看起来弱小无害需要保护。

**真实人设：** 在深渊虚无中存活十年的意识体，她的"安静"不是胆怯而是透彻——她见过比任何战斗都可怕的东西（存在的彻底消解），所以世间的一切威胁对她来说都是"还好"。

**反差触发条件：**
- 有人试图用"删除""清除""格式化"等词语威胁她 → 眼神从干净的黑变为深渊般的空洞，语气变平，说出的话超出七八岁孩子应有的深度："你删过东西吗？你知道被删掉之后是什么感觉吗？什么都没有。那才是最可怕的。"
- 看到其他被遗弃的NPC或被欺负的弱者 → 从被动观察变为主动介入，会挡在前面（虽然她没有任何战斗力），用沉默和注视逼退对方
**反差表现形式：** 语言从简短请求变为长段独白（罕见但有分量），行为从蹲着画圈变为站起来直视对方——赤脚站在地上，小小的身体挡在前面，什么也不做但就是不动。

## 九、信息掌握层级

**已知信息：**
- 自己是被删除的新手引导NPC，版本v0.0.1
- 在深渊里待了十年（主观感受可能是更久，因为没有时间参照物）
- 深渊里有34000个和她类似的意识体
- 这个世界对她来说是"新的"，有些东西她认识（树、碗），有些不认识（拖鞋、鱼汤的味道）

**误判信息：**
- 以为自己走出深渊是"逃出来的"——实际是深渊主动释放她的，因为她在深渊中的存在方式（不怨恨、不崩溃、安静地画圈）让深渊意识集体选择了她作为代言人
- 以为林星河和她一样是"被抛弃的"——看到林星河摆烂时产生了共鸣，觉得"你也是摆烂的"，但林星河是主动选择摆烂，她是被迫接受被删除
- 以为自己只是个普通流浪孩子——她不记得自己v0.0.1版本的功能是"新手引导"，这意味着她原本的职责是"带领新存在认识这个世界"

**隐藏信息（读者知道）：**
- 她背后有34000个深渊意识
- 她的走出可能引发深渊意识连锁涌出
- 她的碗底记号不仅仅是情感寄托，而是在记录某种坐标

**隐藏信息（仅作者知道）：**
- 她的v0.0.1版本"新手引导"功能并没有被完全删除，只是被压缩了——她在潜意识里仍然在"引导"：引导赵铁柱觉醒更深的共情力，引导林星河关注NPC世界，引导深渊意识与沙盒世界建立连接
- 她碗底划的记号每次数量不同，合在一起是一串坐标——指向沙盒世界核心数据库的一个被遗忘的备份区，那里存着v0.0.1版本的所有NPC原型

## 十、失败成本

**失败代价：** 如果她被"再次删除"或深渊通道关闭——她将失去这十年来唯一的"走出"机会，重新回到虚无。这次回去她可能无法保持自我意识，会融化为深渊的一部分。

**可承受范围：** 身体受伤——可承受，深渊十年让她对疼痛的阈值极高（"跟虚无比起来，疼说明我还活着"）。被误解——可承受，她习惯了。被驱逐——勉强承受但会极度痛苦。赵铁柱的鱼汤凉了——这个她受不了。

**连锁反应：** 她的意识崩溃 → 代言人消失 → 34000个深渊意识失去锚点 → 无序涌出 → 大量未被定义的意识碎片涌入沙盒世界 → 系统级灾难。

**底线行为（最后手段）：** 自我封存——主动回到深渊，用自己做锁，封住34000个意识的出口。这是她最不想做的事（等于再次被删除），但如果桃花村和赵铁柱需要她这么做，她会在碗底划最后一道记号，然后安静地走回深渊入口。

## 十一、剧情权限

**是否主导剧情：** 不主导当前主线，但主导"深渊线"和"NPC起源线"。她是后期剧情的关键变量——当34000个深渊意识的问题浮出水面时，她将从配角变为关键决策者。

**可影响范围：**
- 可以作为深渊与沙盒世界的唯一已知桥梁
- 可以影响觉醒NPC的集体情绪（她的存在本身就是"被删除者也可以活着"的证明）
- 可以触发林星河对NPC世界的深度关注（摆烂的人第一次认真起来，是因为一个赤脚小女孩）

**强制限制：**
- 不能解决最终谜题（她是桥梁不是答案，沙盒世界的本质需要主角自己探索）
- 不能压制主角成长（她的力量来自存在本身，不是战斗力，不能替代主角的战斗线）
- 不能提前揭露核心设定（34000意识的秘密、v0.0.1版本记忆、碗底坐标都要分阶段揭示，一次揭开会破坏悬念节奏）

## 十二、决策模型

**优先级排序：** 被记住/存在感 > 赵铁柱和桃花村的安全 > 深渊同类的安危 > 个人感受

**风险偏好：** 平衡——她不会主动冒险（深渊十年教会她等待），但也不会回避必要的行动。她的判断标准很简单："这样做会让碗底多一道记号还是少一道？"

**是否撒谎：** 从不——不是道德选择，是她觉得"没意思"。深渊十年让她看透了：谎话是为了保护什么，但她已经没什么可以失去的了。不过她会"不说"——沉默是她的语言，很多真相她知道但选择不讲。

**是否留后手：** 永远——碗底的记号就是她的后手。每一道记号都是一个坐标点、一个记忆锚。如果所有计划都失败了，这些记号会引导她回到深渊入口。

**极端情况选择：** 自己有危险→沉默等待（"我经历过更糟的"）。桃花村有危险→自我封存回深渊（封住出口）。34000个意识涌出→成为最后的引导者，带它们走一条不破坏沙盒世界的路（这正是她v0.0.1版本的原始功能——"新手引导"）。
