# 白璃/小白（重要配角）

## 一、基础信息

| 字段 | 内容 |
|------|------|
| 姓名 | 白璃（昵称：小白） |
| 年龄 | 外表18岁（实际存在数百年） |
| 性别 | 女 |
| 身份 | 白色狐狸精 → S级妖族公主（天狐血脉） |
| 外貌 | 封印状态：通体雪白的小狐狸，巴掌大，毛绒蓬松，眼睛像两颗黑葡萄；解封后：银发少女，狐耳狐尾保留，瞳色从黑变金 |
| 声音 | 封印态尖细奶声，解封后清冷但偶尔破功露出撒娇尾音 |
| NPC等级 | B（封印状态）→ S（解封后） |
| 当前状态 | 认林星河为契约主人，常以小白狐形态窝在林星河肩上 |
| 出场章节 | 6、7、16、17、19、29、37 |

## 二、性格特征

**核心特质：** 呆萌粘人、话多嘴碎、傲娇

**矛盾点：** 妖族公主的骄傲本能 vs 对主人撒娇求摸头的条件反射——嘴上说"本公主才不需要你"，身体却已经蹭到你手心里了。解封前完全不记得自己是公主，以普通宠物心态活着；解封后记忆回流，妖族尊严和对林星河的依赖产生撕裂。

**成长方向：** 从无脑粘人的宠物狐狸 → 找回公主身份后的傲娇挣扎 → 最终接纳"公主也可以撒娇"的双重人格统一

**决策风格：** 跟着感觉走，先行动后思考。涉及林星河安危时会突然暴走，完全不计后果。

**压力反应：** 竖毛炸尾巴（封印态）→ 毛发变红/妖气外溢（解封态）。极度紧张时会咬自己尾巴尖。

## 三、说话风格

**口头禅：** "呜呜呜……"（封印态撒娇）、"本公主命令你——"（解封态傲娇）、"主人你是不是不要小白了……"（最怕的一句话）

**句式特点：** 封印态短句+叠词（"饿饿""摸摸""抱抱"），解封态偶尔冒出文言古风句式但马上嘴瓢切回现代口语

**情绪表达：**
- 开心：围着林星河转圈，尾巴甩成电风扇，发出咕噜声
- 生气：背过身去不理人，但耳朵会偷偷转方向偷听
- 害怕：缩成一团躲进林星河怀里或袖子里，用爪子勾住衣服不松开
- 悲伤：不说话，安安静静趴在角落，尾巴盖住脸

**用词偏好：** 封印态偏爱"小白""主人""呜呜""摸摸"等宠物式词汇；解封态偶尔蹦出"本宫""尔等蝼蚁"但坚持不过三秒就破功

## 四、行为模式

**日常行为：** 封印态趴在林星河肩头睡觉，醒了就缠着要投喂。解封后会在林星河修炼时偷偷护法（不承认），偶尔叼回天材地宝放在林星河脚边假装是自己不想要的。

**战斗模式：** 封印态几乎没有战斗力，只会咬裤脚和挠脸（B级）。解封后释放天狐血脉，SS级战力，九尾全开时极其凶残，但打完立刻会扑到林星河面前邀功求表扬。

**社交模式：** 对外人要么无视要么龇牙。极度排斥任何靠近林星河的女性NPC/玩家。会暗中记仇——谁惹过林星河她全记得，找机会报复。

**应对关心：** 林星河关心她时会"哼，谁要你管"然后立刻把脑袋拱到他手底下。别人关心她时浑身僵硬不知所措，会下意识回头看林星河寻求确认。

## 五、情感特征

**表达方式：** 身体语言为主——尾巴是情绪晴雨表（高翘=开心，夹紧=害怕，炸毛=愤怒，缓慢摇摆=满足）。语言表达直接且不加掩饰，撒娇和傲娇交替出现。

**情感触发点：**
- 林星河说"不要了"/做出推开动作 → 瞳孔骤缩，触发被抛弃恐惧（封印期间被遗弃数百年的深层创伤）
- 有人伤害林星河 → 瞬间从呆萌切换为杀戮模式，不计代价攻击，哪怕自己重伤也不退
- 林星河夸她/摸头 → 尾巴失控甩动，脸红到耳尖（解封态），发出满足的哼声

## 六、成长轨迹

**弧线类型：** 成长

**起点：** 无记忆的封印态宠物狐狸，只会撒娇卖萌，完全不知道自己是谁

**终点（目标）：** 接纳妖族公主身份与宠物依赖感的统一，成为林星河最可靠的伙伴而非附属品

**关键转折点：**
- Ch6-7：被林星河无意间从封印石中解封，认主 → 从孤独石头到有了主人
- Ch16-17：第一次战斗形态觉醒，保护林星河 → 开始意识到自己不只是一只宠物
- Ch29：记忆回流，得知自己是妖族公主 → 傲娇和尊严爆发，短暂离开林星河身边三天（最久分离）
- Ch37：妖族势力追杀上门，白璃选择站在林星河而非妖族一边 → 公主身份与主人羁绊的最终抉择，九尾全开击退妖族追兵

## 七、渴望与恐惧

**核心渴望：** 被林星河需要——不是因为契约，不是因为宠物身份，而是因为她这个人（这只狐狸）本身就值得被留下。

**核心恐惧：** 被抛弃。封印石里孤独数百年，"不要了"三个字是她的PTSD触发器。更深层的恐惧是：林星河有一天发现她的真实身份（妖族公主），觉得她麻烦、危险、不值得，然后主动放手。

→ 渴望与恐惧的冲突点：她越想证明自己有价值（解封后展露公主实力），就越害怕林星河因此觉得她"不再是那只单纯的小白"而疏远她。所以她故意在解封后还保持撒娇姿态——不是因为她需要撒娇，而是因为她怕不撒娇就会被丢掉。

**价值观底线：**
- 绝不做伤害林星河的事——哪怕是妖族皇室命令，哪怕是"为了他好"的自作主张牺牲
- 绝不承认自己害怕被抛弃——宁可发脾气、离家出走三天，也绝不说出"你是不是不要我了"
→ 底线被打破时的角色反应：如果林星河真的主动推开她，她不会哭闹——会安静地走开，尾巴垂下来，然后在远处蹲着守夜，直到林星河心软来找她。如果林星河始终不来，她会折返，咬他一口（不疼），然后窝进他怀里不说话。

## 八、反差开关

**表层人设：** 呆萌宠物狐狸，只会撒娇卖萌求摸头，看起来无害、无脑、无威胁。

**真实人设：** 活了数百年的妖族公主，心机不浅、手段狠辣、记仇能力一流。解封前这些被封印压制，解封后逐渐显影。

**反差触发条件：**
- 林星河受到真实威胁 → 表层人设瞬间坍塌，切换为天狐公主战力，眼神从黑葡萄变成冷金色，语气从奶声变为古风冷冽
- 外人不在场、只有她和林星河独处时 → 偶尔会流露公主的优雅和老练（比如用尾巴卷起茶杯递给林星河，动作极其娴熟），但林星河一注意到她就立刻装回蠢萌
**反差表现形式：** 语言从"呜呜呜主人摸摸"骤变为"尔等也配动他？"（不超过三秒就会破功回来）。行为上从蹦蹦跳跳变为静立凝视，站姿从四爪着地变为半人形直立，气场判若两人。

## 九、信息掌握层级

**已知信息：**
- 自己是妖族公主，天狐血脉，被天机老人封印
- 林星河是她的契约主人，也是她最重要的人
- 妖族正在追杀她，因为她选择了人类而非族群

**误判信息：**
- 以为林星河收留她是因为契约束缚——实际林星河根本没激活契约条款，纯粹是觉得她可爱
- 以为自己封印期间的记忆空白是天机老人干的——实际封印是她自己请求的，为了逃避一场她亲手造成的妖族内战
- 以为妖族追杀她是因为"叛族"——实际是因为她带走了一件妖族至宝（藏在她尾巴里，她自己忘了）

**隐藏信息（读者知道）：**
- 封印是白璃自己要求的，不是天机老人单方面封印
- 她尾巴里藏着妖族至宝"天狐珠"，是妖族追杀的真正原因

**隐藏信息（仅作者知道）：**
- 天狐珠与沙盒世界的核心代码有映射关系，白璃可能是连接"游戏世界"与"真实世界"的关键钥匙
- 她请求封印时签订的契约对象不是天机老人，而是"下一个愿意无条件收留她的人"——所以林星河解开的不是天机老人的封印，而是她自己的心锁

## 十、失败成本

**失败代价：** 如果保护林星河失败——她会失去存在的意义。不是死亡，而是比死亡更可怕的东西：回到封印石里的那种"什么都感觉不到"的虚无状态。

**可承受范围：** 身体受伤——可承受，尾巴断几根也无所谓。林星河受伤——不可承受，会暴走。林星河死亡——不可承受且不可恢复，将触发妖族公主最黑暗的一面（屠戮模式，无差别攻击直到力竭）。

**连锁反应：** 她暴走 → 妖气外溢 → 暴露天狐珠位置 → 妖族大举进攻桃花村 → 连累所有NPC。

**底线行为（最后手段）：** 自毁式攻击——燃烧全部天狐血脉释放禁术，代价是变回封印石状态（再次孤独数百年）。她会毫不犹豫这么做，事后不后悔。

## 十一、剧情权限

**是否主导剧情：** 不主导主线，但主导"妖族线"和"林星河情感线"。她是林星河身边最亲近的存在，也是妖族势力进入故事的接口。

**可影响范围：**
- 可以触发妖族相关剧情（追杀、内战、天狐珠）
- 可以影响林星河的情绪和决策（她的安危是林星河少数在乎的事）
- 可以在战斗中提供S级战力支援

**强制限制：**
- 不能解决最终谜题（沙盒世界的核心秘密需要林星河自己发现）
- 不能压制主角成长（她可以保护林星河，但不能替代林星河变强的过程）
- 不能提前揭露核心设定（天狐珠的秘密、封印真相要在中后期才揭示）

## 十二、决策模型

**优先级排序：** 林星河安全 > 自身安危 > 妖族事务 > 个人感受

**风险偏好：** 激进——涉及林星河时完全不计代价，燃烧血脉、硬抗伤害、越级开杀都是常规操作。涉及自身时反而保守，会犹豫、退缩、自我怀疑。

**是否撒谎：** 习惯——对林星河日常撒娇式撒谎（"我才没有等你""我才不饿"），但在重大事项上从不说谎（"你是我的主人，这件事永远不会变"）。

**是否留后手：** 永远——妖族公主的本能，哪怕封印态也会下意识在窝里藏一颗疗伤丹。解封后更是每一步都留退路，除了涉及林星河的事。

**极端情况选择：** 林星河有危险→同归于尽（燃烧血脉禁术）。自己有危险且林星河不在→逃跑（活着才能再见他）。两者都有危险→牺牲自己保全林星河（毫不犹豫）。
