| 姓名 | 李青风 |
| 年龄 | 25岁（游戏内建模25岁，与现实同步） |
| 性别 | 男 |

## 二、性格特征

**核心特质：** 理性分析狂、好胜心强、嘴硬心软

**矛盾点：** 商业精英的精明计算 vs 面对林星河时完全无法用常理解释的挫败感——他能算清每笔账，但算不清一个F级NPC为什么一个眼神就能让他跪下。理性告诉他不该信，证据又让他不得不信。

**成长方向：** 从"我要证明他是个BUG"的对抗心态 → "我悟了，是我太菜"的认知重建 → 成为林星河最忠实的记录者和半个信徒

**决策风格：** 数据驱动，凡事先做分析表。但遇到林星河相关事件时会放弃分析直接行动（自己没意识到这个变化）。

**压力反应：** 下意识掏出小本本记录（游戏内是卷轴），分析速度加快到语无伦次。极度压力下会沉默——李青风的沉默比任何人都可怕，因为这意味着他放弃了分析。

## 三、说话风格

**口头禅：** "我悟了"、"让我分析一下"、"第一、第二、第三"、"这个数据不对"

**句式特点：** 列举式表达（"原因有三"），习惯性反问确认（"你确定？让我看看数据"），震惊时短句重复（"不可能不可能不可能"）

**情绪表达：**
- 震惊：瞳孔地震+折扇掉地上（每次都掉，捡起来的速度越来越快）
- 佩服：长叹一声，收起折扇，双手抱拳，表情认真
- 不服：嘴角抽搐但强撑微笑，手指无意识地敲折扇
- 崩溃：原地转圈踱步，嘴里念叨"没道理啊"

**用词偏好：** 偏爱"分析""数据""概率""逻辑""不合理"；口头汇报时用"会长认为""青风建议"等第三人称自称（公司开会养成的习惯）

## 四、行为模式

**日常行为：** 维护"上仙行为档案"——记录林星河每一次异常行为的时间、地点、影响范围、数据变化。随身携带三本卷轴（游戏内），分别是：观察记录、推测理论、未解之谜。

**战斗模式：** 青云剑法体系，B+级战力，擅长阵法配合。公会战时坐镇后方指挥，极少亲自上阵。但在林星河面前会放下会长架子主动请缨（想表现）。

**社交模式：** 对下属威严果断，对同级客气疏离，对林星河……会变成话痨研究员。结识新NPC时第一反应是"你的数据面板能给我看看吗"。

**应对关心：** 别人关心他时会客气推辞"不用不用，青风自己能处理"。林星河关心他时会愣住三秒，然后掏出卷轴记录"上仙第一次主动关心在场人员"。

## 五、情感特征

**表达方式：** 用行动和分析报告代替情感。真正动感情时反而说不出话，会把情绪写进档案备注里。

**情感触发点：**
- 看到不合逻辑的超自然现象 → 肾上腺素飙升，兴奋到手抖，必须立刻记录
- 公会成员被欺负 → 从理性分析者秒变护短暴君，平时的"第一第二第三"全忘光，直接拔剑
- 林星河认可他/采纳他的建议 → 表面镇定但折扇摇得飞快，回公会后会破例请全员喝酒

## 六、成长轨迹

**弧线类型：** 成长

**起点：** 全服第二公会的自信会长，认为林星河是个"有趣的异常数据点"，试图用理性破解

**终点（目标）：** 放下"证明他是BUG"的执念，接受有些事情不需要解释只需要见证，成为林星河最可靠的盟友之一

**关键转折点：**
- Ch9：首次目睹林星河异常表现，在公会频道写下第一篇观察记录 → 从对手变研究者
- Ch15：被林星河一个眼神吓跪，公会成员全看见 → 面子尽失，闭关三天写下"我悟了。上仙不是F级，是我太菜"
- Ch20：主动带着分析报告找林星河，试图"理性合作" → 林星河完全不看报告，但随手帮了他一个忙，李青风第一次体会到"不讲道理的好"
- Ch27：在重大公会战中选择站在林星河一边对抗幽冥殿，放弃全服排名争夺 → 从"研究对象"到"我要保护的人"

## 七、渴望与恐惧

**核心渴望：** 用逻辑和数据掌控一切——证明世界是可分析、可预测、可优化的。深层渴望是被认可：不只是"第二公会会长"，而是被林星河本人视为"有用的人"。

**核心恐惧：** 失控。最怕遇到完全无法用理性解释的现象——不是怕林星河强大，而是怕"我的分析体系是废的"。如果连分析都没用，那他在游戏和现实里建立的一切认知框架都会崩塌。

→ 渴望与恐惧的冲突点：越是渴望破解林星河的秘密，就越接近"理性无用"的恐惧深渊。每次记录"上仙行为档案"都是在同时满足渴望和逼近恐惧——他用分析来对抗"分析没用"的事实。

**价值观底线：**
- 绝不出卖公会成员换取情报——青云盟的人不是数据，是战友
- 绝不向林星河隐瞒自己在记录他——可以偷偷记，但被问到时必须坦白
→ 底线被打破时的角色反应：如果发现自己为了"数据完整性"牺牲了公会成员利益，会当场撕毁卷轴，沉默三天不说话。这是比被林星河吓跪更严重的崩溃。

## 八、反差开关

**表层人设：** 冷静理性的数据分析师，说话带"第一第二第三"，永远在计算概率和逻辑链。

**真实人设：** 本质是个上头的赌徒。创业本身就是最大的赌博，他选了一条高风险的路，骨子里享受"不确定中寻找确定"的刺激感。

**反差触发条件：**
- 当林星河做出完全超出预测范围的行为 → 数据分析师外壳碎裂，露出赌徒本性，会做出非理性的冲动决定（比如Ch27放弃排名站队林星河）
- 当公会成员被欺负但对方实力远超己方 → "第一第二第三"全部忘记，直接拔剑，事后才反应过来"刚才那个决策概率上完全不合理"

**反差表现形式：** 语言从列举式变为短句爆发（"管不了了"），行为从后方指挥变为亲自冲锋，折扇一合直接当剑用。

## 九、信息掌握层级

**已知信息：**
- 林星河是F级NPC但拥有远超S级的实力
- 林星河能一招秒杀顶级玩家
- 林星河对公会排名和资源争夺毫无兴趣
- 三本卷轴中积累了全服最详细的林星河行为数据

**误判信息：**
- 以为林星河是"系统BUG"或"隐藏数据溢出"——用程序员思维理解一个穿越者，方向从根上就错了
- 以为只要数据足够多就能"破解"林星河的底层逻辑——实际上林星河的行为逻辑根本不来自系统

**隐藏信息（读者知道）：**
- 林星河是穿越者，拥有前世记忆
- 林星河的"摆烂"是一种主动选择，不是BUG
- 林星河的真实实力连天机阁主都忌惮

**隐藏信息（仅作者知道）：**
- 李青风的"上仙行为档案"未来会成为天机OS分析林星河的核心数据源——他不知道自己一直在帮AI打工
- 他创业失败的经历和林星河穿越前的挫败有微妙呼应，是潜在的情感共鸣点

## 十、失败成本

**失败代价：** 具体量化——公会解散（200+核心成员流散），全服排名跌出前十（青云盟品牌价值归零），个人信誉破产（"第二公会会长"这个标签是他创业失败后最后的骄傲）。

**可承受范围：** 公会排名下降——可。公会解散——不可。后者意味着他在虚拟世界也"创业失败"了，这会彻底击垮他。

**连锁反应：** 公会解散 → 失去观察林星河的平台和资源 → "上仙行为档案"中断 → 失去最后的精神寄托 → 可能退出游戏，回归现实面对一地鸡毛。

**底线行为（最后手段）：** 不会背叛，但会"战略性撤退"——解散公会保全成员，自己独自面对后果。最极端情况下会向林星河求助，但开口的那一刻对他来说比死还难。

## 十一、剧情权限

**是否主导剧情：** 否。他是催化剂和观察者，不是驱动者。他的分析报告会推动其他角色的认知，但不直接引发主线事件。

**可影响范围：** 青云盟内部决策、与林星河相关的支线情报、公会战中的战术布局。能影响中型战斗的结果，但无法左右涉及天机阁主或世界底层设定的核心剧情。

**强制限制：**
- 不能解决最终谜题——他只是在记录，不是在破解
- 不能压制主角成长——他的分析对林星河无效，不存在"看穿主角"的可能
- 不能提前揭露核心设定——他的"上仙行为档案"永远是现象级描述，触不到穿越者真相

## 十二、决策模型

**优先级排序：** 公会成员安全 > 数据完整性 > 全服排名 > 个人面子

**风险偏好：** 表面保守（凡事先分析），实际在关键时刻极度激进（为了信念可以放弃一切数据成果）。

**是否撒谎：** 必要时。对公会成员会隐瞒"会长也没把握"的事实以维持士气，对林星河从不撒谎——因为他知道谎言在上仙面前毫无意义。

**是否留后手：** 永远。三本卷轴本身就是后手——观察记录、推测理论、未解之谜分册存放，即使丢了两本也不影响整体研究。战斗时也会在后方留预备队。

**极端情况选择：** 保命（保公会成员的命）。如果面临"自己死还是公会成员死"，会毫不犹豫选自己。但如果面临"公会解散还是向林星河低头"，会纠结到折扇被捏断。
