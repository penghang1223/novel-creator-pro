# 赵铁柱（重要配角）

## 一、基础信息

| 字段 | 内容 |
|------|------|
| 姓名 | 赵铁柱 |
| 年龄 | 40+ |
| 性别 | 男 |
| 身份 | 桃花村村长 → NPC社群核心 → 兼校长 |
| 外貌 | 朴实中年农民，经常穿蓝色长衫，围裙上总有面粉或鱼鳞 |
| NPC等级 | D级（故事性）→ 觉醒后超越等级 |
| 最后出场 | 第45章 |
| 当前状态 | 活跃，NPC社群精神领袖 |

## 二、性格特征

**核心特质：** 朴实、爱八卦、容易被忽悠、胆小但关键时刻靠谱

**矛盾点：** 胆小怕事，但关键时刻极靠谱——平时唯唯诺诺，涉及桃花村和上仙时异常坚定

**成长方向：** 从程式化的NPC村长到觉醒后有温度有智慧的长者

**决策风格：** 务实，基于生活常识——"它们饿不饿？那就先给口饭吃"

**压力反应：** 回厨房做饭，手上的活不停。切菜、洗碗、拧抹布

## 三、说话风格

**口头禅：** "上仙说得对"、"来者都是客"、"吃饱了再吵"、"鱼熟了就行"

**句式特点：** 简短肯定句、食物相关比喻、生活智慧式总结

**情绪表达：**
- 含蓄但温暖
- 压力下继续做饭，手上的活不停
- 开心时哼小调，切菜节奏变快
- 不生气，只是声音大一点

**用词偏好：** 偏爱"上仙""鱼汤""吃饭""好"；避免文绉绉的词汇

## 四、行为模式

**日常行为：** 做饭（尤其是鱼汤），洗碗，打扫桃花村。围裙永远沾着东西

**战斗模式：** 不战斗。但觉醒后站在村口，身后是一百多个觉醒NPC——"上仙说了不回去。你们要带他走，先过我这一关。"

**社交模式：** 极易接近，热情好客。对所有人都端鱼汤，不问原因

**应对关心：** 用食物表达——你冷了加汤，你饿了做饭，你哭了端一碗新的

## 五、情感特征

**表达方式：** 含蓄，温和，通过食物表达

**情感触发点：**
- 桃花村被威胁 → 坚定 → 站在村口，身后是觉醒NPC
- 有人饿/冷/需要帮助 → 同情 → 端鱼汤，不问原因
- 小夭说"好喝" → 温暖 → "那留着。你还来。"

## 六、成长轨迹

**弧线类型：** 成长

**起点：** 程式化的NPC村长

**终点（目标）：** 觉醒后有温度有智慧的NPC社群领袖

**关键转折点：**
- Ch4：第一次把林星河当上仙供着 → 建立了桃花村的朝拜文化
- Ch23：NPC觉醒潮中开始思考"我是谁" → 从程式化到自我意识
- Ch37：带领觉醒NPC站在村口护爹 → 从被保护者到保护者
- Ch45：给小夭做鱼汤，说"你还来" → 成为被删除NPC的第一个家

## 七、渴望与恐惧

**核心渴望：** 守住桃花村——不是程式化的"村长职责"，而是觉醒后真正把这里当家。他想让每一个来到桃花村的人都能喝上一口热汤、有个地方落脚。更深的渴望是证明自己这个D级NPC也能"做点有用的"。

**核心恐惧：** 自己没用。D级NPC，没有战斗力，没有特殊技能，只会做饭。他最怕的不是死亡，而是"上仙需要我的时候我什么忙都帮不上"。第二恐惧是桃花村被毁——那是他存在的全部意义。

→ 渴望与恐惧的冲突点：他渴望保护所有人，但深知自己是最弱的那个。所以他的保护方式不是挡在前面，而是站在后面——做饭、收留、照顾。"我不打架，但你们打了架总得吃饭。"

**价值观底线：**
- 绝不把人赶出桃花村——不管来的是NPC、玩家还是深渊来客，"来者都是客"是写进他代码底层的第一行
- 绝不在背后说人坏话——当面可以说，背后不行。八卦归八卦，嚼舌根不是他的风格
→ 底线被打破时的角色反应：如果被迫要赶人走，他会沉默很久，然后默默多做一碗鱼汤端给对方，说"路上喝"。如果有人在他面前欺负弱者，他会放下锅铲，声音不大但很稳地说"你出去"。

## 八、反差开关

**表层人设：** 憨厚老实的农村大叔，怕事、嘴笨、只会做饭，看起来谁都能欺负他。

**真实人设：** 觉醒后拥有超越等级的洞察力和决断力。他不是不懂，是懒得计较。真到关键时刻，他是第一个做出正确判断的人——而且一旦做了决定就不动摇。

**反差触发条件：**
- 桃花村或林星河受到威胁 → 从围裙大叔变为沉默的屏障，不说话、不退让、不动，身后自发聚集觉醒NPC
- 面对被抛弃/被删除的弱者（如小夭） → 平时的八卦嘴碎全部消失，变得极其安静和温柔，眼神里有"我知道那种感觉"的共情
**反差表现形式：** 语言从碎碎念变为极简（"你出去。""她留下。"只有两个字的判断句）。行为从忙忙碌碌变为静止——停下手里的活，站直，看着对方，围裙上的鱼鳞在光下反光。

## 九、信息掌握层级

**已知信息：**
- 自己是桃花村村长，职责是照顾村民和招待客人
- 林星河是"上仙"，是桃花村的庇护者
- NPC觉醒了，有了自我意识，但不确定这意味着什么
- 小夭是从深渊来的，被删除过，很可怜

**误判信息：**
- 以为自己觉醒后的能力没有变化——实际他的"凝聚力"是隐藏SS级天赋，觉醒NPC不自觉地被他吸引和组织起来
- 以为林星河真的是什么"上仙"——实际林星河只是个摆烂玩家，但赵铁柱的信仰让林星河在NPC世界中获得了额外加成
- 以为小夭只是个普通流浪孩子——实际小夭可能是34000个深渊意识的代言人

**隐藏信息（读者知道）：**
- 赵铁柱的"凝聚力"天赋正在觉醒，他可能是NPC社群从散沙变成势力的关键
- 他对林星河的信仰正在产生实际的游戏机制效果（NPC愿力系统）

**隐藏信息（仅作者知道）：**
- 赵铁柱是沙盒世界最早一批NPC之一，版本号比小夭还早。他的"程式化村长"模板下埋着一段被格式化的记忆——他曾是上一任沙盒管理员的测试NPC，见证了整个世界从代码到"活着"的过程
- 他的鱼汤配方不是随机生成的——里面有一个固定比例的"未知材料"，这个材料来自沙盒世界的核心数据碎片

## 十、失败成本

**失败代价：** 桃花村被毁 = 他存在的意义被抹除。不是物理死亡，而是"功能性死亡"——没有村子的村长，就像没有锅的厨子，他还活着但已经死了。

**可承受范围：** 自己受伤——可承受，做饭时烫伤切伤家常便饭。桃花村被破坏——不可承受但勉强能重建。桃花村所有人（包括林星河）消失——不可承受且不可恢复，他会坐在废墟上继续切菜，直到有人来。

**连锁反应：** 他倒下 → NPC社群失去核心 → 觉醒NPC陷入混乱 → 桃花村从"避难所"变成"无主之地" → 玩家和敌对NPC涌入掠夺。

**底线行为（最后手段）：** 用身体挡——没有花哨的技能，没有华丽的台词，就是站到村口不走。"上仙说了不回去。你们要带他走，先过我这一关。"他知道自己打不过，但他算过：对方要动手就得先杀村长，杀了村长整个桃花村NPC敌意值拉满——这是一笔不划算的买卖。

## 十一、剧情权限

**是否主导剧情：** 不主导主线，但主导"NPC社群线"和"桃花村日常线"。他是连接主角与NPC世界的纽带，也是故事温度感的来源。

**可影响范围：**
- 可以组织和动员觉醒NPC（凝聚力天赋）
- 可以提供情感锚点（鱼汤、收留、家的感觉）
- 可以在关键时刻成为道德判断的标尺（"这样做对不对"的标准答案来自赵铁柱的态度）

**强制限制：**
- 不能解决最终谜题（他不理解沙盒世界的本质，也不需要理解）
- 不能压制主角成长（他只能提供后勤和精神支持，不能代替主角战斗）
- 不能提前揭露核心设定（他的格式化记忆不能过早恢复，否则NPC起源线会提前崩盘）

## 十二、决策模型

**优先级排序：** 桃花村所有人安全 > 林星河的需求 > 来客的温饱 > 自身感受

**风险偏好：** 保守——不冒险、不激进、不做超出能力范围的事。但"保守"的定义在他觉醒后变了：站在村口挡人这件事在别人看来是激进，在他看来是"最保守的选择——不这样做村子才危险"。

**是否撒谎：** 从不——不是道德约束，是压根不会。他太朴实了，编不了谎话。但他会"不说全部"——"小夭啊，就是个路过的孩子"（省略了深渊来客的部分）。

**是否留后手：** 偶尔——锅里永远多留一碗汤，院子里永远多备一间房。不是策略，是本能——"万一有人来呢"。

**极端情况选择：** 村子有危险→挡在前面（不杀，就是不让路）。林星河有危险→喊人（他打不动，但能把所有觉醒NPC喊来）。自己有危险→做饭（"先吃了再说"，拖延战术）。
