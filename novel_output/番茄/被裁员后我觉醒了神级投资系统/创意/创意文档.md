# 创意文档：《被裁员后，我觉醒了神级投资系统》

## 基本信息

| 项目 | 内容 |
|------|------|
| 书名 | 被裁员后，我觉醒了神级投资系统 |
| 题材 | 都市·系统·投资·逆袭 |
| 平台 | 番茄小说 |
| 规划字数 | 105万字（350章 × 3000字） |
| 目标读者 | 20-40岁都市男性读者，对职场逆袭、财富自由题材感兴趣 |

## 一句话梗概

32岁被裁互联网中层林辰，觉醒能看到所有人"投资价值"的神级系统，从3万存款到万亿资产，完成从社畜到资本大鳄的逆袭。

## 核心卖点

1. **极强代入感**：被裁、35岁危机、信用卡催款、前妻催学费——开局就是普通人最怕的处境
2. **系统设定新颖**：不是修炼/战斗系统，而是"投资价值可视化"——看人识人、看公司识公司
3. **爽点密集**：每3章一个小高潮，每10章一个中高潮，每30章一个大高潮
4. **双线并行**：事业线（投资崛起）+ 情感线（父女情深），爽感与温度兼具
5. **打脸不生硬**：前公司、前同事的打脸建立在真实的投资逻辑上，不是无脑碾压

## 对标作品

- 《重生之都市修仙》（系统+都市逆袭结构）
- 《我有一座冒险屋》（系统升级节奏感）
- 《超级神基因》（金手指逐步升级，避免后期崩坏）

## 开篇钩子

第1章直接从被裁开始——HR通知、工牌被注销、十年资料被清空、前妻催学费。不铺垫、不回忆、直接把读者扔进主角的至暗时刻。第5章系统觉醒，前4章的压抑在第5章集中爆发。
