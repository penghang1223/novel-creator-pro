# 人物档案

## 主角

### 林辰

| 项目 | 设定 |
|------|------|
| 姓名 | 林辰 |
| 年龄 | 32岁（开篇）→35岁（结局） |
| 性别 | 男 |
| 背景 | 互联网公司中层，985毕业，工作10年，一朝被裁 |
| 家庭 | 离异，女儿朵朵6岁（跟前妻苏晴，林辰每月付抚养费+周末陪伴） |

**性格特征**：
- 核心特质：有底线、不圣母、该狠时狠
- 矛盾特质：商场上冷静果断，但面对女儿时柔软到笨拙
- 成长方向：从被动接受命运→主动掌控人生→平衡事业与家庭

**说话风格**：
- 对外：简洁、不废话、偶尔冷幽默
- 对女儿：温柔、耐心、会编故事
- 对前妻：克制、客气、有距离感

**人物弧光**：
- 第1卷：从绝望到希望（被裁→第一桶金）
- 第2卷：从希望到自信（股市崛起→打脸前公司）
- 第3-4卷：从自信到野心（京城立足→资本暗战）
- 第5-6卷：从野心到格局（收购前公司→国际舞台）
- 第7-9卷：从格局到使命（全球投资→超越系统）
- 第10卷：回归本心（家庭圆满→财富自由）

## 反派谱系

### 第2卷反派：刘总

前公司创始人，因错误决策导致公司破产。林辰被裁的直接责任人。

### 第3-4卷反派：王德发

沈家投资委员会委员，对林辰充满敌意。最终因做空天恒亏损被问责。

### 第4卷反派：赵天成

京城四大家族之一赵家掌舵人，投资价值38.5，敌意值75%。联合狙击辰星资本，最终被林辰反杀。

### 第6卷反派：李万山

京城四大家族之一李家掌门人，比赵天成更难缠的老狐狸。试图恶意收购辰星资本，最终失败。

### 第9卷反派：曹德胜

系统创造者张维民的儿子，暗黑资本首领。继承了父亲的AI技术但走向相反方向——用资本统治世界。最终被林辰感化。
