# 那本日记

> 粉色封面，塑料膜已泛黄，边角卷起干瘪。
> 装在"花好月圆"老式铁皮月饼盒里，藏了35年。

## 基本信息

| 属性 | 内容 |
|------|------|
| 发现时间 | 林美凤去世第三天 |
| 发现地点 | 林美凤卧室衣柜上方的月饼铁盒 |
| 外观 | 粉色封面，塑料膜泛黄，边角卷起 |
| 笔迹 | 林美凤的字（每年春节对联都是她写的） |

## 关键疑点

1. **为什么写？** 林美凤不是写日记的人，为何突然开始记录？
2. **写给谁看？** "如果有一天我不在了，我希望有人能找到这个。"
3. **"他"是谁？** 日记中多次提到一个"他"，不是沈建国。
4. **"小赵"是谁？** 1998年医院的保洁赵小满？
5. **换了什么？** 换了孩子——和谁换？为什么？
6. **藏了多久？** 月饼盒1998年前就有，说明藏的不只是日记。
