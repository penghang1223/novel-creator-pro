# 《我丈夫的备忘录里，有另一个我》主角人物档案

## 一、沈念 / 苏晚（女主，27岁）

### 基础信息

| 字段 | 内容 |
|------|------|
| 真名 | 苏晚 |
| 使用名 | 沈念（车祸后被顾言"赋予"的身份） |
| 年龄 | 27岁 |
| 性别 | 女 |
| 职业 | 自由插画师 |
| 外貌 | ①右耳有细小疤痕（大火伤，非车祸）②咬下唇（紧张/思考时的习惯）③笑起来有酒窝 |
| 出场频率 | 主角（第一人称叙述） |

### 出身背景

- **真实身份**：苏晚，苏锦的女儿，10岁时母亲因火灾去世，被送入福利院
- **被赋予的身份**：沈念，与苏晚同年同月同日生，安宁医院病友，先天性心脏病患者
- **家庭关系**：生母苏锦去世，姨妈苏玉芬找了她15年（后期出现）
- **重大事件**：一年前的车祸——沈念心脏病突发，苏晚开车送她去医院，途中出事。沈念死亡，苏晚幸存但失去记忆。

**背景如何影响性格**：
> 苏晚从小在福利院长大，养成了讨好型人格——"只要我对别人好，就不会被抛弃。"这种性格让她在失忆后很容易被"安排"——她不会质疑顾言的说法，因为她害怕失去好不容易拥有的"家"。

### 核心诉求与恐惧

- **表层诉求**：搞清楚备忘录里的"她"是谁
- **深层诉求**：搞清楚自己是谁
- **核心恐惧**："如果我连自己都记不起来，那我还是我吗？"
- **核心渴望**：被真实地爱——不是因为她像谁，而是因为她是她自己

### 性格矛盾

| 表面 | 内在 |
|------|------|
| 温顺、听话、善解人意 | 内心有极强的直觉力——她隐约知道自己不是"沈念" |
| 嘴上说"我不在乎真相" | 实际上比任何人都想知道 |
| 看起来很脆弱 | 但在关键时刻有惊人的韧性（车祸中她活了下来，大火中她也活了下来） |

**道德底色**：
- 善：善良、敏感、有同理心。她不是复仇者，她只是想知道自己是谁
- 恶：几乎没有。但她在"选择成为沈念"的那段时间里，也参与了这个谎言
- 位置：浅灰。她既是受害者，也是共谋者

### 说话风格

- **口头禅**："我不确定……"、"是不是我多想了？"、"算了，没什么"
- **用词偏好**：温和、含蓄，常用自我怀疑的句式
- **情绪表达**：压抑型——极度痛苦时反而会变得很平静
- **压力下表现**：咬下唇，手指无意识地画圈（插画师的习惯）

### 人物弧线

| 阶段 | 状态 |
|------|------|
| 起点（Ch1） | 温顺的妻子，不会质疑丈夫 |
| 中点（Ch10） | 开始反抗——"你骗了我" |
| 转折（Ch18） | 崩溃——发现自己身体里有沈念的心脏 |
| 终点（Ch22） | 和解——"我是苏晚。我身体里有一颗很勇敢的心。" |

### 标志性细节

- 画画时会不自觉地把人物的右耳画上疤痕——这是她潜意识的记忆
- 她画的所有插画里，都有两个女孩手牵手的元素——但她不记得为什么
- 做噩梦时会说一个名字："小晚"——那是沈念对她的称呼

## 二、顾言（男主，30岁）

### 基础信息

| 字段 | 内容 |
|------|------|
| 姓名 | 顾言 |
| 年龄 | 30岁 |
| 性别 | 男 |
| 职业 | 金融分析师（真实职业）/ 曾被苏晚误以为是"顾医生"（Ch2钩子） |
| 外貌 | ①温和型长相 ②眼神深邃（像藏着很多话）③笑起来有泪沟（显疲惫） |
| 出场频率 | 主角（从"我"的视角描述） |

### 出身背景

- **家庭阶级**：中产家庭，父母都是大学教授
- **父母状况**：父母健在，但关系疏远（父母反对他和"来历不明"的苏晚在一起）
- **家庭关系**：与父母关系冷淡，这也是他选择和苏晚单独生活的原因
- **童年重大事件**：少年时父母忙于学术，他被"放养"。习惯了自己做决定，不跟人商量。这导致了他后来"替苏晚做决定"的性格。

**背景如何影响性格**：
> 从小被放养让他学会了独立，但也让他养成了"我自己来"的习惯。他习惯替别人做决定——不是因为控制欲，而是因为他不知道怎么"一起面对"。他用"保护"代替了"信任"。

### 核心诉求与恐惧

- **表层诉求**：保护苏晚不被真相击垮
- **深层诉求**：被原谅——原谅自己没能救沈念，原谅自己用谎言"留住"了苏晚
- **核心恐惧**：再次失去爱的人
- **核心渴望**：有一天苏晚能"自己想起来"——不是他告诉她的，而是她自己找回的

### 性格矛盾

| 表面 | 内在 |
|------|------|
| 温柔、体贴、完美的丈夫 | 用"保护"的方式"欺骗"——最大的温柔也是最大的残忍 |
| 嘴上说"我不需要你记起来" | 内心每天都在煎熬——"她什么时候会发现？" |
| 看起来很坚强 | 但每晚苏晚睡着后，他会偷偷写备忘录——那是他的日记，也是他的忏悔 |

**道德底色**：
- 善：真心爱苏晚。他做的一切都是因为他害怕再次失去
- 恶：剥夺了苏晚知道真相的权利。以爱之名的控制，仍然是控制
- 位置：深灰。他是故事中最复杂的角色——既是加害者也是受害者

### 说话风格

- **口头禅**："没关系"、"有我在"、"你不用想那么多"
- **用词偏好**：温和、简洁，从不提高音量
- **情绪表达**：极度压抑——所有痛苦都写在备忘录里，从不对人说
- **压力下表现**：沉默，独自坐在书房。偶尔会摸一下右手中指的戒指痕（沈念送的戒指他已经摘了，但痕迹还在）

### 人物弧线

| 阶段 | 状态 |
|------|------|
| 起点（Ch1） | 完美的丈夫面具——一切尽在掌控 |
| 中点（Ch10） | 面具破碎——"我一直在等你想起来" |
| 转折（Ch17-18） | 消失——把选择权还给苏晚 |
| 终点（Ch22） | 重生——第二次初见，这一次他是真实的自己 |

### 标志性细节

- 备忘录是他的忏悔录——每一条都以"她"开头，从不用"苏晚"或"沈念"
- 他从不吃香菜——因为沈念不吃，他怕苏晚发现
- 书房上锁的抽屉里有两样东西：一张合影和一封沈念的遗书
