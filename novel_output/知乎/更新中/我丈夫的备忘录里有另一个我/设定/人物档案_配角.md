## 一、林夏（28岁）

### 基础信息

| 字段 | 内容 |
|------|------|
| 姓名 | 林夏 |
| 年龄 | 28岁 |
| 性别 | 女 |
| 职业 | 幼儿园老师 |
| 外貌 | 中长发，圆脸，笑起来很温暖，但眼神深处有愧疚的阴影。左手无名指戴着一枚银戒指（苏晚送的）。 |
| 出场频率 | 主要配角（Ch5首次出场，Ch13/Ch15/Ch19关键戏份） |

### 出身背景

- **家庭阶级**：普通工薪家庭
- **父母状况**：父母健在，关系一般
- **家庭关系**：与母亲关系亲近，父亲沉默寡言
- **童年重大事件**：高中时最好的朋友因抑郁症自杀，她没有察觉到任何征兆。这件事成为她一生的阴影——"如果我当时多问一句就好了。"

**背景如何影响性格**：
> 因为经历过"失去朋友"的痛，林夏对身边人的情绪异常敏感。她会过度保护身边的人——但正是这种"保护欲"，让她在苏晚的事情上选择了沉默。她以为不说就是在保护，实际上是在重复高中的错误。

### 核心诉求与恐惧

- **表层诉求**：保护苏晚（沈念）不受伤害
- **深层诉求**：弥补高中时没能救下朋友的愧疚
- **表层恐惧**：苏晚知道真相后崩溃
- **深层恐惧**：再次因为自己的沉默而失去朋友
- **矛盾**：越想保护，越是在伤害。她的沉默不是爱，是恐惧。

### 性格矛盾

| 表面 | 内在 |
|------|------|
| 温柔、善解人意、永远支持朋友 | 内心有强烈的控制欲——"我来决定什么对你好" |
| 说"有些事不知道更好"是关心 | 实际上是逃避——她害怕面对"说出真相"后的后果 |
| 嘴上说"我没有选择" | 其实她选择了最容易的那条路——沉默 |

**道德底色**：
- 善：真心爱苏晚，愿意为她做任何事——除了说真话
- 恶：以"保护"为名行"隐瞒"之实，剥夺了苏晚知道真相的权利
- 位置：灰色。她不是坏人，但她的善意造成了伤害

### 说话风格

- **口头禅**："有些事，不知道更好"、"你别想太多了"、"听我的"
- **用词偏好**：口语化，常用"亲爱的""宝贝"等亲昵称呼
- **情绪表达**：表面温暖，但遇到敏感话题会突然沉默或转移话题
- **压力下表现**：说话变得很快，手会不自觉地绞在一起

### 人物弧线

| 阶段 | 状态 |
|------|------|
| 起点（Ch5） | 坚守沉默，认为自己在保护苏晚 |
| 转折（Ch13） | 被苏晚的追问逼到墙角，终于说出"两个女孩的故事" |
| 终点（Ch19） | 承认错误："我不该替你决定。对不起。"获得苏晚的原谅 |

**关键转变点**：
1. Ch5：苏晚第一次找她问车祸的事，她回避了。内心挣扎但最终选择了沉默。
2. Ch13：苏晚带着证据来对质，她知道再也瞒不住了。哭着说出了两个女孩的故事。
3. Ch19：苏晚崩溃后，她全程陪伴。第一次承认："我不是在保护你，我是在保护我自己。"

### 与主角的关系

- **关系类型**：闺蜜（认识5年）
- **关系动态**：从"无话不说" → "有所隐瞒" → "坦诚和解"
- **关系意义**：林夏是苏晚在这个城市最亲近的人。她的沉默代表了"中国式友情"中常见的善意谎言——"不说是因为爱你"，但这种爱是有毒的。

### 标志性细节

- 左手无名指的银戒指是苏晚住院时送的，她一直戴着
- 每次苏晚提到"车祸"，她的右手会下意识握紧
- 她的手机里有一张三个人的合影：她、苏晚、沈念。但她从来不敢看

## 二、陈医生（陈志远，45岁）

### 基础信息

| 字段 | 内容 |
|------|------|
| 姓名 | 陈志远 |
| 年龄 | 45岁 |
| 性别 | 男 |
| 职业 | 心理医生（私人诊所） |
| 外貌 | 戴金丝眼镜，头发花白，面容和蔼但眼神锐利。办公室永远很整洁，茶几上放着一盆绿萝。 |
| 出场频率 | 关键配角（Ch7/Ch10/Ch16关键戏份） |

### 出身背景

- **家庭阶级**：医学世家，父亲是三甲医院精神科主任
- **父母状况**：父亲已退休，母亲去世
- **家庭关系**：与父亲关系紧张（父亲认为心理治疗是"伪科学"）
- **童年重大事件**：母亲患有抑郁症，父亲用药物治疗但从未真正理解她。陈志远因此立志学心理学——"我想做父亲没做到的事：真正理解病人。"

**背景如何影响性格**：
> 他对"帮助人"有近乎执念的渴望。但也正因为这种执念，他在顾言的事情上越界了——他把"帮助顾言"置于"职业伦理"之上。他认为自己在做正确的事，但他的"正确"建立在一个谎言上。

### 核心诉求与恐惧

- **表层诉求**：帮助顾言走出创伤
- **深层诉求**：证明自己比父亲更懂"治愈"
- **表层恐惧**：苏晚的记忆恢复会击垮顾言
- **深层恐惧**：承认自己的"治疗"实际上是在助长一个谎言
- **矛盾**：他以"治愈"为名，行"隐瞒"之实。当治愈和真相冲突时，他选择了治愈。

### 性格矛盾

| 表面 | 内在 |
|------|------|
| 专业、温和、值得信赖 | 固执，认为自己的判断永远是对的 |
| 对苏晚说"你的记忆可能永远无法恢复" | 其实他知道恢复的可能性很大——但他不想让她恢复 |
| 嘴上说"我尊重患者的知情权" | 实际上剥夺了苏晚的知情权 |

**道德底色**：
- 善：真心想帮助患者，出发点是好的
- 恶：越过了职业伦理的边界，用专业权威掩盖真相
- 位置：深灰。他的问题不是"坏"，而是"傲慢"——他以为自己有权利替别人做决定

### 说话风格

- **口头禅**："从心理学角度来说……"、"你确定你想知道吗？"、"这需要时间"
- **用词偏好**：专业术语和通俗语言交替，善于用温和的语气说锋利的话
- **情绪表达**：极度控制，几乎不外露情绪。但当苏晚识破他时，他的手会微微发抖
- **压力下表现**：推眼镜（掩饰不安），说话变得非常慢

### 人物弧线

| 阶段 | 状态 |
|------|------|
| 起点（Ch7） | 沉默的同谋者，认为自己在做正确的事 |
| 转折（Ch10） | 苏晚发现心理评估报告后找他质问，他第一次动摇 |
| 终点（Ch16） | 对苏晚坦白一切，承认"我犯了一个专业人员不该犯的错误" |

**关键转变点**：
1. Ch7：苏晚来找他问记忆恢复的事。他说了谎。但苏晚注意到他桌上顾言的病历——这是第一个裂缝。
2. Ch10：苏晚带着心理评估报告来对质。他试图用专业术语搪塞，但苏晚的眼神让他想起了母亲——那个同样被"专业人士"忽视的人。
3. Ch16：他主动找到苏晚，说出了全部真相。他说："我不应该替你和顾言做决定。这是我职业生涯最大的污点。"

### 与主角的关系

- **关系类型**：医患关系（表面上）/ 同谋（实际上）
- **关系动态**：从"权威医生" → "被识破的骗子" → "坦诚的道歉者"
- **关系意义**：陈医生代表了"专业权威"对普通人的碾压。他用知识和地位构建了一堵墙，让苏晚觉得自己"没资格质疑"。当他最终承认错误时，这堵墙才倒下。

### 标志性细节

- 每次说谎时会推一下眼镜
- 办公桌上永远放着一杯已经凉了的茶
- 他的办公室里有一幅字："医者仁心"——但他的所作所为与之相悖

## 三、周警官（周建国，40岁）

### 基础信息

| 字段 | 内容 |
|------|------|
| 姓名 | 周建国 |
| 年龄 | 40岁 |
| 性别 | 男 |
| 职业 | 交警（事故调查科） |
| 外貌 | 中等身材，皮肤黝黑，下巴有胡茬，眼睛很亮。穿着不太合身的制服，袖口有磨损。 |
| 出场频率 | 关键配角（Ch4线索/Ch11-12关键戏份） |

### 出身背景

- **家庭阶级**：农村出身，靠自己考上了警校
- **父母状况**：父亲去世，母亲在老家
- **家庭关系**：妻子两年前因病去世，有一个12岁的女儿由他独自抚养
- **童年重大事件**：少年时目睹一场肇事逃逸，受害者是他的邻居。从那时起，他就发誓要做一个"不放过任何疑点"的人。

**背景如何影响性格**：
> 他经历过"不被看见的真相"——邻居的案子至今未破。这让他对"被掩盖的真相"有一种近乎本能的嗅觉。一年前的车祸，所有人都说是意外，但他总觉得不对劲。

### 核心诉求与恐惧

- **表层诉求**：查清一年前车祸的真相
- **深层诉求**：证明自己的直觉没有错——"我当了15年交警，意外和非意外我分得清"
- **表层恐惧**：被上级施压停止调查
- **深层恐惧**：再次看到一个真相被掩埋（像邻居的案子一样）
- **矛盾**：他执着于"真相"，但他的"真相"可能并不是苏晚需要的

### 性格矛盾

| 表面 | 内在 |
|------|------|
| 严肃、沉默、不苟言笑 | 内心有柔软的一面（对女儿极其温柔） |
| 看起来只是在例行公事 | 实际上在偷偷调查这个案子一年了 |
| 嘴上说"我只是个交警" | 心里觉得这个案子"不该就这么算了" |

**道德底色**：
- 善：正义感极强，看到不公正的事会追到底
- 恶：有时候过于执着，分不清"真相"和"执念"的边界
- 位置：浅灰。他是个好人，但他追求的"真相"未必是苏晚需要的

### 说话风格

- **口头禅**："这个案子……不太对"、"你确定你想看？"、"我当了15年交警"
- **用词偏好**：简短、直接，不喜欢废话。偶尔会冒出一两句农村老话
- **情绪表达**：极少外露，但说到案子时眼神会亮起来
- **压力下表现**：抽烟，沉默

### 人物弧线

| 阶段 | 状态 |
|------|------|
| 起点（Ch4线索） | 在档案中留下线索——被涂掉的名字 |
| 转折（Ch11-12） | 主动找苏晚，提供车祸报告原件，说出他的怀疑 |
| 终点（Ch22） | 车祸真相大白，他终于放下了这个案子 |

**关键转变点**：
1. Ch4（间接）：苏晚找到车祸报告，发现一个被涂掉的名字。这是周警官故意留下的线索——他涂掉名字是上级命令，但他用特殊墨水涂的，用光照能隐约看到。
2. Ch11：他主动找到苏晚，给了她一份车祸报告原件。"我等了一年，终于有人来问了。"
3. Ch12：他告诉苏晚他的怀疑——"那天的刹车痕迹不对。不像是意外失控，更像是……"他没有说完。

### 与主角的关系

- **关系类型**：调查者/协助者
- **关系动态**：从"陌生警官" → "秘密同盟" → "真相揭露者"
- **关系意义**：周警官代表了"体制内的正义"——他想做正确的事，但受制于上级和规则。他用"不完美的方式"（涂掉名字但留线索）来追求真相。

### 标志性细节

- 办公桌上有一个旧相框，里面是他和女儿的合影
- 每次谈到案件，手会下意识摸口袋找烟
- 他的笔记本上密密麻麻记满了手写笔记——一年前的车祸占了整整三页

## 四、苏玉芬（55岁）

### 基础信息

| 字段 | 内容 |
|------|------|
| 姓名 | 苏玉芬 |
| 年龄 | 55岁 |
| 性别 | 女 |
| 职业 | 退休小学教师 |
| 外貌 | 短发花白，面容慈祥但有深深的法令纹，穿着朴素整洁。右耳有一个小耳洞——和苏晚的一样。 |
| 出场频率 | 后期关键配角（Ch18-21关键戏份） |

### 出身背景

- **家庭阶级**：普通家庭
- **父母状况**：父母已故
- **家庭关系**：姐姐（苏晚生母）在苏晚10岁时因火灾去世，之后她一直想找到苏晚，但苏晚被送进了福利院，失联多年
- **童年重大事件**：和姐姐感情极深。姐姐的死是她一生的痛。

**背景如何影响性格**：
> 她用了一生来寻找姐姐的女儿。当她终于找到苏晚时，发现苏晚已经不记得自己是谁了。她选择不直接出现——而是把信息交给了顾言。她和顾言一样，都在用自己的方式"保护"苏晚。

### 核心诉求与恐惧

- **表层诉求**：找到姐姐的女儿，告诉她身世
- **深层诉求**：替姐姐完成未了的心愿——让苏晚知道她不是被抛弃的
- **表层恐惧**：苏晚无法接受真相
- **深层恐惧**：苏晚恨她——"你为什么现在才来找我？"
- **矛盾**：她想找苏晚找了15年，但真正找到后却不敢现身。她怕自己的出现会打破苏晚好不容易建立的生活。

### 性格矛盾

| 表面 | 内在 |
|------|------|
| 温和、慈祥、说话轻声细语 | 内心有极强的韧性——找了15年从未放弃 |
| 看起来只是一个普通的退休教师 | 实际上是故事中"真正的爱"的象征——不求回报的寻找 |
| 说"我不敢认她" | 其实比任何人都想认她 |

**道德底色**：
- 善：纯粹的善意。她找苏晚不是为了什么回报，只是因为"她是姐姐的女儿"
- 恶：几乎没有。她唯一的"错"是出现得太晚
- 位置：纯白。她是故事中最干净的角色

### 说话风格

- **口头禅**："你妈妈以前也这样"、"我找了你好久"、"不怪你，谁都不怪"
- **用词偏好**：朴素、温暖，像外婆说话
- **情绪表达**：克制但深沉，说到姐姐时会红了眼眶但不哭
- **压力下表现**：沉默，然后轻轻叹气

### 人物弧线

| 阶段 | 状态 |
|------|------|
| 起点（Ch18线索） | 通过档案间接出现——苏晚找到她的名字 |
| 转折（Ch19-20） | 亲自出现，告诉苏晚关于她生母的故事 |
| 终点（Ch21） | 和苏晚一起去墓前，三人（苏晚、苏玉芬、沈念）"重逢" |

**关键转变点**：
1. Ch18：苏晚在安宁医院档案中发现"紧急联系人：苏玉芬"——这是她姨妈的名字。
2. Ch19：苏玉芬终于出现。她带了一张照片——苏晚10岁时和妈妈的合影。"你妈妈叫苏锦。她最放不下的人就是你。"
3. Ch21：她陪苏晚一起去沈念的墓前。她说："锦儿，我找到小晚了。她长大了，很好。"

### 与主角的关系

- **关系类型**：失散多年的姨妈
- **关系动态**：从"档案中的名字" → "终于现身的亲人" → "新家庭的纽带"
- **关系意义**：苏玉芬代表了"被时间掩埋的亲情"。她的出现让苏晚明白——即使她失去了记忆，失去了身份，她仍然不是一个人。有人一直在找她。

### 标志性细节

- 随身带着一个旧钱包，钱包里有一张苏晚10岁时的照片（她找了15年的线索之一）
- 右耳和苏晚一样有一个小耳洞——家族遗传
- 做饭时会习惯性多做一份——"万一她今天来了呢"
