## 📝 AI-Ready User Story 模板

### 六组件结构
| 组件 | 说明 | 示例 |
|------|------|------|
| **Intent** | 用户意图 | "作为卖家，我想批量导入商品" |
| **Acceptance** | 谓词式验收标准 | "当上传 Excel 后，系统解析所有行并显示预览" |
| **Examples** | 消歧示例（最强工具） | "示例 1: 100 行商品→预览表格；示例 2: 空行→跳过" |
| **Constraints** | 告诉 AI 不要做什么 | "不存储原始 Excel，不导入重复 SKU" |
| **NFRs** | 非功能需求 | "响应时间<2s，支持 1000 行/次" |
| **Metadata** | 优先级/依赖 | "MoSCoW: Must, 依赖：用户认证" |

## 🚀 AI Agent 企业落地阶段门控

### 治理最低标准
- 范围：明确允许的工具/数据域/动作
- 身份：服务账户/每步归因/审计追踪
- 安全：内容和动作策略
- 人工监督：定义人工介入点
- 变更控制：版本化 prompt/工具 schema
- 第三方：子处理器审查/数据流图/退出计划

### 试点被砍的 5 大原因
1. 所有权模糊
2. Shadow Autonomy
3. 合规债务
4. 实验室经济
5. 二元开关
