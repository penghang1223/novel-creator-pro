## 统一模板结构

每个方案均包含以下7个部分（源自飞书文档模板）：

1. **一句话故事** — 核心概念，30字以内
2. **世界观设计** — 五维模型：时空/规则/权力/禁忌/例外
3. **核心异质物** — 推动剧情的关键道具/异常物
4. **人物设计** — 主角MACH模型（动机/能力/缺陷/成长弧光）+ 配角 + 反派
5. **分卷大纲** — 5卷结构（起/承/转/合/终）
6. **三条暗线全览** — 暗线起点→发展→揭示
7. **伏笔追踪表** — 三级分类（关键🔴/中等🟡/装饰🟢）

## 各方案核心卖点

### A · 《夜班规则》
- **差异化**：规则怪谈 + 底层保安视角
- **情感核**：兄妹情 — 执念驱动一切
- **最大反转**：妹妹不是受害者，是自愿的"守夜人"
- **适合平台**：知乎盐选（社会派悬疑）+ 番茄（规则怪谈热度高）

### B · 《最后的订单》
- **差异化**：外卖员视角 + 编码解谜 + 人口贩卖
- **情感核**：兄弟情 — 老K用生命编码的信息
- **最大反转**：网络不是人在操控，是算法在运作
- **适合平台**：知乎盐选（社会派）+ 短剧改编（外卖员视觉冲击强）

### C · 《失眠者的共眠》
- **差异化**：心理悬疑 + 意识连接 + 黑镜式科技伦理
- **情感核**：自我救赎 — 失眠不是病，是超能力
- **最大反转**：主角不是医生，是实验节点，在帮药企做人体实验
- **适合平台**：知乎盐选（科技伦理讨论度高）

### D · 《轮回APP》
- **差异化**：无限流 + 设定系推理 + 创伤治愈
- **情感核**：原谅自己 — 通关不是逃离，是面对
- **最大反转**：最终副本是主角童年的那场火灾
- **适合平台**：番茄（无限流热度最高）+ 知乎（设定推理）

### E · 《时间当铺》
- **差异化**：时间交易设定 + 哲学反思 + 中国本土化奇幻
- **情感核**：珍惜当下 — 时间不属于当铺，属于活着的人
- **最大反转**：当铺老板都是受害者，东家想回到过去
- **适合平台**：知乎盐选（哲学反思引发讨论）
