## 一、一句话故事

废弃商场的夜班保安收到一本用血写成的"夜班规则手册"——每一条规则都是一条命换来的，而最后一行写着他的名字。

---

## 二、世界观设计（五维模型填充）

### 2.1 时空

| 维度 | 内容 |
|------|------|
| **时代** | 现在线 2024年（主线）+ 过去线 1998-2005年（暗线回溯：商场前身疗养院时期） |
| **核心空间** | "星辉购物广场"——城市边缘的废弃商场，2019年停业，建在旧疗养院原址上 |
| **辅助空间** | 地下室（旧疗养院遗迹保留区）、24小时便利店、城中村出租屋、区档案馆 |
| **空间隐喻** | "星辉购物广场" = 表面繁华消费主义，底下是填平的历史创伤 |

### 2.2 规则

| 类型 | 内容 |
|------|------|
| **明规则** | 物业管理公司规定：夜班巡逻时间表、监控记录流程、紧急报警程序 |
| **暗规则** | "夜班手册"：13条用血写成的规则，每一条都对应一次失踪事件 |
| **深层规则** | 建筑本身有"意志"——旧疗养院的能量残留，以"规则"形态存在，每隔七年"进食"一次 |

### 2.3 权力

| 层级 | 角色 | 权力来源 |
|------|------|---------|
| **表层权力** | 物业管理公司 | 控制夜班规则和信息 |
| **中层权力** | "手册"的原作者（第一个失踪者的亡魂） | 知道真相但已无法直接行动 |
| **终极权力** | 建筑本身的"意志" | 无形，操控规则，无法被常规手段对抗 |

### 2.4 禁忌

- 不得违反手册中的任何一条规则
- 不得在凌晨三点后独自进入地下室
- 不得询问之前保安的失踪原因
- 不得试图带走手册

### 2.5 例外（主角凭什么打破规则）

- **血亲联系**：主角的妹妹是上一个试图破解规则的人，这种血缘让主角能"感知"规则的松动
- **记者训练**：前刑侦记者的逻辑推理能力，能发现规则之间的逻辑漏洞
- **执念驱动**：寻找妹妹的执念让他敢于在关键时刻打破规则

## 三、核心异质物：一本不存在的夜班手册

- 一本破旧的A5笔记本，藏在商场二楼卫生间水箱后面
- 用黑色中性笔写成的13条规则，但每条规则旁边都有不同人的笔迹补充
- 规则内容示例："凌晨两点后，三楼东侧的女卫生间只能进不能出。如果灯闪了三下，站在隔间里不要动。"
- 每次夜班后，手册上会多出一条之前没有的规则——有人（或什么）在续写
- 最后一页有一行字迹："别相信第7条"——但这行字不是手册原作者的笔迹，是妹妹的
- 手册最后一页夹着一张模糊的照片：一个男人在商场中庭被影子吞噬

## 四、人物设计

### 4.1 主角：陈默（32岁，男）

| MACH维度 | 内容 |
|----------|------|
| **动机（M）** | 寻找失踪五年的妹妹陈小雨。她五年前应聘了星辉购物广场的夜班保安，之后人间蒸发。警方以"自行离开"结案，但陈默不信 |
| **能力（A）** | 前刑侦记者——强观察力、逻辑推理、审讯技巧；记者时期学过犯罪心理学，认识几个关键人脉；对"规则"有天生的分析本能 |
| **缺陷（C）** | 执念过重——面对与妹妹有关的线索时容易丧失判断力；独来独往——不信任任何人，习惯一个人扛；曾因调查报道得罪地方势力被开除，有心理阴影 |
| **成长弧光（H）** | 从"只为找妹妹不顾一切"到"愿意保护其他受害者"；学会信任身边的伙伴；最终发现妹妹已不在人世，但她留下的线索救了其他人——他继承了妹妹的意志，成为新的"守夜人" |

### 4.2 核心配角

| 角色 | 类型 | 功能 |
|------|------|------|
| **老周（50+，已失踪）** | 推动型 | 手册的原作者，通过手册上的笔迹"活着"推动剧情。每揭开一条规则，就揭示一段老周的故事 |
| **小林（24岁，女）** | 对比型 | 新来的白班保安，代表"普通人"视角。她的恐惧和无助与陈默的冷静形成对比 |
| **盲人大爷（70+）** | 功能型/线人 | 便利店老板，1998年就在这条街上摆摊。知道疗养院时期的一切，但从不主动说 |
| **赵姐（45岁）** | 推动型 | 物业经理，刻意隐瞒信息。不是坏人，只是不想惹麻烦 |

### 4.3 反派设计

| 层级 | 反派 | 说明 |
|------|------|------|
| **中层反派** | 物业管理公司 | 掩盖失踪事件，修改记录。不是邪恶，只是"不想影响招商" |
| **终极反派** | 建筑"意志" | 不是传统意义上的恶，而是旧疗养院数百名病人的痛苦凝聚成的一种半意识存在。它没有善恶，只有"留住"的本能——每一个失踪者都被"留住"了 |

## 五、分卷大纲（5卷结构）

### 卷一：起 · "手册上的名字不是我的"
- 建立商场的诡异日常：深夜的自动扶梯、监控里的影子、三楼的哭声
- 陈默发现手册，开始尝试遵守规则
- 第一次违规：陈默为了追一个声音打破了"不得进入地下室"的规则
- 在地下室发现妹妹留下的记号——她来过这里，而且不止一次
- **卷末钩子**：手册上多了一条新规则："如果你在读这条规则，说明你已经来晚了。"

### 卷二：承 · "每一条规则都是一条命"
- 陈默开始主动调查，不再被动遵守
- 通过盲人大爷得知疗养院的历史：1998年大火，数十名病人未能逃出
- 发现规则之间的逻辑关联——规则不是孤立的，它们构成了一张"地图"
- 小林遭遇灵异事件，陈默救了她，两人建立信任
- 老周的故事逐渐浮出——他不是受害者，而是自愿留下来的"守夜人"
- **卷末钩子**：陈默发现自己也在手册上留下了笔迹——但他不记得写过

### 卷三：转 · "我不是来找她的，我是来替她的"
- 最大反转：妹妹不是受害者，她是老周的"接班人"，自愿成为新的"守夜人"
- 妹妹留下的信息：她在尝试"关闭"这个建筑，但失败了
- 陈默的执念崩塌——他不是来救妹妹的，他是来继承妹妹未完成的事
- 建筑"意志"的真面目揭示：它不是恶灵，而是数百名病人的集体记忆
- **卷末钩子**：陈默进入最深层的地下室，看到了"它"——一个由记忆构成的人形

### 卷四：合 · "规则是用来打破的"
- 陈默决定不按妹妹的方式——不"关闭"，而是"改写"
- 利用记者的逻辑能力，找到规则的漏洞
- 联合小林和盲人大爷，三个人一起对抗建筑意志
- 老周的亡魂最后一次出现，告诉陈默真相："规则不是为了保护你，是为了保护它自己"
- **高潮**：陈默打破了最核心的规则——在凌晨三点进入了建筑的心脏
- **结局**：建筑没有消失，但它"睡着"了。手册上的规则一条条消失，最后只剩一条："好好活着。"

### 卷五：终 · "新保安的第一夜"（彩蛋）
- 一年后，新的夜班保安来到商场
- 在二楼卫生间后面发现了一本崭新的笔记本
- 上面只有一行字，笔迹是陈默的："凌晨两点后，三楼灯会闪。别怕，那只是风。"
- 暗示：陈默成为了新的"守夜人"，但这次——规则是温暖的
