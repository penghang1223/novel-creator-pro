# Claude Code 读取飞书文档 · 完整配置教程

**创建时间**：2026-04-22 | 实测通过
**适用场景**：Claude Code CLI 读取飞书 Wiki、飞书文档（doc/docx）
**核心方案**：lark-mcp OAuth + Feishu Open API 直接调用

---

## 方案概览

有两种方式读取飞书文档：

| 方案 | 原理 | 优点 | 缺点 |
|------|------|------|------|
| **方案 A：lark-mcp MCP 集成** | 通过 Claude Code 的 `mcpServers` 配置，让 lark-mcp 作为 MCP 工具加载 | 自动化，Claude 直接调用工具 | 需要 Claude Code session 重启才能加载 |
| **方案 B：Open API 直接调用**（✅ 推荐） | 用 `app_id` + `app_secret` 获取 tenant_access_token，通过 curl/python 直接调 API | 即装即用，不依赖 MCP 加载 | 需要手动写 API 调用脚本 |

**推荐方案 B**——更稳定、更快、不依赖 MCP server 的加载状态。

---

## 前置准备

### 1. 获取飞书应用的 App ID 和 App Secret

1. 打开 [飞书开放平台](https://open.feishu.cn/app)
2. 进入你的应用（或创建一个企业自建应用）
3. 在 **凭证与基础信息** 页面找到：
   - `App ID`（格式：`cli_xxxxxxxxxxxx`）
   - `App Secret`（格式：一串随机字符串）

4. 在 **权限管理** 页面确保以下权限已开通：

| 权限 | 说明 |
|------|------|
| `docs:doc:readonly` | 读取旧版文档 |
| `docx:document:readonly` | 读取新版文档 |
| `wiki:wiki:readonly` | 读取 Wiki 节点 |
| `drive:drive:readonly` | 读取云空间文件 |

### 2. 确认文档可访问

- 文档需要在该应用的可见范围内（企业内公开或已授权给应用）
- Wiki 文档需要知道 `wiki_token`（即 URL 末尾那串字符）

## 方案 A：lark-mcp MCP 集成（可选）

### 步骤 1：配置 settings.json

在 Claude Code 项目的 `.claude/settings.json` 中添加：

```json
{
  "mcpServers": {
    "lark-mcp": {
      "command": "npx",
      "args": [
        "-y",
        "@larksuiteoapi/lark-mcp",
        "mcp",
        "-a", "你的App_ID",
        "-s", "你的App_Secret",
        "--oauth",
        "--token-mode", "user_access_token"
      ]
    }
  }
}
```

### 步骤 2：完成 OAuth 授权

```bash
# 启动 OAuth 登录
npx -y @larksuiteoapi/lark-mcp login --oauth --token-mode user_access_token
```

会输出一个授权 URL，在浏览器中打开并点击"授权"。

**重要**：首次使用需要配置回调 URL：
1. 打开 [飞书应用安全设置](https://open.feishu.cn/app/你的App_ID/safe)
2. 添加重定向 URL：`http://localhost:3001/callback`

### 步骤 3：验证登录

```bash
npx -y @larksuiteoapi/lark-mcp whoami
```

成功输出类似：
```
✅ Login successful
App ID: cli_a92842babb389ccd
AccessToken: Valid (not expired)
Scopes: [wiki:wiki:read, docx:document:readonly, ...]
```

### 步骤 4：重启 Claude Code

lark-mcp 工具需要在 Claude Code session 重启后才会出现在可用工具列表中。

**局限性**：
- `--token-mode user_access_token` 模式下，token 存储在本地，需要定期刷新
- MCP server 加载失败时无法排查（stdio 模式无日志输出）

## 方案 B：Open API 直接调用（✅ 推荐）

### 步骤 1：获取 tenant_access_token

```bash
# 用 curl 直接获取
curl -X POST "https://open.feishu.cn/open-apis/auth/v3/tenant_access_token/internal" \
  -H "Content-Type: application/json" \
  -d '{"app_id":"你的App_ID","app_secret":"你的App_Secret"}'
```

返回示例：
```json
{
  "code": 0,
  "msg": "ok",
  "tenant_access_token": "t-g1044mk...",
  "expire": 7200
}
```

**关键信息**：
- `tenant_access_token` 有效期 2 小时，每次请求前可重新获取
- 不需要 OAuth，用 `app_id` + `app_secret` 即可
- 应用需要在企业内，且文档对应用可见

### 步骤 2：通过 wiki_token 获取 obj_token

飞书 Wiki 文档有两层标识：
- `wiki_token`：URL 中的标识，用于 wiki 层级导航
- `obj_token`：实际文档的标识，用于读取内容

```bash
WIKI_TOKEN="从URL获取，如 XmXiwmuqniossJkpOUmcInj4nyd"
TENANT_TOKEN="步骤1获取的token"

# 查询 wiki 节点信息
curl "https://open.feishu.cn/open-apis/wiki/v2/spaces/get_node?token=$WIKI_TOKEN" \
  -H "Authorization: Bearer $TENANT_TOKEN"
```

返回示例：
```json
{
  "code": 0,
  "msg": "success",
  "data": {
    "node": {
      "obj_token": "DqBSdCIMjoxKUAxuAYecSuOgnrc",
      "obj_type": "docx",
      "title": "📖 《她的名字不是她的》· 完整策划方案"
    }
  }
}
```

记录 `obj_token` 和 `obj_type`（`docx` 或 `doc`）。

### 步骤 3：读取文档内容

#### 方式一：raw_content（纯文本，最简单）

```bash
OBJ_TOKEN="步骤2获取的obj_token"

# docx 文档
curl "https://open.feishu.cn/open-apis/docx/v1/documents/$OBJ_TOKEN/raw_content" \
  -H "Authorization: Bearer $TENANT_TOKEN"
```

返回：
```json
{
  "code": 0,
  "data": {
    "content": "纯文本内容，表格结构会丢失为制表符分隔"
  }
}
```

**优点**：一次请求获取全部内容，简单
**缺点**：丢失表格、列表、格式等结构信息

#### 方式二：blocks API（保留结构）

```bash
# 获取根 block 的子节点
curl "https://open.feishu.cn/open-apis/docx/v1/documents/$OBJ_TOKEN/blocks/$OBJ_TOKEN/children?page_size=500" \
  -H "Authorization: Bearer $TENANT_TOKEN"
```

返回每个 block 的类型和内容，包括：
- `block_type`: 1=page, 2=text, 3=heading1, 29=table, 30=table_cell 等
- `text_elements`: 文本内容
- `children`: 子 block ID 列表

**优点**：保留完整结构
**缺点**：需要递归获取所有 block，较复杂

### 步骤 4：Python 脚本（一键读取）

将以下步骤 1-3 整合为一个脚本：

```python
#!/usr/bin/env python3
"""读取飞书文档内容，输出为 Markdown 格式"""

import urllib.request
import json
import ssl
import sys

# ========== 配置区 ==========
APP_ID = "你的App_ID"
APP_SECRET = "你的App_Secret"
WIKI_TOKEN = "从飞书文档 URL 获取"
# 或者直接用 obj_token（如果知道的话）:
# OBJ_TOKEN = "直接指定"
# ============================

ctx = ssl.create_default_context()

def get_tenant_token():
    """获取 tenant_access_token"""
    url = "https://open.feishu.cn/open-apis/auth/v3/tenant_access_token/internal"
    data = json.dumps({"app_id": APP_ID, "app_secret": APP_SECRET}).encode()
    req = urllib.request.Request(url, data=data, headers={"Content-Type": "application/json"})
    resp = urllib.request.urlopen(req, context=ctx)
    result = json.loads(resp.read())
    if result.get("code") != 0:
        raise Exception(f"获取 token 失败: {result}")
    return result["tenant_access_token"]

def get_obj_token(wiki_token, tenant_token):
    """通过 wiki_token 获取 obj_token"""
    url = f"https://open.feishu.cn/open-apis/wiki/v2/spaces/get_node?token={wiki_token}"
    req = urllib.request.Request(url, headers={"Authorization": f"Bearer {tenant_token}"})
    resp = urllib.request.urlopen(req, context=ctx)
    result = json.loads(resp.read())
    node = result["data"]["node"]
    return node["obj_token"], node["obj_type"]

def get_doc_content(obj_token, tenant_token):
    """获取文档纯文本内容"""
    url = f"https://open.feishu.cn/open-apis/docx/v1/documents/{obj_token}/raw_content"
    req = urllib.request.Request(url, headers={"Authorization": f"Bearer {tenant_token}"})
    resp = urllib.request.urlopen(req, context=ctx)
    result = json.loads(resp.read())
    return result["data"]["content"]

def main():
    print("1. 获取 tenant_access_token...")
    token = get_tenant_token()
    
    if WIKI_TOKEN and not globals().get("OBJ_TOKEN"):
        print(f"2. 解析 wiki_token: {WIKI_TOKEN}...")
        obj_token, obj_type = get_obj_token(WIKI_TOKEN, token)
        print(f"   obj_token: {obj_token}, obj_type: {obj_type}")
    else:
        obj_token = globals().get("OBJ_TOKEN", "")
        obj_type = "docx"
    
    print(f"3. 读取文档内容...")
    content = get_doc_content(obj_token, token)
    print(f"\n内容长度: {len(content)} 字符")
    print("=" * 50)
    print(content)

if __name__ == "__main__":
    main()
```

使用方法：
```bash
# 修改脚本中的 APP_ID、APP_SECRET、WIKI_TOKEN
python3 read_feishu_doc.py

# 或保存到文件
python3 read_feishu_doc.py > output.md
```

## 常见问题

### Q1: token 过期了怎么办？

`tenant_access_token` 有效期 2 小时。方案：每次读取前重新获取（推荐），或者缓存 token 并在过期前刷新。

### Q2: 读不到文档内容，返回权限错误？

检查以下几点：
1. 应用的权限是否包含 `docx:document:readonly` 和 `wiki:wiki:readonly`
2. 文档是否对应用可见（企业内公开文档可以，个人私密文档不行）
3. 应用是否已发布（未发布的应用 token 无效）

### Q3: 表格内容格式混乱？

`raw_content` API 会丢失表格结构。如果需要保留表格，使用 `blocks` API 逐块读取，或者用 Chrome DevTools MCP 截取网页快照。

### Q4: 非 Wiki 文档（直接分享的文档链接）怎么读？

直接从 URL 中提取 `obj_token`：
- 新版文档 URL：`https://xxx.feishu.cn/docx/ABC123TOKEN...` → `obj_token = ABC123TOKEN`
- 旧版文档 URL：`https://xxx.feishu.cn/doc/ABC123TOKEN...` → `obj_token = ABC123TOKEN`
- Wiki 文档 URL：`https://xxx.feishu.cn/wiki/ABC123TOKEN...` → 需要先查节点获取 `obj_token`

### Q5: lark-mcp 的 user_access_token 和 tenant_access_token 有什么区别？

| | user_access_token | tenant_access_token |
|--|---|---|
| **获取方式** | OAuth 用户授权 | app_id + app_secret |
| **权限范围** | 用户个人能访问的文档 | 应用在企业内能访问的文档 |
| **有效期** | 较长（可刷新） | 2 小时 |
| **适用场景** | 个人文档、私人 Wiki | 企业内公开文档、团队 Wiki |

## 网络请求流程图

```
1. POST /auth/v3/tenant_access_token/internal
   → 请求体: {app_id, app_secret}
   ← 返回: {tenant_access_token, expire}

2. GET /wiki/v2/spaces/get_node?token={wiki_token}
   → Header: Authorization: Bearer {tenant_access_token}
   ← 返回: {obj_token, obj_type, title}

3. GET /docx/v1/documents/{obj_token}/raw_content
   → Header: Authorization: Bearer {tenant_access_token}
   ← 返回: {content} (纯文本)

或者：

3b. GET /docx/v1/documents/{obj_token}/blocks/{obj_token}/children
   → Header: Authorization: Bearer {tenant_access_token}
   ← 返回: {items: [{block_id, block_type, text_elements, children}]}
```
