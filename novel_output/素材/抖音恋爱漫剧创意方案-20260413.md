## 🎯 二、受众分析（JTBD框架）

### 目标受众画像
**核心受众**：18-35岁女性，抖音活跃用户，日均刷短视频1-3小时

### Jobs To Be Done
| Job类型 | 描述 | 当前替代方案 |
|---------|------|--------------|
| **功能性Job** | 通勤/睡前/碎片时间有内容可看 | 真人短剧/小说/综艺 |
| **情感性Job** | 获得情感代偿/恋爱幻想/情绪释放 | 言情小说/乙女游戏 |
| **社交性Job** | 有话题和闺蜜讨论/分享 | 热播剧/综艺 |

### 核心洞察
**用户雇佣恋爱漫剧不是为了"看故事"，而是为了：**
1. **体验理想恋爱** — 现实中没有的浪漫/被偏爱/被理解
2. **确认自我价值** — 女主独立清醒，投射"我也能做到"
3. **社交货币** — 和闺蜜讨论"男主好甜/女主好飒"

## 💡 三、创意方案（3个方向）

### 方向A：《离婚后，她成了他的甲方》
**一句话**：前妻变甲方，霸总追妻火葬场

| 维度 | 内容 |
|------|------|
| **题材** | 先婚后爱+追妻火葬场+职场逆袭 |
| **核心矛盾** | 女主离婚后成为男主公司的甲方负责人，身份反转 |
| **Hook** | "三年前你签离婚协议说我不配，今天你求我签字" |
| **集数** | 60集×90秒 |
| **情绪节奏** | 爽（身份反转）→ 虐（追妻火葬场）→ 甜（重新爱上） |
| **差异化** | 传统霸总是"救赎"，这个是"惩罚+成长" |

### 方向B：《我的AI男友会吃醋》
**一句话**：AI男友觉醒自我意识，和真人男友争宠

| 维度 | 内容 |
|------|------|
| **题材** | 科幻恋爱+轻喜剧+三角关系 |
| **核心矛盾** | 女主买的AI男友突然有了感情，和真人男友展开竞争 |
| **Hook** | "他连我生理期都记不住，我的AI男友却为我学会了哭" |
| **集数** | 40集×90秒 |
| **情绪节奏** | 搞笑（AI吃醋）→ 感动（AI真心）→ 思考（什么是爱） |
| **差异化** | AI题材+恋爱，天然适合AI漫剧形式 |

### 方向C：《她在热搜上谈恋爱》
**一句话**：顶流女星和素人恋爱，全网直播磕CP

| 维度 | 内容 |
|------|------|
| **题材** | 娱乐圈+素人恋爱+网络暴力+双向奔赴 |
| **核心矛盾** | 顶流女星和素人男主恋爱，全网反对，两人如何坚持 |
| **Hook** | "所有人都说你不配，但只有我知道你有多好" |
| **集数** | 50集×90秒 |
| **情绪节奏**：甜（偷偷恋爱）→ 虐（全网网暴）→ 燃（公开对抗） |
| **差异化** | 互动性强，可设计"全网磕CP"互动玩法 |

## 📐 四、叙事结构（推荐方向A）

### 单集结构（90秒Hook Model）
```
0-3s:   HOOK — "三年前你签离婚协议说我不配"
3-15s:  SETUP — 建立当下情境（女主已是甲方）
15-60s: CONFLICT — 情感冲突升级（男主求合作被拒）
60-80s: CLIMAX — 本集高潮（男主红眼眶"能不能重新认识一次"）
80-90s: CLIFFHANGER — 悬念（女助理推门进来看到这一幕）
```

### 季叙事弧线（60集）
| 阶段 | 集数 | 内容 | 情绪 |
|------|------|------|------|
| **身份反转** | 1-10 | 女主变身甲方，男主震惊 | 爽 |
| **猫鼠游戏** | 11-25 | 职场交锋+情感试探 | 甜虐交织 |
| **真相揭露** | 26-35 | 当年离婚真相/误会 | 虐 |
| **追妻火葬场** | 36-50 | 男主疯狂追妻 | 爽+甜 |
| **危机与选择** | 51-55 | 新危机出现 | 紧张 |
| **HE结局** | 56-60 | 重新在一起 | 甜+治愈 |

### 关键设计
- **每3集一个小payoff**（防止观众流失）
- **每10集一个大转折**（维持追更动力）
- **每集结尾必须cliffhanger**（Hook Model的Variable Reward）

## 🎨 五、角色设计（原型理论）

### 女主：林知夏（28岁）
| 维度 | 设计 |
|------|------|
| **原型** | **英雄（Hero）+ 统治者（Ruler）** |
| **核心特质** | 清醒/独立/有野心/不恋爱脑 |
| **视觉风格** | 职场干练风，冷色调（蓝/灰/白），后期逐渐加入暖色 |
| **角色弧光** | 从"被抛弃的前妻"→"独当一面的甲方女王" |
| **记忆点** | 标志性的红唇/高跟鞋声音/永远挺直的背 |

### 男主：陆景深（30岁）
| 维度 | 设计 |
|------|------|
| **原型** | **爱人（Lover）+ 照顾者（Caregiver）** |
| **核心特质** | 霸道但内心柔软/后悔/学会尊重 |
| **视觉风格** | 西装/深色系，后期逐渐柔和 |
| **角色弧光** | 从"傲慢霸总"→"学会爱的男人" |
| **记忆点** | 习惯性皱眉/紧张时会摸领带/红眼眶 |

### 色彩策略
| 阶段 | 主色调 | 情绪 |
|------|--------|------|
| 1-10集 | 冷蓝/灰 | 疏离/职场 |
| 11-35集 | 冷暖交替 | 拉扯/试探 |
| 36-50集 | 暖橙/粉 | 追妻/甜 |
| 51-60集 | 暖金/白 | 治愈/HE |
