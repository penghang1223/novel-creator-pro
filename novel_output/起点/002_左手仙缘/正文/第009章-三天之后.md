# 第009章 三天之后

第三天深夜，林左被疼醒了。

不是普通的疼。像是有一万只蚂蚁在左手掌心爬行，从指尖到手腕，密密麻麻，又痒又麻又疼。

他猛地睁开眼。

左手在发光。

绷带下面透出灰白色的光芒，不刺眼，但很清晰。光芒在流动，沿着掌心的纹路——那条现在已经变成网状结构的纹路——扩散到整条手臂。

他解开绷带。

掌心上的网纹变得清晰可见。不是画上去的，是从皮肤里面透出来的。网纹的中心，有一个很小的、几乎看不见的漩涡图案。

然后，疼感消失了。

取而代之的是一种全新的感觉——左手"醒"了。

不只是恢复知觉。是升级。

林左能感觉到左手的变化。之前，万象触能复制功法、灵力运转方式。现在——多了一种能力。

复制法宝特性。

这个认知不是"想"出来的，是直接出现在脑海里的。像是万象触自己告诉他的。

林左从床底下翻出自己的铁剑。

这是他杂役院的标配——凡铁打造的剑，没有灵力加持，砍柴都费劲。但他平时用不上剑，就一直搁在床底。

他把铁剑拿出来，放在桌上。

然后伸出左手，握住了剑柄。

万象触，启动。

一瞬间，铁剑的剑身泛起了灵光。淡淡的、灰白色的灵光，从剑柄蔓延到剑尖。剑身发出低沉的嗡鸣，像是在欢呼。

林左举起剑。

剑的重量没变，但"质感"完全不一样了。他能感觉到剑身里流动着灵力——那是万象触临时赋予的法宝特性。

灵器级别。

一把凡铁剑，被他的左手提升到了灵器级别。

林左走到院子后面，对着那块用来练拳的巨石挥了一剑。

灰白色灵光一闪。

巨石从中间裂开，两半石块轰然倒地，切口平滑如镜。

林左看了看剑，又看了看地上的石块。

"……"

他把剑收回来，仔细观察剑身的灵光。

灵光在缓慢消退。从剑尖开始，一点一点地往后退。他估算了一下，大概十分钟就会完全消失。

十分钟的灵器。

对于一把凡铁剑来说，十分钟的灵器级别，足够斩断精钢、劈开巨石、甚至伤到凝气境的修士。

林左把剑插回地上，坐了下来。

左手掌心的网纹已经淡了下去，但还是能看到。漩涡图案也还在，比之前大了一点。

他试着用右手活动了几下——右手的指尖还是有些发麻。上次打赵虎之后就一直这样，到现在没好。

万象触的副作用。

用左手越多，右手越麻木。这像是某种平衡——左手获得了能力，右手在付出代价。

林左不知道这个代价的极限在哪里。

如果右手彻底麻木了会怎样？

他没有答案。

"控制用量。"他给自己定了一条规矩。

能不用就不用。非用不可的时候，速战速决。

他把绷带重新缠上左手，回屋睡觉。

第二天早上，他照常去藏经阁扫地。

左手恢复了正常，但掌心的网纹还在。他不确定这个纹路会不会消失，也不确定别人能不能看到。

"绷带不能摘。"

他做出决定。至少在弄清楚万象触的全部秘密之前，左手不能暴露。

到了藏经阁，周长老看了他一眼。

"你的手好了？"

"好多了。"

"那就好。今天继续扫三层。"

林左点了点头。

扫三层的时候，他刻意控制左手不去碰功法书。左手现在"吃饱了"，暂时没有"饿"的感觉。但他知道，这只是暂时的。

万象触的"饥饿"迟早会再来。

下一次，它想吃什么？
