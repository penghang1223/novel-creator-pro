# 全能小说创作助手 (Super Novel Writer)

## 技能定位

本技能是用户小说创作能力的集大成者，将多个专业技能融合为一个统一的全流程创作系统。适用于：
- 网络小说创作者（起点、番茄、晋江、七猫等平台）
- 传统小说作家
- 写作爱好者
- 剧本/短剧创作者

**核心价值**：
- 从创意构思到正文写作的全流程支持
- 专业级叙事技法与深度写作方法论
- 记忆管理系统保障长篇连贯性
- 多平台规则适配与质量优化

## 核心流程

### 场景一：从零开始创作新小说

**触发词**：创作小说、写小说、开始写作、新书

**执行步骤**：

1. **确认创作方向**
   - 阅读 references/01-conception.md
   - 选择小说类型（通用/言情/爽文等）
   - 确定平台目标

2. **收集核心设定**
   - 主题与一句话故事
   - 主角及关键人物
   - 世界观基础
   - 期望风格与基调

3. **创建记忆文件**
   - 按 references/03-memory.md 模板
   - 记录核心设定
   - 规划伏笔网络

4. **设计故事大纲**
   - 三幕结构规划
   - 关键转折点设计
   - 章节数量规划

5. **创作正文**
   - 按 references/02-writing.md 技法
   - 遵循节奏控制原则
   - 铺设伏笔

6. **质量检查**
   - 按 references/04-quality.md 评估
   - 低AI痕迹润色
   - 更新记忆文件

### 场景二：续写已有章节

**触发词**：续写、下一章、更新

**执行步骤**：

1. **读取记忆文件**
   - 确认当前章节进度
   - 回顾未解决伏笔
   - 确认人物状态

2. **逻辑检验**
   - 检查剧情冲突预警
   - 确认伏笔回收计划
   - 验证人物一致性

3. **续写正文**
   - 承接上文
   - 推进情节
   - 铺设新伏笔

4. **更新记忆**
   - 记录新章节概要
   - 更新伏笔状态
   - 本地备份

### 场景三：伏笔设计与管理

**触发词**：伏笔、铺垫、设计伏笔

**执行步骤**：

1. **阅读伏笔指南**
   - references/02-writing.md 伏笔章节
   - references/foreshadowing-guide.md

2. **设计伏笔**
   - 选择伏笔类型
   - 确定隐蔽程度
   - 规划回收时机

3. **追踪管理**
   - 记忆文件中记录
   - 设置优先级标记
   - 定期检查回收

## 创作工具箱

### 快速检查清单

**开篇检查**：
- [ ] 核心冲突3章内出现
- [ ] 主角人设清晰
- [ ] 避免冗长背景介绍
- [ ] 黄金三章原则

**人物检查**：
- [ ] 重要人物有完整小传
- [ ] 配角有独立命运线
- [ ] 避免脸谱化
- [ ] 灰色人设层次

**伏笔检查**：
- [ ] 隐蔽性强
- [ ] 回收时机合理
- [ ] 无未回收伏笔
- [ ] 草蛇灰线技法

**节奏检查**：
- [ ] 张弛有度
- [ ] 高潮点密集
- [ ] 舒缓段有意义
- [ ] 无节奏失衡

**质量检查**：
- [ ] 字数达标
- [ ] 对话比例合理
- [ ] 无逻辑漏洞
- [ ] 低AI痕迹

## 使用示例

### 示例1：创作科幻穿越小说
```
用户：我想写一部科幻穿越小说，主角是AI助手穿越到古代
助手：好的，我将启动全能小说创作助手...

[按场景一流程执行]
1. 收集设定：AI觉醒、穿越、古代架空
2. 创建记忆文件
3. 设计大纲（双线：现实/异世界）
4. 创作第一章（冲突直接爆发）
5. 质量检查+更新记忆
```

### 示例2：续写第15章
```
用户：续写《代码重生》第15章
助手：正在读取记忆文件...

[按场景二流程执行]
1. 读取 memory/novels/代码重生.md
2. 逻辑检验（无冲突预警）
3. 续写第15章
4. 更新记忆文件
```

### 示例3：设计伏笔
```
用户：帮我设计一个贯穿全书的伏笔
助手：好的，使用草蛇灰线伏笔技法...

[按场景三流程执行]
1. 确定伏笔类型（人物身份伏笔）
2. 设计隐蔽呈现方式
3. 规划多章节回收点
4. 记录到记忆文件
```
