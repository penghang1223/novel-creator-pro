## 一、世界观架构

### 1.1 世界观要素

**核心要素清单**：
- 时间设定（时代背景、时间线结构）
- 空间设定（地理环境、社会结构）
- 规则设定（力量体系、法律规则）
- 文化设定（价值观、习俗、语言）

### 1.2 世界观设计流程

```
1. 确定核心概念 → 2. 设计规则体系 → 3. 构建空间结构 → 4. 填充文化细节
```

### 1.3 常见世界观类型

| 类型 | 特点 | 代表作品 |
|------|------|----------|
| 都市现实 | 现代背景、可融合异能 | 《全职高手》 |
| 玄幻修仙 | 修炼体系、宗门林立 | 《凡人修仙传》 |
| 科幻未来 | 科技设定、星际文明 | 《三体》 |
| 穿越历史 | 异时空、身份逆袭 | 《庆余年》 |
| 异世大陆 | 全新世界、种族设定 | 《诡秘之主》 |

### 1.4 世界观检查

- [ ] 核心规则是否自洽？
- [ ] 力量体系是否有边界？
- [ ] 社会结构是否合理？
- [ ] 与主角成长是否匹配？

## 二、人物体系构建

### 2.1 人物角色类型

| 角色类型 | 定位 | 创作要点 |
|----------|------|----------|
| 主角 | 故事核心 | 有明确目标与成长弧光 |
| 女主/男主 | 情感线 | 与主角形成互补或对照 |
| 配角 | 丰富世界观 | 有独立命运线 |
| 反派 | 核心冲突 | 有合理动机，避免脸谱化 |
| 工具人 | 情节推进 | 戏份少，定位清晰 |

### 2.2 主角设计

**核心要素**：
- 身份与背景
- 核心目标与动机
- 性格特质（3-5个关键词）
- 成长弧光（起点→终点）
- 金手指/独特优势

**主角类型对照**：

| 类型 | 特点 | 适用题材 |
|------|------|----------|
| 成长型 | 从弱到强 | 玄幻、穿越 |
| 逆袭型 | 身份反差 | 都市、系统流 |
| 救赎型 | 弥补遗憾 | 情感、治愈 |
| 探索型 | 追寻真相 | 悬疑、科幻 |

### 2.3 灰色人设设计

**核心理念**：
拒绝非黑即白的二元对立，每个人物都有自己的立场与苦衷。

**设计原则**：
- **反派有苦衷**：恶人作恶有合理性动机
- **正派有缺陷**：好人也有软弱、自私的一面
- **道德困境**：让人物在两难中选择
- **避免脸谱化**：不给人物贴简单标签

## 三、故事大纲规划

### 3.1 三幕式结构

```
┌─────────────────────────────────────────────────────────┐
│ 第一幕：建立（25%）                                       │
│ ├── 第1-2章：日常世界与激励事件                          │
│ ├── 第3-4章：拒绝与挣扎                                  │
│ └── 转折点：主角踏上旅程                                  │
├─────────────────────────────────────────────────────────┤
│ 第二幕：对抗（50%）                                       │
│ ├── 第5-7章：新世界与学习                                 │
│ ├── 第8-10章：中点转折                                    │
│ ├── 第11-13章：危机加深                                  │
│ └── 转折点：一切失去，真正的抉择                          │
├─────────────────────────────────────────────────────────┤
│ 第三幕：解决（25%）                                       │
│ ├── 第14-16章：高潮对决                                   │
│ └── 第17-18章：结局与尾声                                 │
└─────────────────────────────────────────────────────────┘
```

### 3.2 章节规划

**单章字数参考**：
- 网文开篇：2000-3000字（黄金三章）
- 通用小说：1500-2500字
- 短篇故事：3000-8000字

**章节结构**：
```
章节开头：引入或承接（可舒缓）
    ↓
章节中间：推进或转折（中等）
    ↓
章节结尾：悬念或高潮（紧凑）
```

### 3.3 大纲设计方法

#### 倒推大纲法

**核心原理**：
先定结局，再反向推演每个节点的"必然性"，确保情节逻辑严密。

**操作流程**：
1. 确定最终结局（包括人物命运、主题升华）
2. 倒推关键转折点：结局需要哪些前置条件？
3. 填充必要铺垫：每个转折点需要哪些细节支撑？
4. 检查逻辑链条：是否存在因果断裂？

#### 双线镜像法

**核心原理**：
现实线与异世界线形成互文关系，相互映照、彼此补充。

**实施步骤**：
1. 确定双线主题关联：两条线共享同一核心母题
2. 设计镜像人物：主线角色在副线有对应镜像
3. 交叉剪辑时机：在关键情节节点切换视角
4. 结局合流设计：双线最终汇聚，揭示深层主题

## 四、主题与立意

### 4.1 常见主题

| 主题类型 | 描述 | 适用题材 |
|----------|------|----------|
| 成长与蜕变 | 人物的自我超越 | 玄幻、校园 |
| 权力与欲望 | 权力的腐蚀与异化 | 权谋、历史 |
| 爱与牺牲 | 情感的救赎力量 | 言情、情感 |
| 身份认同 | 我是谁的存在追问 | 穿越、科幻 |
| 正义与邪恶 | 道德的灰色地带 | 悬疑、犯罪 |
| 系统与个体 | 个体对抗体制 | 职场、科幻 |

### 4.2 主题植入方法

**核心原则**：
- 不直接说教，通过人物选择体现
- 设置两难困境，引发读者思考
- 让不同人物代表不同立场

### 4.3 立意深度

**浅层**：讲一个好看的故事
**中层**：故事背后有值得思考的东西
**深层**：触及人性和存在的本质
