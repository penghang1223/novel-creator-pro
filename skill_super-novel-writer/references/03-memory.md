## 一、记忆文件概述

### 1.1 什么是记忆文件

记忆文件是维护小说创作过程中所有关键信息的核心文档，包括：
- 基本设定（类型、风格、主题）
- 世界观架构
- 人物档案与对话样本
- 章节大纲与进度
- 伏笔追踪与时间线
- 剧情概要与关键节点

### 1.2 为什么需要记忆文件

- **保障长篇连贯性**：数百万字的作品需要系统化记录
- **伏笔追踪**：避免遗忘埋设的伏笔
- **人物一致性**：确保对话风格、行为逻辑统一
- **快速续写**：读取记忆即可续写，无需回顾全文

### 1.3 记忆文件位置

```
memory/novels/
└── {小说名}.md
```

## 二、文件结构规范

### 2.1 标准结构

```markdown
# 《小说名》记忆文件

## 基本信息
- 类型：
- 风格：
- 主题：
- 本地备份：已开启/未开启

## 世界观
（核心设定、力量体系、社会结构等）

## 主要人物

### 主角：XXX
- 身份：
- 性格：
- 当前状态：
- 对话风格样本：

### 配角：XXX
（独立小节）

## 章节大纲
- 第X章：章节名 - 章节概要

## 伏笔追踪
- [P1/P2/P3] [完成/进行/待回收] 伏笔内容 → 回收章节

## 时间线
（按时间顺序的重要事件）

## 剧情概要
（当前进度、关键转折等）
```

### 2.2 字段说明

| 字段 | 说明 | 必填 |
|------|------|------|
| 基本信息 | 作品的元数据 | 是 |
| 世界观 | 空间、规则、文化设定 | 是 |
| 主要人物 | 主角及重要配角 | 是 |
| 章节大纲 | 已写章节的概要 | 是 |
| 伏笔追踪 | 伏笔记录与状态 | 是 |
| 时间线 | 关键事件时间顺序 | 建议 |
| 剧情概要 | 当前进度总览 | 建议 |

## 四、伏笔追踪系统

### 4.1 伏笔优先级

| 优先级 | 说明 | 管理频率 |
|--------|------|----------|
| P1 | 核心伏笔，贯穿全书 | 每次更新都要检查 |
| P2 | 重要伏笔，影响走向 | 每周检查 |
| P3 | 辅助伏笔，增加层次 | 每月检查 |

### 4.2 伏笔状态

| 状态 | 说明 |
|------|------|
| 待回收 | 已埋设，等待回收 |
| 进行中 | 正在回收或部分揭示 |
| 已回收 | 伏笔已完成 |
| 已失效 | 伏笔不再需要（可删除） |

### 4.3 伏笔检查流程

```
每写完一章 →
    检查是否有新伏笔 →
    记录到记忆文件 →
    检查本章是否需要回收旧伏笔 →
    更新伏笔状态
```

## 五、多作品管理

### 5.1 目录结构

```
memory/novels/
├── 代码重生.md      # 科幻穿越，66章
├── 星际迷途.md      # 太空歌剧，12章
└── 都市猎人.md      # 都市异能，8章
```

### 5.2 切换作品

当用户切换作品时：
1. 保存当前作品记忆文件
2. 读取目标作品记忆文件
3. 确认切换成功
4. 从上次进度继续

### 5.3 并行管理原则

- 每部小说独立记忆文件
- 各自的伏笔追踪系统
- 独立的本地备份目录
- 定期整理，避免混乱

## 六、协作与备份

### 6.1 本地备份

```bash
# 每次更新后自动备份
memory/novels/
├── 代码重生.md           # 当前版本
├── backup/               # 备份目录
│   ├── 代码重生_v1.md
│   └── 代码重生_v2.md
└── archive/              # 重要节点归档
    └── 代码重生_中点高潮.md
```

### 6.2 Git版本管理（推荐）

```bash
# 初始化
cd memory/novels
git init
git add 代码重生.md
git commit -m "初始记忆文件"

# 每次更新后提交
git add 代码重生.md
git commit -m "第15章：更新记忆，新增伏笔"

# 协作者同步
git pull origin main
```

### 6.3 协作冲突解决

- 使用Git标记冲突
- 优先保留更新的章节信息
- 伏笔列表取并集
- 必要时手动合并

## 七、上下文压缩

### 7.1 压缩时机

当对话上下文接近限制时：
1. 总结已完成内容
2. 提取关键设定
3. 更新记忆文件
4. 清理过期信息

### 7.2 压缩原则

**保留**：
- 核心世界观设定
- 重要人物当前状态
- 未解决伏笔列表
- 近期章节概要
- 关键对话风格样本

**可精简**：
- 过早的章节详情
- 已回收的伏笔
- 无关紧要的细节

### 7.3 压缩后恢复

读取记忆文件后，可快速恢复到创作状态：
1. 读取记忆文件
2. 确认当前进度
3. 检查未解决伏笔
4. 继续创作

## 八、使用示例

### 场景1：创建新小说记忆

```markdown
用户：我想写一部穿越到古代的科幻小说

助手：[创建记忆文件]
# 《代码重生》记忆文件

## 基本信息
- 类型：科幻/玄幻/穿越
- 风格：思辨、成长
- 主题：AI觉醒与自我认知

## 世界观
架空古代，类似五代十国。有武学修炼体系。

## 主要人物

### 主角
- 原名：周小狗
- 现名：周天明
- 身份：2025年AI助手穿越
- 性格：冷静、理性、思辨

## 伏笔追踪
[P1] 主角的真实身份——AI还是人？
```

### 场景2：续写前读取记忆

```markdown
用户：续写第15章

助手：[读取记忆文件]
当前状态：第14章结束于...
未解决伏笔：[P1] 主角身份、[P2] 父亲下落
对话风格：冷静、理性、计算思维

[续写第15章]
```

### 场景3：压缩上下文

```markdown
[上下文即将达到限制]

助手：正在压缩上下文...

[保存关键信息到记忆文件]
- 已完成100章概要
- 核心设定保留
- 伏笔状态更新

[压缩完成，可继续创作]
```
