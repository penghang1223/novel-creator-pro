## 一、数据检查标准

### 1.1 字数统计

| 类型 | 单章字数 | 说明 |
|------|----------|------|
| 网文开篇 | 2000-3000字 | 黄金三章要求 |
| 通用小说 | 1500-2500字 | 标准章节 |
| 短篇小说 | 3000-8000字 | 完整故事 |
| 言情发展 | 1500字左右 | 中等篇幅 |

**检查要点**：
- [ ] 每章节是否在规定范围内
- [ ] 字数分布是否均匀
- [ ] 总字数是否符合预期篇幅

### 1.2 段落结构

| 段落类型 | 字数范围 | 说明 |
|----------|----------|------|
| 短段落 | 30字以下 | 用于快节奏、强调 |
| 标准段落 | 80-150字 | 阅读舒适区 |
| 长段落 | 300字以上 | 需评估是否拆分 |

**检查要点**：
- [ ] 段落长度是否多样化（长短结合）
- [ ] 是否存在过长的大段落
- [ ] 段落切换是否流畅

### 1.3 对话分析

| 对话占比 | 效果 |
|----------|------|
| <20% | 可能节奏拖沓，缺乏互动 |
| 20%-40% | 平衡区间（推荐） |
| >40% | 可能缺乏必要描写 |

**检查要点**：
- [ ] 对话与叙述的比例是否平衡
- [ ] 对话是否符合人物性格
- [ ] 对话是否推进情节或揭示信息

### 1.4 关键词与意象

**检查要点**：
- [ ] 关键意象是否贯穿全文
- [ ] 是否有词汇重复的问题
- [ ] 同一词汇短篇幅内重复是否超过3次
- [ ] 象征性元素的使用是否恰当

## 二、质量评估维度

### 2.1 内容维度

| 维度 | 说明 | 检查要点 |
|------|------|----------|
| 情节逻辑 | 情节发展是否合理 | 是否存在逻辑漏洞 |
| 人物一致性 | 行为、性格、对话是否统一 | 性格是否自洽 |
| 节奏控制 | 快慢节奏是否得当 | 是否能在关键节点营造张力 |
| 情感表达 | 情感是否真实自然 | 是否有层次感 |

### 2.2 文字维度

| 维度 | 说明 | 检查要点 |
|------|------|----------|
| 语言流畅性 | 句子是否通顺 | 是否存在拗口表达 |
| 词汇丰富度 | 是否过度使用重复词汇 | 词汇选择是否精准 |
| 修辞运用 | 比喻、拟人等是否恰当 | 是否过度使用 |
| 语法规范 | 是否存在语法错误、错别字 | 基础规范 |

### 2.3 结构维度

| 维度 | 说明 | 检查要点 |
|------|------|----------|
| 开头吸引力 | 开篇是否抓住读者 | 是否有钩子 |
| 章节过渡 | 章节之间衔接是否自然 | 是否有跳跃感 |
| 伏笔呼应 | 伏笔是否在后文得到呼应 | 是否有遗漏 |
| 结局完整性 | 结局是否合理 | 是否给人余味 |

## 三、逻辑一致性检验

### 3.1 冲突类型

| 冲突类型 | 说明 | 严重程度 |
|----------|------|----------|
| 世界观冲突 | 与设定不一致 | 🔴 高 |
| 人物冲突 | 性格/行为前后矛盾 | 🔴 高 |
| 时间线冲突 | 事件顺序混乱 | 🟡 中 |
| 细节冲突 | 物品/外貌描述不一致 | 🟢 低 |

### 3.2 检验流程

```
章节创作完成
    ↓
自动逻辑检验
    ↓
发现问题 → 标记警告 → 用户确认
    ↓
无问题 → 通过
    ↓
更新记忆文件
```

### 3.3 剧情冲突预警

**示例报告**：
```markdown
## 第15章《未知星球》逻辑检验报告

### ⚠️ 剧情冲突预警
- [世界观] 记忆文件显示世界观为"古代架空"，但本章出现"飞船"
  - 严重程度：🔴 高
  - 建议：确认是否需要调整世界观，或改为"发现神秘遗迹"

### ✅ 通过项
- [人物一致性] 主角对话风格保持冷静理性
- [伏笔] 本章推进了"主角身份"伏笔
```

## 四、低AI痕迹润色

### 4.1 AI痕迹特征

**常见AI特征**：
- 过度使用"首先、其次、最后"
- 机械的因果连接词
- 过于完美的修辞
- 缺乏个人风格的对话
- 信息堆砌感强

### 4.2 人类化重写技巧

#### 技巧1：打破机械结构

```
❌ AI风格：
首先，主角走进了森林。其次，他发现了一条小路。最后，他找到了宝藏。

✓ 人类风格：
森林很深。
他走了很久，才在一片荆棘后面发现那条小路。
宝藏就在路的尽头。
```

#### 技巧2：增加细节纹理

```
❌ 平淡叙述：
他很累。

✓ 细节描写：
他靠在墙上，腿在发抖。汗水顺着脖子流下来，浸湿了衣领。

❌ 过于流畅：
她优雅地走到窗前，轻轻推开窗户，望着远方的山峦，陷入了深深的沉思。

✓ 有意停顿：
她走到窗前。
推开窗。
山在远处。
她没在看山。
```

#### 技巧3：对话自然化

```
❌ AI对话：
"你好，"他说，"我是来自远方的旅行者。"
"很高兴认识你，"她回应，"我叫Alice。"

✓ 人类对话：
"你谁啊？"
"……旅行者。"
"哦。Alice。"
```

#### 技巧4：情绪表达间接化

```
❌ 直接表达：
他非常紧张，心跳加速。

✓ 间接暗示：
他攥紧了拳头。手心全是汗。

❌ 心理描写直白：
她感到悲伤，眼泪止不住地流下来。

✓ 行为暗示：
她背过身去，肩膀在抖。
```

## 五、润色优化方法

### 5.1 节奏优化

| 场景 | 技巧 | 示例 |
|------|------|------|
| 动作场面 | 增加短句短段落 | `他冲出去。门在身后炸开。` |
| 情感场景 | 使用较长句子 | 深入心理描写 |
| 叙述段落 | 混合长短句 | 保持阅读节奏 |
| 对话处理 | 简洁有力 | 避免冗长解释 |

### 5.2 描写增强

**感官细节**：
- 视觉：颜色、形状、光影
- 听觉：声音、语调、静默
- 触觉：温度、质感、疼痛
- 嗅觉：气味、氛围
- 味觉：食物、情绪

**环境烘托**：
- 用环境反映人物心境
- 天气作为情绪符号
- 意象复现形成符号

**动作细节**：
- 通过具体动作展现状态
- 用动作代替心理描写
- 微表情传递情感

### 5.3 对话优化

| 原则 | 说明 |
|------|------|
| 个性化 | 每个角色有独特说话方式 |
| 自然化 | 符合口语习惯，避免文艺腔 |
| 信息量 | 每句对话都有意义 |
| 潜台词 | 善用隐含信息 |

### 5.4 语言精炼

- **删除冗余**：去除重复、啰嗦的表达
- **替换陈词**：用更精准、生动的词汇
- **调整句式**：变换句式结构，避免单一
- **统一风格**：确保全文语言一致

## 六、检查报告格式

### 6.1 标准报告模板

```markdown
# 章节质量检查报告

## 基本信息
- 章节编号：第 X 章
- 章节标题：《标题》
- 字数：XXXX 字
- 检查时间：YYYY-MM-DD

## 数据统计

### 字数统计
- 总字数：XXXX 字 ✅/⚠️
- 段落数量：XX 个
- 平均段落长度：XXX 字

### 对话分析
- 对话占比：XX%
- 对话段落数：X 个
- 独白/旁白：X 个

### 关键词统计
- 核心意象出现次数：X
- 高频词（>3次）：词1、词2

## 质量评估

### ✅ 通过项
- [项目1]
- [项目2]

### ⚠️ 待改进
- [问题1] → 建议
- [问题2] → 建议

### 🔴 需修复
- [冲突1] → 处理建议

## 伏笔检查
- [ ] 伏笔1：已回收/待回收
- [ ] 伏笔2：已回收/待回收

## 润色建议
1. 建议1
2. 建议2

---

**下次检查重点**：
- 重点关注项1
- 重点关注项2
```

## 七、快速自检清单

### 写完一章后自检

- [ ] 字数是否达标？
- [ ] 开头是否吸引人？
- [ ] 结尾是否有钩子？
- [ ] 是否有明显错别字？
- [ ] 对话是否自然？
- [ ] 节奏是否合适？
- [ ] 是否推进了情节？
- [ ] 是否有新伏笔需要记录？

### 修改后复查

- [ ] 修改是否引入新问题？
- [ ] 是否保持了原文优点？
- [ ] 整体是否更流畅？
- [ ] AI痕迹是否减少？
