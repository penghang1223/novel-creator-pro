## 一、主流平台概览

### 1.1 平台特点对比

| 平台 | 特点 | 适合类型 | 读者画像 |
|------|------|----------|----------|
| 番茄小说 | 免费阅读体量大 | 爽文、系统流、穿越 | 下沉市场、中老年 |
| 起点中文网 | 付费精品向 | 玄幻、科幻、悬疑 | 资深网文读者 |
| 晋江文学城 | 女性向为主 | 言情、纯爱、同人 | 年轻女性 |
| 七猫小说 | 免费保底 | 爽文、种田文 | 下沉市场 |
| 飞卢小说 | 飞卢风、快节奏 | 同人、系统流 | 年轻读者 |

### 1.2 选平台建议

**新人首发的选择**：
1. 番茄小说：流量大，签约门槛相对低
2. 起点中文网：精品导向，适合有功底的作品
3. 晋江文学城：言情/纯爱首选

## 二、番茄小说规则

### 2.1 平台特点

**优势**：
- 字节跳动流量支持
- 免费阅读，用户基数大
- 新人曝光机会多
- 签约门槛相对较低

**风格偏好**：
- 爽文、快节奏
- 冲突激烈、打脸爽
- 系统流、签到流
- 脑洞文、新奇设定

**读者特点**：
- 下沉市场占比大
- 阅读时间碎片化
- 偏好轻松解压内容

### 2.2 番茄写作规范

**书名规范**：
- 建议格式：核心爽点 + 主角/职业
- 示例：《都市：我有万亿遗产》《穿书后我嫁给了反派》

**简介规范**：
- 前三行决定读者是否点进去
- 包含：身份 + 金手指 + 核心爽点
- 避免：过于文艺/抽象

**章节规范**：
- 单章建议2000字以上
- 日更最佳（至少隔日更）
- 保持节奏紧凑

### 2.3 番茄开篇模板

```markdown
【模板一：系统流】
主角 + 系统觉醒 + 第一个任务/挑战 + 爽点展示

示例结构：
- 第1章：主角濒死，系统觉醒（身份建立）
- 第2章：系统奖励，新手礼包（能力展示）
- 第3章：第一个挑战/打脸（爽点爆发）

【模板二：穿越文】
原主困境 + 穿越觉醒 + 第一个反击/逆袭

示例结构：
- 第1章：原主被欺压/危机（困境展示）
- 第2章：主角穿越，接收记忆（身份转换）
- 第3章：第一次反击，打脸对方（爽点爆发）

【模板三：都市重生】
重生优势 + 信息差展示 + 第一个布局/打脸

示例结构：
- 第1章：重生回到关键节点
- 第2章：回忆前世，展示信息差优势
- 第3章：布局完成，第一次打脸
```

## 三、起点中文网规则

### 3.1 平台特点

**优势**：
- 付费阅读，精品导向
- 读者付费意愿高
- 大神云集，氛围专业
- 版权运营成熟

**风格偏好**：
- 深度、世界观完整
- 智斗、权谋
- 人物塑造立体
- 节奏稳健但不失爽点

**读者特点**：
- 网文老读者居多
- 鉴赏能力较高
- 愿意为优质内容付费

### 3.2 起点写作规范

**书名规范**：
- 简洁有力
- 可包含类型标签
- 示例：《诡秘之主》《全职高手》

**简介规范**：
- 展示世界观/设定亮点
- 体现主角特色
- 暗示核心冲突
- 避免太长或太短

**章节规范**：
- 单章建议2000-3000字
- 保持稳定更新
- 注重章节名

### 3.3 起点开篇模板

```markdown
【模板一：西幻/奇幻】
世界观展示 + 主角困境 + 能力/机遇展示 + 冲突建立

示例结构：
- 第1章：世界设定切入，主角处境（世界观+人设）
- 第2章：转折点，获得能力或机遇（伏笔）
- 第3章：第一次能力展示/冲突（爽点+节奏）

【模板二：都市/现实】
现实背景 + 主角特殊 + 第一个事件 + 冲突展开

示例结构：
- 第1章：主角身份+特殊之处（差异化）
- 第2章：遭遇第一个事件/挑战
- 第3章：解决/反击，建立优势

【模板三：科幻/未来】
背景设定 + 主角身份 + 危机/机遇 + 行动展开
```

## 四、晋江文学城规则

### 4.1 平台特点

**优势**：
- 女性向市场第一
- 言情/纯爱品类成熟
- 读者粘性高
- 同人创作活跃

**风格偏好**：
- 情感细腻
- 人物互动精彩
- 甜、虐、治愈
- 事业线与感情线并重

**读者特点**：
- 年轻女性为主
- 注重情感体验
- 对人设有高要求
- 愿意互动（评论、投票）

### 4.2 晋江写作规范

**书名规范**：
- 言情向：情感标签 + 主角/设定
- 示例：《偷偷藏不住》《天官赐福》
- 纯爱向：主角关系 + 特色设定

**简介规范**：
- 情感线为主
- 展示主角魅力
- 暗示感情走向
- 文案要有吸引力

**章节规范**：
- 单章建议1000-2000字
- 注重章节名（可文艺）
- 更新稳定很重要

### 4.3 晋江开篇模板

```markdown
【模板一：现代言情】
场景切入 + 主角出场 + 相遇/冲突 + 情感勾子

示例结构：
- 第1章：场景建立，主角出场（人设展示）
- 第2章：相遇/产生联结（情感铺垫）
- 第3章：冲突或甜蜜互动（情感勾子）

【模板二：古言/穿越】
原主困境 + 穿越/重生 + 第一个转折 + 伏笔

示例结构：
- 第1章：原主处境/危机
- 第2章：穿越觉醒，身份转换
- 第3章：第一次逆袭或被注意

【模板三：快穿/系统】
任务世界 + 第一个任务 + 主角魅力展示

示例结构：
- 第1章：系统说明，第一个世界
- 第2章：任务展开，智慧/魅力展示
- 第3章：任务完成，收获关注/好感
```

## 五、开篇模板适配

### 5.1 通用开篇原则

**黄金三章法则**：
1. 第一章：建立主角、设定、冲突
2. 第二章：展示能力/金手指，建立期待
3. 第三章：第一个高潮/打脸，满足期待

**开篇三要素**：
- 主角：读者要有代入感
- 冲突：要有危机或悬念
- 金手指：要有期待感

### 5.2 平台适配开篇

| 平台 | 开篇侧重点 | 节奏要求 | 字数建议 |
|------|------------|----------|----------|
| 番茄 | 爽点前置 | 最快 | 2000+ |
| 起点 | 世界观+人设 | 中快 | 2500+ |
| 晋江 | 情感张力 | 中 | 1500+ |

### 5.3 反例提醒

❌ **通用反例**：
- 大段世界观介绍
- 与主角无关的场景
- 冗长的背景铺垫
- 过于平淡的开局

✅ **正确做法**：
- 主角第一时间出场
- 冲突/危机立刻出现
- 信息逐步释放
- 节奏紧凑

## 六、黄金三章法则

### 6.1 核心要点

```
第1章：Who（主角是谁）+ Why（为什么有趣）
第2章：How（怎么做到的/能力展示）
第3章：Wow（第一个高潮/打脸）
```

### 6.2 三章结构详解

**第一章：建立**
- 主角出场（身份、处境）
- 核心冲突/危机
- 金手指暗示或觉醒
- 留下悬念钩子

**第二章：展开**
- 能力/金手指详细展示
- 第一次小试牛刀
- 与反派的初次交锋
- 持续推进的悬念

**第三章：爆发**
- 第一个高潮点
- 第一次爽点/打脸
- 建立信心和优势
- 为后续埋下伏笔

### 6.3 检验标准

- [ ] 读者能记住主角是谁
- [ ] 读者知道故事讲什么
- [ ] 读者想知道后续发展
- [ ] 有让人"想看下去"的钩子

## 七、各平台风格对比

### 7.1 文风差异

| 维度 | 番茄 | 起点 | 晋江 |
|------|------|------|------|
| 爽点密度 | 高 | 中 | 中 |
| 文笔要求 | 中 | 中高 | 中高 |
| 情感描写 | 少 | 中 | 多 |
| 世界观深度 | 浅 | 深 | 中 |
| 节奏 | 快 | 中 | 中 |
| 创新要求 | 高 | 高 | 中 |

### 7.2 读者期望差异

**番茄读者**：
- "爽就完事了"
- 节奏要快
- 打脸要直接
- 脑洞要新奇

**起点读者**：
- "好看就行"
- 注重深度
- 接受慢热
- 欣赏智斗

**晋江读者**：
- "磕到了"
- 注重CP
- 情感细腻
- 人设要立住

- [ ] 是否有深度？

### 8.3 晋江适配检查

- [ ] 情感张力是否够？
- [ ] CP是否有火花？
