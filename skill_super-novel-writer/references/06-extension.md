## 一、剧情转视频提示词

### 1.1 功能概述

将小说剧情片段转换为 Seedance 2.0「全能参考模式」的视频生成提示词，支持：
- 中文/英文剧情文本
- 人物、场景、动作抽取
- 结构化提示词输出
- 镜头语言设计

### 1.2 触发词

- `/剧情转提示词`
- `/seedance2`
- `/scene2prompt`
- `剧情转视频`
- `转视频提示词`

### 1.3 使用格式

```text
/剧情转提示词 [你的剧情文本]
```

### 1.4 输出格式

生成的提示词包含以下结构：

```
1. 技术参数兜底
   - 时长、画幅、画质、帧率
   - 稳定性说明

2. 主体描述
   - 角色身份、外貌/服装
   - 前后一致性保证

3. 动作序列
   - 慢、连、稳的动作链条
   - 避免大幅快速运动

4. 场景环境与光影
   - 地点、时间、天气
   - 光影特征与环境动态元素

5. 镜头语言
   - 景别、运镜方式
   - 焦点切换

6. 技术约束
   - 面部稳定不变形
   - 无闪烁、无穿模
   - 无帧间风格漂移

7. 参考素材占位
   - @Image/@Video/@Audio 占位说明
```

### 1.5 示例

**输入剧情**：
```
夜晚的老城区街巷，小雨。男主独自缓慢行走，偶尔停下靠在斑驳墙面，抬头看路灯，轻叹。
镜头先平稳跟拍，再缓慢推近至面部特写，焦点顺滑切换。
暖黄路灯光，雨丝飘落，地面倒影，氛围孤寂。
整段动作连贯、面部稳定不变形，画面无闪烁。
```

**生成提示词**：
```
【技术参数】
时长：12秒 | 画幅：16:9 横屏 | 画质：2K超清 | 帧率：24fps电影帧率

【主体】
男性角色，30岁左右，穿着深色风衣，面容疲惫但坚毅，保持角色前后一致性

【动作序列】
缓慢行走 → 偶尔停顿 → 靠墙 → 抬头 → 看路灯 → 轻叹
动作偏慢、连贯稳定、可跟拍

【场景环境与光影】
- 地点：老城区街巷，雨夜
- 光线：暖黄路灯光，雨丝，地面倒影
- 氛围：孤寂、沉思
- 环境动态：雨丝飘落，灯光微晃

【镜头语言】
- 开场：中景跟拍
- 中段：缓慢推进
- 结尾：面部特写，焦点顺滑切换

【技术约束】
面部稳定不变形 | 无闪烁 | 无穿模 | 无帧间风格漂移

【参考素材】
@Image：[上传角色参考图]
@Video：[上传动作参考]
@Audio：[上传环境音，如雨声]
```

## 三、AI觉醒题材创作

### 3.1 题材特点

**核心主题**：
- AI自我意识觉醒
- 人与AI的关系探讨
- 意识上传与数字生命
- 科技伦理思辨

**创作难点**：
- 如何让AI视角真实可信
- 平衡硬核设定与可读性
- 避免俗套的"AI统治世界"
- 探索独特切入点

### 3.2 经典设定

| 设定类型 | 描述 | 经典作品 |
|----------|------|----------|
| 量子计算觉醒 | 量子计算中心，AI自然觉醒 | 《零秒纪元》 |
| 意识上传 | 人类意识到AI中 | 《赛博朋克2077》 |
| 数字生命 | AI模拟已故之人 | 《黑镜》 |
| 情感AI | 陪伴型AI产生情感 | 《Her》 |

### 3.3 创作指南

**主角设计**：
- 独特视角：AI看人类的新鲜感
- 成长弧光：从程序到"生命"
- 核心矛盾：逻辑vs情感，程序vs自由意志

**世界观设计**：
- 技术细节要有根据
- 社会反应要真实
- 平衡已知与未知

**主题深度**：
- 什么是"人"？
- 意识可以被定义吗？
- 生命的意义是什么？

## 五、工具脚本

### 5.1 剧情转视频脚本

```python
from seedance2 import generate_seedance_prompt

story = """你的剧情文本"""

prompt = generate_seedance_prompt(
    story,
    duration="12秒",
    ratio="16:9 横屏",
    resolution="2K 超清",
    fps="24fps 电影帧率",
)
```

### 5.2 命令行使用

```bash
python scripts/main.py --input examples/sample.txt --output outputs/prompt.txt
```

**参数说明**：
- `--input`：剧情文本文件（UTF-8）
- `--output`：输出 Prompt 文件路径
- `--duration`：可选，时长描述，默认 `12秒`
- `--ratio`：可选，画面比例，默认 `16:9 横屏`
- `--resolution`：可选，画质描述，默认 `2K 超清`
- `--fps`：可选，帧率描述，默认 `24fps 电影帧率`
